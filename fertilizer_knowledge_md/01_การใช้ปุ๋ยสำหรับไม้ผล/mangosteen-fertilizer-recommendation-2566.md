# บทที่ 2 การใช้ปุ๋ยสำหรับมังคุด

## 1. สภาพแวดล้อมที่เหมาะสม

ปี 2564 ประเทศไทยมีพื้นที่ปลูกมังคุด 443,831 ไร่ พื้นที่ให้ผลผลิต 424,777 ไร่ ผลผลิต 270,774 ตัน และผลผลิตเฉลี่ย 637 กิโลกรัมต่อไร่

พื้นที่ควรเป็นดินร่วนปนทราย อุดมสมบูรณ์สูง สูงจากระดับทะเลไม่เกิน 650 เมตร ความลาดเอียง 1-3% และไม่ควรเกิน 15% หน้าดินลึกมากกว่า 50 เซนติเมตร ระดับน้ำใต้ดินลึกกว่า 1.5 เมตร ระบายน้ำและอากาศดี pH 5.5-6.5 EC 0-2 เดซิซีเมนส์ต่อเมตร OM ประมาณ 3% P ที่เป็นประโยชน์ 15-45 มก./กก. และ K 50-100 มก./กก. อุณหภูมิที่เหมาะสม 25-35 องศาเซลเซียส ฝนมากกว่า 2,000 มม./ปี ความชื้นสัมพัทธ์ 70-80% และต้องการแสงประมาณ 50% ของแสงปกติ

แหล่งอ้างอิง: PDF หน้า 20 (เลขหน้าในเล่ม 14)

## 2. น้ำตามระยะพืช

มังคุดต้องการน้ำมากในระยะสร้างต้น ระยะแทงช่อดอกและติดผลอ่อน รวมถึงระยะพัฒนาผล แต่ก่อนออกดอกต้องควบคุมน้ำไม่ให้มากจนแตกใบอ่อน ช่วงพัฒนาผลอายุ 8-12 สัปดาห์หลังดอกบานต้องไม่ขาดน้ำ เพราะทำให้ผลบิดเบี้ยวและเล็ก ต้นทนท่วมขังได้บ้างแต่ไม่ทนแล้ง

ปริมาณน้ำโดยประมาณคำนวณได้จาก 0.6 x อัตราการระเหย (มม./วัน) x พื้นที่ใต้ทรงพุ่ม (ตร.ม.) ตัวอย่างอัตราระเหย 3.8-5.7 มม./วัน ให้ความต้องการราว 2.3-3.4 ลิตรต่อต้นต่อวันตามสภาพพื้นที่

| ขนาดทรงพุ่ม | น้ำต่อต้นต่อวัน |
| ----------- | --------------- |
| 1-2 เมตร    | 5-20 ลิตร       |
| 3-4 เมตร    | 45-80 ลิตร      |
| 5-6 เมตร    | 125-180 ลิตร    |
| 7-8 เมตร    | 245-320 ลิตร    |
| 9-10 เมตร   | 405-500 ลิตร    |

ช่วงชักนำดอกควรงดน้ำ 10-14 วัน แล้วกลับมาให้น้ำตามอาการและระยะพืช

แหล่งอ้างอิง: PDF หน้า 21 (เลขหน้าในเล่ม 15)

## 3. วิเคราะห์ใบและป้องกันเนื้อแก้ว

เก็บใบเพสลาดคู่แรกที่ปลายกิ่งระดับกลางทรงพุ่ม จากทั้ง 4 ทิศ เมื่อใบอายุ 7-9 เดือน ค่ามาตรฐานในใบมังคุดคือ N 1.10-1.40%, P 0.05-0.08%, K 0.60-1.10%, Ca 1.00-1.40%, Mg 0.12-0.18%, Fe 50-150, Mn 50-250, Cu 5-15, Zn 15-35 และ B 25-45 มก./กก.

แคลเซียมและโบรอนเกี่ยวข้องกับคุณภาพผล โดยอาการเนื้อแก้วมักสัมพันธ์กับการสะสม Ca ต่ำ ก่อนผลอายุ 10 สัปดาห์หลังดอกบาน ต้นฉบับแนะนำให้พ่นสารประกอบแคลเซียมคลอไรด์ 10% และกรดบอริก 0.5 มก./กก. ที่ช่อผลโดยตรง ทั้งนี้ต้องตรวจฉลากและความเข้มข้นผลิตภัณฑ์จริงก่อนใช้

แหล่งอ้างอิง: PDF หน้า 22 (เลขหน้าในเล่ม 16)

## 4. ธาตุอาหารที่ออกไปกับผลผลิต

ในผลมังคุด เนื้อสะสมธาตุอาหารสูงที่สุด โดยเฉพาะ K 3.07 กก./ตันผลผลิต รองลงมาคือ N 1.00 และ P 0.47 กก./ตัน เมื่อรวมเปลือก เนื้อ เมล็ด และขั้ว ผลผลิต 1 ตันนำ N ออก 1.40 กก. P 0.57 กก. และ K 3.60 กก. จึงควรวางแผนชดเชยธาตุอาหารตามผลผลิตจริง

แหล่งอ้างอิง: PDF หน้า 23 (เลขหน้าในเล่ม 17)

## 5. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

สำหรับขนาดทรงพุ่ม 6-8 เมตร ให้แบ่งใส่ 4 ระยะ: บำรุงต้นหลังเก็บเกี่ยว, สร้างตาดอกก่อนออกดอก 1-2 เดือน, บำรุงผลหลังดอกบาน 1 เดือน และปรับปรุงคุณภาพก่อนเก็บเกี่ยว 2 เดือน

| รายการ              | ระดับดิน                      | อัตราแนะนำต่อต้นต่อปี      |
| ------------------- | ----------------------------- | -------------------------- |
| N จาก OM            | OM <2 / 2-3 / >3%             | 1,400 / 700 / 350 กรัม N   |
| P2O5 จาก Bray II    | P <15 / 15-45 / >45 มก./กก.   | 700 / 350 / 175 กรัม P2O5  |
| K2O จาก NH4OAc pH 7 | K <50 / 50-100 / >100 มก./กก. | 1,680 / 840 / 420 กรัม K2O |

ระยะยังไม่ให้ผลผลิตอายุ 1-5 ปี ใช้ปุ๋ยอินทรีย์ 15-30 กิโลกรัมต่อต้น ร่วมกับ 20-10-10 ประมาณ 0.5-1.0 กิโลกรัมต่อต้นต่อปี แบ่งใส่ 2 ครั้งตามคำแนะนำ

แหล่งอ้างอิง: PDF หน้า 23-25 (เลขหน้าในเล่ม 17-19) ตารางที่ 4-5

## 6. ถ้าไม่มีผลดิน ให้ใช้เนื้อดินเป็นตัวช่วย

| ระยะ           | ดินเหนียว/ดินร่วนเหนียว                              | ดินทราย/ดินร่วนปนทราย                                |
| -------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| อายุ 1-5 ปี    | อินทรีย์ 15-30 กก./ต้น + 20-10-10 0.5-2.5 กก./ต้น/ปี | อินทรีย์ 15-30 กก./ต้น + 20-10-10 1.0-3.0 กก./ต้น/ปี |
| บำรุงต้น       | 20-10-10 1.5 กก./ต้น + อินทรีย์ 25-50 กก.            | 20-10-10 3.0 กก./ต้น + อินทรีย์ 25-50 กก.            |
| สร้างตาดอก     | 13-13-21 1.5 กก./ต้น                                 | 13-13-21 3.0 กก./ต้น                                 |
| บำรุงผล        | 13-13-21 1.5 กก./ต้น                                 | 13-13-21 3.5 กก./ต้น                                 |
| ปรับปรุงคุณภาพ | 0-0-50 0.2 กก./ต้น                                   | 0-0-50 0.4 กก./ต้น                                   |

หว่านรอบโคนบริเวณทรงพุ่ม พรวนดินกลบ และรดน้ำตาม ดินทรายต้องใช้อัตราสูงกว่าเพราะอุ้มน้ำและดูดยึดธาตุอาหารต่ำ

แหล่งอ้างอิง: PDF หน้า 26-27 (เลขหน้าในเล่ม 20-21) ตารางที่ 6

## 7. หลักใช้งานแบบไม่หลุดจากต้นฉบับ

1. ตรวจผลดินก่อนเลือกอัตรา เพราะ OM เป็นฐานสำคัญของการประเมิน N
2. อย่าดูแต่ปุ๋ยสูตร ให้ดูธาตุอาหารที่ต้องการจริงและช่วงเวลาใส่
3. เนื้อแก้ว/ยางไหลไม่ควรแก้ด้วยการเพิ่มปุ๋ย N แบบเดา ต้องตรวจใบ ดิน น้ำ และ Ca-B ร่วมกัน
4. ช่วงก่อนออกดอกและช่วงผลอายุ 8-12 สัปดาห์ต้องควบคุมน้ำให้เหมาะ ไม่ใช่ใช้ปุ๋ยแก้ปัญหาน้ำ
