# บทที่ 3 การใช้ปุ๋ยสำหรับเงาะ

## 1. สภาพแวดล้อมและน้ำ

เงาะเป็นไม้ผลเมืองร้อนที่ต้องการความชื้นค่อนข้างสูง ปี 2564 มีพื้นที่ปลูก 226,143 ไร่ ผลผลิตรวม 283,621 ตัน และผลผลิตเฉลี่ย 1,361 กิโลกรัมต่อไร่

พื้นที่เหมาะสมสูงไม่เกิน 300 เมตร ความลาดเอียง 1-3% ดินร่วนเหนียวหรือดินร่วนปนทราย อุดมสมบูรณ์สูง ระบายน้ำดี หน้าดินลึก 2-3 เมตร pH 5.5-6.5 EC ต่ำกว่า 0.4 เดซิซีเมนส์ต่อเมตร OM 3.4-6.9% P 20-120 มก./กก. K มากกว่า 156 มก./กก. Ca มากกว่า 1,000 และ Mg มากกว่า 192 มก./กก. อุณหภูมิที่เหมาะสม 25-30 องศาเซลเซียส

เงาะต้องการน้ำตลอดฤดู ฝนเฉลี่ย 1,800-3,000 มม./ปี ต้นทรงพุ่ม 6 เมตรใช้น้ำราว 60-75 ลิตรต่อต้นต่อวัน หากแล้งเกิน 21-30 วันใบจะห่อ ระยะออกดอกถ้าขาดน้ำ ใบแก่ปลายช่อจะตั้งชันและห่อ ให้ประมาณ 1,000 ลิตรต่อต้นต่อครั้ง 1 ครั้งแล้วหยุด; เมื่อตายอดเปลี่ยนจากน้ำตาลเป็นน้ำตาลทอง ให้น้ำประมาณ 500 ลิตรต่อต้นต่อวัน; เมื่อตายอดเริ่มพัฒนาเป็นตาดอก ให้น้ำ 85-110 ลิตรต่อต้นต่อวัน

แหล่งอ้างอิง: PDF หน้า 29-30 (เลขหน้าในเล่ม 22-23)

## 2. ธาตุอาหารและการสูญเสีย

ผลเงาะมี N 0.98%, P 0.15%, K 0.88%, Ca 0.27%, Mg 0.13%, S 0.09%, Fe 47.7, Mn 87.6, Cu 14.6, Zn 18.6 และ B 14.3 มก./กก. ผลผลิต 1,000 กิโลกรัมสูญเสีย N 2.1 กก., P 0.3 กก., K 1.6 กก., Ca 0.8 กก. และ Mg 0.4 กก. จึงควรให้ความสำคัญกับ N และ K โดยไม่ใส่เกินความต้องการ

แหล่งอ้างอิง: PDF หน้า 30 (เลขหน้าในเล่ม 23)

## 3. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

อัตราต่อไปนี้ใช้กับต้นขนาดทรงพุ่ม 6-8 เมตร แบ่งใส่ 4 ครั้ง คือ บำรุงต้นหลังเก็บเกี่ยว, สร้างตาดอกก่อนออกดอก 1-2 เดือน, บำรุงผลหลังดอกบาน 1 เดือน และปรับปรุงคุณภาพก่อนเก็บเกี่ยว 2 เดือน

| รายการ              | ค่าวิเคราะห์                | อัตราแนะนำต่อต้นต่อปี     |
| ------------------- | --------------------------- | ------------------------- |
| N จาก OM            | <2 / 2-3 / >3%              | 1,680 / 840 / 420 กรัม N  |
| P2O5 จาก Bray II    | <15 / 16-45 / >45 มก./กก.   | 560 / 280 / 140 กรัม P2O5 |
| K2O จาก NH4OAc pH 7 | <50 / 51-100 / >100 มก./กก. | 840 / 420 / 210 กรัม K2O  |

ต้นยังไม่ให้ผลผลิตใช้อินทรีย์ 15-30 กิโลกรัมต่อต้นต่อปี ร่วมกับ 15-15-15 ประมาณ 400 กรัมต่อต้น แบ่งใส่ 2 ครั้ง ส่วนต้นให้ผลผลิตใช้อินทรีย์ 25-50 กิโลกรัมต่อต้นต่อปีร่วมกับปุ๋ยเคมีตามตาราง

แหล่งอ้างอิง: PDF หน้า 31-32 (เลขหน้าในเล่ม 24-25) ตารางที่ 2-3

## 4. คำแนะนำตามเนื้อดิน

| ระยะ           | ดินเหนียว/ดินร่วนเหนียว                          | ดินทราย/ดินร่วนปนทราย                            |
| -------------- | ------------------------------------------------ | ------------------------------------------------ |
| อายุ 1-4 ปี    | อินทรีย์ 15-30 กก. + 15-15-15 0.5-2.0 กก./ต้น/ปี | อินทรีย์ 15-30 กก. + 15-15-15 1.0-2.5 กก./ต้น/ปี |
| บำรุงต้น       | อินทรีย์ 25-50 กก. + 20-10-10 1.5 กก./ต้น        | อินทรีย์ 25-50 กก. + 20-10-10 3.0 กก./ต้น        |
| สร้างตาดอก     | 13-13-21 1.5 กก./ต้น                             | 13-13-21 3.0 กก./ต้น                             |
| บำรุงผล        | 13-13-21 1.5 กก./ต้น                             | 13-13-21 3.0 กก./ต้น                             |

แหล่งอ้างอิง: PDF หน้า 33 (เลขหน้าในเล่ม 26) ตารางที่ 4

## 5. สรุปการตัดสินใจ

1. เงาะต้องการน้ำต่อเนื่อง แต่ระยะออกดอกต้องสังเกตตายอดและควบคุมน้ำเป็นจังหวะ
2. ผลผลิตนำ N และ K ออกจากสวนมากกว่า P จึงควรชดเชยตามผลผลิต ไม่เพิ่มปุ๋ยแบบเหมารวม
3. ใช้ผลดินเป็นหลัก หากไม่มีผลดินจึงใช้เนื้อดินเป็นตัวประมาณ
4. ปุ๋ยอินทรีย์มีบทบาททั้งธาตุอาหารและโครงสร้างดิน โดยเฉพาะสวนดินทราย
