# บทที่ 5 การใช้ปุ๋ยสำหรับลำไย

## 1. สภาพแวดล้อมและน้ำ

ลำไยเป็นไม้ผลที่ไทยผลิตและส่งออกเป็นอันดับหนึ่งของโลก ปี 2564 มีพื้นที่ปลูก 1,749,042 ไร่ พื้นที่ให้ผลผลิต 1,650,124 ไร่ ผลผลิต 1,567,087 ตัน และผลผลิตเฉลี่ย 950 กิโลกรัมต่อไร่

ลำไยปลูกได้ตั้งแต่ที่ราบถึงสูงกว่า 1,000 เมตร โดยเฉพาะดินร่วนปนทราย หน้าดินลึก ระบายน้ำและอากาศดี pH 5.0-6.5 ฝน 1,000-2,000 มม./ปี อุณหภูมิที่เจริญได้ 4-30 องศาเซลเซียส และช่วงพฤศจิกายน-มกราคมต้องการอุณหภูมิ 10-22 องศาเซลเซียสเพื่อสร้างตาดอก

ต้นอายุ 1-3 ปีในฤดูแล้ง เมื่อฝนทิ้งช่วงยาวให้ 20-60 ลิตรต่อต้นต่อครั้งทุก 7-10 วัน ต้นอายุ 4 ปีขึ้นไปหรือให้ผลแล้วควรงดน้ำช่วงออกดอก จากนั้นเริ่มให้น้ำน้อยและเพิ่มเป็น 200-300 ลิตรต่อต้นต่อครั้ง สัปดาห์ละ 2 ครั้ง สำหรับทรงพุ่ม 7 เมตร

แหล่งอ้างอิง: PDF หน้า 42 (เลขหน้าในเล่ม 33)

## 2. ค่าวิเคราะห์ใบและความต้องการตามขนาดทรงพุ่ม

เก็บใบตำแหน่งที่ 3-4 จากยอด เมื่ออายุ 6-8 สัปดาห์หรือคลี่เต็มที่ประมาณ 1 สัปดาห์ ค่ามาตรฐานคือ N 1.45-1.88%, P 0.12-0.22%, K 0.88-1.36%, Ca 0.88-1.90%, Mg 0.18-0.31%, Fe 68.11-86.99, Mn 47.00-80.46, Cu 7.87-16.10, Zn 16.99-30.13 และ B 15.32-34.49 มก./กก.

ถ้าต่ำกว่ามาตรฐานให้พิจารณาเพิ่มปุ๋ย 15-30%; ถ้าสูงกว่ามาตรฐานลด 15-30% และตรวจดินประกอบ

ปริมาณการดูดใช้ในระยะสร้างช่อใบเพิ่มตามทรงพุ่มอย่างชัดเจน เช่น ทรงพุ่ม 1 เมตรใช้ N/P/K 6.0/0.5/3.8 กรัมต่อต้น และทรงพุ่ม 7 เมตรใช้ 241.4/19.3/150.9 กรัมต่อต้น

| ขนาดทรงพุ่ม | ความต้องการต่อปีโดยประมาณ N-P-K                |
| ----------- | ---------------------------------------------- |
| 1-2 เมตร    | 40-80 / 4-8 / 35-70 กรัมต่อต้น                 |
| 3-4 เมตร    | 220-350 / 25-40 / 200-300 กรัมต่อต้น           |
| 5-6 เมตร    | 550-1,000 / 70-120 / 500-900 กรัมต่อต้น        |
| 7-8 เมตร    | 1,500-2,500 / 200-300 / 1,300-2,000 กรัมต่อต้น |

แหล่งอ้างอิง: PDF หน้า 43-44 (เลขหน้าในเล่ม 34-35) ตารางที่ 1-3

## 3. ธาตุอาหารที่สูญเสียกับผลผลิต

ผลผลิตลำไยสด 1 ตันนำ N 3.71 กก., P 0.42 กก., K 3.73 กก., Ca 1.53 กก., Mg 0.26 กก., Fe 0.021 กก., Mn 0.015 กก., Cu 0.003 กก. และ Zn 0.004 กก. ออกจากพื้นที่ ตัวเลขนี้ควรใช้ร่วมกับผลดินและจำนวนผลผลิตจริงเพื่อปรับการบำรุงต้นหลังเก็บเกี่ยว

แหล่งอ้างอิง: PDF หน้า 44-45 (เลขหน้าในเล่ม 35-36)

## 4. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

สำหรับขนาดทรงพุ่ม 8 เมตร แบ่งใส่ 4 ระยะ

| รายการ              | ค่าวิเคราะห์                | อัตราแนะนำต่อต้นต่อปี      |
| ------------------- | --------------------------- | -------------------------- |
| N จาก OM            | <1.5 / 1.5-2.5 / >2.5%      | 1,440 / 720 / 360 กรัม N   |
| P2O5 จาก Bray II    | <15 / 15-45 / >45 มก./กก.   | 800 / 400 / 200 กรัม P2O5  |
| K2O จาก NH4OAc pH 7 | <50 / 50-100 / >100 มก./กก. | 1,360 / 680 / 360 กรัม K2O |

ต้นอายุ 1-4 ปีใช้อินทรีย์ 15-30 กิโลกรัมต่อต้นต่อปี ร่วมกับ 20-10-10 อัตรา 0.5-2.0 กก./ต้น/ปีในดินเหนียวหรือร่วนเหนียว และ 1.0-2.5 กก./ต้น/ปีในดินทราย แบ่ง 2 ครั้ง เพิ่มปุ๋ยปีละ 0.5 กก./ต้น/ปีตามช่วงอายุ

แหล่งอ้างอิง: PDF หน้า 45-46 (เลขหน้าในเล่ม 36-37) ตารางที่ 5-6

## 6. ปุ๋ยทางใบและสารช่วยชักนำดอก

ต้นฉบับแนะนำช่วงเตรียมต้นด้วยโมโนโพแทสเซียมฟอสเฟต 0-52-34 อัตรา 150 กรัมต่อน้ำ 20 ลิตร พ่นอย่างน้อย 3 ครั้งเมื่อใบชุดสุดท้ายอายุมากกว่า 60 วัน เพื่อให้ใบแก่พร้อมกันและป้องกันแตกใบอ่อน ช่วงชักนำดอกใช้โพแทสเซียมคลอเรต (KClO3) อัตรา 40 กรัมต่อน้ำ 20 ลิตรกับต้นที่สมบูรณ์เต็มที่ และช่วงผลขนาดประมาณ 0.5 เซนติเมตรใช้ยูเรีย 46-0-0 30 กรัม + 0-52-34 10 กรัม + 13-0-46 60 กรัมต่อน้ำ 20 ลิตร พ่นทุก 10 วัน 3 ครั้ง

ข้อมูลโพแทสเซียมคลอเรตและสารเร่งไม่ใช่คำแนะนำให้ใช้โดยอัตโนมัติ ต้องตรวจฉลาก กฎหมาย ผู้เชี่ยวชาญ และความสมบูรณ์ต้นก่อนใช้ทุกครั้ง

แหล่งอ้างอิง: PDF หน้า 9 (เลขหน้าในเล่ม 5) และ PDF หน้า 42-47 (เลขหน้าในเล่ม 33-38)
