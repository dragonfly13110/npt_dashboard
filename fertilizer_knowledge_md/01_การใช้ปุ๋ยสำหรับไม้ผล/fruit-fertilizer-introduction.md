# หลักการจัดการธาตุอาหารและการใช้ปุ๋ยสำหรับไม้ผล

บทนี้ถอดและเรียบเรียงจาก **เอกสารวิชาการ คำแนะนำการใช้ปุ๋ยสำหรับไม้ผล** ของกองวิจัยพัฒนาปัจจัยการผลิตทางการเกษตร กรมวิชาการเกษตร พิมพ์กันยายน 2566 โดยแบ่งสาระต้นฉบับไว้เป็นช่วงหน้าอย่างชัดเจน เพื่อให้ตรวจย้อนกลับได้

## 1. อ่านตัวเลขในบทความนี้อย่างไร

- ตัวเลขอัตราปุ๋ยที่ระบุเป็นปริมาณธาตุอาหาร เช่น N, P2O5 และ K2O ไม่ใช่น้ำหนักผลิตภัณฑ์เสมอไป
- หากระบุเป็นสูตร 20-10-10 หมายถึงมี N 20%, P2O5 10% และ K2O 10% โดยน้ำหนักของปุ๋ย
- อัตราต่อต้นต่อปีต้องนำไปแบ่งตามระยะการเจริญเติบโต ไม่ควรเทใส่ครั้งเดียวโดยไม่ดูคำแนะนำของพืชและดิน
- ตารางแต่ละพืชใช้ขนาดทรงพุ่มและช่วงค่าวิเคราะห์ดินเป็นเงื่อนไข จึงไม่ควรยกอัตราของพืชหนึ่งไปใช้กับอีกพืชหนึ่ง

## 2. บทบาทของธาตุอาหาร

### ธาตุอาหารหลัก

- **ไนโตรเจน (N)** ช่วยการเจริญเติบโตและการสร้างผลผลิต แต่ถ้ามากเกินไปจะทำให้แตกยอดและใบมากกว่าดอกและผล การสุกแก่ช้า คุณภาพลดลง และในไม้ผลอาจเกิดใบอ่อนแย่งอาหารกับผลอ่อนจนผลร่วง
- **ฟอสฟอรัส (P)** เกี่ยวข้องกับการสังเคราะห์ด้วยแสง การหายใจ การทำงานของเอนไซม์ และการสร้างดอกและผล
- **โพแทสเซียม (K)** ช่วยเคลื่อนย้ายแป้งและน้ำตาล การสังเคราะห์ด้วยแสง และการสร้างคุณภาพเนื้อผล

### ธาตุอาหารรองและจุลธาตุ

แคลเซียมช่วยสร้างผนังเซลล์และการแบ่งขยายเซลล์ แมกนีเซียมเป็นองค์ประกอบของคลอโรฟิลล์และเกี่ยวข้องกับการสังเคราะห์ด้วยแสง ส่วนกำมะถันเป็นองค์ประกอบของโปรตีนและมีผลต่อการสังเคราะห์ด้วยแสง จุลธาตุ ได้แก่ เหล็ก แมงกานีส ทองแดง สังกะสี โบรอน โมลิบดินัม คลอรีน และนิกเกิล แม้พืชต้องการน้อยมาก แต่การขาดธาตุใดธาตุหนึ่งทำให้การเจริญเติบโตผิดปกติและผลผลิตลดลงได้

## 3. ลำดับตัดสินใจก่อนใส่ปุ๋ย

1. ประเมินพื้นที่: หน้าดินต้องลึก ระบายน้ำและอากาศได้ และไม่มีข้อจำกัดสำคัญ เช่น อินทรียวัตถุต่ำหรือ pH ไม่เหมาะสม
2. ปรับปรุงดินก่อน: ถ้าดินมีข้อจำกัด ให้แก้สมบัติทางกายภาพ เคมี และชีวภาพก่อนเร่งใส่ปุ๋ย
3. วิเคราะห์ดิน: เก็บดินที่ความลึก 0-15 และ 15-30 เซนติเมตร เพื่อดูธาตุอาหารที่เป็นประโยชน์และใช้กำหนดอัตราปุ๋ย
4. ใช้ข้อมูลพืชร่วมกัน: พิจารณาชนิด/พันธุ์ อายุ ต้นสมบูรณ์แค่ไหน ผลผลิตที่เก็บเกี่ยวไป และระยะการเจริญเติบโต
5. แบ่งใส่ตามระยะ: ระยะบำรุงต้น ระยะสร้างตาดอก และระยะติดผล/พัฒนาผลมีความต้องการธาตุอาหารไม่เท่ากัน
6. ประเมินซ้ำ: สวนไม้ผลควรติดตามดินและอาการพืชเป็นระยะ ไม่ยึดอัตราเดิมตลอดอายุสวน

สำหรับไม้ผลอายุไม่เกิน 1 ปี ต้นฉบับเสนอให้แบ่งใส่ 3 ระยะ ได้แก่ ระยะปลูกหรือก่อนปลูก ระยะสร้างต้นและใบมาก และระยะใกล้ออกดอก ส่วนไม้ผลที่ให้ผลผลิตแล้วให้พิจารณาอายุต้น ความสมบูรณ์ สมบัติดิน และผลผลิตฤดูที่ผ่านมา

## 4. แนวทางตามระยะการเจริญเติบโตของไม้ผล

| ระยะ                    | เป้าหมาย             | แนวทางจากต้นฉบับ                                                                                                                          |
| ----------------------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| หลังเก็บเกี่ยว/บำรุงต้น | สร้างใบและสะสมอาหาร  | ใช้ปุ๋ยอินทรีย์ร่วมกับปุ๋ยเคมี โดยสัดส่วน N:P2O5:K2O อาจเป็น 1:1:1 เมื่อ OM มากกว่า 3%, 2:1:1 เมื่อ OM 2-3% และ 3:1:1 เมื่อ OM ต่ำกว่า 2% |
| ก่อนออกดอก              | ช่วยพัฒนาตาดอก       | ลดสัดส่วน N และเพิ่ม K เช่น 1:1:2 หรือ 2:1:3                                                                                              |
| ติดผลและพัฒนาผล         | เพิ่มขนาดและคุณภาพผล | ใช้สัดส่วนที่ N ไม่สูงและ K สูง เช่น 1:1:2 หรือ 2:2:3 แบ่งใส่ช่วงผลอ่อนและก่อนเก็บเกี่ยวประมาณ 1 เดือน                                    |

ช่วงบำรุงต้นในฤดูฝนควรแบ่งใส่ประมาณ 3 ครั้งเพื่อลดการชะล้าง ส่วนช่วงติดผลควรแบ่งใส่ 2 ครั้งตามจังหวะพืช

## 5. ปุ๋ยอินทรีย์และปุ๋ยชีวภาพ

ปุ๋ยอินทรีย์ เช่น ปุ๋ยหมักและปุ๋ยคอก ช่วยให้ดินโปร่ง ร่วนซุย ระบายน้ำและถ่ายเทอากาศดีขึ้น ต้นที่ยังไม่ให้ผลผลิตใช้ประมาณ 15-30 กิโลกรัมต่อต้นต่อครั้งร่วมกับปุ๋ยเคมี ส่วนต้นที่ให้ผลผลิตแล้วใช้ประมาณ 25-50 กิโลกรัมต่อต้นต่อครั้งในระยะบำรุงต้นหลังเก็บเกี่ยว หว่านรอบทรงพุ่ม พรวนดินกลบ และรดน้ำตาม

ปุ๋ยชีวภาพมี 2 กลุ่มใหญ่ คือ (1) จุลินทรีย์สร้างธาตุอาหาร โดยเฉพาะจุลินทรีย์ตรึงไนโตรเจน ทั้งแบบอยู่ร่วมกับพืชและแบบอิสระ และ (2) จุลินทรีย์ที่ทำให้ธาตุอาหารเป็นประโยชน์ เช่น ไมคอร์ไรซา จุลินทรีย์ละลายฟอสเฟต และจุลินทรีย์ละลายโพแทสเซียม

อัตราการใช้ที่ต้นฉบับยกตัวอย่างคือ อาร์บัสคูลาร์ไมคอร์ไรซา 3 กรัมต่อถุงเพาะ, 10 กรัมต่อหลุม, 30-40 กรัมต่อต้นสำหรับอายุ 1-3 ปี และ 40-50 กรัมต่อต้นสำหรับอายุ 3 ปีขึ้นไป ส่วนปุ๋ยชีวภาพละลายฟอสเฟตใช้ 10 กรัมต่อถุงเพาะหรือหลุม, 50-100 กรัมต่อต้นสำหรับอายุ 1-3 ปี และ 100-200 กรัมต่อต้นสำหรับอายุ 3 ปีขึ้นไป โดยคลุกกับปุ๋ยอินทรีย์และกลบดินทันที

## 6. ปุ๋ยทางใบสำหรับแก้ขาดธาตุ

ปุ๋ยทางใบดูดใช้ได้เร็ว จึงเหมาะเป็นตัวช่วยเสริมเมื่อพืชขาดธาตุหรือรากมีปัญหา แต่ความเข้มข้นสูงเกินไปทำให้ใบไหม้ ตารางอัตราต่อน้ำ 100 ลิตรจากต้นฉบับมีดังนี้

| ธาตุ | ผลิตภัณฑ์/สารประกอบ                   | อัตราต่อน้ำ 100 ลิตร |
| ---- | ------------------------------------- | -------------------- |
| N    | ยูเรีย                                | 500-1,000 กรัม       |
| P    | โมโนโพแทสเซียมฟอสเฟต                  | 125-250 กรัม         |
| K    | โพแทสเซียมซัลเฟตหรือโพแทสเซียมคลอไรด์ | 300-500 กรัม         |
| Ca   | แคลเซียมไนเตรท                        | 600 กรัม             |
| Mg   | แมกนีเซียมซัลเฟต                      | 1.5 กิโลกรัม         |
| Mn   | แมงกานีสซัลเฟต                        | 100-200 กรัม         |
| Fe   | เหล็กซัลเฟต                           | 400 กรัม             |
| Zn   | สังกะสีซัลเฟตเฮปตะไฮเดรต              | 400 กรัม             |
| Cu   | คอปเปอร์ซัลเฟต                        | 100-200 กรัม         |
| B    | ไดโซเดียมออกตะบอเรตเตตระไฮเดรต        | 100 กรัม             |

ตัวอย่างการใช้ตามระยะพืชในต้นฉบับ: ทุเรียนใช้ 15-30-15 หรือ 20-20-20 อัตรา 60 กรัมต่อน้ำ 20 ลิตรในใบเพสลาด; ลำไยและลิ้นจี่ใช้ 0-52-34 อัตรา 150 กรัมต่อน้ำ 20 ลิตรอย่างน้อย 3 ครั้งเมื่อใบชุดสุดท้ายอายุมากกว่า 60 วัน; มะม่วงใช้โพแทสเซียมไนเตรท 200-250 กรัมต่อน้ำ 20 ลิตรหลังตัดแต่งกิ่ง 10-15 วัน; สับปะรดมีสูตรเฉพาะตามช่วงเตรียมต้นและบังคับดอก

## 7. เช็กลิสต์ใช้จริง

- [ ] เลือกอัตราตามชนิดพืช ขนาดทรงพุ่ม อายุ และระยะพืช

- [ ] แบ่งใส่และให้น้ำตามจังหวะการดูดใช้ ลดการสูญเสีย
- [ ] ไม่เพิ่มไนโตรเจนเพียงเพราะพืชโตช้าโดยยังไม่หาสาเหตุจากดิน น้ำ ราก และโรค
