# บทที่ 1 การใช้ปุ๋ยสำหรับทุเรียน

## 1. ข้อมูลและเงื่อนไขแปลง

ทุเรียนเป็นไม้ผลเศรษฐกิจสำคัญ ปี 2564 ประเทศไทยมีพื้นที่ปลูก 1,222,913 ไร่ ผลผลิต 1,217,700 ตัน และผลผลิตเฉลี่ย 1,404 กิโลกรัมต่อไร่ แหล่งปลูกสำคัญอยู่ภาคตะวันออกและภาคใต้

พื้นที่เหมาะสมอาจเป็นที่ราบ ลูกคลื่น หรือเนินเขา สูงไม่เกิน 650 เมตรจากระดับทะเล ดินควรเป็นดินร่วนปนทรายถึงดินร่วนเหนียว หน้าดินลึกมากกว่า 1.5 เมตร ระบายน้ำและอากาศดี pH 4.5-6.5 และไม่มีปัญหาความเค็ม อุณหภูมิที่เหมาะสม 22-34 องศาเซลเซียส ความชื้นสัมพัทธ์ 75-80% ฝน 1,500-3,000 มิลลิเมตรต่อปี และควรมีช่วงแล้ง 20-30 วันเพื่อสะสมอาหารก่อนออกดอก

แหล่งอ้างอิง: PDF หน้า 12 (เลขหน้าในเล่ม 7)

## 3. ค่าธาตุอาหารในใบและการแปลผล

ควรเก็บใบอายุ 45-60 วันหลังแตกใบใหม่ ตำแหน่งใบที่ 2-3 จากกิ่งระดับกลางของทรงพุ่ม และควรเก็บจากแปลงอย่างมีแบบแผน

| ธาตุ | ช่วงมาตรฐานในใบ |
| ---- | --------------- |
| N    | 2.0-2.4%        |
| P    | 0.15-0.25%      |
| K    | 1.5-2.5%        |
| Ca   | 1.7-2.5%        |
| Mg   | 0.25-0.50%      |
| Fe   | 40-120 มก./กก.  |
| Mn   | 50-120 มก./กก.  |
| Cu   | 10-25 มก./กก.   |
| Zn   | 10-30 มก./กก.   |
| B    | 30-70 มก./กก.   |

ถ้าต่ำกว่ามาตรฐาน ให้ตรวจดินหาสาเหตุร่วม และพิจารณาเพิ่มปุ๋ยประมาณ 15-30% จากอัตราแนะนำพร้อมเสริมปุ๋ยทางใบ; ถ้าสูงกว่ามาตรฐาน ให้ลดประมาณ 15-30% ไม่ควรแก้ด้วยการเพิ่มหรือลดปุ๋ยโดยดูจากอาการเพียงอย่างเดียว

แหล่งอ้างอิง: PDF หน้า 13-14 (เลขหน้าในเล่ม 8-9)

## 4. ธาตุอาหารที่ออกไปกับผลผลิต

โพแทสเซียมเป็นธาตุที่มีความเข้มข้นสูงสุดในเปลือก เนื้อ และเมล็ด ช่วยการสร้างคาร์โบไฮเดรต ขนาดผล และความหวาน โดยค่าความเข้มข้นเฉลี่ยในเปลือก/เนื้อ/เมล็ดตามลำดับคือ K 1.76/1.73/1.35%, N 0.86/1.50/1.26% และ P 0.21/0.12/0.20% แคลเซียมและโบรอนแม้มีปริมาณน้อยแต่สำคัญต่อการผสมเกสร การสร้างพู เนื้อ และเปลือก

การสูญเสียธาตุอาหารต่อผลผลิต 1 ตันมีค่าประมาณ N 2.19-3.19 กก., P 0.42-0.45 กก., K 4.39-5.37 กก., Ca 0.26-0.62 กก., Mg 0.40-0.51 กก. และ S 0.24-0.32 กก. จึงควรใช้ผลผลิตจริงร่วมกับผลดินในการปรับอัตราปุ๋ย

แหล่งอ้างอิง: PDF หน้า 14-16 (เลขหน้าในเล่ม 9-11)

## 5. อัตราปุ๋ยตามค่าวิเคราะห์ดิน

ตารางนี้เป็นอัตรา **ธาตุอาหารต่อต้นต่อปี** สำหรับขนาดทรงพุ่ม 8 เมตร แบ่งใส่ 4 ครั้ง และควรวิเคราะห์ดินซ้ำทุก 5 ปี

| รายการ            | ค่าวิเคราะห์ดิน               | อัตราธาตุอาหารแนะนำ        |
| ----------------- | ----------------------------- | -------------------------- |
| N จาก OM          | OM <2% / 2-3% / >3%           | 1,920 / 960 / 720 กรัม N   |
| P จาก Bray II     | P <15 / 15-45 / >45 มก./กก.   | 800 / 400 / 200 กรัม P2O5  |
| K จาก NH4OAc pH 7 | K <50 / 50-100 / >100 มก./กก. | 1,600 / 800 / 400 กรัม K2O |

### สูตรผสมตามระยะ

- ระยะบำรุงต้นหลังเก็บเกี่ยว: สูตร N สูงกว่าระยะอื่น โดยอัตราแม่ปุ๋ยจริงต้องเลือกจากแถว OM-P-K ในตารางที่ 5 PDF หน้า 17
- ระยะสร้างตาดอกก่อนออกดอก 1-2 เดือน: ลด N และคง P เพิ่ม K
- ระยะบำรุงผลหลังดอกบาน 1 เดือน: ใช้ P และ K เพียงพอเพื่อขยายผล
- ระยะปรับปรุงคุณภาพก่อนเก็บเกี่ยว 2 เดือน: ต้นฉบับให้ K เป็นหลัก และหลายกรณีไม่ต้องใส่ 46-0-0 หรือ 18-46-0

แหล่งอ้างอิง: PDF หน้า 16-18 (เลขหน้าในเล่ม 11-13) ตารางที่ 4-6

## 7. ปุ๋ยทางใบและจุดควบคุมสำคัญ

เตรียมต้นก่อนออกดอกด้วยปุ๋ยเกล็ด 15-30-15 หรือ 20-20-20 ที่มีธาตุรองและจุลธาตุ 60 กรัมต่อน้ำ 20 ลิตร พ่นช่วงใบเพสลาด 1-2 ครั้ง ถ้าดอกออกน้อยกว่า 60% ของกิ่งที่ออกดอกได้และความหนาแน่นต่ำกว่า 3 ช่อดอกต่อกิ่งยาว 1 เมตร ต้นฉบับให้พิจารณาโพแทสเซียมไนเตรท 13-0-46 อัตรา 100-200 กรัมร่วมสารสกัดสาหร่าย 60 มิลลิลิตรต่อน้ำ 20 ลิตร พ่นให้ทั่วพอเปียก ส่วนการติดผลให้พ่นสารประกอบแคลเซียมและโบรอนเมื่อดอกอายุ 6 สัปดาห์ 1 ครั้ง

**คำเตือน:** อัตราข้างต้นเป็นข้อมูลจากเอกสารปี 2566 ต้องพิจารณาฉลากผลิตภัณฑ์จริง ความเข้มข้น และสภาพสวนก่อนใช้ โดยเฉพาะสารที่ไม่ใช่ปุ๋ยธาตุอาหารโดยตรง

## แหล่งอ้างอิงต้นฉบับ

กองวิจัยพัฒนาปัจจัยการผลิตทางการเกษตร กรมวิชาการเกษตร. 2566. _คำแนะนำการใช้ปุ๋ยสำหรับไม้ผล_. บทที่ 1 การใช้ปุ๋ยสำหรับทุเรียน, PDF หน้า 11-18 (เลขหน้าในเล่ม 7-13).
