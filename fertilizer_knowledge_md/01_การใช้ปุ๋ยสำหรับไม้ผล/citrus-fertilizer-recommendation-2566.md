# บทที่ 7 การใช้ปุ๋ยสำหรับส้ม

## 1. สภาพแวดล้อมและการให้น้ำ

ปี 2564 ประเทศไทยมีพื้นที่ปลูกส้ม 128,046 ไร่ พื้นที่ให้ผลผลิต 111,679 ไร่ ผลผลิต 259,354 ตัน และผลผลิตเฉลี่ย 2,322 กิโลกรัมต่อไร่

ส้มปลูกได้สูงถึง 1,800 เมตร ดินเหมาะสมตั้งแต่ดินทรายละเอียดถึงดินร่วนที่ชั้นดินลึกและระบายน้ำดี pH 5.0-7.0 EC ไม่เกิน 1.6 เดซิซีเมนส์ต่อเมตร OM มากกว่า 2% P 15-45 และ K 50-100 มก./กก. อากาศเหมาะสม 23-30 องศาเซลเซียส ฝน 1,500-2,000 มม./ปี และควรมีช่วงแล้ง 20-30 วันก่อนออกดอก

หลังปลูกให้น้ำทันที 20-40 ลิตรต่อต้น แล้วทุก 2-5 วันจนตั้งตัว ช่วงให้น้ำเหมาะสม 08.00-10.00 น. และ 14.00-16.00 น. ระยะชักนำดอกหลังแตกใบอ่อน 60-90 วัน งดน้ำประมาณ 7 วัน เมื่อเห็นอาการเครียดให้น้ำ 150-250 ลิตรต่อวัน แล้วงดต่อ 4-5 วัน หากเห็นตาดอกให้น้ำน้อยแต่สม่ำเสมอ ระยะพัฒนาผลให้น้ำ 150-250 ลิตรต่อวัน และก่อนเก็บเกี่ยวประมาณ 10 วันงดน้ำเพื่อคุณภาพและการเก็บรักษา

แหล่งอ้างอิง: PDF หน้า 56-57 (เลขหน้าในเล่ม 45-46)

## 2. บทบาทของ N และ K

N เกี่ยวข้องกับการแบ่งและขยายเซลล์ ผลขาด N จะเล็ก แต่ N มากเกินไปก็ทำให้ผลเล็กและคุณภาพลดลง K ช่วยเคลื่อนย้ายน้ำตาลและพัฒนาคุณภาพผล หากขาด K ผลเล็ก เปลือกบาง แคระแกร็น และร่วง แต่ K มากเกินไปทำให้แก่ช้า สีซีด เปลือกหนา เนื้อหยาบ ฟ่าม น้ำส้มและน้ำตาลลดลง รวมถึงรบกวน Mg และ Ca

ค่ามาตรฐานในใบตำแหน่ง 4-6 อายุ 2-4 เดือนหรือก่อนแตกยอดอ่อนในประเทศไทยคือ N 2.4-2.6%, P 0.12-0.16%, K 0.80-1.10%, Ca 3.0-5.5%, Mg 0.26-0.60%, Mn 25-100, Cu 5-16, Zn 25-100 และ B 31-100 มก./กก.

แหล่งอ้างอิง: PDF หน้า 57-59 (เลขหน้าในเล่ม 46-48) ตารางที่ 1-2

## 3. ธาตุอาหารที่สูญเสียกับผลผลิต

ผลส้มสด 1 ตันนำ K ออกมากที่สุด 2,662 กรัม รองลงมา N 1,773 กรัม, Ca 721 กรัม, P 221 กรัม, Mg 221 กรัม, S 142 กรัม, Fe 3.0 กรัม, Mn 0.8 กรัม, Cu 0.6 กรัม, Zn 1.4 กรัม และ B 2.8 กรัม ปริมาณผลผลิตปีที่ผ่านมาจึงต้องนำมาประกอบการวางแผนปุ๋ย โดยเฉพาะระยะบำรุงต้นหลังเก็บเกี่ยว

แหล่งอ้างอิง: PDF หน้า 59 (เลขหน้าในเล่ม 48) ตารางที่ 3

## 4. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

สำหรับขนาดทรงพุ่ม 4 เมตร แบ่งใส่ 4 ระยะ

| รายการ              | ค่าวิเคราะห์                | อัตราแนะนำต่อต้นต่อปี     |
| ------------------- | --------------------------- | ------------------------- |
| N จาก OM            | <1.5 / 1.5-2.5 / >2.5%      | 800 / 400 / 200 กรัม N    |
| P2O5 จาก Bray II    | <15 / 15-45 / >45 มก./กก.   | 480 / 240 / 120 กรัม P2O5 |
| K2O จาก NH4OAc pH 7 | <50 / 50-100 / >100 มก./กก. | 640 / 320 / 160 กรัม K2O  |

ต้นอายุ 1-2 ปีใช้อินทรีย์ 15-30 กิโลกรัมต่อต้นต่อปีร่วมกับ 20-10-10 0.5 กก./ต้น แบ่ง 2 ครั้ง ส่วนต้นให้ผลผลิตใช้อินทรีย์ 25-50 กิโลกรัมต่อต้นต่อปีร่วมกับปุ๋ยเคมีตามค่าวิเคราะห์

แหล่งอ้างอิง: PDF หน้า 60-61 (เลขหน้าในเล่ม 49-50) ตารางที่ 4-5

## 6. ข้อควรคุม

- ส้มต้องการความชื้นตลอดปี แต่ระยะชักนำดอกต้องงดน้ำเป็นช่วง ไม่ใช่งดทั้งฤดู
- อย่าแก้ต้นโทรมด้วย N อย่างเดียว เพราะน้ำขัง รากเสีย และโรคแมลงทำให้ต้นโทรมได้
- K ต้องพอดี: ขาดก็คุณภาพตก มากไปก็ทำให้แก่ช้าและรบกวน Ca/Mg
- วิเคราะห์ใบอย่างน้อยปีละ 1 ครั้ง โดยเฉพาะหลังเก็บเกี่ยว ตามคำแนะนำในต้นฉบับ
