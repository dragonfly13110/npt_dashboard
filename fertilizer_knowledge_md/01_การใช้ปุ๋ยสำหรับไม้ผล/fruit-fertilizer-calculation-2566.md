# ภาคผนวก: ตัวอย่างคำนวณแม่ปุ๋ยตามค่าวิเคราะห์ดิน

บทนี้ถอดตัวอย่างคำนวณของต้นฉบับ เพื่อให้เห็นวิธีแปลงอัตราธาตุอาหารเป็นน้ำหนักแม่ปุ๋ย ไม่ใช่สูตรตายตัวสำหรับทุกสวน

## 1. ข้อมูลตั้งต้น

แปลงมังคุดมี OM ต่ำกว่า 2%, P ที่เป็นประโยชน์ต่ำกว่า 15 มก./กก. และ K ต่ำกว่า 50 มก./กก. ตามตารางค่าวิเคราะห์ดินของมังคุด ต้องการ N 1.40 กก./ต้น/ปี, P2O5 0.70 กก./ต้น/ปี และ K2O 1.68 กก./ต้น/ปี

## 2. คำนวณ 18-46-0 จากความต้องการ P2O5

ปุ๋ย 18-46-0 จำนวน 100 กก. มี P2O5 46 กก.

- ปริมาณ 18-46-0 ที่ต้องใช้ = (100 x 0.70) / 46 = 1.52 กก./ต้น/ปี
- N ที่ได้จาก 18-46-0 = (18 x 1.52) / 100 = 0.27 กก. N
- N ที่ยังขาด = 1.40 - 0.27 = 1.13 กก. N

## 3. คำนวณ 46-0-0 เพื่อเติม N

ปุ๋ย 46-0-0 จำนวน 100 กก. มี N 46 กก.

- ปริมาณ 46-0-0 ที่ต้องใช้ = (100 x 1.13) / 46 = 2.45 กก./ต้น/ปี

## 4. คำนวณ 0-0-50 เพื่อเติม K2O

ปุ๋ย 0-0-50 จำนวน 100 กก. มี K2O 50 กก.

- ปริมาณ 0-0-50 ที่ต้องใช้ = (100 x 1.68) / 50 = 3.36 กก./ต้น/ปี

ดังนั้น ตัวอย่างนี้ใช้ 18-46-0 1.52 กก., 46-0-0 2.45 กก. และ 0-0-50 3.36 กก. ต่อต้นต่อปี โดยต้องแบ่งตามระยะพืช ไม่เททั้งหมดครั้งเดียว

แหล่งอ้างอิง: PDF หน้า 80 (เลขหน้าในเล่ม 67)

## 5. ตัวอย่างเมื่อใช้ปุ๋ยเชิงผสม

อีกกรณีหนึ่ง ดินมี OM, P และ K ระดับปานกลาง จึงต้องการ N 700 กรัม, P2O5 350 กรัม และ K2O 840 กรัมต่อต้นต่อปี แบ่ง 4 ระยะ โดยสัดส่วนระยะคือ บำรุงต้น 2:1:1, สร้างตาดอก 1:1:2, บำรุงผล 1:1:2 และปรับปรุงคุณภาพ 0:0:2

ตัวอย่างการแปลงเป็นปุ๋ยเชิงผสมจากต้นฉบับ

| ระยะ           | สูตร                   | อัตราประมาณต่อต้น |
| -------------- | ---------------------- | ----------------- |
| บำรุงต้น       | 15-15-15 หรือ 20-10-10 | ประมาณ 2 กก.      |
| สร้างตาดอก     | 13-13-21               | ประมาณ 1.5 กก.    |
| บำรุงผล        | 13-13-21               | ประมาณ 1.5 กก.    |
| ปรับปรุงคุณภาพ | 0-0-50                 | ประมาณ 0.5 กก.    |

หลักคำนวณคือ (ธาตุอาหารที่ต้องการ x 100) / เปอร์เซ็นต์ธาตุอาหารในสูตร แล้วปัดเป็นอัตราที่ชั่งและแบ่งใส่ได้จริง โดยต้องตรวจว่าสูตรที่เลือกเติมธาตุอื่นเกินความต้องการหรือไม่

แหล่งอ้างอิง: PDF หน้า 81 (เลขหน้าในเล่ม 68)

## 6. เช็กลิสต์ก่อนนำไปใช้

- ตรวจหน่วยให้ชัดว่าเป็นกิโลกรัมหรือกรัมต่อต้น และเป็นต่อปีหรือ ต่อครั้ง
- ใช้เปอร์เซ็นต์บนถุงปุ๋ยจริง ไม่ใช้ชื่อสูตรจากความจำ
- แม่ปุ๋ย 18-46-0 เติมทั้ง P2O5 และ N ต้องหัก N ที่ได้รับออกก่อนเติมด้วย 46-0-0
- ปุ๋ย K มีทั้ง 0-0-50 และ 0-0-60 ต้องคำนวณตามเปอร์เซ็นต์จริง
- อัตราในภาคผนวกเป็นตัวอย่างมังคุดจากเงื่อนไขดินที่ระบุ ไม่ควรย้ายไปพืชอื่น
