# บทที่ 8 การใช้ปุ๋ยสำหรับมะพร้าว

## 1. สภาพแวดล้อมและน้ำ

มะพร้าวแบ่งตามการใช้ประโยชน์เป็นมะพร้าวอุตสาหกรรม มะพร้าวบริโภคผลสด และมะพร้าวผลิตน้ำตาล ปี 2564 มีพื้นที่ปลูก 860,903 ไร่ ผลผลิตรวม 651,856,000 ผล และผลผลิตเฉลี่ย 813 ผลต่อไร่

พื้นที่เหมาะสมสูงไม่เกิน 100 เมตร ดินเกือบทุกชนิดโดยเฉพาะดินร่วน หน้าดินลึกไม่น้อยกว่า 50 เซนติเมตร ระบายน้ำและอากาศดี pH 5.5-7.5 ฝนไม่น้อยกว่า 1,500 มม./ปี อุณหภูมิเฉลี่ย 20-27 องศาเซลเซียส และความชื้นสัมพัทธ์เฉลี่ยไม่ต่ำกว่า 60% หลีกเลี่ยงการปลูกฤดูแล้งเพราะเสี่ยงยืนต้นตาย

มะพร้าวต้องการน้ำสูง การขาดน้ำลดการสร้างตาดอก การติดผล และผลผลิต ต้นยังไม่ให้ผลผลิตควรให้น้ำอย่างน้อย 80 ลิตรต่อต้นต่อสัปดาห์ ส่วนต้นให้ผลแล้วอย่างน้อย 385-840 ลิตรต่อต้นต่อสัปดาห์

แหล่งอ้างอิง: PDF หน้า 64 (เลขหน้าในเล่ม 52)

## 2. วิเคราะห์ใบและบทบาทของธาตุ

ไนโตรเจนช่วยสังเคราะห์แสงและทำให้ดอกตัวเมียพัฒนาเป็นผล ฟอสฟอรัสช่วยราก ดอก และผล โพแทสเซียมช่วยสร้างน้ำและเนื้อ เพิ่มขนาดผล ความแข็งแรงของเปลือก กะลา เส้นใย จำนวนช่อดอก ดอกตัวเมีย และความหวาน

เก็บตัวอย่างใบทางใบที่ 14 จากยอดลงมา เลือกใบย่อยกึ่งกลางทางใบข้างละ 5-10 ใบ ตัดโคนและปลาย เหลือช่วงกลางยาว 10-12 นิ้ว แล้วลอกเส้นกลางใบออก

| ธาตุ | ค่ามาตรฐานในใบมะพร้าวอายุ 6 ปีขึ้นไป |
| ---- | ------------------------------------ |
| N    | 1.80-2.00%                           |
| P    | 0.12-0.13%                           |
| K    | 0.80-1.00%                           |
| Ca   | 0.30-0.50%                           |
| Mg   | 0.25%                                |
| Fe   | 50 มก./กก.                           |
| Mn   | 60 มก./กก.                           |

ถ้าต่ำกว่ามาตรฐานให้เพิ่มปุ๋ย 15-30%; ถ้าสูงกว่ามาตรฐานให้ลด 15-30%

แหล่งอ้างอิง: PDF หน้า 65 (เลขหน้าในเล่ม 53) ตารางที่ 1

## 3. ธาตุอาหารที่สูญเสีย

มะพร้าวดูดใช้ K มากที่สุด ประมาณ 13.60-20.20 กก./ไร่/ปี ขณะที่ N 9.44-15.68, P 4.32-7.36, Ca 13.60 และ Mg 5.6 กก./ไร่/ปี ประมาณ 62% ของ K ที่ดูดใช้เกี่ยวข้องกับการเพิ่มผลผลิต

ข้อมูลการสูญเสียต่อไร่ต่อปีจากส่วนของผลโดยเฉลี่ย 10 ทะลายคือ น้ำ N/P/K/Ca/Mg 0.12/0.05/1.21/0.06/0.04 กก., กะลา 0.67/0.04/1.15/0.09/0.07 กก., เนื้อ 7.37/1.02/3.88/0.16/0.59 กก. และกาบ 3.92/0.43/23.45/0.69/0.92 กก. รวม N 12.08, P 1.54, K 29.69, Ca 1.00 และ Mg 1.62 กก.

แหล่งอ้างอิง: PDF หน้า 65-66 (เลขหน้าในเล่ม 53-54) ตารางที่ 2

## 4. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

สำหรับขนาดทรงพุ่ม 5 เมตร แบ่งใส่ 2 ครั้งต่อต้นต่อปี ช่วงต้นฤดูฝนและปลายฤดูฝน

| รายการ              | ค่าวิเคราะห์                | อัตราแนะนำต่อต้นต่อปี      |
| ------------------- | --------------------------- | -------------------------- |
| N จาก OM            | <1.5 / 1.5-2.5 / >2.5%      | 1,200 / 600 / 300 กรัม N   |
| P2O5 จาก Bray II    | <15 / 15-45 / >45 มก./กก.   | 500 / 250 / 125 กรัม P2O5  |
| K2O จาก NH4OAc pH 7 | <50 / 50-100 / >100 มก./กก. | 1,000 / 500 / 250 กรัม K2O |

ต้นฉบับมีตารางผสมแม่ปุ๋ย 46-0-0, 18-46-0 และ 0-0-60 สำหรับต้นอายุ 6 ปีขึ้นไปไว้ที่ PDF หน้า 67 โดยแบ่งเป็นการบำรุงต้นครั้งที่ 1 และสร้างตาดอกครั้งที่ 2

แหล่งอ้างอิง: PDF หน้า 66-67 (เลขหน้าในเล่ม 54-55) ตารางที่ 3-4

## 6. จุดควบคุม

- มะพร้าวเป็นพืชอายุยาว การสะสมผลผลิตและการนำกาบ/เนื้อออกจากสวนทำให้ K สูญเสียมาก ต้องวางแผนชดเชยระยะยาว
- อย่าเพิ่ม K เกินโดยไม่ตรวจ Mg และ Ca เพราะอาจทำให้สมดุลธาตุเสีย
- มะพร้าวที่ยังไม่ให้ผลและให้ผลแล้วใช้อัตราไม่เท่ากัน ต้องระบุอายุและวัตถุประสงค์การผลิตก่อนคำนวณ
