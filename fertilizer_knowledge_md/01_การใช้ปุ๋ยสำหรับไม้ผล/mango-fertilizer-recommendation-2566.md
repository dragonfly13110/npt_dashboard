# บทที่ 4 การใช้ปุ๋ยสำหรับมะม่วง

## 1. สภาพแวดล้อมและการจัดการน้ำ

มะม่วงเป็นไม้ผลเศรษฐกิจ ปี 2564 มีพื้นที่ปลูก 913,888 ไร่ ผลผลิต 903,311 ตัน และผลผลิตเฉลี่ย 2,077 กิโลกรัมต่อไร่

พื้นที่ปลูกสูงไม่เกิน 300 เมตร ปลูกได้ทั้งที่ดอนและที่ลุ่ม โดยเฉพาะดินร่วนปนทรายที่ไม่ท่วมขัง ระบายน้ำและอากาศดี pH 5.5-7.5 EC 0-2 เดซิซีเมนส์ต่อเมตร และ OM ไม่น้อยกว่า 1.5% สภาพอากาศเหมาะสมเมื่อฝน 700-1,500 มม./ปี อุณหภูมิ 20-34 องศาเซลเซียส และมีช่วงแล้งก่อนออกดอกราว 2 เดือน

น้ำระยะบำรุงต้นคิดจากประมาณ 0.7 เท่าของการระเหย ตัวอย่างอัตราระเหย 5 มม./วัน กับทรงพุ่มเส้นผ่านศูนย์กลาง 3 เมตร ใช้น้ำประมาณ 31.5 ลิตรต่อต้นต่อวัน หลังติดผลเป็นระยะวิกฤต ใช้ประมาณ 0.7-0.8 เท่าของการระเหย; ทรงพุ่ม 5 เมตรในตัวอย่างใช้น้ำ 87.5-100 ลิตรต่อต้นต่อวัน ดินทรายให้น้ำทุก 1.5-2.5 วัน ดินเหนียวทุก 4-5 วัน และก่อนออกดอกงดน้ำจนเริ่มแทงช่อดอก

แหล่งอ้างอิง: PDF หน้า 35-36 (เลขหน้าในเล่ม 27-28)

## 2. วิเคราะห์ใบและความต้องการธาตุ

เก็บใบอายุ 45-50 วันหลังแตกใบอ่อน จากต้นละ 4 ฉัตร บริเวณกลางทรงพุ่ม เลือกใบลำดับที่ 3 หรือ 4 จากยอดฉัตร

| ธาตุ | ระดับต่ำ      | ระดับเหมาะสม   | ระดับสูง     |
| ---- | ------------- | -------------- | ------------ |
| N    | 0.70-0.99%    | 1.00-1.50%     | >1.50%       |
| P    | 0.05-0.07%    | 0.08-0.25%     | >0.25%       |
| K    | 0.25-0.39%    | 0.40-0.90%     | >0.90%       |
| Ca   | 1.00-1.99%    | 2.00-5.00%     | >5.00%       |
| Mg   | 0.15-0.19%    | 0.20-0.50%     | >0.50%       |
| Fe   | 25-49 มก./กก. | 50-250 มก./กก. | >250 มก./กก. |
| Mn   | 25-49 มก./กก. | 50-250 มก./กก. | >250 มก./กก. |
| Zn   | 15-18 มก./กก. | 20-200 มก./กก. | >200 มก./กก. |
| B    | 20-24 มก./กก. | 25-150 มก./กก. | >150 มก./กก. |

ต้นฉบับมีค่าทองแดงในตารางที่อ่านได้เป็น 5-6 มก./กก. ระดับต่ำ และ 75-50 มก./กก. ระดับเหมาะสม ซึ่งควรตรวจต้นฉบับภาพ/นักวิชาการก่อนนำตัวเลขส่วนนี้ไปใช้เป็นเกณฑ์ภาคสนาม

ถ้าต่ำกว่ามาตรฐาน ให้ตรวจดินและพิจารณาเพิ่มปุ๋ย 15-30%; ถ้าสูงกว่ามาตรฐานให้ลด 15-30% พร้อมติดตามอาการและผลผลิต

แหล่งอ้างอิง: PDF หน้า 36 (เลขหน้าในเล่ม 28)

## 3. ธาตุอาหารที่ออกไปกับผลผลิต

ผลมะม่วงสด 1 ตันนำ N 5.78 กก., P 0.86 กก., K 5.56 กก., Ca 1.01 กก., Mg 0.73 กก., Fe 0.032 กก., Mn 0.015 กก., Cu 0.011 กก. และ Zn 0.007 กก. ออกจากสวน ตัวเลขนี้อธิบายว่าทำไมช่วงบำรุงต้นหลังเก็บเกี่ยวต้องประเมินจากผลผลิตฤดูที่ผ่านมา ไม่ควรใช้สูตรเดิมโดยไม่ดูผลผลิต

แหล่งอ้างอิง: PDF หน้า 37 (เลขหน้าในเล่ม 29)

## 4. อัตราธาตุอาหารตามค่าวิเคราะห์ดิน

อัตรานี้สำหรับขนาดทรงพุ่ม 5 เมตร แบ่ง 4 ครั้งต่อปีตามระยะพืช และควรวิเคราะห์ดินทุก 5 ปี

| รายการ              | ค่าวิเคราะห์                  | อัตราแนะนำต่อต้นต่อปี      |
| ------------------- | ----------------------------- | -------------------------- |
| N จาก OM            | OM <1.5 / 1.5-2.5 / >2.5%     | 1,200 / 600 / 300 กรัม N   |
| P2O5 จาก Bray II    | P <15 / 15-45 / >45 มก./กก.   | 400 / 200 / 100 กรัม P2O5  |
| K2O จาก NH4OAc pH 7 | K <50 / 50-100 / >100 มก./กก. | 1,000 / 500 / 250 กรัม K2O |

ต้นอายุ 1-4 ปีใช้อินทรีย์ 15-30 กิโลกรัมต่อต้นต่อปีร่วมกับ 20-10-10 อัตรา 250 กรัมต่อต้นต่อปี แบ่งใส่ต้นและปลายฤดูฝน

แหล่งอ้างอิง: PDF หน้า 37-39 (เลขหน้าในเล่ม 29-31) ตารางที่ 3-4

## 5. อัตราตามเนื้อดินและระยะพืช

| ระยะ                   | ดินร่วนเหนียว/ดินเหนียว                            | ดินทราย/ดินร่วนปนทราย                            |
| ---------------------- | -------------------------------------------------- | ------------------------------------------------ |
| อายุ 1-3 ปี            | อินทรีย์ 15-30 กก. + 20-10-10 0.25-0.75 กก./ต้น/ปี | อินทรีย์ 15-30 กก. + 20-10-10 0.5-1.5 กก./ต้น/ปี |
| บำรุงต้นหลังเก็บเกี่ยว | อินทรีย์ 25-50 กก. + 20-10-10 1 กก./ต้น            | อินทรีย์ 25-50 กก. + 20-10-10 2 กก./ต้น          |
| สร้างตาดอก             | 13-13-21 1 กก./ต้น                                 | 13-13-21 2 กก./ต้น                               |
| บำรุงผล                | 13-13-21 1 กก./ต้น                                 | 13-13-21 2 กก./ต้น                               |
| ปรับปรุงคุณภาพ         | 0-0-50 0.2 กก./ต้น                                 | 0-0-50 0.4 กก./ต้น                               |

ช่วงพ่นทางใบตามระยะการเจริญเติบโต: ระยะกิ่งก้านใบใช้สูตร N สูงประมาณ 2:1:1 และตัวอย่างโพแทสเซียมไนเตรท 200-250 กรัมต่อน้ำ 20 ลิตรหลังตัดแต่งกิ่ง 10-15 วัน; ระยะแทงช่อดอกใช้สูตร P และ K สูง เช่น 1:2:1, 1:2:2, 1:3:2 หรือ 0-52-34; ระยะติดผลใช้ 21-21-21, 30-15-15 หรือ 30-10-10; ก่อนเก็บเกี่ยวลด N และเพิ่ม 13-0-46 หรือ 0-0-60 1-2 ครั้ง

แหล่งอ้างอิง: PDF หน้า 39-40 (เลขหน้าในเล่ม 31-32) ตารางที่ 4-5 และ PDF หน้า 10 (เลขหน้าในเล่ม 6)

## 6. จุดควบคุมสำหรับสวนมะม่วง

- อย่าให้น้ำก่อนออกดอกเพียงเพราะเห็นใบเหี่ยว ต้องประเมินจังหวะแทงช่อดอกและสภาพดิน
- ไนโตรเจนมากทำให้แตกใบอ่อนและรบกวนดอก/ผล จึงต้องใช้ให้ตรงระยะ
- ถ้าผลดกกว่าปกติ ให้ประเมินการชดเชย K และธาตุอื่นจากผลผลิตจริง
- ฉลากผลิตภัณฑ์ปุ๋ยทางใบและความเข้มข้นจริงต้องตรวจทุกครั้งก่อนผสม
