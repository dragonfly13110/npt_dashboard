# 03 | โดรนการเกษตรและอากาศยานไร้คนขับ (Agricultural Drones & UAV)

**สถานะ: ✅ เจาะลึกแล้ว — `เจาะลึก-03-โดรนการเกษตรและอากาศยานไร้คนขับ.md` (สิงหาคม 2569)**

## ขอบเขต

โดรนพ่นยา/หว่านเมล็ด/โปรยปุ๋ย โดรนสำรวจแปลง ระบบลำเลียงทางอากาศ (lifting) เทคโนโลยี RTK/เรดาร์ กันสายไฟ และระบบนิเวศการบริการในไทย

## หัวข้อที่จะเจาะลึก

- ตลาดโดรนการเกษตร: US$6B (2026) → $12B (2035), เอเชีย-แปซิฟิก 20%, จีนนำผลิต
- DJI Agras T55/T100 Dual Battery: ข้อมูลจำเพาะ (50L/90L, radar mmWave 250K จุด/วินาที, quad-vision)
- ตัวเลข DJI ไทย: 50% ของ SEA, โต 50 เท่าใน 7 ปี, 19,000+ นักบินรับรอง, 300+ ร้าน 70 จังหวัด
- ผลลัพธ์จริง: ทุเรียนสูง 30 ม. (4 วัน → 1–2 วัน, สาร -20–30%), ลำเลียง 6.5 ล้านตัน/ปี (จีน)
- XAG: แผนตั้งฐานผลิตไทย 2028, SuperX farms, วาล์วอัจฉริยะ 100,000 ฟาร์ม
- เทคโนโลยี: dual battery, atomizer, การตรวจจับสายไฟ (obstacle memory), RTK เซนติเมตร
- โดรน vs รถพ่น: เศรษฐศาสตร์เปรียบเทียบ, ความคุ้มค่าต่อแปลงไทย
- กฎหมาย CAAT: ทะเบียน/ใบอนุญาตนักบิน/การพ่นสาร
