## 1. หลักการและขอบเขต

เครื่องจักรพลังงานทางเลือกคือเครื่องจักรกลการเกษตรที่ใช้พลังงานทดแทนน้ำมันดีเซลอย่างน้อยบางส่วน: ไฟฟ้า (BEV) ไฮบริด (ดีเซล-ไฟฟ้า) ไบโอมีเทน/CNG และไฮโดรเจน — ขับเคลื่อนด้วยแรงจูงใจ 3 อย่าง: (1) ต้นทุนพลังงานผันผวน (2) แรงกดดันลดการปล่อยก๊าซเรือนกระจก/PM2.5 (3) ความเงียบและความปลอดภัยในงานเฉพาะ (โรงเรือน/คอกสัตว์)

**ข้อเท็จจริงสำคัญจากงานวิจัย**: "รถแทรกเตอร์ไฟฟ้าเหมาะกับงานเบา-กลางและระยะเวลาสั้น (สวน/โรงเรือน/งานบริการแปลงย่อย) ส่วนงานหนักต่อเนื่อง (ไถ/เก็บเกี่ยว) ยังต้องใช้ดีเซลหรือไฮบริด" — พลังงานทางเลือกไม่ใช่ "แทนที่ทุกงาน" แต่เป็น "เติมเต็มเฉพาะงาน" [25]

## 2. เทรนด์ใหญ่จาก Agritechnica 2025: ไฮบริดมาแรง

งาน Agritechnica 2025 (ธีม "Touch Smart Efficiency") ให้สัญญาณชัด:
| เทรนด์ | รายละเอียด |
|---|---|
| **ไฮบริด = เทรนด์หลัก** | Zoomlion โชว์รถไถไฮบริด 3 รุ่น + เกี่ยวนวดไฮบริด "คันแรกของโลก"; New Holland โชว์ telehandler ไฟฟ้า-มีเทน |
| **เต็มไฟฟ้า (BEV) = niche** | รถ BEV ขนาดเล็ก (Fendt e100 Vario) ยังเป็นตลาดเฉพาะ — งานเบา/สวน |
| **ไฮโดรเจนถอย** | AGCO Power โชว์เครื่องยนต์ไฮโดรเจน แต่โครงสร้างพื้นฐานเป็นกำแพง — อยู่ "ข้างสนาม" |
| **มีเทนยังเดินหน้าต่อ** | New Holland ขยายสาย T7.270 Methane (เชิงพาณิชย์ยุโรป ฤดูใบไม้ผลิ 2026) |

**ข้อสรุปของงาน**: ผู้ผลิตใหญ่เห็นพ้องว่า "5–10 ปีข้างหน้า ตลาดเครื่องจักรใหญ่จะใช้ไฮบริด (ดีเซล-ไฟฟ้า) เป็นสะพาน" — ประหยัดน้ำมัน 15–30% โดยไม่เปลี่ยนโครงสร้างพื้นฐาน [23][21]

| รายการ     | รายละเอียด                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------- |
| KIN 40CS   | 60 แรงม้า, แบต 48 kWh, ทำงาน 4–6 ชม./ชาร์จ, แรงบิดสูงสุด 220 Nm, IP65, ใช้งานได้ 220V inverter (ปั๊มน้ำ/เครื่องมือ) |

| หน่วยงาน   | บริษัท ไทย อชิเทค จำกัด (TACT) — ส่งเสริม BOI, มีสิทธิบัตร/อนุสิทธิบัตรการแปลงเพลาขับ                               |

### 3.3 RAINA EV (ไทย) — รถอเนกประสงค์ไฟฟ้าสำหรับสวน

- สตาร์ทอัปไทย "ไร่นา โรโบเทค": รถ EV 100% สำหรับสวนผลไม้/สวนปาล์ม (โครงสร้างกันร้อนชื้น, แบตใช้งาน ~10 ชม.)
- ระบบ **RaiNav**: นำทางกึ่งอัตโนมัติ/เต็มรูปแบบ, วิ่งตามแถวพืช, โหมด **Human Following** (วิ่งตามเกษตรกรขณะเก็บผลไม้ลดการแบกของ)
- มุมมอง: ไทยเริ่มมีผู้เล่น EV เกษตรในประเทศ — ยังเล็กแต่เป็นสัญญาณของการเกิดห่วงโซ่อุปทาน

### 3.4 ข้อจำกัดเชิงเทคนิคของ BEV งานหนัก

- ความหนาแน่นพลังงาน: น้ำมันดีเซล ~13,900 Wh/kg vs แบตลิเธียม ~250 Wh/kg — ต้องแบกแบตหนักมากเพื่อเทียบเท่าแรงงาน 8–10 ชม.
- งานไถ/เก็บเกี่ยวต้องการกำลัง 100–600 hp ต่อเนื่อง — ยังไม่มีแบตขนาดใช้งานได้ในราคาเชิงพาณิชย์
- สรุปงานวิจัย [25]: BEV เหมาะ 30–70 hp งานเบา-กลาง 4–8 ชม./วัน

### 5.2 ความหมายต่อฟาร์มปศุสัตว์

- ฟาร์มโคนม/สุกรใหญ่มี "วัตถุดิบ" (มูลสัตว์) เป็นเชื้อเพลิง — ต้นทุนต่อชั่วโมงต่ำและเสถียร
- ผนวกกับระบบผลิตก๊าซชีวภาพของฟาร์ม (หลายฟาร์มไทยมีอยู่แล้ว) — โอกาสใช้รถไถมีเทนในไทย (รอผู้จำหน่าย)

## 6. ไฮโดรเจน: อยู่ข้างสนาม

- AGCO Power โชว์ **เครื่องยนต์สันดาปไฮโดรเจน** ที่ Agritechnica 2025 (ไม่ใช่ fuel cell) — ตั้งใจรักษาโครงสร้างเดิมของเครื่องยนต์
- แต่ข้อจำกัดชัด: (1) แหล่งไฮโดรเจนเขียวมีจำกัด (2) โครงสร้างพื้นฐานเติมก๊าซไม่มี (3) ค่าใช้จ่ายสูง
- **ข้อสรุปในงาน**: ไฮโดรเจนจะไม่เป็นทางเลือกหลักของเครื่องจักรเกษตรในทศวรรษนี้ — ติดตามเฉพาะโครงการนำร่องขนาดใหญ่

## 7. การชาร์จด้วยพลังงานแสงอาทิตย์

### 7.1 งานวิจัย (IEEE IC3I 2024) — สถานีชาร์จโซลาร์สำหรับรถฟาร์ม EV

| ตัวชี้วัด          | ระบบโซลาร์ใหม่ | ระบบเดิม   |
| ------------------ | -------------- | ---------- |
| ประสิทธิภาพพลังงาน | 4.0 km/kWh     | 2.5 km/kWh |
| ค่าใช้จ่ายต่อปี    | ~US$6,500      | ~US$12,000 |
| CO₂ ต่อปี          | 3,000 กก.      | 15,000 กก. |

### 7.2 หลักการ

- แผงโซลาร์บนโรงเก็บ/หลังคาแปลง → ชาร์จแบตในเวลากลางวัน → รถทำงานช่วงบ่าย/เย็น (ย้ายงานไปช่วงที่ไฟฟ้าโซลาร์เหลือ)
- ผนวกกับ "Time-of-Use" — ชาร์จตอนแสงแดดดี ลดค่าไฟขีดสุด
- **สภาพไทยเหมาะมาก**: แสงแดด 5–5.5 kWh/m²/วัน ตลอดปี + โครงการโซลาร์เพื่อการเกษตรของรัฐ (เอโฟ/กฟน./สหกรณ์) + BOI — "โซลาร์บนฟาร์ม" เป็นทางลัดให้ EV เกษตรไทยคุ้มค่าโดยไม่พึ่งสถานีชาร์จสาธารณะ

### 7.3 ข้อจำกัด

- งานกลางคืน/งานดึกต้องใช้แบตอย่างเดียว — ต้องคำนวณรอบการทำงานให้พอดี
- การลงทุนแผงโซลาร์ 10–30 กิโลวัตต์ ~2–6 แสนบาท (คืนทุน 4–7 ปีในอัตราค่าไฟเกษตร) — ดีเมื่อมีงาน EV หลายคัน

| --------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **ลูกค้าซื้อ EV ไม่ใช่ autonomy** | MK-V 70 hp / PTO 40 hp / 14 ชม. (โฆษณา) — ขายดีจากประหยัดน้ำมันในไร่องุ่นแคลิฟอร์เนีย ไม่ใช่โหมดไร้คน               |
| **ราคา vs ดีเซล**                 | แม้ค่าใช้จ่ายต่อชม.ต่ำกว่า แต่ราคาซื้อสูง (US$85K+) + ค่าแบต/บริการ — คืนทุน 3–5 ปีสำหรับฟาร์มที่ใช้งานหนักเท่านั้น |
| **การรับประกัน**                  | 4 ปี/4,000 ชม. (ตัวรถ) + 8 ปี/8,000 ชม. (แบต) — มาตรฐานใหม่ที่ OEM BEV ต้องมี                                       |
| **ผลต่อตลาด**                     | Caterpillar ได้เทคโนโลยี + ฐานรถ — รอการวางตำแหน่งเครื่องจักร EV งานหนักของ Caterpillar                             |

**บทสรุปเชิงปฏิบัติ**: EV เกษตรต้องขาย "ค่าใช้จ่ายต่อชั่วโมงต่ำกว่า + เงียบกว่า + ไม่มีควัน" ก่อนเรื่องอัตโนมัติ — และต้องมีบริการหลังการขายที่พร้อม (ผู้ซื้อกลัวแบตเสื่อม/ศูนย์บริการ)

## 9. ตลาดและตัวเลข

| ตลาด                                            | ตัวเลข                                                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| ตลาดรถไถอัตโนมัติ-กึ่งอัตโนมัติ (รวม EV/hybrid) | US$1.9–2.7B (2024) → US$10–14B (2030–32) [8]                                                                    |
| ตลาดรถไถไฟฟ้าไทย                                | US$197M (2025) → US$226M (2032), CAGR 2.0% — แบ่งเป็น battery/solar, light-heavy duty [36+]                     |

**ข้อสังเกต**: ตลาดไทย $197M ส่วนใหญ่เป็น "ตัวเลขเชิงทฤษฎี" (รถ EV เกษตรจดทะเบียนจริงยังน้อย) — การเติบโตจริงจะมาเมื่อ: ราคาแบตตก + สถานีโซลาร์ + นโยบายสนับสนุน

## 10. สถานการณ์ประเทศไทย

### 10.1 จุดแข็ง

- **ผู้เล่นในประเทศเริ่มมี**: TACT (KIN 40CS/48, BOI), RAINA Robotech (สวนผลไม้/ปาล์ม) — ฐานการผลิตในไทยเริ่มก่อตัว
- **โซลาร์ราคาถูก + นโยบาย**: โครงการโซลาร์เพื่อเกษตร (กฟผ./กฟน. + สหกรณ์), BOI ส่งเสริม EV/agritech, เป้า Net Zero 2050 — เหมาะ EV เกษตร
- **โครงสร้างฟาร์ม**: แปลงเล็ก/สวนผลไม้/ปาล์มจำนวนมาก = งานเบา-กลางที่ BEV ทำได้จริง (เก็บขน/พ่น/ตัดหญ้าในสวน)
- **ทดลองต่างประเทศแล้ว**: Monarch ใช้ได้จริงในไร่องุ่นแคลิฟอร์เนีย — สภาพคล้ายสวนองุ่น/ทุเรียนไทย

### 10.2 จุดอ่อน/อุปสรรค

| อุปสรรค       | รายละเอียด                                                                       |
| ------------- | -------------------------------------------------------------------------------- |
| ราคาสูง       | รถ BEV เกษตรในไทยแพงกว่าเครื่องดีเซล 2–3 เท่า — ยังไม่มีสินเชื่อเฉพาะ            |
| สถานีชาร์จ    | ไม่มีสถานีชาร์จในแปลง — ต้องพึ่งโซลาร์/ไฟฟ้าฟาร์ม (จำกัดแรงม้า 15A–30A เฟสเดียว) |
| งานหนัก       | นา/ไร่ขนาดใหญ่ ยังเป็นดีเซล — ตลาด BEV ไทย = งานสวน/เบาเป็นหลัก                  |
| ความเชื่อมั่น | กรณี Monarch + แบตเสื่อม — ผู้ซื้อไทยกลัว "ตัวแทนจำหน่ายหาย"                     |
| มาตรฐาน       | ยังไม่มีมาตรฐานการรับรองรถ EV เกษตรไทย (ช่องว่างด้านมาตรฐาน)                     |

### 10.3 ทางเลือกสำหรับไทย (เรียงตามความเหมาะ)

1. **งานสวน/ปาล์ม**: RAINA-class รถ EV อเนกประสงค์ + โซลาร์โรงเก็บ — คุ้มทันที (ค่าใช้จ่าย <50% ดีเซล)
2. **งานไถเบา/แปลงเล็ก-กลาง**: TACT KIN 48-class (48–60 hp) — ทดสอบในสหกรณ์
3. **งานหนัก**: รอไฮบริดจีน (Zoomlion/LOVOL) เข้าตลาดไทย ราคาแข่งขัน — ติดตามดีลเลอร์ BOI
4. **ฟาร์มปศุสัตว์ใหญ่**: พิจารณา T7.270 Methane เมื่อมี biodigester + ผู้จำหน่าย

## 11. แนวทางนำไปใช้

### 11.1 Blueprint 4 ขั้น

1. **คำนวณสมดุลพลังงานก่อนซื้อ (ปี 1)**: นับชั่วโมงทำงาน/งานจริงของรถแต่ละคัน — ถ้า <6 ชม./วัน และแรงม้า <80 hp มีโอกาส EV; ถ้าทำงาน >10 ชม./วัน/งานหนัก → ยังดีเซล/ไฮบริด
2. **เริ่มจาก "รถคันที่ 2" (ปี 1–2)**: ใช้ EV ในงานประจำสวน/แปลง (พ่น/ตัดหญ้า/ขนผล) เก็บตัวเลขจริง 2 ฤดู — อย่าเปลี่ยนรถหลักทันที
3. **ติดตั้งโซลาร์ก่อนหรือพร้อมกัน**: แผง 10–20 kW + แบตสำรอง — ทำให้ค่าไฟฟ้าต่อชม.คงที่ (เชื่อมราคาไม่ผันผวน)
4. **ขยายเมื่อระบบพิสูจน์แล้ว (ปี 3+)**: เพิ่ม EV คันที่ 2/3 หรือรถไฮบริดสำหรับงานหนัก; ตรวจสอบค่าใช้จ่ายรวม (TCO) เทียบดีเซลทุกปี

### 11.2 เกณฑ์ตัดสินใจ TCO

| ปัจจัย                           | ดีเซล | BEV (พร้อมโซลาร์)   | ไฮบริด    |
| -------------------------------- | ----- | ------------------- | --------- |
| ราคาซื้อ                         | 1x    | 2–3x                | 1.3–1.8x  |
| ค่าใช้จ่ายต่อชม. (พลังงาน+บำรุง) | 1x    | 0.3–0.5x            | 0.7–0.85x |
| ความเงียบ/ควัน/CO₂               | สูง   | ต่ำมาก              | ปานกลาง   |
| คืนทุน                           | -     | 3–6 ปี (ใช้งานหนัก) | 4–8 ปี    |

## 12. ความท้าทาย

| ความท้าทาย            | รายละเอียด                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------ |
| **แบตเตอรี่**         | ความหนาแน่นพลังงานต่ำ งานหนักไม่ไหว; ราคาแบตตกช้า; อายุ/ความเสื่อมในความร้อนไทย                  |
| **โครงสร้างพื้นฐาน**  | ไม่มีสถานีชาร์จในแปลง; ไฟฟ้าเฟสเดียว 15A จำกัดการชาร์จเร็ว                                       |
| **ราคา**              | ราคาซื้อสูง — แม้ TCO ดี แต่เงินต้นเป็นกำแพงฟาร์มเล็ก                                            |
| **บริการหลังการขาย**  | ผู้จำหน่ายรายเล็กเสี่ยง "หายไป" (กรณี Monarch) — ต้องเลือกแบรนด์ที่มีเครือข่าย                   |
| **มาตรฐาน/การรับรอง** | ไม่มีมาตรฐานไทยสำหรับ EV เกษตร (แบต/ชาร์จ/ความปลอดภัย) — ต้องรอหรือนำมาตรฐานต่างประเทศ           |
| **ข้อมูลจริงน้อย**    | งานวิจัย peer-review เรื่อง EV เกษตรในเขตร้อนยังน้อย — ตัวเลข "ประหยัด 50%" มาจากผู้ผลิตเป็นหลัก |
| **ไฮโดรเจน/CNG**      | โครงสร้างพื้นฐานไม่มีในไทย — มีเทนเหมาะฟาร์มปศุสัตว์ขนาดใหญ่เท่านั้น                             |

## 13. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **ไฮบริดจีนบุกตลาดราคา**: Zoomlion/LOVOL ตั้งเป้าตลาดเอเชีย-อเมริกาใต้ — เมื่อเข้าผ่าน BOI ราคาไฮบริดจะถูกลงมาก
2. **"เครื่องกำเนิดติดรถ" (series hybrid) เป็นสะพาน**: ดีเซล+มอเตอร์ไฟฟ้า กลายมาตรฐานเครื่องใหญ่ — ทำให้ระบบอัตโนมัติ/ควบคุมแม่นยำง่ายขึ้น
3. **โซลาร์ + EV = คู่บังคับ**: นโยบายโซลาร์เพื่อการเกษตร + แบตตก → EV เกษตรเริ่มคุ้มในงานสวนไทย
4. **EV เฉพาะงานปิด**: สวนผลไม้/ปาล์ม/โรงเรือน/คอก — "EV เฉพาะที่" โตเร็วกว่า EV เอนกประสงค์
5. **มาตรฐานแบต/การรีไซเคิล**: ประเด็นความรับผิดชอบแบตเก่าเริ่มถูกกฎหมายกดดัน (EU Battery Regulation) — ไทยจะตาม
6. **ความหมายของ "Net Zero ฟาร์ม"**: การรับรองคาร์บอนเครดิต (ISO 14064-1 ของ TACT) จะเป็นแรงจูงใจใหม่ของฟาร์มส่งออก

## 14. อภิธานศัพท์

| คำศัพท์                  | ความหมาย                                                  |
| ------------------------ | --------------------------------------------------------- |
| **BEV**                  | รถไฟฟ้าแบตเตอรี่ล้วน (Battery Electric Vehicle)           |
| **HEV / Hybrid**         | ไฮบริดดีเซล-ไฟฟ้า — เครื่องยนต์ + มอเตอร์ทำงานร่วมกัน     |
| **Series hybrid**        | ดีเซลเป็นเครื่องกำเนิดไฟฟ้าล้วน มอเตอร์ไฟฟ้าขับเคลื่อนล้อ |
| **PTO (Power Take-Off)** | เพลาส่งกำลังถ่ายออกจากเครื่องยนต์ไปเครื่องมือพ่วง         |
| **CNG / Bio-CNG**        | ก๊าซธรรมชาติอัด / ไบโอมีเทนจากชีวมวล (มูลสัตว์)           |
| **Biodigester**          | ถังหมักก๊าซชีวภาพจากมูลสัตว์/เศษเหลือ                     |
| **TCO**                  | ต้นทุนรวมตลอดอายุการใช้งาน (Total Cost of Ownership)      |
| **kWh**                  | หน่วยพลังงานไฟฟ้า — ความจุแบต/การใช้พลังงาน               |
| **Human Following**      | โหมดหุ่นยนต์วิ่งตามผู้ปฏิบัติงานอัตโนมัติ                 |
| **CCS / Type 2**         | ขั้วชาร์จเร็ว / ขั้วชาร์จปกติมาตรฐานยุโรป                 |
