# คลังความรู้: เครื่องจักรการเกษตรล้ำสมัย

คลังความรู้รวบรวมงานวิจัย บทความวิชาการ ข่าวเทคโนโลยี และข้อมูลตลาดเกี่ยวกับเครื่องจักรกลการเกษตรรุ่นใหม่ (Smart Machinery / Agriculture 4.0) ทั้งในระดับโลกและบริบทประเทศไทย

## โครงสร้างคลังความรู้

```
เครื่องจักรการเกษตรล้ำสมัย/
├── README.md                          ← ไฟล์นี้ (หน้าหลัก / สารบัญ)
├── 00-Overview-เครื่องจักรการเกษตรล้ำสมัย.md  ← เอกสารภาพรวม 12 ด้าน พร้อมอ้างอิง (เริ่มต้นที่นี่)
│
├── 01-รถแทรกเตอร์อัตโนมัติและระบบนำทางอัตโนมัติ/
├── 02-เครื่องเก็บเกี่ยวอัจฉริยะ/
├── 03-โดรนการเกษตรและอากาศยานไร้คนขับ/
├── 04-ระบบพ่นสารและฉีดพ่นแม่นยำ/
├── 05-เครื่องจักรพลังงานทางเลือก/
├── 06-หุ่นยนต์ภาคสนามและฝูงหุ่นยนต์/
├── 07-เครื่องหยอดและเพาะปลูกแม่นยำ/

├── 10-เครื่องจักรเฉพาะพืชเศรษฐกิจไทย/
├── 11-เครื่องจักรและหุ่นยนต์ปศุสัตว์/
└── 12-บริการเครื่องจักรและระบบการแบ่งปัน/
```

## วิธีใช้งาน

1. **เริ่มต้นอ่าน** `00-Overview-เครื่องจักรการเกษตรล้ำสมัย.md` เพื่อเห็นภาพรวมทั้ง 12 ด้าน เทคโนโลยี AI/อัตโนมัติที่ใช้ ผลลัพธ์จากงานวิจัย และแหล่งอ้างอิง
2. **เจาะลึกรายด้าน** แต่ละโฟลเดอร์ย่อย (01–12) มี `README.md` ระบุขอบเขต หัวข้อที่จะเจาะลึก และแหล่งข้อมูลเริ่มต้น — ไฟล์เนื้อหาเชิงลึกของแต่ละด้านมีชื่อ `เจาะลึก-XX-ชื่อหัวข้อ.md`
