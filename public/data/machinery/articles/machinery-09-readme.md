# 09 | เครื่องจักรหลังการเก็บเกี่ยวและแปรรูป (Post-Harvest & Processing Machinery)

**สถานะ: ✅ เจาะลึกแล้ว** — ดู [เจาะลึก-09-เครื่องจักรหลังการเก็บเกี่ยวและแปรรูป.md](เจาะลึก-09-เครื่องจักรหลังการเก็บเกี่ยวและแปรรูป.md)

## ขอบเขต

ระบบอบแห้งและเก็บรักษาเมล็ดพืชอัจฉริยะ โรงสี/เครื่องกะเทาะ เครื่องคัดเกรดด้วยวิทัศน์ AI การตรวจคุณภาพด้วยเซนเซอร์ NIR และการลดการสูญเสียหลังเก็บเกี่ยว

## หัวข้อที่จะเจาะลึก

- อบแห้งอัจฉริยะ: เซนเซอร์ความชื้น + IoT, ลดการเสียหายและต้นทุนพลังงาน
- Smart storage: คลังเมล็ดอัตโนมัติ, ระบบควบคุมสภาพอากาศในไซโล
- การคัดเกรดด้วย vision AI: ความเร็ว/ความแม่นยำ vs คน, เกรดข้าว/ผลไม้
- NIR on-machine: วิเคราะห์โปรตีน/ความชื้น/แป้งแบบ real-time (เทรนด์ Agritechnica 2025)
- โรงสีข้าวไทย: โครงสร้างอุตสาหกรรม, โอกาสโรงสีอัจฉริยะ
- มันสำปะหลัง: เครื่องสับ/ตาก/มันเส้นอัตโนมัติ
- ตัวเลขการสูญเสียหลังเก็บเกี่ยวของไทย (ข้าว 10–15%?)
- การเชื่อมกับคลัง AI เกษตร: หัวข้อ 09 (ห่วงโซ่อุปทาน)
