# 02 | เครื่องเก็บเกี่ยวอัจฉริยะ (Smart Harvesting Machinery)

**สถานะ: ✅ เจาะลึกแล้ว — `เจาะลึก-02-เครื่องเก็บเกี่ยวอัจฉริยะ.md` (สิงหาคม 2569)**

## ขอบเขต

รถเกี่ยวนวดข้าว/ธัญพืช เครื่องตัดอ้อยสด เครื่องเก็บเกี่ยวข้าวโพด/มันสำปะหลัง — ระบบอัตโนมัติ เซนเซอร์วัดการสูญเสีย yield monitor และ AI ในเครื่องเก็บเกี่ยว

## หัวข้อที่จะเจาะลึก

- Combine อัตโนมัติ: auto-guide, auto-header, ระบบวัดการสูญเสียเมล็ด, yield monitor
- CNH combine automation: มูลค่า €70/ha ในข้าวสาลี
- Kubota Agri Robo Combine (ญี่ปุ่น): GPS เซนติเมตร, เก็บเกี่ยวกลางคืน
- เครื่องตัดอ้อยสด (chopper/whole stalk): เทคโนโลยี, มาตรฐานฝุ่น PM2.5 ไทย
- ตลาดเครื่องเก็บเกี่ยวไทย: 27.9% ฟาร์มใช้เกี่ยวนวด, ผู้เล่นหลัก (Kubota/Yanmar/ISEKI/ในประเทศ)
- การเก็บเกี่ยวมันสำปะหลัง/ข้าวโพด: อัตราการสูญเสีย, เทคโนโลยีลดความเสียหายหัวมัน
- การเชื่อมโยงกับเครื่องเกี่ยวนวดรับจ้าง (contract harvesting)
