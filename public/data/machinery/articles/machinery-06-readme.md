# 06 | หุ่นยนต์ภาคสนามและฝูงหุ่นยนต์ (Field Robots & Swarms)

**สถานะ: ✅ เจาะลึกแล้ว — `เจาะลึก-06-หุ่นยนต์ภาคสนามและฝูงหุ่นยนต์.md` (สิงหาคม 2569)**

## ขอบเขต

หุ่นยนต์กำจัดวัชพืช (กล/เลเซอร์/ไฟฟ้า) หุ่นยนต์หลายบทบาท (multi-task) ฝูงหุ่นยนต์ (swarm) ระบบ carrier แบบโมดูลาร์ และการประสานงานหุ่นยนต์-เครื่องจักรใหญ่

## หัวข้อที่จะเจาะลึก

- FarmDroid FD20 (โซลาร์, หว่าน+กำจัดวัชพืช), Carbon Robotics LaserWeeder, Ecorobotix
- CNH R4 Robot Family, New Holland R4 (สวนผลไม้), AGCO RowPilot/SymphonyVision
- Kubota x Kilter (กำจัดวัชพืช ultra-precise), Kubota KVPR Transformer robot
- NEXAT carrier: แพลตฟอร์มโมดูลาร์ครอบคลุมทุกงาน (ไถ→หว่าน→ปุ๋ย→เก็บ)
- CLAAS TORION Autonomy Connect: LiDAR + digital twin, ไม่พึ่ง GPS
- Swarm: AGCO Fendt Mars (6+ ตัว/ผู้ควบคุม 1 คน) — สถานะ early commercial
- CLAAS dock weed detection: แผนที่วัชพืชทุ่งหญ้า → พ่นเฉพาะจุด (ตลาดใน 5 ปี)
- เศรษฐศาสตร์หุ่นยนต์ vs แรงงาน/สารเคมี: จุดคุ้มทุน
- การเชื่อมกับคลัง AI เกษตร: หัวข้อ 05 (วัชพืช) และ 06 (หุ่นยนต์)
