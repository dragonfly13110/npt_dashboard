**สถานะ: ✅ เจาะลึกแล้ว — `เจาะลึก-01-รถแทรกเตอร์อัตโนมัติและระบบนำทางอัตโนมัติ.md` (สิงหาคม 2569)**

## ขอบเขต

รถแทรกเตอร์ไร้คนขับ/กึ่งอัตโนมัติ ระบบนำทางอัตโนมัติ (auto-steer, RTK-GPS) การควบคุมผ่านแอป การทำงานเป็นฝูง และรูปแบบธุรกิจ Autonomy-as-a-Service

## หัวข้อที่จะเจาะลึก

- John Deere 8R/9RX: สถาปัตยกรรมระบบ (16 กล้อง, safety bubble), kit retrofit, เส้นทางสู่ fleet อัตโนมัติ 2030
- ตลาดรถแทรกเตอร์อัตโนมัติ: ตัวเลข US$2B → $10–14B (2032), สัดส่วน semi vs full autonomy
- Kubota AgriRobo/M5 Narrow + Agtonomy, KVPR Transformer robot, Yanmar
- Autonomy-as-a-Service: ราคา $14–18/เอเคอร์, 410 สัญญา Q1 2026, ARR $90M+
- ตัวเลขพื้นที่ Level-4 จริง: 1.04 ล้านเอเคอร์ (2026) — Deere/Monarch/Bonsai
- ระบบนำทาง: RTK ±1–2 ซม., โครงข่าย RTN ไทย (กรมที่ดิน), AGCO PTx Trimble
- กฎหมาย/ความปลอดภัย: ISO 18497, ความรับผิด, ยุโรป vs อเมริกาเหนือ
- บทเรียน Monarch MK-V (ล้มละลาย 2026): ความจริง vs การตลาดเรื่อง autonomy
