# 12 | บริการเครื่องจักรและระบบการแบ่งปัน (Machinery Services & Sharing Economy)

**สถานะ: ✅ เจาะลึกแล้ว** — ดู [เจาะลึก-12-บริการเครื่องจักรและระบบการแบ่งปัน.md](เจาะลึก-12-บริการเครื่องจักรและระบบการแบ่งปัน.md)

## ขอบเขต

Custom hiring (บริการรับจ้างเครื่องจักร) การแบ่งปันเครื่องจักร (sharing economy) การลงทะเบียนผู้ให้บริการ Machinery-as-a-Service และรูปแบบธุรกิจการเข้าถึงเทคโนโลยีของฟาร์มเล็ก

## หัวข้อที่จะเจาะลึก

- Custom hiring ไทย: กลไก "วิถีปกติ" มานาน, ตัวเลขการใช้บริการต่องาน (เตรียมดิน/เก็บเกี่ยว)
- ระบบลงทะเบียนผู้ให้บริการเครื่องจักรการเกษตร 2025: โครงสร้าง, ผลต่อราคา
- Sharing Economy ระดับท้องถิ่น (นโยบาย 13th Plan): การรวมกลุ่มเกษตรกรเป็นผู้ให้บริการ
- Machinery-as-a-Service โลก: Deere Autonomy-as-a-Service ($14–18/เอเคอร์), Robot-as-a-Service
- ตัวเลขธุรกิจ: ค่าบริการเกี่ยวนวด/ไถต่อไร่ในไทย, อัตราการใช้เครื่องจักร (การหมุนเวียน)
- ฟาร์มรับจ้างหุ่นยนต์/โดรน: รูปแบบผู้ประกอบการใหม่ (โดรนรับจ้างพ่น 100–250 บาท/ไร่)
- ผลต่อการเข้าถึงเทคโนโลยีของฟาร์ม 65.4% ที่ถือครอง <20 ไร่
- นโยบาย/การเงิน: สินเชื่ออุปกรณ์, การค้ำประกัน, กลุ่มวิสาหกิจ
