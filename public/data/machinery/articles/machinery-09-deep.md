## 1. หลักการและขอบเขต

งานหลังเก็บเกี่ยว (อบแห้ง → เก็บรักษา → สี/แปรรูป → คัดเกรด → ขนส่ง) กำหนด "คุณภาพและมูลค่า" ของผลผลิต ด้านนี้ครอบคลุม: การอบแห้งอัจฉริยะ, คลังจัดเก็บอัจฉริยะ (smart storage), โรงสี/เครื่องกะเทาะ, การคัดเกรดด้วยวิทัศน์ AI + เซนเซอร์ NIR, และตัวเลขการสูญเสียหลังเก็บเกี่ยว

**หลักเศรษฐศาสตร์พื้นฐาน**: ข้าวสาร 100% ราคา ~840 บาท/กระสอบ แต่ข้าวหัก ~430 บาท/กระสอบ — "การรักษาคุณภาพ" (ไม่แตก/ไม่เหลือง/ไม่หอมเสีย) มีมูลค่ามหาศาล และเกิดขึ้นได้ในขั้นตอนหลังเก็บเกี่ยวเท่านั้น

## 2. ตัวเลขการสูญเสีย: ไทย vs โลก

### 2.1 ระดับโลก

| ตัวเลข                                                                                             | แหล่ง                 |
| -------------------------------------------------------------------------------------------------- | --------------------- |
| **~14% ของอาหารโลกสูญหายในขั้นตอนหลังเก็บเกี่ยว** (ก่อนถึงมือผู้บริโภค) — การเก็บรักษาเป็นส่วนหลัก | FAO                   |
| ธัญพืชเล็ก (ข้าวฟ่าง/ลูกเดือย): PHL 10–30% (บางแหล่ง FAO 30–40%)                                   | ScienceDirect reviews |
| ตลาดข้าวฟ่างโลก $11.53B (2024) → $14.43B (2029), CAGR 4.6% — ตลาดที่ PHL สูงมาก                    | Tanwar et al.         |

### 2.2 ไทย (งานวิจัย UPRU, 4 จังหวัดภาคเหนือ 2560/61)

- ข้าวเปลือก 3,188,435 ตัน/ปี → สูญเสีย **312,409 ตัน/ปี (9.8%)** = ไร่ที่สูญเปล่า 506,092 ไร่ + น้ำ 81.7 ล้าน ลบ.ม./ปี
- **96.9% ของการสูญเสียเกิดที่ "การเก็บเกี่ยวในนา"** (302,612 ตัน — รถเกี่ยวไทยประดิษฐ์/ความเร็ว/ระยะเวลาผิด) / โรงสีเพียง 3.1% (9,797 ตัน)
- แนวทางลด: (1) ยกระดับรถเกี่ยวไทยให้เทียบรถญี่ปุ่น → **-22.5%** (2) ลดความเร็วรถเกี่ยว → -15.1% (3) เกี่ยวระยะพลับพลึง → -4.0% (4) ซ่อมบำรุงโรงสี → -0.13%
- **บทสรุป**: "ลงทุนหลังเก็บเกี่ยวที่คุ้มที่สุดของไทย = ตั้งค่ารถเกี่ยวให้ถูกต้อง" (เชื่อมด้าน 02 และเจาะลึก 10)

## 3. การลดความชื้นและอบแห้งอัจฉริยะ

### 3.1 พื้นฐาน

- ความชื้นปลอดภัยเก็บข้าว = **14% wb** — ข้าวนาปรังฤดูฝนเก็บมา 20%+ → เสื่อมเร็ว: รอยร้าวในเมล็ด, กลิ่นสาบ, เมล็ดเหลืองคล้ำ, แมลงเติบโต
- ไทยมีปัญหา "ลานตาก/เครื่องอบไม่พอเพียงกับปริมาณข้าวความชื้นสูงที่เก็บเกี่ยวรายวัน" → ข้าวรวมกองรออบ เสี่ยงเสื่อม (PHTNet)
- ข้อเท็จจริงจากงานวิจัย: ลมร้อนอบลดความชื้นต่ำกว่า 18% → เมล็ดร้าวเพิ่ม (แต่ถึง 14% เมล็ดแกร่ง/คุณภาพสีดีกว่า); การเปียกซ้ำ (rewetting) ร้ายที่สุด

### 3.2 เทคโนโลยีอัจฉริยะ

| เทคโนโลยี                                       | รายละเอียด                                                                        |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| **เซนเซอร์ความชื้น + IoT**                      | วัดความชื้นกองข้าว real-time → ปรับลมร้อน/รอบอบอัตโนมัติ — ลดพลังงาน + ลดความร้าว |
| **การชะลอเสื่อมด้วยการระบายอากาศกอง** (งาน มข.) | ระบายอากาศออกจากกองข้าวความชื้นสูงระหว่างรออบ — "สะพาน" ไปสู่ลานตาก/เครื่องอบ     |
| **การอบตามคุณภาพเป้าหมาย**                      | โปรไฟล์อบแยกตามพันธุ์ (ขาวดอกมะลิ 105 ห้ามอบแรง → กลิ่นหอมเสื่อม) — งาน มช./มข.   |
| **อบแห้งด้วยพลังงานแสงอาทิตย์/ชีวมวล**          | ลดต้นทุนพลังงานในโรงสีชุมชน (เชื่อมด้าน 05 พลังงานทางเลือก)                       |

## 4. Smart grain storage: คลังเมล็ดอัจฉริยะ

### 4.1 วิวัฒนาการ 4 ยุค (IJABE 2026)

Manual (แรงงาน) → Mechanization (เครื่องจักร: ลำเลียง/พัดลม/ดูดฝุ่น) → Automation (ควบคุมสภาพอากาศ/ควัน/สัญญาณเตือน) → **Informatization (IoT+Big Data)** → **Intelligent (AI ตัดสินใจเอง: ตรวจศัตรูพืช/คัดเมล็ดเสีย/ควบคุมพัดลมอัตโนมัติ)**

### 4.2 ผลงานวิจัยที่พิสูจน์แล้ว

| ระบบ                                                                                  | ผลลัพธ์                                                                                                                                                                         |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **3D DenseNet + 3DCNN-LSTM** (MDPI Foods 2568)                                        | จำแนกสถานะกองข้าว (ปกติ/ว่าง/ระบายอากาศ/เติมข้าวใหม่/กลั่นตัว/รา) **แม่นยำ 97.38%**; พยากรณ์อุณหภูมิ MAE 0.24°C; เตือนเสี่ยงรา/กลั่นตัวล่วงหน้า (ล่าช้า ~2 วัน ยังต้องปรับปรุง) |
| **GCN-TFT (physics-guided graph transformer)** (Computers & Electronics in Ag., 2569) | ตรวจจับ "ขั้วอุณหภูมิผิดปกติ" (hot spots) ที่แบบจำลองพยากรณ์อุณหภูมิธรรมดาพลาด — แก้ข้อจำกัดของกลยุทธ์เดิมที่พึ่งพาแต่ "การพยากรณ์อุณหภูมิ"                                     |
| **AI ติดตามศัตรูโรงเก็บ** (IJABE 2569)                                                | CNN/Transformer/Mamba ตรวจจับแมลงศัตรูโรงเก็บ + คัดเมล็ดเสีย (unsound kernel) ที่จุดรับข้าวเข้า (grain intake) + ควบคุมการระบายอากาศอัจฉริยะ                                    |
| **เซนเซอร์ CO2**                                                                      | ความเข้มข้น/อัตราเปลี่ยนแปลง CO2 ในกอง = ตัวชี้วัดเริ่มต้นของเชื้อรา — ใช้งานง่ายราคาถูก                                                                                        |
| **Portable NIR (ICRISAT)**                                                            | สเปกโตรโฟโตมิเตอร์พกพา วิเคราะห์โภชนาการ/คุณภาพ 150+ ตัวอย่าง/วัน ที่หน้าโรงนา — "โรงตรวจคุณภาพพกพา" ราคาเข้าถึงได้                                                             |

## 5. โรงสีข้าว: จาก Lean สู่ AI

### 5.1 โครงสร้างอุตสาหกรรมไทย

- โรงสีไทย กระจายทั่วประเทศ (โรงสีขนาดเล็ก-กลาง ชุมชนนับหมื่นราย + โรงสีส่งออกรายใหญ่) — ต้นทางราคารับซื้อข้าวเปลือกของชาวนา
- คุณภาพการสี ขึ้นกับ: ความชื้นเมล็ดเข้าโรงสี, รอบเครื่องจักร (ขัดขาว/กะเทาะ), สภาพอากาศขณะสี (RH/อุณหภูมิ), พันธุ์

### 5.2 กรณีศึกษา "ปรับรอบเครื่อง = เพิ่มรายได้ 2.9 ล้านบาท/ปี" (ลีน, 2568)

- โรงสี 20 ตัน/วัน: เครื่องขัดขาวรอบที่ 1 ความเร็ว 430 rpm → ลดเป็น 300 rpm
- ผล: อัตราการสูญเสียข้าวต้น 22% → 13.3% (ข้าวต้นรวม 35.2% → 36.19%)
- **รายได้เพิ่ม 2,963,340 บาท/ปี** จากข้าวต้นที่ขายราคาสูง — ลงทุนแค่ "ตั้งค่าความเร็ว" ไม่ต้องซื้อเครื่องใหม่!
- บทเรียน: "การเก็บข้อมูล + ปรับตั้ง = ของฟรีที่ทำกำไร" — ก่อนลงทุน AI ควรตั้งระบบวัด KPI (ข้าวต้น/ข้าวหัก) ให้ถูกต้องก่อน

### 5.3 AI ในโรงสี

| งาน                               | เทคโนโลยี                                                             |
| --------------------------------- | --------------------------------------------------------------------- |
| คัดเมล็ดเสีย/สิ่งเจือปนตอนรับข้าว | วิทัศน์ AI (unsound kernel detection) — กำหนดราคารับซื้ออย่างเป็นธรรม |
| ควบคุมรอบขัดขาวตามความชื้น        | แบบจำลอง ML ปรับรอบแบบ real-time (จากกรณีลีน)                         |
| ตรวจรอยร้าว/กระเทาะก่อนสี         | NIR + image — ลดสีข้าวพลาด                                            |
| โรงสี "ไร้คน" (ปลายทาง)           | หุ่นยนต์ลำเลียง/เก็บตัวอย่าง + AI ตัดสินใจ (ยังไกลในไทย)              |

## 6. การคัดเกรดด้วยวิทัศน์ AI และ NIR

| เทคโนโลยี                       | หลักการ                                                                           | จุดเด่น vs คน                                                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Machine vision (วิทัศน์ AI)** | กล้องความเร็วสูง + CNN จำแนกเมล็ด/ผลไม้: แตก/หัก/เหลือง/สิ่งเจือปน/แมลง           | ความเร็วหลายสิบตัน/ชม., ตรวจได้ตลอด 24 ชม., เกณฑ์คงที่ — ตรงข้ามคนที่ล้า/เพลี่ยงพล้ำตอนดึก                         |
| **NIR on-machine**              | สเปกตรัมอินฟราเรดใกล้ วัดความชื้น/โปรตีน/แป้ง/ไขมัน แบบไม่ทำลาย (non-destructive) | **เทรนด์ Agritechnica 2025** — เซนเซอร์ NIR ติดบนเครื่องจักร วิเคราะห์แบบ real-time ระหว่างไหล (Dinamica Generale) |
| **เทคนิค NIR พกพา**             | อุปกรณ์มือถือที่หน้าโรง/แปลง                                                      | ICRISAT: 150+ ตัวอย่าง/วัน — ใช้ตั้งราคารับซื้อ                                                                    |
| **X-ray/LF-NMR**                | ตรวจภายในเมล็ด (โรค/แมลงในเมล็ด)                                                  | ยังราคาสูง — ใช้เฉพาะโรงใหญ่                                                                                       |

## 7. มันสำปะหลังและผลไม้หลังเก็บเกี่ยว

### 7.1 มันสำปะหลัง

- ห่วงโซ่: ขุด → สับเหง้า (ด้าน 10: เครื่องสับ 6 ช่องป้อน เร็วกว่าคน 2.92 เท่า แต่สูญเสียเนื้อ 0.78%) → **มันเส้น/มันอัดเม็ด** (อบแห้ง-บด-อัด) สำหรับอาหารสัตว์/เอทานอล
- เปอร์เซ็นต์แป้ง (starch content) = ตัวกำหนดราคา — เครื่องชั่ง/เซนเซอร์หาแป้ง (Reimann/ลอยน้ำ) เริ่มใช้ตามท่ามัน/ลานรับซื้อ
- โรงงานมันเส้น: อบแห้งด้วยลมร้อน/ตากลาน + เตาอบมันเส้นอัตโนมัติ (หลังการเก็บเกี่ยวเป็นงาน "โรงงาน" มากกว่าแปลง)
- บทเรียน ด้าน 10: โครงการ "คูโบต้า มัน(ส์) ขยายร่อง" (2569) ตั้งเป้า 3→5 ตัน/ไร่ — ถ้าเก็บเกี่ยว/จัดการหลังเก็บเกี่ยวดี ที่นี่คือ "กำไรที่ซ่อนอยู่"

### 7.2 ทุเรียน/ผลไม้

- ตลาดทุเรียนสดต้องการ "คุณภาพผลสด" → ระบบคัดเกรดด้วยวิทัศน์ AI (ขนาด/หนาม/สี/รอย) เริ่มใช้ในแพ็กกิ้งเฮาส์ (เชื่อมคลัง AI เกษตร)
- ตลาดส่งออก (จีน) บังคับมาตรฐาน GAP → โรงคัด/แพ็กกิ้งเฮาส์อัตโนมัติเติบโต
- ตรวจความสุกแบบไม่ทำลาย: NIR/ultrasound ตรวจเนื้อในผล

## 8. สถานะไทย vs ต่างประเทศ

| งาน            | ต่างประเทศ                               | ไทย                                                | ช่องว่าง                              |
| -------------- | ---------------------------------------- | -------------------------------------------------- | ------------------------------------- |
| อบแห้งอัจฉริยะ | เซนเซอร์ IoT + ควบคุมอัตโนมัติ (โรงใหญ่) | งานวิจัยมี (มข./มช.) แต่โรงสีชุมชนยังใช้วิธีเดิม   | ราคาชุด IoT/การส่งเสริม               |
| Smart storage  | AI ตรวจจับรา/ศัตรูโรงเก็บ (97.38%)       | ไซโลรัฐ/เอกชนใหญ่เริ่มมี telematics ข้อมูลอุณหภูมิ | การนำ AI มาใช้ + ข้อมูลเปิด           |
| โรงสี          | ควบคุมรอบอัตโนมัติ/NIR on-line           | ลีนตั้งค่าคนทำ (กรณี 300 rpm = +2.9 ล้าน/ปี)       | เซนเซอร์+NIR ราคาถูก                  |
| คัดเกรด        | vision AI เต็มรูปแบบ                     | โรงใหญ่ (ข้าวส่งออก/ทุเรียน) เริ่มใช้              | SME โรงสีเล็กยังใช้คน                 |
| ตัวเลขสูญเสีย  | FAO 14%                                  | 9.8% (แต่ 96.9% เกิดในแปลงเก็บเกี่ยว)              | การเชื่อมโยงเก็บเกี่ยว→หลังเก็บเกี่ยว |

## 9. แนวทางนำไปใช้

### 9.1 Blueprint

| ระดับ                | 1–2 ปี                                                                             | 2–4 ปี                                                 | 4+ ปี                                                  |
| -------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| **ชาวนา/กลุ่ม**      | เก็บเกี่ยวให้ถูกระยะ (พลับพลึง, -4%) + ระบายอากาศกองข้าวความชื้นสูง                | ใช้ NIR พกพา/บริการตรวจความชื้นตั้งราคาก่อนขาย         | ร่วมลงทุนอบแห้งชุมชน (พลังงานชีวมวล)                   |
| **โรงสีเล็ก-กลาง**   | ตั้ง KPI ข้าวต้น/หัก + ปรับรอบเครื่อง (ลีน = +รายได้ 2.9 ล้าน/ปี); ซ่อมบำรุงตามรอบ | เซนเซอร์ความชื้น + ควบคุมรอบอัตโนมัติ (ML ตามความชื้น) | วิทัศน์ AI คัดเมล็ด + NIR on-line (เกรด/ราคาอัตโนมัติ) |
| **โรงสีส่งออก/ไซโล** | ติดตั้ง telematics ข้อมูลอุณหภูมิ + ระบายอากาศอัจฉริยะ                             | ระบบเตือนรา/กลั่นตัว (3D DenseNet/GCN-TFT) + CO2       | โรงคัด "ไร้คน" + เกรดส่งออกผ่าน AI                     |

### 9.2 เกณฑ์การลงทุนหลังเก็บเกี่ยว

1. **เริ่มจาก "เกี่ยวให้ดี"** — 96.9% ของการสูญเสียข้าวไทยอยู่ที่รถเกี่ยว (ตั้งค่าถูก = -22.5%)
2. **ของฟรีมาก่อน**: ปรับรอบเครื่อง/ตารางซ่อม → วัดผล 1 ฤดู (กรณีโรงสี +2.9 ล้าน/ปี)
3. **NIR พกพา มาก่อน NIR on-line** — ราคาหลักหมื่น ไม่ใช่หลักแสน
4. **เก็บ "ข้อมูลความชื้น+อุณหภูมิ" ทุกชุด** — ข้อมูลนี้เองเป็นอาหารของระบบ AI ต่อไป
5. **ลงทุนอบแห้งก่อนเก็บ** — "เก็บดี-อบดี" คุ้มกว่าซื้อเครื่องคัดเกรดแพง ๆ (ข้าวเสียคุณภาพแล้วคัดไปก็ขายถูกอยู่ดี)

## 10. ความท้าทาย

| ความท้าทาย                 | รายละเอียด                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **การสูญเสียอยู่ต้นทาง**   | 96.9% เกิดที่รถเกี่ยว — เทคโนโลยี "หลังเก็บเกี่ยว" แก้ได้แค่ 3.1% ถ้าไม่แก้การเก็บเกี่ยว |
| **ลานตาก/เครื่องอบไม่พอ**  | ข้าวความชื้นสูงรออบเป็นกอง เสี่ยงเสื่อมก่อนถึงมือผู้ประกอบการ                            |
| **โรงสีเล็กไร้ข้อมูล**     | ไม่มี KPI ข้าวต้น/หัก → ปรับปรุงไม่รู้ทิศทาง                                             |
| **ราคาเซนเซอร์/NIR**       | ยังแพงสำหรับโรงสีชุมชน (จุดคุ้มที่กำลังการผลิตสูง)                                       |
| **พฤติกรรม**               | ชาวนาตากข้าวบนถนน (เสี่ยงอันตราย) — สวนทางกับมาตรฐานคุณภาพ                               |
| **AI ต้องมีข้อมูลจริงไทย** | แบบจำลองโรงเก็บมาจากต่างประเทศ (ข้าวต่างพันธุกรรม/สภาพอากาศ) — ต้องเทรนใหม่              |

## 11. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **"Smart Grain Storage" สู่เชิงพาณิชย์**: 3D DenseNet 97.38% + GCN-TFT (2569) — ผู้จำหน่ายไซโลเริ่มแพ็ก AI เตือนรา/กลั่นตัวเป็นบริการ (เชื่อม ด้าน 08: telematics โรงสี)
2. **NIR on-machine ราคาถูกลง** (เทรนด์ Agritechnica 2025) — ติดบนรถเกี่ยว/โรงสีไทยใน 3–5 ปี (วัดความชื้น+โปรตีนขณะไหล)
3. **การตั้งราคาตามคุณภาพ (quality-based pricing)**: NIR พกพา + วิทัศน์ AI ตรวจเมล็ดเสียตอนรับซื้อ → ชาวนาได้รับค่าตอบแทนตามคุณภาพจริง (สร้างแรงจูงใจดูแลหลังเก็บเกี่ยว)
4. **โรงสีลีน→AI**: กรณี 300 rpm +2.9 ล้าน/ปี จะกลายเป็นชุด "auto-setting" ในเครื่องขัดขาวรุ่นใหม่ (ผู้ผลิตไทย/จีน)
5. **อบแห้งพลังงานชีวมวล/โซลาร์**: ลดต้นทุนพลังงานอบข้าว + คาร์บอนเครดิต (เชื่อมด้าน 05)
6. **การเชื่อมข้อมูล "แปลง→โรงสี"**: ข้อมูลความชื้นจากรถเกี่ยว (ด้าน 02/08) ส่งตรงถึงโรงสี ลดการรอตรวจ/กำหนดแผนอบล่วงหน้า — ห่วงโซ่ข้อมูลครบวงจร (ตรงกับหัวข้อ 09 ของคลัง AI เกษตร)

## 12. อภิธานศัพท์

| คำศัพท์                     | ความหมาย                                                      |
| --------------------------- | ------------------------------------------------------------- |
| **PHL (Post-Harvest Loss)** | การสูญเสียหลังเก็บเกี่ยว: เชิงปริมาณ+เชิงคุณภาพ (ราคาตก)      |
| **Head rice / ข้าวต้น**     | ข้าวสารที่ไม่หัก (ราคาสูงสุด) — ตรงข้ามข้าวหัก                |
| **ความชื้น wb**             | ความชื้นแบบ wet basis; ข้าวปลอดภัยเก็บ = 14% wb               |
| **ระยะพลับพลึง**            | ระยะการเก็บเกี่ยวที่เหมาะสมของข้าว (ก่อนล้ม/หลังสุกพอดี)      |
| **NIR**                     | อินฟราเรดใกล้: วัดคุณภาพแบบไม่ทำลาย (ความชื้น/โปรตีน/แป้ง)    |
| **Unsound kernel**          | เมล็ดเสีย (หัก/ด่าง/ขึ้นรา) — ตรวจตอนรับข้าวเข้า              |
| **Intelligent aeration**    | การระบายอากาศอัตโนมัติตามสภาพกองข้าว (AI ตัดสินใจ)            |
| **Rewetting**               | การเปียกซ้ำของเมล็ด (หลังแห้งแล้วโดนน้ำ) — ทำร้ายคุณภาพมากสุด |
| **Digital twin (คลัง)**     | จำลองกองข้าว/ไซโลแบบ real-time ใช้พยากรณ์ความเสี่ยง           |
