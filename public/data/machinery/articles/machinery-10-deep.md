## 1. หลักการและขอบเขต

ด้านนี้รวบรวมเครื่องจักรที่ออกแบบ/ปรับใช้สำหรับ "พืชเศรษฐกิจของไทยโดยเฉพาะ" — ข้าว อ้อย มันสำปะหลัง ยางพารา ปาล์มน้ำมัน ทุเรียน/ผลไม้ — ซึ่งโครงสร้างแปลง ขั้นตอนการผลิต และคุณภาพผลผลิตต่างจากธัญพืชตะวันตก โดยเน้น 3 คำถาม: (1) มีเครื่องจักรไทยที่ทำได้จริงแค่ไหน (2) เทคโนโลยีโลกแปลมาใช้ได้ตรงไหน (3) ช่องว่างที่ต้องพัฒนา

**ความจริงที่ต้องยอมรับ**: เครื่องจักร "อัจฉริยะ" ระดับ AI ที่ขายในสหรัฐฯ/ยุโรป **ยังแทบไม่เข้าสู่แปลงไทย** — สิ่งที่ไทยใช้จริงคือเครื่องจักรพื้นฐาน (เกี่ยวนวด/ตัดอ้อย/ขุดมัน) ที่ถูกปรับปรุงเป็นรุ่น "กึ่งอัตโนมัติ" และโดรน (ด้าน 03) — ช่องว่างระหว่าง "เทคโนโลยีที่มี" กับ "เทคโนโลยีที่ใช้" เป็นประเด็นหลักของด้านนี้

## 2. โครงสร้างการถือครองแปลงไทยและนัยต่อเครื่องจักร

| ตัวเลข (ภาพรวม)              | ค่า                   | ผลต่อเครื่องจักร                                   |
| ---------------------------- | --------------------- | -------------------------------------------------- |
| ครัวเรือนถือครอง <20 ไร่     | 65.4%                 | เครื่องใหญ่ไม่คุ้ม → ต้องบริการรับจ้าง/เครื่องเล็ก |
| ครัวเรือนที่ใช้เครื่องจักร   | 71.3%                 | การใช้เครื่องจักรเป็น "เรื่องปกติ" อยู่แล้ว        |
| ภาคอีสานใช้เครื่องจักรสูงสุด | ~80%                  | กลุ่มตลาดใหญ่สุดของเกี่ยวนวด/รถไถ                  |
| รถไถ 4WD                     | 50.8% ของรถไถ         | ฐานสำหรับเครื่องมือพ่วง/ระบบนำทาง                  |
| ข้าว = พื้นที่เพาะปลูก       | 46.2% ของพื้นที่เกษตร | เครื่องข้าว = ตลาดหลัก                             |
| ฟาร์มใช้เกี่ยวนวด            | 27.9%                 | อีก ~72% ใช้แรงงาน/บริการรับจ้าง                   |

**นัยเชิงกลยุทธ์**: การออกแบบเครื่องจักรไทยต้องเริ่มจาก "แปลง <20 ไร่ + บริการรับจ้าง" ไม่ใช่ "ฟาร์ม 5,000 ไร่" — นี่คือเหตุผลที่เครื่องไทยประสบความสำเร็จ (เช่น รถตัดอ้อยเล็ก/เกี่ยวนวดเล็ก) ต่างจากเครื่องใหญ่ตะวันตก

### 3.3 ระบบรับจ้างครบวงจร

- วิสาหกิจชุมชน 175/208 กลุ่ม (ขอนแก่น) มีเกี่ยวนวด (ข้อมูลงานวิจัย 2568) — คิดค่าบริการถูกกว่าตลาด 50–200 บาท/ไร่
- การรับจ้างไถ + ดำนา + เก็บ = 28–33% ของรายได้ฟาร์ม (920–1,350 บาท/ไร่) — "ค่าบริการเครื่องจักร" เป็นต้นทุนหลักของเกษตรกรรายย่อย

## 4. อ้อย: เครื่องตัดอ้อยสดและการเปลี่ยนผ่าน PM2.5

### 4.1 สถานการณ์

- อ้อยสด (ไม่เผา) 97% ของการเก็บเกี่ยว MY2025/26 — สูงสุดเป็นประวัติการณ์ (ค่าเฉลี่ย 10 ปี 63%) เกิดจากนโยบาย PM2.5 + ส่วนเพิ่มราคา + การลงทุนเครื่องตัดอ้อย
- แต่ราคาอ้อย 890 บาท/ตัน (MY2025/26) ต่ำกว่าต้นทุน 1,358 บาท/ตัน → พื้นที่อ้อยคาดหด 1.5–8% (MY2026/27) — เศรษฐศาสตร์ฟาร์มเป็นตัวชะลอการใช้เครื่องจักร

### 4.2 ผู้ผลิตเครื่องตัดอ้อยไทย: กรณีสามารถเกษตรยนต์

| รุ่น                    | รายละเอียด                                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SM-200C** (ตีนตะขาบ)  | ขายดีอันดับต้นของประเทศ 10+ ปี; 200 แรงม้า 6 สูบ; ตัด 80–100 ตัน/วัน; เหมาะแปลงเล็ก/พื้นที่ลาด (35°)/อ้อยล้ม                                             |
| **SM-200 Predator**     | เปิดตัว Sugarex 2022; 80–180 ตัน/วัน; ขายแล้ว 20+ คัน; สหเรือง มุกดาหารสั่ง 23 คัน (พ.ย. 2568)                                                           |
| **Superspeed**          | ออกแบบสำหรับผู้รับเหมาตัดอ้อย (งานหนัก/ยาว)                                                                                                              |
| **ระบบ Self-Unloading** | ถังบรรทุกในตัว 3 ตัน (SM200C/Predator) และ 7 ตัน (Superspeed) — ไม่ต้องพึ่งรถพ่วงรับอ้อยข้างเครื่อง, เทได้เองปลายแปลง, ลดความเสียหายตอ, ทำงานแปลงเล็กได้ |
| ประสิทธิภาพ             | สูงสุด ~22 ตัน/ชม., น้ำมัน <1 ลิตร/ตันอ้อย                                                                                                               |
| ตลาดส่งออก              | อินโดนีเซีย บราซิล กัมพูชา เมียนมา                                                                                                                       |

### 4.3 นวัตกรรมภาควิชาการ: "พาลี ซีโร่พีเอ็ม1" (สจล.)

- เครื่องตัดอ้อยสดพ่วงแทรกเตอร์ (PTO ขับ) ทำครบ 4 ขั้น: สางใบ-ตัดโคน-ตัดยอด-ลำเลียงวางกอง ในเครื่องเดียว
- ประสิทธิภาพ ~10 ไร่/100 ตันต่อวัน; ใช้คนเดียว; ราคาไม่แพง; ทดลองในไร่อ้อยมิตรผล (ชัยภูมิ)
- ประกอบกับนโยบาย ธกส. สินเชื่อรถตัดอ้อย 4,000 คัน/6,000 ล้านบาท (ดอกเบี้ย 2%, 8 ปี) — เป้าหมายยุคแรก "เลิกเผาอ้อยภายใน 2565"

### 4.4 บทเรียนการสูญเสีย

- งานวิจัยชัยภูมิ (2569): เครื่องตัดอ้อยอายุ 17 ปี สูญเสีย 241.93 กก./ไร่ (+54% เทียบเครื่องใหม่), กำไรฟาร์มลด 12–18%; สิ่งเจือปนหลัก = ยอดอ้อย 57% (รายละเอียดในด้าน 02)
- นัย: การซ่อมบำรุง/เปลี่ยนเครื่องตามรอบเป็น "การลงทุน" ไม่ใช่ค่าใช้จ่าย

## 5. มันสำปะหลัง: การเก็บเกี่ยวและเครื่องจักรในประเทศ

### 5.1 ปัญหาหลักของการเก็บเกี่ยวมันสำปะหลัง

- งานเก็บเกี่ยว = 3 ขั้น: ขุด/ถอน → สับเหง้า (แยกหัวออกจากลำต้น) → รวมกอง/ขนขึ้นรถ — **ขั้นสับเหง้ายังเป็นแรงงานคนเป็นส่วนใหญ่**
- การสูญเสียหัวมันในดิน 5–15% (หัวแตก/ขุดไม่ขึ้น) — งานวิจัยไทย 30+ ปี มุ่งแก้จุดนี้

### 5.2 ความก้าวหน้าของเครื่องขุด/เก็บเกี่ยวไทย

| งานวิจัย/เทคโนโลยี                                             | ผลลัพธ์                                                                                                                                                   |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| เครื่องขุด มข.46 (ขอนแก่น, 2548)                               | ลำเลียงหัวมันพ้นแนวล้อ (700–800 มม.) ลดการสูญเสียจากการเหยียบซ้ำ; ความสามารถ 0.74 ไร่/ชม.                                                                 |
| เครื่องขุดแบบไถหัวหมู (อนุชิต, 2552)                           | ผาลขุดพลิกดินแบบไม่ตัดหัว — มีผู้ประกอบการนำไปผลิตจำหน่าย                                                                                                 |
| **ผาลขุดจานโค้งถ่วงน้ำหนัก 50 กก.** (TSAEJ 2566, กาฬสินธุ์)    | ความลึกขุด 19.1→22.2 ซม. (ครอบคลุมหัวมัน 48.9%→81.1%), สูญเสียลด 0.99%, รายได้เพิ่ม **117.56 บาท/ไร่** — "ปรับเงินง่าย ๆ ด้วยถ่วงน้ำหนักผาล"              |

| **เครื่องสับเหง้า 6 ช่องป้อน** (TSAEJ)                         | 522 ต้น/ชม./คน (1,152 กก./ชม.) — **เร็วกว่าแรงงานคน 2.92 เท่า** (แต่สูญเสียเนื้อ 0.78% สูงกว่า 2.65 เท่า — ต้องปรับปรุง)                                  |
| **เครื่องหยอดปุ๋ยตามค่าวิเคราะห์ดินอัตโนมัติ** (TSAEJ 2568)    | Arduino Mega + มอเตอร์ DC 24V 500W + PWM; ความแม่นยำ 90–94% ต่อปุ๋ย 3 สูตร; ทำงาน 4.79 ไร่/ชม.; น้ำมัน 0.69 ลิตร/ไร่ — "VRT ฉบับไทย" เริ่มเป็นรูปเป็นร่าง |

### 5.3 สรุปสถานะ

- เครื่องขุด = มีเชิงพาณิชย์แล้ว (ทั้งในประเทศและนำเข้า) — ปัญหาเหลือที่ "รวมขั้นตอน" และ "ลดความเสียหายหัวมัน"
- เครื่องสับเหง้า = กึ่งอัตโนมัติ ยังต้องคนป้อน
- เครื่องเก็บเกี่ยวครบวงจร (ขุด+สับ+ขนในเครื่องเดียว) = ยังเป็นงานวิจัย/ต้นแบบ — ช่องว่างที่ชัดเจนที่สุดของมันสำปะหลัง

## 6. ยางพารา: เครื่องกรีดยางอัตโนมัติ

### 6.1 ปัญหาโครงสร้าง

- การกรีดยางเป็นงานฝีมือ ต้องเริ่มตี 2–3 ขึ้นต้น มีทักษะ ใช้เวลานาน/ต้น
- แรงงานกรีดยางหายากขึ้นเรื่อย ๆ + กรีดช่วงหน้าแล้งไม่ได้ — ปัญหาหนักในภาคใต้
- ยางไทยส่วนใหญ่เป็นสวนรายย่อย (แปลง <20 ไร่) — กำไรต่อไร่บาง → ลงทุนเครื่องจักรยาก

| ประเภท                                 | สถานะ                                                                                                                                                          |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| เครื่องกรีดยางอัตโนมัติ (ในประเทศ/จีน) | มีต้นแบบวิจัยไทย (ม.สงขลานครินทร์ ฯลฯ) + เครื่องเชิงพาณิชย์นำเข้าจากจีนเริ่มใช้ในบางพื้นที่ — ความแม่นยำรอยกรีด/ความลึกยังเป็นโจทย์ (กรีดลึกไปทำร้ายท่อน้ำยาง) |
| หุ่นยนต์กรีดแนวตั้ง/ความสูงตามลำต้น    | ต้นแบบต่างประเทศ (มาบนแทร็ก/ตีนตะขาบ) — ยังไม่เชิงพาณิชย์ในไทย                                                                                                 |
| ระบบเก็บน้ำยางอัตโนมัติ                | เซนเซอร์วัดน้ำยาง + ท่อ/ปั๊ม — มีใช้ในสวนใหญ่บางแห่ง                                                                                                           |
| ข้อควรรู้                              | "เครื่องกรีดได้ ไม่เท่ากับกรีดดี" — ผลผลิตยางขึ้นกับคุณภาพรอยกรีด ต้นทุนแรงงานกรีดคิดเป็น ~40–50% ของต้นทุนการผลิต                                             |

### 6.3 โจทย์วิจัยที่สำคัญ

1. กรีดได้แม่นยำเทียบเท่าช่างกรีด (ความลึก/มุม/ความสะอาดรอย)
2. ราคาต่อต้นต้องต่ำพอ (ยางราคากก.ละ 60–100 บาท)
3. ทนสภาพอากาศ (ฝน/ความชื้นสูง) และใช้งานง่ายสำหรับสวนเล็ก

## 7. ปาล์มน้ำมันและผลไม้: สวนต้นสูง

### 7.1 ปาล์มน้ำมัน (ใต้/กลาง)

| งาน                        | เทคโนโลยี                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------- |
| เก็บทะลาย (ตัดทางใบ-เครือ) | ยังเป็นแรงงานคน (จ้างตัด) + กรรไกรยาว/เสากล — เครื่องจักรช่วยได้น้อย (ต้นสูง 5–10 ม.) |
| ขนย้ายทะลายในสวน           | รถอเนกประสงค์ EV (RAINA-class, ด้าน 05), รถเข็น/รางเลื่อน, โดรนลำเลียง (เริ่มนำร่อง)  |
| งานตัด/รดน้ำ               | เครื่องตัดหญ้าใต้ทรงพุ่ม, ระบบน้ำอัตโนมัติ                                            |
| โรงงาน                     | ระบบหีบน้ำมันปาล์มอัตโนมัติ (ห่วงโซ่โรงงาน) — อยู่นอกขอบเขตเครื่องจักรในแปลง          |

**ประเด็นสำคัญ**: แรงงานต่างด้าวในสวนปาล์มลดลงหลังปัญหาชายแดน → ราคาค่าแรงตัดทะลายพุ่ง — ตลาด "เครื่องช่วยตัด/ลำเลียง" เปิดกว้าง

### 7.2 ทุเรียน/ผลไม้ต้นสูง (ตะวันออก/ใต้)

- **การพ่นยา**: โดรนแก้ปัญหาได้จริง (ต้นสูง 30 ม. — ดูด้าน 03): ลดเวลาจาก 4 วัน → 1–2 วัน, สาร -20–30%
- **การลำเลียง**: ระบบลิฟต์/รางในสวน + โดรนลำเลียง (40 กก.) เริ่มใช้ในสวนทุเรียนภูเขาไฟ
- **การตรวจทรงพุ่ม**: โดรนสำรวจ + AI ตรวจโรค/นับผล (เชื่อมคลัง AI เกษตร)
- **การเก็บผล**: ยังเป็นคนทั้งหมด (ต้องพลิก/เคาะตามความสุก) — หุ่นยนต์เก็บผลไม้ยังไกล

### 7.3 ข้าวโพด (สลับด้วย)

- หัวเก็บข้าวโพด (corn picker/header) มีในไทย (เกษตรพัฒนา ผลิต+ส่งออก) — การเก็บฝักจากต้นยืน

## 8. ผู้ผลิตเครื่องจักรไทยและห่วงโซ่อุปทาน

| ผู้ผลิต                          | ความเชี่ยวชาญ                                              | สถานะ                                                 |
| -------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------- |
| **สยามคูโบต้า** (JV ไทย-ญี่ปุ่น) | รถไถ/เกี่ยวนวด/ดำนา/โดรน DJI; เครื่องตัดอ้อยสายใหม่ (2026) | รายได้ 55B (2568) → เป้า 62B (2569)                   |
| **ยันมาร์ เอส.พี.**              | รถไถ/เกี่ยวนวด/ตัดอ้อย/ดำนา + Yanmar Capital (สินเชื่อ)    | เครือข่ายดีลเลอร์ทั่วประเทศ                           |
| **ไทยเส็งยนต์**                  | รถเกี่ยวนวดข้าว (แบรนด์ไทยล้วน, 60+ ปี)                    | ผู้นำตลาดเกี่ยวนวดในประเทศ                            |
| **เกษตรพัฒนา (Kaset Phattana)**  | เกี่ยวนวด/ข้าวโพด/เครื่องสี/รถเกษตร (40+ ปี)               | ส่งออก 11+ ประเทศ                                     |
| **สามารถเกษตรยนต์**              | รถตัดอ้อย SM-200C/Predator/Superspeed + รถคีบอ้อย          | เกิดจากชาวไร่อ้อยเอง (2528), ส่งออกอินโดนีเซีย/บราซิล |
| **ไทย อชิเทค (TACT)**            | รถไถไฟฟ้า KIN (BOI, ISO 14064)                             | สตาร์ท EV เกษตรไทย (ด้าน 05)                          |
| **ไร่นา โรโบเทค (RAINA)**        | รถ EV อเนกประสงค์สวนผลไม้/ปาล์ม + RaiNav                   | สตาร์ทหุ่นยนต์ไทย                                     |

**บทเรียนจากสามารถเกษตรยนต์**: นวัตกรรมเครื่องจักรไทยที่ "รอดและโต" ไม่ได้มาจากยักษ์ใหญ่ แต่มาจากผู้ประกอบการที่ "เกิดจากแปลง" (ชาวไร่อ้อยเอง) รู้ปัญหาแท้จริง (แปลงเล็ก/ลาดชัน/อ้อยล้ม/ไม่มีรถพ่วง) แล้วออกแบบแก้ — โมเดลที่ควรเลียนแบบในพืชอื่น

## 9. สถานะเทคโนโลยีไทย vs ต่างประเทศ

| พืช/งาน         | ไทย                                    | ต่างประเทศ                        | ช่องว่าง                       |
| --------------- | -------------------------------------- | --------------------------------- | ------------------------------ |
| เกี่ยวนวดข้าว   | กึ่งอัตโนมัติ (เล็ก/ราคาถูก)           | อัตโนมัติเต็ม (Deere/Kubota DRH)  | yield map/loss sensor/autonomy |
| ตัดอ้อย         | รถเล็ก-กลางทำเองได้ดี (self-unloading) | รถใหญ่ chopper (Case/JD)          | ประสิทธิภาพ/ความสะอาดต่อตัน    |
| มันสำปะหลัง     | ขุด=พาณิชย์, สับ=กึ่งอัตโนมัติ         | (ไม่มีเทียบเท่าโดยตรง — พืชเฉพาะ) | เครื่องเก็บเกี่ยวรวมขั้นตอน    |
| กรีดยาง         | งานวิจัย/นำเข้าจีน                     | ต้นแบบหุ่นยนต์                    | ความแม่นยำ/ราคา/ความเชื่อมั่น  |
| โดรนพ่นสวนผลไม้ | ใช้งานจริงกว้างสุดภูมิภาค              | จีนนำ (DJI/XAG)                   | ไทยใช้ของจีนทั้งหมด            |
| ปาล์ม           | งานคนเกือบหมด                          | มาเลย์/อินโดมีเครื่องช่วยเก็บ     | งานตัดทะลาย                    |
| รถไถ+นำทาง      | เริ่มนำเข้า RTK (1.5–2%)               | 20–25% ของรถที่เหมาะ              | โครงข่าย RTN/ราคา              |

**ข้อสรุป**: ไทยเก่ง "เครื่องจักรพื้นกลาง" (เกี่ยวนวด/ตัดอ้อยขนาดเล็ก ทำเองได้) แต่ล้าหลัง "ชั้นอัจฉริยะ" (เซนเซอร์/AI/autonomy) — ช่องว่างนี้ปิดได้ด้วยการผสานของ 3 ฝ่าย: ผู้ผลิตไทย + เทคโนโลยี IoT/GNSS (ราคาลง) + นโยบายสนับสนุน

| อ้อย          | ใช้บริการรถตัดอ้อย (เทียบต้นทุนเผา+ค่าแรง)       | วิสาหกิจซื้อเครื่อง 1–2 คัน (SM-200C) ให้บริการสมาชิก | ระบบจัดตารางตัด-ขนส่งตาม CCS (ข้อมูล)   |

| ทุเรียน/ผลไม้ | บริการโดรนพ่น+ลำเลียง (ไร่ละ ~100–250 บาท)       | โดรนสำรวจตรวจโรคก่อนพ่น (เชื่อม AI เกษตร)             | ระบบพ่นตามแผนที่ (VRT โดรน)             |

### 10.2 กติกาการลงทุนเครื่องจักรพืชไทย

1. **คำนวณเป็น "บาท/ไร่/ฤดู"** ไม่ใช่ราคาเครื่อง — ใช้ข้อมูลจริงของจังหวัด
2. **จ้างก่อนซื้อ**: ใช้บริการรับจ้าง 1 ฤดู แล้วค่อยตัดสินใจซื้อ
3. **รวมกลุ่มซื้อ**: แปลงเล็กควรซื้อผ่านวิสาหกิจ/กลุ่มแปลงใหญ่
4. **ตรวจสอบอะไหล่/ศูนย์บริการในจังหวัด** ก่อนซื้อทุกครั้ง
5. **ตรวจผลงานวิจัย/รีวิว** (TSAEJ, วารสารวิศวกรรมเกษตรไทย) — ไม่เชื่อโบรชัวร์ล้วน ๆ

## 12. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **ผู้ผลิตไทยทำ "เครื่องอัจฉริยะ"**: ไทยเส็งยนต์/เกษตรพัฒนา/สามารถเกษตรยนต์ เพิ่มเซนเซอร์+GNSS ในรุ่นใหม่ (แนวโน้มการส่งออกแบบ smart)
2. **VRT ฉบับไทย**: เครื่องหยอดปุ๋ยตามค่าวิเคราะห์ดิน (TSAEJ 2568) → ขยายสู่ข้าว/อ้อย — "precision ที่ราคาจับต้องได้"
3. **เครื่องเก็บเกี่ยวมันสำปะหลังรวมขั้นตอน**: งานวิจัยหลายสถาบันใกล้สำเร็จ — จับตาต้นแบบเชิงพาณิชย์
4. **เครื่องกรีดยางเชิงพาณิชย์**: เครื่องจีน + การทดสอบไทย — ถ้าราคา/ความแม่นยำผ่าน จะพลิกอุตสาหกรรมยาง
5. **โดรน=เครื่องจักรหลักของสวนผลไม้**: งานพ่น/สำรวจ/ลำเลียง รวมเป็นแพ็กเกจบริการครบวงจร
6. **นาแปลงใหญ่ + RTN**: โครงข่าย RTK สาธารณะ (กรมพัฒนาที่ดิน 10 จังหวัด) + นาแปลงใหญ่ → เกี่ยวนวด/ดำนาอัตโนมัติแบบไทย
7. **การอัปเกรดเครื่องมือเดิม (retrofit)**: ชุด GNSS/เซนเซอร์ราคาถูกติดตั้งบนเครื่องไทยที่มีอยู่ — เส้นทางเร็วสุดสู่ "เครื่องอัจฉริยะ"
