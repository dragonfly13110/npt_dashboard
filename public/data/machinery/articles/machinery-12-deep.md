## 1. หลักการและขอบเขต

"เครื่องจักรไม่ได้สร้างกำไรจากการเป็นเจ้าของ แต่สร้างกำไรจากการทำงาน" — เครื่องจักรการเกษตรใช้งานจริงเฉลี่ย 50–300 ชั่วโมง/ปี เท่านั้น (เครื่องส่วนใหญ่จอดเฉย 90% ของเวลา) → เศรษฐศาสตร์ของการ "แบ่งปัน" (sharing economy) จึงเข้มแข็งกว่าการ "เป็นเจ้าของ" โดยเฉพาะแปลงไทยที่ 65.4% ถือครอง <20 ไร่ (ด้าน 10) ด้านนี้ครอบคลุม: ระบบ ASP/รับจ้างไทย, แพลตฟอร์มจับคู่ทั่วโลก, Machinery-as-a-Service (MaaS), และการเงินสำหรับผู้ให้บริการ

## 2. ทำไม "การแบ่งปัน" จึงเป็นหัวใจของกลไกเครื่องจักรไทย

| ตัวเลข                                                                                 | ความหมาย                                                                                                         |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 65.4% ของแปลง <20 ไร่                                                                  | ซื้อเครื่องเองคืนทุนไม่ได้ — ต้องจ้าง/แบ่งปัน                                                                    |
| เกี่ยวนวด 500–600 บาท/ไร่ (สศข.5)                                                      | ค่าบริการนี้ "หลุดออกจากหมู่บ้าน" ไปให้ผู้รับจ้างต่างถิ่น — หมู่บ้านเดียว 2,000 ไร่ = **1.1 ล้านบาท/ฤดู** ไหลออก |
| 28–33% ของรายได้ฟาร์มเป็นค่าบริการเครื่องจักร (ขอนแก่น, ด้าน 10)                       | ระบบรับจ้างคือ "ตลาดใหญ่ที่มองไม่เห็น" — ราคาไม่มีมาตรฐาน                                                        |
| งานวิจัยขอนแก่น: วิสาหกิจ 175/208 กลุ่มมีเกี่ยวนวด ค่าบริการต่ำกว่าตลาด 50–200 บาท/ไร่ | การรวมกลุ่มลดราคาได้จริง                                                                                         |

**บทสรุปเชิงโครงสร้าง**: ไทยมี "บริการรับจ้าง" เป็นวิถีปกติมานาน (ผู้ประกอบการนำรถเกี่ยวนวดตระเวนต่างจังหวัด) แต่ขาด **การจัดระเบียบ ข้อมูลราคา และการยกระดับคุณภาพ** — นี่คือที่มาของระบบ ASP ปี 2568–69

## 3. ระบบ ASP ของไทย (สศก. + กรมส่งเสริมการเกษตร)

### 3.1 แนวคิด Agricultural Service Provider (ASP)

- **ต้นน้ำ**: ผู้ถือเครื่องจักร/เทคโนโลยี (รถไถ, รถเกี่ยว, โดรน, ชุดปรับปรุงดิน)
- **กลางน้ำ**: ผู้ประสาน/มาตรฐาน — รัฐ (มาตรฐานบริการ เช่น "ไถต้องลึกพอ, เกี่ยวต้องสะอาด" + **มาตรฐานราคา** ป้องกันตัดราคา/โก่งราคา)
- **ปลายน้ำ**: เกษตรกรผู้รับบริการ

**ผลลัพธ์จากข้อมูล สศก. (สำรวจ เม.ย. 2569)**:

- เกษตรกรใช้ ASP ลดต้นทุน + เพิ่มผลผลิต/รายได้ **≥10%**
- ผู้ให้บริการ (รับเหมาครบวงจร 50 ไร่/ฤดู) มีรายได้เสริม **62,000–138,000 บาท/ฤดูกาล**
- **ปี 2569: สศก. เริ่มจัดเก็บอัตราค่าบริการเครื่องจักรเป็นปีแรก 296 ตัวอย่างทั่วประเทศ** (ผ่าน สศข.1–12) — ฐานข้อมูลราคารายพื้นที่ สำหรับวางนโยบาย + ต่อยอดสู่การกำหนดมาตรฐานราคา

### 3.2 ทะเบียนผู้ให้บริการ (emachine.doae.go.th)

- ขึ้นทะเบียนผ่านเว็บไซต์ eMachine ของกรมส่งเสริมการเกษตร (หรือสำนักงานเกษตรอำเภอ/จังหวัด)
- จับคู่ "คนมีเครื่อง" ↔ "คนต้องการใช้" — รัฐเป็นกลางในการตั้งมาตรฐานทั้งสองฝ่าย

## 4. โครงสร้างราคาบริการรับจ้างไทย

| บริการ                              | ราคา (ข้อมูลอ้างอิง)                 | หมายเหตุ                                             |
| ----------------------------------- | ------------------------------------ | ---------------------------------------------------- |
| เกี่ยวนวดข้าว                       | **500–600 บาท/ไร่** (เฉลี่ย 550)     | สศข.5; ขอนแก่นวิสาหกิจ 650–850 (ต่ำกว่าเอกชน 50–200) |
| ขนข้าวเปลือก                        | 120–200 บาท/ตัน หรือ 5–10 บาท/กระสอบ | ตามระยะทางแปลง→ลาน                                   |
| รับทำนาครบวงจร (ไถ+ดำ/หยอด+เก็บ+ขน) | 920–1,350 บาท/ไร่                    | 28–33% ของรายได้ฟาร์ม (ขอนแก่น)                      |
| โดรนพ่นสวนผลไม้                     | 100–250 บาท/ไร่                      | ด้าน 03 — ราคาพึ่งพา/เกิดบริการแบบใหม่               |
| รับเหมาครบวงจร 50 ไร่/ฤดู (ASP)     | รายได้ 62,000–138,000 บาท            | สศก. เม.ย. 2569                                      |

**ประเด็นนโยบายจาก สศข.5**: ค่าเกี่ยวนวดจำนวนมหาศาลไหลออกจากชนบทไปผู้รับจ้างต่างถิ่น (ภาคกลางตระเวนมาอีสาน) — การสนับสนุน "ASP ประจำพื้นที่" จะเก็บเงินคืนถิ่น + สร้างงานทักษะใหม่ในชุมชน

## 5. กรณีศึกษาการรวมกลุ่ม: วิสาหกิจแปลงใหญ่ข้าวโพดเขาลวกฯ

**นายสุริยา ห่วงถวิล** ประธานวิสาหกิจชุมชนแปลงใหญ่ข้าวโพดเขาลวกพัฒนาฯ (เป็นกรณีตัวอย่างในรายการ Green Guide สศก.):

- บริหารเครือข่าย **รถเกี่ยว+รถไถ 40+ คัน** ตอบโจทย์สมาชิก 3,000+ ไร่ — เกษตรกรไม่ต้องลงทุนเอง
- ผลลัพธ์ผู้รับบริการ (คุณทองแดง นครสูตร): ผลผลิตข้าวโพด **600–700 กก./ไร่ → 1.4–1.5 ตัน/ไร่** — จากไถลึกพอ + หยอดแม่นยำ + ปุ๋ยตามค่าวิเคราะห์ดิน
- **ปลายน้ำรวมกันส่ง**: รวบรวมผลผลิตเป็นก้อน → ใช้รถพ่วง 30 ตันขนส่งครั้งเดียว ลดค่าขนส่ง/ตัน + ต่อรองราคาขายได้สูงขึ้น
- บทเรียนการเงิน: "ไม่ต้องเป็นทุกข์กับค่างวดรถ" — เงินหมุนเวียนไปซื้อเมล็ดพันธุ์/ปุ๋ยคุณภาพดีแทน (ตรงกันข้ามกับฟาร์มที่กู้ซื้อเครื่องเองแล้วหนี้ท่วม)

| --------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |

## 7. Machinery-as-a-Service โลก: จาก Deere สู่ Robot-as-a-Service

| โมเดล                                | รายละเอียด                                                                                                                     | สถานะ                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| **Deere Autonomy-as-a-Service**      | ใช้รถ 8R/8RX อัตโนมัติ (16 กล้อง, 100 ms) แบบ "เช่าใช้งาน" — ไม่ต้องซื้อเครื่อง; จ่าย $14–18/เอเคอร์ (จากการงานไถ 100 เอเคอร์) | เชิงพาณิชย์สหรัฐฯ/แคนาดา (ด้าน 01); 1.04 ล้านเอเคอร์ Level-4              |
| **Robot-as-a-Service (RaaS)**        | จ้าง "งาน" ไม่ใช่ "เครื่อง" — เช่น LaserWeeder จ่ายตามงานกำจัดวัชพืช, FarmDroid ตามไร่, โดรนพ่นตามไร่                          | Carbon Robotics, FarmDroid, จีน DJI Agriculture (pay-per-acre เริ่มทดสอบ) |
| **"จ่ายเมื่อได้ผล" (outcome-based)** | vendor เก็บค่าบริการเมื่อประหยัด/ผลผลิตเกินเป้า (เช่น Application Savings Guarantee ด้าน 04 — จ่ายตามหลักฐานการลดสารเคมี)      | เริ่มในสหรัฐฯ; สินค้าประเภท chemical/herbicide saving                     |

**นัยต่อไทย**: โดรนรับจ้าง (100–250 บาท/ไร่) คือ "RaaS ฉบับไทย" ที่พิสูจน์แล้ว — โมเดลเดียวกันใช้ได้กับรถตัดอ้อยรับจ้าง/รถไถ ASP (สศก. 62K–138K บาท/ฤดู)

## 8. การเงินและสินเชื่อสำหรับผู้ให้บริการ

| เครื่องมือ                          | รายละเอียด                                                                    |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| **สินเชื่อ ธกส. (รถตัดอ้อย)**       | 4,000 คัน/6,000 ล้านบาท ดอกเบี้ย 2% 8 ปี (นโยบาย PM2.5, ด้าน 10)              |
| **สินเชื่อเครื่องจักรดีลเลอร์**     | Kubota Financial Service, Yanmar Capital — ผ่อนรายเดือนตามรอบการใช้งาน        |
| **PAYG (Pay-As-You-Go)**            | Hello Tractor: จ่ายตามชั่วโมง/ไร่ที่ใช้จริง — ลดความเสี่ยงผู้ซื้อเครื่องแรก   |
| **สินเชื่อวิสาหกิจ/กองทุนหมู่บ้าน** | แหล่งเงินต้นทุนต่ำสำหรับซื้อเครื่อง 1–2 คันแล้วรับจ้างในกลุ่ม                 |
| **สวัสดิการภาษี**                   | บันทึกเป็นรายได้ผู้ให้บริการ (62K–138K/ฤดู) — ต้องแจ้งสรรพากรเป็นผู้ประกอบการ |
| **ประกันเครื่องจักร**               | ยังไม่แพร่หลายในไทย — อัตราเบี้ยสูง/ขาดข้อมูลความเสี่ยง → งานวิจัยช่องว่าง    |

**ตัวเลขประกอบ (ด้าน 08)**: ค่าซ่อมฉุกเฉิน $1,500–4,500/ครั้ง, downtime $5,000–15,000/ชม. — สำหรับผู้ให้บริการ ความเสี่ยง "เครื่องเสียกลางฤดู" = เสียทั้งรายได้ + ค่าชดเชยลูกค้า → การประกัน/สัญญาบริการจึงสำคัญกว่าฟาร์มเจ้าของเอง

## 9. สถานะไทย vs ต่างประเทศ

| มิติ                | ไทย                                         | ต่างประเทศ                                        | ช่องว่าง                                            |
| ------------------- | ------------------------------------------- | ------------------------------------------------- | --------------------------------------------------- |
| ระบบรับจ้าง         | มีมานาน (เกี่ยวนวดตระเวน) แต่ไร้มาตรฐานราคา | India/แอฟริกา: แพลตฟอร์ม+agent ระบบราคาโปร่งใส    | ข้อมูลราคารายพื้นที่ (สศก. เริ่ม 296 ตัวอย่าง 2569) |
| ทะเบียนผู้ให้บริการ | eMachine (กรมส่งเสริมการเกษตร)              | CHC (อินเดีย) มาตรฐานกลางของรัฐ                   | การบังคับใช้/ความน่าเชื่อถือ                        |
| MaaS                | โดรนพ่นรับจ้าง (ใช้งานจริง)                 | AaaS Deere เชิงพาณิชย์ (US/CA)                    | รถไถ/เกี่ยวนวด "เป็นบริการ" ยังไม่เกิด              |
| คุณภาพงาน           | ขึ้นกับผู้ประกอบการรายบุคคล                 | มาตรฐาน + การรับรอง operator (Hello Tractor cert) | การรับรองผู้ปฏิบัติงานไทย                           |
| การเงิน             | ธกส. สินเชื่อเฉพาะกรณี (ตัดอ้อย)            | PAYG, outcome-based pricing                       | การทดลอง PAYG/ประกันเครื่อง                         |

## 10. แนวทางนำไปใช้

### 10.1 Blueprint 3 ระดับ

| ระดับ                  | 1–2 ปี                                                               | 2–4 ปี                                                            | 4+ ปี                                                       |
| ---------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| **เกษตรกรรายย่อย**     | จองบริการผ่าน ASP/eMachine; เก็บใบเสร็จทุกครั้ง (สร้างประวัติ)       | ใช้บริการที่มี "การันตีราคา/คุณภาพ" จากฐานข้อมูล สศก.             | เข้าถึงชุดบริการอัจฉริยะ (โดรน+GPS+ปุ๋ย) แบบแพ็กเกจต่อไร่   |
| **ผู้ให้บริการ (ASP)** | ขึ้นทะเบียน + ตั้งราคาจากข้อมูล สศก.; ทำบัญชีรายได้/ค่าใช้จ่ายต่อไร่ | ติด telematics (ด้าน 08) รายงานงานดิจิทัล + ประกันความเสียหาย     | ให้บริการ "ผลลัพธ์ต่อไร่" (ผลผลิต/คุณภาพ) แทน "รายชั่วโมง"  |
| **รัฐ/วิสาหกิจ**       | เก็บข้อมูลราคา 296 จุดให้ครบ + เผยแพร่รายเดือน                       | กำหนดมาตรฐานบริการขั้นต่ำ (ความลึกไถ/การสูญเสียเกี่ยว) + ใบอนุญาต | ระบบการันตีผล (outcome guarantee) + สินเชื่อ PAYG ผ่าน ธกส. |

### 10.2 เกณฑ์การตัดสินใจ "ซื้อ vs จ้าง"

1. ชั่วโมงใช้งานต่อปี < 150 ชม. → **จ้าง** (ไม่คุ้มซื้อ)
2. ค่าจ้าง/ไร่ < 10% ของกำไรต่อไร่ → จ้าง
3. ต้องใช้พร้อมกันทั้งอำเภอ (เกี่ยว) → **ซื้อเพื่อรับจ้าง** (เป็นธุรกิจ ไม่ใช่เพื่อแปลงตัวเอง)
4. เครื่องอัจฉริยะ/แพง (autonomy, เทเลเมติกส์) → เริ่มจากบริการก่อนเสมอ
5. รวมกลุ่มซื้อ: วิสาหกิจ 5–10 ราย ซื้อ 1–2 คัน + แผนรับจ้างสมาชิกก่อน — ได้ราคา/ประหยัดกว่าเอกชน 50–200 บาท/ไร่

## 11. ความท้าทาย

| ความท้าทาย                   | รายละเอียด                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| **ราคาไม่มีมาตรฐาน**         | 550 บาท/ไร่ ± ตามพื้นที่/ฤดู — ข้อมูล สศก. เพิ่งเริ่มเก็บ (296 จุด)                 |
| **เงินไหลออกจากถิ่น**        | ผู้รับจ้างต่างถิ่นเก็บรายได้ออกจากหมู่บ้าน (สุรินทร์ 1.1 ล้านบาท/หมู่บ้าน/ฤดู)      |
| **คุณภาพไม่มีการันตี**       | "เกี่ยวนวดไม่สะอาด/ไถไม่ลึก" ไม่มีมาตรการชดเชย                                      |
| **หนี้ของ "เจ้าของเครื่อง"** | การกู้ซื้อเครื่องโดยไม่มีแผนรับจ้าง = หนี้ท่วม (ตรงข้าม ASP ที่รายงานกำไร 62K–138K) |
| **โครงสร้างพื้นฐานดิจิทัล**  | แอปจองต้อง offline-first (ทุ่งนาสัญญาณไม่ดี) — ไทยยังไม่มีแพลตฟอร์มกลาง             |
| **ผลตอบแทนของข้อมูล**        | ระบบทะเบียน eMachine ยังเป็น "ทะเบียน" ไม่ใช่ "ตลาด" — ต้องมีกลไกจ่ายเงิน/Trust     |

## 12. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **ฐานข้อมูลราคา สศก. (296 จุด, 2569)** — ตัวตั้งต้น "ราคาอ้างอิงรายพื้นที่" → ต่อยอดมาตรฐานราคา/สัญญาบริการ (ติดตามผลรอบเก็บข้อมูลปีแรก)
2. **eMachine → "ตลาด"**: จากทะเบียนสู่การจอง/ชำระเงิน/รีวิว (ตามแบบ TractoGo/Hello Tractor) — นโยบาย 13th Plan หนุน
3. **โดรน = เครื่องมือสร้าง ASP ใหม่**: ผู้ประกอบการโดรนพ่น/หว่าน/สำรวจ ราคา 100–250 บาท/ไร่ กำลังกลายเป็น "ผู้ให้บริการอัจฉริยะรายแรก" ของชนบทไทย
4. **PAYG สำหรับเครื่องไทย**: สินเชื่อ ธกส. ผูกกับการใช้งานจริง (จ่ายตามชั่วโมง) — ลดภาระค่างวดเมื่อว่างงานกลางปี
5. **มาตรฐานผู้ปฏิบัติงาน**: การรับรอง operator (แบบ Hello Tractor cert กับ TVET) — โจทย์ร่วม กรมส่งเสริมการเกษตร + สถาบันอาชีวะ
6. **Telematics = ตัวพิสูจน์งาน**: ผู้ให้บริการติด GNSS/เซนเซอร์ (ด้าน 08) → "ใบเสร็จดิจิทัล" แทนการนับลูกไม้ — สร้างความน่าเชื่อถือกับลูกค้า/ธนาคาร
7. **ประกันเครื่องจักรตามข้อมูล**: เมื่อมีข้อมูลชั่วโมงใช้งาน/ประวัติดีลเลอร์จริง → ประกันรายชั่วโมง (เชื่อม ด้าน 08, 12) — ลดความเสี่ยงของผู้ประกอบการรายใหม่

## 13. อภิธานศัพท์

| คำศัพท์                                 | ความหมาย                                                            |
| --------------------------------------- | ------------------------------------------------------------------- |
| **ASP (Agricultural Service Provider)** | ผู้ให้บริการเครื่องจักร/เทคโนโลยีทางการเกษตร รับจ้างงานในแปลง       |
| **Custom hiring**                       | การจ้างงานเครื่องจักรเป็นรายงาน/รายไร่ (ไม่ใช่เช่าระยะยาว)          |
| **Sharing economy**                     | เศรษฐกิจแบ่งปัน: ใช้เครื่องจักรของกันและกันแทนการเป็นเจ้าของคนเดียว |
| **Machinery-as-a-Service (MaaS)**       | ขาย "ผลงาน/ชั่วโมง" ไม่ใช่ขายเครื่อง (จ่ายตามใช้งาน)                |
| **PAYG (Pay-As-You-Go)**                | จ่ายตามการใช้งานจริง (รายชั่วโมง/ไร่) — ลดภาระค่างวดคงที่           |
| **Outcome-based pricing**               | เก็บค่าบริการเมื่อได้ผลตามเป้า (ประหยัด/ผลผลิตเพิ่ม)                |
| **Booking agent**                       | ผู้ประสานในพื้นที่ที่ช่วยจอง/ให้คำแนะนำ (โมเดล Hello Tractor)       |
| **CHC (Custom Hiring Centre)**          | ศูนย์กลางให้เช่าเครื่องจักรที่รับรองโดยรัฐ (อินเดีย)                |
