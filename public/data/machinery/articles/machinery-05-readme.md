# 05 | เครื่องจักรพลังงานทางเลือก (Alternative Powertrains)

**สถานะ: ✅ เจาะลึกแล้ว — `เจาะลึก-05-เครื่องจักรพลังงานทางเลือก.md` (สิงหาคม 2569)**

## ขอบเขต

รถแทรกเตอร์/เครื่องจักรไฟฟ้า (BEV) ไฮบริด ไบโอมีเทน/CNG ไฮโดรเจน การชาร์จด้วยพลังงานแสงอาทิตย์ และเศรษฐศาสตร์การเปลี่ยนผ่านพลังงานของเครื่องจักรเกษตร

## หัวข้อที่จะเจาะลึก

- Agritechnica 2025: ไฮบริด = เทรนด์หลัก, ไฮโดรเจนถอย, เต็มไฟฟ้า niche
- Monarch MK-V: ข้อมูลจำเพาะ (70 HP, PTO 40 HP, 14 ชม./ชาร์จ, 8 ปีแบต) + บทเรียนการล้มละลาย
- New Holland T7.270 methane: ปิดลูปไบโอมีเทนจากมูลสัตว์
- Zoomlion ไฮบริด: combine ไฮบริด "คันแรกของโลก", Lovol BEV (2027–28)
- ชิ้นส่วน: ZF eTERRADRIVE (100 kW), FPT F28 serial-hybrid (+30%), Danfoss 48V
- การชาร์จด้วยโซลาร์: งานวิจัยการทำงานต่อเนื่อง >8 ชม./วัน
- เศรษฐศาสตร์ TCO: diesel vs EV vs hybrid ต่อชั่วโมงทำงาน
- แนวโน้มไทย: โซลาร์บนฟาร์ม, นโยบาย Net Zero 2030/2050, การนำเข้า
