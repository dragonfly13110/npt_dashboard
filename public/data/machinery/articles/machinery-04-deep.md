## 1. หลักการและขอบเขต

ระบบพ่นสารแม่นยำ (Smart/Precision Spraying) คือการพ่นสารเคมี/ปุ๋ยเฉพาะจุดหรือปรับอัตราตามสภาพจริงของแปลงแบบเรียลไทม์ แทนการพ่นเต็มพื้นที่ (broadcast) ที่สิ้นเปลืองและเกิดสารตกค้าง ประกอบด้วย 2 กลไกหลัก:

| กลไก                                | หลักการ                                                                                                                                         | ตัวอย่าง                                    |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| **Spot spraying / See-and-Spray**   | กล้อง + AI จำแนกวัชพืช/สิ่งไม่พึงประสงค์ → เปิดหัวฉีดเฉพาะจุดที่พบ (green-on-brown: วัชพืชบนดินเปล่า; green-on-green: วัชพืชในแปลงที่มีพืชปลูก) | See & Spray, Greeneye, Ecorobotix, Bilberry |
| **Variable Rate Application (VRA)** | ปรับอัตราสารตามแผนที่ (map-based) หรือตามเซนเซอร์ (sensor-based) — ปุ๋ยไนโตรเจนตาม biomass, สารเคมีตามความหนาแน่นศัตรูพืช                       | ExactApply Multi-Rate, SenseApply Live VRA  |

**เหตุผลสำคัญ** (เทียบกับพ่นทั้งแปลง):

- ลดต้นทุนสารเคมี (ส่วนใหญ่ของต้นทุนการผลิตในพืชไร่)
- ลดสารตกค้าง/ผลกระทบสิ่งแวดล้อม
- ลด crop stress จากการถูกสาร (ผลการทดลอง: ฉีดเฉพาะจุดให้ผลผลิตถั่วเหลือง +2 bu/A)
- ลดค่าแรงและเวลากรอกถัง (น้ำยาน้อยลง → กรอกน้อยลง → ทำงานได้พื้นที่ต่อวันมากขึ้น)

## 2. เทคโนโลยี 4 ระดับ

| ระดับ | เทคโนโลยี                                    | ความสามารถ                              | ราคาโดยประมาณ            |
| ----- | -------------------------------------------- | --------------------------------------- | ------------------------ |
| 0     | พ่นเต็มพื้นที่แบบคงที่ (broadcast)           | ไม่มีเซนเซอร์                           | -                        |
| 1     | Section control (ปิดเป็นช่วง)                | ปิดหัวฉีดช่วงเลี้ยว/พื้นที่ว่าง (GPS)   | +$5K–15K                 |
| 2     | Nozzle-by-nozzle / Individual Nozzle Control | เปิด-ปิดหัวฉีดรายหัว (±5–10 ซม.)        | +$15K–40K                |
| 3     | **See-and-Spray / AI spot spraying**         | กล้อง+AI ตรวจจับวัชพืชรายจุด ปรับอัตรา  | $100K–250K (ติดตั้ง)     |
| 4     | **Live VRA + selective รวมกัน**              | กล้องหน้าคันเดียว ปรับอัตรา/จุดพร้อมกัน | อยู่ในรถใหม่ factory-fit |

**จุดเปลี่ยนสำคัญ**: ระดับ 3–4 เป็น "sense-and-act" — เครื่องจักร "เห็น" และ "ตัดสินใจ" เองแบบเรียลไทม์ ไม่ใช่แค่ GPS ปิดหัวฉีด — นี่คือจุดที่ AI เข้ามาในงานพ่นสารเต็มรูปแบบ

## 3. John Deere See & Spray

### 3.1 วิวัฒนาการ

| รุ่น                  | ปี            | รายละเอียด                                                                                                                                |
| --------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| See & Spray Select    | 2019–2022     | green-on-brown เฉพาะแปลงว่าง (fallow); แพลตฟอร์ม Blue River Technology                                                                    |
| See & Spray Ultimate  | 2022          | + green-on-green ในข้าวโพด/ถั่วเหลือง/ฝ้าย                                                                                                |
| **See & Spray Gen 2** | 2026 (MY2027) | เกือบ 2 เท่าของชนิดพืช: + ข้าวสาลี ข้าวบาร์เลย์ คาโนลา (เฉพาะ broadleaf), ถั่วลิสง, หัวบีทน้ำตาล; เพิ่มโหมด **variable-rate ตาม biomass** |

### 3.2 ตัวเลขหลัก (2025 season)

- ใช้จริงบน **5+ ล้านเอเคอร์** (ใหญ่กว่ารัฐนิวเจอร์ซีย์) ปี 2025
- ลดการใช้สารกำจัดวัชพืช non-residual **เฉลี่ย ~50%** — ประหยัดสารผสม **~31 ล้านแกลลอน**
- ผลงานวิจัย 3rd party 7 รัฐ (Beck's Hybrids 2024): ผลผลิตถั่วเหลือง **+2 bu/A (131 กก./เฮกตาร์)** เมื่อเทียบกับพ่นแบบ broadcast — จากลด crop injury และสุขภาพพืชที่ดีขึ้น
- ความแม่นยำตรวจจับ >96%, ประมวลผล ~2500 ตร.ฟุต/วินาที ที่ 15 mph (ข้อมูลผู้ผลิต)

### 3.3 ฮาร์ดแวร์/การติดตั้ง

- **See & Spray Gen 2 มาตรฐานจากโรงงาน** ในรถพ่น 400R/600R Series MY2027 ขึ้นไป (408R, 410R, 412R, 612R, 616R) — ลดราคาได้ถ้าไม่เอา (factory deduct)
- **See & Spray Premium** = Precision Upgrade ติดตั้งหลังขายบนรถ R Series และ 400/600 Series MY18–MY26 และ Hagie จากโรงงาน
- โหมด fallow (แปลงว่าง) **ไม่คิดค่าใช้จ่ายเพิ่ม** — เปิดกล้องได้เสมอ
- ตัวเลือก: ถังสารเดี่ยว/คู่ (dual-tank: พ่น pre-emergent full broadcast + spot ได้พร้อมกัน), ไฟส่องแถวพ่นกลางคืน

### 3.4 โหมด Gen 2 (MY2027)

- **โหมด variable rate**: ผู้ใช้ตั้งค่า threshold biomass เช่น 40% (ต่ำ) – 90% (สูง) → พ่นอัตราต่ำ-สูงระหว่างเกณฑ์ (เช่น 10–20 แกลลอน/เอเคอร์) — มาพร้อม hardware ชุดใหม่
- ทำงานกลางคืนได้ (ไฟ LED ส่องแถว)
- เก็บข้อมูลแมปวัชพืช → วางแผนฤดูกาลถัดไป

## 6. ผลลัพธ์เชิงประจักษ์จากงานวิจัย

### 6.1 การลดสารเคมี (เปรียบเทียบ)

| แหล่ง                               | ผลการลดสาร                  | หมายเหตุ                                                |
| ----------------------------------- | --------------------------- | ------------------------------------------------------- |
| Deere See & Spray 2025 (5M เอเคอร์) | เฉลี่ย ~50% (non-residual)  | ประหยัด 31M แกลลอน                                      |
| Deere 2024 (1M เอเคอร์)             | เฉลี่ย 59%                  |                                                         |
| Iowa State (งานวิจัยอิสระ)          | **43.9–90.6% (เฉลี่ย 76%)** | ขึ้นกับความหนาแน่นวัชพืช                                |
| Greeneye (อ้างอิงผู้ผลิต)           | เฉลี่ย 87%                  | UNL ยืนยันประสิทธิภาพควบคุมเทียบเท่า                    |
| CNH SenseApply                      | สูงสุด ~60–65%              | คืนทุน 1–2 ปี                                           |
| Ecorobotix ARA                      | 50–95%+                     | ละเอียด 6×6 ซม.                                         |
| XAG + IRRI (ข้าว, ฟิลิปปินส์ 2025)  | **~30%**                    | เปรียบเทียบกับ ground-boom แบบเดิม — ข้อมูลเอเชียโดยตรง |

### 6.2 ประโยชน์รองที่งานวิจัยพบ

- ลด crop injury (อาการสารทำลายพืช) → ผลผลิตเพิ่ม (+2 bu/A ถั่วเหลือง)
- ลดค่าแรงกรอกน้ำยา + เพิ่มพื้นที่ต่อวัน (กรอกน้อย = ทำงานเยอะ)
- แผนที่วัชพืชที่เก็บได้ → ปรับกลยุทธ์กำจัดวัชพืชระยะยาว (เชื่อม AI เกษตร ด้าน 05)
- ลดการบดอัดดิน (วิ่งซ้ำน้อยลง) ในกรณีพ่นตรงจุด

### 6.3 ข้อควรระวัง

- ตัวเลข "ลด 50–90%" เป็น **non-residual herbicide** เท่านั้น — สาร residual (ออกฤทธิ์ค้างในดิน) ยังต้องพ่นเต็มพื้นที่
- ประสิทธิภาพขึ้นกับความหนาแน่นวัชพืช: แปลงที่วัชพืชน้อย ลดได้น้อย แปลงที่วัชพืชหนาแน่นสม่ำเสมอ แทบไม่คุ้ม (จะพ่นทั้งแปลงอยู่ดี)
- งานวิจัยอิสระในแปลง "จริง" (หลากหลายสภาพ) มีน้อยกว่างานของผู้ผลิต — โดยเฉพาะในภูมิอากาศเขตร้อน

| เงื่อนไข          | คิดค่าใช้จ่ายเฉพาะเมื่อเปิดระบบและเครื่องพ่นไม่ฉีดสารลงพื้นที่นั้นจริง                                                         |
| ความหมาย          | Deere แบกรับความเสี่ยงผลลัพธ์เอง — ลูกค้าจ่ายตามคุณค่าที่ได้รับจริง                                                            |

| ผลต่ออุตสาหกรรม   | คู่แข่งตอบโต้ด้วย "no per-acre fee" (CNH) — เทรนด์ราคาย้ายจาก "ขายฮาร์ดแวร์แพง" เป็น "ขายผลลัพธ์/ค่าบริการ"                    |

**บทเรียนสำหรับไทย**: โมเดล "จ่ายเมื่อได้ผล" นี้แปลเป็นบริการรับจ้างพ่นได้ — ผู้ให้บริการคิดเงินตาม "พื้นที่ที่พ่นจริง" (ที่ไม่มีวัชพืช) ทำให้เกษตรกรเห็นคุณค่าทันทีและลดความเสี่ยงการตัดสินใจ

## 9. สถานการณ์ประเทศไทยและอาเซียน

### 9.1 จุดแข็งไทย

- **ไทย = ฮับเครื่องพ่นสาร/โดรนของ SEA**: DJI เปิดเผยว่าไทยคิดเป็น ~50% ของรายได้ SEA; นักบินโดรนรับรอง 19,000+; ร้านค้า 300+ แห่ง 70+ จังหวัด
- เครือข่ายดีลเลอร์หนาแน่น (คูโบต้า/ยันมาร์/เจียไต๋) + Yanmar เปิด **YANMAR Solution Experience Center** (บางน้ำเปรี้ยว ฉะเชิงเทรา, พ.ค. 2569) เพื่อถ่ายทอดเทคโนโลยีพ่นแม่นยำ
- โครงการ Smart Farmer (2568): ส่งเสริม GPS-guided sprayer + โดรน
- งาน AGRITECHNICA Asia (BITEC) เป็นเวทีเปิดตัวสินค้าใหม่ของภูมิภาค

### 9.2 ช่องว่างในไทย

| ช่องว่าง                           | คำอธิบาย                                                                |
| ---------------------------------- | ----------------------------------------------------------------------- |
| รถพ่นบูม AI-class ยังแทบไม่มีในไทย | ราคาสูง + แปลงเล็ก (65.4% <20 ไร่) — ตลาดระดับ 3–4 ยังเป็นศูนย์         |
| การพ่นแม่นยำหลักในไทย = โดรน       | โดรน+เรดาร์+RTK ให้ผลใกล้เคียง spot spraying สำหรับแปลงเล็ก (ดูด้าน 03) |
| VRT ปุ๋ยยังจำกัดกลุ่มแปลงใหญ่      | กลุ่มอ้อย/มัน/ข้าวโพดรายใหญ่เริ่มใช้ (John Deere/Trimble นำเข้า)        |
| งานวิจัย/ข้อมูลผลตอบแทนน้อย        | ควรทดลองนำร่อง + เผยแพร่ผลเป็นภาษาไทย                                   |

### 9.3 ทางเลือกที่เหมาะบริบทไทย (เรียงตามต้นทุน)

1. **โดรนพ่นตามแผนที่ VRT** (มีใน T100/ระบบ XAG) — เริ่มต้น ~1.9–3.4 แสนบาท — เหมาะแปลงเล็ก-กลาง
2. **รถพ่นบูม + Individual Nozzle Control** (ExactApply-class) — แปลง >1,000 ไร่
3. **รถพ่นพร้อม See & Spray-class** — รอ OEM จีน/ญี่ปุ่นทำราคาเข้าถึง หรือใช้บริการรับจ้างข้ามประเทศ
4. **โปรแกรม "พ่นเฉพาะจุดด้วยมือ"** (ตามแผนที่จากโดรนสำรวจ) — ต้นทุนศูนย์ เหมาะแปลงเล็ก

## 10. แนวทางนำไปใช้

### 10.1 Blueprint สำหรับฟาร์มไทย

| ขั้น                             | การลงทุน                                      | ระยะเวลา  | ผลที่คาด                                    |
| -------------------------------- | --------------------------------------------- | --------- | ------------------------------------------- |
| 1. รู้ก่อนพ่น: สำรวจแปลงด้วยโดรน | รับจ้าง ~200–500 บาท/ครั้ง                    | 1 ฤดู     | แผนที่วัชพืช/ศัตรูพืช — รู้ว่าพ่นจุดไหนจริง |
| 2. พ่นตามแผนที่ (VRT แบบง่าย)    | โดรน + ซอฟต์แวร์วางแผน (ถ้ามีอยู่แล้ว)        | 1–2 ฤดู   | ลดสาร 20–30% (เทียบเคียงผล XAG-IRRI)        |
| 3. พ่นเฉพาะจุดอัตโนมัติ          | รถพ่นระบบ AI (บริการรับจ้าง/รถใหม่)           | 3+ ปี     | ลดสาร 50%+ เริ่มเห็นผลกับแปลงใหญ่           |
| 4. ปรับกลยุทธ์ทั้งระบบ           | ข้อมูลแผนที่หลายฤดู → เปลี่ยนระบบจัดการวัชพืช | ต่อเนื่อง | ลดการใช้สารถาวร 30–50%                      |

### 10.2 เกณฑ์ตัดสินใจลงทุน

- **ใช้ See-and-Spray-class ต้องมีเงื่อนไข**: แปลง >1,000 ไร่ (พ่นเอง) หรือแปลงที่มีวัชพืชกระจายไม่สม่ำเสมอ (จุดต่าง 2x ขึ้นไป), และมีประวัติค่าใช้จ่ายสารเคมีสูง
- **สำหรับแปลงเล็ก**: จ้างโดรน/บริการพ่นแม่นยำ ดีกว่าซื้อระบบ — คำนวณเป็นต้นทุนต่อไร่
- **ให้ความสำคัญ "crop safety"**: การลดสารตรงจุดลด crop injury → กำไรระยะยาวอาจมาจากผลผลิตที่เพิ่ม ไม่ใช่แค่สารที่ประหยัด

| **ฝุ่น/แสง/ความชื้นเขตร้อน**       | ภาพจากกล้องในฝุ่นนา หมอก/แดดจ้า/ใบเปียก — ประสิทธิภาพ AI ลดลง ต้องทดสอบในสภาพไทย                           |
| **ข้อมูลจำกัดในเอเชีย**            | งานวิจัยอิสระส่วนใหญ่จากสหรัฐฯ/ยุโรป (อุณหภูมิ/พืช/วิธีปฏิบัติต่าง) — ต้องมีชุดข้อมูลไทย                   |
| **ความเป็นเจ้าของข้อมูล**          | ระบบเก็บภาพ/แมปแปลง — ข้อตกลงสิทธิ์ข้อมูลต้องชัดเจน (เกษตรกร vs บริษัท)                                    |
| **มาตรฐาน/การรับรอง**              | ยังไม่มีมาตรฐานไทยสำหรับ "AI ตรวจวัดการพ่น" — การเคลมคุณภาพพึ่งผู้ผลิต                                     |
| **การพ่นสารในไทยมีกฎหมายเฉพาะ**    | ประกาศ กษ. ว่าด้วยการพ่นสาร ต้องมีนักพ่น/เครื่องพ่นที่ขึ้นทะเบียน — ระบบ AI ยังไม่เข้าในระบบการขึ้นทะเบียน |

## 12. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **AI ระดับรายต้น/รายใบ**: Ecorobotix 6×6 ซม. → รายใบ (plant-by-plant) — งานผัก/แปลงมูลค่าสูง
2. **กล้องเดียว + ไม่มีค่าธรรมเนียม (CNH ทางเลือก)**: ทำลายโมเดล "ต่อเอเคอร์" — ราคาเข้าถึงของ OEM ตกต่ำลง
3. **Dual-tank กลายมาตรฐาน**: พ่น residual ทั้งแปลง + non-residual เฉพาะจุดพร้อมกัน (Greeneye/Deere/CNH) — เพิ่มกรณีใช้งาน
4. **VRT "ตามผลผลิต/ตามสภาพอากาศ"**: ใช้ข้อมูลหลายปี + สภาพอากาศพยากรณ์ มาปรับอัตรา (ไนโตรเจน)
5. **โดรนกับ See & Spray รวมกัน**: โดรนสำรวจสร้างแมป → รถพ่น/โดรนพ่นตามแมป — ระบบ "เห็นก่อนพ่น" แบบไทย ๆ ราคาถูก
6. **บริการ "พ่นแม่นยำเป็นบริการ"**: โมเดลผลลัพธ์ (จ่ายเมื่อประหยัด) ขยายสู่บริการรับจ้างในเอเชีย
7. **มาตรฐานการวัดผล**: การวัด "reduction" ให้ตรงกัน (ต่อเอเคอร์/ต่อจุด) — กำลังเป็นประเด็นอ้างอิงระหว่างผู้ผลิต

## 13. อภิธานศัพท์

| คำศัพท์                             | ความหมาย                                                  |
| ----------------------------------- | --------------------------------------------------------- |
| **Broadcast application**           | พ่นเต็มพื้นที่ทั้งแปลง (วิธีเดิม)                         |
| **Spot spraying / See-and-Spray**   | พ่นเฉพาะจุดที่ตรวจพบวัชพืช/เป้าหมาย                       |
| **Green-on-Brown**                  | ตรวจจับ "สีเขียว" (วัชพืช) บนพื้น "สีน้ำตาล" (ดินเปล่า)   |
| **Green-on-Green**                  | ตรวจจับวัชพืชในแปลงที่มีพืชสีเขียว (ยากกว่า)              |
| **VRA (Variable Rate Application)** | การปรับอัตราใส่ตามตำแหน่ง (แผนที่/เซนเซอร์)               |
| **Individual Nozzle Control**       | การเปิด-ปิด/ปรับอัตราหัวฉีดรายหัวอิสระ                    |
| **Residual herbicide**              | สารออกฤทธิ์ค้างดิน — ต้องพ่นทั้งแปลง กันวัชพืชงอก         |
| **Non-residual herbicide**          | สารที่ฆ่าวัชพืชเฉพาะจุดที่โดน (เป้าหมายของ See & Spray)   |
| **Base + Boost**                    | พ่นอัตราพื้นฐานทั่วแปลง + เพิ่มอัตราตรงจุดวัชพืชหนาแน่น   |
| **Application Savings Guarantee**   | โมเดล "จ่ายเมื่อประหยัด" — คิดเงินตามพื้นที่ที่ไม่ต้องพ่น |
| **Biomass threshold**               | เกณฑ์ความหนาแน่นของพุ่มวัชพืชที่ใช้ตั้งอัตรา VRA          |
