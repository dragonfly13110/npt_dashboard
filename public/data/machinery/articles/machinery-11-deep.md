## 1. หลักการและขอบเขต

ปศุสัตว์เป็นงานที่ "ตอบสนองต่อข้อมูลรายตัว" ต่างจากพืชที่จัดการรายแปลง: วัวแต่ละตัวกิน/เป็นสัด/ป่วยต่างกัน → เซนเซอร์+AI ตรวจจับได้ก่อนคนเห็น ด้านนี้ครอบคลุม: หุ่นยนต์รีดนม (AMS), ให้อาหารอัตโนมัติ (TMR), ปลอกคอ IoT/กล้อง AI ตรวจสุขภาพและสัด, คอกอัจฉริยะ, ฟาร์มสุกร/ไก่แบบไทย และการจัดการมูลสัตว์/พลังงาน

## 3. หุ่นยนต์รีดนมอัตโนมัติ (AMS)

### 3.1 สถาปัตยกรรม

| องค์ประกอบ                     | หน้าที่                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| หุ่นยนต์จับหัวนม (teat cup)    | ติดถ้วยรีดอัตโนมัติ — ใช้วิชั่น+เซนเซอร์หาตำแหน่งหัวนม                        |
| ระบบนับ/ตรวจน้ำนมรายตัว        | ปริมาณ, อัตราไหล, เซลล์ร่างกาย (SCC) — ตรวจเต้านมอักเสบ (mastitis) ตั้งแต่ต้น |
| เซนเซอร์ตรวจเต้านม             | จับสัญญาณเต้านมอักเสบก่อนคลินิกปรากฏ                                          |
| ซอฟต์แวร์ฝูง (herd management) | วางแผนรีด/ผสม/สุขภาพ รายตัว                                                   |
| การซักล้างอัตโนมัติ            | วงจรทำความสะอาดหลังรีดทุกครั้ง                                                |

### 3.2 ผลลัพธ์

- **ลดแรงงานรีดนมได้ถึง 70%** (ตัวอย่างผู้ใช้ M&M)
- คุณภาพน้ำนมสม่ำเสมอ + ตรวจสุขภาพเต้านม real-time → รองรับพรีเมียมราคา/ตรวจสอบย้อนกลับ
- ผู้เล่นหลัก: Lely (Astronaut), DeLaval (VMS), GEA (DairyProQ), BouMatic, Fullwood Packo, Dairymaster
- จุดคุ้ม: ยุโรป/อเมริกาเหนือฟาร์มโคนมขนาดกลาง-ใหญ่; เอเชีย-แปซิฟิกเป็นตลาดที่โตเร็วสุด (ฟาร์มสมัยใหม่+ดีมานด์นม)

### 3.3 ข้อควรรู้สำหรับไทย

- โคนมไทย ~765,000 ตัว (กรมปศุสัตว์ 2565) — ฟาร์ม 70–80% เป็นรายเล็ก → AMS แบบเต็มรูปแบบยังแพงเกินสำหรับรายเล็ก; เริ่มที่ "เซนเซอร์ปลอกคอ + รีดแบบเดิม" ก่อน (ดูหัวข้อ 5/9)

## 4. ระบบให้อาหารอัตโนมัติ (TMR/Feeding)

| ระบบ                                   | รายละเอียด                                                                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **DeLaval OptiMat** (มี.ค. 2566)       | หุ่นยนต์ให้อาหารอัตโนมัติโมดูลาร์: สถานีผสม + รถกระจาย + ควบคุมกลาง — ผสม/กระจาย/จัดการสต็อกอาหารอัตโนมัติ                                                   |
| **Dinamica Generale DTM**              | แพลตฟอร์ม TMR + เซนเซอร์ NIR วิเคราะห์องค์ประกอบอาหาร (ความชื้น/โปรตีน/ไฟเบอร์) แบบ real-time ก่อน-หลังผสม → **ลดต้นทุนอาหาร 10–20%** (ตรงข้อมูลภาพรวม [24]) |
| **PLT AI feed prediction** (ม.ค. 2567) | AI ทำนายความต้องการกิน/วัน ของโคเนื้อรายตัว (ข้อมูล bunk management + สภาพอากาศ + สูตรอาหาร) — ปรับสูตรแม่นยำ                                                |
| **CLAAS TORION Autonomy Connect**      | รถตักหญ้าหมักไร้คนขับในฟาร์ม (LiDAR + digital twin — ไม่ต้องพึ่ง GPS) ลดงานคนในห่วงโซ่ให้อาหาร                                                               |

**เหตุผลที่อาหารเป็นจุดสนใจ**: อาหาร = 60–70% ของต้นทุนปศุสัตว์ — การลด 10–20% ของส่วนนี้ส่งผลกำไรโดยตรงมากที่สุดในระบบ

## 5. การติดตามสัตว์รายตัว: ปลอกคอ IoT + AI

| เทคโนโลยี                                                          | ข้อมูลที่จับ                                | การใช้งาน                                                    |
| ------------------------------------------------------------------ | ------------------------------------------- | ------------------------------------------------------------ |
| **ปลอกคอ accelerometer** (SCR/Allflex/Afimilk, ไทย: True Farm Cow) | เคี้ยวเอื้อง/กิน/เคลื่อนไหว เป็นนาที/24 ชม. | เตือนสัด (หมั่นไส้), สุขภาพผิดปกติ, heat stress, วันคลอดใกล้ |
| **กล้อง AI / 3D camera**                                           | น้ำหนัก, gait (การเดิน), พฤติกรรม           | ชั่งน้ำหนักไม่ต้องจับโค; ตรวจจับขาพิการ/เจ็บ                 |
| **Ear tag RFID/อุณหภูมิ**                                          | ระบุตัว + อุณหภูมิ                          | ประวัติรายตัว, โรคไข้                                        |
| **Sound talk (สุกร)**                                              | เสียงไอ/หายใจในโรงเรือน                     | เตือนโรคระบบทางเดินหายใจล่วงหน้า (CPF ใช้)                   |
| **NIR อัตโนมัติ**                                                  | องค์ประกอบนม/อาหาร                          | คุณภาพน้ำนม/สูตรอาหาร                                        |

**ผลลัพธ์ที่พิสูจน์ (ต่างประเทศ)**: การตรวจจับสัดแบบอัตโนมัติเพิ่มอัตราการผสมติด (ลดวันท้องว่าง) — ลดค่า "กินเปล่า" ของแม่โคหลายพันบาท/ตัว/ปี; การเตือนป่วยก่อนมีอาการ = รักษาทัน ลดโคตาย/ค่าเสียโอกาส

## 6. ฟาร์มสุกรอัจฉริยะ (กรณี CPF)

**CPF Smart Farm (ธุรกิจสุกร, แถลง 2566–68)** — ต้นแบบ "ฟาร์มอัจฉริยะ" ไทยรายใหญ่สุด:

- **Automation + CCTV** (ร่วม TRUE): ฟาร์มคอนแทรก 100% ติด CCTV — ควบคุม/ดูฟาร์มระยะไกลผ่านสมาร์ทโฟน
- **Auto Feeding Systems**: ให้อาหารอัตโนมัติ ลดคนเข้าคอก → ความปลอดภัยทางชีวภาพ (biosecurity)
- **Sound Talk (IoT)**: ฟังเสียงไอในโรงเรือน → เตือนโรคระบบหายใจทันที
- **SMART PIG**: เก็บ+วิเคราะห์ประสิทธิภาพทุกช่วงวัย (สุขภาพ/การเติบโต) บนคลาวด์ + QR ติดตาม
- **ChatBot รายงาน**: เกษตรกรบันทึกจำนวน/อาหาร/วัคซีนผ่านมือถือ — ส่งภาพสุกรให้สัตวแพทย์วิเคราะห์ระยะไกล
- **ปลายน้ำ**: กล้อง AI วิเคราะห์อัตราส่วนเนื้อแดง:ไขมันในชิ้นเนื้อ + traceability ย้อนถึงฟาร์ม (Happy Pig)
- **ขยายสู่คอนแทรกฟาร์ม**: ถ่ายทอดเทคโนโลยีเดียวกับบริษัท (โมเดลเดียวกับ ASP ในด้าน 12 — "บริษัทถือเทคโนโลยี ฟาร์มถือแรงงาน/พื้นที่")

**กรณีฟาร์มดีพัฒนา 1 (อุบลฯ/อำนาจเจริญ)**: ฟาร์มปิด EVAP 3,500 ตัว — ระบบไบโอแก๊ส+ปั่นไฟใช้เอง + แยกกาก → "ปันน้ำปุ๋ย" ให้เกษตรกรรอบข้าง (เชื่อมด้าน 05: วงจรพลังงาน)

## 7. สัตว์ปีกและอื่น ๆ

- **Poultry monitoring + robotics = segment โตเร็วสุด (CAGR 10.7%)**: กล้อง AI นับไก่/ตรวจสุขภาพ/พฤติกรรมทั้งโรงเรือน (ฝูงละหมื่น+ ตรวจรายตัวไม่ได้ — AI ตรวจรายโรงเรือนแทน), หุ่นยนต์เดินเก็บไข่
- **ระบายอากาศ/ระบบทำความเย็นอัตโนมัติ**: เซนเซอร์อุณหภูมิ/ความชื้น/แก๊ส (NH₃) → ควบคุมพัดลม/EVAP/น้ำดื่ม (heat stress ลดอัตรารอด/ผลผลิตไข่)
- **ปลา/กุ้ง (aquaculture)**: เซนเซอร์คุณภาพน้ำ + กล้องใต้น้ำ + ระบบให้อาหารอัตโนมัติตามความอยากกิน (งานวิจัยไทยโตเร็ว — ต่อยอดในคลัง AI เกษตร)

## 8. การจัดการมูลสัตว์และพลังงาน

| ระบบ                     | รายละเอียด                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| เก็บกวาด/แยกมูลอัตโนมัติ | รถตัก/สกรู/ลานลาดอัตโนมัติ — ลดแรงงาน + สุขอนามัยคอก                                                                      |
| **ไบโอแก๊สจากมูล**       | หมักไร้ออกซิเจน → มีเทน → ไฟฟ้า/แก๊ส (CPF ใช้ในฟาร์มต้นแบบ) — วงจรปิดพลังงาน (ด้าน 05: New Holland T7.270 ใช้มีเทนจากมูล) |

## 9. สถานการณ์ไทย

### 9.1 โคนมไทย (True Farm Cow + Senovate AI)

- **True Farm Cow** (True Digital + MSD Animal Health, เทคโนโลยีอิสราเอล 30 ปี): ปลอกคอวัดเคี้ยวเอื้อง/กิน/เคลื่อนไหว 24 ชม. → AI แจ้งเตือนสัด/ป่วย/heat stress + รายงานฝูง (ผสมติด/วันท้องว่าง/หลอดน้ำเชื้อ) — กรณี มานะกุลฟาร์ม (รุ่นที่ 3) ใช้จริง ลดภาระแรงงาน เพิ่มคุณภาพน้ำนมเทียบตะวันตก
- **Senovate AI** (สตาร์ทอัพจุฬาฯ): อัลกอริทึม activity meter สำหรับโคนมไทย — ราคาต่ำ (เหมาะฟาร์มเล็ก 70–80%), ใช้แอป/เว็บ ไม่ต้องลงโครงสร้างพื้นฐาน; เป้า 10,000 ตัว/รายได้ 80 ล้านบาท (ปี 2568), เป้าหมายผู้นำเทคโนโลยีโคนม SEA 2570
- **บริบท**: ฟาร์มโคนมไทยลดลง >20% ใน 5 ปี (ต้นทุนสูง/กำไรต่ำ) + FTA 2568 เปิดแข่งขัน — เทคโนโลยี "เพิ่มผลผลิตต่อตัว" เป็นทางรอด

### 9.2 สุกร (CPF + คอนแทรกฟาร์ม)

- ฟาร์มคอนแทรก CPF: CCTV 100% + Auto feeding + Sound Talk + SMART PIG — ต้นแบบอัตโนมัติของไทย
- ฟาร์มอิสระ/รายย่อย: เริ่มใช้ระบบอัตโนมัติบางส่วน (ให้อาหาร/ระบายอากาศ)

### 9.3 ช่องว่างไทย

- AMS หุ่นยนต์รีดนม: แทบไม่มีใช้ในไทย (ราคา $150–300K/เครื่อง) — รายใหญ่ที่คิดจะลงทุนต้องวิเคราะห์จุดคุ้มกับฟาร์มไทย (ร้อน/ฝูงเล็ก)
- เซนเซอร์ปลอกคอ: เริ่มขยาย (True Farm Cow/Senovate) แต่ครอบคลุมยัง <5% ของโคนมทั้งหมด
- สัตว์ปีก: ฟาร์มไก่คอนแทรก (CP/เบทagro) ใช้ระบบอัตโนมัติสูง แต่ "AI ตรวจสุขภาพรายโรงเรือน" ยังจำกัด

| **โคนมรายเล็ก** (70–80% ของไทย) | ปลอกคอราคาต่ำ (Senovate-class) เริ่มด้วย "เตือนสัด" อย่างเดียว | เพิ่มการเตือนป่วย/heat stress + บันทึกผสมเทียมดิจิทัล        | เชื่อมข้อมูลสู่สหกรณ์/โรงนม — ราคานมตามคุณภาพ (SCC) |
| **โคนมรายกลาง-ใหญ่**            | True Farm Cow/SCR เต็มรูปแบบ + ปรับสูตรอาหารตาม NIR            | ให้อาหารอัตโนมัติ (DTM-class) — เป้าหมายลดต้นทุนอาหาร 10–20% | AMS คัดคอกเดียว/กะทัดรัดเมื่อแรงงานหาย              |
| **สุกรคอนแทรก**                 | Auto feeding + CCTV + Sound Talk (ตามมาตรฐาน CPF)              | SMART PIG ครบวงจร + เชื่อมข้อมูลโรงชำแหละ                    | ระบบ "จ่ายตามสุขภาพฝูง" (outcome-based กับบริษัท)   |
| **ไก่เนื้อ/ไข่**                | ระบายอากาศ/EVAP อัตโนมัติ + กล้องนับไก่                        | AI ตรวจจับซาก/พฤติกรรมผิดปกติรายโรงเรือน                     | หุ่นยนต์เก็บไข่/จับไก่                              |

### 10.2 เกณฑ์การลงทุน (จากตัวเลข)

1. **เริ่มที่ "อาหาร"** — 60–70% ของต้นทุน; NIR/TMR ลด 10–20% = คืนทุนเร็วสุด
2. **เซนเซอร์ปลอกคอ ก่อน AMS** — ราคาหลักพัน/ตัว (ไทย) vs หุ่นยนต์รีดนมหลายล้านบาท
3. **ผูกกับ "รายได้ต่อตัว"** — โคนมไทยผลผลิตเฉลี่ยต่ำ (ราว 11–12 กก./ตัว/วัน) — ทุก กก. ที่เพิ่มมีค่ามากกว่าเครื่องจักรฟาร์มพืชต่อไร่
4. **ใช้โมเดล "บริษัทถือเทคโนโลยี"** (CPF) หรือ "บริการเซนเซอร์" (รายเดือน) แทนซื้อขาด — ลดเงินลงทุนเริ่มต้น

## 11. ความท้าทาย

| ความท้าทาย                     | รายละเอียด                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------- |
| **ราคา AMS สูง**               | $150–300K/เครื่อง — เกินกำลังฟาร์มเล็กไทย; จุดคุ้มที่ฝูง 60–100+ ตัว + ค่าแรงสูง |
| **สภาพอากาศร้อนชื้น**          | heat stress ลดผลผลิตนม/อัตรารอด — อัลกอริทึมจากยุโรปต้องเทรนใหม่กับข้อมูลไทย     |
| **โครงสร้างรายย่อย**           | 70–80% ฟาร์มโคนมรายเล็ก — ระบบราคาถูก (Senovate-class) ยังต้องขยาย               |
| **ข้อมูล/การยอมรับ**           | เกษตรกรไม่คุ้นเคยการตัดสินใจจากข้อมูล — ต้องมี "คนกลาง" (สัตวบาล/สหกรณ์)         |
| **ไฟฟ้า/อินเทอร์เน็ตในฟาร์ม**  | ฟาร์มปศุสัตว์ไทยหลายแห่งนอกโครงข่าย 4G/5G หนาแน่น                                |
| **โรคระบาด/ความปลอดภัยชีวภาพ** | ความเสี่ยง ASF/โรคใหม่ — ระบบอัตโนมัติลดการสัมผัสแต่เพิ่มการพึ่งพาเทคโนโลยี      |

## 12. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **AI in PLF โต CAGR 23–28%** — "การตรวจสุขภาพอัตโนมัติ" เป็น segment ที่เงินไหลเข้าเร็วสุด (TBRC/GII)
2. **AMS ราคาลง + รุ่นฟาร์มเล็ก**: ผู้เล่นหลักแข่งทำโมเดล "รีดนมกึ่งอัตโนมัติ" ราคากลาง — จับตาความเป็นไปได้ในไทย (ฟาร์ม 50–100 ตัว)
3. **Feeding AI + NIR เป็น "มาตรฐานใหม่"**: การวิเคราะห์อาหารแบบ real-time (Dinamica/DeLaval) จะกลายเป็นฟีเจอร์พื้นฐานของระบบ TMR — ไทยรายใหญ่ควรนำร่อง
4. **การจ่ายราคานมตามคุณภาพ (SCC/โปรตีน)**: เซนเซอร์ตรวจเต้านม+คุณภาพนมรายตัว → สหกรณ์โคนมไทยตั้งราคา "จูงใจคุณภาพ" (เชื่อม True Farm Cow data)
5. **พอร์ตไทยสู่ต่างประเทศ**: Senovate AI/สตาร์ทอัพไทย ตั้งเป้า SEA — ตลาดปศุสัตว์ SEA ใหญ่กว่าไทยหลายเท่า
6. **หุ่นยนต์ในสัตว์ปีก**: โรงเรือนไก่ 30,000+ ตัว/หลัง — "AI ตรวจรายโรงเรือน" จะเป็นสินค้าแรกที่ไทย/ผู้ผลิตท้องถิ่นทำเองได้ (ข้อมูลไทย/สายพันธุ์ไทย)
7. **Carbon/ESG**: การจัดการมูล (ไบโอแก๊ส/ปุ๋ย) + ข้อมูลโปร่งใส = รายได้คาร์บอนเครดิต — เชื่อมด้าน 05/08

| **Contract farming**                  | ฟาร์มในเครือบริษัท (CPF) — บริษัทส่งเทคโนโลยี/ตลาด ฟาร์มส่งพื้นที่/แรงงาน |
