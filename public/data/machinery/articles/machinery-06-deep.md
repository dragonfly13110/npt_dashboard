## 1. หลักการและขอบเขต

หุ่นยนต์ภาคสนาม (Field Robot) คือเครื่องจักรทำงานอัตโนมัติขนาดเล็ก-กลาง ไร้ห้องโดยสาร/ไร้คนควบคุมประจำ ที่ทำงานเฉพาะทางในแปลง — กำจัดวัชพืช (เลเซอร์/กล/สารไมโครโดส) หยอดเมล็ด ฉีดพ่น เก็บเกี่ยว หรือเป็น "แคร์ริเออร์" (carrier) โมดูลาร์สำหรับหลายงาน — ขับเคลื่อนด้วยกำลังไฟฟ้า/โซลาร์/ดีเซล-ไฟฟ้าไฮบริด

**ความต่างจากรถแทรกเตอร์อัตโนมัติ** (ด้าน 01): หุ่นยนต์ภาคสนามออกแบบ "เกิดมาเพื่องานเดียว/ไม่กี่งาน" ตั้งแต่ต้น (robot-first) — เบา บดอัดดินน้อย ทำงานซ้ำ ๆ ได้แม่นยำและนาน — ขณะที่รถอัตโนมัติคือ "รถเดิมที่ขับเอง"

**งานที่เหมาะที่สุดวันนี้**: การกำจัดวัชพืช (งานที่ต้องเดินซ้ำ ถี่ ใช้แรงงานมากที่สุด) และงานดูแลผัก/แปลงมูลค่าสูง — สวนผลไม้กำลังเป็นตลาดที่สอง

## 3. Carbon Robotics LaserWeeder: กรณีศึกษาเลเซอร์กำจัดวัชพืช

### 3.1 ข้อมูลผลิตภัณฑ์ (สถานะ 2026)

| รายการ         | รายละเอียด                                                                                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| หลักการ        | รถแทรกเตอร์ลากเครื่องมือ 20 ฟุต, กล้องความละเอียดสูง 42 ตัว + AI deep-learning 100+ โมเดลพืช → ตรวจจับวัชพืชรายต้น → ยิงเลเซอร์ CO2 30 ตัว กำลัง 150W ละความแม่นยำต่ำกว่า 1 มม. |
| ประสิทธิภาพ    | กำจัดได้ถึง **99%** ของวัชพืช, อัตรา 5,000+ ต้น/นาที (200,000 ต้น/ชม.), 0.5–1.5 เอเคอร์/ชม., ทำงานได้ทั้งวันทั้งคืน (ไฟ LED), ทำงานได้เร็ว 6 mph                                |
| ความคุ้มแรงงาน | "เทียบเท่าทีมงาน 75 คน" (อ้างอิงผู้ผลิต); ลดต้นทุนกำจัดวัชพืช **80%** เมื่อเทียบกับโปรแกรมสารเคมี                                                                               |
| รุ่น           | G2 เปิดตัว ก.พ. 2568 (เร็วขึ้น/โมดูลาร์); LPM (Large Plant Model) เทรนบน **150 ล้านต้นที่ติดฉลาก** — ฐาน AI ชื่อ Carbon AI ใช้ร่วมกับ ATK                                       |
| ราคา           | ~US$750K–1.4M (ประมาณการนักวิเคราะห์/สื่อ)                                                                                                                                      |
| การติดตั้งจริง | 250,000+ เอเคอร์, กำจัด 15,000 ล้านต้น, 150+ เครื่อง, 100+ ฟาร์ม, ~14–15 ประเทศ                                                                                                 |

### 3.2 จุดเปลี่ยนสำคัญ (2026)

- **รายได้ทะลุ US$100M** (FY สิ้นสุด 31 ม.ค. 2569) — บริษัทหุ่นยนต์ภาคสนามแรกที่ทำรายได้ 9 หลัก
- ระดมทุนรวม $157M (รอบ Series D) — รายได้โตแบบ organic โดยไม่ต้องกู้รอบใหม่
- สร้าง Carbon AutoTractor Kit (เม.ย. 2568): retrofit เพิ่ม autonomy ให้รถ John Deere 6R/8R — แยก "เครื่องมืออัจฉริยะ" กับ "ตัวเคลื่อนที่" ออกจากกัน (กลยุทธ์ชัด: ขายผลลัพธ์ทีละชั้น)
- **ข้อควรระวัง**: ตัวเลขผู้ผลิต (acreage/จำนวนวัชพืช) เป็นข้อมูลบริษัท ไม่ได้ตรวจสอบอิสระ; ราคา $1.4M จากสื่อ ไม่ใช่ราคาอย่างเป็นทางการ

### 3.3 ทำไมสำเร็จ (บทเรียน)

1. **เปลี่ยนจาก "หุ่นยนต์ขับเคลื่อนเอง" เป็น "เครื่องมือลากตาม"**: ใช้รถแทรกเตอร์ที่มีอยู่ — ลดราคา/การซื้อซ้ำ, ติดตั้งง่าย, คืนทุนไวขึ้น
2. **ข้อมูลเป็นม้วนห่วง (data flywheel)**: กองเรือ 150+ เครื่องใน 15 ประเทศป้อนข้อมูลเทรนโมเดล — ยิ่งใช้ยิ่งแม่น คู่แข่งเริ่มจากศูนย์
3. **จับเทรนด์กฎหมาย**: EU Farm to Fork ลดสารเคมี 50% ภายใน 2030 + ต้นทุนแรงงานสูงขึ้น — ความต้องการถูกสร้างโดยนโยบาย
4. **เจาะตลาดเฉพาะก่อน**: ผัก/แปลงมูลค่าสูง (หอม หัวผักกาด บรอกโคลี ผักกาดหอม ฝ้าย) — ค่าจ้างแรงงานถอนวัชพืชสูงสุด

## 4. FarmDroid FD20: หุ่นยนต์โซลาร์หยอด-กำจัดวัชพืช

| การติดตั้ง   | 500+ เครื่อง, 26 ประเทศ (นับ 2026); ระดมทุน €10.5M (ต.ค. 2567) ขยายสู่ตลาด conventional                                                                                                                                        |
| ตลาดหลัก     | เกษตรอินทรีย์ยุโรป (ชูการ์บีท ผัก)                                                                                                                                                                                             |

### 4.2 จุดเด่นทางเทคนิค

- ไม่ต้องใช้กล้อง/ภาพเพื่อหาแถวหลังงอก — ใช้ "ความจำพิกัดเมล็ด" ลดความซับซ้อน/ค่าใช้จ่าย/ความผิดพลาด
- โซลาร์ = ค่าเชื้อเพลิงศูนย์ ทำงานวันละ 18–24 ชม. ตามแสง — เหมาะแปลงอินทรีย์/พื้นที่ไม่มีไฟ
- การทดลองในอเมริกาเหนือยังเป็นช่วงนำร่อง (ไม่ใช่เชิงพาณิชย์เต็ม)

## 5. Fendt Xaver GT และวิวัฒนาการฝูงหุ่นยนต์

### 5.1 จาก Xaver swarm → Xaver GT (Agritechnica 2025)

| รายการ   | รายละเอียด                                                                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| แนวคิด   | สานต่อ Xaver swarm (ฝูงหุ่นยนต์เล็กไร้คน 6+ ตัว/ผู้ควบคุม 1 คน) สู่ "แคร์ริเออร์ไร้คน" ที่โตขึ้น                                                                                           |

| งาน      | งานเบา-กลางตลอดวงจร: ไถพรวน หยอด กำจัดวัชพืช (hoe แบบ sliding frame ใต้ท้องรถ = แม่นยำสูง) บรรทุกขนย้าย; เครื่องมือสามจุดมาตรฐาน                                                           |
| สถานะ    | คอนเซปต์/ต้นแบบ — คาดทดสอบแปลงต่อเนื่อง 2026; สถาปัตยกรรมรองรับ multi-unit (ฝูงหลายคันภายใต้แพลตฟอร์มเดียว)                                                                                |

### 5.2 ความหมาย

- "หนึ่งคน → ไร้คน" (one-man → no-man): ผู้ควบคุม 1 คนดูแลหลายคันจากห้องทำงาน — จุดขายเรื่องแรงงานและความยืดหยุ่น
- แนวทาง Fendt: รถแทรกเตอร์มาตรฐานยังจำเป็นสำหรับงานหนัก/เครื่องมือใหญ่; หุ่นยนต์รับงานเบา-ซ้ำ — ระบบ hybrid "รถใหญ่ + หุ่นยนต์เล็ก" เป็นวิสัยทัศน์ระยะยาวของ AGCO

### 6.2 Kubota (M5 Narrow + KVPR + Kilter)

- **M5 Narrow + Agtonomy**: เชิงพาณิชย์แล้ว (2026) — รถดีเซลติดตั้งระบบอัตโนมัติจากโรงงาน งานสวน/ไร่องุ่น (ดูเจาะลึก-01)
- **Kilter (นอร์เวย์)**: หุ่นยนต์กำจัดวัชพืช ultra-precise (ร่วมพัฒนาต้นแบบ 2025) — เจาะกลุ่ม "กำจัดวัชพืชรายต้นในสวน"
- **KVPR Transformer**: คอนเซปต์แพลตฟอร์มเปลี่ยนรูปได้หลายแกน เปลี่ยนเครื่องมือ — วิสัยทัศน์ "หุ่นยนต์อเนกประสงค์" ของ Kubota

## 11. สถานการณ์ประเทศไทย

### 11.1 ตลาด/ผู้เล่น

- **หุ่นยนต์ภาคสนามเชิงพาณิชย์ยังแทบไม่มีในไทย** — ผลิตภัณฑ์ทั้งหมด (Carbon, FarmDroid, Ecorobotix) ยังไม่มีตัวแทนจำหน่าย
- บริษัทไทย/ผู้ประกอบการเริ่มทดลอง: หุ่นยนต์กำจัดวัชพืช DIY (งานวิจัย ม.เกษตร/ขอนแก่น/แม่โจ้), ระบบพ่นแม่นยำบนรถไถ (โครงงานนำร่อง)
- ข้อจำกัดเชิงโครงสร้าง: ค่าแรงงานไทยยังต่ำกว่า OECD มาก → "คืนทุนจากแทนแรงงาน" ยากกว่ายุโรป/อเมริกา; ราคาอุปกรณ์นำเข้าแพง (ภาษี+ขนส่ง)

### 11.2 งานที่น่าจะรับได้ก่อนในไทย

| ลำดับ | งาน                                    | เหตุผล                                                     |
| ----- | -------------------------------------- | ---------------------------------------------------------- |
| 1     | กำจัดวัชพืชในสวนผลไม้ (ทุเรียน/ลำไย)   | วัชพืช+ค่าจ้างแรงงานขึ้นสูง, ต้องการลดสารเคมี (ส่งออก GAP) |
| 2     | ผักอินทรีย์/แปลงโรงเรือน               | มูลค่าสูงต่อพื้นที่ — คืนทุนไว                             |
| 3     | ระหว่างแถวอ้อย/ข้าวโพด (hoe อัตโนมัติ) | ลดค่าแรงดายหญ้า, ตลาดใหญ่                                  |
| 4     | สวนปาล์ม/ยาง (ตัดหญ้าใต้ทรงพุ่ม)       | งานซ้ำถี่ เดิมใช้คน/สารเคมี                                |

### 11.3 ทางลัดสำหรับไทย

- **เริ่มจาก "เครื่องมืออัจฉริยะลากตาม"** (แบบ Carbon) ที่ใช้รถไถที่มีอยู่ + ระบบนำทาง RTK — ลงทุนต่ำกว่า "หุ่นยนต์ทั้งตัว"
- **โมเดล "รับจ้างหุ่นยนต์"** (Robot-as-a-Service): ผู้ประกอบการซื้อเครื่องจักร 1–2 ตัว ให้บริการข้ามแปลง/ข้ามจังหวัด — เชื่อมด้าน 12
- **รวมกับนโยบาย**: สารเคมีลดการใช้วัชพืชในอ้อย/ส่งออก GAP ทุเรียน → งบส่งเสริม/วิจัยจาก กษ. และทุนกองทุนต่างๆ

## 12. ความท้าทาย

| ความท้าทาย                     | รายละเอียด                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| **ราคาสูง vs ค่าแรงถูก (ไทย)** | จุดคุ้มทุนของหุ่นยนต์ $60K–1.4M ต้องใช้แรงงานแพง/แปลงใหญ่ — ไทยต้องรอราคาลงหรือเจาะงานเฉพาะ |
| **ความหลากหลายแปลง**           | พืช/วิธีการ/ขนาดแปลงไทยต่างจากยุโรป-อเมริกา — โมเดล AI ต้องเทรนใหม่ในสภาพไทย                |
| **การบริการหลังการขาย**        | ไม่มีเครือข่ายดีลเลอร์ในไทย — การซ่อม/อะไหล่เป็นอุปสรรคใหญ่                                 |
| **ข้อมูล/ความน่าเชื่อถือ**     | ตัวเลขผู้ผลิต (acreage, % กำจัด) ไม่มีงานวิจัยอิสระรองรับ — โดยเฉพาะในเขตร้อน               |
| **มาตรฐาน**                    | ไม่มีมาตรฐานไทยสำหรับหุ่นยนต์ภาคสนาม/การทำงานไร้คนในแปลง                                    |
| **ฝุ่น/ความร้อน/ความชื้น**     | อุปกรณ์ precision (กล้อง/เลเซอร์/LiDAR) เสี่ยงในสภาพไทย — ต้องทดสอบภาคสนามจริง              |
| **การลงทุนระยะยาว**            | agtech ทั่วโลกอยู่ในรอบเงินทุนต่ำ (US$4.8B, 2025) — ความเสี่ยงซัพพลายเออร์รายเล็กหายไป      |

## 13. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **Implement-first ชนะ**: แนวทาง "เครื่องมืออัจฉริยะ + รถที่มีอยู่" (Carbon, Ecorobotix) เติบโตเร็วกว่า "หุ่นยนต์ทั้งระบบ" — คาดเป็นกระแสหลักของตลาดเกิดใหม่
2. **Foundation models ภาคสนาม**: LPM ของ Carbon (150 ล้านต้น) → โมเดลใหญ่เฉพาะพืช ระดับ "LLM ของการเกษตร" — ผู้ที่เทรนได้ก่อนชนะ
3. **หุ่นยนต์ฝูงจากคอนเซปต์สู่ตลาด**: Fendt Xaver GT + สถาปัตยกรรม multi-unit — การจัดการฝูงผ่าน cloud เป็นงานวิจัยหลัก
4. **ขยายสู่สวนผลไม้เอเชีย**: R4/M5/Kilter เจาะสวนองุ่น-ทุเรียน-ส้ม — ตลาดเอเชียเป็นเป้าถัดไป
5. **บูรณาการกับ See & Spray**: กล้อง-เลเซอร์กับกล้องพ่นแม่นยำใช้ฐาน AI เดียวกัน — ลดต้นทุนต่อหน่วย
6. **Robot-as-a-Service**: บริการเช่า/รับจ้างหุ่นยนต์ (RoboWork ฯลฯ) — ลดกำแพงเงินทุนสำหรับฟาร์มเล็ก
