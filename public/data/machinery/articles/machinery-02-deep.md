## 1. หลักการและขอบเขต

เครื่องเก็บเกี่ยวอัจฉริยะ (Smart Combine / Smart Harvester) คือเครื่องเก็บเกี่ยวที่ติดตั้งระบบอัตโนมัติและเซนเซอร์เพื่อ: (1) ปรับการทำงานเองตามสภาพแปลง (2) วัดและลดการสูญเสียเมล็ด (3) วัดคุณภาพและผลผลิตแบบเรียลไทม์ (4) ลดการพึ่งพาผู้ควบคุมที่มีประสบการณ์สูง

งานเก็บเกี่ยวคือ "งานที่ไวต่อเวลาที่สุด" ของฤดูกาล — รอไม่ได้ ฝนตกเมื่อไหร่เสียหายทันที — การอัตโนมัติจึงให้คุณค่าสูงสุด: ขยายเวลาทำงาน (กลางคืน/อากาศแปรปรวน) และลดข้อผิดพลาดมนุษย์

**ขอบเขตด้านนี้ครอบคลุม**:
| เครื่อง | พืช | เทคโนโลยีอัจฉริยะ |
|---|---|---|
| Combine Harvester (เกี่ยวนวด) | ข้าว ข้าวสาลี ข้าวโพด ถั่ว | ระบบอัตโนมัติครบชุด (หัวข้อ 2–5) |
| เครื่องตัดอ้อยสด | อ้อย (chopper/whole stalk) | เซนเซอร์ความสูงตัด, auto-feed |
| เครื่องเก็บมันสำปะหลัง | มันสำปะหลัง | ลดความเสียหายหัวมัน |
| หัวเกี่ยวนวด (header) | หลายพืช | Row guidance, auto-height |

## 2. เทคโนโลยียกระดับ: Combine อัตโนมัติ (John Deere)

### 2.1 ระบบหลัก (MY2025–2027)

| ระบบ                                      | หลักการ                                                                                                                                    | ผลลัพธ์                                                                                                                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Predictive Ground Speed Automation**    | กล้อง stereo 2 ตัวหน้าเกี่ยวนวดวัดความสูง/ปริมาณต้น + แผนที่ผลผลิตจากดาวเทียม (Operations Center) + terrain map → ปรับความเร็วเกี่ยวนวดเอง | เกี่ยวนวดสม่ำเสมอ ลดการอุดตัน ทำงานได้เร็วขึ้นในสภาพแปลงหลากหลาย; MY2027 เพิ่ม Green Crop Detection (ตรวจจับต้นเขียวในแปลงที่แก่แล้ว) และโหมด "throughput target" ที่ตั้งเป้าคุณภาพ-การสูญเสีย |
| **Harvest Settings Automation**           | ตั้งช่องว่างตะแกรง 2 ตะแกรง ความเร็วพัดลม/โรเตอร์ อัตโนมัติตามรุ่นรถ/ชนิดพืช/ตำแหน่ง; ปรับอัตโนมัติขณะผ่านแปลงที่เก็บแล้ว (out-of-crop)    | เข้าทำงานเร็วขึ้น (ไม่ต้องตั้งมือ), ลดการสูญเสียในจุดแปลงบาง; MY2027: ผู้ใช้ตั้งเป้า (grain loss/สิ่งเจือปน/เมล็ดแตก) แล้วระบบปรับ 5 ค่าการตั้งให้อยู่ในเป้า                                   |
| **AutoTrac Turn Automation**              | เลี้ยวหัวแถวอัตโนมัติ + ยก/ลดหัวเกี่ยวนวดเองตาม trigger (ขอบแปลง/แนวขวาง)                                                                  | เลี้ยวได้มือเปล่าจริง ทำงานกลางคืนได้ (ฝุ่นน้อย = มองไม่เห็น) ไม่พลาดแนว                                                                                                                       |
| **Auto-Unload (กล้องถ่ายลำเลียง)**        | กล้องบนท่อลำเลียงวัดระดับเมล็ดในรถกระบะ (grain cart) → สั่ง nudge รถคันข้างให้เมล็ดกระจายสม่ำเสมอ                                          | ลดการหก/การเสียสมาธิ (ผู้ควบคุมต้องถ่ายถัง ~10 ครั้ง/ชม.)                                                                                                                                      |
| **Grain Sensing + HarvestLab 3000 (NIR)** | วัดความชื้น โปรตีน แป้ง น้ำมัน เรียลไทม์ (ข้าวสาลี บาร์เลย์ คาโนลา ข้าวโพด ถั่วเหลือง ข้าวโอ๊ต ข้าวไรย์ **และข้าว**)                       | เอกสารคุณภาพรายแปลง → ต่อยอดการตลาด/สายพันธุ์                                                                                                                                                  |
| **ActiveYield**                           | ปรับเทียบค่าผลผลิตอัตโนมัติตลอดการเก็บ (เซนเซอร์ 3 จุดในถัง + TCM) รองรับ **ข้าว** ด้วย                                                    | แผนที่ผลผลิตแม่นยำไม่ต้อง calibrate มือ                                                                                                                                                        |
| **RowSense / Corn Head Automation**       | เซนเซอร์จัดตำแหน่งหัวเกี่ยวนวดข้าวโพด + ควบคุม deck plate/ความเร็วเพลา อัตโนมัติ (MY2027)                                                  | เข้าถูกแถวตอนกลางคืน, ลดการสูญเสียฝัก                                                                                                                                                          |
| **Combine Advisor / Auto Maintain**       | กล้อง ActiveVision วิเคราะห์เมล็ดสะอาด/เศษวัสดุ (train ด้วยผู้เชี่ยวชาญ) → ปรับระบบนวดอัตโนมัติตามเป้า                                     | รักษาเป้า loss/คุณภาพโดยอัตโนมัติ                                                                                                                                                              |

### 2.2 ประสิทธิภาพที่รายงาน

- ออสเตรเลีย: ชุดอัปเดต 2026 เพิ่มผลผลิตงานเก็บ **สูงสุด +20%** (อ้างอิงผู้ผลิต)
- ระบบต่าง ๆ เหล่านี้ช่วยให้ "คนขับระดับกลาง" เก็บได้คุณภาพเทียบเท่ามืออาชีพ (ข้ออ้างหลักของ Deere)

## 3. New Holland: IntelliSense และระบบเซนเซอร์

| ระบบ                                | รายละเอียด                                                                                                                                                           |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IntelliSense Combine Automation** | ปรับการทำงานทุก 20 วินาทีตามสภาพที่เปลี่ยน → **throughput +25%, การสูญเสียเมล็ด -33%** (อ้างอิงผู้ผลิต); ป้องกัน overload                                            |

**จุดขาย CNH/New Holland**: "ทุกชิ้นเชื่อม FieldOps" + ผสานกับระบบพ่น IntelliSense (ด้าน 04) — ข้อมูลทั้งวงจรในแพลตฟอร์มเดียว

## 4. Kubota DRH1200A: เกี่ยวนวดอัตโนมัติคันแรกของโลก

### 4.1 ข้อมูลหลัก

- **DRH1200A (วางตลาด 2024)**: เกี่ยวนวดข้าวไร้คนแบบ "ทำงานอัตโนมัติภายใต้การเฝ้าดูของคน" คันแรกของโลก — ครบชุดระบบอัตโนมัติของ Kubota (รถแทรกเตอร์ + เครื่องดำนา + เกี่ยวนวด = SmartAgri System ครบวงจร)

### 4.2 เทคโนโลยีเด่น

| ระบบ                        | รายละเอียด                                                                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **การตรวจจับคันนา/ขอบแปลง** | แผนที่จาก point cloud ด้วย LiDAR — รู้ความสูง/สภาพคันนา ทำงานอัตโนมัติเลี่ยงคันนาได้เอง                                                  |
| **เก็บมุมแปลงอัตโนมัติ**    | เลี้ยวมุม (corner harvesting) เทียบเท่าช่างผู้ชำนาญ — ขยายพื้นที่ทำงานอัตโนมัติได้มาก                                                    |
| **เลียนแบบมืออาชีพ**        | Kubota เก็บข้อมูลการเก็บของช่างเซียนทั่วญี่ปุ่น (ความสูงต้น/ความเร็ว/ตำแหน่ง reel/รอบหมุน) → สร้างพารามิเตอร์ครอบคลุมแปลงเอียงสูงถึง 60° |
| **ผสานระบบ**                | ทำงานต่อเนื่องกับรถแทรกเตอร์/เครื่องดำนาแบบอัตโนมัติเดียวกัน — ข้อมูลไหลตลอดห่วงโซ่                                                      |

### 4.3 นัยสำคัญ

- การเก็บเกี่ยว = งานสุดท้ายที่ยากสุดในระบบอัตโนมัติ (งานไถ/ดำนา ทำไปแล้ว) — การสำเร็จของ Kubota ปิด "ลูป" ของนาไร้คนทั้งระบบ
- Kubota ระบุเป้าหมายถัดไป: "ไร้คนสมบูรณ์แบบภายใต้การเฝ้าดูระยะไกล" — เหลือประเด็นฮาร์ดแวร์/การสื่อสาร/กฎหมาย

## 5. Yanmar และระบบ SmartAssist ในไทย

- **YH1180 Smart Combine (ทดลองจริงในไทย 2565)**: โครงการร่วม JICA + คณะกรรมการไทย-ญี่ปุ่น ที่สระบุรี — ติดตั้ง GNSS + Linear mode (วิ่งตรงอัตโนมัติ + พวงมาลัยบังคับต่อได้) + **SmartAssist Remote (SA-R)** + เซนเซอร์ผลผลิตในถัง
- ใช้ข้อมูลแก้ไขตำแหน่งจาก **National CORS Data Center (NCDC) ของไทย** — การทำงานร่วมกับโครงข่าย RTK ในประเทศ
- YR8D เครื่องดำนาอัตโนมัติ + YT5113A รถแทรกเตอร์อัตโนมัติสาธิตคู่กัน
- **YANMAR Smart Combine (เชิงพาณิชย์ญี่ปุ่น)**: บันทึกผลผลิต/เวลาต่อแปลงลง SMARTASSIST → เชื่อมกับ remote sensing → ปรับการให้ปุ๋ยปีถัดไป (ปิดลูปข้อมูล)
- Yanmar S.P. มีโรงงาน/เครือข่ายดีลเลอร์ + Yanmar Capital (สินเชื่อ) ในไทย ตั้งแต่ 1978 — ช่องทางกระจายเทคโนโลยีพร้อม

## 6. การวัดการสูญเสียเมล็ดและคุณภาพการเก็บ

### 6.1 เทคโนโลยี

| เทคโนโลยี               | หลักการ                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| **Grain Loss Sensor**   | เซนเซอร์ความถี่สูงใต้ตะแกรงแยก นับเมล็ดที่หลุดร่วงผ่านท้ายเครื่อง (Deere S7: เพิ่มเซนเซอร์ x2x1) |
| **ActiveVision camera** | วิเคราะห์ภาพเมล็ดสะอาด/เมล็ดแตก/สิ่งเจือปน (train โดยผู้เชี่ยวชาญ) — Auto Maintain               |
| **HarvestLab NIR**      | วัดความชื้น/โปรตีน/แป้งในธัญพืชรายจุด                                                            |
| **Yield Monitor**       | ชั่งน้ำหนัก + วัดความชื้น → แผนที่ผลผลิตต่อตารางเมตร                                             |

### 6.2 ทำไมเรื่องนี้สำคัญ (ข้อมูลไทย)

- **การสูญเสียระหว่างเกี่ยวนวดข้าวไทย**: ประเมิน 3–10% ของผลผลิต (ขึ้นกับสภาพแปลง/เครื่อง/ช่าง) — ที่ผลผลิต 600–800 กก./ไร่ เท่ากับเงิน 100–300 บาท/ไร่ ที่หายไป
- **งานวิจัยอ้อย (ชัยภูมิ 2569, วารสาร RAE)**: เครื่องตัดอ้อยอายุ 17 ปี สูญเสีย 241.93 กก./ไร่ สูงกว่าเครื่องใหม่ (156.90 กก./ไร่) **54%** — สาเหตุ: ตัดโคนไม่ได้ 36% + ลูกกลิ้งป้อน 34% (=70%); สิ่งเจือปนหลัก = ยอดอ้อย 57%; **กำไรฟาร์มลด 12–18%** จากการสูญเสียของเครื่องเก่า
- **บทเรียน**: ข้อมูลเซนเซอร์บนเครื่องเก่าที่ดีพอ + ตั้งค่าถูกต้อง = ประหยัดเงินก้อนใหญ่โดยไม่ต้องซื้อเครื่องใหม่

| ราคาส่งออกเฉลี่ย | US$18K/คัน (2023) — จากจุดสูง US$142K (2018); ราคานำเข้าเฉลี่ย US$6.5K (จาก US$127K ปี 2014) — สะท้อนการเปลี่ยนแปลงโครงสร้างสู่เกี่ยวนวดขนาดเล็ก/ราคาถูก (จีน) |
| สเปกที่นิยม      | self-propelled ขนาด 75–120 แรงม้า, ความเร็วเก็บ 1.2–1.8 ม./วินาที, รุ่นล้อโคลน (crawler) สำหรับนาลึก                                                           |
| ตัวเลขใช้        | 27.9% ของฟาร์มใช้เกี่ยวนวด (ภาพรวม); ฟาร์มสหกรณ์/วิสาหกิจข้าวให้บริการรับจ้าง 650–800 บาท/ไร่ (ถูกกว่าตลาด 50–200 บาท)                                         |

### 7.3 ความต้องการปี 2026 (สยามคูโบต้า)

- ตั้งเป้าขาย **200 คันเกี่ยวนวดข้าว/ปี** + รถแทรกเตอร์ 4,000 คัน + โดรน 700–800 ลำ
- รายได้รวมเป้า 62,000 ล้านบาท (+12%) — ผลจากเครื่องตัดอ้อยสายใหม่ (ขายไปแล้ว 50 คัน 2026)

## 8. เครื่องตัดอ้อยสดและสถานการณ์อ้อยไทย

### 8.1 การเปลี่ยนผ่านสู่ "อ้อยสด" (green cane)

- **97% ของอ้อยไทยเป็นอ้อยสด (ไม่เผา) ใน MY2025/26** — สูงสุดเป็นประวัติการณ์ (จาก 85% ปีก่อน และค่าเฉลี่ย 10 ปี 63%) — เกิดจาก: แรงกดดัน PM2.5, ส่วนเพิ่มราคา (OCSB ให้ premium), และการลงทุนเครื่องตัดอ้อยที่ sunk แล้ว
- CCS (ความหวาน) เพิ่ม: 110 กก./ตันอ้อย (MY2025/26) เทียบ 109.2 (ก่อนหน้า) และ 107.2 ในช่วงแล้ง 2566/67

### 8.3 ความท้าทายเฉพาะอ้อย

- การตัดสดต้องขนย้ายเร็ว (อ้อยเน่าเสีย CCS ลดหลังตัด 24–48 ชม.) — ต้องวางแผนขนส่งร่วม
- ต้นทุนเครื่องสูงมากเทียบรายได้ฟาร์มอ้อยเล็ก → ต้องพึ่งบริการรับจ้าง/สหกรณ์

## 10. สถานการณ์ประเทศไทย

### 10.1 โครงสร้างบริการเก็บเกี่ยวไทย

- **เกี่ยวนวดรับจ้างเป็นธุรกิจใหญ่**: ค่าบริการ 650–800 บาท/ไร่ (วิสาหกิจ) หรือ ~700–850 บาท/ไร่ (เอกชน); งานเก็บ = 28–33% ของรายได้ฟาร์ม (ค่าจ้างไถ + ค่าเก็บ)
- **วิสาหกิจชุมชน**: 175/208 กลุ่ม (ขอนแก่น) มีเกี่ยวนวดจากการอุดหนุน — คิดค่าเก็บถูกกว่าตลาด 50–200 บาท/ไร่
- **ปัญหาหลัก**: ขาดแคลน "ผู้ควบคุมเกี่ยวนวด" (ช่างเก็บข้าว) — ฤดูเก็บงานแน่นมากจนจ้างไม่ได้ (เป็นเหตุผลของระบบอัตโนมัติ)
- **แปลงเล็ก**: นาแปลงเล็ก/ขั้นบันได (0.1 ไร่) ไม่เหมาะเครื่องใหญ่ — ยังเป็นช่องว่างสำหรับเครื่องขนาดเล็กอัตโนมัติ/แบบร่วมกลุ่ม

### 10.2 จุดแข็ง/จุดอ่อน

| จุดแข็ง                                                         | จุดอ่อน                                                       |
| --------------------------------------------------------------- | ------------------------------------------------------------- |
| ไทยเป็นฮับผลิต/ส่งออกเกี่ยวนวดภูมิภาค (ส่งออก 71% ไปเพื่อนบ้าน) | ราคาเครื่องตกหนัก (จีนบุก) — margin ผู้ผลิตไทยถูกกด           |
| เครือข่ายบริการรับจ้างแน่น (วิสาหกิจ + เอกชน)                   | เครื่องส่วนใหญ่ไม่มีระบบวัดการสูญเสีย/แผนที่ผลผลิต            |
| มีโครงข่าย NCDC (RTK) + โครงการ JICA/Yanmar นำร่องแล้ว          | เทคโนโลยีอัตโนมัติระดับ Deere/Kubota ยังไม่มีในตลาดไทย (ราคา) |
| อ้อย: โครงสร้าง green cane 97% — ตลาดเครื่องตัดอ้อยโตต่อเนื่อง  | ราคาอ้อยต่ำกว่าต้นทุน → ฟาร์มเล็กไม่มีเงินซื้อเครื่อง         |

### 10.3 ตัวเลขที่น่าจับตา

- เกี่ยวนวดข้าวราคาในไทย: 1.5–8 ล้านบาท (คูโบต้า/ยันมาร์/จีน)
- ค่าเก็บเกี่ยว 650–850 บาท/ไร่ — คิดเป็น ~15–20% ของรายได้ข้าวเปลือก (~4,000 บาท/ไร่)
- ฟาร์มข้าว 65.4% <20 ไร่ → เกือบทั้งหมดใช้บริการรับจ้าง

## 11. แนวทางนำไปใช้

### 11.1 Blueprint 3 ขั้น (ฟาร์ม/วิสาหกิจบริการ)

1. **รู้ตัวเลข (ปี 1)**: ตรวจวัดการสูญเสียเมล็ดจริง (เก็บตัวอย่างจุด/ใช้ sensor kit) — ส่วนใหญ่จะพบการสูญเสีย 3–10% ที่แก้ได้ด้วยการตั้งเครื่อง
2. **ตั้งค่าอัจฉริยะ-ปรับเครื่อง (ปี 1–2)**: นำระบบ "harvest settings ตามชนิดพืช/ตำแหน่ง" (มีในเครื่องใหม่หลายรุ่น) + อบรมช่างประจำถิ่นเรื่องการตั้งตะแกรง/พัดลมตามความชื้นข้าว; บำรุงรักษาเชิงป้องกัน (เลิกใช้เครื่องอายุ >10 ปีโดยไม่ซ่อม) — ลด loss ได้ทันทีโดยไม่ซื้อเครื่องใหม่
3. **เครื่องอัจฉริยะ (ปี 3+)**: เมื่อถึงรอบเปลี่ยนเครื่อง เลือกรุ่นที่มี yield monitor + loss sensor + auto-steer อย่างน้อย; วิสาหกิจใหญ่พิจารณาเครื่อง autonomy-class (Kubota DRH) เมื่อแรงงานช่างขาดแคลนถึงจุดวิกฤต

### 11.2 สำหรับวิสาหกิจรับจ้างเกี่ยวนวด

- ติดตั้ง **yield map** บนเครื่อง → บริการ "เก็บ + รายงานผลผลิต/ความชื้นรายแปลง" เพิ่มมูลค่าบริการ 50–150 บาท/ไร่
- ใช้ **data หลายฤดู** ช่วยสมาชิกวางแผนพันธุ์/ปุ๋ย (เชื่อมด้าน 08/10)
- สำรองแผนช่วงหน้าฝน: เกี่ยวนวด 24 ชม. (กลางคืน) ต้องมีไฟ + auto-steer

### 11.3 สำหรับอ้อย

- ตรวจสอบอายุ/สภาพเครื่องตัดอ้อยก่อนตัด — งานวิจัยชี้ loss เพิ่ม 54% ในเครื่อง 17 ปี (กำไรหาย 12–18%)
- เลือกเครื่อง "1 แถวเล็ก" สำหรับแปลงลาด/เล็ก; chopper สำหรับแปลงใหญ่
- รวมกลุ่มซื้อ/เช่าเครื่องตัดอ้อยร่วมกัน ผ่านวิสาหกิจ (เชื่อมด้าน 12)

## 13. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **"การเก็บเกี่ยวอัตโนมัติครบวงจร"**: Kubota ปิดลูป (รถไถ+ดำนา+เกี่ยวนวดไร้คน) → ขยายสู่ไทย/อาเซียนเมื่อกฎหมายเอื้อ
2. **Predictive harvesting**: Deere ใช้ดาวเทียม/ข้อมูลสภาพอากาศพยากรณ์ "หน้าต่างเก็บ" + วางแผนลำดับแปลงเก็บอัตโนมัติ
3. **NIR ทุกเครื่อง**: HarvestLab 3000/NutriSense กลายมาตรฐาน → เอกสารคุณภาพรายแปลงเปลี่ยนการค้าข้าว (ซื้อขายตามคุณภาพ)
4. **Autonomous unloading**: กล้อง auto-unload → ระบบ "รถกระบะตามเกี่ยวนวดอัตโนมัติ" (swarm เก็บเกี่ยว)
5. **การสูญเสียเป็นตัวชี้วัด**: งานวิจัยไทยเริ่มวัดผล (เช่น ชัยภูมิ 2569) — ฐานข้อมูล loss ต่อจังหวัดจะขับเคลื่อนการตัดสินใจซื้อเครื่อง
6. **ตลาดอาเซียน**: ไทยส่งออกเกี่ยวนวด 71% ไปกัมพูชา/ฟิลิปปินส์/เมียนมา — การอัปเกรด "สมาร์ท" ของเครื่องส่งออกไทยเป็นช่องทางเพิ่มมูลค่า
