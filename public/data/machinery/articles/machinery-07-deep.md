## 1. หลักการและขอบเขต

การเพาะปลูกเป็น "จุดที่พลาดไม่ได้" ของฤดูกาล — หยอดเมล็ดพลาดวัน เปลี่ยนผลผลิตทั้งปี แนวคิด "เครื่องหยอดแม่นยำ" (precision planter) คือการควบคุม 4 ตัวแปรให้แม่นยำระดับเมล็ด/จุด: (1) **ตำแหน่งเมล็ด** (spacing, ละระยะ skips/doubles) (2) **ความลึก** (depth/ลงแรงกด) (3) **อัตราเมล็ด/ปุ๋ยรายจุด** (VRT) (4) **การเลี้ยวหัวแถว** (turn automation) — ด้านนี้ยังรวมเครื่องดำนา/ย้ายกล้าอัตโนมัติ ซึ่งเป็น "งานเพาะปลูก" ของข้าวไทย

## 2. เทคโนโลยีหลักของเครื่องหยอดแม่นยำ

| เทคโนโลยี                            | หน้าที่                                                               | ผู้เล่นหลัก                                                                             |
| ------------------------------------ | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **Seed singulation (seed metering)** | จัดเมล็ดทีละเมล็ดเข้าหลุม — ลด skips (เมล็ดข้าม) / doubles (เมล็ดคู่) | Deere (MaxEmerge/ExactEmerge), Precision Planting (vSet/eSet), Väderstad (Tempo), Kinze |
| **Seed delivery**                    | ลำเลียงเมล็ดจาก meter ถึงร่องเมล็ดอย่างแม่นยำ                         | ExactEmerge BrushBelt (Deere) — "tracking each seed"                                    |
| **Downforce ควบคุมอัตโนมัติ**        | กดล้อ gauge ตามแรงตั้งเป้า (45.4 กก.) รักษาความลึกสม่ำเสมอ            | Active Pneumatic Downforce (Deere)                                                      |
| **Section control / RowCommand**     | ตัด/ต่อการหยอดเป็นแถวเมื่อเลี้ยวหัวแถวหรือซ้ำร่อง                     | ทั้ง Deere/CNH/AGCO                                                                     |
| **Electric drive planter**           | แทนเพลาขับกลไก — เปลี่ยนอัตราได้ทันที (<1 วินาที)                     | Deere ExactRate (ไฟฟ้า+ปุ๋ยน้ำ)                                                         |
| **As-planted map**                   | บันทึกพิกัด+อัตราจริงทุกแถว                                           | SeedStar 5 + Operations Center                                                          |
| **Autonomy/เลี้ยวอัตโนมัติ**         | AutoPath/AutoTrac Turn Automation (ด้าน 01)                           | Deere                                                                                   |

**ตัวเลขผลลัพธ์ (งานวิจัย Precision Planting, 8 ปี 2018–2025, PTI Farm IL)**

- ทุก 1% ของ singulation ที่ต่ำกว่า 99.5% → ผลผลิตข้าวโพดลดเฉลี่ย **-1.9 บุชเชล/เอเคอร์**
- singulation 95% (ลดลง 4.5%) → ขาดทุนเฉลี่ย **-$36.68/เอเคอร์/ปี** (ข้าวโพด)

## 3. เครื่องหยอดรุ่นใหม่ของ Deere (MY2026)

ประกาศ ก.พ. 2568 (Farmers Hotline / Agriculture.com) — 3 เทคโนโลยี "logistics + precision":

| เทคโนโลยี                    | รายละเอียด                                                                                                                                                           | การเข้าถึง                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| **Seed-Level Sensing**       | เซนเซอร์วัดปริมาณเมล็ดในถังแบบ real-time (ปริมาตร/%) ดูในจอ G5 + Operations Center ระยะไกล; เตือนระดับต่ำ; จัดการรถเติมเมล็ด (seed tender) ไม่ให้เครื่องหยุดกลางแปลง | MY2026 มาตรฐาน / retrofit รุ่น 2022+ |
| **Fertilizer-Level Sensing** | เซนเซอร์ระดับปุ๋ยน้ำ (ExactRate/ExactShot) ในถัง; ดูจากในห้องขับ; เชื่อม Liquid Transfer Automation (โอนปุ๋ยจากแทรกเตอร์→เครื่องอัตโนมัติ, ไม่หก/ไม่ลืม prime)       | MY2026 (electric drive)              |
| **Active Vacuum Automation** | ดู singulation แบบ real-time แล้วปรับสุญญากาศอัตโนมัติ — ลด skips/doubles โดยไม่ต้องปรับมือ                                                                          | MY2026 + SeedStar 5 + electric drive |

**ExactRate (ระบบปุ๋ยน้ำแบบ VRT)**: ความเร็วเกิน 8 กม./ชม. (เดิม 5 ไมล์/ชม.), turn compensation, section control รายแถว, as-applied documentation, ปุ๋ยน้ำ VRA — "เครื่องหยอด+ใส่ปุ๋ยในเครื่องเดียวแบบ VRT"

**ข้อควรระวังจากงานวิจัย (Springer, 2019)**: as-planted map จากจอเชิงพาณิชย์**ไม่สะท้อนการทำงานจริง**เสมอ — ตำแหน่งเปลี่ยนอัตราเกิดช้ากว่าเส้นแบ่งโซน (lag 7.7 ม. ทิศตะวันออก-ตะวันตก vs 3.8 ม. ตรงข้าม) และความลึกที่ได้ต่างจากค่าตั้ง (ตื้นกว่า/ลึกกว่าเป้า) — "ตั้งเครื่องผิด = ข้อมูลสวยแต่ผลงานแย่" การ calibrate ตำแหน่ง GPS vs meter และ look-ahead time สำคัญมาก

## 4. VRT: การปรับอัตราเมล็ดและปุ๋ยรายจุด

### 4.1 หลักการ

VRT (Variable Rate Technology) = เปลี่ยนอัตราเมล็ด/ปุ๋ยตาม "คุณภาพแปลงรายจุด" จาก prescription map (เกิดจาก yield map หลายปี + ค่าวิเคราะห์ดิน + DEM/ความลาดชัน) — เป็นส่วน 26% ของมูลค่า precision ag ปี 2025 (Alora)

### 4.2 ผลลัพธ์ที่พิสูจน์แล้ว (เมล็ด, ข้าวโพดสหรัฐฯ)

| งานวิจัย                                           | ผลลัพธ์                                                                                                                                             |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agronomy Journal (1998, 42,000 แปลงทดลอง 10 รัฐ)   | มูลค่า VRS = **$12.83/เฮกตาร์** เมื่อมีข้อมูลเต็มที่ vs $0.15/เฮกตาร์ เมื่อข้อมูลไม่ครบ — "คุณค่าอยู่ที่ข้อมูล ไม่ใช่เครื่อง"                       |
| Ohio State (125 trials, 2012–2016)                 | EOSR ได้กำไรเพิ่ม **$12.53/เอเคอร์** (Ohio) แต่แค่ $3.14/เอเคอร์ (Illinois แปลงสม่ำเสมอ) — 86% มาจากผลผลิต + 14% จากเมล็ดที่ประหยัด                 |
| Agronomy Journal (2026, ML + geospatial, Miami OH) | VRS แยกโซนด้วย ML (elevation/CEC/slope/SOM) ได้ผลกับข้าวโพดแปลงต่างกันสูง แต่แทบไม่มีประโยชน์ในถั่วเหลือง — "VRS ไม่ใช่ของทั่วไป ต้องเลือกพืช/แปลง" |
| Springer Precision Ag (2019)                       | การเปลี่ยนอัตราทำได้รวดเร็ว (<1 วินาที) — เทคโนโลยีไม่ใช่คอขวด; คอขวดคือการตั้งค่าที่ถูกต้อง                                                        |

**บทสรุปทางเศรษฐศาสตร์ VRS**: ได้กำไรจริงแต่ "เล็ก" ($3–13/เอเคอร์) และขึ้นกับความต่างของแปลงภายในแปลงเดียว — แปลงสม่ำเสมอ/ราคาเมล็ดถูก ไม่คุ้ม; ปุ๋ย VRT ให้ผลเด่นกว่าเมล็ด VRS (ดูด้าน 04 และงานไทย TSAEJ 2568)

### 4.3 VRT ฉบับไทย

- **เครื่องหยอดปุ๋ยตามค่าวิเคราะห์ดินอัตโนมัติ (TSAEJ 2568, มันสำปะหลัง)**: Arduino Mega 2560 + มอเตอร์ DC 24V 500W + PWM — ความแม่นยำ 90.3–94.1% ต่อปุ๋ย 3 สูตร, ทำงาน 4.79 ไร่/ชม., น้ำมัน 0.69 ลิตร/ไร่ (รายละเอียดด้าน 10)
- ตัวขับ VRT ไทยยังเป็น "โซนย่อย + ข้อมูลราชการ" (กรมพัฒนาที่ดิน/กรมวิชาการเกษตร) ไม่ใช่ yield map รายจุด — เริ่มจาก "ปุ๋ย VRT" ก่อน "เมล็ด VRS" เพราะผลตอบแทนชัดเจนกว่า

## 5. เครื่องดำนา/ย้ายกล้าอัตโนมัติ (ญี่ปุ่น → ไทย)

### 5.1 ญี่ปุ่น: ต้นกำเนิด automation การปักดำ

| เครื่อง                                | รายละเอียด                                                                                                                                                                                                                                                                 |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kubota Agri Robo Rice-Transplanter** | เครื่องปักดำแบบไม่มีคนบนเครื่อง **คันแรกของโลก** (วางตลาด ต.ค. 2563) — วิ่งเส้นตรง+เลี้ยว+หลบสิ่งกีดขวางอัตโนมัติ, Safety Stop เมื่อออกนอกพื้นที่กำหนด, "expert full-field planting" ปักทั่วทั้งแปลงไม่ทับแถว                                                              |
| **Yanmar YR8D (SMARTPILOT)**           | วางตลาด 1 ก.พ. 2562 ราคา JPY 3.955–5.545 ล้าน (เฉพาะญี่ปุ่น, เป้าขาย 200 คัน/ปีแรก); RTK-GNSS ความแม่นยำระดับซม.; EPS พวงมาลัยไฟฟ้าอัตโนมัติ; Auto Mode เลี้ยวอัตโนมัติ; **กับกล้าความหนาแน่นสูง (Mitsunae)** 50–60 ต้น/3.3 ตร.ม. → ปักได้ 30 ไร่ (30a) โดยไม่ต้องเติมกล้า |
| **Kubota KA Series (จีน)**             | สำหรับตลาดผู้รับจ้างปักดำจีน — ล้อใหม่ + ระบบปรับระดับสำหรับนาโคลน ใหญ่ขึ้น/เร็วขึ้น                                                                                                                                                                                       |

ระดับอัตโนมัติเครื่องจักร (ญี่ปุ่น): L1 = ผู้ขับบนเครื่อง + บังคับพวงมาลัยอัตโนมัติ / L2 = ไม่มีคนบนเครื่อง ผู้ควบคุมเฝ้าอยู่ใกล้ / L3 = ควบคุมระยะไกล — เครื่องปักดำ/เกี่ยวนวดของ Kubota/Yanmar ทำถึง L2 เชิงพาณิชย์

### 5.2 ไทย: เครื่องดำนามีมานาน แต่ automation ยังไกล

- Kubota/Yanmar/ISEKI ขายเครื่องดำนาในไทย + บริการรับจ้างดำนา (ภาคกลาง/อีสาน) — แต่รุ่นที่ขายเป็นแบบธรรมดา (ยังต้องคนบังคับ), รุ่น auto (YR8D) ยังไม่นำเข้าเชิงพาณิชย์
- การนำ GPS/RTK มาใช้กับงานดำนา/เกี่ยวนวดในไทย <2% ของเครื่อง (ดูด้าน 01) — โอกาสของ "นาสาธิต + บริการรับจ้างดำนาอัตโนมัติ"

## 6. เครื่องหยอดข้าวไทย: นาแห้ง/นาน้ำตม/นาโคลน

ข้าวไทย 46.2% ของพื้นที่เพาะปลูก (ด้าน 10) — "การหยอด" เป็นทางเลือกกลางระหว่างนาหว่าน (เสี่ยง/เมล็ดเยอะ) กับนาดำ (แพง/แรงงาน) และถูกจับตาเรื่องต้นทุน

### 6.1 ผลลัพธ์เชิงประจักษ์

| งาน                                                                  | ผลลัพธ์                                                                                                                                                                                  |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AIT-จุฬาฯ เครื่องหยอดข้าวอัตโนมัติ** (ARDA, 2 รุ่น: นาแห้ง+นาโคลน) | GPS นำทางวิ่งเอง; หยอด 1–3 เมล็ด/หลุม แม่นยำ 2–5%; **เมล็ดลด 25 → 1.5 กก./ไร่**; ผลผลิต 961 vs 936 กก./ไร่ (นาหว่าน); ต้นทุนรวม -10%; จดสิทธิบัตร 3 ฉบับ (ARDA)                          |

| **การยอมรับเกษตรกร (สุรินทร์, 200 ราย)**                             | ตัวแปรเพิ่มโอกาสใช้: พื้นที่ชลประทาน, ขนาดถือครอง, ผลผลิต/ไร่, การรับรู้+ทัศนคติ; ตัวแปรลดโอกาส: อายุ, ต้นทุนการผลิต — "การส่งเสริม/ความรู้" สำคัญสุด                                    |

### 6.2 สรุปสมการไทย

"หยอด" ให้ผลเหมือน "ปักดำ" แต่ต้นทุนต่ำกว่าเทียบ "หว่าน" — แต่อุปสรรคการยอมรับอยู่ที่ความเคยชิน/การตลาดของผลผลิต (ซังข้าวเส้นตรง) มากกว่าเทคโนโลยี — การส่งเสริมผ่านนาแปลงใหญ่ + กลุ่มวิสาหกิจ (ด้าน 12) เป็นเส้นทางหลัก

## 7. สถานะเทคโนโลยีไทย vs ต่างประเทศ

| งาน                | ต่างประเทศ                              | ไทย                                        | ช่องว่าง                        |
| ------------------ | --------------------------------------- | ------------------------------------------ | ------------------------------- |
| หยอดข้าวโพด/ธัญพืช | singulation 99%+ / VRT / electric drive | เครื่องหยอดกลไก (นำเข้า), หยอดข้าวเป็นหลัก | seed sensor / section control   |
| ปักดำ              | ไม่มีคน L2 (Kubota/Yanmar)              | เครื่องดำนาธรรมดา + รับจ้าง                | รุ่น auto ยังไม่เข้าตลาด        |
| VRT ปุ๋ย           | prescription จาก yield map              | ต้นแบบ Arduino (90%+)                      | ข้อมูลรายจุด / การต่อยอดพาณิชย์ |
| As-planted data    | มาตรฐาน SeedStar 5                      | ไม่มี                                      | เซนเซอร์+ซอฟต์แวร์              |
| เศรษฐศาสตร์        | พิสูจน์แล้วแต่ "เล็ก" ($3–13/เอเคอร์)   | ต้นแบบพิสูจน์ -970 บาท/ไร่ (หยอด)          | ขยายผลเชิงพาณิชย์               |

| ขั้น       | ระดับฟาร์ม (ไทย, ข้าว/ข้าวโพด/อ้อย)                                   | ระดับธุรกิจ/สหกรณ์                                             |
| ---------- | --------------------------------------------------------------------- | -------------------------------------------------------------- |
| 1 (1–2 ปี) | ลองเครื่องหยอดข้าวนาแห้ง/นาน้ำตม (ค่าปลูก 150–200 บาท/ไร่) เทียบหว่าน | จัดบริการรับจ้างหยอดข้าว (เครื่อง AIT/เชิงพาณิชย์)             |
| 2 (2–4 ปี) | ทำโซนปุ๋ยจากค่าวิเคราะห์ดิน (รายแปลง) → ใช้ VRT ปุ๋ยราคาประหยัด       | ชุด GNSS + section control กับเครื่องหยอด/ดำนาที่มี (retrofit) |
| 3 (4+ ปี)  | นาแปลงใหญ่: ปักดำ RTK + เกี่ยวนวด yield map ครบวงจร                   | บริการ "เพาะปลูกแม่นยำครบเซ็ต" (หยอด+ปุ๋ย+ข้อมูล)              |

### 8.2 กฎการตัดสินใจ 5 ข้อ (จากงานวิจัยโลก+ไทย)

1. **VRS เฉพาะแปลงไม่สม่ำเสมอ** — ถ้าแปลงสม่ำเสมอ ข้าม VRS ไป (ผล $3/เอเคอร์ ไม่คุ้ม)
2. **เริ่ม VRT ที่ปุ๋ยก่อนเมล็ด** — ผลตอบแทนชัดเจนกว่าและข้อมูลน้อยกว่า
3. **คุณค่าอยู่ที่ข้อมูล** ($12.83 vs $0.15/เฮกตาร์) — ลงทุนเก็บ yield/ดินก่อนซื้อเครื่อง
4. **Calibrate ก่อนทำงาน** — as-planted map หลอกได้ (lag 3.8–7.7 ม.)
5. **สินเชื่อ/ส่งเสริม** — งานสุรินทร์: ความรู้+ทัศนคติขับเคลื่อนการยอมรับมากกว่าตัวเครื่อง

## 9. ความท้าทาย

| ความท้าทาย              | รายละเอียด                                                               |
| ----------------------- | ------------------------------------------------------------------------ |
| **ผลตอบแทน "เล็ก"**     | VRS $3–13/เอเคอร์ — ไม่ดึงดูดฟาร์มเล็กไทย (ไร่ละ ~$60–100 กำไร)          |
| **ข้อมูลรายจุดขาด**     | ไทยไม่มี yield map ระดับแปลงใหญ่ — VRT ติดโซนหยาบ                        |
| **เครื่อง auto ยังแพง** | YR8D ราคา ¥3.9–5.5M (~9–13 แสนบาท) เฉพาะญี่ปุ่น                          |
| **ตลาดผลผลิตไม่รองรับ** | นาข้าวเส้นตรงจากเครื่องหยอด ราคาขาย/ความเคยชินโรงสี                      |
| **เมล็ดพันธุ์**         | ข้าวไทยใช้เมล็ดขยายเอง (ไม่ได้ seed-coated/standardized) — หยอดแม่นยำยาก |
| **โครงสร้างแปลง**       | 65.4% <20 ไร่ — รับจ้างหยอด/ดำนาจึงเป็นโมเดลเดียวที่ทำงาน                |

## 10. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **Active Vacuum Automation → มาตรฐานอุตสาหกรรม**: ปรับพารามิเตอร์เองแบบ real-time จะลงมาสู่เครื่องระดับกลาง (เช่นเดียวกับ downforce auto ที่กลายเป็นมาตรฐาน)
2. **Liquid Transfer Automation + ExactRate**: ปุ๋ยน้ำ VRT ในตัวเครื่อง — ลดรอบ "เติมถัง" = ลด idle time กลางฤดู
3. **As-planted data กลายเป็น "สินทรัพย์"**: ใช้ปรับ prescription ปีถัดไป + ตรวจสอบคุณภาพบริการรับจ้าง (เชื่อมด้าน 12)
4. **การปักดำ L2 เชิงพาณิชย์ในไทย**: เมื่อแรงงานดำนาหาย + ค่าแรงรับจ้างสูง → รุ่น auto ถูกกว่าแรงงาน (จับตา Siam Kubota/Yanmar หลัง DRH1200A เกี่ยวนวด L2 เข้าตลาด)
5. **เครื่องหยอดข้าวไทยเชิงพาณิชย์**: จากงาน AIT/จุฬา (สิทธิบัตร 3 ฉบับ) → หาพันธมิตรผู้ผลิต — ตัวเลือกนอกจากนาดำ/นาหว่าน
6. **VRT ราคาจับต้องได้**: ชุด Arduino-class + เซนเซอร์ราคาถูก (งาน TSAEJ 2568) กลายเป็นผลิตภัณฑ์ retrofit สำหรับผู้รับจ้าง
7. **ML กำหนดโซน**: การแบ่งโซน VRS ด้วย ML (Agron. J. 2026) ลดการพึ่งนักวิชาการ — แต่ต้องพิสูจน์กับข้อมูลไทย (ดิน/น้ำฝนต่างจาก Corn Belt)
