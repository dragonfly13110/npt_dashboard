# 07 | เครื่องหยอดและเพาะปลูกแม่นยำ (Precision Planting & Seeding)

**สถานะ: ✅ เจาะลึกแล้ว** — ดู [เจาะลึก-07-เครื่องหยอดและเพาะปลูกแม่นยำ.md](เจาะลึก-07-เครื่องหยอดและเพาะปลูกแม่นยำ.md)

## ขอบเขต

เครื่องหยอดแม่นยำ (seed singulation) การปรับอัตราเมล็ด/ปุ๋ยแบบ VRT ระบบตรวจการเพาะ (SeedStar) การเลี้ยวหัวแถวอัตโนมัติ และเครื่องดำนา/ย้ายกล้าอัตโนมัติ

## หัวข้อที่จะเจาะลึก

- John Deere 2026 planter tech: Seed-Level/Fertilizer-Level Sensing, Active Vacuum Automation
- Seed singulation: เทคโนโลยีลด skips/doubles, เมล็ดต่อความยาวแถว (population)
- AutoPath/AutoTrac Turn Automation: การเลี้ยวอัตโนมัติ, การวางแผนเส้นทาง
- VRT เมล็ด/ปุ๋ย: 26% ของมูลค่า precision ag, การสร้าง prescription map
- เครื่องดำนาอัตโนมัติ (Kubota/Yanmar/ISEKI): สถานะในไทย, ราคา/บริการรับจ้าง
- เครื่องหยอดข้าวโพด/อ้อย: เทคโนโลยีจากสหรัฐฯ/ยุโรป vs ท้องถิ่น
- เทคโนโลยีใหม่: ย้ายกล้าด้วยหุ่นยนต์, seed coating + เซนเซอร์
- โอกาสไทย: นาหว่าน, ข้าวโพดพลังงาน, อ้อย
