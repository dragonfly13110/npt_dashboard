## 1. หลักการและขอบเขต

รถแทรกเตอร์อัตโนมัติ (Autonomous Tractor) หมายถึงรถแทรกเตอร์ที่สามารถทำงานในแปลงได้โดยไม่มีคนนั่งบังคับ โดยใช้ชุดเซนเซอร์ (กล้อง เรดาร์ LiDAR GNSS) ตรวจจับสิ่งกีดขวางและนำทางตามแผนที่ที่กำหนดไว้ล่วงหน้า และระบบนำทางอัตโนมัติ (Auto-Steer) คือการบังคับเลี้ยวด้วย GNSS/RTK ให้เครื่องจักรวิ่งตรงตามแนวเส้นคงที่โดยคนขับไม่ต้องจับพวงมาลัย — นี่คือ "บันไดขั้นแรก" สู่รถอัตโนมัติเต็มรูปแบบ และเป็นจุดเริ่มต้นการยอมรับเทคโนโลยีของเกษตรกรจำนวนมาก

ความเข้าใจสำคัญ 2 ประการ:

1. **อัตโนมัติ ≠ ไร้คน**: รถแทรกเตอร์อัตโนมัติในเชิงพาณิชย์ส่วนใหญ่ (2026) ยังเป็น "กึ่งอัตโนมัติ" — มีคนขับในที่นั่งเพื่อความปลอดภัยทางกฎหมาย แต่ระบบบังคับเลี้ยว/การทำงานหลักเป็นของเครื่อง รถ "ไร้คนนั่งจริง" (Level 4-5) เริ่มใช้เชิงพาณิชย์เฉพาะงานไถพรวน (tillage) ในสหรัฐฯ [36][37]
2. **เส้นทางสู่ความอัตโนมัติเป็นเส้นทางสะสม**: เทคโนโลยีที่ผู้ใช้ยอมรับแล้ว เช่น AutoTrac, AutoPath, Operations Center, StarFire 7500 คือ "ครึ่งทางของรถอัตโนมัติ" — ผู้ใช้ที่คุ้นเคยระบบเหล่านี้พร้อมอัปเกรดสู่ autonomy มากที่สุด [35][37]

ประโยชน์หลักในเอกสารการตลาดและงานวิจัย: ขยายเวลาทำงาน (ทำงานกลางคืน/ฝุ่น/ฝนเบา), ลดแรงงาน (โดยเฉพาะงานเก็บเกี่ยว/ไถที่หาคนยาก), เพิ่มความสม่ำเสมอของแนวแถว (ส่งผลต่อผลผลิต), และลดต้นทุนค่าแรงต่อเอเคอร์ [36][37][2]

## 2. ระดับของอัตโนมัติและคำนิยาม

การแบ่งระดับในอุตสาหกรรมเกษตรยังไม่เป็นเอกภาพ ใช้ร่วมกันได้ 2 ระบบ:

| ระดับ | SAE (ยานยนต์)  | การเกษตร (เทียบเคียง)                          | ตัวอย่างจริง                                         |
| ----- | -------------- | ---------------------------------------------- | ---------------------------------------------------- |
| 0     | ไม่มีอัตโนมัติ | คันบังคับกลไก                                  | รถแทรกเตอร์ทั่วไป                                    |
| 1     | Assisted       | Auto-steer (คนนั่ง, ระบบเลี้ยว)                | Topcon/Trimble kits, StarFire + AutoTrac             |
| 2     | Partial        | Auto-steer + เทิร์นอัตโนมัติ (Turn Automation) | AutoTrac Turn Automation (2023+)                     |
| 3     | Conditional    | ทำงานเองในแปลงแต่มีคนเฝ้า                      | Semi-autonomous (คนนั่ง)                             |
| 4     | High           | ไร้คนนั่งในพื้นที่ปิด (autonomous zone)        | Deere 8R autonomy (งานไถ), Kubota AgriRobo (ญี่ปุ่น) |
| 5     | Full           | ทุกงาน/ทุกพื้นที่ ไม่มีมนุษย์                  | ยังไม่มีเชิงพาณิชย์                                  |

**ข้อสังเกตสำคัญจากตัวเลขตลาด**: การแบ่งตลาดแบบ Driverless vs Driver-assisted ชี้ว่า **semi-autonomous (ระดับ 1–3) ครองสัดส่วนหลักราว 68%** ของมูลค่าตลาดรถแทรกเตอร์อัตโนมัติ-กึ่งอัตโนมัติทั่วโลก (ดูหัวข้อ 8) — ระบบไร้คนนั่งจริงเป็นตลาดเฉพาะ (niche) ยังไม่ใช่กระแสหลัก [8][46]

## 3. สถาปัตยกรรมระบบรถแทรกเตอร์อัตโนมัติ

ใช้กรณี John Deere 8R (รถ autonomy เชิงพาณิชย์คันแรกของโลก เปิดขายปลายปี 2022, ขยายเป็น 8R/8RX/9R/9RX 2025–26) เป็นแบบ [35][36][37]:

### 3.1 ชั้นรับรู้ (Perception Layer)

| ส่วนประกอบ                  | รายละเอียด                                                                  |
| --------------------------- | --------------------------------------------------------------------------- |
| **กล้อง 360° จำนวน 16 ตัว** | ครอบบนหลังคา เห็นรอบคันรถและเครื่องมือ ใช้ triangulate ระยะห่างสิ่งกีดขวาง  |
| **โพรเซสเซอร์ความเร็วสูง**  | ประเมินทุก pixel ของทุกภาพแบบ real-time                                     |
| **Neural Network (AI)**     | จำแนกภาพตัดสินใจว่า "พื้นปลอดภัยหรือไม่" ใน ~100 มิลลิวินาที                |
| **StarFire 7500 receiver**  | GNSS + SF-RTK ความแม่นยำ ±1–2 ซม. ใช้ทั้งบนรถและบนเครื่องมือ (ต้องมีคู่กัน) |
| **Lidar/เรดาร์ (บางรุ่น)**  | เสริมการตรวจจับในฝุ่นหนา/กลางคืน (เช่น TORION, รถญี่ปุ่น)                   |

### 3.2 ชั้นตัดสินใจ (Decision Layer)

- **Autonomous Perception System**: จำแนกวัตถุ 3 กลุ่ม — (1) สิ่งกีดขวางถาวร (รั้ว คู คันดิน เสาไฟฟ้า) → หยุดหรือเปลี่ยนเส้นทาง (2) วัตถุขนาดเล็กชั่วคราว (ถุงพลาสติก กระป๋อง สัตว์เล็ก) → ไม่แจ้งเตือน (3) ความผิดปกติ/จำแนกไม่ได้ → **หยุดรถทันทีและส่งแจ้งเตือนเข้าแอป** (Fail-safe = ทางเลือกเริ่มต้นเสมอ) [35][36]
- **Vehicle Autonomy Domain Controller**: ศูนย์ควบคุมงานอัตโนมัติของรถ (เปิดเมื่อสั่งงานผ่านแอป)
- **G5Plus CommandCenter™**: จอที่ใช้ทั้งโหมดคนขับ (ภายในห้องโดยสาร) และโหมดอัตโนมัติ
- **TruSet™**: ควบคุมการปรับจูนเครื่องมือระยะไกล (ความลึกไถ ฯลฯ)

### 3.3 ชั้นปฏิบัติการและสื่อสาร (Operation & Connectivity)

- **John Deere Operations Center**: แพลตฟอร์มวางแผน — กำหนดแปลง เส้นทาง แผนงาน (job) แบบ edge-to-edge เลี้ยวหัวแถวอัตโนมัติ และส่งไปยังรถจากบ้านก่อนเข้าทุ่งได้
- **JDLink™ Boost (เสียเงินเพิ่ม)**: สื่อสารผ่านดาวเทียม/เซลลูลาร์ ในพื้นที่สัญญาณไม่ดี — ทำงานต่อเนื่องแบบเรียลไทม์
- **พิธีเปิด-ปิดความปลอดภัย**: ผู้ปฏิบัติงานต้องอยู่ในรัศมี 1,500 ฟุต (ราว 457 ม.) ถึงจะสั่งสตาร์ทได้; เมื่อสตาร์ทรถ จะมีเสียงแตร + ไฟกระพริบเป็นลำดับเตือนก่อนเคลื่อนที่ [37]

### 3.4 สภาพการทำงานที่ระบบรองรับ

- กลางคืน ฝุ่นละอองหนา ฝนตกเบา — ทำงานได้ (ทดสอบฝุ่นได้ดี) แต่ถ้าน้ำเกาะเลนส์กล้องมากพอ ระบบหยุดเอง
- ขณะนี้รองรับงานไถพรวน (tillage) เป็นหลัก: CC Series Coulter Chisels, 2430 Chisel Plow, 2230FH Field Cultivator, HSD High-Speed Disks, 2730 Combination Ripper, 2660VT Vertical Tillage — "Autonomy Ready" เป็นอุปกรณ์มาตรฐานในเครื่องมือชุดนี้ [35]
- เป้าหมายถัดไปของ Deere: ขยายสู่การหยอด การพ่น จนถึงเก็บเกี่ยว (ดูหัวข้อ 13)

## 4. ระบบนำทางอัตโนมัติ (Auto-Steer / Guidance)

### 4.1 เทคโนโลยีพื้นฐาน

| องค์ประกอบ                                     | หน้าที่                                                                                   |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **GNSS receiver**                              | รับสัญญาณดาวเทียมหลายระบบ (GPS+GLONASS+BeiDou+Galileo)                                    |
| **RTK correction**                             | สัญญาณแก้ไขความคลาดเคลื่อนจากสถานีฐาน/เครือข่าย → ความแม่นยำ ±2 ซม. (แบบเดียว ±30–50 ซม.) |
| **IMU (Inertial Measurement Unit)**            | วัดความเอียง/อัตราเร่ง — กันการลื่นไถลและทำงานบนพื้นที่ลาดเอียง                           |
| **Steering actuator (พวงมาลัยไฟฟ้า/ไฮดรอลิก)** | บังคับเลี้ยวตามคำสั่ง ±90° (hydraulic: FJDynamics AH1, ระบบ OEM)                          |
| **จอแสดงผล + ซอฟต์แวร์นำทาง**                  | แสดงแนววิ่ง แผนที่ ผลการวิเคราะห์                                                         |

### 4.2 ระดับความแม่นยำ

| ระดับ                           | ราคา (USD)    | ความแม่นยำ | การใช้งาน                             |
| ------------------------------- | ------------- | ---------- | ------------------------------------- |
| Entry GPS guidance (ไม่ใช่ RTK) | ~500–2,000    | 20–50 ซม.  | งานกว้าง (ไถ) ประหยัดน้ำมัน           |
| RTK มาตรฐาน                     | 3,000–8,000   | ±2.5 ซม.   | งาน row-crop: หยอด พ่น เก็บเกี่ยว     |
| RTK แบบหลาย constellation + IMU | 8,000–12,000+ | ±1 ซม.     | งานต้องการความแม่นยำสูงสุด / autonomy |

### 4.3 ประโยชน์ที่วัดได้

- ลดการซ้ำของแนว (overlap) ในการพ่น/หว่านปุ๋ย: ประหยัดค่าเมล็ด/สารเคมี 5–15%
- ขยายชั่วโมงทำงาน: ทำงานกลางคืน/หมอกได้ (คนบังคับเลี้ยวเห็นแนวไม่ชัด)
- เพิ่มความเร็วทำงาน (วิ่งตามแนวได้เร็วขึ้น) และลดความเหนื่อยล้าคนขับ
- เป็น "รากฐานบังคับ" ของรถอัตโนมัติ: งานวิจัยตลาดชี้ว่า RTK auto-steer คือ "transition to autonomous-ready steering platforms" [46]

### 4.4 แนวโน้มเทคโนโลยี

- **OEM-integrated ชนะ aftermarket**: ระบบติดตั้งจากโรงงานคาดครอง 55–60% ของการขายใหม่ในไทยภายใน 2035 (และ >60% ทั่วโลกภายใน 2031) [42][46]
- **ราคาลดลงแต่รายได้บริการเพิ่ม**: ราคาระบบมาตรฐานลดจริง 10–15% (2035) แต่รายได้จาก correction service + data analytics + OTA update จะเป็น 30–35% ของรายได้ซัพพลายเออร์ภายใน 2035 [46]
- **Swarm/ฝูง**: ผู้ควบคุม 1 คนดูแลรถหลายคัน — ต้องการ auto-steer ที่ sync กันได้ทุกระดับ

## 5. ผู้เล่นและผลิตภัณฑ์หลัก

### 5.1 John Deere — ผู้นำเชิงพาณิชย์ (ตลาดอเมริกาเหนือ)

| รายการ     | รายละเอียด                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ผลิตภัณฑ์  | Fully Autonomous 8R (2022) → ขยาย 8R/8RX/9R/9RX (2025+) + Autonomy Precision Upgrade (ชุดติดตั้งหลังขายสำหรับรถรุ่น 2020 ขึ้นไป) |
| งานแรก     | ไถพรวน (tillage) — ค่อย ๆ ขยายสู่การเพาะปลูกทั้งหมด                                                                              |
| ช่องทางขาย | ผ่านดีลเลอร์; พรีออเดอร์เปิดปลายปี 2025; สมาชิกมี "Autonomy Ready" ในรุ่น 2020+ เป็นฐาน                                          |
| กลยุทธ์    | Autonomy-as-a-Service (เก็บค่าใช้จ่ายต่อเอเคอร์) + ขายข้อมูล/ซอฟต์แวร์ (เป้า software revenue 10% ภายใน 2030)                    |

### 5.2 Kubota + Agtonomy — เจาะสวนผลไม้/ไร่องุ่น (ต้นแบบ "autonomy เฉพาะทาง")

- **Autonomous M5 Narrow** (เปิดตัว CES 2026, เชิงพาณิชย์แล้ว): รถดีเซล 105.7 แรงม้า ติดตั้งระบบอัตโนมัติจากโรงงาน (factory-integrated) ทำงานหลัก: ตัดหญ้าและพ่นสารตามแนวแถวในไร่องุ่น/สวนผลไม้
- **Agtonomy** (Mooco Robotics, ก่อตั้ง 2021, CEO Tim Bucher): ซอฟต์แวร์/แพลตฟอร์ม autonomy สร้างขึ้นบนรถ OEM แบรนด์เดิม ("embed physical AI into trusted machines") — มีการลงทุนรอบ Series B $18M (2025) และ **Kubota เข้าลงทุนเม.ย. 2026** [38][39][40][41]
- จุดขาย: ไม่ใช่ "รถหุ่นยนต์ที่ทำทุกอย่าง" แต่เป็นโซลูชันเฉพาะงาน 2–3 อย่างที่เจ็บปวดที่สุด (mowing, spraying) เริ่มจำหน่ายนำร่องฝั่งตะวันตกสหรัฐฯ ผ่านเครือข่ายดีลเลอร์ของ Kubota; ขยายสู่ฝั่งตะวันออกเฉียงใต้สหรัฐฯ + ออสเตรเลีย
- บทเรียนจากการทำตลาด: โปรแกรม "shared tractor" ในญี่ปุ่นพบว่าอุปสรรคใหญ่ไม่ใช่เครื่องจักรแต่เป็น **ความยากของการใช้แอปบนสมาร์ทโฟน** ของเกษตรกรวัย 60–70 — ผู้ขายต้องออกแบบ UX ให้เรียบง่าย (กรณีศึกษา World Ag Expo 2026) [41]
- **KVPR Transformer robot** (คอนเซปต์ CES 2026): แพลตฟอร์มเปลี่ยนรูปได้ ยก/ขยาย/หดได้ตามแกน เปลี่ยนเครื่องมือได้หลายชนิด — "วิสัยทัศน์ระยะยาว" หลังคนเริ่มเชื่อถือ autonomy บนรถแบบเดิม

### 5.3 ค่ายญี่ปุ่นอื่น

## 6. บทเรียน Monarch MK-V: ความจริง vs การตลาด

**Monarch Tractor** (สหรัฐฯ) สตาร์ทอัป EV tractor อ้าง "world's first driver-optional electric tractor" — ระดมทุนสูง (รวมรอบ $133M), รถผลิตจริง (ฐานติดตั้ง ~600+ คัน) แต่ล้มละลาย เม.ย. 2026 ทรัพย์สินตกเป็นของ Caterpillar [5][6]

| ปัจจัย                                                        | รายละเอียด                                                                                                                                                                                       |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ผลิตภัณฑ์                                                     | MK-V 70 แรงม้า, PTO 40 แรงม้า, แบต 14+ ชั่วโมง (ข้อมูลโฆษณา), ชาร์จ J1772 มาตรฐาน; รับประกันรถ 4 ปี/4,000 ชม. แบต 8 ปี/8,000 ชม.; WingspanAI (ฟลีท/telematics)                                   |
| บทเรียนที่ 1: ขาย "autonomy" แต่ลูกค้าซื้อ "EV/ประหยัดน้ำมัน" | รถส่วนใหญ่ถูกซื้อแบบมีคนขับ — โหมดไร้คนเป็นตัวเลือกน้อย; ตลาด autonomy ยังต้องการการพิสูจน์ความน่าเชื่อถือในงานจริง (ฟาร์มไวน์ในแคลิฟอร์เนียเป็นลูกค้าหลัก)                                      |
| บทเรียนที่ 2: การเปลี่ยนแบต/ค่าบริการ                         | โมเดล subscription + แบตเปลี่ยนทดแทน — ต้นทุนการเป็นเจ้าของยังไม่ชัดพอแข่งกับดีเซล                                                                                                               |
| บทเรียนที่ 3: ความยั่งยืนของสตาร์ทอัป                         | รายได้จากฮาร์ดแวร์อย่างเดียวไม่พอรองรับ R&D — ต้องมี recurring revenue (บริการ/ข้อมูล) ตั้งแต่วันแรก                                                                                             |
| ผลต่ออุตสาหกรรม                                               | Caterpillar ได้เทคโนโลยี EV tractor + ฝูงรถติดตั้ง → ใช้วางตำแหน่งเครื่องจักรพลังงานทางเลือก (ดูด้าน 05); ตลาด autonomy ต้องปรับความคาดหวัง: "driver-optional" ≠ autonomy-ready เชิงพาณิชย์ทันที |

**ข้อสรุปเชิงปฏิบัติ**: รถอัตโนมัติที่ขายจริงในวันนี้คือ 1) รถ OEM ใหญ่ (Deere) ผ่าน AaaS, 2) รถเฉพาะงานในสวนผลไม้ (Kubota/Agtonomy), 3) รถเล็กในญี่ปุ่น — ยังไม่มีใครทำตลาด "รถอัตโนมัติสำหรับฟาร์มทั่วไป" สำเร็จแบบ mass-market [6][41]

## 7. Autonomy-as-a-Service และโมเดลธุรกิจ

### 7.1 โมเดลการคิดเงิน

| โมเดล                                | ตัวอย่าง                                                               | จุดเด่น                                     |
| ------------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------- |
| **ต่อเอเคอร์ (per-acre)**            | Deere: ~$14–18/เอเคอร์ (ไถ); บริษัท 3P เริ่มใช้ (Deere/Monarch/Bonsai) | จ่ายตามงานทำจริง ไม่ต้องซื้อรถ              |
| **ต่อชั่วโมง/ต่องาน (per-hour/job)** | บริการรับจ้าง autonomy (Moscow/Russia, Australia)                      | คล้ายบริการรับจ้างไถแบบเดิม                 |
| **Subscription ซอฟต์แวร์**           | JDLink Boost, WingspanAI, Operations Center Pro                        | รายได้ประจำของ OEM                          |
| **Rental/เช่าลองใช้**                | Agtonomy rental program                                                | ลดความเสี่ยงผู้ซื้อรายแรก (TAM ของสวนผลไม้) |

### 7.2 ตัวเลขที่เห็นจากตลาด (2026)

- พื้นที่ทำงานจริงระดับ Level-4 (ไร้คน): **~1.04 ล้านเอเคอร์** ครอบคลุม Deere + Monarch + Bonsai (นำร่องหลักที่สหรัฐฯ) [2]
- สัญญา AaaS: ~410 สัญญา Q1 2026, รายได้ประจำต่อปี (ARR) ~$90M+ — เติบโตหลักจาก Deere [2]
- การประหยัดที่อ้าง: แรงงานไถ -80%, เวลางาน +40% (ทำงานกลางคืน), ต้นทุนต่อเอเคอร์ลด 10–20% (คำนวณจากค่าแรง + เชื้อเพลิงที่ลดลง)

### 7.3 ทำไม AaaS สำคัญต่อผู้เล่นรายใหญ่

- สร้างรายได้ประจำ (recurring) ลดความผันผวนของวงจรขายรถ (Deere ตั้งเป้า software/บริการ = 10% ของรายได้ภายใน 2030)
- ลดกำแพงราคาให้ฟาร์มเล็กเข้าใช้ได้ (จ่ายตามงาน ไม่ต้องกู้ซื้อรถ $500K+)
- เป็น "แพลตฟอร์มบังคับ" (platform play): เจ้าของซอฟต์แวร์เป็นเจ้าของข้อมูลแปลง ตั้งมาตรฐานฝูงรถข้ามแบรนด์ — การแข่งขัน $13B "platform war" ระหว่าง Deere/AGCO/Kubota/CNH กำลังเกิดขึ้น [1]

## 9. ความปลอดภัยและมาตรฐาน ISO 18497

**ISO 18497:2024** — มาตรฐานสากลชุดแรกว่าด้วยความปลอดภัยเครื่องจักรกลการเกษตรแบบ partially automated / semi-autonomous / autonomous แบ่ง 4 ส่วน (เผยแพร่ ก.ค. 2024):

| ส่วน                                                            | เนื้อหา                                                                                                                                                         |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Part 1: หลักการออกแบบเครื่องจักรและคำศัพท์**                  | หลักการออกแบบเพื่อความปลอดภัย การระบุอันตราย (hazard identification) แนวปฏิบัติการใช้งานอย่างปลอดภัย ข้อมูล residual risks ที่ผู้ผลิตต้องแจ้ง                   |
| **Part 2: หลักการออกแบบระบบป้องกันสิ่งกีดขวาง**                 | การตรวจจับสิ่งกีดขวาง — perception/supervisory systems; ข้อกำหนดสัญญาณ (ไฟกระพริบ ≤125 ครั้ง/นาที สีขาว/น้ำเงิน-เขียว/เหลืองอำพัน; เสียงแจ้งเตือนจังหวะต่างกัน) |
| **Part 3: เขตปฏิบัติการอัตโนมัติ (Autonomous Operating Zones)** | การป้องกันรถหลุดออกนอกเขตที่กำหนด (ขอบเขตทางกายภาพ/เสมือน ระบบ supervisory)                                                                                     |
| **Part 4: วิธีตรวจสอบและการทวนสอบ (Verification/Validation)**   | หลักการตรวจสอบความปลอดภัยของระบบ                                                                                                                                |

**มาตรฐานที่เกี่ยวข้อง**: ISO 25119 (functional safety เครื่องจักรเกษตร), Australian Code of Practice (กรอบรวม: การขนส่งระหว่างแปลง, การบำรุงรักษา, การจัดการฉุกเฉิน — ต้องหยุด/แยกเขต)

**แนวปฏิบัติจาก Deere**: ผู้ควบคุมต้องอยู่ในรัศมี 1,500 ฟุตตอนสตาร์ท; "หยุด + แจ้งเตือน" เมื่อจำแนกไม่ได้; สัญญาณไฟ/เสียงก่อนเคลื่อนที่ — สอดคล้องกับหลักของ ISO 18497-2/3 [37][47]

**ผลต่อการยอมรับในไทย**: ยังไม่มีกฎหมายเฉพาะ; กรมพัฒนาที่ดิน/กรมวิชาการเกษตรใช้แนวปฏิบัติ ISO 18497 อ้างอิงในโครงการนำร่อง; จุดอ่อนคือผู้ใช้ต้องเข้าใจ "residual risk" (ความเสี่ยงที่เหลืออยู่) ว่าผู้ผลิตไม่รับผิดชอบ — ต้องมีแผนเผชิญเหตุ (หยุดเขต + สัญญาณ)

## 10. สถานการณ์ประเทศไทย

### 10.1 ภาพรวมการยอมรับเทคโนโลยี

- **ฐาน**: กองรถแทรกเตอร์ไทย ~300,000–350,000 คัน (รวม 4WD ใหญ่ + 2WD กลาง + ญี่ปุ่นเล็ก); 71.3% ของครัวเรือนเกษตรใช้เครื่องจักร; ภาคอีสานใช้สูงสุด 80% (ข้อมูลจากภาพรวม [7])
- **RTK auto-steer**: penetration ต่ำมาก (~1.5–2% ของกองรถ) แต่ตลาดโต 8–12%/ปี; ผู้ใช้หลักคือแปลงอ้อย/มันสำปะหลัง/ข้าวโพด/ยางรายใหญ่ในภาคกลางและอีสาน [42]
- **สัดส่วนรถ "smart-enabled"** (มี telematics/นำทางจากโรงงาน): 11% → 25.5% ภายในช่วงพยากรณ์ (KenResearch) [7]

### 10.2 โครงสร้างพื้นฐาน RTK ในไทย

- **กรมพัฒนาที่ดิน**: นำร่องเครือข่าย RTK สาธารณะ 10 จังหวัด (ขยายทั้งประเทศในแผนฯ 13) — เป็นตัวแปรสำคัญที่ทำให้ราคาเข้าถึงของระบบนำทางลดลง
- **Smart Farming 4.0 / แผนฯ 12–13**: โครงการเงินสนับสนุน/ร่วมลงทุน (co-investment) กับผู้ผลิต (Siam Kubota, Yanmar S.P. ฯลฯ) และสหกรณ์/วิสาหกิจชุมชน
- **ผู้ให้บริการ correction เชิงพาณิชย์**: Trimble/TOPCON/Leica ผ่านดีลเลอร์ในประเทศ; RTX/OmniSTAR แบบ satellite-based (ไม่ต้องมีสถานีฐาน)

### 10.3 ช่องว่างและโอกาส

| ช่องว่าง                                                                                      | โอกาส                                                                                 |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| penetration ต่ำกว่า 2% vs ระดับสหรัฐฯ 25%+ / บราซิล-ออสเตรเลีย 8–12% (ฟาร์มโครงสร้างคล้ายไทย) | ตลาดเปลี่ยนผ่าน 8K–12K ระบบใน 10 ปี (สะสม) [42]                                       |
| ราคาชุด RTK ยังสูงเทียบรายได้ฟาร์ม 65.4% ถือครอง <20 ไร่                                      | โมเดล "บริการรับจ้างระบบนำทาง" โดยสหกรณ์/กลุ่มวิสาหกิจ (เชื่อมด้าน 12)                |
| รถ autonomy เต็มรูปแบบราคาแพง ไม่เหมาะไทย                                                     | ขั้นแรก: auto-steer + เกี่ยวนวดอัตโนมัติ + เทเลเมติกส์ — ใช้กับงานอ้อย/มันที่แปลงใหญ่ |
| แรงงานไถ/เก็บเกี่ยวขาดแคลนภาคอีสาน/เหนือ                                                      | เทคโนโลยี "ไร้คนควบคุมขั้นสูง" (remote monitoring) บนเกี่ยวนวด/รถไถ 6 หมื่นไร่        |

### 10.4 บทเรียนเชิงนโยบาย

- ญี่ปุ่น: semi-autonomous + remote monitoring ชนะ autonomy เต็มรูปแบบในนาเล็ก — ไทยควรตามแนวนี้ก่อน
- จีน: รัฐผลักดันผ่านฟาร์มจัดตั้งขนาดใหญ่ + บริษัทในประเทศ (ราคาต่ำกว่า OEM ตะวันตก 30–50%) — ไทยควรเปิดรับและทดสอบระบบจีนในแปลงนำร่อง
- การรับรอง/มาตรฐาน: ควรออกหลักเกณฑ์ Thai National Annex ต่อ ISO 18497 + แผนทดสอบแปลงจริงร่วมมหาวิทยาลัย (กำแพงเพชร/ขอนแก่น/แม่โจ้) ก่อนส่งเสริมในวงกว้าง

## 11. แนวทางนำไปใช้สำหรับฟาร์มไทย

### 11.1 Blueprint 3 ขั้น (เหมาะฟาร์ม 100–2,000 ไร่)

1. **ขั้นนำทาง (ปี 1–2)**: ติดตั้ง RTK auto-steer บนรถที่มีอยู่ (ชุด $3,000–8,000) + จัดการลด overlap → คืนทุน 1–3 ปีจากเมล็ด/ปุ๋ย/น้ำมันที่ประหยัด
   - เลือก: ระบบ OEM (Topcon/Trimble/พาหุ้นดีลเลอร์) หรือ e-commerce kit (FJDynamics ฯลฯ) — ตรวจสอบบริการหลังขายก่อน
2. **ขั้นข้อมูล (ปี 2–3)**: ต่อเชื่อม telematics + แผนที่ผลผลิต (yield map) → เริ่มทำ prescription map (ด้าน 04/07)
3. **ขั้นอัตโนมัติเฉพาะงาน (ปี 3–5)**: นำร่อง "remote monitoring" กับงานไถ/เกี่ยวนวดแปลงใหญ่ (รถมีคนนั่งตอนนี้, ควบคุม/ติดตามระยะไกล) → ประเมิน AaaS จากผู้ให้บริการไทย (รับจ้างไถอัตโนมัติ) ก่อนซื้อรถอัตโนมัติ

### 11.2 ปัจจัยความสำเร็จ

- **เริ่มจากงานที่เจ็บปวดที่สุด**: ไถ/ไถคราดกลางคืน เกี่ยวนวดกลางคืน — ขยายเวลาทำงานคือกำไรทันที
- **โครงข่าย RTK ต้องพร้อม**: ตรวจสอบความคุ้มครองก่อนซื้อชุด RTK (อาจต้องเช่าอินเทอร์เน็ต/สถานีฐานของเอกชน)
- **อบรมผู้ใช้งาน**: บทเรียน Kubota ญี่ปุ่น — แอปยาก = ไม่ใช้; ต้องมี "เจ้าหน้าที่ส่งเสริม" ประจำพื้นที่
- **รวมกลุ่ม**: แปลงเล็ก (<20 ไร่) ควรใช้บริการรับจ้าง/กลุ่มวิสาหกิจ มากกว่าซื้อระบบเอง (เชื่อมด้าน 12)

## 12. ความท้าทาย

| ความท้าทาย                   | รายละเอียด                                                                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **ราคา vs ผลตอบแทน**         | รถ autonomy ใหม่ >$500K; ฟาร์มส่วนใหญ่ยังไม่เห็น ROI กับงานไถเพียงอย่างเดียว — AaaS เป็นคำตอบชั่วคราว                                  |
| **การยอมรับ/ความไว้ใจ**      | เกษตรกรยังไม่ไว้ใจระบบไร้คนในงานเก็บเกี่ยว/ใกล้ผู้คน; ต้องผ่านประสบการณ์ขั้นบันได (auto-steer → turn automation → remote)              |
| **กฎหมาย/ความรับผิด**        | ISO 18497 ยังเป็น voluntary; ประเทศยังไม่มีกฎหมาย "ถ้าไม่มีคนนั่งแล้วเกิดอุบัติเหตุใครรับผิด"; ความต้องการ monitor ระยะไกลเพิ่มภาระ    |
| **โครงสร้างพื้นฐาน**         | ไทย: RTN สาธารณะยัง 10 จังหวัด; สัญญาณอินเทอร์เน็ต/4G ในแปลงไม่ทั่วถึง (ต้อง JDLink Boost แบบ satcom)                                  |
| **ข้อมูลและความเป็นเจ้าของ** | รถอัตโนมัติเก็บข้อมูลแปลงทั้งหมด — เกษตรกรอาจสูญเสียอำนาจต่อรองราคาที่ดิน/ค่าเช่า; ประเด็น right-to-repair ถูกบีบ                      |
| **ฝุ่น/สภาพอากาศเขตร้อน**    | ฝุ่นละออง ละอองฝน/ความชื้นสูง อุณหภูมิ 35°C+ — การทดสอบของ OEM อยู่สภาพอบอุ่น; ต้องทดสอบในไทยจริง                                      |
| **การหลอกขาย (overpromise)** | กรณี Monarch: "driver-optional" ที่ขายจริงเป็นแค่ EV — ผู้ซื้อต้องถามเจาะลึก: ความครอบคลุมงาน, การรับประกัน performance, ค่าใช้จ่ายแฝง |

## 13. แนวโน้มและงานวิจัยที่ควรติดตาม

1. **Deere ขยาย autonomy ไปทุกงาน**: เป้าหมายประกาศ — จาก tillage สู่ planting → spraying → harvesting ภายใน 2030–2033; "Autonomy Precision Upgrade" ทำตลาด retrofit ให้รถ 2020+ [36]
2. **Platform war $13B**: แข่งซอฟต์แวร์/ข้อมูลระหว่าง Deere, AGCO (PTx Trimble), CNH, Kubota — ผู้ชนะคือเจ้าของ "ฟลีท OS" [1]
3. **หุ่นยนต์แบบฝูง/หลายคัน**: Fendt Xaver, Kubota KVPR, NEXAT — "รถหนึ่งคัน" เริ่มกลายเป็น "แพลตฟอร์ม + อุปกรณ์พ่วง"
4. **Agtonomy เติบโตข้ามทวีป**: Series B $18M + Kubota investment → ขยาย US Southeast + Australia; ต้นแบบ "autonomy เป็นบริการผ่านดีลเลอร์" [38][41]
5. **AI สำคัญขึ้น**: neural network จำแนก 100 ms กลายเป็นสเปกมาตรฐาน; Physical AI (โมเดลที่เข้าใจแรง/สภาพแปลง) เริ่มถูกกล่าวถึงในงาน CES 2026 [3][39]
6. **มาตรฐาน RTK เป็นสินค้าพื้นฐาน**: ราคาร่วง + OEM-integrated ชนะ aftermarket → auto-steer เป็น "option มาตรฐาน" ของรถใหม่ทุกคันภายใน 2031 [46]

## 14. อภิธานศัพท์

| คำศัพท์                          | ความหมาย                                                              |
| -------------------------------- | --------------------------------------------------------------------- |
| **Autonomy Level (SAE 0–5)**     | ระดับความอัตโนมัติของยานยนต์ ใช้เทียบเคียงการเกษตร                    |
| **RTK (Real-Time Kinematic)**    | เทคนิคแก้สัญญาณ GNSS ด้วยสถานีฐาน/เครือข่าย ได้ความแม่นยำระดับ ±2 ซม. |
| **Auto-Steer**                   | ระบบบังคับเลี้ยวอัตโนมัติตามแนว GNSS — คนนั่งเฝ้าตามหน้าที่           |
| **Turn Automation**              | การเลี้ยวหัวแถวอัตโนมัติ — ปลดคนออกจากการบังคับเลี้ยวที่โค้ง          |
| **Autonomous Operating Zone**    | เขตที่กำหนดให้รถทำงานอัตโนมัติ (ISO 18497-3)                          |
| **Perception System**            | ชุดเซนเซอร์+AI รับรู้สภาพแวดล้อม (กล้อง/LiDAR/เรดาร์)                 |
| **Fail-safe**                    | หลักการ "ถ้าไม่แน่ใจ ให้หยุด" — หัวใจความปลอดภัย                      |
| **AaaS (Autonomy-as-a-Service)** | จ่ายค่าใช้ตามงาน/ตามพื้นที่ ไม่ต้องซื้อรถ                             |
| **Retrofit kit**                 | ชุดติดตั้งระบบหลังขาย บนรถที่มีอยู่                                   |
| **Prescription map**             | แผนที่การจัดการรายจุด (อัตราปุ๋ย/สาร) สร้างจากข้อมูลแปลง              |
