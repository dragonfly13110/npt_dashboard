# 16-002 | การเลือกพันธุ์และการจัดการเมล็ดพันธุ์ข้าวโพด

> **ประเภท:** คู่มือเลือกพันธุ์จากหลักฐาน | **สร้าง:** 2026-08-08 | **อัปเดตล่าสุด:** 2026-08-08 | **ทบทวน:** 2027-02-08  
> **คำสำคัญ:** ข้าวโพดไร่ ข้าวโพดข้าวเหนียว ข้าวโพดฝักสด เมล็ดพันธุ์ เสถียรภาพผลผลิต

## 1. บทสรุปสำหรับตัดสินใจ

พันธุ์ที่ให้ผลผลิตสูงในงานทดลองอาจไม่ใช่พันธุ์ที่เหมาะกับแปลงของเราเสมอไป การเลือกพันธุ์ควรเริ่มจาก **สิ่งที่จะขาย** แล้วค่อยตรวจอายุเก็บเกี่ยว ความต้องการน้ำ ความต้านทานโรค แหล่งเมล็ดพันธุ์ และต้นทุน

| เป้าหมาย                | ตัวชี้วัดหลัก                            | คำถามก่อนซื้อเมล็ด                                |
| ----------------------- | ---------------------------------------- | ------------------------------------------------- |
| เมล็ดแห้งหรืออาหารสัตว์ | ผลผลิตเมล็ด ความชื้น เปอร์เซ็นต์กะเทาะ   | ผู้รับซื้อรับความชื้นเท่าไร และมีเครื่องอบหรือไม่ |
| ฝักสด                   | ขนาดฝัก สี ความสม่ำเสมอ อายุเก็บ         | ตลาดต้องการเก็บเกี่ยววันใด และรับฝักเกรดใด        |
| ข้าวโพดข้าวเหนียว       | ความนุ่ม รสชาติ สี และอายุเก็บ           | มีผู้ซื้อหรือช่องทางขายก่อนปลูกหรือยัง            |
| ข้าวโพดต้นสดพร้อมฝัก    | ปริมาณชีวมวล ความชื้น และคุณภาพอาหารหยาบ | ฟาร์มมีแผนตัด ขน และเก็บรักษาหรือไม่              |

## 2. หลักการและขอบเขต

บทนี้ใช้ข้อมูลจากบทความ NPT เป็นแผนที่ประเด็น และใช้บทความต้นทางประกอบเมื่อมี URL เปิดได้ ไม่จัดอันดับพันธุ์เชิงพาณิชย์ทั้งหมดในตลาด และไม่รับรองชื่อพันธุ์ที่ยังตรวจเอกสารทะเบียนไม่ตรงกัน

## 3. เกณฑ์เลือกพันธุ์ 6 ด้าน

1. **ตลาด:** ผลผลิตที่ดีต้องขายได้ตามคุณภาพและวันส่งมอบ
2. **ฤดู:** พันธุ์เดียวกันอาจมีอายุและผลผลิตต่างกันในฤดูฝนกับฤดูแล้ง
3. **น้ำ:** ถ้าไม่มีน้ำสำรองให้หลีกเลี่ยงการวางแผนที่พึ่งน้ำในช่วงวิกฤตโดยไม่มีแผนเสริม
4. **ดิน:** ดูการระบายน้ำ ความแน่น และความอุดมสมบูรณ์ของแปลง ไม่ดูชื่อชุดดินอย่างเดียว
5. **โรคและแมลง:** ตรวจข้อมูลความต้านทานที่ระบุในเอกสารพันธุ์และถามแหล่งเมล็ดพันธุ์ว่าข้อมูลมาจากการทดสอบใด
6. **เมล็ดพันธุ์:** ตรวจรุ่นผลิต ฉลาก อัตราความงอก วันหมดอายุ และการเก็บรักษา

## 4. หลักฐานจากงานวิจัยนครปฐม

บทความ NPT ระบุประเด็นข้าวโพดไร่ลูกผสมก่อนการค้าที่พัฒนาโดยศูนย์วิจัยข้าวโพดและข้าวฟ่างแห่งชาติ และรายงานว่า KSX5720 กับ KSX5819 มีผลผลิตเฉลี่ยและเสถียรภาพเด่นในชุดทดสอบหลายสภาพแวดล้อม `[2]` ข้อมูลนี้เหมาะสำหรับตั้งรายชื่อพันธุ์ที่จะนำไปประเมินต่อ ไม่ควรแปลงเป็นคำสั่งให้ปลูกทุกแปลง

งานของมหาวิทยาลัยราชภัฏนครปฐมรายงาน CNW2182 เป็นข้าวโพดข้าวเหนียวลูกผสมดีเด่น โดยบทความทบทวน NPT สรุปผลผลิตฝักและอายุเก็บเกี่ยวไว้ `[1]` งานนี้เหมาะกับการออกแบบแปลงทดสอบตลาดฝักสด แต่ต้องตรวจคุณภาพฝักและความต้องการผู้ซื้อในพื้นที่จริง

### หมายเหตุเรื่องชื่อ “สุวรรณ 6480” (ตรวจสอบแล้ว 2026-08-08)

บทความ NPT ระบุ URL PDF กรมวิชาการเกษตร (AnnoDOA_Public353.pdf) เป็นแหล่งของสุวรรณ 6480 เมื่อตรวจสอบ PDF ต้นทางแล้วพบว่าประกาศฉบับนี้ครอบคลุมข้าวโพดหลายพันธุ์ ได้แก่ ข้าวโพดพันธุ์เกษตรศาสตร์ 65, 66 และ 67 และยังมีข้อมูล **สุวรรณ 6480** ข้าวโพดไร่ลูกผสมเดี่ยว (Ki 66 × Ki 67) ของมหาวิทยาลัยเกษตรศาสตร์ ร่วมกับสำนักงานพัฒนาการวิจัยการเกษตร (สวก.) `[4]` ชื่อพันธุ์นี้ยังได้รับการยืนยันจากทะเบียนประกาศขึ้นทะเบียนพันธุ์ข้าวโพด 4 ธ.ค. 2567 (กรมวิชาการเกษตร) `[5]` และข้อมูลสิทธิบัตร/อนุสิทธิบัตรข้าวโพดไร่ลูกผสมที่ได้รับอนุมัติ 26 ก.พ. 2568 (มก.) `[6]`

การปฏิบัติที่ปลอดภัยคือ

- อ่านตัวเลขและคุณสมบัติของสุวรรณ 6480 จากเอกสารทะเบียนที่ชื่อตรงกันเท่านั้น `[5]` `[6]` โดยเทียบกับฉลากและรุ่นเมล็ดพันธุ์จริง
- ไม่ใช้ตัวเลขของพันธุ์อื่นที่อยู่รวมใน PDF เดียวกันมาปนกับสุวรรณ 6480
- บันทึกชื่อพันธุ์บนถุงเมล็ดพันธุ์จริง แยกจากชื่อสายพันธุ์พ่อแม่หรือชื่อโครงการ

## 5. ตรวจเมล็ดพันธุ์ก่อนปลูก

| รายการตรวจ            | ผ่านเมื่อ                                  | หลักฐานที่เก็บ                |
| --------------------- | ------------------------------------------ | ----------------------------- |
| ชนิดและชื่อพันธุ์     | ตรงกับตลาดและเอกสารสั่งซื้อ                | รูปฉลากและใบซื้อ              |
| รุ่นผลิตและแหล่งที่มา | ตรวจสอบย้อนกลับได้                         | เลขล็อต ผู้จำหน่าย วันที่ซื้อ |
| ความงอก               | มีผลทดสอบหรือสุ่มทดสอบก่อนปลูก             | ใบบันทึกการทดสอบ              |
| ความสะอาด             | ไม่มีเมล็ดพืชอื่น เมล็ดเสีย หรือสิ่งเจือปน | ภาพตัวอย่าง                   |
| การเก็บรักษา          | ภาชนะปิด แห้ง ไม่ร้อน และไม่สัมผัสพื้น     | วันเริ่มและวันสิ้นสุดการเก็บ  |

หากเมล็ดมาจากแหล่งที่ไม่คุ้นเคย ให้ทดลองงอกในถาดหรือพื้นที่เล็กก่อนวางแผนทั้งแปลง การทดสอบนี้ช่วยแยกปัญหาเมล็ดออกจากปัญหาดินและน้ำ

## 6. ขั้นตอนเลือกพันธุ์แบบใช้งานจริง

1. เขียนปลายทางผลผลิตและวันขายให้ชัด
2. ทำรายชื่อพันธุ์ 2 ถึง 3 ตัวเลือกที่มีเอกสารและแหล่งเมล็ดพันธุ์ตรวจสอบได้
3. เทียบอายุเก็บเกี่ยวกับช่วงน้ำใช้และแรงงานของแปลง
4. ขอข้อมูลผลผลิตจากสภาพทดลองพร้อมเงื่อนไข ไม่รับเฉพาะตัวเลขโฆษณา
5. ปลูกพันธุ์หลักร่วมกับพันธุ์เปรียบเทียบในแปลงนำร่อง
6. สรุปผลจากผลผลิตขายได้ คุณภาพ และต้นทุน ไม่ใช่กิโลกรัมต่อไร่อย่างเดียว

## 7. ช่องว่างข้อมูล

- ควรมีทะเบียนข้อมูลเมล็ดพันธุ์ที่มีจำหน่ายจริงในจังหวัดนครปฐม แยกตามตลาด
- ควรเก็บข้อมูลความต้องการของผู้รับซื้อข้าวโพดข้าวเหนียวและฝักสดเป็นรายฤดู
- ควรทำแปลงเปรียบเทียบพันธุ์โดยใช้วิธีจัดการเดียวกันและชั่งผลผลิตตามมาตรฐานเดียวกัน

## 8. Blueprint แปลงสาธิต

| จุด             | วิธีทำ                                | สิ่งที่ต้องแสดงให้เกษตรกรเห็น          |
| --------------- | ------------------------------------- | -------------------------------------- |
| แปลงหลัก        | พันธุ์ที่ต้องการส่งเสริมตามหลักฐาน    | ผลผลิตและคุณภาพตามตลาด                 |
| แปลงเปรียบเทียบ | พันธุ์เดิมหรือพันธุ์ที่เกษตรกรคุ้นเคย | ความแตกต่างของต้นทุน แรงงาน และวันเก็บ |
| จุดเก็บตัวอย่าง | สุ่มจุดเดิมและใช้เครื่องชั่งเดียวกัน  | วิธีเก็บข้อมูลที่ทำซ้ำได้              |
| สรุปหลังเก็บ    | นัดผู้ซื้อหรือผู้ใช้ผลผลิตเข้าดู      | ราคาและอัตราผลผลิตขายได้               |

## 9. ข้อจำกัด

- รายชื่อสายพันธุ์ก่อนการค้าอาจไม่ใช่เมล็ดพันธุ์ที่เกษตรกรซื้อได้ในปัจจุบัน
- ชื่อพันธุ์ทางการค้า ชื่อสายพันธุ์ทดลอง และชื่อพ่อแม่พันธุ์อาจต่างกัน ต้องตรวจเอกสารให้ตรง
- ผลผลิตจากหลายสภาพแวดล้อมช่วยเห็นเสถียรภาพ แต่ไม่แทนการทดลองในแปลงเป้าหมาย

## 10. สมมติฐานสำหรับแปลงทดสอบ

1. การเลือกพันธุ์ตามตลาดทำให้สัดส่วนผลผลิตขายได้สูงกว่าการเลือกจากผลผลิตรวมเพียงอย่างเดียวหรือไม่
2. การทดสอบความงอกก่อนปลูกลดจำนวนจุดแหว่งและต้นทุนซ่อมแปลงได้เพียงใด
3. พันธุ์ที่เสถียรในหลายสภาพแวดล้อมยังรักษาคุณภาพตามตลาดนครปฐมได้หรือไม่

## 11. อภิธานศัพท์

- **พันธุ์ลูกผสม:** พันธุ์ที่เกิดจากการผสมพ่อแม่ที่คัดเลือกเพื่อรวมลักษณะเด่น
- **ความงอก:** สัดส่วนเมล็ดที่งอกเป็นต้นปกติภายใต้เงื่อนไขทดสอบ
- **เปอร์เซ็นต์กะเทาะ:** สัดส่วนเมล็ดที่ได้เมื่อเทียบกับน้ำหนักฝักหรือผลผลิตตามวิธีวัดของงานนั้น
- **เสถียรภาพ:** ความสามารถของพันธุ์ในการรักษาผลผลิตเมื่อสภาพแวดล้อมเปลี่ยน
- **เมล็ดพันธุ์ก่อนการค้า:** สายพันธุ์ที่อยู่ระหว่างการทดสอบและยังต้องตรวจสถานะการจำหน่าย
