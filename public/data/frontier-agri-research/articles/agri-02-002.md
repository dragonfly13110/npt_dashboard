## 1. บทสรุปผู้บริหาร

- **ใจความ**: การกักเก็บคาร์บอนในดิน (Soil Organic Carbon, SOC sequestration) เป็นกลไกหลักของ “เกษตรคาร์บอน” (Carbon Farming) ที่ลด CO₂ ในบรรยากาศพร้อมกับเพิ่มความอุดมสมบูรณ์ของดิน แต่หัวใจของการนำไปขายเป็นคาร์บอนเครดิตคือระบบ MRV (Measurement–Reporting–Verification) ซึ่งมีต้นทุนและความไม่แน่นอนสูง Remote sensing ร่วมกับ machine learning กำลังถูกนำมาใช้ลดต้นทุน MRV แต่ถูกจำกัดด้วยความลึกตรวจวัดที่ตื้นมาก (ไม่กี่เซนติเมตร) และสัญญาณการเปลี่ยนแปลง SOC ต่อปีที่เล็กมาก
- **ตัวเลขสำคัญ**: โลกคาดว่าดินสามารถกักเก็บคาร์บอนได้ประมาณ 20 Pg C ภายใน 25 ปี คิดเป็นมากกว่า 10% ของการปล่อยก๊าซเรือนกระจกจากมนุษย์ [1]; การเปลี่ยนและการเพาะปลูกที่ดินเป็นแหล่งปล่อย GHG ประมาณ 1 ใน 3 [1]; โครงการ MRV มาตรฐานกลาง เช่น VM0042 ของ Verra เปิดใช้งานเวอร์ชัน 2.2 ตั้งแต่วันที่ 2025-10-21 [2]
- **นัยต่อไทย**: ไทยมีฐาน SOC ของพื้นที่เกษตรที่ยังไม่ได้สำรวจแบบครบแปลง (ยังไม่ยืนยัน) และยังไม่มีหน่วยรับรองคาร์บอนเครดิตภาคเกษตรขนาดใหญ่รองรับ remote sensing MRV — เป็นช่องว่างที่ต้องปิดด้วยข้อมูลภาคสนาม + มาตรฐานระดับชาติ
- **สถานะโดยรวม**: 🧪 นำร่องแปลงทดลอง + 📈 เชิงพาณิชย์เริ่มต้น (มีมาตรฐาน/ตลาดแล้วในต่างประเทศ แต่ในไทยยังเป็นช่วงเริ่มต้น)

## 2. หลักการและขอบเขต

- **หลักการ**: พืชดูด CO₂ ผ่านการสังเคราะห์แสงแล้วเปลี่ยนเป็นชีวมวล เมื่อเศษซาก/รากลงสู่ดินและถูกย่อยสลายบางส่วนโดยจุลินทรีย์ จะกลายเป็นอินทรียวัตถุในดิน (SOC) ซึ่งเป็น “แหล่งเก็บ” คาร์บอน (sink) [1] แนวทางเพิ่ม SOC เช่น การไถพรวนน้อย (reduced tillage), การปลูกพืชคลุมดิน (cover crop), การจัดการปุ๋ย/เศษซาก/น้ำ, การแทะเล็มหญ้าแบบหมุนเวียน และการใส่ biochar [2]
- **MRV คืออะไร**: คือกระบวนการพิสูจน์ว่าคาร์บอนเพิ่มขึ้นจริง ประกอบด้วย (1) การวัด/ประเมิน — การสุ่มเก็บตัวอย่างดิน + การใช้แบบจำลอง + remote sensing; (2) การรายงานตามระเบียบวิธี; (3) การตรวจสอบโดยหน่วยงานอิสระ (Validation/Verification Body) ก่อนออกเครดิตในทะเบียนกลางเช่น VCS Registry ของ Verra [2]
- **บทบาทของ remote sensing**: ใช้ดาวเทียม (Sentinel-2, Landsat) / เซนเซอร์ hyperspectral / เครื่องวัดดินแบบ proximal sensing (NIR/MIR spectroscopy) ร่วมกับ machine learning (PLSR, Random Forest, deep learning) ประเมิน SOC แบบไม่ทำลายตัวอย่าง แต่ตรวจได้เฉพาะชั้นผิวดิน (ไม่กี่เซนติเมตร) — ใช้สำหรับการติดตามการจัดการ/การครอบคลุมพื้นที่มากกว่าการวัด SOC ทั้งแปลงโดยตรง (ยังไม่ยืนยัน ตัวเลขความแม่นยำ)
- **ขอบเขตในไฟล์นี้**: ครอบคลุมกลไกการกักเก็บคาร์บอน, มาตรฐาน/ระเบียบวิธี MRV, เทคโนโลยี remote sensing + spectroscopy, ตัวเลขผลลัพธ์, ตลาดคาร์บอน, และสถานการณ์ไทย
- **สิ่งที่ไม่อยู่ในขอบเขต**: คาร์บอนป่าไม้/ป่าชายเลน (blue carbon) และ biochar เชิงอุตสาหกรรมแบบเต็มระบบ (หากจะเจาะลึกให้ไปดูไฟล์โดเมนที่เกี่ยวข้อง) — ไฟล์นี้เน้น SOC ในดินเกษตรเป็นหลัก

## 5. ตลาดและการลงทุน

- ตลาดคาร์บอนภาคเกษตร/ดินยังเล็กแต่โตไว เม็ดเงินส่วนใหญ่ไหลไปสู่ตลาดสมัครใจ (voluntary carbon market) ผ่านมาตรฐานอย่าง VCS ของ Verra ซึ่ง VM0042 ช่วยให้โครงการ “Improved Agricultural Land Management” คำนวณเครดิต SOC ได้ [2]
- ผู้เล่นหลัก: Verra (มาตรฐาน VCS/Methodology), Indigo Ag และ TerraCarbon (ผู้พัฒนา VM0042 ดั้งเดิม), บริษัท consult/verification (VVB), และสตาร์ทอัพด้าน soil carbon / remote sensing หลายราย (ยังไม่ยืนยัน รายชื่อและมูลค่าลงทุนรอบล่าสุด)
- ปัจจัยขับเคลื่อน: แรงกดดัน Net Zero ขององค์กร, ความต้องการ Scope 3 offset, นโยบาย/เงินอุดหนุนด้าน regenerative agriculture
- ปัจจัยฉุดรั้ง: ต้นทุนสูงของการสุ่มเก็บตัวอย่างดิน/การตรวจสอบ, ความไม่แน่นอนทางสถิติ, ปัญหาความยั่งยืน (permanence) และการรั่วไหล (leakage) [2]
- มูลค่าตลาดตัวเลขรวมยังไม่ยืนยัน (ยังไม่ยืนยัน)

## 6. สถานการณ์ประเทศไทย

- **หน่วยงาน**: องค์การบริหารจัดการก๊าซเรือนกระจก (อบก./TGO) ดำเนินโครงการ T-VER (Thailand Voluntary Emission Reduction Program) สำหรับคาร์บอนเครดิตในประเทศ รวมถึงภาคเกษตรแต่ยังจำกัด (รายละเอียด/ตัวเลขยังไม่ยืนยัน — ต้องตรวจจากเว็บ TGO โดยตรง)
- **นโยบาย**: ไทยมี NDC/เป้าหมาย Carbon Neutrality และอยู่ระหว่างการผลักดันกฎหมาย Climate Change Act (สถานะและรายละเอียดยังไม่ยืนยัน)
- **งานวิจัยไทย**: มีงานวิจัย SOC / เกษตรคาร์บอนในหลายสถาบัน (มก., มข., สวทช. ฯลฯ) แต่ยังขาดการรวมข้อมูล SOC ระดับชาติและแปลง remote sensing MRV เชิงปฏิบัติ (ยังไม่ยืนยัน รายละเอียด)
- **ภาคเอกชนไทย**: มีโครงการคาร์บอนเครดิตจากเกษตรกร/การปลูกข้าวลดการปล่อย methane และโครงการ soil carbon เบื้องต้น แต่สเกลยังเล็ก (ยังไม่ยืนยัน)
- **อุปสรรค**: ต้นทุนการวัด SOC ต่อแปลงสูง, การถือครองที่ดินไม่ชัดเจนสำหรับสิทธิเครดิต, มาตรฐาน MRV ระดับชาติยังไม่รองรับ remote sensing เต็มรูปแบบ

## 7. ช่องว่างงานวิจัย (Open Questions)

1. จะแยกสัญญาณการเปลี่ยนแปลง SOC ต่อปี (ซึ่งเล็กมาก) ออกจากสัญญาณรบกวนเชิงพื้นที่/ฤดูกาล ด้วย remote sensing ได้อย่างไร?
2. ควรผสาน remote sensing + spectroscopy + แบบจำลอง (เช่น RothC/DNDC) อย่างไรให้ได้ค่าที่ยอมรับได้ทางการเงินในมาตรฐาน MRV [2]
3. ต้นทุน MRV ต่อตัน CO₂e สำหรับดินไทย (แปลงเล็ก-กลางของเกษตรกร) อยู่ที่เท่าไร และ remote sensing ช่วยลดได้กี่ % ?
4. ความเสี่ยงด้าน permanence/reversal ของ SOC ในสภาพอากาศเขตร้อนชื้นของไทยมีมากน้อยแค่ไหน?
5. ควรมีมาตรฐาน SOC MRV ระดับชาติของไทยที่รองรับเทคโนโลยีใหม่และสอดคล้องกับ T-VER อย่างไร?
6. คำตอบของงานวิจัยนี้เปลี่ยนแปลงตามการสอบเทียบกับข้อมูลดินจริง (ground truth) จากแปลงไทยหรือไม่?

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                           | ระดับนโยบาย                                                                        |
| ---------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | เก็บข้อมูล SOC พื้นฐานแปลง + ใช้ spectroscopy/remote sensing นำร่องในแปลงสาธิต | สนับสนุนทุนสำรวจ SOC ระดับชาติ + เร่ง Climate Change Act ให้ชัดเจน                 |

| 3 (4+ ปี)  | สเกลเต็มเป็นธุรกิจ carbon farming + ระบบ MRV ดิจิทัลที่ยอมรับได้               | เชื่อมโยงตลาดคาร์บอนไทยกับสากล, จูงใจ regenerative ag ด้วยเครดิต                   |

| ------------------------------------ | -------------------------------------------------- | ------------------------------------------------------ |
| ความแม่นยำ/ความลึกของ remote sensing | ตรวจได้แค่ชั้นผิวดินไม่กี่ซม. ไม่ใช่ทั้งโปรไฟล์ราก | ใช้ proximal sensing + แบบจำลอง + ข้อมูลดินจริงช่วย    |
| สัญญาณเปลี่ยนเล็กต่อปี               | SOC เปลี่ยนเพียงเล็กน้อย ทำให้แยกจากความแปรปรวนยาก | ออกแบบสุ่ม/stratified ตามมาตรฐาน [2]                   |
| ต้นทุน MRV                           | การสุ่มเก็บ/วิเคราะห์ดินแพง                        | remote sensing + ML ลดจุดตรวจได้ (สัดส่วนยังไม่ยืนยัน) |
| Permanence/reversal                  | SOC กลับคืนได้ถ้าเปลี่ยนวิธีจัดการ                 | ระยะเวลาเครดิต/กติกา “reversal buffer” ในมาตรฐาน [2]   |
| ข้อมูลพื้นฐานไทยน้อย                 | ยังขาด SOC map ระดับชาติที่ทันสมัย                 | ลงทุนสำรวจ + open data                                 |
| ความน่าเชื่อถือของตลาด               | ปัญหา greenwashing/ความไม่แน่นอนของเครดิต          | มาตรฐานตรวจสอบอิสระ (VVB) [2]                          |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] ตัวเลข “4 per 1000 ชดเชย 20–35%” และ “SOC ~1,500 Gt C 0–1 ม.” ยังไม่ได้ยืนยันจากแหล่งต้นฉบับโดยตรง — ให้ค้นจาก IPCC AR6 WG3 และบทความ Chabbi et al. (2017)
- [ ] ค่าความแม่นยำ R² ของ remote sensing SOC และต้นทาง/ปีของงาน review ยังไม่ชัดเจน — ค้นบทความทบทวน (review) ล่าสุดเรื่อง satellite/hyperspectral SOC estimation
- [ ] รายละเอียด/ตัวเลข T-VER และ Climate Change Act ของไทย (สถานะกฎหมาย, จำนวนโครงการภาคเกษตร, ราคาเครดิต) ยังไม่ยืนยัน — ต้องดึงจากเว็บ TGO (ghg.or.th) โดยตรง
- [ ] ชื่อสตาร์ทอัพและมูลค่าการลงทุนของตลาด carbon farming ยังไม่ยืนยัน — ค้นรายงานตลาด voluntary carbon จาก Ecosystem Marketplace/World Bank
- [ ] ควรติดตามการแก้ไข VM0042 หลัง 2026-06-11 (Corrections and Clarifications) ว่าถูกยกระดับเป็นเวอร์ชันใหม่หรือไม่ [2]

## 11. อภิธานศัพท์

| คำศัพท์                       | ความหมาย                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------- |
| SOC (Soil Organic Carbon)     | คาร์บอนที่อยู่ในอินทรียวัตถุของดิน                                              |
| Carbon sequestration          | กระบวนการนำ CO₂ ออกจากบรรยากาศไปเก็บในแหล่ง (sink) เช่น ดิน [1]                 |
| Carbon Farming / เกษตรคาร์บอน | การจัดการฟาร์มให้ดูดซับและเก็บ CO₂ ในดิน/ชีวมวล [2]                             |
| MRV                           | Measurement–Reporting–Verification: วัด–รายงาน–ตรวจสอบ                          |
| ALM                           | Improved Agricultural Land Management — กลุ่มวิธีจัดการที่ดินเกษตรใน VM0042 [2] |
| remote sensing                | การสำรวจโดยปราศจากการสัมผัส เช่น ดาวเทียม/อากาศยาน                              |
| proximal sensing              | การวัดด้วยเซนเซอร์ใกล้ตัวอย่าง (NIR/MIR spectroscopy)                           |
| VCS / Verra                   | โปรแกรม/องค์กรมาตรฐานคาร์บอนเครดิตสมัครใจ [2]                                   |
| VVB                           | Validation/Verification Body — หน่วยตรวจสอบอิสระ [2]                            |
| Pg C / Gt C                   | หน่วยปริมาณคาร์บอน 1 เพตากรัม = 1,000 ล้านตันคาร์บอน                            |
