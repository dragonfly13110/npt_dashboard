## 1. บทสรุปผู้บริหาร

- **ใจความ**: หุ่นยนต์สำรวจแปลงภาคพื้น (ground/UGV scouting robot) = รถ/หุ่นยนต์อัตโนมัติเดินตรวจแปลง (ตามแถว/เส้นทาง) พร้อมกล้อง/เซนเซอร์ เก็บภาพ/ข้อมูลรายต้น (ใต้ทรงพุ่ม — ที่โดรนมองไม่เห็น) แล้วส่ง AI วิเคราะห์ (โรค/แมลง/ธาตุอาหาร/ความเครียด/นับผล) — ตอบโจทย์ "การตรวจแปลงที่คนทำได้น้อย/ช้า/พลาด" + "ข้อมูลรายต้นที่โดรนมองไม่เห็น" — ตัวอย่าง: Thorvald (UV — กำจัดโรคราแป้ง — Saga Robotics, นอร์เวย์), Burro (ช่วยขน/อัตโนมัติ — US), Solix (Solinftec — ตรวจ+พ่นจุด — บราซิล), GUSS (พ่นสวนผลไม้ — US), Agrointelli Robotti (แพลตฟอร์มทำงานหลายอย่าง — เดนมาร์ก) [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น (ตรวจ/บริการ — ยุโรป/อเมริกา/บราซิล; ไทยยังไม่มี) [2][3]
- **ตัวเลขสำคัญที่สุด**: UGV ตรวจได้ ~10–50+ ไร่/วัน (ช่วง — ขึ้นเครื่อง/แปลง); ภาพ/ข้อมูลรายต้น (ตรงจุดที่โดรน/ดาวเทียมมองไม่เห็น — ใต้ทรงพุ่ม/ในแถว) — การตรวจด้วยคน ~นาที–ชม./ไร่ (ช้า/ตามกำลัง); UV robot (Thorvald — โรคราแป้งสตรอเบอร์รี) ลดสารเคมีได้ ~50–90% (งาน/ผู้ผลิต — ช่วง); ต้นทุนเครื่อง/บริการ ~$50–300K (ช่วง) [1][2][3][4]
- **นัยต่อไทย**: ไทยยังไม่มีหุ่นยนต์ตรวจแปลงเชิงพาณิชย์ — แต่ "ข้อมูลรายต้น" นี้แหละที่ไทยขาด (งานตรวจ/นับด้วยคนใช้แรงงานมาก — ทุเรียน/ลองกองนับผล, โรค/แมลงในแปลง) — จุดเริ่ม: (1) "บริการตรวจแปลง" ในพืชมูลค่าสูง (ทุเรียน/กาแฟ/ผัก — ผู้ประกอบการ) (2) งานวิจัย UGV ไทย (มก./มจธ./มข. — ราคาถูก/แปลงไทย) (3) ผูกกับ AI ภาพ (06-009/05-005) + ข้อมูล→06-001 (twin) [5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (ต่างประเทศ) — ไทย: งานวิจัย/เริ่มนำร่อง

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (5 ชั้น)

1. **ตัวยาน (UGV)**: ล้อ/สายพาน/คร่อมแถว (row straddle) — ขนาดเล็ก-กลาง (น้ำหนักเบา — ไม่กดดิน 07-003), นำทางอัตโนมัติ (RTK/กล้อง/เส้นแถว), ทำงานกลางคืนได้ (ไฟ)
2. **เซนเซอร์เก็บข้อมูล (sensing)**: กล้อง RGB/สเตอรีโอ/ไฮเปอร์สเปกตรัม/เทอร์มอล (โรค/ธาตุอาหาร/ความเครียด), LiDAR (โครงสร้าง/นับผล), เซนเซอร์อากาศ/ดิน (05-007 — ผูก) — "ความได้เปรียบเหนือโดรน: มองใต้ทรงพุ่ม/ใบล่าง/รายต้น"
3. **AI วิเคราะห์ (on-board/edge — 05-005)**: ตรวจจับ/จำแนก (โรค/แมลง/วัชพืช/นับผล/ความสุก) — เรียลไทม์หรือส่ง cloud; ต่อยอดโมเดลจากภาพ (06-009)
4. **การทำงานต่อเนื่อง (operations)**: แผนที่เส้นทาง (ทุกแถว/จุดเสี่ยง), สถานีชาร์จ, หลายเครื่อง (ฝูง — 07-003), สภาพอากาศ (ฝน/โคลน)
5. **การเชื่อมข้อมูล (integration)**: ข้อมูล → แดชบอร์ด/คำแนะนำ (DSS — 06-008) / แผนที่พ่น (07-008) / twin (06-001) — "ตรวจแล้วจัดการต่อ" (ตรวจ→กำจัดวัชพืช 07-002 / พ่น 07-008)

### 2.3 ขอบเขต

- **ครอบคลุม**: UGV ตรวจแปลง (เซนเซอร์/AI/การใช้งาน) + ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: โดรนสำรวจ (05-006), หุ่นยนต์กำจัดวัชพืช (07-002 — อ้างข้าม), รถแทรกเตอร์ (07-005), ฝูงไมโคร (07-003), AI ภาพเชิงลึก (06-009/05-005)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                             | ผลลัพธ์                                                | สถานที่/เงื่อนไข    | แหล่ง  |
| ------------------------------------- | ------------------------------------------------------ | ------------------- | ------ |
| พื้นที่ตรวจ/วัน (UGV)                 | ~10–50+ ไร่/วัน (ช่วง — ขึ้นเครื่อง/แปลง)              | ฟาร์ม/งาน           | [2][3] |
| ความเร็วตรวจเทียบคน                   | เร็วกว่ามาก (คนตรวจไร่ละนาที–ชม.) — ไม่มีข้อมูลมาตรฐาน | งาน                 | [2]    |
| การลดสารเคมี (UV robot — โรคราแป้ง)   | ~50–90% (งาน/ผู้ผลิต — ช่วง)                           | สตรอเบอร์รี (ยุโรป) | [3]    |
| ความแม่นยำ AI ตรวจโรค/แมลง (ภาพ UGV)  | ~80–95% (งาน — ช่วง; ขึ้นแสง/ความละเอียด)              | งานทดลอง            | [2]    |
| ต้นทุน UGV/บริการ                     | ~$50–300K/เครื่อง; บริการต่อไร่ (ช่วง)                 | ตลาด                | [4]    |
| ข้อมูลรายต้น (ใต้ทรงพุ่ม — เทียบโดรน) | ได้เฉพาะ UGV (โดรน/ดาวเทียมมองไม่เห็น)                 | ลักษณะทางเทคนิค     | [1][2] |
| งาน UGV ไทย (วิจัย/นำร่อง)            | เริ่มมี (ทุเรียน/ลองกอง/ผัก)                           | TCI/ข่าว            | [5]    |
| ตลาด UGV เกษตร (scouting)             | ~$0.5–2 พันล้านดอลลาร์ (2030 — analyst ช่วง)           | ตลาด                | [4]    |

- **กฎ**: "UGV = ข้อมูลรายต้น/ใต้ทรงพุ่ม + ทำงานกลางคืน/ซ้ำๆ — เสริมโดรน (มองจากฟ้า)" — "คุ้มเมื่อพืชมูลค่าสูง/แรงงานตรวจแพง/ต้องตัดสินใจรายต้น" — ตัวเลขช่วงกว้าง/จากผู้ผลิต — ใช้เทียบเคียงทิศทาง (ตรวจหัวข้อ 10)
- **หมายเหตุ**: ตัวเลขการลดสาร/ความแม่นยำจากงาน/ผู้ผลิต — ต้องตรวจอิสระ

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด "agricultural UGV/scouting robots" ~$0.5–2 พันล้านดอลลาร์ (2030 — analyst ช่วงกว้าง); โต ~15–25%/ปี (ช่วง) [4]
- **ผู้เล่นหลัก**: ตาราง 3.1 + ผู้จัดจำหน่ายไทย (ยังไม่มี UGV พาณิชย์), งานวิจัยมหาวิทยาลัย (ไทย — UGV ต้นแบบ), ผู้ให้บริการโดรนไทย (ขยายสู่ UGV — ระยะยาว)

| ขับเคลื่อน                                       | ฉุดรั้ง                                  |
| ------------------------------------------------ | ---------------------------------------- |
| แรงงานตรวจแปลงขาด/แพง (หมอพืช/คนนับผล)           | ราคา UGV สูง (ฟาร์มเล็กไทยไม่ไหว)        |
| ข้อมูลรายต้น (แม่นยำ/ตัดสินใจเฉพาะจุด)           | การบำรุง/ช่าง (ไฮเทค)                    |
| ลดสารเคมี (UV/ตรวจ→พ่นจุด)                       | สภาพแปลง (โคลน/ลาดชัน/แปลงเล็ก)          |
| การผูก AI/DSS/twin (06-001/06-008) — มูลค่าเพิ่ม | การยอมรับ/ทักษะ (14-003)                 |
| ทำงานกลางคืน/ซ้ำ (แมลง/โรคราแป้ง — UV)           | กฎ/ความปลอดภัย (เครื่องเคลื่อนที่ในแปลง) |

- **แนวโน้ม**: "ตรวจ→จัดการ" ครบวงจร (UGV+พ่น/กำจัด — รวม 07-002/07-008), บริการรับจ้างตรวจ (RaaS), ราคาลง (รุ่นเล็ก/ประกอบท้องถิ่น), ผูก multimodal AI (06-009) + ภาพทุกแหล่ง (05-006) → แผนที่ตัดสินใจ

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ยังไม่มี UGV ตรวจแปลงเชิงพาณิชย์ในไทย; งานวิจัย/ต้นแบบเริ่ม (มก./มจธ./มข. — UGV ตรวจทุเรียน/ลองกอง/ผัก — นับผล/โรค); การตรวจแปลงปัจจุบัน = คน (หมอพืช/เจ้าหน้าที่/แรงงานนับผล) + โดรน (05-006); ผู้ให้บริการโดรนมีพร้อม (ขยายสู่ UGV ได้) [5][6]
- **จุดแข็งไทย**: งานวิจัยหุ่นยนต์/วิศวกรรม (มก./มจธ./มข.) พร้อม (ต้นแบบราคาถูก), พืชมูลค่าสูงที่ "ข้อมูลรายต้น" คุ้ม (ทุเรียน/ลองกอง/กาแฟ/ผัก), ผู้ให้บริการโดรน/เครื่องจักรมีโครงสร้าง, แรงงานตรวจขาด/แก่ (ภาคเหนือ/ตะวันออก)
- **จุดอ่อน**: ไม่มีผู้เล่นพาณิชย์/บริการ, ฟาร์มเล็ก (UGV ไม่คุ้ม), สภาพแปลง (ลาดชัน/โคลน — ต้องออกแบบ), การยอมรับ/ทักษะ (14-003), ข้อมูล/ภาพไทย (ชุดเปิด — ยังน้อย), ช่าง/บริการ
- **โอกาส**: (1) "บริการตรวจแปลงรายต้น" (ทุเรียน/กาแฟ/ผัก — ผู้ประกอบการ+งานวิจัย — นับผล/โรค/ความเครียด) (2) งาน "UGV ไทยราคาถูก" (ประกอบในประเทศ — มหาวิทยาลัย+บริษัท) (3) ผูกข้อมูล→คำแนะนำ (DSS 06-008) — "ตรวจแล้วรู้ว่าต้องทำอะไร" (4) การใช้กับสวนขนาดใหญ่/สหกรณ์ (รวมแปลง) (5) ต่อยอด UV/บำบัดไม่ใช้สาร (สตรอเบอร์รีไทย/ผัก)
- **หน่วยงาน**: มก./มจธ./มข./มช. (วิจัย), กรมวิชาการ/ส่งเสริม (หมอพืช/แปลง), ผู้ประกอบการทุเรียน/กาแฟ (ผู้ใช้), NIA/สวทช. (ทุน), สหกรณ์/กลุ่มแปลงใหญ่

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: UGV ไทยราคาถูก/ประกอบในประเทศ (แปลงไทย — โคลน/ลาดชัน/ร้อน) — ยังไม่มี
- **Q2**: ชุดภาพ "รายต้น" ไทยเปิด (ทุเรียน/ลองกอง/กาแฟ/ผัก — โรค/แมลง/ผล) — ยังไม่มี
- **Q3**: เศรษฐศาสตร์ "บริการตรวจแปลง" ไทย (บาท/ไร่/ปี — เทียบแรงงาน) — ยังไม่มีข้อมูล
- **Q4**: การผูก UGV+ข้อมูล→DSS (06-008) — "ตรวจแล้วแนะนำ" ครบวงจรไทย — ยังไม่มี
- **Q5**: UV robot ในสภาพไทย (สตรอเบอร์รีเหนือ/ผัก — โรคราแป้ง/เชื้อรา) — ยังไม่มีงาน
- **Q6**: การทำงานกลางคืน/ในแปลงยาก (ฝน/โคลน/มืด) — งานยังน้อย
- **Q7**: การยอมรับ/ทักษะเกษตรกรไทย (14-003) ต่อหุ่นยนต์ตรวจ — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                 | ระดับนโยบาย                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | งาน "UGV ตรวจทุเรียน/กาแฟ/ผัก" (ต้นแบบราคาถูก — มก./มจธ./มข.); ชุดภาพรายต้นเปิด; สาธิตบริการตรวจ (สหกรณ์/ผู้ประกอบการ)               | ทุนวิจัย UGV ไทย (สวทช./NIA); ข้อมูลโรค/ผลผลิต (กรมวิชาการ — เปิด)                  |
| 2 (2–4 ปี) | "บริการตรวจแปลงรายต้น" เชิงพาณิชย์ (ทุเรียน/กาแฟ — ผู้ประกอบการ+งานวิจัย); การผูก UGV→DSS (06-008) แนะนำ; UV/บำบัดไม่ใช้สาร (นำร่อง) | มาตรฐาน/การทดสอบ UGV ไทย (สนค./กรมวิชาการ); หนุนกลุ่มแปลงใหญ่/สหกรณ์                |
| 3 (4+ ปี)  | "ระบบตรวจ-แนะนำ-จัดการครบวงจรไทย" (UGV+AI+DSS — 06-001/06-008 — ทุกพืชมูลค่าสูง); บริการรับจ้างตรวจระดับชาติ                         | นโยบาย "หมอพืชอัตโนมัติ" (เสริมเจ้าหน้าที่ — 14-004); ข้อมูล/การยอมรับสะสม (14-003) |
