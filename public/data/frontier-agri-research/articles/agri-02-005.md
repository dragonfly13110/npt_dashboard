## 1. บทสรุปผู้บริหาร

- เซนเซอร์ดิน "on-the-go" คือการติดเซนเซอร์บนเครื่องจักร (รถไถ/เครื่องหยอดปุ๋ย) เพื่อวัดสมบัติดินแบบต่อเนื่องระหว่างแล่นไป โดยใช้หลักการหลัก 3 แบบ คือ ไฟฟ้าแม่เหล็กไฟฟ้า (EM/ECa) วัดค่าการนำไฟฟ้า ตรวจหาความเค็ม ความชื้น เนื้อดิน; ออปติคัล VIS-NIR วัดอินทรียวัตถุ (OM) และคาร์บอน; และไอออนซีเล็คทีฟอิเล็กโทรด (ISE) วัดธาตุอาหารละลายน้ำ เช่น ไนเตรต-ไนโตรเจน
- จุดแข็งชัดเจนคือ **EC และ OM** วัดได้แม่นยำและเสถียร ใช้ทำแผนที่ระดับความอุดมสมบูรณ์/การจัดการอัตราปุ๋ยแบบแปรผัน (VRT) แล้ว แต่สำหรับ **ฟอสฟอรัส (P) และโพแทสเซียม (K) ที่พืชใช้ได้โดยตรง** ยังเป็นจุดอ่อนใหญ่ เพราะไม่มีสเปกตรัมตรง จึงต้องพึ่งแบบจำลองเคโมเมตริกซ์และให้ค่าความแม่นยำต่ำ-ผันแปรสูง (R² ประมาณ 0.3–0.6) — ตัวเลขเฉพาะรายชิ้นงานยังต้องตรวจสอบยืนยัน
- ราคาระบบ on-the-go ทั้งชุด (แพลตฟอร์ม + เซนเซอร์ + ซอฟต์แวร์) อยู่ระดับหลายหมื่นดอลลาร์สหรัฐต่อชุด สำหรับฟาร์มรายย่อยไทยยังแพง แต่แนวโน้มบริการ "จ้างแมป" (soil mapping as a service) และเซนเซอร์ต้นทุนต่ำกำลังโต — ตัวเลขราคาต้องยืนยันเพิ่ม
- นัยต่อไทย: N (ไนเตรท) เหมาะสุดกับ ISE บนเครื่อง แต่ยังมีปัญหาเรื่องการลอยของสัญญาณและการเทียบค่าห้องแล็บ ส่วน P/K ควรใช้วิธี "SMART sampling" (เก็บตัวอย่างแบบชี้เป้าโดยอาศัยแผนที่ EC/OM จาก on-the-go มาลดจุดเก็บ) แทนการวัดตรง
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (แพลตฟอร์ม Veris ขายจริงมานาน [4]) สำหรับ EC/OM/pH แต่การวัด N/P/K แบบเรียลไทม์ยังอยู่ในช่วงวิจัย-นำร่องเป็นส่วนใหญ่

## 2. หลักการและขอบเขต

เซนเซอร์ on-the-go แตกต่างจาก "เซนเซอร์ฝังดินประจำจุด (in-situ/IoT)" ตรงที่เคลื่อนที่ต่อเนื่องกับเครื่องจักร ทำให้ได้ **ข้อมูลเชิงพื้นที่ความหนาแน่นสูง** ทั้งแปลง (เช่น เก็บได้หลายร้อยถึงหลายพันจุดต่อเฮกตาร์ เทียบกับวิธีกริดที่เก็บเพียงจุดเดียวต่อหลายไร่) [3] ระบบทำงานบนหลักการ 3 กลุ่มที่อาจติดตั้งพร้อมกันบนแพลตฟอร์มเดียว:

1. **การนำไฟฟ้าดิน (EMI/ECa)**: ใช้ขดลวดเหนี่ยวนำหรือล้ออิเล็กโทรดปล่อยกระแสสลับ วัดค่าการนำไฟฟ้าปรากฏ (ECa) ซึ่งสัมพันธ์กับเนื้อดิน ความชื้น ความเค็ม และความอุดมสมบูรณ์โดยรวม เป็นตัวชี้วัดทางอ้อมที่แม่นยำและนิยมใช้มากที่สุด โดยผลิตภัณฑ์แถวหน้าคือแพลตฟอร์ม Veris (U3/ProScan/CoreScan) [4]
2. **สเปกโทรสโกปี VIS-NIR**: ใช้แสงช่วง 350–2500 นาโนเมตรยิงผ่านตัวอย่างดินที่สัมผัสกับช่องวัด คำนวณจากค่าสะท้อนแสง สัมพันธ์กับ OM/คาร์บอน ดินเหนียว แร่ดินเหนียว และในงานวิจัยย่อยสามารถประมาณ P/K ได้ผ่านแบบจำลอง แต่ P/K ไม่มีโครโมฟอร์ตรงจึงแม่นยำต่ำ [1][2]
3. **ไอออนซีเล็คทีฟอิเล็กโทรด (ISE)**: อิเล็กโทรดแบบตันวัดไนเตรต (NO3-) โพแทสเซียม (K+) ในสารละลายดินได้โดยตรงใกล้เคียงวิธีห้องแล็บ แต่ไวต่อการแทรกสอดของไอออนอื่น การลอยของสัญญาณ และต้องบำรุง/รีเจนชั้นฟิล์มบ่อย [2]

ขอบเขตที่ครอบคลุม: หลักการ ราคา ความแม่นยำของ N/P/K/EC/OM on-the-go และการประยุกต์เพื่อการจัดการปุ๋ยแบบอัตราแปรผัน (VRT) สิ่งที่ไม่อยู่ในขอบเขต (เพื่อไม่ทับซ้อนไฟล์อื่น): เซนเซอร์ประจำจุด/IoT สำหรับดิน (อยู่ในโดเมนอื่น), สเปกโทรสโกปีดินจากดาวเทียม/โดรน (remote sensing), และการสุ่มตัวอย่างแบบกริดโดยไม่ใช้เครื่องจักร

## 3. สถานะงานวิจัย

| ช่วงเวลา         | ความก้าวหน้า                                                                                                                                            | แหล่ง  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| ทศวรรษ 1980–1990 | จุดตั้งต้นของการวัด ECa/EMI on-the-go เพื่อแมปเนื้อดินและความเค็มในตะวันตก                                                                              | [2]    |
| กลางทศวรรษ 2000  | Adamchuk และคณะทบทวนเซนเซอร์ on-the-go (EC, pH, OM, ไนเตรท) และวางกรอบการใช้งานใน precision agriculture อย่างเป็นระบบ                                   | [2]    |
| 2010–2015        | ผู้ผลิต (Veris, SoilOptix, AgroCares ฯลฯ) ทำให้แพลตฟอร์มเชิงพาณิชย์แพร่หลาย; งาน VIS-NIR ขยายสู่การทำนาย C/N/P/K ด้วยเคโมเมตริกซ์                       | [1][4] |
| 2020–ปัจจุบัน    | ผสาน ML/Deep learning กับ VIS-NIR ขยายความแม่นยำบางธาตุ; บริการจ้างแมปและ "soil mapping as a service" เติบโต; การวัด N/P/K โดยตรงยังเป็นงานวิจัยเชิงรุก | [1][3] |

- **เส้นแบ่ง**: EC/OM/pH on-the-go มีบริษัทขายเชิงพาณิชย์แล้วและใช้งานจริงในอเมริกาเหนือ/ยุโรป [4] แต่การวัด **N/P/K แบบเรียลไทม์บนเครื่อง** ยังอยู่ในช่วง bench/แปลงทดลองและนำร่อง ไม่ใช่เทคโนโลยีที่ "ซื้อแล้ววัดได้ทันที" แบบเดียวกับ EC/pH — ต้องยืนยันตัวเลขความพร้อมจำหน่ายของแต่ละผู้ผลิตในรอบทบทวนถัดไป

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                                | ผลลัพธ์                                                                                    | สถานที่/เงื่อนไข                                                                                    | แหล่ง                |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | -------------------- |
| ความหนาแน่นจุดเก็บ on-the-go                             | หลายร้อย–หลายพันจุด/เฮกตาร์ ระหว่างการแล่น                                                 | ประเมินจากหลักการเก็บต่อเนื่องบนเครื่องจักร; เทียบวิธีกริดที่แนะนำ 10–20 จุด/40 เอเคอร์ในแปลงสหรัฐฯ | [3]                  |
| R² การทำนาย OM/คาร์บอนด้วย VIS-NIR                       | สูงถึง ~0.90+ ในดินเนื้อเดียวกัน                                                           | แปลงวิจัย เนื้อดินสม่ำเสมอ มีชุดเทียบค่าห้องแล็บ; ยังไม่ยืนยัน — ใช้เทียบเคียงทิศทาง                | [1](ยังไม่ยืนยัน)    |
| R² การทำนาย P (สกัด Bray/Mehlich) ด้วย VIS-NIR           | ต่ำ–ปานกลาง ประมาณ 0.3–0.5 ขึ้นกับดิน/ชุดเทียบค่า                                          | ดินต่างชนิดกัน; มีการอภิปรายเชิงทบทวนว่าต่ำกว่าธาตุอื่น                                             | [1][2](ยังไม่ยืนยัน) |
| R² การทำนาย K (แลกเปลี่ยนได้) ด้วย VIS-NIR               | ผันแปรประมาณ 0.4–0.6 ตามชุดข้อมูล                                                          | เงื่อนไขชุดเทียบค่า/เนื้อดินไม่เสมอต้นเสมอปลาย                                                      | [1](ยังไม่ยืนยัน)    |
| ความแม่นยำ ISE วัดไนเตรท-ไนโตรเจนในดิน                   | ใกล้เคียงห้องแล็บ ~±10–20% ในดินเปียกสม่ำเสมอ แต่มี drift หลังใช้นาน                       | ดินในฟาร์มทดสอบ; ต้องการการรีเจนชั้นฟิล์มบ่อย                                                       | [2](ยังไม่ยืนยัน)    |
| การวัด ECa                                               | แม่นยำ/เสถียรสูง ใช้แมปเนื้อดิน ความเค็ม ความชื้นได้จริง                                   | ใช้เชิงพาณิชย์มานานในอเมริกาเหนือ                                                                   | [2][4]               |
| ราคาชุดทั้งระบบ on-the-go (แพลตฟอร์ม+เซนเซอร์+ซอฟต์แวร์) | ประมาณหลายหมื่นดอลลาร์สหรัฐ/ชุด (เช่น ช่วง 30,000–80,000 ดอลลาร์ฯ) สำหรับรุ่นเดินหน้าฟาร์ม | ราคาไม่เป็นสาธารณะชัดเจน; ต้องสอบถามผู้ขายโดยตรง                                                    | [4](ยังไม่ยืนยัน)    |
| ต้นทุนการวิเคราะห์ห้องแล็บต่อตัวอย่าง (N/P/K/OM/pH)      | ประมาณ 8–20 ดอลลาร์สหรัฐ/ตัวอย่าง (ขึ้นกับแพ็กเกจ/ประเทศ)                                  | ราคาห้องแล็บพาณิชย์ในสหรัฐฯ; ยังไม่ยืนยัน                                                           | (ยังไม่ยืนยัน)       |

- **กฎที่ใช้**: ตัวเลขทุกตัวที่ไม่มีเงื่อนไขระบุชัดให้เขียน "ไม่ระบุ"; ตัวเลขที่ยังไม่สามารถดึงยืนยันจากแหล่งออนไลน์ในการเขียนรอบนี้ถูกกำกับ (ยังไม่ยืนยัน) ทุกจุด และต้องตรวจซ้ำในรอบทบทวน (ดูข้อ 10)
- **ตัวเลขที่ต่างกันหลายแหล่ง**: ค่า R² ของ P/K ผันแปรสูงตามเนื้อดิน/ชุดเทียบค่า → ใช้เทียบเคียงทิศทางเท่านั้น ไม่ใช่ค่ามาตรฐาน

## 5. ตลาดและการลงทุน

- มูลค่าตลาดเซนเซอร์ดิน/soil sensing โลกกำลังเติบโตจากแรงขับของ precision agriculture และการกักเก็บคาร์บอนในดิน (carbon farming/MRV) — ตัวเลขมูลค่าตลาดรายปีของสำนักวิเคราะห์เฉพาะยังต้องดึงและยืนยันใหม่ในรอบทบทวน (ยังไม่ยืนยัน)
- ผู้เล่นหลัก: **Veris Technologies (สหรัฐฯ)** — แพลตฟอร์ม U3, ProScan, CoreScan, FurrowScan และเครือข่ายบริการแมปดินใหญ่ที่สุดในโลก [4]; ผู้เล่นอื่นในกลุ่ม soil sensing/on-the-go ได้แก่ SoilOptix, GeoCrowd, AgroCares และกลุ่มสตาร์ทอัพสเปกโทรสโกปี NIR — รายชื่อ/รอบการลงทุนต้องยืนยัน
- รูปแบบธุรกิจที่โต: สลับจากการขายเครื่อง (capEx สูง) สู่ **บริการจ้างแมป/soil mapping as a service** และการแยกจ่ายต่อเฮกตาร์ (per-acre pricing) เพื่อลดภาระลงทุนของเกษตรกร [4]
- ปัจจัยขับเคลื่อน: การลดต้นทุนปุ๋ย/เพิ่มประสิทธิภาพปุ๋ย, นโยบายคาร์บอนเครดิตดิน, การขาดแคลนแรงงาน ปัจจัยฉุดรั้ง: ราคาเครื่องสูง ต้นทุนการเทียบค่าวิเคราะห์ และความน่าเชื่อถือของผล N/P/K

## 6. สถานการณ์ประเทศไทย

- ยังไม่มีข้อมูลที่เป็นระบบเปิดเผยว่าไทยมีแพลตฟอร์ม on-the-go เชิงพาณิชย์ท้องถิ่นที่วัด N/P/K เดินเครื่องได้เต็มรูปแบบ — งานในประเทศส่วนใหญ่ยังเป็นงานวิจัยสเปกโทรสโกปีดิน (VIS-NIR) เพื่อทำนายธาตุอาหารและการทำ digital soil mapping ร่วมกับ กรมพัฒนาที่ดิน และมหาวิทยาลัยเกษตรศาสตร์/ขอนแก่น/เชียงใหม่ (ตัวเลขและรายงานเฉพาะต้องยืนยันในรอบทบทวน)
- โครงสร้างที่เอื้อ: กรมพัฒนาที่ดินมีระบบฐานข้อมูลดินและห้องแล็บวิเคราะห์ทั่วประเทศ; การนำร่อง VRT ปุ๋ยในนาข้าว/อ้อย/มันสำปะหลังเริ่มมีแปลงสาธิต
- สิ่งที่ขวาง: ต้นทุนเครื่องสูงเกินกำลังฟาร์มรายย่อย, ความหนาแน่นแปลงเล็ก-แตกกระจายทำให้คุ้มทุนยาก, และการขาดมาตรฐานการเทียบค่า/การรับรองผลบนเครื่องกับห้องแล็บ
- แนวทางที่ไทยน่าจะเหมาะกว่าเครื่องราคาแพง: นำข้อมูล EC/OM on-the-go (โดยบริการจ้างแมป) มาใช้ลดจุดเก็บตัวอย่างแบบชี้เป้า (smart/composite sampling) แล้วส่งวิเคราะห์ N/P/K ในห้องแล็บ — ลดต้นทุนทั้งสองทาง (ยังเป็นข้อเสนอเชิงนโยบาย ต้องเทียบต้นทุนจริงในไทย)

## 7. ช่องว่างงานวิจัย (Open Questions)

- [ ] ทำไมการทำนาย P และ K ด้วย VIS-NIR ถึงมีความแม่นยำต่ำและผันแปรตามเนื้อดิน/สภาพชื้น — และกลไกทางสเปกโทรสโกปีที่แท้จริงคืออะไร ควรมีชุดข้อมูลเปิดหลายดิน
- [ ] วิธีเทียบค่า/มาตรฐาน (calibration/validation) แบบใดที่ทำให้ ISE วัด NO3-N บนเครื่องทนทานต่อการลอยของสัญญาณและไอออนรบกวนในดินเขตร้อนชื้นได้
- [ ] ต้นทุนรวม (TCO) จริงของการวัด N/P/K on-the-go เทียบกับการสุ่ม-วิเคราะห์ห้องแล็บต่อเฮกตาร์ในบริบทแปลงเล็กแบบไทย ยังไม่มีข้อมูลเชิงปริมาณ
- [ ] การรวมข้อมูล ECa+VIS-NIR+ML จะยกระดับ R² ของ P/K ให้ถึงระดับที่ใช้ตัดสินใจใส่ปุ๋ย VRT ได้หรือไม่ (ค่า R² ขึ้นต่ำที่ยอมรับได้คือเท่าไร)
- [ ] Soil spectroscopy (แบบ on-the-go และแบบตัวอย่างแห้ง) ไทยควรสร้าง "สเปกตรัมไลบรารีดินไทย" ของตัวเองหรือไม่ เพื่อลดการพึ่งพาแบบจำลองจากต่างประเทศ
- [ ] ประสิทธิภาพ/การยอมรับของ "บริการจ้างแมป" ในกลุ่มเกษตรกรรายย่อยและสหกรณ์ไทย — อัตราการเข้าใช้และความคุ้มทุน

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                              | ระดับนโยบาย                                                                                               |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | เริ่มจาก services จ้างแมป EC/OM ผ่านผู้ให้บริการในพื้นที่บนแปลงอ้อย/มันสำปะหลังขนาดใหญ่; ใช้ข้อมูลแมปชี้เป้าลดจุดเก็บตัวอย่างปุ๋ย | อบรม/สนับสนุนผู้ประกอบการบริการแมปดิน; เปิดข้อมูลดินของกรมพัฒนาที่ดินเป็น API                             |
| 2 (2–4 ปี) | ฟาร์มขนาดกลางผสานแผนที่ EC/OM กับ VRT ปุ๋ยไนโตรเจน; ทดลองนำร่อง ISE วัดไนเตรทบนเครื่องในแปลงสาธิต                                 | สร้างมาตรฐานกลางการเทียบค่า/การรายงานผลเซนเซอร์ on-the-go เทียบห้องแล็บ; สนับสนุนเงินทุนอุปกรณ์ผ่านสหกรณ์ |
| 3 (4+ ปี)  | สเกลเต็มสู่แปลงรายย่อยผ่านบริการจ้างแมประดับสหกรณ์; เริ่มรับรองคุณภาพผล P/K จากสเปกโทรสโกปีที่แม่นยำขึ้น                          | จัดตั้ง "สเปกตรัมไลบรารีดินไทย" แห่งชาติ + ผูกกับ MRV คาร์บอนดินและนโยบายปุ๋ยแม่นยำระดับชาติ              |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย               | รายละเอียด                                                  | โอกาสแก้                                                          |
| ------------------------ | ----------------------------------------------------------- | ----------------------------------------------------------------- |
| ความแม่นยำ P/K ต่ำ       | ธาตุทั้งสองไม่มีสเปกตรัมตรง ต้องพึ่งแบบจำลอง; R² ต่ำ/ผันแปร | ใช้ "smart sampling" ชี้เป้าด้วยแผนที่ EC/OM แทนการวัดตรง; รวม ML |
| ราคาเครื่องสูง           | ระบบทั้งชุดหลายหมื่นดอลลาร์ฯ                                | บริการจ้างแมป ต่อเฮกตาร์ แบ่งปันต้นทุน                            |
| การลอยของ ISE            | ISE drifting/แทรกสอดไอออน ต้องบำรุงบ่อย                     | พัฒนาอิเล็กโทรดตันรุ่นใหม่/อัตโนมัติล้าง                          |
| การเทียบค่าห้องแล็บ      | ผล on-the-go ต้องการชุดเทียบค่าเฉพาะท้องถิ่น                | สร้างมาตราฐาน/ไลบรารีสเปกตรัมไทย                                  |
| ความชื้น/เนื้อดินแปรปรวน | สภาพแปลงกวนสัญญาณมิติทั้งสาม                                | เก็บข้อมูลหลายฤดู/ปรับแบบจำลองตามเนื้อดิน                         |
| แปลงเล็ก-แตกกระจายของไทย | คุ้มทุนยากเมื่อพื้นที่ต่อแปลงน้อย                           | เน้นบริการจ้างแมปครอบคลุมพื้นที่รวมกลุ่มสหกรณ์                    |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ราคาระบบ on-the-go ทั้งชุด (30,000–80,000 USD/ชุด) ยังไม่ยืนยัน** — ควรสอบถามราคาจริงจาก Veris/ผู้แทนจำหน่าย และรวบรวมราคารุ่น U3/ProScan/CoreScan ใหม่
- [ ] **ค่า R² ของ P (~0.3–0.5) และ K (~0.4–0.6) จาก VIS-NIR ยังไม่ยืนยันค่าลง** — ควรดึงปี-วารสารต้นฉบับ (ทบทวน Viscarra Rossel / Adamchuk / มาเลขอ้างอิงที่แม่นยำ)
- [ ] **ความแม่นยำ ISE วัดไนเตรท (±10–20%, drift) ยังไม่ยืนยัน** — ควรหาเอกสารทดสอบแปลงสหรัฐ/ยุโรปปีล่าสุด
- [ ] **มูลค่าตลาด/อัตราโตของ soil sensing (ข้อ 5) ยังไม่มีตัวเลขยืนยัน** — ควรรวบรวมจากสำนักวิเคราะห์ (Grand View, MarketsandMarkets, Mordor) พร้อมปี
- [ ] **ราคาห้องแล็บต่อตัวอย่าง (8–20 USD) ยังไม่ยืนยัน** — ควรเทียบราคาจริงของห้องแล็บไทย (กรมพัฒนาที่ดิน/เอกชน) ต่อชุด N/P/K/OM/pH
- [ ] ข่าว/งานวิจัยใหม่ที่ควรติดตาม: การวัด N/P/K on-the-go ด้วย ML+VIS-NIR และบริการ "soil mapping as a service" ปี 2025–2026
- [ ] ตรวจการมีอยู่ของแพลตฟอร์ม commercial อื่น (SoilOptix, AgroCares, CropX) และรอบการลงทุนล่าสุด

## 11. อภิธานศัพท์

| คำศัพท์                                | ความหมาย                                                     |
| -------------------------------------- | ------------------------------------------------------------ |
| On-the-go sensing                      | การวัดสมบัติดินต่อเนื่องขณะเครื่องจักรเคลื่อนที่             |
| ECa (apparent electrical conductivity) | ค่าการนำไฟฟ้าปรากฏของดิน บอกเนื้อดิน/ความชื้น/ความเค็ม       |
| VIS-NIR spectroscopy                   | วัดสเปกตรัมแสงช่วงมองเห็น–อินฟราเรดใกล้ เพื่อประมาณสมบัติดิน |
| ISE (ion-selective electrode)          | อิเล็กโทรดคัดเลือกไอออน วัดไนเตรต/โพแทสเซียมในสารละลาย       |
| VRT (variable rate technology)         | ระบบใส่ปัจจัยการผลิตแบบแปรผันตามตำแหน่งในแปลง                |
| Chemometrics / เคโมเมตริกซ์            | สถิติ+คณิตศาสตร์แปลงสเปกตรัมเป็นค่าธาตุอาหาร                 |
| R² (coefficient of determination)      | สัดส่วนความแปรปรวนที่แบบจำลองอธิบายได้ (เข้าใกล้ 1 = แม่นยำ) |
| Digital soil mapping                   | การสร้างแผนที่ดินต่อเนื่องจากการสุ่ม+แบบจำลอง                |
