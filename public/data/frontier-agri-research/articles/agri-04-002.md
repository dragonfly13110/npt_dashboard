## 1. บทสรุปผู้บริหาร

- **ใจความ**: สเปกตรัม LED เป็น "ตัวควบคุม" การเจริญเติบโต สัณฐาน (morphology) และสารทุติยภูมิของพืช — แดง (660 nm) กระตุ้นการสังเคราะห์แสง/ลำต้น, น้ำเงิน (450 nm) ควบคุมรูปทรง/ปากใบ/สารต้านอนุมูลอิสระ, ไกลแดง (730 nm) ยืดใบ/เร่งดอก, UV เพิ่มสารอาหารรอง (แอนโธไซยานิน/ฟลาโวนอยด์) [1][2][6]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เต็มรูปแบบ — LED กลายเป็นมาตรฐานในโรงเรือน/VF ทั่วโลก (แทน HPS); งานวิจัยยังขยับต่อที่ "spectral recipe เฉพาะพืช/เฉพาะช่วงการเจริญ"
- **ตัวเลขสำคัญที่สุด**: ประสิทธิภาพ LED 3.0–3.6 µmol/J (2025) vs HPS ~1.7 µmol/J — ไฟน้อยลง ~40–50% ต่อผลผลิต; การเพิ่มแสงเสริมในโรงเรือน +20–40% ผลผลิตผัก/มะเขือเทศ [3][5]
- **นัยต่อไทย**: งานวิจัยไทย LED ผักสลัด/เมล่อน/กล้วยไม้ (มก./มข./มจพ.) มีอยู่แต่ยังไม่เป็น "ตำราสเปกตรัมไทย" — โรงเรือนไทยส่วนใหญ่ยังใช้มุ้ง/แดดธรรมชาติ + LED เสริมเฉพาะบางฤดู [6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: พืชมีตัวรับแสง (photoreceptors) — phytochrome (แดง/ไกลแดง), cryptochrome/phototropin (น้ำเงิน/UV-A) — เมื่อ LED ปล่อยสเปกตรัมต่างกัน → กระตุ้นช่องทางฮอร์โมน (auxin, GA, ABA) เปลี่ยนการเจริญ (ยืด/กิ่งก้าน/ออกดอก) และเมแทบอไลต์ทุติยภูมิ (สี/กลิ่น/รส/สารต้านอนุมูลอิสระ) [1][2]
- **องค์ประกอบที่ปรับได้**: (1) สเปกตรัม (2) ความเข้ม PPFD (3) ระยะเวลา/รอบวัน photoperiod (4) รูปแบบเวลา (ไฟกะพริบ/ไฟเปลี่ยนตอนเช้า-เย็น) (5) ตำแหน่ง (ในทรงพุ่ม intra-canopy)
- **ค่าแสงที่นิยม**: ผักกาดหอม/ไมโครกรีน DLI 12–17 mol/m²/วัน, โหระพา 15–25, มะเขือเทศ 25–30, สตรอว์เบอร์รี 20–25, กัญชา 40–65; ไฟผสมที่ใช้จริง Red:Blue ≈ 3:1–4:1 (+ White/Green/Far-red 10–30%) [2][5]
- **ขอบเขตที่ครอบคลุม**: ผลของสเปกตรัมต่อผลผลิต/คุณภาพ (ผักใบ, มะเขือเทศ, สตรอว์เบอร์รี, สมุนไพร), การปรับรอบวัน, ประสิทธิภาพไฟ, แนวปฏิบัติเชิงพาณิชย์
- **นอกขอบเขต**: เศรษฐศาสตร์โรง (04-001), ระบบควบคุมรวม (04-005), การจัดการธาตุอาหาร (04-007), หุ่นยนต์ (04-004)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด               | ผลลัพธ์                                                                   | เงื่อนไข                     | แหล่ง  |
| ----------------------- | ------------------------------------------------------------------------- | ---------------------------- | ------ |
| ประสิทธิภาพ LED         | 3.0–3.6 µmol/J (2025, top-tier) vs HPS ~1.7 — ไฟลด 40–50%                 | แผ่นข้อมูลผู้ผลิต/งานวิชาการ | [3][5] |
| แสงเสริมในโรงเรือน      | +20–40% ผลผลิต (มะเขือเทศ/ผักใบ) เปรียบเทียบไม่มีเสริม                    | เนเธอร์แลนด์/งาน WUR         | [5]    |
| Red:Blue 3:1–4:1        | น้ำหนักสด/ใบเพิ่ม vs ไฟขาวล้วน 10–25% ในผักกาดหอม (งานส่วนใหญ่)           | งานควบคุมในห้อง              | [2][4] |
| Blue สูง (20–30%)       | ใบหนา/กะทัดรัด (compact), ปากใบเปิด — เหมาะขนย้าย; ลดการยืด               | ผักกาดหอม/ผักโขม             | [2]    |
| Far-red (730 nm)        | ยืดใบ/เพิ่มพื้นที่ใบ (จนถึงจุด), กระตุ้นออกดอกของพืชวันยาว, สะสมน้ำตาล    | งานหลายชนิด                  | [1][2] |
| UV-A/UV-B               | เพิ่มแอนโธไซยานิน/ฟลาโวนอยด์/วิตามิน C 20–60% (ผักกาดหอมแดง, เบอร์รี่)    | งาน 2020–25                  | [4][6] |
| Photoperiod ยาวขึ้น     | ผักใบผลผลิต/กก. +10–20% (12→16–18 ชม.) แต่เสี่ยง bolting (ยอดแทง) บางชนิด | ผักกาดหอม/โหระพา             | [2][5] |
| Intra-canopy            | มะเขือเทศ/แตงกวา +10–30% (ไฟในทรงพุ่ม ชั้นล่าง)                           | โรงเรือนดัตช์                | [5]    |
| กะพริบ (pulsed) สูง kHz | ประหยัดไฟ 10–20% ที่กำลังผลผลิตเท่ากัน (บางงาน)                           | งานทดลอง                     | [6]    |
| ต้นทุนไฟต่อกก.          | ผักใบ ~1–3 บาท/กก. (LED ใหม่) — ขึ้นกับค่าไฟ/ความเข้ม                     | คำนวณจาก 04-001              | [3]    |

- **กฎ**: ผลของสเปกตรัม "ขึ้นกับพันธุ์/สภาพ/ช่วงเวลา" — ตัวเลขควรอ่านเป็นแนวโน้ม ไม่ใช่ค่าคงที่; สเปกตรัมที่ดีที่สุดต้องเทียบกับเกณฑ์ (ผลผลิต/คุณภาพ/ไฟ)
- **เงื่อนไขสำคัญ**: ไฟไม่ทดแทนธาตุอาหาร/CO2/น้ำ — ต้องบูรณาการ (เชื่อม 04-005/04-007); UV ต้องระวัง (เสียหายเซลล์ได้ ถ้าเข้มเกิน)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: LED การเกษตร (horticultural LED) ทั่วโลก ~1.5–3 พันล้านดอลลาร์/ปี (2025 — analyst estimate ยังไม่ยืนยัน) [3]; โต 15–25%/ปี ตาม VF/โรงเรือน
- **ผู้เล่นหลัก**: Signify (Philips), Fluence (Osram), Heliospectra, Sananbio, Valoya, Samsung/Seoul Semiconductor (ชิป), ผู้ผลิตจีน (Sanan, Opple, Kinglumi) — ราคาชิป LED ลด ~10–20%/ปี [3][5]
- **การลงทุน**: โรงเรือนใหม่ติด LED ทั้งระบบ (แปลง HPS→LED คืนทุน ~2–4 ปีด้วยค่าไฟที่ลด — ยังไม่ยืนยัน); VF ใช้ LED เป็นต้นทุนหลัก (~25–40% OPEX — อ้างข้าม 04-001)
- **ปัจจัยขับเคลื่อน**: ราคา LED ลด, ค่าไฟสูง (ผลตอบแทนเร็วขึ้น), นโยบายคาร์บอน (ไฟลด → คาร์บอนลด)
- **ความเสี่ยง**: สเปกตรัม "แพงแต่ไม่จำเป็น" (เพิ่ม UV ต้องซื้อฮาร์ดแวร์เพิ่ม) — ต้องประเมิน ROI ตามพืช/ตลาด

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: โรงเรือนผัก/เมล่อนไทยใช้ LED เสริม (หลัก ๆ ช่วงกลางคืน/ฤดูฝน/หน้าหนาวมีเมฆ); กล้วยไม้/ไม้ประดับใช้ LED กระตุ้นดอก/ทรงต้น; ฟาร์ม VF ขนาดเล็กใน กทม./เชียงใหม่ใช้ LED 100% [6]
- **งานวิจัยไทย**: มีงาน LED ผักกาดหอม/ผักสลัด/เมล่อน (มก., มข., มจพ., มอ.) — ส่วนใหญ่เป็นงาน "เปรียบเทียบสเปกตรัมความเข้ม" ยังไม่ถึงระดับ "recipe เฉพาะพันธุ์ไทย + เศรษฐศาสตร์" [6]
- **ต้นทุน/ราคา**: อุปกรณ์ LED คุณภาพดีเริ่ม ~3,000–8,000 บาท/โคม ครัวเรือน–เชิงพาณิชย์ (ช่วง — ยังไม่ยืนยัน); ผู้จำหน่ายในประเทศหลายราย (นำเข้า + ประกอบ)
- **ข้อจำกัด**: ค่าไฟไทย ~4–5 บาท/kWh (ภาคธุรกิจ) — การใช้ LED ต้องคุ้มด้วยผลผลิต/ราคาพืช; ไฟฟ้าดับ/ไฟตก (ต้องใช้โซลาร์/แบตเตอรี่ร่วม — เชื่อม 08)
- **โอกาส**: พืชมูลค่าสูงที่ LED ช่วยได้จริงในไทย — ไมโครกรีน, ผักสลัดพรีเมียม, กล้วยไม้ตัดดอก (ส่งออก), สมุนไพร/เครื่องเทศราคาสูง (โหระพา/แมงลัก — แข่งตลาดสดได้ถ้า "ตัดรอบผลิต")

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: สเปกตรัมที่เหมาะสมสำหรับพันธุ์ผักสลัดที่นิยมไทย (กรีนโอ๊ค/เรดโอ๊ค/คอส) ณ อุณหภูมิ/ความชื้นเขตร้อน (30–35°C) — งานต่างประเทศทำในสภาพเย็น
- **Q2**: เศรษฐศาสตร์ "LED เสริม" ในโรงเรือนมุ้งไทย (ฤดูฝน/ฤดูหนาว) — ROI จริงต่อบาท
- **Q3**: สเปกตรัมเพิ่มสารต้านอนุมูลอิสระ/รสชาติของผักไทย (แพ็กชอย/กวางตุ้ง/ผักชี) — ยังไม่มี
- **Q4**: ผลระยะยาวของ UV-B ต่อกล้วยไม้ตัดดอกไทย (สี/อายุปักแจกัน) — มีงานบ้าง ยังไม่ครบ
- **Q5**: การรวม "เซนเซอร์ใบ/กล้อง → ปรับสเปกตรัมอัตโนมัติ" (dynamic) ในสภาพไทย — ยังไม่มี
- **Q6**: การใช้โซลาร์+LED ในฟาร์มไทย (กลางวันเก็บไฟ กลางคืนเปิดไฟ) — มีงานพลังงาน ยังไม่มีรวมแสง

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ---------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงทดสอบ LED เสริมในโรงเรือนมุ้ง 3 พืช (ผักสลัด, เมล่อน, กล้วยไม้) — บันทึกผลผลิต/คุณภาพ/ค่าไฟ 1 รอบปี | ทดสอบมาตรฐานความเข้มแสง (PPFD) สำหรับโรงเรือนไทย; รวมข้อมูลงานวิจัยไทยเป็น "ตำราแสงไทย"     |
| 2 (2–4 ปี) | ผู้จำหน่าย/ฟาร์มนำเสนอ "package ไฟ+สเปกตรัมตามพืช" (เซ็นเซอร์ + แอป) — ราคาเข้าถึงรายย่อย               | เงินช่วยเหลือ/สินเชื่อ LED สำหรับฟาร์ม Smart Farmer; มาตรฐานประสิทธิภาพโคม (µmol/J ขั้นต่ำ) |
| 3 (4+ ปี)  | "ไฟสูตรเฉพาะพันธุ์" + dynamic lighting อัตโนมัติ (เชื่อม 04-005) — โรงเรือนไทยประหยัดไฟ 20–40%          | นโยบายส่งเสริม CEA ใช้พลังงานสะอาด (โซลาร์+LED); การประเมินคาร์บอนต่อกก. ผักไทย             |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย        | รายละเอียด                                       | โอกาสแก้                                             |
| ----------------- | ------------------------------------------------ | ---------------------------------------------------- |
| ต้นทุนโคม/ติดตั้ง | หลักพัน–หลักหมื่นบาท/โคม — รายย่อยแบกรับยาก      | การเช่า/ผ่อน, โครงการสินเชื่อ, รวมกลุ่มซื้อ          |
| ความรู้สเปกตรัม   | สูตรแสงแต่ละพันธุ์/ช่วงอายุ ต่างกัน              | ตำราไทย + แอปแนะนำ + บริการผู้เชี่ยวชาญ              |
| ไฟกับความร้อน     | ไฟแรง → อุณหภูมิพุ่งในโรงเรือนไทย (ร้อนอยู่แล้ว) | LED เย็นกว่า HPS มาก + การระบายอากาศ (เชื่อม 04-008) |
| ไฟฟ้าไม่เสถียร    | ไฟดับ/ตก ทำรอบแสงเสียหาย                         | โซลาร์+แบตเตอรี่, เครื่องสำรอง, สัญญาไฟ              |
| UV อันตราย        | UV เข้มเกิน → ใบไหม้/ชะงัก                       | ปรับความเข้ม/เวลา, เซนเซอร์, คู่มือ                  |
| พืชไม่ตอบสนอง     | บางพันธุ์ตอบสนองสเปกตรัมน้อย (ไม่มีกำไรคืน)      | ทดสอบก่อนลงทุน (แปลงนำร่อง)                          |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ประสิทธิภาพ LED 3.0–3.6 µmol/J (2025)** — ตรวจแผ่นข้อมูลผู้ผลิต (Signify/Fluence) + งานวัดประสิทธิภาพ
- [ ] **LED เสริม +20–40% ผลผลิต** — ตรวจงาน WUR/เนเธอร์แลนด์ ระบุชนิดพืช/กำลังแสง
- [ ] **Red:Blue 3:1–4:1 เป็นมาตรฐาน** — ตรวจรีวิว (review) ล่าสุด
- [ ] **UV เพิ่มแอนโธไซยานิน 20–60%** — ตรวจงาน 2020–25 (ระบุชนิด/ความเข้ม UV)
- [ ] **ตลาด horticultural LED 1.5–3 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **ราคาโคม LED ไทย 3,000–8,000 บาท** — ตรวจตลาด/ผู้จำหน่ายไทย
- [ ] **ค่าไฟธุรกิจไทย 4–5 บาท/kWh** — ตรวจอัตราการไฟฟ้า ณ รอบอัปเดต

## 11. อภิธานศัพท์

| คำศัพท์                    | ความหมาย                                                |
| -------------------------- | ------------------------------------------------------- |
| Photomorphogenesis         | การตอบสนองการเจริญต่อแสง (ไม่ใช่การสังเคราะห์แสงโดยตรง) |
| Phytochrome                | ตัวรับแสงแดง/ไกลแดง (Pfr/Pr) — ควบคุมการออกดอก/ยืดต้น   |
| Cryptochrome / Phototropin | ตัวรับแสงน้ำเงิน/UV-A — ปากใบ/การหันใบ                  |
| PPFD                       | ความเข้มแสงช่วงสังเคราะห์ (µmol/m²/วินาที)              |
| DLI                        | ปริมาณแสงรวมต่อวัน (mol/m²/วัน) = PPFD × ชั่วโมง        |
| Spectral recipe            | สูตรสเปกตรัม (สัดส่วนสี/ความเข้ม/เวลา) สำหรับพืชหนึ่ง ๆ |
| Intra-canopy lighting      | การให้ไฟในทรงพุ่ม (ชั้นล่างของมะเขือเทศ/แตงกวา)         |
| Bolting                    | การยืดยอดแทงดอกก่อนเก็บ — ปัญหาในผักใบ (แสง/ความร้อน)   |
| µmol/J                     | ประสิทธิภาพการแปลงไฟฟ้าเป็นแสงสังเคราะห์                |
| Far-red                    | แสงไกลแดง ~700–750 nm — ยืดใบ/ออกดอก                    |
