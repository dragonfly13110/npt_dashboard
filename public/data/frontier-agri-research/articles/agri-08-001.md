## 1. บทสรุปผู้บริหาร

- **ใจความ**: Agrivoltaics (agrophotovoltaics/APV) = ตั้งแผงโซลาร์บนแปลงเดียวกันกับพืช (แผงสูง 2–5 ม. — รถ/คนทำงานใต้แผงได้) — เก็บ "ไฟฟ้า + ผลผลิต" จากพื้นที่เดียว; แผงให้ร่ม (ลดแสง 20–50% — พืชบางชนิดชอบ/ผลผลิตขึ้น; ลดการระเหยน้ำ/ความร้อน) + ไฟฟ้าช่วยค่าใช้จ่ายฟาร์ม (ปั๊มน้ำ 08-005/EV 08-004/ค่าไฟโรงเรือน) — แนวคิด/งานวิจัยนำร่องเยอะในยุโรป (สเปน/ฝรั่งเศส/เยอรมนี/เนเธอร์แลนด์), ญี่ปุ่น (ข้าว/ผัก), จีน, สหรัฐ — ไทย: เริ่มนำร่อง/นโยบาย [1][2][3]
- **ขั้นพัฒนา**: 🧪 นำร่องแปลงทดลอง/โครงการแรก (ยุโรป/ญี่ปุ่นมีโครงการพาณิชย์; ไทยเริ่มนำร่อง) [2][3]
- **ตัวเลขสำคัญที่สุด**: ผลผลิตพืชใต้แผง (งานทบทวน) = เปลี่ยนแปลง ~−30% ถึง +50% (ขึ้นชนิดพืช/ความหนาแน่นแผง/ภูมิภาค — พืชทนร่ม/ร้อน: ผัก/มันฝรั่ง/ข้าวบางกรณี ขึ้น; ข้าวสาลี/ข้าวโพดบางงาน ลด); ค่าใช้จ่ายไฟฟ้าในฟาร์มไทย (ปั๊มน้ำ/โรงเรือน) ~10–30% ของต้นทุนพลังงาน (ช่วง); รายได้ต่อไร่ (ไฟฟ้า+ผลผลิต) — APV เพิ่มมูลค่าที่ดินได้ ~2–3 เท่า (งานบางชิ้น — ช่วง; ขึ้นราคาไฟ/การออกแบบ) [1][2][3][4]
- **นัยต่อไทย**: ไทยแดดจัด/แปลงใหญ่ (อ้อย/มัน/ข้าว) — Agrivoltaics เหมาะกับ: (1) พืชทนร่ม/ราคาสูง (ผัก/กาแฟ/ผลไม้) (2) แปลงที่ต้องการร่ม (ลดการระเหย — ผูก 03) (3) พื้นที่แล้ง/ดินเสื่อม (ได้รายได้ทั้งไฟ+พืช) — แต่ติดข้อจำกัด: ต้นทุนสูง (โครงเหล็ก ~2–3 ล้านบาท/ไร่ — ช่วง), กฎ/สิทธิ์ที่ดิน (สปก./ประทาน — ต้องเช็ค), การยอมรับ (14-003), ราคารับซื้อไฟ (nett metering/PPA ยังไม่ชัด) [4][5][6]
- **สถานะโดยรวม**: 🧪 นำร่องแปลงทดลอง/โครงการแรก

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (3 รูปแบบโครงสร้าง)

1. **แผงสูง (elevated/raised)**: แผงสูง 2–5 ม. เหนือแปลง (เสาเหล็ก) — รถ/คนทำงานใต้แผงได้ (พืชไร่/ผัก/ข้าว — ญี่ปุ่น/ฝรั่งเศส) — แพงสุด แต่ใช้เครื่องจักรได้ (ผูก 07)
2. **แผงคร่อมแถว (row-mount)**: แผงทำมุม/สูงพอระหว่างแถว (สวนผลไม้/ไร่องุ่น) — ทำงานระหว่างแถวได้ — ยุโรป (องุ่น/เบอร์รี)
3. **โรงเรือนโซลาร์ (greenhouse PV)**: แผงบนหลังคาโรงเรือน (ผ้าโปร่ง/แผงโปร่งแสง — 4-12% light) — ผัก/ระบบปิด (04) — ญี่ปุ่น/เนเธอร์แลนด์

### 2.2 การออกแบบหลัก (หัวใจของงานวิจัย)

| ปัจจัย                         | รายละเอียด                                                             |
| ------------------------------ | ---------------------------------------------------------------------- |
| ความหนาแน่น/ความทึบของแผง      | ~20–50% ร่ม (แสงเหลือ 50–80% — พืชต้องพอ)                              |
| ความสูง/มุม/การหมุน (tracking) | แผงหมุนตามแดด (เพิ่มไฟ — แต่เงาเปลี่ยน; งานวิจัย)                      |
| การเลือกพืช                    | พืชทนร่ม (C3/ผักใบ/มัน/ชา/กาแฟ) vs ชอบแสง (C4 — ข้าวโพด/อ้อย บางงานลด) |
| สภาพอากาศ                      | เขตร้อน (ไทย — ร้อน/แสงแรง — ร่มอาจช่วย; ฝน/ลม)                        |
| การจัดการน้ำ/ปุ๋ย              | แผงช่วยลดการระเหย (ประหยัดน้ำ 03); การจัดการใต้แผง (02-012)            |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ผลผลิต/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: ปั๊มน้ำโซลาร์ (08-005), ตลาดคาร์บอน (08-002), EV/แบตเตอรี่ (08-004), การผลิตพลังงานชีวมวล/ไบโอแก๊ส (08-003), กฎที่ดิน (12)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                                                                     | แหล่ง     |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| 2010s     | แนวคิด APV (Fraunhofer 2014 — งาน "agrophotovoltaics"); นำร่องแรก (เยอรมนี/สเปน/ญี่ปุ่น)                                                                         | [1]       |
| 2015–2020 | งานวิจัยผลผลิตใต้แผง (ข้าว/ผัก/มันฝรั่ง — ญี่ปุ่น/ฝรั่งเศส/สเปน); นโยบายเริ่ม (ฝรั่งเศส/ญี่ปุ่น — รับรอง/หนุน)                                                   | [1][2]    |
| 2021–2025 | โครงการเชิงพาณิชย์แรก (ยุโรป — องุ่น/เบอร์รี/ผัก; จีน — แปลงใหญ่); งานทบทวนผลผลิต (~−30% ถึง +50%); ไทย: นำร่อง (เอกชน/วิจัย — ข้าว/ผัก/มัน)                     | [2][3][4] |
| 2026–     | แนวโน้ม: "APV ออกแบบเพื่อพืช" (ต่อยอด 06-001 — จำลองแสง/ผลผลิต), แผงโปร่งแสง (light-splitting), นโยบาย/PPA ชัดขึ้น (ไทย — เอกสารพลังงาน), การผูกคาร์บอน (08-002) | [3][4][5] |

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                           | ผลลัพธ์                                                          | สถานที่/เงื่อนไข    | แหล่ง  |
| ----------------------------------- | ---------------------------------------------------------------- | ------------------- | ------ |
| ผลผลิตพืชใต้แผง (เทียบแปลงเปิด)     | ~−30% ถึง +50% (ขึ้นชนิด/การออกแบบ/ภูมิภาค)                      | งานทบทวน (หลายแปลง) | [1][2] |
| พืชที่ผลผลิตขึ้นใต้แผง (งาน)        | ผักใบ/มัน/ถั่ว/ชา-กาแฟ (บางงาน +10–50%); ข้าวบางงานขึ้น (ทนร้อน) | งาน/ภูมิภาค         | [2]    |
| พืชที่ผลผลิตร่วงใต้แผง (งาน)        | ข้าวโพด/ข้าวสาลี/อ้อย (บางงาน −10–30%)                           | งาน (แสงไม่พอ)      | [1][2] |
| การประหยัดน้ำ (การระเหยลดใต้แผง)    | ลดได้ ~10–30% (งาน — ช่วง)                                       | งานทดลอง            | [2][3] |
| ต้นทุนโครงสร้าง APV                 | ~2–5 ล้านบาท/ไร่ (ช่วง — ขึ้นโครง/แผง)                           | ตลาด/งาน            | [4]    |
| รายได้รวมต่อไร่ (ไฟ+ผลผลิต — APV)   | เพิ่มมูลค่าที่ดิน ~2–3 เท่า (งานบางชิ้น — ช่วง; ขึ้นราคาไฟ/PPA)  | งาน/ผู้พัฒนา        | [3][4] |
| ไฟฟ้าที่ผลิต (ต่อไร่ — ช่วง)        | ~150–300 กิโลวัตต์/ไร่ (ติดตั้ง — ขึ้นแผง)                       | ผู้พัฒนา            | [3]    |
| นโยบาย/ราคารับซื้อไทย (โซลาร์ฟาร์ม) | ยังไม่ชัดสำหรับ APV (รับซื้อแบบฟาร์ม — ช่วง)                     | เอกสารพลังงาน       | [5]    |

- **กฎ**: "APV ไม่ใช่ 'ปลูกอะไรก็ได้ใต้แผง' — ต้องเลือกพืช/การออกแบบตามพื้นที่ (ผลผลิตผันผวน −30% ถึง +50%)" — "คุ้มเมื่อราคาไฟสูง + พืชทนร่ม + พื้นที่ที่มีปัญหา" — ตัวเลขช่วงกว้าง/หลายแหล่ง ใช้เทียบเคียงทิศทาง (ตรวจหัวข้อ 10)
- **หมายเหตุ**: ตัวเลขจากผู้พัฒนา/งาน — ต้องตรวจอิสระ (ราคา/ผลผลิต)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด Agrivoltaics ~$3–9 พันล้านดอลลาร์ (2030 — analyst ช่วงกว้าง — ยังเล็กแต่โตเร็ว); ยุโรป/ญี่ปุ่น/จีนนำ [3][4]
- **ผู้เล่นหลัก**: ผู้พัฒนาโซลาร์/พลังงาน (ยุโรป/ญี่ปุ่น/จีน — Next2Sun/ผู้พัฒนา), มหาวิทยาลัย/งานวิจัย (Fraunhofer-class), ไทย: การไฟฟ้า/ผู้ประกอบการโซลาร์ (เริ่มนำร่อง), เอกชนที่ดินใหญ่ (อ้อย/มัน — บริษัท)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                            | ฉุดรั้ง                             |
| ------------------------------------- | ----------------------------------- |
| ที่ดินแข่ง (ไฟ vs อาหาร — APV แก้ได้) | ต้นทุนโครงสูง (2–5 ล้าน/ไร่)        |
| รายได้สองทาง (ไฟ+ผลผลิต)              | ผลผลิตผันผวน (ความเสี่ยงเกษตรกร)    |
| ร่มช่วยลดน้ำ/ความร้อน (เขตร้อน — ไทย) | กฎ/สิทธิ์ที่ดิน (สปก. — ห้าม/จำกัด) |
| นโยบายพลังงานสะอาด (หลายประเทศหนุน)   | ราคารับซื้อ/PPA ไทยยังไม่ชัด        |
| คาร์บอน/ESG (08-002 — รายได้เพิ่ม)    | การยอมรับ/ความรู้ (14-003)          |

- **แนวโน้ม**: การออกแบบเฉพาะพืช (จำลองแสง 06-001), แผงโปร่งแสง (แสงผ่านบางส่วน), แนวตั้ง (vertical — เช้า-เย็น), นโยบาย/PPA ชัด (ไทย), การผูกคาร์บอน (08-002)/EV (08-004)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยเริ่มนำร่อง APV (เอกชน/มหาวิทยาลัย/การไฟฟ้า — ข้าว/ผัก/มัน/กาแฟ — 2024–25); นโยบายโซลาร์ฟาร์มไทยมีอยู่ (รับซื้อ — ช่วง) แต่ "APV/โซลาร์บนแปลงเกษตร" ยังไม่มีระเบียบ/ราคารับซื้อเฉพาะ; กฎที่ดิน (สปก./ที่ดิน ส.ป.ก. — การใช้ประโยชน์) เป็นข้อจำกัด (ต้องเช็ค); งานวิจัยไทย (แสง/ผลผลิต — มก./มจธ./มข.) เริ่ม [5][6]
- **จุดแข็งไทย**: แดดจัด (ผลิตไฟดี), แปลงใหญ่ (อ้อย/มัน/ข้าว — บริษัท/สหกรณ์), พืชทนร่มราคาดี (กาแฟ/ผัก/ผลไม้), ต้นทุนแรงงาน/ก่อสร้างต่ำ, นโยบายโซลาร์ (ภาครัฐสนับสนุน)
- **จุดอ่อน**: ระเบียบ/สิทธิ์ที่ดิน (สปก.) ยังจำกัด, ราคารับซื้อ/PPA ยังไม่ชัด, งานวิจัยผลผลิตใต้แผง (ไทย) ยังน้อย, การยอมรับ (14-003), ต้นทุนโครงสูง (ฟาร์มเล็กไม่ไหว), ความเสี่ยงราคาไฟ/นโยบาย
- **โอกาส**: (1) "APV สำหรับพืชทนร่มไทย" (กาแฟ/ผัก/ผลไม้ — งานวิจัย+นำร่อง มก./มจธ.) (2) "APV ในแปลงอ้อย/มันของบริษัท" (พื้นที่แล้ง/ดินเสื่อม — รายได้ไฟ+พืช) (3) "โรงเรือนโซลาร์" (04 — ผักส่งออก — ไฟฟ้า+ร่ม) (4) นโยบาย/PPA APV ไทย (การไฟฟ้า+กกพ. — รับซื้อ/ระเบียบ) (5) การผูกคาร์บอน (08-002) + EV (08-004)
- **หน่วยงาน**: กกพ./การไฟฟ้า (นโยบาย/รับซื้อ), สปก./กรมที่ดิน (สิทธิ์), มก./มจธ./มข. (วิจัย), ผู้ประกอบการโซลาร์/ที่ดินใหญ่, กรมวิชาการ (ผลผลิต), NIA/สวทช. (ทุน)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: งาน "ผลผลิตใต้แผง" สำหรับพืชหลักไทย (ข้าว/มัน/อ้อย/กาแฟ/ผัก — หลายภูมิภาค/หลายฤดู) — ยังไม่มีข้อมูลครบ
- **Q2**: การออกแบบ APV "เพื่อพืชไทย" (ความทึบ/ความสูง/มุม/การหมุน — จำลองแสง 06-001) — ยังไม่มี
- **Q3**: ระเบียบ/สิทธิ์ APV บนที่ดิน สปก./ที่ดินเกษตรไทย — ยังไม่ชัด (เอกสาร)
- **Q4**: เศรษฐศาสตร์ APV ไทย (บาท/ไร่ — ราคาไฟ/PPA/ผลผลิต) — ยังไม่มีข้อมูลเปิด
- **Q5**: ผลของร่มต่อการระเหย/คุณภาพน้ำ/ดิน (ไทย — เขตร้อน) — ยังไม่มีงาน
- **Q6**: การยอมรับของเกษตรกร/เจ้าของที่ดิน (14-003) ต่อ "แผงบนแปลง" — ยังไม่มี
- **Q7**: มาตรฐานความปลอดภัย/การบำรุง (แผง+โครง — ลม/พายุไทย) — ยังไม่มี

## 11. อภิธานศัพท์

| คำศัพท์                        | ความหมาย                                  |
| ------------------------------ | ----------------------------------------- |
| Agrivoltaics (APV)             | โซลาร์+พืชแปลงเดียวกัน (ไฟ+ผลผลิต)        |
| Agrophotovoltaics              | ชื่อเดิมของ APV (Fraunhofer)              |
| Shade tolerance                | ความทนร่มของพืช (เลือกใต้แผง)             |
| Bifacial panel                 | แผงสองหน้า (เก็บแสงสองด้าน — แนวตั้ง)     |
| Light splitting                | แผงโปร่งแสง (แสงผ่านบางส่วน)              |
| Vertical mounting              | แผงแนวตั้ง (แดดเช้า-เย็น — พืชระหว่างแถว) |
| Elevated structure             | โครงยกสูง (2–5 ม. — เครื่องจักรผ่าน)      |
| PPA (Power Purchase Agreement) | สัญญาซื้อขายไฟฟ้า (ราคารับซื้อ)           |
| Net metering                   | การหักกลบไฟ (ผลิตใช้เอง/ขาย)              |
| Land use conflict              | การแย่งที่ดิน (ไฟ vs อาหาร)               |
| Evapotranspiration             | การคายระเหย (แผงช่วยลด — ประหยัดน้ำ)      |
| Crop modeling (06-001)         | การจำลองผลผลิต/แสง (ออกแบบ APV)           |
| Solar farm                     | ฟาร์มโซลาร์ (ไม่มีพืช — เทียบ APV)        |
| ส.ป.ก. (ที่ดิน)                | การถือครองที่ดินทำกิน (กฎ APV — ต้องเช็ค) |
| EIA                            | การประเมินผลกระทบ (โครงการใหญ่)           |
| Feed-in tariff                 | อัตรารับซื้อไฟฟ้า (นโยบาย)                |
| Greenhouse PV                  | โรงเรือนหลังคาแผง (04)                    |
| Energy crop                    | พืชพลังงาน (อ้อย/มัน — APV ต้องระวังแสง)  |
