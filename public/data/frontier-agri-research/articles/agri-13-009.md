## 1. บทสรุปผู้บริหาร

- **ใจความ**: การสำรองอาหารเชิงยุทธศาสตร์ = สต็อก/คลังอาหารที่รัฐถือไว้รับมือวิกฤต (ภัยพิบัติ/ราคาพุ่ง/ห้ามส่งออกของคู่ค้า) — หัวใจคือ **ข้าว** (พืชหลักในเอเชีย — 18% ของพลังงานรายวันของคนโลก-class [14]) — โครงสร้างสต็อกโลกเบี้ยวสุดขั้ว: **จีน + อินเดีย ถือ ~80% ของสต็อกข้าวโลก** (สต็อกโลก 188.8 ล้านตัน-class 2025/26 — USDA) [1][17] — กลไกระดับภูมิภาค: **APTERR** (ASEAN+3 — โควตา 787,000 ตัน-class — แต่เล็กกว่า "อุปสงค์อาเซียน 1.5 วัน") [7][10] — บทเรียน: **อินเดียห้ามส่งออกข้าวขาว 2023 → ราคาข้าวโลกพุ่ง 15–32%-class** [11][12][13][14] — ไทย: สต็อก ~2.85 ล้านตัน-class (อันดับ 5 โลก) vs บริโภคในประเทศ ~11 ล้านตัน/ปี → **อุ้มได้ ~2–3 เดือน-class** [17][18] แต่สต็อกภาครัฐแท้จริงเล็ก (~2.4 แสนตัน-class — เอกชนถือหลัก) [35] — บทเรียนจำนำข้าว 2554–2557 (สต็อก 18 ล้านตัน/ขาดทุน 5 แสน–1 ล้านล้านบาท) [19][20][21] — ระดับโลก: WTO ยังหาข้อยุติ "public stockholding" ไม่ได้ (MC14 มี.ค. 2569) [26][27]
- **ขั้นพัฒนา**: 🏭 ใช้จริง/ขยาย (สต็อกของรัฐ+กลไกระดับภูมิภาค — ดำเนินการทั่วโลก) [6][7][23]
- **ตัวเลขสำคัญที่สุด**: (1) สต็อกข้าวโลก 188.8 ล้านตัน (2025/26 — USDA ธ.ค. 2568) จีน+อินเดีย ~80% [1] (2) อินเดียแบนส่งออกข้าวขาว 20 ก.ค. 2566 → ราคา Thai 5% broken +22% (ต.ค. 2567) [13] (3) ไทยสต็อก ~2.85 ล้านตัน = ความคุ้มครอง ~3 เดือน-class [17][18] — APTERR 787,000 ตัน แต่ปล่อยจริง Tier 3 รวม >60,000 ตัน (2011–2026) [9]
- **นัยต่อไทย**: ไทย (1) เป็นผู้ส่งออกข้าวอันดับ 2–3 ของโลก-class (7–8 ล้านตัน/ปี) [17][30] — สำรองขนาดกลางพอดี (ไม่ง้อสต็อกยักษ์แบบจีน/อินเดีย) (2) สต็อกภาครัฐเล็ก — "อุ้มได้" ส่วนใหญ่มาจากสต็อกเอกชน (โรงสี/ผู้ส่งออก) [35] (3) บทเรียนจำนำข้าว (13-009 เชื่อม 12-005 — ประกันรายได้) — ราคาประกันไม่บิดเบือนเหมือนรับจำนำ [19][21] (4) APTERR — เลขาฯ ตั้งในไทย-class [6] — สินทรัพย์เชิงภูมิรัฐศาสตร์อาหาร (5) โอกาส: งาน "ระดับสต็อกที่คุ้มค่าที่สุดของไทย" ยังไม่มี [ดู Q6] — ต้นทุนถือครอง $44–95/ตัน/ปี-class [23] — จุดสำคัญ: สต็อกช่วย "Stability" (13-005) แต่ต้องไม่ซ้ำรอย "กักข้าวจนเน่า" — ยอดดุลระหว่างความมั่นคงกับต้นทุน [19][20]
- **สถานะโดยรวม**: 🏭 ใช้จริง/ขยาย (สต็อกของรัฐ + APTERR + นโยบาย — ดำเนินการ)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (ทำไมต้องถือสต็อก + ใครถือ)

1. **เหตุผลของรัฐ**: ราคาอาหารผันผวนรุนแรง (elasticity ต่ำ — อุปสงค์/อุปทานยืดหยุ่นน้อย) + วิกฤตเกิดซ้ำ (1972–75, 2007–08, 2020 COVID, 2022–23 สงคราม/อินเดียแบน) — สต็อก = เบาะรองรับแรงกระแทก [23][28]
2. **ระดับสต็อก vs ราคา**: stock-to-use ratio (สต็อก/การใช้) ต่ำ → ราคาพุ่งแรง; วิกฤต 2516/2549 โลกมีสต็อกธัญพืชต่ำกว่า 17% — งานจำลอง: สต็อกที่สูงขึ้นจะลดการพุ่งของราคาได้ 38–52% [28]
3. **ใครถือครอง**: (ก) รัฐ — ความมั่นคง/แทรกแซงราคา (ข) เอกชน — โรงสี/พ่อค้า/ผู้ส่งออก (ถือเพื่อธุรกิจ) — ตลาดเอกชนถือระดับ "ไม่เหมาะสมทางสังคม" (private storage ต่ำกว่า social optimum-class — ประโยชน์สาธารณะของการมีสต็อก) [23][28] (ค) ภูมิภาค — APTERR/SAARC Food Bank/ECOWAS-class [24]
4. **เครื่องมือของสต็อกภาครัฐ**: รับซื้อจากเกษตรกร (MSP อินเดีย/รับจำนำ-ประกันรายได้ไทย 12-005) → เก็บในคลัง → ระบายยามขาดแคลน/ราคาพุ่ง — การแทรกแซงราคาโดยตรง = จุดถกเถียง WTO [23][26]

### 2.2 ขอบเขต

- **ครอบคลุม**: สต็อกข้าวโลก (ขนาด/การกระจุกตัว) / มาตรการห้ามส่งออก (กรณีอินเดีย) / APTERR (กติกา-จำนวน-การใช้งาน) / คลังข้าวไทย (รับจำนำ-ประกันรายได้-สต็อก) / ต้นทุนถือครอง/การบิดเบือน / ข้อเสนอระดับโลก (WTO)
- **นอกขอบเขต**: นโยบายข้าวไทยลึก (ราคา-ชดเชย — ดู [12-005 นโยบายข้าว](12-ระบบอาหาร เศรษฐศาสตร์ และนโยบาย/เจาะลึก-12-นโยบายข้าวยาง-ประกันรายได้.md)), ความมั่นคงอาหาร 4 เสาหลัก (13-005), traceability/คุณภาพ (13-002), FLW ในคลังเก็บ (13-001), การปรับตัวโลกร้อน (08-002-class)

## 5. ตลาดและการลงทุน

- **ขนาด**: ไม่ใช่ "ตลาด" แต่เป็นรายจ่ายสาธารณะ + โครงข่ายการค้า: การค้าข้าวโลก 62.8 ล้านตัน (2026 — สูงสุดเป็นประวัติการณ์) [1][17] — ต้นทุนสต็อกฉุกเฉิน $1–58 ล้าน/ปี-class (ธนาคารโลก-class — ขึ้นกับขนาด/ความคุ้มครอง) [23] — ต้นทุนเก็บสต็อก $44–95/ตัน/ปี [23] — ต้นทุนรวม PSH 0.5–1.5% ของ GDP (อินเดีย/อินโดนีเซีย/ฟิลิปปินส์/แซมเบีย-class) [24]
- **ผู้เล่นหลัก**: รัฐ (FCI อินเดีย/China state reserves/BULOG อินโดนีเซีย/อคส. ไทย), ภูมิภาค (APTERR/SAARC Food Bank/ECOWAS-class [24]), เอกชน (โรงสี/ผู้ส่งออก — ถือสต็อกเพื่อการค้า), องค์กรระหว่างประเทศ (WTO/FAO/ธนาคารโลก — กติกา/คำแนะนำ) [6][23][26]

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน (ทำไมถือ/ถือเพิ่ม)                           | ฉุดรั้ง (ทำไมถือน้อย/เลิก)                  |
| ------------------------------------------------------- | ------------------------------------------- |
| วิกฤตซ้ำ (COVID/สงคราม/El Niño-class)                   | ต้นทุนถือครองสูง ($44–95/ตัน/ปี-class)      |
| การห้ามส่งออกของคู่ค้า (อินเดีย 2023-class)             | สต็อกเน่า/เสื่อมคุณภาพ (ไทย 2 แสนตัน-class) |
| บทบาท "เบาะ" ลดราคาพุ่ง (38–52%-class)                  | บิดเบือนราคา/การลงทุน (จำนำข้าว 2554–57)    |
| ความมั่นคงอาหาร = ประเด็นการเมืองในประเทศ (อินเดีย MSP) | ข้อจำกัด WTO (PSH ยังไม่มีข้อยุติ)          |
| อุปสงค์จีน/แอฟริกา-class                                | งบประมาณ (ต้นทุน PSH 0.5–1.5% GDP-class)    |

- **แนวโน้ม**: สต็อกโลก "ล้น" ระยะสั้น (อินเดียระบาย — ราคาต่ำ [4][17]) → แรงจูงใจถือสต็อกลดลง; แต่ระยะยาวโลกร้อน/ความเสี่ยงภูมิรัฐศาสตร์ (08-002-class) → งาน "ระดับสต็อกที่พอดี" (อิงต้นทุน/ความเสี่ยง) = โจทย์วิจัย [ดู Q1–Q6]

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: (1) ผู้ส่งออกข้าวอันดับ 2–3 โลก (7–8 ล้านตัน/ปี-class; 2568 จริง 7.9 ล้านตัน) [17][30][31] (2) สต็อกรวม ~2.85 ล้านตัน (อันดับ 5 โลก) = ความคุ้มครอง ~3 เดือน-class [17][18] (3) สต็อกภาครัฐแท้จริงเล็กมาก (อคส. ~2.4 แสนตัน-class — ระบายล็อตสุดท้าย 15,013 ตัน) — เอกชน (โรงสี/ผู้ส่งออก) ถือครองหลัก [35] (4) นโยบาย: เปลี่ยนจากรับจำนำ (2554–2557 — สต็อก 18 ล้านตัน/ขาดทุน 5 แสนล้านบาท-class) เป็นประกันรายได้ (12-005 — รัฐชดเชยส่วนต่างราคา ไม่กักสต็อก) [19][20] (5) มาตรการระยะสั้น: ดูดซับข้าวเปลือกผ่านสหกรณ์/อคส. เป้า 4 ล้านตัน (68/69) ราคาขั้นต่ำ 12,000 บาท/ตัน [29]
- **จุดแข็งไทย**: ผลผลิตเกินบริโภค (ปี 2568 ผลผลิต ~22 ล้านตันข้าวสาร-class vs บริโภค 11 ล้านตัน — เหลือส่งออก) [18] — สต็อกเอกชนกระจายทั่วประเทศ (โรงสี ~1,000+ ราย-class) — เลขาฯ APTERR ตั้งในไทย (ฮับข้อมูล/เครือข่าย) [6] — ประกันรายได้ไม่สร้าง "ภูเขาข้าว" แบบจำนำข้าว [19]
- **จุดอ่อน**: สต็อกภาครัฐเล็ก — "อุ้มได้ ~3 เดือน" พึ่งตลาดเอกชนเป็นหลัก (ถ้าเอกชนกัก/ส่งออกหมด → รัฐไร้อาวุธ) [18][35] — บทเรียนจำนำข้าว → ความเชื่อมั่นนโยบายสต็อกต่ำ [19][20] — ราคาไทยแพงกว่าอินเดีย $40–50/ตัน-class → แย่งตลาดไม่ได้เมื่ออินเดียระบาย [18] — ข้อมูลสต็อกภาคเอกชนไม่เปิดเผยสม่ำเสมอ (งานวิจัย Q2) — ต้นทุนเก็บ (ความชื้น/แมลง/เน่า — เชื่อม 13-001) [23]
- **โอกาส**: (1) งาน "ระดับสต็อกปลอดภัย+ต้นทุนคุ้มค่า" ของไทย (อิง FAO 17%-class / ต้นทุน $44–95/ตัน) [23][28] (2) "ความร่วมมือ APTERR+" — ขยายโควตา/การ prepositioned (ไทยเป็นเจ้าภาพ — เพิ่มบทบาท) [9] (3) "สต็อกเสมือน/สัญญาซื้อขายล่วงหน้า" (virtual reserve-class — ลดต้นทุนกายภาพ) [24] (4) "เอกชน-รัฐหุ้นส่วนถือสต็อก" (PPP — แชร์ต้นทุนเก็บ) [23] (5) ระบบข้อมูลสต็อกเปิด (เชื่อม 06-class — คาดการณ์)
- **หน่วยงาน**: กระทรวงพาณิชย์/อคส. (สต็อก/ระบาย), กรมการข้าว/กรมการค้าต่างประเทศ (ข้อมูล/ส่งออก), กระทรวงเกษตรฯ/ธ.ก.ส. (12-005 — ประกันรายได้), สศก. (สถิติ), APTERR Secretariat (ภูมิภาค), WTO/FAO (กติกา)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ระดับสต็อกที่ "เหมาะสมที่สุด" ของไทย (อิงต้นทุนถือครอง vs ความเสี่ยงวิกฤต/ราคา) — ยังไม่มีงานวิเคราะห์อัปเดต (งานเก่า = จำนำข้าว 2557) [19][23]
- **Q2**: ข้อมูลสต็อกภาคเอกชนไทย (โรงสี/ผู้ส่งออก — จริงเท่าไร/อยู่ที่ไหน) — ยังไม่เปิดเผยสม่ำเสมอ — จำเป็นต่อการออกแบบนโยบาย [18][35]
- **Q3**: ผลของ "อินเดียกลับมาส่งออกเต็มกำลัง (2025–26)" ต่อสต็อก/ราคาไทยระยะยาว — ยังอยู่ระหว่างการเกิด [4][17]
- **Q4**: APTERR ควรขยายโควตา/กลไกเร็วขึ้นไหม? (งานจำลอง ADB-class: สต็อกปัจจุบันไม่พอรับภัยรุนแรง — งานเก่า 2560 ต้องอัปเดต) [10][32]
- **Q5**: มาตรการ "ราคาขั้นต่ำ+รับซื้อ" (68/69-class) ต่างจากจำนำข้าวตรงไหน/เสี่ยงสะสมสต็อกใหม่หรือไม่ — ต้องติดตาม [29]
- **Q6**: ทางเลือกสต็อกแบบใหม่ (virtual reserve/PPP/สัญญาล่วงหน้า-class) เหมาะกับไทยไหม — ยังไม่มีงาน [23][24]
- **Q7**: โลกร้อน (08-002-class) เปลี่ยน "ความถี่วิกฤตที่ต้องใช้สต็อก" อย่างไร — งานคาดการณ์ยังน้อย [32]

| Stock-to-use ratio        | สต็อกต่อการใช้ (%) — ต่ำ <17% = เสี่ยงวิกฤต (ธัญพืช-class)     |
| Earmarked reserve         | โควตาสต็อกที่แต่ละประเทศ "สำรองไว้" (ไม่ต้องวางกองจริง)        |
| APTERR                    | ASEAN+3 Emergency Rice Reserve — โควตา 787,000 ตัน-class       |
| Tier 1/2/3 (APTERR)       | เชิงพาณิชย์ / กู้-ให้แบบตกลงทวิภาคี / บริจาคฉุกเฉิน            |
| Pre-positioned stock      | สต็อกที่วางล่วงหน้าในประเทศเสี่ยงภัย                           |
| MSP (อินเดีย)             | ราคารับซื้อขั้นต่ำของรัฐ — ต้นตอสต็อกอินเดียล้น                |
| MEP                       | Minimum Export Price — ค่าราคาขั้นต่ำส่งออก (อินเดีย 2024)     |
| Public Stockholding (PSH) | การถือสต็อกสาธารณะเพื่อความมั่นคงอาหาร — ประเด็น WTO           |
| Peace clause              | ข้อตกลงระงับการฟ้อง (Bali 2556) จนกว่าจะมี permanent solution  |
| การบิดเบือนราคา           | สต็อกรัฐเกินจำเป็น → กด/ดันราคาผิดธรรมชาติ (จำนำข้าว-class)    |
