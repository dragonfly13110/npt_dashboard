## 1. บทสรุปผู้บริหาร

- **ใจความ**: ผลกระทบระยะยาว (climate change trend) ต่อข้าว/ข้าวโพด/มันสำปะหลัง/อ้อยไทย ถูกประเมินด้วยแบบจำลองพืช (DSSAT/APSIM-class) ต่อกับ GCM ภายใต้ RCP (CMIP5) และ SSP (CMIP6) — ทิศทางหลัก = ผลผลิตลดลงเมื่ออุณหภูมิเกินขีดจำกัด โดยเฉพาะ SSP5-8.5 ปลายศตวรรษ แต่ผลยังต่างกันมากตามลุ่มน้ำ/โมเดล/การปรับตัว [1][2][3][21]
- **ตัวเลขสำคัญที่สุด**: ข้าวไทยนาปี/นาปรัง คาดลด **-6.0% ถึง -17.7%** ภายใต้ SSP5-8.5 (ช่วงกลาง–ปลายศตวรรษ, ภาคเหนือตอนล่าง) [2]; อ้อยไทยผลผลิตรวม **-24.9% ถึง -34.9%** (2046–2055, RCP4.5/8.5) [10]; มันสำปะหลังผลผลิตรวม **-14.7% ถึง -21.3%** [8]; ระดับโลก: ผลผลิตอาหารโลกลด **-8% ภายใน 2050** และ **-11% (net zero) ถึง -24% (SSP สูง) ภายใน 2100** [9]; ข้าวลด ~**-8.1% ต่อ 1°C** ที่โลกร้อนขึ้น (เอเชียใต้/ตะวันออกเฉียงใต้เสี่ยงสุด) [14]
- **สถานะโดยรวม**: 🔬 งานวิจัย (ตัวแบบประเมินผลกระทบ = สากล/เป็นเครื่องมือมาตรฐานแล้ว แต่ผลลัพธ์ระดับชาติไทยยังกระจายรายลุ่มน้ำ รายพืช; การนำไปผูกประกันภัย/ตัดสินใจเชิงพาณิชย์ยังเริ่มต้น)
- **นัยต่อไทย**: การปรับตัวที่ได้ผลดีสุด = ชลประทาน + ธาตุอาหาร (กู้คืนผลผลิตได้ถึง +8.2% ถึง +42.7% ตาม IPCC AR6 — สูงสุดในกัมพูชา/ไทย) [1], เปลี่ยนวันปลูก/พันธุ์ (+7–15% ผลผลิตจำลอง) [18] และสลับพืช (ข้าวโพด/ถั่วแทนข้าวนาปี 2) [2] — แต่ยังมี yield gap สูง (นาไร่ฝน ~55%) เป็น "ตัวกันชน" ของไทย [23]

## 2. หลักการและขอบเขต

- **กลไก 4 ขั้น**: (1) GCM จำลองภูมิอากาศอนาคต (CMIP6/SSP: SSP1-2.6 → SSP5-8.5) (2) downscale ให้ละเอียดระดับลุ่มน้ำ/ตารางกิโลเมตร (3) แบบจำลองพืชจำลองการเจริญรายวัน — อุณหภูมิ (heat stress ช่วงออกดอก/เมล็ดลีบ), ฝน/ความเครียดน้ำ, รังสี, CO₂ (C3: ข้าว/มัน/อ้อย ได้ประโยชน์ CO₂ fertilization; C4: ข้าวโพด/อ้อย ได้น้อย) (4) เปรียบเทียบกับ baseline → % เปลี่ยนแปลงผลผลิต [2][5][15]
- **ตัวขับหลัก**: อุณหภูมิสำคัญกว่าฝนต่อผลผลิตข้าวในหลายงาน (degree-day สูงกว่าเกณฑ์ 33°C มีผลรุนแรง; ข้าวลด -7% ต่อ +1°C อุณหภูมิกลางคืน) [16]; ความร้อนสะสมทำลายการผสมเกสร/เมล็ดลีบ [16][17]; ฝนเปลี่ยนฤดูทำร้ายข้าวนาไร่ [23]
- **ขอบเขตที่ครอบคลุม**: คาดการณ์ SSP/RCP ของข้าว ข้าวโพด มันสำปะหลัง อ้อย (ไทย + ภูมิภาค + ระดับโลกที่อ้างอิงได้), ตัวเลข CO₂ fertilization, การปรับตัวที่พิสูจน์แล้ว, งานไทย (มก./มพ./มข. และหน่วยงาน)
- **นอกขอบเขต**: ENSO/ความแปรปรวนรายปี (ดูไฟล์ ENSO), พันธุกรรมต้านทาน (../01), ระบบชลประทาน/น้ำ (../03), ต้นทุนคาร์บอน/ตลาดคาร์บอนของนาข้าว, ผลต่อปศุสัตว์/ประมง

## 3. สถานะงานวิจัย

| ช่วงเวลา   | ความก้าวหน้า                                                                                                                                                                                                                                        | แหล่ง         |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| 1990s–2009 | แบบจำลอง DSSAT/APSIM ใช้ประเมินข้าวไทยรายแปลงแรกๆ (ศรีสะเกษ 1,030 แปลง: 1 ใน 3 แปลงผลผลิต -30 ถึง -40% ตาม DSSAT; แต่เมื่อรวมการปรับตัวของเกษตรกร เฉลี่ย -13%)                                                                                      | [6]           |
| 2010s      | ยุค CMIP5/RCP: ลุ่มน้ำมูล/แม่น้ำสงคราม/ร้อยเอ็ด (DSSAT: -1.2% ถึง -14.7% ตามช่วงปี/สคริปต์) + งาน panel จังหวัดทั้งประเทศเริ่มทำอ้อย/มันสำปะหลัง (2020)                                                                                             | [3][7][8][10] |
| 2020–2022  | เปลี่ยนสู่ CMIP6/SSP (Arunrat et al. 2022: SSP2-4.5/SSP5-8.5 ภาคเหนือตอนล่าง); IPCC AR6 WGII เอเชีย (2022) สรุป "ผลผลิตพืชลด โดยเฉพาะเอเชียใต้/ตะวันออกเฉียงใต้" (medium confidence)                                                                | [1][2]        |
| 2023–2026  | เน้น heat stress/ขีดจำกัดความร้อน (ข้าวเกินเกณฑ์อุณหภูมิเฉลี่ย 28°C ปลายศตวรรษ — SE Asia); งานระดับโลกชี้ "แม้ปรับตัวแล้วผลผลิตยังลด -8% 2050" (Nature 2025); งาน SE Asia รายฤดูฝนใหม่ (Climatic Change 2026: นาข้าวฝน 76% ของพื้นที่ผลผลิตลด >10%) | [9][17][23]   |

- **เส้นแบ่ง**: การประเมินผลกระทบ = งานวิจัยที่โตเต็มที่ (เครื่องมือมาตรฐานโลก, DSSAT v4.8.5 ฟรี) แต่การคาดการณ์ระดับชาติไทยแบบ SSP ครบวงจร + การนำไปผูกประกันภัย/การวางแผนเชิงพาณิชย์ = ยังอยู่ในช่วงวิจัย/นำร่อง

| ข้าวไทยจริง (เอลนีโญ 2023/24)   | **-3.27%** (-871,000 ตัน, เหลือ 25.8 ล้านตัน) — ความแปรปรวนรายปีเทียบผลระยะยาวได้ (ดูไฟล์ ENSO)                                                                                                                                         | OAE/กระทรวงเกษตร                                                       | [19]     |
| ความไม่แน่นอนของโมเดล           | ทางเลือกโมเดลพืช = ความไม่แน่นอน 10–20% ของผลผลิตโลก (ข้าว/ข้าวโพด/ข้าวสาลี)                                                                                                                                                            | Global ensemble                                                        | [22]     |

- **กฎ**: ตัวเลขไทย = การจำลอง (แบบจำลอง + GCM) ไม่ใช่ผลจริง — ต่างลุ่มน้ำ/ต่างชุด GCM เทียบกันต้องระวัง; RCP (CMIP5) vs SSP (CMIP6) ต่างฐานกัน — ใช้เทียบเคียงทิศทาง; ช่วงกว้าง/ผลขัดแย้ง (เช่น ร้อยเอ็ดผลบวก) = สะท้อนความไม่แน่นอนจริง

## 5. ตลาดและการลงทุน

- **ความสำคัญเชิงตลาดไทย**: ข้าว = ผู้ส่งออกรายใหญ่ (อันดับ ~2 ของโลก); มันสำปะหลัง = ผู้ส่งออกอันดับ 1 โลก (แป้งมัน 72.3% ของมูลค่าส่งออกโลก 2019) [8]; อ้อย = ผู้ส่งออกน้ำตาลอันดับ 2 โลก (16.95% ของปริมาณส่งออกโลก, US$2.97 พันล้าน 2019) [10] — ตัวเลขคาดการณ์ลด 15–35% ระยะ 2046–2055 จึงกระทบรายได้ 1 ล้านครัวเรือนอ้อย + 5 แสนครัวเรือนมันสำปะหลังโดยตรง [8][10]
- **ผู้เล่น/การลงทุนงานวิจัย**: ทีม มก. (Attavanich — โมเดล panel รายจังหวัด: ข้าว/อ้อย/มัน/ปาล์ม; ทบทวนวรรณกรรมความมั่นคงอาหารไทย 2023) [20], มพ./มช. (Amnuaylojaroen — WRF/DSSAT ภาคเหนือ) [5], มหิดล (ลุ่มน้ำบางปะกง) [4]; ทุนวิจัย NRCT/BEDO/NARIT [5]; ภาครัฐ: DCCE Climate Risk Map ระดับตำบล (เป้า 2028 — ดูไฟล์ ENSO)
- **ตลาดปลายน้ำที่ได้รับอานิสงส์**: ประกันภัยพืชผล/ประกัน index-based, บริการ advisory พยากรณ์ผลผลิต (AgTech), การวางแผนโรงงานน้ำตาล/แป้งมัน (รับซื้อล่วงหน้า) — ยังไม่มีตัวเลขตลาดไทยเปิดเผย (ช่องว่าง Q3)
- **ปัจจัยขับเคลื่อน**: ราคาอาหารโลกผันผวนตามสภาพอากาศ, นโยบายลดนาปรัง/ส่งเสริมพลังงานชีวภาพ (อ้อย-มัน) [10], มาตรฐานความยั่งยืนของคู่ค้า
- **ปัจจัยฉุดรั้ง**: ความไม่แน่นอนของตัวเลขคาดการณ์ (10–20% จากโมเดล [22]), ข้อมูลเพื่อสอบเทียบแบบจำลองรายพื้นที่ไม่ครบ, เกษตรกรรายย่อยเข้าถึงเทคโนโลยีจำกัด

## 6. สถานการณ์ประเทศไทย

- **งานวิจัยไทยที่มี**: panel จังหวัด 1989–2016 (มก.) — อ้อย/มันสำปะหลังคาดการณ์ระดับประเทศ 2046–2055 [8][10]; DSSAT รายลุ่มน้ำ (แม่น้ำสงคราม [3], บางปะกง [4], ลุ่มน้ำมูล [7], ภาคเหนือ 1 กม. [5], ภาคเหนือตอนล่าง CMIP6 [2]); ทบทวนความมั่นคงอาหารไทย (Attavanich 2023) [20]
- **หน่วยงาน**: สศก./กระทรวงเกษตร (เฝ้าระวังรายปี — เอลนีโญ 2023/24 คาดข้าว -3.27% [19]), TMD (ภูมิอากาศ), RID/ONWR (น้ำ), GISTDA, DCCE (Climate Risk Map — ดูไฟล์ ENSO)
- **โครงสร้างที่เอื้อ/ขวาง**: เอื้อ — พื้นที่เพาะปลูกกว้าง + พันธุ์ข้าวไทย (KDML105) มีข้อมูลวิจัยมาก + yield gap สูง (~55% นาไร่) = โอกาสกู้คืนผลผลิต [23]; ขวาง — 80% พื้นที่พึ่งฝน (นอกชลประทาน — ดูไฟล์ ENSO), งานคาดการณ์ระดับชาติแบบ SSP ถึง 2100 ยังไม่ครบทุกพืช, ข้อมูลสอบเทียบรายพื้นที่ไม่เปิดเป็นระบบ, ประกันภัยสภาพอากาศยังครอบคลุมจำกัด

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: คาดการณ์ระดับชาติแบบ CMIP6/SSP (SSP2-4.5/SSP5-8.5) ครบ 4 พืช (ข้าว/ข้าวโพด/มัน/อ้อย) ถึง 2100 ภายใต้ชุด GCM/โมเดลเดียว — งานไทยปัจจุบันต่างลุ่มน้ำ/ต่าง RCP เทียบกันไม่ได้ [2][8][10]
- **Q2**: ผลของ CO₂ fertilization ที่ลดลงข้ามรุ่น (multi-generation) ต่อตัวเลขคาดการณ์ — งาน FACE ระยะสั้น (+14–16%) อาจเกินจริง [12][13]
- **Q3**: มูลค่าเชิงเศรษฐกิจของการปรับตัว (ชลประทาน/พันธุ์/ปฏิทิน) ในบริบทไทย — มีตัวเลขการกู้คืน % [1][18] แต่ยังไม่มีต้นทุน-ผลตอบแทนระดับฟาร์มไทย
- **Q4**: ปฏิสัมพันธ์ ENSO × แนวโน้มระยะยาว — ความเสียหายรายปี (เอลนีโญ) ทับซ้อน/ซ้ำเติม trend ระยะยาวอย่างไร (ดูไฟล์ ENSO)
- **Q5**: การสอบเทียบ DSSAT/APSIM สำหรับพันธุ์ไทยรายภูมิภาค + การผูกข้อมูลดาวเทียม (ข้อมูลเปิด) — ยังไม่เป็นระบบ (ต่อยอดหมวด 06)
- **Q6**: ประกันภัย/ชดเชยที่ผูกกับตัวเลขคาดการณ์ผลผลิต (index insurance จากพยากรณ์ SSP รายฤดู) — ยังไม่มีงานออกแบบไทย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                                                      | ระดับนโยบาย                                                                                                                                                |

| 1 (1–2 ปี) | ใช้ตาราง "อุณหภูมิ/ฝนรายฤดู vs พืช" (จากงานจำลอง [2][3][5]) เลื่อนวันปลูก/เลือกพันธุ์อายุสั้น; ธุรกิจโรงงานน้ำตาล/แป้งมันประเมินความเสี่ยงปริมาณวัตถุดิบจากตัวเลข [8][10] | สนับสนุนฐานข้อมูลภูมิอากาศรายลุ่มน้ำเปิด (TMD/GISTDA) + ตั้ง "Climate-adapted crop calendar" ระดับจังหวัด; วิจัย/สอบเทียบ DSSAT-ไทย 4 พืชเป็นระบบ (ต่อ Q5) |

| 3 (4+ ปี)  | ระบบวางแผนฟาร์มผูกพยากรณ์ผลผลิต AI + พันธุ์ทนร้อน/แล้ง (../01) + ประกันภัย index — ตัดสินใจรายแปลงอัตโนมัติ                                                               | นโยบายปรับระบบพืชแห่งชาติรับ SSP5-8.5 (ลดพื้นที่เสี่ยง เปลี่ยนพืช) + แผนน้ำ 30 ปี + ประกันภัยระดับชาติผูกดัชนีภูมิอากาศ                                    |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย                  | รายละเอียด                                                                                                      | โอกาสแก้                                                    |
| --------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| ความไม่แน่นอนของโมเดล       | ทางเลือกโมเดลพืช/ GCM = 10–20% ของผลผลิตที่พยากรณ์ [22]; งานไทยต่างชุดโมเดล เทียบตรงไม่ได้                      | ใช้ ensemble หลายโมเดล + รายงานช่วงแทนค่าเดียว              |

| ข้อมูลสอบเทียบไทยจำกัด      | พันธุ์ไทย (KDML105 ฯลฯ)/ดินรายพื้นที่ ยังไม่ครอบคลุมทุกภูมิภาค                                                  | ฐานข้อมูลเปิด + ความร่วมมือ มหาวิทยาลัย-กรมวิชาการ (ต่อ Q5) |

## 11. อภิธานศัพท์

| คำศัพท์                                     | ความหมาย                                                                                     |
| ------------------------------------------- | -------------------------------------------------------------------------------------------- |
| SSP (Shared Socioeconomic Pathways)         | สคริปต์สังคม-เศรษฐกิจ-การปล่อยก๊าซ 5 เส้นทาง (SSP1-2.6 ถึง SSP5-8.5) ใช้แทน RCP ใน CMIP6/AR6 |
| RCP (Representative Concentration Pathways) | สคริปต์การปล่อยตามแรงบังคับรังสี (W/m²) — 4.5/8.5 ใช้ใน CMIP5/AR5                            |
| GCM                                         | แบบจำลองภูมิอากาศโลก (HadGEM, MPI-ESM, EC-Earth ฯลฯ)                                         |
| CMIP6/CMIP5                                 | โครงการเปรียบเทียบแบบจำลองภูมิอากาศรุ่นที่ 6/5 — แหล่ง GCM มาตรฐาน                           |
| DSSAT                                       | ชุดแบบจำลองการเจริญพืช (CERES-Rice/Maize ฯลฯ) — มาตรฐานงานวิจัยไทย                           |
| APSIM                                       | แบบจำลองระบบการผลิตพืช-ดิน-น้ำของออสเตรเลีย                                                  |
| CO₂ fertilization                           | พืช C3 สังเคราะห์แสงได้ดีขึ้นเมื่อ CO₂ สูง (ข้าว/มัน/อ้อย ~+13–17%; C4 อย่างข้าวโพด ~+4–12%) |
| C3/C4                                       | เส้นทางสังเคราะห์แสง — C3 ตอบสนอง CO₂ มากกว่า C4                                             |
| FACE                                        | การทดลองเพิ่ม CO₂ ในแปลงเปิด (มาตรฐานวัด CO₂ fertilization)                                  |
| Downscaling                                 | การลดสเกลข้อมูล GCM ให้ละเอียดระดับลุ่มน้ำ/ตำบล                                              |
| Baseline                                    | ช่วงอ้างอิง (เช่น 1992–2016, 2000–23) ที่เทียบ % การเปลี่ยนแปลง                              |
| Yield gap                                   | ช่องว่างระหว่างผลผลิตจริงกับศักยภาพ (นาไร่ไทย ~55%)                                          |
| Heat stress / WBGT                          | ความเครียดความร้อน / ดัชนีความร้อนชื้นที่ใช้ประเมินวันอันตราย                                |
| DSSAT v4.8.5                                | เวอร์ชันล่าสุด (ธ.ค. 2024) เปิดให้ดาวน์โหลดฟรี                                               |
