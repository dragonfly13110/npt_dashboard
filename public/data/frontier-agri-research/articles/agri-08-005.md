## 1. บทสรุปผู้บริหาร

- **ใจความ**: ปั๊มน้ำโซลาร์ = แผงโซลาร์ + ปั๊มน้ำ (ปั๊มชัก/หอยโข่ง/บาดาล — DC หรือ AC+อินเวอร์เตอร์) — สูบน้ำจากบ่อ/คลอง/สระ/บาดาล มาใช้ชลประทาน/อุปโภคในฟาร์ม — "ทำงานเมื่อมีแดด (น้ำมาเวลามีแสง — ตรงกับความต้องการกลางวัน)" — ไม่ต้องจ่ายค่าไฟ (ค่าไฟการเกษตรไทยสูงขึ้นเรื่อยๆ) — เทคโนโลยีที่คุ้มสุดสำหรับการเกษตรไทย (จุดแข็ง: แดดจัด 8–12 ชม./วัน + หลายพื้นที่แล้ง/หน้าแล้ง/ไม่มีไฟฟ้า) [1][2][3]
- **ขั้นพัฒนา**: 🏭 ใช้จริง/แพร่หลาย (ทั่วโลก + ไทย — กรมวิชาการ/กรมชลประทาน/ภาคเอกชน/โครงการหนุนมีเยอะ; ราคาโซลาร์ถูกลงมาก) [2][3]
- **ตัวเลขสำคัญที่สุด**: ต้นทุนไฟฟ้าปั๊มน้ำลดลง ~70–90% เมื่อใช้โซลาร์ (ช่วง — เทียบปั๊มไฟฟ้า/ดีเซล); ขนาดปั๊มเหมาะฟาร์มไทย ~1–7.5 แรงม้า (สูบ 20–100 ม³/วัน — ช่วง); ราคาระบบปั๊มโซลาร์ไทย ~30–150,000 บาท (ช่วง — ขึ้นขนาด/ความลึก); คืนทุน ~2–5 ปี (ช่วง — ขึ้นราคาไฟ/น้ำมันที่ประหยัด); พลังงานแผงไทย ~3.5–4.5 กิโลวัตต์ชั่วโมง/วัน/กิโลวัตต์ (ช่วง — 08-004) [1][3][4]
- **นัยต่อไทย**: เหมาะมาก (1) พื้นที่แล้ง/หน้าแล้ง/ขยายการปลูก (น้ำต้นทุนต่ำ) (2) พื้นที่ไร้ไฟฟ้า/ไฟฟ้าไม่เสถียร (3) แปลงเล็ก/กลาง (ผัก/ผลไม้/ข้าวนอกฤดู — มูลค่าสูง) (4) สระ/บ่อ/บาดาล (เติมน้ำ) — จุดสำคัญ: (1) เลือกขนาดให้พอดี (ความลึก/ระยะทาง/ปริมาณน้ำ — ไม่ใช่ซื้อใหญ่สุด) (2) มี "ถัง/สระเก็บน้ำ" (เก็บตอนกลางวัน — ใช้ตอนเย็น/ฝนตก/ไม่มีแดด) (3) ตรวจแหล่งน้ำก่อน (บ่อแห้งหน้าแล้ง = แผงไม่ช่วย) [2][3][4]
- **สถานะโดยรวม**: 🏭 ใช้จริง/แพร่หลาย (ไทย — ราคาถูก/โครงการหนุน) — ยังขยายต่อ (โซลาร์ฟาร์ม/ปั๊มใหญ่/การผูกชลประทานอัจฉริยะ 03)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (องค์ประกอบ)

1. **แผงโซลาร์ (PV array)**: ขนาดตามกำลังปั๊ม (1–10 กิโลวัตต์ — ฟาร์ม) + ระบบยึด (พื้น/เสา/หลังคา)
2. **ปั๊มน้ำ**: (1) ปั๊ม DC (เล็ก — น้ำตื้น — ไม่ต้องอินเวอร์เตอร์) (2) ปั๊ม AC + อินเวอร์เตอร์ (ใหญ่/น้ำลึก — บาดาล) (3) ปั๊มผิวดิน (ชัก/หอยโข่ง — คลอง/สระ) vs ปั๊มบาดาล (submersible — หลุมลึก)
3. **การจัดการน้ำ**: ถัง/สระเก็บน้ำ (สำคัญ — เก็บตอนกลางวัน) + ท่อ/วาล์ว/หัวจ่าย (03) + การรดแม่นยำ (02-012)

### 2.2 การเลือกขนาด (หัวใจ — ผิดแบบก็เปลือง)

| ปัจจัย                       | หมายเหตุ                                |
| ---------------------------- | --------------------------------------- |
| ความลึก/ระยะทางของน้ำ (head) | ยิ่งลึก/ไกลยิ่งแพง/ต้องกำลังมาก         |
| ปริมาณน้ำที่ต้องการ (ม³/วัน) | คำนวณจากพื้นที่/พืช (ผัก/ผลไม้/ข้าว)    |
| ชั่วโมงแสง (ไทย ~8–12 ชม.)   | ปั๊มทำงานเฉพาะกลางวัน (มีถังเก็บน้ำ)    |
| ราคาไฟ/น้ำมันที่ประหยัด      | คืนทุนเร็วถ้าปัจจุบันจ่ายแพง            |
| แหล่งน้ำคงที่                | หน้าแล้งบ่อแห้ง = แผงไม่ช่วย (ตรวจก่อน) |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ขนาด/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: การจัดการน้ำลึก (03 — อ้างข้าม), โซลาร์รูปแบบอื่น (08-001/08-004 — อ้างข้าม), ไฟฟ้าอื่น/กริด (08), กฎน้ำ/บ่อบาดาล (03/12)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                      | ผลลัพธ์                                         | สถานที่/เงื่อนไข | แหล่ง  |
| ------------------------------ | ----------------------------------------------- | ---------------- | ------ |
| ลดต้นทุนไฟฟ้าปั๊ม (โซลาร์)     | ~70–90% (ช่วง — เทียบไฟ/ดีเซล)                  | ผู้ประกอบการ/งาน | [1][3] |
| ขนาดปั๊มเหมาะฟาร์มไทย          | ~1–7.5 แรงม้า (สูบ 20–100 ม³/วัน — ช่วง)        | ผู้ประกอบการ     | [3]    |
| ราคาระบบ (ไทย)                 | ~30–150,000 บาท (ช่วง — ขึ้นขนาด/ความลึก)       | ผู้ประกอบการ     | [4]    |
| ระยะคืนทุน                     | ~2–5 ปี (ช่วง — ขึ้นราคาไฟ/น้ำมันที่ประหยัด)    | ผู้ประกอบการ/งาน | [3][4] |
| ปั๊มทำงาน (ชั่วโมงแสงไทย)      | ~8–12 ชม./วัน (กลางวัน)                         | งาน/ข้อมูล       | [4]    |
| พลังงานแผง (ไทย — 1 กิโลวัตต์) | ~3.5–4.5 กิโลวัตต์ชั่วโมง/วัน (ช่วง — 08-004)   | งาน/ผู้ประกอบการ | [4]    |
| นโยบาย/สินเชื่อไทย             | ภาครัฐ/ธนาคารหนุน (สินเชื่อ/เงินอุดหนุน — ช่วง) | ข่าว/ธนาคาร      | [5]    |

- **กฎ**: "ปั๊มโซลาร์ = 'น้ำฟรี' (ค่าติดตั้งแล้วใช้ได้ 20+ ปี — คืนทุน 2–5 ปี)" — "แต่ต้องมี 'ถัง/สระเก็บน้ำ' (กลางคืน/ฝน/ไม่มีแดด) + ตรวจแหล่งน้ำก่อน (บ่อแห้ง = แผงไม่ช่วย)" — "เลือกขนาดพอดี (ความลึก/ระยะทาง/ปริมาณน้ำ) — ซื้อใหญ่สุด = เปลือง" — ตัวเลขช่วง (ราคาเปลี่ยน) — ตรวจหัวข้อ 10
- **หมายเหตุ**: ราคาแผง/ระบบลดเรื่อยๆ — ตรวจราคาปีปัจจุบัน

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดปั๊มน้ำโซลาร์โลก ~$2–5 พันล้านดอลลาร์/ปี (ช่วง — โต 10–20%/ปี); ผู้ติดตั้ง/จำหน่ายไทยหลายร้อยราย (ตลาดคึกคัก — ราคาแข่งขัน) [3][4]
- **ผู้เล่นหลัก**: ผู้ผลิตแผง (จีน/ไทย), ผู้ประกอบการระบบ (ไทย — ครบวงจร/ติดตั้ง), การไฟฟ้า/ชลประทาน (โครงการหนุน), ธนาคาร/กองทุน (สินเชื่อ/เงินอุดหนุน), ผู้ค้าปลีก (อินเทอร์เน็ต/ร้านเครื่องจักรกล)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                                 | ฉุดรั้ง                                       |
| ------------------------------------------ | --------------------------------------------- |
| ราคาโซลาร์ต่ำ/ลดลง                         | ต้นทุนเริ่มแรก (ระบบ — หลักหมื่น-แสนบาท)      |
| ค่าไฟ/น้ำมันสูงขึ้น                        | ขนาด/การออกแบบผิด (ซื้อใหญ่เกิน/ไม่พอ)        |
| พื้นที่แล้ง/หน้าแล้ง/ไร้ไฟฟ้า (ไทย)        | แหล่งน้ำไม่พอ (บ่อแห้ง — แผงไม่ช่วย)          |
| นโยบาย/สินเชื่อหนุน (ไทย/โลก)              | ความรู้/การติดตั้งผิด (ผู้ประกอบการหลายระดับ) |
| น้ำเป็นสินทรัพย์ (ผลผลิตเพิ่ม — ผัก/ผลไม้) | การดูแล/อะไหล่ (ปั๊ม/แผงในฟาร์ม)              |

- **แนวโน้ม**: ปั๊มโซลาร์ "อัจฉริยะ" (รีโมต/AI/พยากรณ์ — 03/06-001), การผูก Agrivoltaics (08-001), การผูกชลประทานแม่นยำ (03/02-012), การเงินยืดหยุ่น (จ่ายตามใช้/สินเชื่อ — 14), ระบบครบวงจร (โซลาร์ฟาร์ม+ปั๊ม+EV — 08-004)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยใช้ปั๊มโซลาร์แพร่ (1) ผู้ประกอบการ/ตลาดคึกคัก (ราคาถูก/ครบวงจร) (2) โครงการภาครัฐ/ชลประทาน/กรมวิชาการ (หนุน/นำร่อง — หลายโครงการ) (3) พื้นที่ไร้ไฟฟ้า/ไฟฟ้าไม่เสถียร (ตามชายแดน/เกาะ — น้ำอุปโภค+เกษตร) (4) สินเชื่อ/นโยบาย (ธนาคารเพื่อการเกษตร — หนุน) — งานวิจัยไทย (การออกแบบ/การประหยัดน้ำ — TCI/ThaiJo) มี [4][5]
- **จุดแข็งไทย**: แดดจัด (8–12 ชม. — ผลิตน้ำดี), ราคาโซลาร์/ระบบถูก (ผู้ประกอบการเยอะ), ค่าไฟ/น้ำมันสูง (แรงจูงใจ), พื้นที่แล้ง/ไร้ไฟฟ้าเยอะ (ความต้องการ), โครงการ/นโยบายหนุน (ชลประทาน/ธนาคาร), ภาคธุรกิจน้ำ/ชลประทาน (03) เริ่ม
- **จุดอ่อน**: ต้นทุนแรก (หลักหมื่น-แสนบาท — รายเล็กไม่ไหว), ขนาด/การออกแบบผิด (ติดตั้งผิด — ระบบไม่พอ/เปลือง), การดูแล/อะไหล่ (ฟาร์มไกล), แหล่งน้ำไม่พอ (หน้าแล้ง — บ่อแห้ง), การยอมรับ/ความรู้ (14-003), การผูกชลประทานอัจฉริยะ (03) ยังน้อย
- **โอกาส**: (1) "ปั๊มโซลาร์+ถัง/สระเก็บน้ำ" (ครบวงจร — ฟาร์มเล็ก/กลาง — ผัก/ผลไม้/ข้าวนอกฤดู) (2) "ปั๊มโซลาร์อัจฉริยะ" (03+06-001 — เซนเซอร์/รีโมต/พยากรณ์ — ประหยัดน้ำ) (3) "โซลาร์ฟาร์ม+ปั๊ม+EV ครบวงจร" (08-001/08-004 — ฟาร์มใหญ่/บริษัท) (4) "สินเชื่อ/จ่ายตามใช้" (14 — ธนาคาร/สตาร์ทอัพ) (5) "พื้นที่ไร้ไฟฟ้า" (ชายแดน/เกาะ — น้ำ+ไฟ — คุณภาพชีวิต+ผลิต)
- **หน่วยงาน**: กรมชลประทาน/กรมวิชาการ (โครงการ/วิจัย), การไฟฟ้า (พื้นที่ไร้ไฟฟ้า/นโยบาย), ธนาคารเพื่อการเกษตร (สินเชื่อ), ผู้ประกอบการโซลาร์/ปั๊ม, สวทช./มก. (งานวิจัย)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: งาน "การออกแบบปั๊มโซลาร์เฉพาะพื้นที่" (ขนาด/ความลึก/ชนิดปั๊ม — รายภูมิภาคไทย) — ยังไม่มีแนวทางครบ
- **Q2**: เศรษฐศาสตร์ "ปั๊มโซลาร์ vs ไฟ vs ดีเซล" ต่อไร่ (ผัก/ผลไม้/ข้าว — ไทย — คืนทุน/กำไร) — ยังไม่มีข้อมูลเปิด
- **Q3**: การผูก "ชลประทานอัจฉริยะ+โซลาร์" (03+06-001 — เซนเซอร์/รีโมต/พยากรณ์ — ประหยัดน้ำ/ไฟ) — ยังไม่มีงานไทยครบ
- **Q4**: การบริหาร "ถัง/สระเก็บน้ำ" ร่วมปั๊มโซลาร์ (ขนาด/เวลา — หน้าแล้ง) — ยังไม่มีแนวทาง
- **Q5**: คุณภาพน้ำ/การบำรุงปั๊มโซลาร์ในฟาร์มไทย (ทราย/ตะกอน/ทนทาน) — ยังไม่มีงาน
- **Q6**: การยอมรับ (14-003) หลังติดตั้ง (การดูแล/การใช้งานจริง) — ยังไม่มีข้อมูล
- **Q7**: นโยบาย/สินเชื่อปั๊มโซลาร์ไทย (สถานะปัจจุบัน) — ยังไม่ชัด
