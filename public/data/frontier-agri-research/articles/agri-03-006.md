## 1. บทสรุปผู้บริหาร

- **ใจความ**: AWD คือการปล่อยให้ผิวดินนาข้าวแห้งสลับกับการขังน้ำเป็นรอบ (แทนการขังน้ำตลอดฤดู) โดยไม่ให้รากขาดน้ำเกินกำหนด — ใช้อุปกรณ์ "ท่อวัดน้ำ" (water tube) ง่าย ๆ กำกับ [1] เป็นวิธีลดน้ำที่ถูกสุด/ใช้ได้จริงในนาข้าว
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์/ขยายผลแล้วในเอเชีย (ฟิลิปปินส์/เวียดนาม/อินเดีย/ไทย) — เป็นแนวปฏิบัติมาตรฐานของ IRRI และมาตรฐานข้าวยั่งยืน SRP [1][2]
- **ตัวเลขสำคัญที่สุด**: ประหยัดน้ำ ~15–30% (บางงานถึง 30%+) โดยผลผลิตไม่ลด [1]; ลดการปล่อยมีเทน (CH₄) ~30–50% ในนาน้ำชลประทาน [2]
- **นัยต่อไทย**: ข้าวไทยส่วนใหญ่เป็นนาชลประทาน/นาฝน — AWD ลดต้นทุนปั๊มน้ำ ลดมีเทน (คาร์บอนเครดิต SRP) และช่วยรองรับวิกฤตแล้ง แต่ต้องระวังในดินทราย/ดินเค็ม/แล้งจัด [1]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์/ขยายผลแล้ว (นำไปใช้จริงในหลายประเทศ)

## 2. หลักการและขอบเขต

- **หลักการ**: ข้าวทน "ดินชื้นแต่ไม่แช่" ได้ดี ยกเว้นช่วงวิกฤต (ตั้งตัว/ออกรวง/น้ำนม) — AWD มาตรฐาน: หลังข้าวตั้งตัว ให้ปล่อยน้ำแห้งจนระดับน้ำใต้ผิวดิน ~15 ซม. (ดูจากท่อวัดน้ำ) แล้วขังน้ำใหม่ — ทำซ้ำเป็นรอบ; ช่วงออกรวงต้องขังน้ำไว้
- **อุปกรณ์**: ท่อวัดน้ำ (perforated PVC) ปักในนา + กติกา 15 ซม. — ต้นทุนต่ำมาก; มีงานใช้เซนเซอร์/แอปช่วยบอกจังหวะ (เชื่อม 03-001/05) [1]
- **ข้อห้าม/ข้อควรระวัง**: (1) ดินทรายจัด/รั่วซึมสูง — น้ำแห้งเร็วเกินไป (2) ดินเค็ม — เกลือจะลอยขึ้นเมื่อแห้ง (เชื่อม 02-006) (3) แล้งจัด/น้ำไม่พอทำรอบ (4) นาหว่านน้ำตมที่ปรับสภาพยาก [1][2]
- **ขอบเขตที่ครอบคลุม**: เทคนิค/อุปกรณ์, ตัวเลขผลลัพธ์ (น้ำ/มีเทน/ผลผลิต), คาร์บอนเครดิต, สถานการณ์ไทย
- **นอกขอบเขต**: การจัดการน้ำท่วม/ระบาย (ดู 03-009), ดินเค็ม (02-006), การชลประทานรายแปลงดิจิทัล (03-001), คาร์บอน/MRV เจาะลึก (02-002)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                    | แหล่ง  |
| --------- | ------------------------------------------------------------------------------- | ------ |
| 2000s     | IRRI พัฒนา AWD ให้เป็นวิธีมาตรฐาน (ฟิลิปปินส์) + ท่อวัดน้ำ                      | [1]    |
| 2010s     | ขยายผลเวียดนาม/อินเดีย/บังกลาเทศ; งาน meta-analysis ยืนยันน้ำ/ผลผลิต            | [3]    |
| 2015+     | SRP Standard (ข้าวยั่งยืน) รับรอง AWD เป็นวิธีลด GHG → เริ่มมีคาร์บอนเครดิตข้าว | [2]    |
| 2020s     | งาน AWD+ดิจิทัล (เซนเซอร์/แอป); ไทยนำร่องหลายจังหวัด (ชลประทาน/กรมการข้าว)      | [5][6] |
| 2025–2026 | โครงการข้าวคาร์บอนต่ำ (โรงสี/บริษัทคาร์บอน) ใช้ AWD เป็นหัวใจของมาตรฐาน         | [4]    |

- **เส้นแบ่ง**: เทคนิคสุกแล้วและใช้จริง — จุดที่ยังเป็นงานวิจัยคือ "การทำ AWD ให้เหมาะกับแต่ละพื้นที่ (ดิน/น้ำ/พันธุ์)" และ "การตรวจวัดเพื่อคาร์บอนเครดิตที่เชื่อถือได้"

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด           | ผลลัพธ์                                             | สถานที่/เงื่อนไข                           | แหล่ง  |
| ------------------- | --------------------------------------------------- | ------------------------------------------ | ------ |
| การประหยัดน้ำ       | ~15–30% (ชลประทาน) — บางงาน 30%+                    | ฟิลิปปินส์/เวียดนาม/อินเดีย — ยังไม่ยืนยัน | [1][3] |
| ผลผลิต              | เท่าเดิม หรือ +/– เล็กน้อย (meta: ไม่ลดโดยรวม)      | หลายงาน/หลายสภาพ — ยังไม่ยืนยัน            | [3]    |
| มีเทน (CH₄)         | ลด ~30–50% ในนาชลประทาน (ช่วงต่างกันตามงาน)         | งานวิจัยเอเชีย — ยังไม่ยืนยัน              | [2]    |
| ต้นทุนปั๊มน้ำ/ไฟฟ้า | ลดตามน้ำที่ประหยัด (รายแปลง)                        | ทั่วไป — ยังไม่ยืนยัน                      | [1]    |
| คาร์บอนเครดิตข้าว   | โครงการ SRP/ตลาดสมัครใจจ่ายต่อตัน CO2e (ราคาผันผวน) | ตลาดสมัครใจ — ยังไม่ยืนยัน                 | [4]    |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: ผลสูงสุดในนาชลประทานที่ควบคุมน้ำได้; ในนาฝน/แล้ง AWD อาจไม่ได้ผลหรือเสี่ยง

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ไม่มีตลาด "AWD" แยก — ฝังใน (1) ตลาดข้าวยั่งยืน/ข้าวพรีเมียม (SRP — ราคา premium) (2) ตลาดคาร์บอนเครดิตสมัครใจภาคเกษตร (ราคา ~5–20 ดอลลาร์/ตัน CO2e ตามโปรเจกต์ — ยังไม่ยืนยัน) [2][4]
- **ผู้เล่น**: IRRI/CRP (พัฒนา), กรมการข้าว/กรมชลประทาน (ไทย), บริษัทคาร์บอน/โรงสี (ผู้ซื้อเครดิต — เช่น โครงการข้าวคาร์บอนต่ำของภาคเอกชน), SRP (มาตรฐาน) [2]
- **การลงทุน**: ท่อวัดน้ำต้นทุนต่ำ (~หลักสิบ–ร้อยบาท/แปลง) — เป็นวิธี "ถูกที่สุด" ในการลด GHG ภาคข้าว [1]
- **ปัจจัยขับเคลื่อน**: นโยบายลดมีเทน/คาร์บอน, ราคาข้าวพรีเมียม, ภัยแล้ง
- **ปัจจัยฉุดรั้ง**: น้ำชลประทานราคาถูก/ไม่มีแรงจูงใจประหยัด, การยอมรับ, การตรวจวัดเครดิต

## 6. สถานการณ์ประเทศไทย

- **งาน/หน่วยงาน**: กรมการข้าว/ศูนย์วิจัยข้าว งาน AWD นำร่องหลายจังหวัด (ชัยนาท/สุพรรณบุรี/พิษณุโลก ฯลฯ — รายละเอียดต้องยืนยัน) [5]; กรมชลประทานส่งเสริมในพื้นที่ชลประทาน [6]
- **บริบทไทย**: นาชลประทานเจ้าพระยา/นาอีสาน (นาฝน/นาหว่าน) — AWD เหมาะกับนาแปลงใหญ่/ควบคุมน้ำได้; โรงสี/ผู้ส่งออกเริ่มรับรองข้าวคาร์บอนต่ำ (ยังไม่ยืนยันรายชื่อ) [5]
- **อุปสรรค**: เกษตรกรชินกับการขังน้ำ (กำจัดวัชพืช/ไม่ต้องดูแล), น้ำมีให้ใช้ตลอดในพื้นที่ชลประทาน, การทำรอบน้ำที่สอดคล้องกับระบบชลประทานรายสัปดาห์
- **นโยบาย**: แผนปฏิบัติการลดก๊าซเรือนกระจกภาคเกษตร (NDC) เอา AWD เป็นมาตรการหลัก — ตัวเลขเป้าหมายต้องยืนยัน [6]

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลขประหยัดน้ำ/มีเทน/ผลผลิตของ AWD ในแปลงไทยจริง (หลายฤดู/หลายพันธุ์) — ยังไม่มี meta ระดับประเทศ
- **Q2**: AWD ในดินทราย/เค็ม/นาหว่านน้ำตมของไทย — ยังไม่มีแนวปฏิบัติชัดเจน
- **Q3**: การยอมรับ/แรงจูงใจของเกษตรกรไทย (เชื่อม 14-001) — ยังไม่มีการสำรวจใหญ่
- **Q4**: ระเบียบวิธี MRV สำหรับคาร์บอนเครดิตข้าวไทย (SRP/Verra) ที่ต้นทุนตรวจต่ำ — ยังไม่มี
- **Q5**: การผูก AWD กับระบบชลประทานรอบเวร (ส่งน้ำรายสัปดาห์) ให้ทำงานร่วมกัน — ยังไม่ได้ออกแบบ
- **Q6**: ปฏิสัมพันธ์ AWD-วัชพืช-แมลง-ธาตุอาหาร (โดยเฉพาะ P) — งานไทยน้อย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                       | ระดับนโยบาย                                                                      |
| ---------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ขยาย AWD + ท่อวัดน้ำสู่แปลงสาธิตในศูนย์ข้าว 20 จังหวัด; เก็บข้อมูลน้ำ/ผลผลิต/มีเทน 2–3 ฤดู                 | ประกาศ AWD เป็นแนวปฏิบัติส่งเสริมของกรมการข้าว; ฝึกเจ้าหน้าที่                   |
| 2 (2–4 ปี) | โครงการข้าวคาร์บอนต่ำกับโรงสี/บริษัทคาร์บอน (จ่ายส่วนต่าง + ค่าเครดิต); แอปแจ้งจังหวะทำรอบ (เชื่อม 03-001) | ระเบียบวิธี MRV ไทย (ต้นทุนต่ำ); ผูกกับประกันภัย/สินเชื่อสีเขียว (เชื่อม 14-002) |
| 3 (4+ ปี)  | ข้าว AWD เป็นมาตรฐานส่งออก (SRP/GI); รายได้คาร์บอนเป็นส่วนหนึ่งของรายได้นา                                 | นโยบายลดมีเทนนาไทยตาม NDC + การออกแบบรอบน้ำชลประทานรองรับ AWD ทั้งลุ่มน้ำ        |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย          | รายละเอียด                          | โอกาสแก้                                    |
| ------------------- | ----------------------------------- | ------------------------------------------- |
| นิสัย/ความเชื่อเดิม | เกษตรกรคิดว่าข้าวต้องแช่น้ำตลอด     | แปลงสาธิต/ชุดข้อมูลผลผลิตไม่ลด              |
| น้ำมีเหลือเฟือ      | ในเขตชลประทานไม่มีแรงจูงใจประหยัด   | ค่าน้ำ/ค่าปั๊มที่สะท้อนจริง + คาร์บอนรายได้ |
| ดิน/พื้นที่ไม่เหมาะ | ดินทราย/เค็ม/แล้งทำ AWD ไม่ได้      | จำแนกพื้นที่เหมาะ-ไม่เหมาะ (เชื่อม 02-003)  |
| วัชพืช/แมลง         | บางงานพบวัชพืชเพิ่มช่วงดินแห้ง      | การจัดการผสมผสาน + ช่วงเวลาที่เหมาะสม       |
| MRV คาร์บอน         | การตรวจวัดมีเทนราคาแพง/ซับซ้อน      | แบบจำลอง + การสุ่มตรวจ (เชื่อม 02-002)      |
| รอบน้ำชลประทาน      | การส่งน้ำรายสัปดาห์ไม่ตรงจังหวะ AWD | วางแผนร่วมชลประทาน (เชื่อม 03-001)          |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ประหยัดน้ำ 15–30% / มีเทน 30–50% / ผลผลิตไม่ลด** — ยืนยันจาก meta-analysis (Field Crops Research; Global Change Biology) + งาน IRRI
- [ ] **ราคาคาร์บอนเครดิตข้าว 5–20 ดอลลาร์/ตัน** — ตรวจตลาดปัจจุบัน (S&P/Ecosystem Marketplace) — ราคาผันผวนมาก
