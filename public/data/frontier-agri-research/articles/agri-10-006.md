## 1. บทสรุปผู้บริหาร

- **ใจความ**: เนื้อจากพืช (Plant-Based Meat) = เลียนแบบเนื้อสัตว์จากโปรตีนพืช (ถั่วเหลือง/ถั่วลันเตา/ข้าวสาลี — ไมโครโพรเทอีน-class) ด้วยกระบวนการเอกซ์ทรูชัน (extrusion — แบบความชื้นสูง) + ไขมันพืช + สี/กลิ่น (myoglobin จากถั่วเหลือง — Impossible-class heme) — ตลาดบูมปี 2563–64 (Beyond/Impossible — ฟีดกระแส "plant-based") แล้วชะลอ/หดตัว (2565–67-class — US ยอดขายหด ~10%/ปี-class — บริษัทหลายรายปิด/ลด) — แต่ตลาดรวมยังโตในเอเชีย (ไส้กรอก/เกี๊ยว/ลูกชิ้น — ผสมเนื้อ) + ผู้เล่นใหญ่ (CPF — โรง plant-based ใหญ่สุดในเอเชีย-class — เปิด 2567-class) — ปัญหาหลัก: ราคาสูงกว่าเนื้อจริง ~30–100% (ช่วง) + รสชาติ/เนื้อสัมผัสยังไม่พอ + การยอมรับ (14-003) [1][2][3]
- **ขั้นพัฒนา**: 🏭 ใช้จริง/พาณิชย์ (ขายทั่วโลก) แต่ตลาดชะลอ (ปรับกลยุทธ์ — "flexitarian" กลุ่มใหม่) [2][3]
- **ตัวเลขสำคัญที่สุด**: ตลาด plant-based meat โลก ~$5–8 พันล้าน (ช่วง — 2567-class — ใหญ่สุดในโปรตีนทางเลือก); US ยอดขายหด ~10%/ปี (2565–67-class); Beyond Meat ยอดขาย ~$300–500M/ปี-class (ช่วง); Impossible ~$400–700M/ปี-class (ช่วง); CPF ลงทุนโรง plant-based ~2 หมื่นล้านบาท-class (ช่วง — ใหญ่สุดเอเชีย); ราคา/กก. สูงกว่าเนื้อจริง ~30–100% (ช่วง); คาร์บอน (LCA) ต่ำกว่าเนื้อวัว ~70–90% (ช่วง — 08-002) [1][2][4]
- **นัยต่อไทย**: ไทยมีจุดแข็ง (อุตสาหกรรมอาหารแปรรูป/ส่งออก — CPF ใหญ่สุดเอเชีย-class) + วัตถุดิบ (ถั่วเหลืองนำเข้า/ถั่วเขียว/ข้าว — ยังต้องนำเข้าถั่วเหลือง) — โอกาส: (1) "เนื้อจากพืชผสมเนื้อจริง (flexitarian)" (ไส้กรอก/ลูกชิ้น/เกี๊ยว — ลดต้นทุน/เพิ่มโปรตีน — ตลาดเอเชีย) (2) "ส่งออกแปรรูป" (ไทยเป็นฐานผลิต — ตลาดโลก) (3) "ราคา/รสชาติ" (งานวิจัย — วัตถุดิบไทย/เครื่องปรุง) — จุดสำคัญ: ตลาดชะลอ (ระวังการลงทุนใหญ่) — เริ่มที่ "ตลาดผสม/ฟู้ดเซอร์วิส" ก่อน [3][4][5]
- **สถานะโดยรวม**: 🏭 ใช้จริง/พาณิชย์ (ขายจริงทั่วโลก — แต่ชะลอ — ปรับกลยุทธ์)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (เทคโนโลยี 3 ชั้น)

1. **โปรตีนพืชหลัก**: ถั่วเหลือง (SPI/ISPC — เส้นใย), ถั่วลันเตา (pea protein — โปรตีนทางเลือก), ข้าวสาลี (gluten — ไมโครโพรเทอีน-class), มัน/ข้าว (แป้ง) — ผสมกัน
2. **เอกซ์ทรูชัน (Extrusion)**: กระบวนการให้ความร้อน+แรงดัน+ตัด (เครื่อง extruder — แบบความชื้นต่ำ/สูง) — เกิดโครงสร้างเส้นใย (fibrillation) — เลียนแบบเนื้อ/โครงสร้างกล้ามเนื้อ (HMMA — high-moisture meat analog)
3. **ส่วนประกอบลิ้มรส**: ไขมันพืช (มะพร้าว/เรพซีด/โกโก้-class), สี/กลิ่น/รส (myoglobin จากถั่วเหลือง (heme — Impossible-class), เครื่องปรุง (13), ยีสต์/หมัก — รสเนื้อ)

### 2.2 ตารางประเภท/รูปแบบ (ตลาดหลัก)

| ประเภท                 | ตัวอย่าง (class)          | ตลาด/รูปแบบ               |
| ---------------------- | ------------------------- | ------------------------- |
| เนื้อบด/เบอร์เกอร์     | Beyond/Impossible Burger  | US/ตะวันตก (ไฮเอนด์)      |
| ไส้กรอก/ลูกชิ้น/เกี๊ยว | ผู้ผลิตเอเชีย (CPF-class) | เอเชีย (ราคากลาง)         |
| ไก่จากพืช              | Beyond/ผู้เล่นจีน-class   | ฟู้ดเซอร์วิส (ไก่ทอด)     |
| ผลิตภัณฑ์ผสมเนื้อจริง  | ไส้กรอกผสม/เกี๊ยวผสม      | เอเชีย (flexitarian — โต) |
| อาหารทะเลจากพืช        | ผู้เล่นใหม่-class         | ตลาดใหม่ (เริ่ม)          |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ตลาด/ตัวเลข/ไทย/Blueprint — **นอกขอบเขต**: เนื้อห้องแล็บ (10-001 — อ้างข้าม), การหมักแม่นยำ (10-007 — อ้างข้าม), โปรตีนแมลง (10-002), พืชโปรตีน/การผลิตถั่ว (04/01 — อ้างข้าม)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดโปรตีนทางเลือก ~$10–20 พันล้าน-class (ช่วง — รวมทุกชนิด); plant-based meat ~$5–8 พันล้าน (ช่วง); เอเชียโต (ผสมเนื้อ — CPF-class/จีน); ไทย: ตลาดในประเทศเล็ก (เริ่ม) + ส่งออก (CPF-class — ใหญ่) [1][2]
- **ผู้เล่นหลัก**: ผู้ผลิตโลก (Beyond/Impossible-class), ผู้ผลิตเอเชีย (CPF-class/STARFIELD-class), วัตถุดิบ (โปรตีนถั่ว — บริษัทถั่วเหลือง/ลันเตา), ฟู้ดเซอร์วิส/ค้าปลีก (McDonald's-class/7-11-class), งาน/ภาครัฐไทย (มก./สวทช.)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                          | ฉุดรั้ง                            |
| ----------------------------------- | ---------------------------------- |
| ESG/สุขภาพ (คาร์บอนต่ำ — 08-002/13) | ราคาสูงกว่าเนื้อจริง (30–100%)     |
| flexitarian (ผสมเนื้อ — เอเชีย)     | รสชาติ/เนื้อสัมผัส (ยังไม่พอ)      |
| CPF-class (โรงใหญ่/ส่งออก)          | การยอมรับ (14-003 — "ไม่ใช่เนื้อ") |
| ราคาวัตถุดิบ (ถั่วเหลือง/ลันเตา)    | ตลาด US ชะลอ (กระแสลดลง)           |
| ฟู้ดเซอร์วิส/ค้าปลีก (ช่องทาง)      | การตลาด/ชื่อ (สับสนกับเนื้อจริง)   |

- **แนวโน้ม**: flexitarian (ผสม) โต, ราคาลด (scale), "เนื้อจากพืช+หมัก (10-007)" (รสชาติดีขึ้น — ต้นทุนยังสูง), เอเชีย/ส่งออก (CPF-class), "เนื้อจากพืชสำหรับอาหารสัตว์?" (โปรตีนผสม — ต่อยอด), การยอมรับ (14-003 — ข้อมูล/การตลาด)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทย (1) CPF (โรง plant-based ใหญ่สุดเอเชีย-class — เปิด 2567-class — ส่งออก) (2) ตลาดในประเทศ (เริ่ม — ไส้กรอก/ลูกชิ้น/ผสม — 7-11-class/ฟู้ดเซอร์วิส) (3) งานวิจัย (มก./มจธ./มข. — HMMA/สูตร/วัตถุดิบไทย — ขมิ้น/สมุนไพร) (4) วัตถุดิบ (ถั่วเหลืองนำเข้า — ยังพึ่งพา — แต่ข้าว/มัน/ถั่วเขียวในประเทศ) (5) การยอมรับ (14-003 — ยังน้อย — วัยรุ่น/เมือง/สุขภาพ) [5]
- **จุดแข็งไทย**: อุตสาหกรรมอาหารแปรรูป (ส่งออกใหญ่), CPF-class (โรง/ช่องทาง/เงินทุน), วัตถุดิบ (ข้าว/มัน/ถั่วเขียว/เครื่องปรุง — ไทย), งานมหาวิทยาลัย (HMMA — มี), การยอมรับอาหารแปรรูป (ไส้กรอก/ลูกชิ้น — คุ้นเคย)
- **จุดอ่อน**: ถั่วเหลือง/โปรตีนถั่ว (นำเข้า — ต้นทุน), ตลาดในประเทศเล็ก (ราคาสูงกว่าเนื้อ), การยอมรับ (14-003 — "ของปลอม/แพง"), งานต่อยอดเชิงพาณิชย์ (ยังน้อย — ต่างจาก CPF-class), การตลาด/ความรู้ (ผู้บริโภคยังงง)
- **โอกาส**: (1) "ผสมเนื้อจริง (flexitarian)" (ไส้กรอก/เกี๊ยว/ลูกชิ้น — ลดต้นทุน — ราคากลาง — เอเชีย/ไทย) (2) "ส่งออกแปรรูป" (CPF-class — ฐานผลิตไทย — ตลาดโลก) (3) "ฟู้ดเซอร์วิส/ค้าปลีก" (เมนูจากพืช — ร้าน/โรงแรม/7-11-class) (4) "งานวัตถุดิบไทย" (โปรตีนข้าว/ถั่วเขียว/ถั่วแดง — ทดแทนถั่วเหลืองนำเข้า) (5) "กลุ่มสุขภาพ/มังสวิรัติ" (ตลาดในประเทศ — งานเจ/เทศกาล)
- **หน่วยงาน**: CPF-class (ผู้ผลิตใหญ่), อย. (มาตรฐาน/ฉลาก — "เนื้อจากพืช"), มก./มจธ./มข. (งานวิจัย), สวทช./NIA (ทุน), กรมส่งเสริมการค้า (ส่งออก), กลุ่มมังสวิรัติ/ผู้ประกอบการรายเล็ก

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: งาน "วัตถุดิบโปรตีนไทย" (โปรตีนข้าว/ถั่วเขียว/ถั่วแดง — ทดแทนถั่วเหลือง — HMMA) — ยังไม่มีครบ
- **Q2**: ราคา/ต้นทุน (LCA + ต้นทุนการผลิตไทย — เทียบเนื้อจริง — 08-002) — ยังไม่มีข้อมูลเปิด
- **Q3**: การยอมรับ (14-003) ไทย (ราคา/รสชาติ/ชื่อ — ผู้บริโภคกลุ่มใดซื้อ) — ยังไม่มีงานสำรวจครบ
- **Q4**: ฉลาก/มาตรฐาน (อย. — "เนื้อจากพืช" — คำโฆษณา — เทียบ EU/สหรัฐฯ) — ยังไม่ชัด
- **Q5**: ผลสุขภาพ (โปรตีน/เกลือ/ไขมัน — เทียบเนื้อจริง) — ยังถกเถียง (13)
- **Q6**: ตลาดส่งออกไทย (CPF-class — ยอดขาย/ตลาดจริง) — ยังไม่มีข้อมูลเปิด
- **Q7**: "เนื้อจากพืช+หมัก (10-007)" (โปรตีนหมักผสม — รสชาติ/ต้นทุน) — ยังไม่มีงานไทย

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ตลาด plant-based meat $5–8 พันล้าน** — ตรวจรายงานตลาด (ปี/บริษัท)
- [ ] **US หด ~10%/ปี** — ตรวจ GFI/SPINS-class (ปี)
- [ ] **Beyond/Impossible ยอดขาย** — ตรวจรายงานบริษัท (ปีล่าสุด)
- [ ] **CPF โรงใหญ่สุดเอเชีย-class (2 หมื่นล้านบาท-class)** — ตรวจข่าว/รายงาน (ปี)
- [ ] **ราคาแพงกว่าเนื้อจริง 30–100%** — ตรวจตลาด (ปี/สินค้า)
- [ ] **คาร์บอนต่ำกว่าเนื้อวัว 70–90%** — ตรวจงาน LCA (ระบุเงื่อนไข)
- [ ] **การยอมรับไทย (กลุ่มผู้ซื้อ)** — ตรวจงาน/สำรวจ (ปี)
- [ ] **สถานะตลาดไทย (CPF-class/ยอดขาย)** — ตรวจข่าว/รายงาน (ปี)
- [ ] **ฉลาก/มาตรฐาน อย. (สถานะ)** — ตรวจเอกสาร/ข่าว
- [ ] **งาน HMMA ไทย (มก./มจธ. — สถานะ)** — ตรวจ TCI/ThaiJo/ข่าว
