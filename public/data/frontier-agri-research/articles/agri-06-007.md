## 1. บทสรุปผู้บริหาร

- **ใจความ**: Reinforcement Learning (RL) = AI เรียนรู้ "นโยบาย" (policy) จากการลอง-ผิด-รับรางวัล — ใช้คุมระบบอัตโนมัติ: รดน้ำ/ใส่ปุ๋ย/เปิดปิดโรงเรือน (เชื่อม 03-001/04-005/02-012) ให้ "ทำเอง/ปรับเอง" ตามสถานการณ์แทนสูตรตายตัว — ฝึกในสภาพแวดล้อมจำลอง (digital twin 06-001) ก่อนย้ายสู่ของจริง; ทางเลือกนิยม: Model Predictive Control (MPC)/การหาค่าที่ดีที่สุด (optimization) ที่พิสูจน์แล้วในงานจริง [1][2][3]
- **ขั้นพัฒนา**: ⚗️ งานวิจัย/นำร่อง (RL ในโรงเรือน/น้ำมีงานทดลอง — ยังไม่เชิงพาณิชย์กว้าง; MPC/การควบคุมอัตโนมัติตามกฎ (rule-based) เชิงพาณิชย์แล้ว) [1][2]
- **ตัวเลขสำคัญที่สุด**: งาน RL โรงเรือน/น้ำ (จำลอง+นำร่อง) ประหยัดน้ำ/พลังงาน/ปุ๋ย 10–30% (ช่วง — งาน); MPC/ตัวควบคุมเชิงพาณิชย์ (โรงเรือน VF — 04-005) ใช้จริงแล้ว (ลดพลังงาน 10–25% — งาน/บริษัท); ข้อจำกัด: การฝึก RL ต้อง "ทดลอง" หลายครั้ง — ในแปลงจริงแพง/เสี่ยง → ต้องมี twin (06-001) คุณภาพดี [1][2][3]
- **นัยต่อไทย**: การควบคุมอัตโนมัติ (รดน้ำตามเซนเซอร์) มีใช้แล้วในไทย (03-001/03-012) — ก้าวต่อไป "RL/MPC" ยังเป็นงานวิจัย (มก./มจธ. — โรงเรือน/น้ำ); ไทยควรรอเทคโนโลยีนิ่งก่อนลงทุนเชิงพาณิชย์ (ใช้ rule-based/MPC ก่อน) [4][5][6]
- **สถานะโดยรวม**: ⚗️ งานวิจัย/นำร่อง (RL) — เชิงพาณิชย์บางส่วน (MPC/rule-based)

## 2. หลักการและขอบเขต

- **หลักการ**: ระบบอัตโนมัติเลือก "การกระทำ" (เปิดน้ำเท่าไร/เปิดพัดลม/ใส่ปุ๋ย) ตาม "สถานะ" (เซนเซอร์/อากาศ/ระยะพืช) เพื่อ "รางวัล" (กำไร/ผลผลิต/ประหยัดทรัพยากร — ลดต้นทุน) — เรียนรู้จากประวัติ (RL: นโยบายปรับเอง; MPC: คำนวณแผนล่วงหน้าแบบจำลอง; rule-based: กฎตายตัว) [1][2]
- **ระดับ**: (1) **Rule-based** (ถ้า-แล้ว — ง่าย/นิยมในฟาร์ม — รดน้ำเมื่อความชื้น < 30%) (2) **MPC** (คำนวณล่วงหน้าด้วยโมเดล+พยากรณ์อากาศ 05-008 — ปรับตามสถานการณ์) (3) **RL** (เรียนรู้จากข้อมูล/การลอง — ปรับเองได้ ไม่ต้องรู้กฎ/โมเดลแม่นยำ) (4) **ผสม** (MPC+RL/ฟีดแบ็ก) [2][3]
- **การใช้งานจริง**: โรงเรือน/VF (เปิด-ปิดพัดลม/ไฟ/น้ำ — 04-005), ระบบน้ำ (กำหนดการรด/น้ำหยด — 03-001/03-012), ปุ๋ย (อัตราตามสถานะ — 02-012), เครื่องจักร/โดรน (การนำทาง/พ่น — 05-005)
- **ขอบเขตที่ครอบคลุม**: เทคนิค/สถานะ, การใช้งาน, ไทย, แนวทางใช้
- **นอกขอบเขต**: การตัดสินใจระดับมนุษย์ (06-008 DSS), เซนเซอร์/ฮาร์ดแวร์ (05), โมเดลคาดการณ์ (06-004)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                                                                               | แหล่ง  |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 2010s     | RL/MPC ในระบบอุตสาหกรรม (process control); งานแรกในโรงเรือน/น้ำ (จำลอง)                                                                                                    | [1]    |
| 2018–2022 | งาน RL โรงเรือน (ควบคุมอุณหภูมิ/แสง — จำลอง+ทดลองเล็ก); MPC ระบบน้ำ/พลังงาน (งานแปลง)                                                                                      | [1][2] |
| 2023–2025 | งาน RL+digital twin (06-001) — ฝึกในจำลองย้ายสู่จริง (sim-to-real); งานประหยัดพลังงาน VF (04-005) ด้วย RL/MPC; ผู้ให้บริการคุมโรงเรือนอัตโนมัติ (เชิงพาณิชย์ — ต่างประเทศ) | [2][3] |
| 2026–     | แนวโน้ม: "RL ปลอดภัย" (ความเสี่ยงต่ำ — การรับประกัน), การผูกกับพยากรณ์อากาศ (05-008)/ราคาไฟฟ้า (04-012), ระบบผสม rule+MPC+RL ในผลิตภัณฑ์                                   | [3]    |

- **เส้นแบ่ง**: Rule-based/MPC "ใช้ได้จริงแล้ว" — RL ยังเป็นงานวิจัย (ต้อง twin คุณภาพ/ข้อมูลเยอะ/ความเสี่ยง) — ผู้ประกอบการควรเริ่มจาก MPC/rule ก่อน แล้วเพิ่ม RL ทีละชั้น

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                     | ผลลัพธ์                                     | เงื่อนไข        | แหล่ง  |
| --------------------------------------------- | ------------------------------------------- | --------------- | ------ |
| ประหยัดน้ำ/พลังงาน/ปุ๋ย (งาน RL โรงเรือน/น้ำ) | 10–30% (ช่วง)                               | งานจำลอง/นำร่อง | [1][2] |
| ประหยัดพลังงาน (MPC โรงเรือน/VF)              | 10–25% (งาน/บริษัท)                         | เชิงพาณิชย์     | [2][3] |
| ผลผลิต (RL/MPC — ไม่ลดลง)                     | เทียบเท่าหรือ +0–10%                        | งาน             | [2]    |
| จำนวนการทดลองที่ต้องฝึก RL                    | หลักหมื่น–ล้านขั้น (จำลอง) — แปลงจริงไม่ได้ | งาน             | [1]    |
| ต้นทุนระบบควบคุมอัตโนมัติ (ฟาร์ม)             | หลักหมื่น–หลักแสนบาท (ระบบ)                 | ตลาด            | [3]    |
| การย้าย RL จากจำลองสู่จริง (sim-to-real)      | ยังท้าทาย (performance gap)                 | งาน             | [2]    |
| งานไทย RL/MPC เกษตร                           | เริ่มมี (โรงเรือน/น้ำ — มก./มจธ.)           | งาน/TCI         | [4][5] |

- **กฎ**: "RL ไม่ใช่คำตอบทุกที่" — เริ่ม rule-based (ง่าย/ถูก), ยกระดับเป็น MPC (มีโมเดล+พยากรณ์), ค่อย RL (ข้อมูล/twin พร้อม) — ประหยัดมากสุดแต่ก็เสี่ยง/ซับซ้อนสุด
- **เงื่อนไขสำคัญ**: (1) ระบบควบคุมจริง (วาล์ว/พัดลม — ทำตามคำสั่งได้) (2) เซนเซอร์ครบ (05-007/05-008) (3) โมเดล/twin (06-001) สำหรับฝึก/ทดสอบ (4) การรับประกันความปลอดภัย (ไม่ทำลายพืช) (5) ต้นทุน/การบำรุงรักษา

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: การควบคุมอัตโนมัติ/RL-MPC เกษตร (embedded ในระบบน้ำ/โรงเรือน) — ไม่มีตลาดแยก (เป็นฟีเจอร์); ตลาด climate control โรงเรือน ~1–3 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน) [3]
- **ผู้เล่นหลัก**: ระบบน้ำอัตโนมัติ (Netafim GrowSphere, CropX — rule/ML), โรงเรือน/VF (Priva, Ridder, 4AG Robotics-class — MPC/rule; ผู้ไทยโรงเรือนนำเข้า), งานวิจัย (EU/จีน/ไทย — มก./มจธ.) [2][3][4][5]
- **การลงทุน**: rule-based ถูก (หลักหมื่น); MPC ต้องมีโมเดล+คน (หลักแสน); RL ลงทุนวิจัย/ทดสอบ (ล้าน — โปรเจกต์) — สำหรับไทย: ลงทุน "ระบบอัตโนมัติตามกฎ+เซนเซอร์" ก่อน (คุ้มทันที — 03-001/03-012) แล้วต่อยอด
- **แนวโน้ม**: "AI คุมฟาร์ม" เป็นฟีเจอร์ในระบบน้ำ/โรงเรือนทุกยี่ห้อ, การผูกพยากรณ์อากาศ/ราคาไฟ (05-008/04-012), ความปลอดภัย/การรับรอง (สำคัญก่อนใช้ RL จริง), การควบคุมผ่านแอป/ไลน์ (06-002)
- **ความเสี่ยง**: RL ผิดพลาด (คุมพลาด = เสียหาย) — ต้องมี safety, การตลาด "AI คุมเอง" เกินจริง, ระบบซับซ้อน/พังยากต่อการซ่อม, การพึ่งผู้ขาย

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ระบบรดน้ำอัตโนมัติตามเซนเซอร์ (rule-based) มีใช้จริง (สวนทุเรียน/น้ำหยด 03-012/03-001 — ผู้ประกอบการไทย); โรงเรือนอัตโนมัติ (ผัก/ดอกไม้ — 04-006/04-008) ใช้ตัวควบคุมนำเข้า; งานวิจัย RL/MPC (มก./มจธ./มข. — โรงเรือน/น้ำ — ระดับแล็บ/จำลอง) มีอยู่จริง — เชิงพาณิชย์ RL ยังไม่มี [4][5][6]
- **จุดแข็งไทย**: ระบบ rule-based/น้ำอัตโนมัติเข้าถึงแล้ว, ผู้ประกอบการระบบน้ำ/โรงเรือนมี, งานวิจัยควบคุมอัตโนมัติเริ่มมี, พืชมูลค่าสูง (ทุเรียน/ผัก) จ่ายไหว
- **จุดอ่อน**: โรงเรือน/VF ไทยยังเล็ก (04-006), การควบคุมแบบ MPC/RL ยังเป็นงานวิจัย, ทักษะระบบอัตโนมัติจำกัด, ต้นทุนระบบ (นำเข้า), การยอมรับการ "ปล่อย AI คุมเอง"
- **โอกาส**: (1) "ระบบน้ำหยด+เซนเซอร์+rule/ML" เชิงพาณิชย์ไทย (ต่อยอด 03-001/03-012 — คุ้มทันที) (2) งานวิจัย MPC โรงเรือนไทย (ต่อยอด 04-005/04-008) (3) การอบรม/ผู้ประกอบการระบบอัตโนมัติ (4) การใช้ในฟาร์มโรงเรือนส่งออก (ผัก/ดอกไม้ — 12)
- **หน่วยงาน**: มหาวิทยาลัย (มก./มจธ./มข.), ผู้ประกอบการระบบน้ำ/โรงเรือน, กรมวิชาการ/ส่งเสริม, AIC

| 3 (4+ ปี)  | "AI คุมฟาร์มไทย" (rule+MPC+RL ผสม — ระบบไทย) สำหรับฟาร์ม/โรงเรือนขนาดใหญ่ — ผูกพยากรณ์/ราคาไฟ (05-008/04-012); การยอมรับสูงขึ้น (06-005/06-010) | นโยบาย "ฟาร์มอัตโนมัติไทย" (การรับรอง/การประกัน); การใช้ในนโยบายประหยัดน้ำ/พลังงานระดับชาติ |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย           | รายละเอียด                  | โอกาสแก้                                            |
| -------------------- | --------------------------- | --------------------------------------------------- |
| ความเสี่ยงคุมผิดพลาด | AI คุมพลาด = พืชเสียหาย     | safety/การจำกัดการกระทำ, rule ฐานหนุน, การรับประกัน |
| การฝึก RL ในแปลงจริง | ทดลองหลายครั้ง — แพง/เสี่ยง | ฝึกใน twin (06-001), sim-to-real                    |
| โมเดล/ข้อมูลไม่พอ    | MPC ต้องโมเดลแม่นยำ/พยากรณ์ | เซนเซอร์ครบ (05-007/05-008), ข้อมูลงานวิจัย         |
| ต้นทุน/ทักษะ         | ระบบซับซ้อน/คนดูแลไม่พอ     | เริ่ม rule-based, ผู้ประกอบการไทย, อบรม             |
| การยอมรับ            | ไม่ไว้ใจ "AI คุมเอง"        | เริ่มกึ่งอัตโนมัติ (แนะนำ→อนุมัติ), XAI (06-005)    |
| การพึ่งผู้ขาย        | ระบบนำเข้า/ปิด              | ระบบเปิด/มาตรฐาน, ตัวควบคุมไทย                      |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **RL โรงเรือน/น้ำ ประหยัด 10–30%** — ตรวจงาน (ระบุระบบ/ปี/จำลองหรือจริง)
- [ ] **MPC โรงเรือน/VF ประหยัดพลังงาน 10–25%** — ตรวจงาน/บริษัท (ระบุ)
- [ ] **ผลผลิตเทียบเท่า/+0–10% (RL/MPC)** — ตรวจงาน
- [ ] **จำนวนการฝึก RL (ขั้น) หลักหมื่น–ล้าน** — ตรวจงาน (เป็นช่วงอ้างอิง)
- [ ] **ต้นทุนระบบควบคุม หลักหมื่น–แสนบาท** — ตรวจตลาดไทย
- [ ] **งานไทย RL/MPC (มก./มจธ./มข.)** — ตรวจ TCI/ThaiJo อัปเดต
- [ ] **ตลาด climate control โรงเรือน 1–3 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **สถานะเชิงพาณิชย์ระบบน้ำอัตโนมัติไทย (ทุเรียน)** — ตรวจข่าว/ตลาดอัปเดต
