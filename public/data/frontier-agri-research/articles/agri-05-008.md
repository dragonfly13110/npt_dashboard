## 1. บทสรุปผู้บริหาร

- **ใจความ**: สถานีอากาศอัตโนมัติ (AWS) วัด อุณหภูมิ/ความชื้น/ฝน/ลม/แดด (+ บางรุ่น: ใบเปียก/ความดัน/ET) ราย 5–60 นาที → ส่งผ่าน LoRaWAN/NB-IoT (05-003) → ใช้คุมชลประทาน (03-001), เตือนโรค (แบบจำลองโรค — ใบเปียก/อุณหภูมิ), เตือนน้ำค้างแข็ง/ภัยแล้ง (เชื่อม 11), คำนวณ ET จริงรายแปลง (เชื่อม 03-011) — "ไมโครไคลเมต" ในแปลงต่างจากสถานีใหญ่ (ทุ่ง/เมือง) หลาย °C และฝนต่างกันมาก [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (อุปกรณ์ราคา 2 หมื่น–2 แสนบาท; บริการพยากรณ์รายแปลง (CropX/FieldClimate/DTN) มีจริง; เครือข่ายสถานีเอกชน (PWS) ขยายตัว) [2][3]
- **ตัวเลขสำคัญที่สุด**: สถานีเริ่มต้น ~20,000–80,000 บาท (ไทย/ตลาด); ฝนรายแปลงต่างจากสถานีใกล้สุดได้ 30–100% (ฝนฟ้าคะนองเฉพาะจุด); การเตือนโรคตามแบบจำลอง (เช่น โรคใบจุดข้าว/โรคใบไหม้มันฝรั่ง) ลดการใช้สารได้ 20–40% (งาน); สถานีกรมอุตุนิยมวิทยา (TMD) ~140 สถานีหลักทั่วประเทศ (ห่างกันเป็นร้อย กม. — หยาบเกินรายแปลง) [1][2][4][5]
- **นัยต่อไทย**: ช่องว่างใหญ่คือ "ความหนาแน่นสถานีในพื้นที่เกษตร + การนำข้อมูลไปใช้จริง" — สถานีเอกชน/โครงการเริ่มเพิ่ม; การรวมกับ AI พยากรณ์ (03-001) และเตือนภัย (11) ยังทำได้น้อย [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: AWS รวบรวมเซนเซอร์ (T/RH/ฝน/ลม/แสง/ใบเปียก) + ตัวบันทึก (logger) + การส่งข้อมูล (SIM/LoRaWAN) — ข้อมูลเรียลไทม์/ประวัติ → ป้อนแบบจำลอง (ET — Penman-Monteith, โรค — leaf wetness+temperature, เตือนภัย) + พยากรณ์อากาศรายแปลง (downscale/การรวมข้อมูลดาวเทียม)
- **ชนิด**:
  - **สถานีมาตรฐาน (research/AWS ของ TMD/กรมวิชาการ)**: ราคา 1–5 แสนบาท — แม่นยำสูง/สอบเทียบ
  - **สถานีเกษตร/เอกชน (PWS — Davis, Barani, ATMOS41, WS-5000)**: 2 หมื่น–1.5 แสนบาท — พอใช้จริง/ติดตั้งง่าย
  - **ไมโครไคลเมต (ในแปลง/โรงเรือน — 05-004/04-005)**: จุดเล็ก/หลายจุด — เห็นความต่างระดับแปลง
  - **ข้อมูลภายนอก**: ดาวเทียมฝน (GPM/IMERG), เรดาร์ฝน (TMD), พยากรณ์โลก (ECMWF/GFS — ฟรี), บริการ API (OpenWeather/Tomorrow.io)
- **การใช้งานหลัก**: (1) คุมรดน้ำ (ET/ฝน — 03-001) (2) เตือนโรค (แบบจำลอง: ใบจุดสีน้ำตาลข้าว/ใบไหม้/แอนแทรคโนส) (3) เตือนภัย (น้ำค้าง/แล้ง/ลมแรง — 11) (4) การวางแผน (วันพ่น/เก็บเกี่ยว/เปิดปิดโรงเรือน)
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/ราคา, การใช้งาน, ไทย, แนวทางใช้
- **นอกขอบเขต**: คุมอากาศโรงเรือน (04-005), เซนเซอร์ความชื้นดิน (05-007), การเตือนภัยระดับนโยบาย (11)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                         | แหล่ง  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 1990s–2000s | AWS มาตรฐาน (Campbell/Adcon); งาน ET แบบจำลอง; การเตือนโรคด้วยสภาพอากาศ (IPM — เชื่อม 04-009)                                        | [1]    |
| 2010s       | สถานีราคาถูก (PWS) + IoT (ส่งไร้สาย); ข้อมูลเปิด (TMD API/GPM) — งานพยากรณ์รายแปลงเริ่ม                                              | [2][3] |
| 2020–2025   | การรวมหลายแหล่ง (สถานี+เรดาร์+ดาวเทียม+พยากรณ์) ด้วย ML/การผสม (data fusion); การพยากรณ์เฉพาะจุด (nowcasting รายชม.)                 | [2][3] |
| 2026–       | แนวโน้ม: สถานีเล็ก/ถูกจำนวนมาก (mesh), การพยากรณ์รายแปลงอัตโนมัติ (AI — เชื่อม 06), การผูกกับการตัดสินใจ (พ่น/รด/เปิด-ปิด) อัตโนมัติ | [3]    |

- **เส้นแบ่ง**: อุปกรณ์/ข้อมูล "พร้อมแล้ว" — ปัญหาจริง: การกระจายสถานี (พื้นที่เกษตรยังบาง), คุณภาพ/การดูแลสถานีเอกชน (สอบเทียบไม่สม่ำเสมอ), การแปลงเป็น "คำแนะนำ/การเตือน" ที่เกษตรกรใช้จริง

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                    | ผลลัพธ์                                | เงื่อนไข       | แหล่ง  |
| -------------------------------------------- | -------------------------------------- | -------------- | ------ |
| ราคาสถานีเริ่มต้น (PWS)                      | ~20,000–80,000 บาท (ไทย/ตลาด)          | ตลาด           | [3][4] |
| ราคาสถานีมาตรฐาน (TMD-class)                 | 1–5 แสนบาท                             | ตลาด/หน่วยงาน  | [1]    |
| ความต่างฝนรายแปลง vs สถานีใกล้สุด            | 30–100% (ฝนฟ้าคะนองเฉพาะจุด)           | งานเปรียบเทียบ | [2]    |
| อุณหภูมิต่างไมโครไคลเมต (แปลง vs ทุ่ง/เมือง) | 1–5 °C (ช่วง)                          | งาน            | [2]    |
| ลดสารกำจัดโรค (ใช้แบบจำลองเตือน)             | 20–40% (งาน — มันฝรั่ง/ข้าว/องุ่น)     | งาน IPM        | [2]    |
| ความแม่นยำ ET คำนวณจากสถานี (03-011)         | RMSE ~10–20% (เทียบวัดจริง)            | งาน            | [1]    |
| ความถี่ส่งข้อมูล                             | 5–60 นาที (เรียลไทม์)                  | อุปกรณ์        | [1]    |
| ครอบคลุมสถานี TMD (สถานีหลัก)                | ~140 แห่งทั่วประเทศ (หลักร้อย กม./จุด) | หน่วยงาน       | [4]    |
| พยากรณ์รายแปลง (ฟรี — ECMWF/GFS)             | ความละเอียด 9–25 กม. (ต้อง downscale)  | ผู้ให้บริการ   | [3]    |
| อายุแบต/โซลาร์สถานี PWS                      | ต่อเนื่องได้ปี (โซลาร์)                | อุปกรณ์        | [3]    |

- **กฎ**: "สถานีใกล้แปลง 1 จุด + ข้อมูลดาวเทียม/พยากรณ์ = ต้นทุนถูกพอใช้รายแปลง" — ไม่จำเป็นต้องสถานีแพงทุกจุด; คุณค่าอยู่ที่ "การแปลงเป็นคำแนะนำ" (รด/พ่น/เตือน) ไม่ใช่ตัวเลขดิบ
- **เงื่อนไขสำคัญ**: (1) การติดตั้งมาตรฐาน (ไม่ใกล้ตึก/ต้นไม้ — วัดผิด) (2) การสอบเทียบ/ดูแลสถานี (3) ข้อมูลคุณภาพ (ตรวจ/กรอง) (4) การเชื่อมกับระบบตัดสินใจ (03-001/04-009/11)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: สถานีอากาศเกษตร/PWS + บริการพยากรณ์รายแปลง ~0.3–1 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 10–20%/ปี [3]
- **ผู้เล่นหลัก**: อุปกรณ์ (Davis Instruments, Barani, Meter/ATMOS41, Campbell, Adcon), บริการพยากรณ์/แอป (FieldClimate/Pessl, DTN, CropX, aWhere, IBM/Agro); ไทย: TMD (ข้อมูลเปิด), กรมวิชาการเกษตร/ชลประทาน (สถานีงานวิจัย), ผู้ประกอบการระบบน้ำ/โดรน (แพ็กเกจ+สถานี) [1][3][4][5]
- **การลงทุน**: สถานี 1 จุด 2–8 หมื่นบาท (พอคุมแปลง 100–500 ไร่ — ขึ้นภูมิประเทศ); บริการ API รายเดือนหลักร้อย–พันบาท; ใช้ข้อมูลฟรี (TMD/ECMWF) + สถานี 1 จุด = จุดเริ่มต้นถูกสุด
- **แนวโน้ม**: สถานีราคาตก (แข่ง) , การรวมหลายแหล่งด้วย AI (6), สถานี "ไร้เซนเซอร์" (ใช้ดาวเทียม/พยากรณ์ล้วน — ราคา 0), การผูกกับการตัดสินใจอัตโนมัติ (เปิดปิดน้ำ/โรงเรือน)
- **ความเสี่ยง**: การพึ่งข้อมูลฟรี (คุณภาพ/การปิดบริการ), คุณภาพสถานีราคาถูก (สอบเทียบ/ลอย), การตลาดเกินจริง, ความเชื่อถือพยากรณ์รายแปลง (ยังผิดได้)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: TMD มีสถานีหลัก ~140 แห่ง + เรดาร์ฝนหลายจุด (ข้อมูลเปิดบางส่วน); สถานีงานวิจัย (กรมวิชาการเกษตร/ชลประทาน/มหาวิทยาลัย) หลายร้อยจุด (ไม่เปิดรวม); สถานีเอกชน/PWS ในฟาร์มใหญ่เริ่มเพิ่ม (สวนทุเรียน/ไร่อ้อย/บริษัท); แอปพยากรณ์รายแปลงมีแล้ว (บริการไทย/ต่างประเทศ — คุณภาพ/การยอมรับต่างกัน) [4][5][6]
- **จุดแข็งไทย**: ข้อมูล TMD/เรดาร์มีพร้อม, งานวิจัย Ag-Met ไทยมี (มก./มข.), โครงข่ายมือถือครอบคลุม (05-003), พืชมูลค่าสูงจ่ายไหว
- **จุดอ่อน**: ความหนาแน่นสถานีในพื้นที่เกษตรต่ำ, ข้อมูลหน่วยงานกระจัดกระจาย (คนละระบบ), สถานีงานวิจัยไม่ได้เปิด/รวมศูนย์, การดูแลสถานีระยะยาว, การใช้จริงของเกษตรกรยังน้อย (ข้อมูลไม่ถึงมือ/ไม่เข้าใจ)
- **โอกาส**: (1) "เครือข่ายสถานีเกษตรไทย" (มาตรฐานเดียว/เปิด — รัฐ+มหาวิทยาลัย+เอกชน) (2) บริการพยากรณ์/เตือนรายแปลงต่อไร่ (ผู้ประกอบการ) (3) การรวมกับระบบน้ำ/เตือนโรค (03-001/04-009) (4) การใช้ข้อมูล TMD/เรดาร์เปิดเป็นฐาน (ต้นทุนต่ำ)
- **หน่วยงาน**: TMD (กรมอุตุนิยมวิทยา), กรมวิชาการเกษตร, กรมชลประทาน, GISTDA (ข้อมูล/แพลตฟอร์ม), มหาวิทยาลัย, ผู้ประกอบการ

## 8. นัยต่อการนำไปใช้ (Blueprint)

| พยากรณ์ยังผิด      | รายแปลงยังคลาดเคลื่อน (พายุเฉพาะจุด)     | การผสมหลายแหล่ง/การอัปเดตถี่, สื่อสาร "ความไม่แน่นอน" |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ราคาสถานี PWS 20,000–80,000 บาท / มาตรฐาน 1–5 แสน** — ตรวจราคาตลาดไทย/ต่างประเทศ
- [ ] **ฝนรายแปลงต่าง 30–100% / อุณหภูมิไมโคร 1–5 °C** — ตรวจงานเปรียบเทียบ (ระบุพื้นที่)
- [ ] **ลดสารกำจัดโรค 20–40% ด้วยแบบจำลองเตือน** — ตรวจงาน IPM (ระบุโรค/พื้นที่)
- [ ] **TMD สถานีหลัก ~140 แห่ง + เรดาร์** — ตรวจจำนวนล่าสุดจาก TMD
- [ ] **พยากรณ์ ECMWF/GFS ความละเอียด 9–25 กม.** — ตรวจผู้ให้บริการ (รุ่น/ปี)
- [ ] **ET จากสถานี RMSE 10–20%** — ตรวจงาน (ต่อยอด 03-011)
- [ ] **สถานะเครือข่าย PWS/สถานีเกษตรไทย** — ตรวจข่าว/งานอัปเดต
- [ ] **ตลาดสถานี/พยากรณ์เกษตร 0.3–1 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
