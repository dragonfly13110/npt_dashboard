## 1. บทสรุปผู้บริหาร

- **ใจความ**: โดรน + เซนเซอร์ (กล้อง RGB/มัลติสเปกตรัม NDVI-NDRE/เทอร์มอล/LiDAR) ให้ภาพความละเอียดเซนติเมตร (0.5–5 ซม.) รายแปลง — เห็นใบ/กอ/ทรงพุ่มชัดกว่าดาวเทียม (05-001: 3–10 ม.) มาก → ใช้ทำแผนที่ความแปรปรวนของแปลง (ยืนต้น/การเจริญ/โรค/วัชพืช/ทรงพุ่ม) และ "แผนที่ใช้บังคับ" (prescription map) ป้อนเครื่องจักรปรับอัตราปุ๋ย/น้ำ/พ่น (เชื่อม 02-012/05-005) [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (บริการสำรวจโดรน/การทำแผนที่ มีทั่วโลก+ไทย; การผูกกับเครื่องจักร VRT ใช้งานจริงในแปลงใหญ่) [2][3]
- **ตัวเลขสำคัญที่สุด**: ความละเอียด 0.5–5 ซม. (ความสูงบิน 30–120 ม.); นับต้น/กอแม่นยำ ~90% (ข้าว/ข้าวโพด); ความสูงทรงพุ่ม (LiDAR) คลาดเคลื่อน ~2–5%; บริการสำรวจไทย ~200–1,000 บาท/ไร่ (ช่วง); 1 เที่ยวบินครอบคลุม ~20–80 ไร่ (แบต 20–40 นาที) [1][2][3][4]
- **นัยต่อไทย**: บริการสำรวจโดรนมีจริง (ข้าว/อ้อย/ยาง/ปาล์ม/ทุเรียน — ผู้ประกอบการไทย) — จุดติดขัดคือ "การแปลงภาพเป็นคำสั่งใช้บังคับ + การพิสูจน์ผลตอบแทน" ไม่ใช่การถ่ายภาพ [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: โดรนบินสำรวจ (อัตโนมัติตามเส้นทาง — flight plan) พร้อมเซนเซอร์ — ภาพหลายช่วงคลื่น → คำนวณดัชนี (NDVI/NDRE/GNDVI/LCI), เทอร์มอล (อุณหภูมิทรงพุ่ม → CWSI เชื่อม 03-002), LiDAR (จุดหลายล้านจุด → ความสูง/ปริมาตรทรงพุ่ม) → "ออร์โธโมเสก/จุดเมฆ" → วิเคราะห์ด้วย AI/ML → แผนที่การจัดการ (management zone) + แผนที่ใช้บังคับ (อัตราปุ๋ย/น้ำ/พ่น รายจุด) → ป้อนเครื่องจักร/โดรนพ่น (05-005)
- **ชนิดเซนเซอร์**: RGB (การนับ/วัชพืช/โรค), มัลติสเปกตรัม 5–10 แถบ (NDVI/NDRE — การเจริญ/ไนโตรเจน), เทอร์มอล (ความเครียดน้ำ — CWSI), LiDAR (โครงสร้าง/ความสูง/ทรงพุ่ม), hyperspectral โดรน (งานวิจัย — ตรวจสาร/โรคแม่นยำสูง)
- **RTK/DGPS**: จำเป็นเมื่อทำแผนที่ใช้บังคับ (ความแม่นยำตำแหน่ง ±2–5 ซม.) — ถ้าไม่มี RTK แผนที่เลื่อนตำแหน่ง/ใช้ได้เฉพาะการวิเคราะห์รวม
- **ขอบเขตที่ครอบคลุม**: เซนเซอร์/การวิเคราะห์, ราคา/บริการ, งานไทย, แนวทางใช้
- **นอกขอบเขต**: ภาพดาวเทียม (05-001), การพ่น/เครื่องจักร (05-005/07), การประมวลผล AI ทั่วไป (06)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                                                       | แหล่ง  |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 2010s     | โดรนราคาถูก (DJI Phantom 2013+) + เซนเซอร์มัลติสเปกตรัมเล็ก (MicaSense RedEdge/Parrot Sequoia) — งาน NDVI รายแปลงเริ่ม                             | [1][2] |
| 2017–2020 | การทำ orthomosaic/processing อัตโนมัติ (Pix4D/DroneDeploy); งานนับต้น/วัชพืชด้วย CNN; การผูก prescription map กับเครื่อง VRT (งานแปลงข้าวโพด/อ้อย) | [2][3] |
| 2021–2025 | LiDAR โดรนราคาลง (DJI L1); การทำ 3D/ปริมาตรทรงพุ่ม; งาน hyperspectral โดรน; การรวมโดรน+AI+เครื่องจักร (ระบบครบวงจร)                                | [2][3] |
| 2026–     | แนวโน้ม: โดรนอัตโนมัติเต็มรูปแบบ (บิน-วิเคราะห์-พ่นด้วยตัวเอง), ราคาเซนเซอร์ลง, การรวมกับดาวเทียม (โดรน=รายละเอียด, ดาวเทียม=ความถี่)              | [3]    |

- **เส้นแบ่ง**: การถ่ายภาพ/ทำแผนที่ "สุกแล้ว" — ปัญหาจริง: การพิสูจน์ว่าการใช้แผนที่ช่วยผลผลิต/ลดต้นทุนจริง (ผลต่างกันตามแปลง/ปี), การเข้าถึงของเกษตรกรรายย่อย, ระบบ VRT ในไทยยังน้อย

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                | ผลลัพธ์                                | เงื่อนไข        | แหล่ง  |
| ---------------------------------------- | -------------------------------------- | --------------- | ------ |
| ความละเอียดภาพโดรน                       | 0.5–5 ซม. (ความสูงบิน 30–120 ม.)       | งาน/เอกสาร      | [1]    |
| การนับต้น/กอ (CNN)                       | แม่นยำ ~85–95% (ข้าว/ข้าวโพด/มัน)      | ชุดข้อมูลเฉพาะ  | [2]    |
| ความสูงทรงพุ่ม LiDAR                     | คลาดเคลื่อน ~2–5% (เทียบวัดจริง)       | งาน 2021–25     | [2]    |
| NDVI โดรน vs วัดใบจริง (LAI/SPAD)        | สัมพันธ์ R² 0.7–0.9                    | งานข้าว/ข้าวโพด | [2][3] |
| CWSI เทอร์มอลโดรน (เชื่อม 03-002)        | แยกน้ำไม่พอ/น้ำพอได้ 70–90%            | งานไม้ผล/ข้าว   | [3]    |
| ครอบคลุมต่อเที่ยวบิน                     | ~20–80 ไร่ (แบต 20–40 นาที)            | ตลาด/งาน        | [1]    |
| ราคาบริการสำรวจไทย                       | ~200–1,000 บาท/ไร่ (ช่วง)              | ตลาด            | [4]    |
| ชุดเซนเซอร์มัลติสเปกตรัมโดรน             | ~2–6 แสนบาท (เซนเซอร์+โดรน)            | ตลาด            | [1]    |
| โดรนสำรวจ (ไม่รวมเซนเซอร์พิเศษ)          | ~3 หมื่น–1.5 แสนบาท                    | ตลาด            | [1]    |
| ผลต่อปุ๋ยไนโตรเจน (ใช้แผนที่ NDVI — VRT) | ลดปุ๋ย N 10–30% (ผลผลิตไม่ลด — บางงาน) | งานแปลงใหญ่     | [3]    |

- **กฎ**: โดรน "เห็นละเอียด" แต่แพงต่อพื้นที่เมื่อแปลงเล็ก/เที่ยวบินจำกัด — เหมาะแปลงขนาดกลาง-ใหญ่/พืชมูลค่าสูง; ผลตอบแทนเกิดเมื่อ "ภาพ→การกระทำ" (แผนที่ใช้บังคับ/การพ่นเฉพาะจุด)
- **เงื่อนไขสำคัญ**: (1) ต้องมี RTK สำหรับแผนที่ใช้บังคับ (2) การสอบเทียบ NDVI/เทอร์มอลกับสภาพจริง (พันธุ์/แสง/เวลา) (3) ลม/ฝน (บินได้เฉพาะสภาพเหมาะ) (4) กฎการบิน (ขึ้นทะเบียน/พื้นที่หวงห้าม — CAAT) (5) หลังภาพแล้วต้องมี "คน/AI แปลความ"

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: โดรนการเกษตรรวม (สำรวจ+พ่น) ~5–10 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); ส่วนสำรวจ/ทำแผนที่ ~1–2 พันล้านดอลลาร์ [3]
- **ผู้เล่นหลัก**: DJI (โดรน+Agras), MicaSense/AgEagle (เซนเซอร์), Pix4D/DroneDeploy/Agremo (ซอฟต์แวร์), Sentera/Precision Hawk, ผู้บริการไทย (หลายราย — บินสำรวจ/ทำแผนที่/พ่น); ซอฟต์แวร์ประมวลผลแบบเปิด (OpenDroneMap — ฟรี) [1][2][3][4]
- **การลงทุน**: ชุดโดรน+เซนเซอร์ ~5–20 หมื่น–6 แสนบาท (ขึ้นสเปก); บริการเช่า/รายไร่ (เริ่มจากบริการ — ไม่ต้องซื้อเครื่อง); ซอฟต์แวร์ประมวลผลรายเดือน (หลักพัน–หมื่นบาท) หรือใช้ OpenDroneMap ฟรี
- **แนวโน้ม**: โดรนบินอัตโนมัติ/ฝูง, เซนเซอร์ถูก (การประกอบ), การรวมซอฟต์แวร์ครบวงจร (บิน→แผนที่→สั่งเครื่องจักร), ข้อมูลเป็นรายเดือน (subscription)
- **ความเสี่ยง**: กฎการบิน (CAAT), เทคโนโลยีเปลี่ยนเร็ว (เครื่องรุ่นเก่าตกค่า), การตลาดเกินจริง (ภาพสวยแต่ผลตอบแทนไม่ชัด), การพึ่งผู้ให้บริการเดียว

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: บริการสำรวจโดรนมีจริง (ผู้ประกอบการ/บริษัท — ข้าว/อ้อย/ยาง/ปาล์ม/ทุเรียน/มัน); งานวิจัยโดรน-NDVI/นับต้น (มก./มข./มจพ./GISTDA); การใช้ "แผนที่ใช้บังคับ+VRT" ยังน้อย (อ้อยมีนำร่องกับโรงงานน้ำตาล/บริษัทปุ๋ย); กฎการบินมีแล้ว (CAAT — ขึ้นทะเบียน/ใบอนุญาต) [4][5][6]
- **จุดแข็งไทย**: ผู้ประกอบการโดรน/บริการเยอะ, งานวิจัยแข็ง (หลายมหาวิทยาลัย), ต้นทุนบริการแข่งได้, โครงสร้างพื้นฐาน (RTK เครือข่ายภาครัฐเริ่มมี)
- **จุดอ่อน**: การแปลงภาพเป็น "คำสั่งปุ๋ย/น้ำ" ยังไม่มาตรฐาน, การพิสูจน์ผลตอบแทนรายแปลงไม่ชัด, เกษตรกรรายย่อยเข้าไม่ถึง (ราคา/ทักษะ), เครื่องจักร VRT ในไทยหายาก, ข้อมูล/งานวิเคราะห์กระจัดกระจาย
- **โอกาส**: (1) บริการ "สำรวจ→แผนที่→แนะนำ" ครบวงจรต่อไร่ (2) การร่วมกับโรงงานน้ำตาล/บริษัทปุ๋ย (อ้อย/ข้าวโพด — มีสัญญาซื้อขายล่วงหน้า) (3) งานไทยนับต้นข้าว/ตรวจโรคทุเรียน-ยาง (4) การรวมโดรน+ดาวเทียม (ราคาถูกลง)
- **หน่วยงาน**: CAAT, GISTDA, มก./มข./มจพ., โรงงานน้ำตาล/ผู้ประกอบการ, สำนักงานเกษตร

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: มาตรฐาน "แผนที่ใช้บังคับ" สำหรับเครื่องจักรไทย (รูปแบบ/การสอบเทียบ — เชื่อม 02-012) — ยังไม่มี

- **Q3**: การสอบเทียบ NDVI/เทอร์มอลต่อพันธุ์ไทย (ข้าวพันธุ์ส่งออก/ทุเรียน/ยาง) — ยังไม่ครบ
- **Q4**: โดรน hyperspectral ราคาถูก/การประมวลผลอัตโนมัติสำหรับตรวจโรคทุเรียน/ยาง (เชื่อม 05-001) — ยังเป็นงานวิจัย
- **Q5**: การรวมโดรน+ดาวเทียม+IoT (05-003/05-007) เป็น "ภาพรายแปลงอัตโนมัติรายสัปดาห์" — ยังไม่มี
- **Q6**: การยอมรับ/การตัดสินใจซื้อบริการของเกษตรกรไทย (ต่อยอด 14-003) — ยังไม่มี

| 1 (1–2 ปี) | นำร่อง "สำรวจโดรน→แผนที่ปุ๋ย/น้ำ" 30–50 แปลง (อ้อย/ข้าว/ทุเรียน) กับโรงงานน้ำตาล/สหกรณ์ — บันทึกต้นทุน/ผลลัพธ์                                | มาตรฐานบริการสำรวจ (ราคา/คุณภาพข้อมูล); แนวทาง CAAT สำหรับงานเกษตร (ใบอนุญาตง่ายขึ้น)             |
| 2 (2–4 ปี) | บริการ "แผนที่ใช้บังคับ" ต่อไร่ (ผู้ประกอบการ+ซอฟต์แวร์ไทย); การติดตั้ง VRT ร่วม (เครื่องจักรนำเข้า/ประกอบ) — ขยายเป็นอ้อย/ข้าวโพดมันสำปะหลัง | ระบบ RTK สาธารณะครอบคลุมพื้นที่เกษตร; ฐานข้อมูล "เส้นโค้งสอบเทียบ" พืชไทยเปิด                     |
| 3 (4+ ปี)  | "โดรนอัตโนมัติประจำแปลง" (บิน-วิเคราะห์-สั่งเครื่อง) — บริการรายเดือน; การรวมข้อมูลทุกชั้น (ดาวเทียม+โดรน+IoT — เชื่อม 05-001/05-003)         | นโยบาย "ฟาร์มอัจฉริยะ" (ข้อมูลรายแปลงเป็นบริการสาธารณะ); การรับรองผลตอบแทนเพื่อสินเชื่อ/ประกันภัย |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย           | รายละเอียด                                  | โอกาสแก้                                  |
| -------------------- | ------------------------------------------- | ----------------------------------------- |
| ต้นทุน/การเข้าถึง    | ชุดอุปกรณ์แพง; รายย่อยเข้าไม่ถึง            | บริการรายไร่, สหกรณ์ซื้อร่วม, RTK สาธารณะ |
| การแปลงภาพเป็นคำสั่ง | มีภาพแต่ไม่มีระบบ "แผนที่→เครื่องจักร"      | มาตรฐานซอฟต์แวร์/การผูกเครื่องจักร, อบรม  |
| การสอบเทียบ          | NDVI/เทอร์มอลต่างพันธุ์/สภาพ                | งานวิจัยสอบเทียบไทย, ข้อมูลเปิด           |

| สภาพอากาศ/เวลา       | บินได้เฉพาะลมสงบ/ไม่มีฝน — บางฤดูถ่ายไม่ได้ | วางแผนการบิน/การใช้ดาวเทียมเสริม (05-001) |
| การพิสูจน์ผลตอบแทน   | ผลต่างปี/แปลง — เชื่อถือยาก                 | การวัดผลระยะยาว (Q2), แปลงสาธิต           |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ความละเอียด 0.5–5 ซม. (บิน 30–120 ม.)** — ตรวจเอกสาร/งาน (ระบุเซนเซอร์/ความสูง)
- [ ] **นับต้น/กอ ~85–95%** — ตรวจงาน CNN (ระบุพืช/ชุดข้อมูล)
- [ ] **LiDAR ความสูงทรงพุ่ม ±2–5%** — ตรวจงาน (DJI L1-class)
- [ ] **NDVI โดรน vs LAI/SPAD R² 0.7–0.9** — ตรวจงานไทย/ต่างประเทศ
- [ ] **ราคาบริการสำรวจไทย 200–1,000 บาท/ไร่** — ตรวจตลาด/ข่าว
- [ ] **ราคาชุดเซนเซอร์มัลติสเปกตรัม 2–6 แสนบาท / โดรน 3 หมื่น–1.5 แสน** — ตรวจราคาตลาดล่าสุด
- [ ] **VRT ตามแผนที่ NDVI ลดปุ๋ย N 10–30%** — ตรวจงาน (ระบุพืช/ปี)
- [ ] **กฎ CAAT สำหรับโดรนเกษตร** — ตรวจประกาศ/ระเบียบอัปเดต
