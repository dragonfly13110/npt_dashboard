## 1. บทสรุปผู้บริหาร

- **ใจความ**: "น้ำเค็มหมุนเวียน" คือการนำน้ำกร่อย/น้ำเค็ม/น้ำเสียมาใช้ซ้ำในระบบเกษตรอย่างเป็นระบบ — ทั้งบำบัดให้กลับมาใช้ได้ (RO/ED ต้นทุนถูกลง), ใช้เลี้ยงสัตว์น้ำ (RAS — เชื่อม 09), ใช้กับพืชทนเค็ม (halophyte), หรือจัดการ "สมดุลเกลือ" ไม่ให้สะสมในแปลง [1] เป็นส่วนสำคัญของ "การหมุนเวียนน้ำ" ในเขตขาดแคลนน้ำจืด
- **ขั้นพัฒนา**: 🧪 นำร่องแปลงทดลอง ถึง 🏭 เชิงพาณิชย์เริ่มต้น — RO เพื่อน้ำชลประทาน/น้ำกุ้งมีใช้จริง; RAS กุ้ง/ปลาเชิงพาณิชย์แล้ว แต่การทำ "ระบบปิดครบวงจรในฟาร์ม" ยังน้อย
- **ตัวเลขสำคัญที่สุด**: ระบบหมุนเวียน (RAS) ลดการใช้น้ำจืดลง ~90%+ เทียบระบบเปิด (ช่วงอ้างอิง — ยังต้องยืนยัน) [4]; ต้นทุนบำบัดน้ำเค็มด้วย RO ลดลงเหลือ ~0.5–1 ดอลลาร์สหรัฐ/ลบ.ม. ในโรงใหญ่ (ยังต้องยืนยัน) [3]
- **นัยต่อไทย**: น้ำบาดาลเค็มภาคอีสานเป็นทั้งปัญหา (ดินเค็ม — 02-006) และทรัพยากร (กุ้งขาวนาอีสาน เกษตรน้ำเค็ม); น้ำเสียจากฟาร์ม/เมืองเป็นแหล่งน้ำหมุนเวียนที่ยังใช้ไม่คุ้ม
- **สถานะโดยรวม**: 🧪 นำร่อง / 🏭 เชิงพาณิชย์เริ่มต้น

## 2. หลักการและขอบเขต

- **แหล่งน้ำเค็ม/น้ำเสียที่หมุนเวียนได้**: (1) น้ำบาดาลกร่อย/เค็ม (ภาคอีสาน/ชายฝั่ง) (2) น้ำเสียจากฟาร์มสัตว์/โรงงานแปรรูป (3) น้ำทิ้งระบบ RAS/บ่อกุ้ง (4) น้ำทิ้งเมือง (treated wastewater) — แต่ละแหล่งมีระดับเกลือ/สารปนเปื้อน/ต้นทุนบำบัดต่างกัน
- **แนวทางจัดการ 4 ทาง**: (ก) บำบัดเพื่อน้ำจืด — RO/nanofiltration/electrodialysis (ED) ต้นทุนต่ำลง + การจัดการ "น้ำเข้มข้น" (brine) ทิ้งอย่างถูกวิธี (ข) ใช้เกลือให้เป็นประโยชน์ — เลี้ยงกุ้ง/ปลากร่อย/สาหร่าย (IMTA — เชื่อม 09), ปลูก halophyte/ข้าวเค็ม (เชื่อม 01-007) (ค) หมุนเวียนในฟาร์ม — RAS กรองน้ำหมุนกลับ ลดการปล่อย (ง) ป้องกันการสะสม — ชลประทานแม่นยำ (03-001/03-003) + ล้างเกลือ (leaching) + การระบายน้ำ
- **แนวคิด "salt balance"**: เกลือเข้าสู่แปลง (น้ำชลประทาน/น้ำใต้ดิน) ต้องสมดุลกับเกลือที่ออก (ล้าง/ระบาย) — ไม่เช่นนั้นดินเค็มสะสม (เชื่อม 02-006)
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยีบำบัด, การใช้น้ำเค็มเลี้ยงสัตว์น้ำ/พืช, RAS, การหมุนเวียนน้ำเสียเกษตร; สถานการณ์ไทย
- **นอกขอบเขต**: RAS/การเลี้ยงกุ้งเชิงลึก (ดู 09 — ยังว่าง), การฟื้นฟูดินเค็ม (ดู 02-006), ชลประทานดิจิทัล (03-001), น้ำเสียเมืองเชิงสุขาภิบาล

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                      | แหล่ง  |
| ----------- | ----------------------------------------------------------------------------------------------------------------- | ------ |
| 1990s–2000s | ต้นทุน RO ลดลงเรื่อย ๆ; เริ่มใช้ RO ผลิตน้ำสำหรับฟาร์ม/โรงแยกเกลือขนาดเล็ก                                        | [3]    |
| 2000s–2010s | RAS กุ้ง/ปลาเชิงพาณิชย์ (สหรัฐฯ/ยุโรป/ไทย) — ลดน้ำ ปล่อยของเสียน้อย                                               | [4]    |
| 2010s       | งาน "brackish agriculture" (halophyte/ข้าวทนเค็ม — เชื่อม 01-007); อิสราเอล/สเปนบำบัดน้ำเสียใช้ชลประทานเป็นนโยบาย | [1][2] |
| 2020s       | ระบบไฮบริด RO+RAS + พลังงานแสงอาทิตย์ (น้ำเค็ม->น้ำจืดด้วยโซลาร์) ในพื้นที่แห้งแล้ง                               | [3][5] |
| 2025–2026   | การหมุนเวียน "เกลือเป็นทรัพยากร" (brine mining/เคมีภัณฑ์) + มาตรฐานน้ำหมุนเวียนเกษตร                              | [5]    |

- **เส้นแบ่ง**: บำบัดน้ำเค็มด้วย RO เป็นเทคโนโลยีสุกแล้ว (ต้นทุนคือตัวแปรหลัก) — RAS ก็พาณิชย์แล้ว — สิ่งที่ยังเป็นงานวิจัยคือ "การผสานครบวงจรในฟาร์มเดียว" กับ "การจัดการ brine/สมดุลเกลือ" ระยะยาว

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                   | ผลลัพธ์                                                            | สถานที่/เงื่อนไข                      | แหล่ง |
| ------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------- | ----- |
| ต้นทุน RO น้ำเค็ม                           | ~0.5–1 ดอลลาร์สหรัฐ/ลบ.ม. (โรงขนาดใหญ่) — เล็กลงแพงขึ้น            | ต่างประเทศ — ยังไม่ยืนยัน             | [3]   |
| RAS ลดการใช้น้ำจืด                          | ~90%+ เทียบระบบเปิด (กุ้ง/ปลา)                                     | ระบบเชิงพาณิชย์ — ยังไม่ยืนยัน        | [4]   |
| พลังงาน RO                                  | ~3–6 kWh/ลบ.ม. (น้ำทะเล) — กร่อยถูกกว่า                            | สเปกผู้ผลิต/งานวิชาการ — ยังไม่ยืนยัน | [3]   |
| น้ำทิ้งเมืองบำบัดแล้วใช้ชลประทาน (อิสราเอล) | ครอบคลุม >80% ของน้ำชลประทาน (อ้างรายงาน)                          | อิสราเอล — ยังไม่ยืนยัน               | [2]   |
| กุ้งขาวนาเกลืออีสาน                         | มีการทำเชิงพาณิชย์/รายได้ดีในบางพื้นที่ (ตัวเลขผลผลิตยังไม่ยืนยัน) | ภาคอีสานไทย — ยังไม่ยืนยัน            | [6]   |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **ข้อควรระวัง**: การหมุนเวียนน้ำเค็มต้องบริหาร "brine" (น้ำเข้มข้นที่เหลือ) — ทิ้งผิดทางจะสร้างดินเค็ม/น้ำใต้ดินเค็มใหม่ (เชื่อม 02-006)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดบำบัดน้ำ/desalination โลก >15 พันล้านดอลลาร์สหรัฐ (analyst estimate — ยังไม่ยืนยัน) [5]; ตลาด RAS/อุปกรณ์น้ำหมุนเวียนเกษตรเติบโต (ตัวเลขต้องยืนยัน — เชื่อม 09)
- **ผู้เล่นหลัก**: ผู้ผลิตเมมเบรน/ระบบ RO (Toray, SUEZ/Veolia, Hydranautics/Nitto, Dupont Water) [3]; ผู้ให้บริการระบบน้ำฟาร์ม/โรงแยกเกลือขนาดเล็ก; ผู้ผลิตอุปกรณ์ RAS (Pentair, Akva Group, ไทย: ผู้ผลิตบ่อ/ระบบกรองรายย่อย) [4]
- **การลงทุน**: โครงการน้ำเค็ม->น้ำจืดด้วยโซลาร์ในเอเชีย/แอฟริกาได้รับทุนพัฒนาระหว่างประเทศ (ตัวเลขยังไม่ยืนยัน) [5]
- **ปัจจัยขับเคลื่อน**: การขาดแคลนน้ำจืด, นโยบายน้ำเสีย/สิ่งแวดล้อม, ต้นทุนพลังงานโซลาร์ที่ถูกลง, ภัยแล้งซ้ำ
- **ปัจจัยฉุดรั้ง**: ต้นทุนพลังงาน/การลงทุน, การจัดการ brine, ความเชื่อถือของเกษตรกร, กฎหมายน้ำ

## 6. สถานการณ์ประเทศไทย

- **น้ำบาดาลเค็ม**: กรมทรัพยากรน้ำบาดาลจัดทำแผนที่/จัดการน้ำบาดาลเค็ม (ภาคอีสาน) — โอกาสใช้เป็น "ทรัพยากร" (กุ้ง/เกลือสินเธาว์) มากกว่ามองเป็นปัญหา [6]
- **กุ้งขาวนาอีสาน**: การเลี้ยงกุ้งด้วยน้ำบาดาลเค็มในนาอีสาน (เชื่อมโยงกับงานเกลือ/ภูมิปัญญา) มีผู้ประกอบการ/ผลผลิตจริง — เป็นตัวอย่าง "ใช้เกลือให้เป็นประโยชน์" (ตัวเลขยังไม่ยืนยัน) [6]
- **น้ำเสียฟาร์ม/เมือง**: ระบบบำบัดน้ำเสียของเมือง/โรงงานมี แต่การนำกลับมาใช้ชลประทานยังไม่เป็นระบบ (มาตรฐาน/ท่อส่ง/ความเชื่อถือ) — งานเริ่มมีในโครงการพระราชดำริ/มหาวิทยาลัย (ยังไม่ยืนยัน)
- **นโยบาย**: แผนแม่บทน้ำ 20 ปี มีหัวข้อ "การนำน้ำกลับมาใช้ใหม่" — ระดับปฏิบัติยังจำกัด (ยังไม่ยืนยัน)
- **อุปสรรค**: ต้นทุนบำบัดสูงสำหรับแปลงเล็ก, กฎหมาย/การจัดสรรน้ำ, การยอมรับผลผลิตจากน้ำหมุนเวียน

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: เศรษฐศาสตร์ RO/บำบัดน้ำเค็มต่อไร่/ต่อลบ.ม. ในเงื่อนไขไทย (แปลงเล็ก/ค่าไฟฟ้า) — ยังไม่มีตัวเลข
- **Q2**: ผลระยะยาวของการใช้น้ำเค็มหมุนเวียนชลประทานต่อดิน/น้ำใต้ดิน (สมดุลเกลือ) ในไทย — ยังไม่มีงาน
- **Q3**: การจัดการ brine ในไทยอย่างถูกวิธี (ทิ้ง/ใช้ต่อยอด) — ยังไม่มีมาตรฐาน
- **Q4**: ศักยภาพ "กุ้ง+ข้าว+เกลือ" แบบหมุนเวียนในนาอีสาน (ระบบผสม) — ยังไม่ได้ศึกษาครบวงจร
- **Q5**: มาตรฐานคุณภาพน้ำหมุนเวียนสำหรับพืช/สัตว์น้ำไทย (เชื่อม 09) — ยังไม่มีข้อบังคับชัดเจน
- **Q6**: การยอมรับของผู้บริโภค/ตลาดต่อสินค้าจากน้ำหมุนเวียน — ยังไม่มีการสำรวจไทย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                     | ระดับนโยบาย                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 1 (1–2 ปี) | แปลงสาธิต 2 โมเดล: (1) RAS/กุ้ง+น้ำหมุนเวียนในอีสาน (2) น้ำเสียฟาร์ม->บ่อบำบัด->ชลประทานสวน; เก็บข้อมูลน้ำ/ผลผลิต/ต้นทุน | แผนที่น้ำบาดาลเค็ม/น้ำเสียที่ใช้ได้ (ข้อมูลเปิด); มาตรฐานคุณภาพน้ำหมุนเวียนเบื้องต้น |
| 2 (2–4 ปี) | บริการ "บำบัดน้ำฟาร์มแบบเหมาจ่าย" (RO โซลาร์ขนาดเล็ก + RAS) ผ่านสหกรณ์; ขยายระบบผสมกุ้ง-ข้าว-เกลือ                       | กฎหมายน้ำเสีย->การชลประทานอย่างเป็นระบบ + เงินทุน (กองทุนน้ำ/ธ.ก.ส.); นโยบาย brine   |
| 3 (4+ ปี)  | เกษตรน้ำหมุนเวียนเป็นแนวปฏิบัติมาตรฐานในเขตน้ำเค็ม/ขาดแคลน; สินค้า (กุ้ง/ข้าว) ได้การรับรองความยั่งยืน                   | แผนแม่บท "น้ำหมุนเวียนเกษตร" ระดับชาติ + การจัดการลุ่มน้ำที่รวมน้ำเค็มเป็นทรัพยากร   |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย            | รายละเอียด                                  | โอกาสแก้                                             |
| --------------------- | ------------------------------------------- | ---------------------------------------------------- |
| ต้นทุนพลังงาน/อุปกรณ์ | RO/RAS ใช้ไฟฟ้ามาก ลงทุนสูง                 | โซลาร์+แบตเตอรี่; สเกลรวมผ่านกลุ่ม                   |
| การจัดการ brine       | ทิ้งไม่ถูกวิธีสร้างดิน/น้ำเค็มใหม่          | มาตรฐาน+แผนที่แหล่งทิ้ง; ใช้ต่อยอด (เกลือ/เคมีภัณฑ์) |
| สมดุลเกลือในแปลง      | ใช้ซ้ำแล้วสะสมเกลือในดิน (เชื่อม 02-006)    | ตรวจวัด EC สม่ำเสมอ + การล้างเกลือตามรอบ             |
| กฎหมาย/สิทธิ์น้ำ      | น้ำเสีย/น้ำบาดาลเค็มเป็นของใคร ใช้ได้แค่ไหน | กฎหมายชัดเจน + การจัดสรรพื้นที่                      |
| การยอมรับ             | เกษตรกร/ตลาดไม่คุ้นเคยสินค้าน้ำหมุนเวียน    | ฉลาก/การรับรอง + การสื่อสาร                          |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **RO 0.5–1 ดอลลาร์สหรัฐ/ลบ.ม. และ 3–6 kWh/ลบ.ม.** — หาแหล่งล่าสุด (IDA/งานทบทวน) ระบุขนาดโรง/ปี (ราคาเปลี่ยนเร็ว)
- [ ] **RAS ลดน้ำ 90%+** — ยืนยันจากงาน primary (Aquacultural Engineering/Aquaculture)
- [ ] **อิสราเอลน้ำชลประทานจากน้ำเสีย >80%** — ตรวจรายงาน/ข่าวล่าสุด (ตัวเลขอ้างบ่อยแต่ต้องยืนยันปี)
- [ ] **ตลาด desalination >15 พันล้านดอลลาร์** — ตรวจ analyst (IDA/Global Water Intelligence) ระบุปี
- [ ] **กุ้งขาวนาอีสาน/ข้อมูลน้ำบาดาลเค็ม** — ค้นกรมทรัพยากรน้ำบาดาล + ข่าว/งานวิชาการไทย ยืนยันตัวเลข
- [ ] **แผนแม่บทน้ำ 20 ปี — หัวข้อน้ำกลับมาใช้ใหม่** — ตรวจเอกสาร สทนช. ล่าสุด

## 11. อภิธานศัพท์

| คำศัพท์           | ความหมาย                                                              |
| ----------------- | --------------------------------------------------------------------- |
| RO                | การกรองรีเวิร์สออสโมซิส — บำบัดน้ำเค็มเป็นน้ำจืด                      |
| ED                | Electrodialysis — การแยกเกลือด้วยไฟฟ้า (เหมาะน้ำกร่อย)                |
| Brine             | น้ำเข้มข้นเค็มที่เหลือจากกระบวนการบำบัด                               |
| RAS               | ระบบเพาะเลี้ยงสัตว์น้ำหมุนเวียนปิด (Recirculating Aquaculture System) |
| Salt balance      | ความสมดุลของเกลือเข้า-ออกจากแปลง/ระบบ                                 |
| Halophyte         | พืชทนเค็มที่ใช้น้ำเค็มเจริญได้                                        |
| IMTA              | การเลี้ยงผสมผสานหลายสปีชีส์ (Integrated Multi-Trophic Aquaculture)    |
| Leaching fraction | สัดส่วนน้ำที่ต้องล้างเกลือออกจากเขตราก                                |
