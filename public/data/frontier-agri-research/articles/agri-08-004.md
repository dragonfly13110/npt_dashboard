## 1. บทสรุปผู้บริหาร

- **ใจความ**: เครื่องจักรกลการเกษตรไฟฟ้า (EV — รถแทรกเตอร์/รถไถเดินตาม/เก็บเกี่ยว/ฉีดพ่น/โดรน — 07-005/07-006/07-008) + การชาร์จด้วยโซลาร์ (แผงบนโรง/เพิง/โรงเรือน/ลานจอด — 08-001) = "เครื่องจักรไร้คาร์บอน" + ลดค่าน้ำมัน (ค่าไฟจากโซลาร์ถูกกว่าน้ำมัน/ดีเซล) + อิสระจากราคาน้ำมัน — แนวโน้มโลก: รถแทรกเตอร์ EV เริ่มมีรุ่นขาย (US/ยุโรป/จีน — Monarch/Fendt-class + รถไถเดินตาม EV เอเชีย) — ไทย: เครื่องจักร EV (รถไถเดินตามไฟฟ้า/โดรน/เครื่องสูบน้ำ) เริ่ม แต่ "ราคาแบต/กำลัง/ความทนทาน" ยังจำกัด [1][2][3]
- **ขั้นพัฒนา**: 🧪 นำร่อง/เริ่มขาย (EV เกษตรมีรุ่นขาย แต่ยังแพง/การชาร์จโซลาร์ในฟาร์มยังน้อย) [2][3]
- **ตัวเลขสำคัญที่สุด**: ค่าไฟฟ้าต่อการใช้งาน (EV เกษตร) ~30–60% ของค่าน้ำมันดีเซล (ช่วง — ขึ้นราคาไฟ/น้ำมัน); รถแทรกเตอร์ EV ขนาดเล็ก (~40–80 แรงม้า) ใช้งาน ~4–8 ชั่วโมง/ชาร์จ (ช่วง); ค่าใช้จ่าย EV เกษตร (ระยะยาว — เชื้อเพลิง+บำรุง) ลด ~30–50% (ช่วง — เทียบดีเซล); โซลาร์ชาร์จ (แผง ~5–10 กิโลวัตต์ + แบต) ลดค่าไฟเหลือ ~1–2 บาท/กิโลวัตต์ชั่วโมง (ช่วง — ราคาโซลาร์ไทย); แผงโซลาร์ไทย ราคาติดตั้ง ~30–50 บาท/วัตต์ (ช่วง) [1][3][4]
- **นัยต่อไทย**: ไทยมี (1) ราคาโซลาร์ถูก/แดดจัด (08-001) (2) เครื่องจักรเล็กเยอะ (รถไถเดินตาม — EV เหมาะ: ใช้สั้น/ไม่ต้องแรงม้าสูง) (3) ค่าน้ำมัน/ดีเซลสูง (แรงจูงใจ) — จุดสำคัญ: (1) เริ่มที่เครื่องจักร "ใช้น้อย/เบา" (ไถเดินตาม/ฉีดพ่น/โดรน/ปั๊มน้ำ — 08-005) ก่อนรถแทรกเตอร์ใหญ่ (ราคาแบตสูง) (2) การชาร์จโซลาร์ = "ช้าแต่ถูก" (เหมาะเครื่องจักรจอดค้างคืน/กลางวัน) (3) ยังต้องดู "แบตในความร้อนไทย" (อายุ/ความปลอดภัย) และราคา (เปลี่ยนแบตแพง) [3][4][5]
- **สถานะโดยรวม**: 🧪 นำร่อง/เริ่มขาย — รถแทรกเตอร์ EV + โซลาร์ชาร์จฟาร์มไทยยังหายาก

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (3 องค์ประกอบ)

1. **เครื่องจักร EV**: รถแทรกเตอร์/ไถเดินตาม/เก็บเกี่ยว/ฉีดพ่น/โดรน (มอเตอร์ไฟฟ้า + แบตเตอรี่ — งานกลางแจ้ง/หนัก — ต้อง "กำลัง+ความทนทาน+ฝุ่น")
2. **การชาร์จ**: (1) ชาร์จบ้าน/ฟาร์ม (ช้า — 8–12 ชม. — กลางคืน) (2) ชาร์จเร็ว (สถานี — 30 นาที–1 ชม. — สนาม/ลานจอด) (3) เปลี่ยนแบต (สวอป — โดรน/เครื่องเล็ก — งาน 07-008) (4) **โซลาร์ชาร์จ** (แผง+อินเวอร์เตอร์+แบต — ชาร์จตอนกลางวัน/เก็บ — ครบวงจร)
3. **การจัดการพลังงาน (สมาร์ทชาร์จ)**: ชาร์จเมื่อไฟถูก (โซลาร์ช่วงแดด/ค่าไฟ TOU ถูก — 05) + "Vehicle-to-farm" (แบตรถช่วยไฟฟาร์ม/สวน) — 06-001/05 ผูก

### 2.2 ข้อดี/ข้อจำกัด EV เกษตร (ตาราง)

| ข้อดี                                        | ข้อจำกัด                             |
| -------------------------------------------- | ------------------------------------ |
| ค่าไฟถูกกว่าน้ำมัน (~30–60%)                 | ราคาแบต/เครื่องแพง (แรงม้าสูงแพงมาก) |
| บำรุงน้อย (มอเตอร์ vs เครื่องยนต์)           | เวลาใช้งานสั้น (ชาร์จบ่อย)           |
| เงียบ/ไม่มีควัน (ฟาร์มปิด/โรงเรือน/ปศุสัตว์) | แบตในความร้อนไทย (อายุ/เสื่อม)       |
| แม่นยำ/ควบคุมง่าย (07-005 — อัตโนมัติ)       | น้ำหนักแบต (กดดิน)                   |
| โซลาร์ผูกได้ (ไร้คาร์บอน/ค่าไฟต่ำ)           | ช่างซ่อม EV เกษตรยังหายาก (ไทย)      |
| นโยบาย EV (บางประเทศหนุน)                    | มาตรฐานชาร์จ/อะไหล่ (ต่างยี่ห้อ)     |

### 2.3 ขอบเขต

- **ครอบคลุม**: EV เกษตร + การชาร์จ (โซลาร์/สมาร์ท) + ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: ตัวเครื่องจักรหุ่นยนต์ลึก (07 — อ้างข้าม), ปั๊มน้ำโซลาร์ (08-005 — อ้างข้าม), แบตเตอรี่ลิเธียมรีไซเคิล (12), รถยนต์ส่วนตัว EV (12)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                | ผลลัพธ์                                       | สถานที่/เงื่อนไข | แหล่ง  |
| ---------------------------------------- | --------------------------------------------- | ---------------- | ------ |
| ค่าไฟ vs น้ำมัน (EV เกษตร)               | ~30–60% ของค่าน้ำมันดีเซล (ช่วง)              | ผู้ผลิต/งาน      | [1][3] |
| รถแทรกเตอร์ EV เล็ก (40–80 แรงม้า)       | ใช้งาน ~4–8 ชม./ชาร์จ (ช่วง)                  | ผู้ผลิต          | [2]    |
| ค่าใช้จ่ายรวมระยะยาว (EV vs ดีเซล)       | ลด ~30–50% (ช่วง — เชื้อเพลิง+บำรุง)          | ผู้ผลิต/งาน      | [1][3] |
| ราคารถแทรกเตอร์ EV (เล็ก-กลาง)           | ~2–5 เท่าของดีเซลรุ่นเดียวกัน (ช่วง)          | ตลาด             | [2]    |
| ราคาติดตั้งโซลาร์ไทย                     | ~30–50 บาท/วัตต์ (ช่วง — ขึ้นขนาด/ยี่ห้อ)     | ตลาดไทย          | [4]    |
| ค่าไฟโซลาร์ชาร์จ (ระยะยาว)               | ~1–2 บาท/กิโลวัตต์ชั่วโมง (ช่วง — หลังคืนทุน) | คำนวณ/งาน        | [4]    |
| แผงโซลาร์ให้ไฟต่อวัน (ไทย — 1 กิโลวัตต์) | ~3.5–4.5 กิโลวัตต์ชั่วโมง/วัน (ช่วง — แดดไทย) | งาน/ผู้ประกอบการ | [4]    |
| อายุแบต LFP                              | ~3,000–6,000 รอบ (ช่วง)                       | ผู้ผลิต          | [3]    |

- **กฎ**: "EV เกษตรคุ้มเมื่อ 'ใช้งานน้อยครั้ง/เบา + ค่าไฟโซลาร์ถูก' (ไถเดินตาม/ฉีดพ่น/โดรน/ปั๊มน้ำ — 08-005) — รถแทรกเตอร์ใหญ่ (แรงม้าสูง) ยังแพง" — "การชาร์จโซลาร์ = ช้าแต่ถูก (เหมาะชาร์จกลางวัน/คืน) — ไม่เหมาะงานต่อเนื่องเร่งด่วน" — ตัวเลขช่วงกว้าง (ราคาเปลี่ยนเร็ว) — ตรวจหัวข้อ 10
- **หมายเหตุ**: ราคาแบต/เครื่องเปลี่ยนเร็ว (ปีต่อปี) — อย่ายึดค่าเดียว

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดรถแทรกเตอร์ EV ยังเล็ก (~<1–2% ของตลาดรถแทรกเตอร์ — ช่วง) แต่โตเร็ว (เป้าหมาย/นโยบาย EU/US); ตลาดเครื่องจักร EV (ไถเดินตาม/โดรน/เล็ก) โตกว่า (เอเชีย — จีน/ญี่ปุ่น); แนวโน้มแบต LFP ราคาลง (~$50–80/กิโลวัตต์ชั่วโมง — ช่วง 2025–26) [2][3][4]
- **ผู้เล่นหลัก**: ผู้ผลิตรถแทรกเตอร์ (John Deere/Fendt/Monarch-class), ผู้ผลิตไถเดินตาม EV (จีน/ญี่ปุ่น/ไทย), ผู้ผลิตโดรน (07-008), ผู้ติดตั้งโซลาร์ (ไทย — ครบวงจร), ผู้ผลิตแบต (LFP — จีน/ไทย), ผู้ประกอบการฟาร์ม/สหกรณ์

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                            | ฉุดรั้ง                               |
| ------------------------------------- | ------------------------------------- |
| ค่าน้ำมัน/ดีเซลสูง (ไทย)              | ราคาเครื่อง EV สูง (แรงม้าใหญ่แพงมาก) |
| ราคาโซลาร์/แบตลดลง                    | แบตเสื่อมในความร้อน (ไทย)             |
| นโยบาย EV (โลก/ไทย — สนับสนุน)        | ช่างซ่อม/อะไหล่ EV เกษตรน้อย (ไทย)    |
| การทำงานอัตโนมัติ (07-005 — EV เหมาะ) | เวลาชาร์จ/ความต่อเนื่องงาน            |
| ไร้คาร์บอน/ESG (08-002)               | มาตรฐานชาร์จ/ความเข้ากัน (ต่างยี่ห้อ) |

- **แนวโน้ม**: แบต LFP ราคาถูกลง (ทำให้ EV เกษตรคุ้มขึ้น), "โซลาร์+แบต+ชาร์จ+เครื่อง EV" ครบวงจร (ผู้ประกอบการแพ็กเกจ), V2F (แบตรถช่วยไฟฟาร์ม — 05 สมาร์ทกริด), รถแทรกเตอร์อัตโนมัติ EV (07-005), การผูกคาร์บอน/การตลาด ESG (08-002), การเช่า/จ่ายตามงาน (EV as a service — 14)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยมี (1) โดรนการเกษตร (07-008 — ใช้จริง/แพร่หลาย) (2) รถไถเดินตาม/เครื่องจักรเล็ก EV (นำเข้า/ประกอบ/งานทดลอง — เริ่ม) (3) รถแทรกเตอร์ EV (นำเข้า — ราคาสูง/ยังน้อย) (4) โซลาร์ฟาร์ม/โซลาร์ติดตั้งราคาถูก (08-001 — แดดจัด) (5) นโยบาย EV (ไทย — EV3.5-class — สนับสนุนรถยนต์/เริ่มขยายเครื่องจักร) — การชาร์จโซลาร์ในฟาร์ม (นำร่อง — สถานะต้องตรวจ) [4][5]
- **จุดแข็งไทย**: ราคาโซลาร์ถูก/แดดจัด, เครื่องจักรเล็กเยอะ (ไถเดินตาม — EV เหมาะ), ค่าน้ำมัน/ดีเซลสูง (แรงจูงใจ), โดรนใช้จริงแล้ว (07-008 — ชินกับ EV), นโยบาย EV (เริ่ม), ผู้ประกอบการโซลาร์/เครื่องจักรมี
- **จุดอ่อน**: ราคา EV แรงม้ากลาง-ใหญ่สูง (นำเข้า), ช่างซ่อม/อะไหล่ EV เกษตรน้อย, แบตในความร้อน (อายุ), การชาร์จโซลาร์ฟาร์มยังน้อย/ไม่เป็นระบบ, การยอมรับ/ความรู้ (14-003), แหล่งเงิน/สินเชื่อเครื่อง EV (ธนาคารยังไม่ชิน)
- **โอกาส**: (1) "เครื่องจักรเล็ก EV + โซลาร์ชาร์จ" (ไถเดินตาม/ฉีดพ่น/โดรน/ปั๊มน้ำ — 08-005 — ฟาร์มเล็ก/กลาง — คุ้มทันที) (2) "แพ็กเกจโซลาร์+แบต+ชาร์จ" (ผู้ประกอบการไทย — ครบวงจร — ฟาร์ม/สหกรณ์) (3) "EV กลาง/ใหญ่ + อัตโนมัติ" (07-005 — ไร่ใหญ่/บริษัท — ค่าแรง/น้ำมันลด) (4) "V2F/สมาร์ทกริดฟาร์ม" (05 — แบตรถช่วยไฟ) (5) "EV as a service/เช่า" (14 — ไม่ต้องซื้อ)
- **หน่วยงาน**: กระทรวงพลังงาน/กกพ. (นโยบาย/ค่าไฟ), กรมวิชาการ/มก. (งานทดลองเครื่อง EV), BOI (การลงทุน/นำเข้า), ผู้ประกอบการโซลาร์/เครื่องจักร, ธนาคาร/กองทุน (สินเชื่อ EV เกษตร), สวทช./NIA (ทุน)
