## 1. บทสรุปผู้บริหาร

- **ใจความ**: กับดักแมลงอัจฉริยะ (pheromone trap + กล้อง + AI นับ/จำแนกแมลง) และกล้องเฝ้าดูแปลง (แมลงวันผลไม้/หนอน/โรค — จับภาพต่อเนื่อง) ส่งข้อมูลผ่าน LoRaWAN/เซลลูลาร์ (05-003) → เตือนการระบาดก่อนถึงระดับทำลายทางเศรษฐกิจ (EIL) — เปลี่ยนจากการเดินสำรวจรายสัปดาห์เป็นการเฝ้าต่อเนื่องรายวัน/รายชม. [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (Trapview/Semios/FarmSense ใช้จริงในไร่ใหญ่ต่างประเทศ; ไทยเริ่มนำร่องสวนผลไม้) — ประเด็นหลัก: ราคา/ความแม่นยำรายชนิดแมลงไทย/การผูกกับการตัดสินใจพ่น [2][3]
- **ตัวเลขสำคัญที่สุด**: กับดักอัจฉริยะ ~10,000–50,000 บาท/จุด (ช่วง — ต่างประเทศ); ความแม่นยำนับ/จำแนกแมลง (CNN) ~80–95% (ชนิดที่ฝึกไว้); ครอบคลุม 1 จุดต่อ 10–50 ไร่ (ขึ้นชนิดแมลง/พื้นที่); ลดการพ่น (พ่นตาม EIL ไม่ใช่ตามตาราง) 20–40% (งานต่างประเทศ) [1][2][3]
- **นัยต่อไทย**: ไทยพึ่งพ่นยาตามตาราง/ตามฤดูเป็นหลัก — กับดักอัจฉริยะ (แมลงวันผลไม้/หนอนเจาะ/เพลี้ย) เหมาะสวนทุเรียน/มังคุด/ลองกองและแปลงส่งออก (สารตกค้าง/การส่งออก — เชื่อม 12) [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ต่างประเทศ) — ไทยนำร่อง

## 2. หลักการและขอบเขต

- **หลักการ**: (1) กับดักดักแมลง (ฟีโรโมน/แสง/สี) + กล้องจับภาพภายในเป็นช่วง (รายชม.) → AI นับ/จำแนกชนิด/เพศ → นับสะสม (cumulative catch) → เปรียบเทียบกับ "เกณฑ์เตือน/EIL" → แจ้งเตือนในแอป (05-002) [1][2] (2) กล้องแปลง/กล้องดักสัตว์: ตรวจจับการเคลื่อนไหว/จับภาพ → AI ระบุ (แมลงปีกแข็ง/หนู/นก/คน) → เตือน [3]
- **เทคโนโลยีประกอบ**: Edge AI (ประมวลผลในกับดัก — 05-005), โซลาร์+แบต (อยู่กลางแปลง), ฟีโรโมนเฉพาะชนิด (ต้องเปลี่ยนทุก 2–8 สัปดาห์), การจำแนกด้วยภาพ (CNN/YOLO — ต้องการชุดข้อมูลแมลงของพื้นที่)
- **ข้อจำกัดหลัก**: แมลงบางชนิดดักยาก (ไม่เข้าแสง/ฟีโรโมนยังไม่มี), การจำแนกชนิดใกล้เคียงกันผิดได้, จำนวนชนิดที่รองรับ (ชุดข้อมูล), กับดักนับได้เฉพาะสิ่งที่เข้ามา
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/เชิงพาณิชย์, งานไทย, แนวทางใช้
- **นอกขอบเขต**: IPM/การพ่น (04-009), กับดัก/ชีววิธีทั่วไป (04-009), การสำรวจด้วยโดรน (05-006), การเตือนโรคจากสภาพอากาศ (05-008)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                                                   | แหล่ง     |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| 2010s     | กับดักถ่ายภาพ/ส่งภาพ (Semios/Trapview เริ่ม — สวนผลไม้อเมริกา/ยุโรป); งาน CNN จำแนกแมลงเริ่ม                                                   | [1][2]    |
| 2018–2021 | Edge AI ในกับดัก (นับในตัว/ส่งเฉพาะผล); การจำแนกหลายชนิด (ยุง/แมลงวันผลไม้/หนอนเจาะ); แพลตฟอร์มเตือนภัย                                        | [2][3]    |
| 2022–2025 | กับดักถูก/เล็ก (ราคาลง); งานชุดข้อมูลแมลง (หลายภูมิภาค); การผูกกับ EIL/การตัดสินใจพ่น (IPM — เชื่อม 04-009); ไทยเริ่มงานนับเพลี้ย/แมลงวันผลไม้ | [2][4][5] |
| 2026–     | แนวโน้ม: ราคาลงถึง "รายแปลงเล็กใช้ได้", การจำแนกครอบคลุมหลายร้อยชนิด (foundation model — เชื่อม 06), การผูกกับการพ่นเฉพาะจุด (โดรน — 05-005)   | [3]       |

- **เส้นแบ่ง**: ต่างประเทศใช้เชิงพาณิชย์แล้ว (สวนใหญ่) — ไทยยังนำร่อง; อุปสรรค: ราคาต่อจุด, ชุดข้อมูลแมลงไทย, ฟีโรโมน/การบำรุงรักษา, การยอมรับของเกษตรกร

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                              | ผลลัพธ์                             | เงื่อนไข       | แหล่ง  |
| -------------------------------------- | ----------------------------------- | -------------- | ------ |
| ความแม่นยำจำแนกแมลง (CNN — ชนิดที่ฝึก) | ~80–95% (Top-1/Top-2)               | ชุดข้อมูลเฉพาะ | [2]    |
| ราคากับดักอัจฉริยะ (จุด)               | ~10,000–50,000 บาท (Trapview-class) | ตลาด/งาน       | [3]    |
| ครอบคลุม/จุด                           | 10–50 ไร่ (ขึ้นชนิด/พื้นที่)        | แนวทาง         | [3]    |
| ลดการพ่น (พ่นตาม EIL)                  | 20–40% (สวนต่างประเทศ)              | งาน IPM        | [2][3] |
| ความถี่ข้อมูล                          | รายชม.–รายวัน (ภาพ/จำนวน)           | อุปกรณ์        | [1]    |
| อายุฟีโรโมน/เหยื่อ                     | 2–8 สัปดาห์ (ต้องเปลี่ยน)           | อุปกรณ์        | [1]    |
| จำนวนชนิดแมลงในฐาน (แพลตฟอร์มใหญ่)     | หลายสิบ–หลายร้อยชนิด (ช่วง)         | แพลตฟอร์ม      | [3]    |
| ลดแรงงานสำรวจ                          | 60–90% (เทียบเดินสำรวจ)             | งาน/บริการ     | [3]    |
| ระยะเตือนก่อนระบาด                     | ก่อนระดับทำลาย 3–14 วัน (ขึ้นชนิด)  | งาน            | [2]    |

- **กฎ**: ประโยชน์เต็มเมื่อ "มีเกณฑ์ EIL/ระดับเตือน" สำหรับชนิดนั้น (มีในงานวิจัย/ต่างประเทศ — ไทยต้องปรับ) + การตอบสนองจริง (พ่น/กับดักเพิ่ม) — กับดักอย่างเดียวไม่ลดสาร
- **เงื่อนไขสำคัญ**: (1) ชุดข้อมูลแมลงพื้นที่ (ไทยยังขาด) (2) ฟีโรโมน/เหยื่อเฉพาะชนิด+การเปลี่ยนสม่ำเสมอ (3) การวางจุดถูกต้อง (ตามลม/ทรงพุ่ม) (4) การเชื่อมกับระบบแจ้งเตือน/คำแนะนำ (5) ราคาต่อจุด vs มูลค่าพืช

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: กับดักอัจฉริยะ/เฝ้าระวังแมลง ~0.2–0.8 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 15–25%/ปี [3]
- **ผู้เล่นหลัก**: Trapview (ยุโรป/สหรัฐฯ — ผีเสื้อกลางคืน), Semios (สหรัฐฯ/แคนาดา — สวนผลไม้), FarmSense (สหรัฐฯ), Spensa (สหรัฐฯ — เม็กซิโก), ผู้ไทย/อาเซียน: งานวิจัย (มก./มข./จุฬา — เพลี้ย/แมลงวันผลไม้) + ผู้ประกอบการเริ่ม [2][3][4][5]
- **การลงทุน**: กับดัก 1–5 จุด/แปลง (เริ่ม) + แอป/แพลตฟอร์ม (รายเดือน); เหมาะสวนผลไม้ราคาสูง/ส่งออก (ทุเรียน/มังคุด/ลองกอง/ลิ้นจี่); โมเดล "บริการเฝ้าระวังต่อไร่/ต่อเดือน" กำลังมา
- **แนวโน้ม**: ราคาลง (Edge AI ถูก — 05-005), การจำแนกอัตโนมัติหลายชนิด, การผูกกับโดรนพ่นเฉพาะจุด (05-005) และ IPM (04-009), ข้อมูลเปิด (การระบาดระดับภูมิภาค)
- **ความเสี่ยง**: การยอมรับ/ความเชื่อถือ (ตัวเลขแมลง "จริง?"), การตลาดเกินจริง (จำแนกได้ทุกชนิด?), การพึ่งซอฟต์แวร์/การอัปเดต, การหยุดใช้หลังโปรเจกต์ (บำรุงรักษา/ค่าสมาชิก)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: งานวิจัยเฝ้าระวังแมลงด้วยภาพ (แมลงวันผลไม้/เพลี้ยกระโดด/หนอนเจาะ — มก./มข./จุฬา/วว.) มีอยู่จริง; ผู้ประกอบการไทยเริ่มนำเข้ากับดักอัจฉริยะ/ทำต้นแบบ (สวนทุเรียน/มังคุด — นำร่อง); การใช้กว้างยังน้อย — การเฝ้าระวังหลักยังเป็นกับดักธรรมดา/การสำรวจเจ้าหน้าที่ (กรมวิชาการเกษตร — ระบบเตือนโรคแมลงรายจังหวัดมีอยู่) [4][5][6]
- **จุดแข็งไทย**: งานวิจัยภาพแมลงไทยมี, พืชส่งออกมูลค่าสูง (ทุเรียน/มังคุด) จ่ายไหว, ระบบเตือนของรัฐมีโครงสร้างอยู่ (ต่อยอดได้), สารตกค้าง/ตลาดส่งออกกดดันให้ลดพ่น
- **จุดอ่อน**: ชุดข้อมูลแมลงไทยแบบเปิดยังขาด, ราคากับดัก/ค่าบริการยังสูงต่อไร่, การบำรุงรักษา (ฟีโรโมน/แบต) ในพื้นที่, การยอมรับของเกษตรกรรายย่อย, การเชื่อมกับ "การตัดสินใจพ่น" ยังไม่เป็นระบบ
- **โอกาส**: (1) "ชุดข้อมูลภาพแมลงไทย" (แมลงวันผลไม้/เพลี้ย/หนอน — เปิด) (2) บริการ "เฝ้าระวัง+เตือน+แนะนำพ่น" สำหรับสวนส่งออก (เชื่อม 12) (3) การผูกกับระบบเตือนของกรมวิชาการเกษตร (ต่อยอด) (4) ต้นแบบกับดักไทยราคาถูก (ผลิตในประเทศ)
- **หน่วยงาน**: กรมวิชาการเกษตร (ระบบเตือน/กักกัน), มหาวิทยาลัย (มก./มข./จุฬา/วว.), สวนผลไม้/สหกรณ์ส่งออก, ผู้ประกอบการ AgTech

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ชุดข้อมูลภาพแมลงศัตรูไทย (แมลงวันผลไม้/เพลี้ยกระโดด/หนอนเจาะผล) แบบเปิดหลายสภาพแสง/มุม — ยังไม่มี
- **Q2**: การสอบเทียบกับดักอัจฉริยะกับกับดักมาตรฐาน (ความแม่นยำนับ/การเปรียบเทียบ) ในสวนไทย — ยังไม่มี
- **Q3**: เกณฑ์ EIL/ระดับเตือนสำหรับแมลงหลักไทย (ทุเรียน/มังคุด/ข้าว) ใช้ข้อมูลกับดัก — ยังไม่ครบ
- **Q4**: เศรษฐศาสตร์ "กับดักอัจฉริยะ+พ่นตาม EIL" ในสวนทุเรียน/มังคุดไทย (ROI/สารตกค้าง) — ยังไม่มี
- **Q5**: กับดักไทยราคาถูก (Edge AI + การผลิตในประเทศ) — ยังไม่มีต้นแบบเชิงพาณิชย์
- **Q6**: การยอมรับ/การใช้ต่อเนื่องของเกษตรกรไทย (ต่อยอด 14-003) — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                       | ระดับนโยบาย                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | นำร่อง 10–15 สวน (ทุเรียน/มังคุด/ลองกอง): กับดัก 3–5 จุด/สวน + แอปเตือน — เทียบการพ่นจริง/บันทึกผล                         | "ชุดข้อมูลภาพแมลงไทยเปิด" (มหาวิทยาลัย+กรมวิชาการเกษตร); ฐานเกณฑ์ EIL ไทย (เปิด)              |
| 2 (2–4 ปี) | บริการ "เฝ้าระวัง+เตือน+แนะนำพ่น" ต่อไร่ (ผู้ประกอบการ — เชื่อม 04-009/05-002); กับดักไทยต้นแบบราคาถูก                     | การรับรองบริการเฝ้าระวัง (เพื่อใบรับรองส่งออก — เชื่อม 12); สินเชื่อ/เงินหนุนกับดัก (ธ.ก.ส.)  |
| 3 (4+ ปี)  | "เฝ้าระวังแมลงอัตโนมัติรายแปลง" ทั้งประเทศที่สำคัญ (ทุเรียน/ข้าว/อ้อย) — ผูกกับโดรนพ่นเฉพาะจุด (05-005) และ IPM เต็มรูปแบบ | "ระบบเตือนแมลงแห่งชาติ" (ข้อมูลกับดัก+ดาวเทียม+สถานีอากาศ — เชื่อม 05-008) — ลดการพ่นทั้งระบบ |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย            | รายละเอียด                            | โอกาสแก้                                              |
| --------------------- | ------------------------------------- | ----------------------------------------------------- |
| ชุดข้อมูลแมลงไทย      | ชนิด/สภาพไทยไม่ครบ — จำแนกผิด         | เปิดชุดข้อมูล, งานเก็บภาพ, การเรียนรู้ต่อเนื่อง       |
| ราคาต่อจุด            | กับดัก+ฟีโรโมน+บริการ แพงรายย่อย      | กับดักถูก (Edge AI/ผลิตไทย), บริการต่อไร่, สหกรณ์     |
| การบำรุงรักษา         | ฟีโรโมนหมด/แบต/โซลาร์เสีย — กลางสวน   | สัญญาบริการ, อุปกรณ์ทนทาน, แจ้งเตือนการดูแล           |
| การยอมรับ             | เกษตรกรไม่ไว้ใจตัวเลข/ไม่รู้วิธีใช้   | สาธิต ROI, แอปง่าย, เจ้าหน้าที่/ที่ปรึกษา             |
| การตอบสนอง            | เตือนแล้วแต่ไม่พ่น/พ่นช้า             | การผูกกับคำแนะนำ+โดรนพ่น (05-005), แจ้งเตือนอัตโนมัติ |
| การจำแนกชนิดใกล้เคียง | แมลงคล้ายกันแยกยาก (ต้องผู้เชี่ยวชาญ) | การตรวจยืนยันภาพ (human-in-loop), หลายกล้อง           |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ความแม่นยำจำแนก 80–95% (CNN)** — ตรวจงาน (ระบุชนิด/ชุดข้อมูล)
- [ ] **ราคากับดัก 10,000–50,000 บาท/จุด** — ตรวจราคาตลาด (Trapview/Semios-class + ไทย)
- [ ] **ครอบคลุม 10–50 ไร่/จุด** — ตรวจแนวทาง/งาน (เป็นช่วง)
- [ ] **ลดการพ่น 20–40% (พ่นตาม EIL)** — ตรวจงานต่างประเทศ (ระบุพื้นที่/ชนิด)
- [ ] **ลดแรงงานสำรวจ 60–90%** — ตรวจงาน/บริการ
- [ ] **สถานะงานวิจัยไทย (มก./มข./จุฬา/วว. — เพลี้ย/แมลงวันผลไม้)** — ตรวจ TCI/ThaiJo อัปเดต
- [ ] **ระบบเตือนโรคแมลงของกรมวิชาการเกษตร (รายจังหวัด)** — ตรวจเว็บ/ข่าวอัปเดต
- [ ] **ตลาดกับดักอัจฉริยะ 0.2–0.8 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
