## 1. บทสรุปผู้บริหาร

- **ใจความ**: น้ำท่วมขัง (inundation) ในพื้นที่นา — ทั้งภัยต่อข้าว (จมน้ำ ต้นเน่า ผลผลิตเสียหาย) และ "ทรัพยากร" ถ้าจัดการเป็นทุ่งรับน้ำ/กักเก็บไว้ใช้หน้าแล้ง [1] การจัดการมี 3 ด้าน: ระบายน้ำเร็วเมื่อเกินพิกัด (drainage), กัก-ชะลอในทุ่งรับน้ำ (retention), และใช้ข้าวทนน้ำท่วม/การจัดการระดับน้ำ (เชื่อม 01-001) [2]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์/ปฏิบัติจริง — ระบบประตูน้ำ-คันกั้น-ทุ่งรับน้ำมีมานาน (ไทย: โครงการแก้มลิง/ทุ่งรับน้ำเจ้าพระยา) แต่การตัดสินใจ "กัก-ระบาย" แบบเรียลไทม์ยังเป็นงานวิจัย [3]
- **ตัวเลขสำคัญที่สุด**: น้ำท่วมใหญ่ปี 2554 สร้างความเสียหาย ~1.44 ล้านล้านบาท (ประมาณการ — ยังต้องยืนยัน) [3]; ข้าวแช่น้ำท่วมเกิน 7–10 วัน มักเสียหาย/ผลผลิตลดรุนแรง (ช่วงอ้างอิง — ยังไม่ยืนยัน) [2]
- **นัยต่อไทย**: อีสาน/เจ้าพระยาโดนน้ำท่วมซ้ำ — การออกแบบ "นาเป็นทั้งแปลงผลิตและอ่างเก็บน้ำ" (ทุ่งรับน้ำ-แก้มลิง) + ระบบระบายน้ำแปลง + การชดเชยที่ยุติธรรม เป็นโจทย์หลัก
- **สถานะโดยรวม**: 🏭 ปฏิบัติจริง (โครงสร้าง) / 🔬–🧪 งานวิจัย (การจัดการอัจฉริยะ/เรียลไทม์)

## 2. หลักการและขอบเขต

- **หลักการ**: นาข้าวมีคันนา (bund) กักน้ำรอบแปลง — "ระบายออกยากแต่กักได้ดี" การจัดการจึงแบ่งเป็น: (1) การระบายน้ำแปลง (ทางระบาย/ท่อ/ประตูน้ำ) ให้ระดับน้ำลดเร็วเมื่อฝนหนัก (2) ทุ่งรับน้ำ/แก้มลิง — พื้นที่ตอนล่าง/พื้นที่ต่ำ รับน้ำส่วนเกิน ลดยอดน้ำท่วมเมือง/พื้นที่เศรษฐกิจ (3) การจัดการระดับน้ำตามช่วงการเจริญของข้าว (น้ำลึก-ตื้นตามอายุ) (4) การพยากรณ์/แจ้งเตือน (เชื่อม 11) ตัดสินใจก่อนน้ำมา
- **ผลต่อข้าว**: ข้าวทนน้ำท่วมได้จำกัดตามอายุ/พันธุ์ (ข้าวลอยน้ำ FL478/Sub1 — เชื่อม 01-001); น้ำท่วมช่วงกล้า/แตกกอ เสียหายมาก; การระบายเร็วช่วยลดความเสียหาย
- **ขอบเขตที่ครอบคลุม**: ระบายน้ำแปลง, ทุ่งรับน้ำ/แก้มลิง, การจัดการระดับน้ำนา, การตัดสินใจอัจฉริยะ
- **นอกขอบเขต**: ระบบเตือนภัยลุ่มน้ำ (ดู 11), พันธุกรรมทนน้ำท่วม (ดู 01-001), ชลประทานปกติ (03-001), AWD (03-006)

## 3. สถานะงานวิจัย

| ช่วงเวลา       | ความก้าวหน้า                                                                                             | แหล่ง |
| -------------- | -------------------------------------------------------------------------------------------------------- | ----- |
| 2511/2538/2554 | น้ำท่วมใหญ่เป็นบทเรียน — ไทยสร้างโครงสร้างรับมือ (คันกั้น/ประตูน้ำ/แก้มลิง)                              | [3]   |
| 2000s–2010s    | แบบจำลองน้ำท่วม (MIKE/HEC-RAS) ใช้วางแผนทุ่งรับน้ำ/การระบาย                                              | [4]   |
| 2554           | น้ำท่วมครั้งใหญ่ที่สุด — ความเสียหาย ~1.44 ล้านล้านบาท; หลัง 2554 วางแผน "ทุ่งรับน้ำ 10+ ทุ่ง"           | [3]   |
| 2020s          | การตัดสินใจกัก-ระบายแบบเรียลไทม์ด้วย AI/เซนเซอร์ (ประตูน้ำอัตโนมัติ — เชื่อม 03-010); ระบบพยากรณ์รายแปลง | [5]   |
| 2025–2026      | "น้ำท่วมเป็นโอกาส": การกักน้ำทุ่งรับน้ำไว้ใช้แล้ง (บูรณาการกับ 03-007/03-008)                            | [6]   |

- **เส้นแบ่ง**: โครงสร้าง/แบบจำลองใช้งานจริงแล้ว — สิ่งที่ยังเป็นงานวิจัยคือ "การบริหารเรียลไทม์" (กักเท่าไร-ระบายเมื่อไร) และ "การยอมรับ/ชดเชยเกษตรกรทุ่งรับน้ำ"

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                     | ผลลัพธ์                                              | สถานที่/เงื่อนไข                    | แหล่ง  |
| ----------------------------- | ---------------------------------------------------- | ----------------------------------- | ------ |
| ความเสียหายน้ำท่วม 2554       | ~1.44 ล้านล้านบาท (ประมาณการหลายแหล่งต่างกัน)        | ไทย — ยังไม่ยืนยัน                  | [3]    |
| ข้าวทนน้ำท่วมได้กี่วัน        | แช่ 7–10 วันขึ้นไป มักเสียหายรุนแรง (ตามพันธุ์/อายุ) | งานวิชาการ — ยังไม่ยืนยัน           | [2]    |
| ประสิทธิภาพทุ่งรับน้ำ         | ลดยอดน้ำท้ายน้ำได้จริง (ตัวเลขต่อเหตุการณ์ต่างกัน)   | เจ้าพระยา — ยังไม่ยืนยัน            | [3][4] |
| ข้าวน้ำท่วม (พันธุ์ Sub1 ฯลฯ) | รอด/ฟื้นตัวได้ในน้ำลึกระยะสั้น (เชื่อม 01-001)       | งานวิจัย — ยังไม่ยืนยัน             | [2]    |
| ระบบระบายอัตโนมัติ            | ลดเวลาตัดสินใจ/ลดความเสียหาย (ตัวเลขต่อกรณี)         | นำร่องต่างประเทศ/ไทย — ยังไม่ยืนยัน | [5]    |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: ความเสียหายขึ้นกับ (1) ความลึก-ระยะเวลาน้ำท่วม (2) อายุข้าว (3) พันธุ์ (4) ความเร็วการระบาย — ไม่มีตัวเลขเดียว

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ไม่มีตลาดแยก — อยู่ในงบภาครัฐ (กรมชลประทาน/สทนช.: เขื่อน/ประตูน้ำ/ทุ่งรับน้ำ) + บริการวิศวกรรม/ที่ปรึกษา (แบบจำลองน้ำท่วม) + ผู้ผลิตประตูน้ำ/เซนเซอร์ [3][4]
- **ผู้เล่น**: กรมชลประทาน (โครงสร้าง/ประตูน้ำ), สทนช. (แผน/การจัดสรร), บริษัทวิศวกรรม/ที่ปรึกษา (TEAM/Modeling), มหาวิทยาลัย (แบบจำลอง), บริษัท IoT (เซนเซอร์ระดับน้ำ) [4][5]
- **การลงทุน**: งบป้องกันน้ำท่วม/ฟื้นฟูหลัง 2554 จำนวนมาก (ตัวเลขสะสมต้องยืนยัน); ประกันภัยน้ำท่วมพืชผล (ตลาดเล็ก — ยังไม่ยืนยัน)
- **ปัจจัยขับเคลื่อน**: น้ำท่วมซ้ำ/รุนแรงขึ้น (สภาพอากาศ), การขยายเมือง
- **ปัจจัยฉุดรั้ง**: งบ/ระยะเวลาโครงการ, การชดเชยทุ่งรับน้ำ (ยังเป็นประเด็น), ข้อมูลเรียลไทม์ไม่ครบ

## 6. สถานการณ์ประเทศไทย

- **โครงสร้าง**: ทุ่งรับน้ำ/แก้มลิงลุ่มน้ำเจ้าพระยา (หลายทุ่ง — จำนวน/พื้นที่ต้องยืนยัน), คันกั้นน้ำ/ประตูระบายน้ำทั่วประเทศ; อีสาน: น้ำท่วมฉับพลันจากลำน้ำ/น้ำป่า [3]
- **หน่วยงาน**: กรมชลประทาน (ปฏิบัติการประตูน้ำ), สทนช. (ศูนย์บัญชาการน้ำ), กรมอุตุนิยมวิทยา/ระบบพยากรณ์ (เชื่อม 11), กช./กษ. (การชดเชย)
- **งานวิจัยไทย**: แบบจำลองน้ำท่วมลุ่มน้ำเจ้าพระยา/ชี-มูล (มหาวิทยาลัย/ชลประทาน); งาน "นาแปลงใหญ่จัดการน้ำท่วม" เริ่มมี (ยังไม่ยืนยัน) [4][6]
- **นโยบาย**: แผนน้ำ 20 ปี/การป้องกันน้ำท่วม; การชดเชยเกษตรกรในทุ่งรับน้ำยังเป็นข้อถกเถียง (อัตรา/ความเป็นธรรม)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ระบบตัดสินใจ "กัก-ระบาย" แบบเรียลไทม์รายแปลง (เซนเซอร์+AI) ในบริบทไทย — ยังไม่มี
- **Q2**: การออกแบบทุ่งรับน้ำที่ "เกษตรกรได้ประโยชน์" (ข้าวทนน้ำท่วม/ปลา/การชดเชย) — ยังไม่มีโมเดลสมบูรณ์
- **Q3**: แบบจำลองความเสียหายข้าวต่อ "ความลึก×ระยะเวลาท่วม" เฉพาะพันธุ์/อายุไทย — ยังไม่มีตารางอ้างอิง
- **Q4**: การกักน้ำท่วมไว้ใช้หน้าแล้ง (ทุ่งรับน้ำ→สระ/MAR — เชื่อม 03-007/03-008) — ยังไม่มีการออกแบบร่วม
- **Q5**: การยอมรับ/ชดเชยของเกษตรกรทุ่งรับน้ำ (เชื่อม 14-001) — ยังไม่มีสำรวจล่าสุด
- **Q6**: ผลระยะยาวของน้ำท่วมขังซ้ำต่อดิน (ธาตุ/โรค/เมล็ดวัชพืช) — งานไทยน้อย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                           | ระดับนโยบาย                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 1 (1–2 ปี) | เซนเซอร์ระดับน้ำ + แอปเตือน "น้ำกำลังมา/ระบายได้" ในแปลงนา 5 ลุ่มน้ำเสี่ยง (เชื่อม 05/11); แปลงสาธิตการจัดการระดับน้ำตามอายุข้าว               | ฐานข้อมูลน้ำท่วมรายแปลงเปิด + แผนผังการระบายน้ำแปลง (ชลประทาน-ท้องถิ่น)       |
| 2 (2–4 ปี) | บริการ "บริหารน้ำท่วมแปลงอัจฉริยะ" (เซนเซอร์+แบบจำลอง+ประตูอัตโนมัติ — เชื่อม 03-010) ผ่านสหกรณ์; ข้าวทนน้ำท่วมในพื้นที่เสี่ยง (เชื่อม 01-001) | การชดเชยทุ่งรับน้ำแบบใหม่ (สิทธิ์+ประกันภัย); การออกแบบทุ่งรับน้ำหลายประโยชน์ |
| 3 (4+ ปี)  | "นาข้าว-อ่างเก็บน้ำ" เป็นระบบ: กักหน้าแล้ง ระบายหน้าน้ำหลาก ใช้ข้อมูลกลางทั้งลุ่มน้ำ                                                           | นโยบายจัดการน้ำท่วมระดับลุ่มน้ำที่รวมการกักใช้ประโยชน์ + การประเมินผล 10 ปี   |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย         | รายละเอียด                             | โอกาสแก้                                       |
| ------------------ | -------------------------------------- | ---------------------------------------------- |
| การชดเชยทุ่งรับน้ำ | เกษตรกรรับภาระไม่พอใจ                  | กลไกชดเชย/ประกันภัยที่ยุติธรรม (เชื่อม 12)     |
