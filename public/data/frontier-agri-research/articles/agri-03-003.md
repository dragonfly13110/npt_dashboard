## 1. บทสรุปผู้บริหาร

- **ใจความ**: VRI คือการปรับ "อัตราน้ำชลประทาน" ให้ต่างกันตามตำแหน่งในแปลง ตามความต้องการจริงของแต่ละโซน (ชนิดดิน/ความชื้น/พืช) — แทนการรดทั้งแปลงเท่ากันหมด — ใช้กับระบบน้ำหมุน (pivot) เป็นหลัก และต่อยอดสู่ระบบน้ำหยด/สปริงเกลอร์ [1][2]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้วในสหรัฐฯ/ออสเตรเลีย (pivot ยี่ห้อใหญ่มีตัวเลือก VRI) — ไทยยังเป็น 🔬–🧪 นำร่อง
- **ตัวเลขสำคัญที่สุด**: งานทดลองหลายแห่งรายงานการประหยัดน้ำ ~10–30% โดยผลผลิตไม่ลด (ช่วงอ้างอิง — ยังต้องยืนยัน) [3]; VRI ทำงานจากแผนที่กำหนดอัตรา (prescription map) เช่นเดียวกับ VRT ปุ๋ย [2]
- **นัยต่อไทย**: โครงสร้างแปลงไทยเล็ก/ระบบคลองเปิด ทำให้ VRI แบบ pivot ไม่ตรงตัว — โอกาสอยู่ที่น้ำหยดอัตราแปรผันในสวนผลไม้/อ้อยแปลงใหญ่ และการวางรากฐานข้อมูล (แผนที่ดิน/ความชื้น) ไว้ก่อน
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ต่างประเทศ) / 🔬 นำร่อง (ไทย)

## 2. หลักการและขอบเขต

- **หลักการทำงาน**: 1) แบ่งแปลงเป็นโซนตามคุณสมบัติ (ดิน/ความชื้น/พืช) 2) สร้างแผนที่กำหนดอัตรา (prescription map) — ตั้งเป้าน้ำต่อโซนจากสมการชลประทาน (ET + ความชื้นดิน) 3) ตัวควบคุม (controller) ปรับอัตราการจ่ายน้ำตามตำแหน่ง (GPS) — ระบบ pivot มีวาล์ว/โซนเรียงตามแขนหมุน; ระบบ drip มีวาล์วต่อท่อหลัก/ตัวปล่อยน้ำ
- **สิ่งที่ VRI แก้**: น้ำมากเกินในโซนดินเหนียว/น้ำขัง, น้ำน้อยเกินในโซนทราย, แปลงมีหลายชนิดดิน/หลายพืชในแขนเดียว
- **ขอบเขตที่ครอบคลุม**: เทคนิค VRI ทั้ง pivot และ drip, ตัวเลขผลลัพธ์, ตลาด, สถานการณ์ไทย
- **นอกขอบเขต**: การตั้งเวลารดอัตโนมัติด้วย AI/พยากรณ์ (ดู 03-001), เซนเซอร์ความชื้นดินเชิงเทคนิค (ดู 05 — ยังว่าง), การให้ปุ๋ยอัตราแปรผัน (ดู 02-012), CWSI กล้องเทอร์มอล (ดู 03-002)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                       | แหล่ง |
| --------- | -------------------------------------------------------------------------------------------------- | ----- |
| 1990s     | ผู้ผลิต pivot (Valmont/Lindsay) เริ่มนำเสนอการแบ่งโซนควบคุมบนแขนหมุน                               | [1]   |
| 2000s     | VRI เชิงพาณิชย์ครบวงจรในสหรัฐฯ (GPS + แผนที่ + วาล์ว); งานวิจัยเริ่มเปรียบเทียบผล                  | [2]   |
| 2010s     | งานทดลอง VRI ในข้าวโพด/ฝ้าย/มันฝรั่ง (เนแบรสกา/จอร์เจีย) — ประหยัดน้ำ/ผลผลิต                       | [3]   |
| 2020s     | VRI + remote sensing (NDVI/ET) + AI สร้าง prescription map อัตโนมัติ; ขยายสู่ drip (วาล์วอัจฉริยะ) | [4]   |
| 2025–2026 | ผูกกับ "ชลประทานตามความต้องการจริง" (variable rate + variable timing) ระดับฟาร์ม/ลุ่มน้ำ           | [5]   |

- **เส้นแบ่ง**: พาณิชย์ครบวงจรแล้วในประเทศที่มี pivot (สหรัฐฯ/ออสเตรเลีย) — ส่วนที่ยังเป็นงานวิจัยคือ "การสร้างแผนที่อัตโนมัติจากข้อมูลดาวเทียม" และการขยายสู่ระบบน้ำหยด/แปลงเล็ก

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                  | ผลลัพธ์                                                   | สถานที่/เงื่อนไข                             | แหล่ง  |
| -------------------------- | --------------------------------------------------------- | -------------------------------------------- | ------ |
| การประหยัดน้ำ (VRI pivot)  | ~10–30% เทียบรดทั้งแปลงเท่ากัน โดยผลผลิตไม่ลด             | งานทดลองสหรัฐฯ (ข้าวโพด/ฝ้าย) — ยังไม่ยืนยัน | [3]    |
| ผลผลิต                     | เท่าเดิมหรือ +เล็กน้อย (หลายงาน); บางงาน +5–10% ในโซนทราย | ขึ้นกับความต่างของดินในแปลง — ยังไม่ยืนยัน   | [3]    |
| ประสิทธิภาพการใช้น้ำ (WUE) | เพิ่มตามสัดส่วนน้ำที่ประหยัด                              | ทั่วไป — ยังไม่ยืนยัน                        | [4]    |
| ROI                        | คุ้มเมื่อแปลงมีโซนดินต่างกันชัดเจน/น้ำมีราคาหรือจำกัด     | สหรัฐฯ — กรณีศึกษา — ยังไม่ยืนยัน            | [2][5] |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: VRI ให้ผลดีเมื่อ (1) แปลงมีโซนต่างกันจริง (2) มีข้อมูลทำแผนที่ (3) ระบบชลประทานปรับอัตราได้ — ถ้าแปลงสม่ำเสมอ ผลต่างน้อย

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด precision irrigation ~1–2 พันล้านดอลลาร์สหรัฐ (analyst estimate — ยังไม่ยืนยัน) [6]; VRI เป็นฟีเจอร์เสริมของระบบ pivot ใหญ่ (Valley/Lindsay) และ drip (Netafim/Rivulis)
- **ผู้เล่นหลัก**: Valmont (Valley pivot — มี VRI commercial), Lindsay (Zimmatic/FieldNET), Netafim/Rivulis (drip + วาล์วอัจฉริยะ), Precision Planting/SmartIrrigation (ซอฟต์แวร์แผนที่), สตาร์ทอัพ AgSense/CropX (เซนเซอร์ + การควบคุม) [2][6]
- **การลงทุน**: กลุ่ม "irrigation intelligence" ได้เงินทุนในรอบ AgTech (ตัวเลขต้องยืนยัน — เชื่อม 14-002)
- **ปัจจัยขับเคลื่อน**: น้ำมีราคา/จำกัด (ออสเตรเลีย/สหรัฐตะวันตก), นโยบายน้ำ, ภัยแล้ง, แรงงาน
- **ปัจจัยฉุดรั้ง**: ต้นทุนฮาร์ดแวร์/การติดตั้ง, ความซับซ้อน, แปลงเล็ก/คลองเปิด (ไทย)

## 6. สถานการณ์ประเทศไทย

- **โครงสร้างปัจจุบัน**: ชลประทานไทยเป็นระบบคลองเปิด/ส่งน้ำเป็นรอบ (ดู 03-001) — การปรับ "อัตรารายตำแหน่ง" ยังไม่ใช่แนวคิดหลัก; ระบบน้ำหมุน (pivot) มีจำกัด (ไร่ใหญ่บางพื้นที่ภาคกลาง/ตะวันออกเฉียงเหนือ — ยังไม่ยืนยันจำนวน) [7]
- **งานวิจัย/ภาครัฐ**: กรมชลประทาน/มหาวิทยาลัยมีงานน้ำหยด+เซนเซอร์ในสวนผลไม้/อ้อย; การจัดการน้ำรายโซนเริ่มถูกพูดถึงในแปลงอ้อย/มัน (เชื่อม 02-012 แนวทางคล้ายกัน) [7]
- **เอกชน**: ผู้จำหน่ายระบบน้ำหยด/หัวฉีด (Netafim ตัวแทนไทย, Jain, ไทยราย) + บริการติดตั้งสวนไม้ผล/อ้อย; บริการโดรนตรวจความเครียดพืชเริ่มมี
- **นโยบาย**: แผนน้ำ 20 ปี/การบริหารน้ำรายลุ่มน้ำ — การชลประทานแม่นยำยังไม่เป็นนโยบายหลัก (ยังไม่ยืนยัน)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลขประหยัดน้ำ/ผลตอบแทนของ VRI ในเงื่อนไขไทย (อ้อย/สวนผลไม้) — ยังไม่มีงาน
- **Q2**: ROI ของการติดตั้งวาล์วอัจฉริยะบนระบบน้ำหยดเดิม (retrofit) — ยังไม่มีตัวเลขไทย
- **Q3**: โมเดลแผนที่ prescription จากข้อมูลดาวเทียม/เซนเซอร์ราคาถูกที่เหมาะกับไทย — ยังไม่มีบริการ
- **Q4**: การผูก VRI กับการจัดรอบน้ำของคลองชลประทานไทย (น้ำมาเป็นรอบ) — ยังไม่ได้คิดร่วมกัน
- **Q5**: ผลระยะยาวของ VRI ต่อความเค็ม/น้ำใต้ดิน (โซนรดน้อย-มาก) — งานน้อย
- **Q6**: การยอมรับของเกษตรกรไทย (เชื่อม 14-001) — ยังไม่มีการสำรวจ

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                 | ระดับนโยบาย                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงสาธิต "น้ำหยดอัตราแปรผัน" ในสวนผลไม้/อ้อยแปลงใหญ่ 3 ภูมิภาค วัดน้ำ-ผลผลิตเทียบ baseline          | ฐานข้อมูลแผนที่ดิน/ความชื้นเปิด (เชื่อม 02-003); สนับสนุนอุปกรณ์ผ่านสินเชื่อ ธ.ก.ส. |
| 2 (2–4 ปี) | บริการ "VRI-as-a-service" (เซนเซอร์+วาล์ว+แอป) จ่ายต่อไร่/ต่อฤดู; เชื่อมกับการตั้งเวลารด AI (03-001) | มาตรฐานการวัด/การรับรองระบบชลประทานแม่นยำ; บูรณาการกับการจัดรอบน้ำคลอง              |
| 3 (4+ ปี)  | การประหยัดน้ำจาก VRI นับเป็น "น้ำที่ปล่อยคืนระบบ" แลกสิทธิ์/ค่าธรรมเนียม (เชื่อม 12)                 | นโยบาย "1 แปลงใหญ่ 1 ระบบแม่นยำ" + การวางแผนน้ำลุ่มน้ำที่ใช้ข้อมูลจริง              |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย             | รายละเอียด                               | โอกาสแก้                                                     |
| ---------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| แปลงเล็ก/หลายเจ้าของ   | ไม่คุ้มลงทุนต่อแปลงเดียว                 | บริการรับจ้าง/สหกรณ์ใช้ร่วม (เชื่อม 14-004)                  |
| ระบบคลองเปิด           | ปรับอัตรารายตำแหน่งทำไม่ได้กับคลองส่งน้ำ | เริ่มที่แปลงที่มีบ่อ/ระบบท่อของตัวเอง                        |
| ต้นทุนฮาร์ดแวร์        | วาล์ว/คอนโทรลเลอร์/GPS แพง               | นำเข้าถูกลง + ผู้ผลิตในประเทศ                                |
| ข้อมูลพื้นฐานขาด       | ไม่มีแผนที่ดิน/ความชื้นรายตำแหน่ง        | ลงทุนข้อมูลก่อน (02-003/05) — VRI ไม่มีแผนที่ก็ไม่มีประโยชน์ |
| การสอบเทียบ/บำรุงรักษา | อุปกรณ์ล้มเหลวถ้าไม่ดูแล                 | บริการหลังการขาย/สัญญา                                       |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ประหยัดน้ำ 10–30% / ผลผลิต +0–10%** — ค้นงาน primary (Transactions of ASABE / Precision Agriculture / Agricultural Water Management) ระบุพืช/ปี
- [ ] **ตลาด precision irrigation 1–2 พันล้านดอลลาร์** — ตรวจข้ามสำนัก (MarketsandMarkets/Grand View) + ปีอ้างอิง
- [ ] **Valmont/Lindsay มี VRI commercial ตั้งแต่ 2000s** — เปิดเว็บผู้ผลิต/ข่าวยืนยัน
- [ ] **จำนวน pivot ในไทย** — ค้นข้อมูล (กรมชลประทาน/สมาคมผู้ประกอบการ) หรือเปลี่ยนเป็น "ไม่ระบุ"
- [ ] **งาน VRI/น้ำหยดอัจฉริยะไทย** — ค้น TCI/ThaiJo เพื่ออ้างรายชิ้น + DOI
