## 1. บทสรุปผู้บริหาร

- **ใจความ**: RAS = ระบบเลี้ยงสัตว์น้ำความหนาแน่นสูงในถัง/บ่อปิด ที่กรองน้ำกลับมาใช้ใหม่ได้ 90–99% ควบคุมโรค/อุณหภูมิ/คุณภาพน้ำได้ตลอดปี — สัญญาแก้ปัญหาใหญ่ของกุ้งไทยคือโรคระบาด (EMS/AHPND) ที่กดผลผลิตจาก 6 แสนกว่าตันเหลือ ~2.7 แสนตัน/ปี และข้อจำกัดด้านน้ำ/พื้นที่/แรงงาน [18][19][11] — แต่จุดอ่อนคือ "ทุนสูง + ค่าไฟสูง + ผลตอบแทนยังแพ้บ่อดิน/ระบบแลกน้ำในหลายงานวิจัย" [1][4]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น — ปลาแซลมอน RAS บนบก (Salmon Evolution/Atlantic Sapphire) ผลิตเชิงพาณิชย์แล้วแต่ยังขาดทุน; กุ้ง RAS ยังเป็น 🧪 นำร่อง/เชิงพาณิชย์เฉพาะกลุ่ม (ไทยมีฟาร์มโรงเรือนปิดของซีพีเอฟ) [6][7][15][16]
- **ตัวเลขสำคัญที่สุด**: ต้นทุนผลิตกุ้ง RAS (บราซิล 2568) US$4.46–6.24/กก. เทียบราคาขาย $7–8/กก. — IRR 19–68% คืนทุน 1.8–4.6 ปี (งานวิจัยขนาดเล็ก-กลาง) [3]; แต่การวิเคราะห์เชิงพาณิชย์ (จีน 2022) พบกำไร RAS เพียง US$124/เฮกตาร์ เทียบระบบแลกน้ำ $471 และค่าไฟคิด 43% ของต้นทุน RAS [1]; งบลงทุนฟาร์มแซลมอน RAS จริงสูงเกินคาด >US$30,000/ตันกำลังผลิต (คาดเดิม $15,000) [8]; ฟาร์มปิด CPF ลงทุน ~5 ล้านบาท/ไร่ ผลผลิต 8 ตัน/ไร่/รุ่น × 3 รุ่น/ปี [15][16]
- **นัยต่อไทย**: RAS ไม่ใช่คำตอบแทนบ่อดินสำหรับกุ้งราคาตลาดปกติ — เหมาะกับ (1) ปลอดโรค/เลี้ยงได้ทุกฤดู (2) พื้นที่น้ำจืด/ใกล้เมือง (3) สินค้าพรีเมียมปลอดสาร-ตรวจสอบย้อนกลับ — ไทยควรเริ่มจาก "ระบบน้ำหมุนเวียน+เซนเซอร์อัจฉริยะ" ต้นทุนต่ำ (ต่อยอด RASCAL-สวทช./งาน IoT) แล้วเลื่อนขั้นเป็น RAS เต็มรูปแบบเฉพาะสินค้ามูลค่าสูง [14][17][23]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (แซลมอนโลก/ฟาร์มปิดรายใหญ่ไทย) — กุ้ง RAS ไทยยัง 🧪

## 2. หลักการและขอบเขต

- **หลักการทำงาน**: RAS วนน้ำในระบบปิดผ่าน 4 หน่วยหลัก: (1) กรองเชิงกล/ดักของแข็ง (drum filter, protein skimmer) (2) กรองชีวภาพ (จุลินทรีย์เปลี่ยนแอมโมเนีย→ไนไตรต์→ไนเตรต) (3) ฆ่าเชื้อ (UV/โอโซน) (4) เติมออกซิเจน/ไล่ CO2 — เหลือน้ำใหม่แค่ 5–10% ต่อวัน ใช้น้ำน้อยกว่าบ่อดิน 90–99% [11][16] — ข้อดีเชิงชีวภาพ: อัตรารอดสูง (ระบบควบคุม), เลี้ยงได้ 3 รุ่น/ปีในไทย (ปลานิล/กุ้ง), ลดความเสี่ยงโรคนำเข้าน้ำ/พาหะ [15][22]
- **ตัวแปรตัดสินใจด้านเศรษฐศาสตร์**: CAPEX (ถัง/โรงเรือน/อุปกรณ์กรอง — แพงสุด), OPEX (ค่าไฟคิด 30–43% ของต้นทุน — สำคัญที่สุด), ผลผลิตต่อ ลบ.ม. (kg/m³), FCR, อัตรารอด และ "ราคาที่ขายได้" — งานวิจัยอเมริกันสรุปว่า RAS ทำกำไรได้ต่อเมื่อผลผลิตต่อ ลบ.ม. สูงกว่าระดับเฉลี่ยในงานวิจัยมาก และขายได้ราคาพรีเมียมจริง [4][26]
- **ขอบเขตที่ครอบคลุม**: เศรษฐศาสตร์/จุดคุ้มทุน RAS กุ้งและปลา (แซลมอน/ปลานิล/ปลากะพง), เทียบกับบ่อดิน/BFT/ระบบแลกน้ำ, งานไทย, แนวทางใช้
- **นอกขอบเขต**: ระบบอัตโนมัติ/หุ่นยนต์ในบ่อ (07-004), เซนเซอร์/เครือข่าย (05), ชีววิทยาโรคกุ้งโดยละเอียด (ไฟล์ AI กล้องใต้น้ำ), เทคโนโลยี BFT/ไบโอฟลอคเป็นหลัก (ดูไฟล์ IMTA/อาหารสัตว์น้ำ)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                                                                                                                                                          | แหล่ง             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| 1980s–2010s | RAS ปลาเทร้าท์/แซลมอนสโมลท์เชิงพาณิชย์ในยุโรป-สหรัฐฯ (Blue Ridge Aquaculture ดำเนินการต่อเนื่อง 30+ ปี); ทดลองกุ้ง super-intensive RAS เริ่ม (Ray & Lotz 2017; อินโดนีเซีย Gresik 2018 ระบบ zero-water-discharge)                                                     | [26][2]           |
| 2014–2019   | CPF เปิดฟาร์มโรงเรือนปิดร้อยเพชร (ตราด)/บางสระเก้า (จันทบุรี) — น้ำหมุนเวียน+ไบโอฟลอค ต้นแบบไทย; งาน RAS-ปลานิล/ปลากะพงในมหาวิทยาลัยไทย                                                                                                                               | [15][16][24]      |
| 2019–2021   | เปิดฟาร์มแซลมอน RAS ใหญ่ที่สุดของโลก: Atlantic Sapphire (ฟลอริดา เก็บเกี่ยวเชิงพาณิชย์ครั้งแรก 2020), Salmon Evolution (นอร์เวย์) — เจอปัญหาประสิทธิภาพ/การเงิน                                                                                                       | [6][7]            |
| 2022–2024   | งานเศรษฐศาสตร์เปรียบเทียบ RAS vs ระบบอื่นหนาแน่นขึ้น (Engle 2020/2024; จีนชิงเต่า 2022; บราซิล 2025); EU ลงทุนวิจัย BIORAS_SHRIMP (ฟาร์มกุ้ง RAS เต็มรูปแบบที่ Gela อิตาลี — แห่งแรกในยุโรป); NaturalShrimp (สหรัฐฯ) เข้าสู่ receivership 9/2024 — บทเรียนความล้มเหลว | [1][3][5][20][25] |
| 2025–2026   | Salmon Evolution ขยายเฟส 2 (กำลังรวม 18,000 ตัน/ปี); Atlantic Sapphire ตั้งเป้า EBITDA คุ้มทุนปลาย 2026 แต่ยังเผชิญปัญหา going concern; ไทย: MTEC-สวทช. เปิด RASCAL, งาน IoT+AI มก. 50 บ่อ                                                                            | [6][7][8][17][23] |

- **เส้นแบ่ง**: ปลาแซลมอน RAS = เชิงพาณิชย์แล้วแต่ยังพิสูจน์กำไร (ขาดทุน 2–4 ปีแรก) [6][7]; กุ้ง RAS = นำร่อง/เชิงพาณิชย์เฉพาะกลุ่ม (ยุโรป/สหรัฐฯ ยังไม่มีฟาร์มขนาดใหญ่ทำกำไรยั่งยืน — NaturalShrimp ล้มละลาย) [20]; ไทย = งานวิจัย + ฟาร์มปิดของบริษัทใหญ่เป็นหลัก [15][17]

- **กฎ**: ตัวเลข "งานทดลอง" (ถังเล็ก/รอบสั้น) ไม่ควรคาดเดาเป็นฟาร์มเชิงพาณิชย์ตรงๆ — งานที่ให้ IRR สูง (19–68%) เป็นการจำลองต่อยอดจากสเกลเล็ก [3]; ส่วนงานเชิงพาณิชย์จริง (แซลมอน) ยังขาดทุน [6][7] — ใช้เทียบเคียงทิศทาง
- **เงื่อนไขสำคัญ**: ราคาค่าไฟ (43% ของต้นทุน), อัตราหมุนเวียนน้ำที่พอดี (ระดับกลาง 1.0 ลบ.ม./ชม. ดีที่สุดในงานจีน) [1], ผลผลิต/ลบ.ม. ที่ทำได้จริง [4], ราคาขายพรีเมียม

## 5. ตลาดและการลงทุน

- **ตลาดกุ้งโลก**: ~5.22 ล้านตัน (2568, +4%) — เอกวาดอร์ 1.4 ล้านตัน, จีน 1.34 ล้านตัน; กุ้งขาวเป็นกุ้งที่เลี้ยงมากสุดในโลก (~5 ล้านตัน จาก 0.15 ล้านตันในปี 2000) [18][2]; RAS กุ้งยังเป็นส่วนน้อยมาก (<1%) ของการผลิตโลก
- **กุ้งไทย**: ผลผลิต 270,000 ตัน (2568, ทรงตัว); ผู้ส่งออกอันดับ 6 ของโลก ส่วนแบ่ง 4–5% (จากอันดับ 1 และ ~70% ของตลาดสหรัฐฯ เดิม); ส่งออก 2568 คาด ~1,116 ล้านดอลลาร์ (-9.4%), 2569 คาด ~1,073–1,075 ล้านดอลลาร์ (-3.6%) — ต้นทุนผลิตไทยสูงกว่าคู่แข่ง (ค่าแรง/ค่าไฟ/อาหารนำเข้า) [18][19]
- **การลงทุน RAS แซลมอนโลก**: งบจริง >$30,000/ตันกำลังผลิต — ฟาร์ม 10,000 ตัน/ปี ต้องลงทุน ~$300 ล้าน+; ยังไม่มีรายใหญ่ทำกำไรสะสม; NaturalShrimp (กุ้ง RAS สหรัฐฯ) ล้มละลาย — ขายทรัพย์สิน $35.7 ล้าน (credit bid) รายได้ปี 2025 เพียง $202,817 [8][20][21]
- **ผู้เล่นหลัก**: Salmon Evolution, Atlantic Sapphire, Nordic Aqua Partners, Proximar (แซลมอน); RDM Aquaculture (กุ้ง RAS ครอบครัว อินดีแอนา ดำเนินการตั้งแต่ 2010, อัตรารอด ~90%, ระบบ zero-exchange) [22]; โครงการ EU (BIORAS_SHRIMP, Bornholm เดนมาร์ก DKK 5.4 ล้าน) [25][27]; ไทย: CPF [15][16]
- **ปัจจัยขับเคลื่อน**: ความต้องการกุ้งสดปลอดภัยใกล้ตลาด/ยุโรป, การควบคุมโรค (AHPND/EMS), ข้อจำกัดพื้นที่-น้ำ-ใบอนุญาต (ยุโรป), ภาษี/โลจิสติกส์ (ผลิตใกล้ผู้บริโภค)
- **ปัจจัยฉุดรั้ง**: CAPEX+OPEX สูง, ค่าไฟ, ราคากุ้งโลกตกต่ำ (perfect storm 2566 ราคาลด 20–30%), การตลาดพรีเมียมไม่ยั่งยืนเมื่อมีผู้เล่นเพิ่ม [26][25]

## 6. สถานการณ์ประเทศไทย

- **งานวิจัย/หน่วยงาน**: กรมประมง (ระบบบำบัดชีวภาพใน RAS อนุบาลลูกกุ้ง PL20 312 ตัว/ตร.ม. 30 วัน — ลดแอมโมเนีย [28]); มรภ.มหาสารคาม (ปลานิลแดง RAS [12]); ม.แม่โจ้ (ปลากะพงขาว RAS น้ำจืด งบ 6 แสนบาท 2563, นวัตกรรม 2566 [24]); มจธ. (นำน้ำเสีย RAS เลี้ยงสาหร่าย); MTEC-สวทช. เปิดซอฟต์แวร์ RASCAL คำนวณอุปกรณ์/คืนทุน ประเมินได้ตั้งแต่ก่อนลงทุน [17]; มก. งาน IoT+AI 50 บ่อ: อาหาร -18%, อัตรารอด +22%, รายได้ +15% [23]; สกสว.+มก.+มานิตย์ฟาร์ม: ระบบ IPRS ปลานิล (ระบบปิดในบ่อ) [24]
- **ภาคเอกชน**: CPF — ฟาร์มร้อยเพชร (ตราด, โรงเรือนปิด+น้ำหมุนเวียนแห่งแรกของไทย, เฟส 1 ผลผลิต 3,000 ตัน/ปี) และบางสระเก้า (จันทบุรี 600 ไร่ 8 ตัน/ไร่/รุ่น, ลงทุน 5 ล้านบาท/ไร่); CPF ใช้ RAS ในฟาร์มสหรัฐฯ (พื้นที่ไกลทะเล) — ตัวเลขต้นทุน/กำไรจริงไม่เปิดเผย [15][16]
- **โครงสร้าง/นโยบาย**: "กุ้งทะเลเป็นวาระแห่งชาติ" มาตรการ 11 ประการ (สิ้นสุด 31 ต.ค. 2568); สมาคมกุ้งไทยเสนองบ 5,400 ล้านบาท ฟื้นผลผลิตสู่ 400,000 ตัน (EMS คร่าความเสียหายเฉลี่ย 5 หมื่นล้านบาท/ปี รวม 6.5 แสนล้านบาทใน 13 ปี); ไทยเสียภาษีสหรัฐฯ 19% vs อินเดีย ~58–61% (2569) → โอกาสชิงตลาด; FTA ไทย–EU เป็นโอกาสตลาดพรีเมียม [18]
- **จุดแข็ง/จุดอ่อน**: จุดแข็ง = ความร้อนเขตร้อนเหมาะปลา/กุ้ง RAS (ลดค่าให้ความร้อน), ฟาร์มปิด CPF เป็นต้นแบบ, ซัพพลายเชนกุ้งครบวงจร; จุดอ่อน = ค่าไฟไทยแพง (จุดตายของ RAS), อาหารกุ้งพึ่งถั่วเหลืองนำเข้า, แรงงาน/ผู้เชี่ยวชาญระบบกรองชีวภาพจำกัด, ข้อมูลต้นทุน RAS ไทยเปิดเผยน้อยมาก

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ต้นทุนผลิต/จุดคุ้มทุน RAS กุ้งเชิงพาณิชย์จริงในไทย (บาท/กก. ทั้ง CAPEX+OPEX) — ยังไม่มีข้อมูลเปิด (ฟาร์ม CPF เป็นข้อมูลภายใน) [15]
- **Q2**: RAS อุณหภูมิเขตร้อน (28–30°C) ปรับจากงานแซลมอนเขตอบอุ่นได้อย่างไร และค่าไฟไทย (บาท/กก. ผลผลิต) จริงเท่าไร — ยังไม่มีงานไทยตีพิมพ์ตัวเลขครบ
- **Q3**: เปรียบเทียบ RAS vs บ่อดิน/ไบโอฟลอคไทย ระยะ 3–5 ปี รวมค่าใช้จ่ายโรค (EMS/EHP/ขี้ขาว) และความเสี่ยงราคา — ยังไม่มีข้อมูล (งานจีน/บราซิลเป็นระบบแลกน้ำ/สเกลเล็ก) [1][2]
- **Q4**: การผูกเซนเซอร์+AI (เชื่อม 05/07-004) ช่วยลดพลังงาน/อาหารใน RAS ได้จริงเท่าไร — งานไทย (มก. 50 บ่อ) ยังเป็นระบบบ่อเปิดไม่ใช่ RAS เต็มรูปแบบ [23]
- **Q5**: ส่วนเพิ่มราคา (premium) ของกุ้ง/ปลา RAS ปลอดสาร-ตรวจสอบย้อนกลับในตลาดไทย/ญี่ปุ่น/ยุโรป เท่าไร และจ่ายได้ถึงเมื่อไร — ยังไม่มีข้อมูลตลาดไทย
- **Q6**: กรอบมาตรฐาน/การรับรองฟาร์ม RAS ไทย (สิ่งแวดล้อม น้ำทิ้ง ตรวจสอบย้อนกลับ) และสิทธิประโยชน์ลงทุน — ยังไม่มีข้อกำหนดเฉพาะ

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ต้นทุนกุ้ง RAS ไทย (บาท/กก.) และจุดคุ้มทุนต่อไร่/ต่อถัง** — ยังไม่มีข้อมูลเปิด; ตรวจงานใหม่ใน TCI/ThaiJo (มก./มจ./มรภ.มหาสารคาม) และข่าว CPF
- [ ] **CPF ร้อยเพชร/บางสระเก้า — ผลผลิต/กำไรจริง (8 ตัน/ไร่/รุ่น, ลงทุน 5 ล้านบาท/ไร่)** — เป็นตัวเลขปี 2561–2562 ต้องอัปเดต; ตรวจงบ CPF/ข่าวล่าสุด
- [ ] **Atlantic Sapphire ถึง EBITDA คุ้มทุนปลาย 2026 หรือไม่** — ตรวจรายงาน Q4 2026/Annual Report 2026
- [ ] **จุดคุ้มทุนแซลมอน RAS 3,000–5,000 ตัน/ปี (แคนาดา)** — เป็นแบบจำลองปีเก่า ตรวจงาน 2025–2026 (Spheric LBAR)
- [ ] **ภาษีสหรัฐฯ กุ้ง: ไทย 19% vs อินเดีย 58–61% → กุ้งไทย/พรีเมียม RAS ฟื้นตัวจริงหรือไม่** — ตรวจสถิติส่งออก 2569 (สมาคมกุ้งไทย/กสิกรไทย)
- [ ] **RAS ปลานิลไทยคุ้มค่าเมื่อเทียบบ่อดิน (FCR 1.56, รอด 97.5% — สเกลทดลอง)** — ตรวจงานขยายสเกล/เชิงพาณิชย์ไทย
- [ ] **ตลาดพรีเมียม RAS ไทย/ญี่ปุ่น (ส่วนเพิ่มราคา)** — ยังไม่มีข้อมูล ตรวจรายงานตลาด 2026

## 11. อภิธานศัพท์

| คำศัพท์                                | ความหมาย                                                            |
| -------------------------------------- | ------------------------------------------------------------------- |
| RAS (Recirculating Aquaculture System) | ระบบเพาะเลี้ยงน้ำหมุนเวียนปิด — กรองน้ำกลับใช้ใหม่ 90–99%           |
| BFT (Biofloc Technology)               | ระบบไบโอฟลอค — ใช้จุลินทรีย์บำบัดน้ำ/เป็นอาหารเสริม                 |
| AHPND/EMS (กุ้งตายด่วน)                | โรคตายด่วนจาก Vibrio parahaemolyticus — คร่าอุตสาหกรรมกุ้งไทย 13 ปี |
| EHP (Enterocytozoon hepatopenaei)      | ไมโครสปอริเดีย — โตช้าในกุ้ง                                        |
| FCR (Feed Conversion Ratio)            | อัตราแลกเนื้อ — อาหารที่ใช้ต่อน้ำหนักเพิ่ม 1 กก.                    |
| SR (Survival Rate)                     | อัตราการรอดตาย                                                      |
| CAPEX / OPEX                           | งบลงทุน / ค่าใช้จ่ายดำเนินการ                                       |
| IRR / NPV / BEP                        | อัตราผลตอบแทนภายใน / มูลค่าปัจจุบันสุทธิ / จุดคุ้มทุน               |
| HFS (Hybrid Flow-Through)              | ระบบไฮบริดไหลผ่าน (Salmon Evolution) — น้ำทะเลใหม่ผ่าน+กรองบางส่วน  |
| IPRS (In-Pond Raceway System)          | ระบบทางวิ่งในบ่อ — หมุนเวียนน้ำในบ่อดิน                             |
| TAN                                    | แอมโมเนียรวมในน้ำ (ต้องควบคุมใน RAS)                                |
| PL (Post-Larvae)                       | ลูกกุ้งระยะโพสต์ลาวา (เช่น PL12, PL20)                              |
| Bio-secure                             | ระบบปลอดภัยทางชีวภาพ — กั้นโรคจากภายนอก                             |
