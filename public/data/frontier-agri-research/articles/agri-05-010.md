## 1. บทสรุปผู้บริหาร

- **ใจความ**: เรดาร์ดาวเทียม (SAR — Sentinel-1, ALOS-2, PAZ) ส่องเห็นพื้นดินทะลุเมฆ/หมอก/กลางคืน — สำคัญที่สุดในเขตร้อนอย่างไทย (เมฆบังภาพออปติคอลหลายเดือน) — ใช้ติดตาม: นาข้าว (ขังน้ำ/ย้ายกล้า/การเจริญ — สัญญาณ VV/VH เปลี่ยนตามระยะ), น้ำท่วม (แผนที่ท่วมรายวัน — เชื่อม 03-009), ความชื้นผิวดิน (05-007 — ระดับแปลงใหญ่), การขยายตัวพื้นที่เพาะปลูก [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงปฏิบัติการแล้ว (การทำแผนที่นาข้าว/น้ำท่วมด้วย Sentinel-1 มีระบบปฏิบัติการจริงในอาเซียน/ไทย — GISTDA/หน่วยงาน; ความชื้นดินยังกึ่งวิจัย) [2][3][4]
- **ตัวเลขสำคัญที่สุด**: Sentinel-1: ฟรี, ความละเอียด 10 ม., กลับถี่ 6–12 วัน (2 ดวงสลับ); แผนที่ข้าว (พื้นที่/ระยะการเจริญ) ความแม่นยำ 85–95%; แผนที่น้ำท่วม: ผลิตได้ภายใน 1–3 วัน (เกือบเรียลไทม์); ความชื้นผิวดิน RMSE ~0.04–0.06 m³/m³ (กึ่งวิจัย) [1][2][3]
- **นัยต่อไทย**: ไทยมีระบบปฏิบัติการอยู่แล้ว (GISTDA — แผนที่น้ำท่วม/ข้าว; งานวิจัยความชื้นดินหลายกลุ่ม) — โอกาสคือการผูก "SAR กับออปติคอล (05-001) และ IoT (05-007)" ให้เป็นบริการต่อเนื่องรายสัปดาห์ [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงปฏิบัติการแล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: SAR ส่งคลื่นไมโครเวฟ (C-band ~5.4 GHz — Sentinel-1; L-band — ALOS-2; X-band — PAZ/TerraSAR) สะท้อนพื้น → ความเข้ม (backscatter) เปลี่ยนตาม (1) ความหยาบพื้นผิว/โครงสร้างทรงพุ่ม (2) ปริมาณน้ำในดิน/พืช (3) พื้นผิวเรียบ (น้ำ) → วิเคราะห์อนุกรมเวลา (multi-temporal) เพื่อแยก "ข้าวขังน้ำ vs พื้นแห้ง vs น้ำท่วม" และติดตามการเจริญ [1][3]
- **โพลาไรเซชัน**: VV/VH — VH (ข้ามโพลาไรซ์) ไวต่อโครงสร้างทรงพุ่มข้าว; อัตราส่วน VH/VV ใช้ติดตามระยะการเจริญ
- **ข้อจำกัดสำคัญ**: ความละเอียดหยาบกว่าออปติคอล (10 ม.)/มี speckle noise (ต้อง filter), อิทธิพลลม/การไถดิน (สัญญาณรบกวน), การตีความต้องผู้เชี่ยวชาญ/ML (ไม่ง่ายเหมือนภาพสี), ความชื้นได้เฉพาะ "ผิวดิน" (ไม่ลึก)
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/การใช้งาน, ไทย, แนวทางใช้
- **นอกขอบเขต**: ภาพออปติคอล/ไฮเปอร์สเปกตรัม (05-001), ET (03-011), การวัดความชื้นดินจุด (05-007)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                      | แหล่ง     |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------- | --------- |
| 1990s–2000s | งาน SAR นาข้าว (Rice mapping — ญี่ปุ่น/จีน/อาเซียน — ERS/Radarsat/JERS); การจำแนกระยะข้าว                                         | [1]       |
| 2014–2016   | Sentinel-1 (C-band, ฟรี) เปิดใช้ → งานข้าว/น้ำท่วมถล่มทลาย (ทั่วโลก) — การทำแผนที่รายสัปดาห์เป็นไปได้                             | [1][2]    |
| 2018–2023   | ALOS-2 (L-band) + Sentinel-1 งานความชื้นดิน; งาน AI (deep learning) จำแนกข้าว/ท่วม/ความชื้น; ระบบปฏิบัติการ (GISTDA flood/rice)   | [2][3][4] |
| 2024–2026   | การรวม SAR+optical (การผสานข้อมูล); การผูก SAR+IoT (05-007); กลุ่มดาวเทียม SAR เชิงพาณิชย์ (ความละเอียด 0.5–1 ม. — Capella/ICEYE) | [3][5]    |
| 2026–       | แนวโน้ม: SAR เชิงพาณิชย์รายวัน/ราคาลง, foundation models (SAR+optical — เชื่อม 06), การประเมินผลผลิต/คาร์บอนด้วย SAR              | [3]       |

- **เส้นแบ่ง**: การจำแนกข้าว/น้ำท่วม "ปฏิบัติการแล้ว" (อาเซียน/ไทย) — ความชื้นดิน/การประเมินผลผลิตยังกึ่งวิจัย; งานไทยส่วนใหญ่ยังเป็นงานวิจัย/โครงการเฉพาะ ยังไม่เป็นบริการต่อเนื่องรายแปลง

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                         | ผลลัพธ์                                 | เงื่อนไข           | แหล่ง  |
| ------------------------------------------------- | --------------------------------------- | ------------------ | ------ |
| ความละเอียด Sentinel-1 (IW)                       | 10 ม. (ฟรี)                             | เอกสาร ESA         | [1]    |
| รอบกลับ Sentinel-1                                | 6–12 วัน (1A+1B — ปัจจุบัน 1A/1C-class) | เอกสาร ESA         | [1][2] |
| ความแม่นยำแผนที่ข้าว (พื้นที่/ระยะ)               | 85–95% (เทียบสำรวจภาคพื้น)              | งานอาเซียน/ไทย     | [2][4] |
| แผนที่น้ำท่วม (ผลิตหลังภาพ)                       | 1–3 วัน (เกือบเรียลไทม์)                | ระบบ GISTDA-class  | [4]    |
| ความชื้นผิวดิน (SAR) RMSE                         | ~0.04–0.06 m³/m³                        | กึ่งวิจัย/สอบเทียบ | [3]    |
| ราคา SAR เชิงพาณิชย์ (X-band 0.5–3 ม.)            | หลายหมื่น–หลักแสนบาท/ภาพ (ช่วง)         | ตลาด               | [5]    |
| อิทธิพลลม/ไถต่อสัญญาณ                             | เปลี่ยน backscatter ได้มาก (ต้องตรวจ)   | งาน                | [1]    |
| ใช้ติดตามพื้นที่นาข้าวทั่วไทย (ระบบ GISTDA-class) | รายสัปดาห์–รายปักษ์ (ช่วง)              | หน่วยงาน           | [4][5] |
| การผสาน SAR+optical ช่วยความแม่นยำ                | +5–15% (เทียบใช้อย่างเดียว — งาน)       | งาน                | [3]    |

- **กฎ**: "ฟรี/ถี่พอ" สำหรับงานระดับแปลงใหญ่/นโยบาย (ข้าว/ท่วม/พื้นที่) — แต่ "รายแปลงเล็ก (ทุเรียน/ไม้ผล)" ยังต้องใช้ SAR เชิงพาณิชย์/การรวมกับออปติคอลและ IoT
- **เงื่อนไขสำคัญ**: (1) การสอบเทียบกับภาคพื้น (ข้อมูลนาข้าว/สถานี) (2) การจัดการ speckle (3) การรวมกับข้อมูลอื่น (ออปติคอล/IoT/ฝน) (4) ความรู้/เครื่องมือ (การประมวลผล SAR ไม่ใช่เรื่องง่าย)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: SAR เชิงพาณิชย์/บริการ ~1–3 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); เติบโตเร่ง (กลุ่มดาวเทียมใหม่) [5]
- **ผู้เล่นหลัก**: ESA Copernicus (Sentinel-1 — ฟรี), JAXA (ALOS-2), GISTDA (ไทย — การเข้าถึง/บริการ), เชิงพาณิชย์ (ICEYE, Capella, Umbra, PAZ — X-band ความละเอียดสูง), บริการอาเซียน (หลายหน่วยงาน — แผนที่ข้าว/ท่วม); งานไทย: GISTDA/มก./จุฬา (ความชื้น/ข้าว/ท่วม) [2][4][5][6]
- **การลงทุน**: ใช้ Sentinel-1 ฟรี (ต้นทุน = คน/เครื่องมือ/การสอบเทียบ); SAR เชิงพาณิชย์รายแปลงแพง (ไม่คุ้มรายย่อย); รัฐ/หน่วยงานลงทุนการประมวลผล/สอบเทียบ — การเป็น "บริการข้อมูล" (รายแปลง/รายสัปดาห์) มีตลาด
- **แนวโน้ม**: SAR เชิงพาณิชย์ถูกลง/ถี่ขึ้น, foundation models (การประมวลผลอัตโนมัติ — เชื่อม 06), การรวม SAR+ออปติคอล+IoT (05-007) ในแพลตฟอร์มเดียว, การใช้ในการประกันภัยดัชนี/ชดเชยภัย (เชื่อม 11)
- **ความเสี่ยง**: การตลาดเกินจริง (ความชื้น/ผลผลิตจาก SAR ยังไม่นิ่ง), การพึ่งผู้ให้บริการ (lock-in), ความรู้/บุคลากรขาด (การประมวลผลซับซ้อน)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: GISTDA มีระบบแผนที่น้ำท่วม (รายวัน — ใช้ข้อมูล SAR+ออปติคอล) และงานแผนที่ข้าว/พื้นที่เกษตร; งานวิจัย SAR ข้าว/ความชื้น/น้ำท่วม (มก./จุฬา/มข./มจพ. + GISTDA) มีหลายชิ้น; การใช้ SAR เชิงพาณิชย์ (X-band) ในไทยยังน้อย (ราคา/งานเฉพาะ) [4][5][6]
- **จุดแข็งไทย**: GISTDA มีโครงสร้าง/ศูนย์ข้อมูล, Sentinel-1 ฟรีใช้ได้, งานวิจัย SAR ไทยมีอยู่จริง, การประยุกต์ข้าว (พื้นที่ใหญ่/ขังน้ำ — เหมาะกับ SAR มาก), ระบบชดเชยภัยมีอยู่ (ต่อยอดข้อมูล)
- **จุดอ่อน**: บริการ "รายแปลง/รายสัปดาห์" ยังไม่เป็นระบบ (งานเป็นโครงการ), ความชื้นดิน SAR ยังไม่ปฏิบัติการ, การรวม SAR+IoT/ออปติคอลยังจำกัด, บุคลากร/ความรู้เฉพาะทางไม่พอ, ข้อมูลบางส่วนไม่เปิด
- **โอกาส**: (1) "บริการแผนที่นาข้าว/ท่วม/ความชื้นรายสัปดาห์เปิด" (ต่อยอด GISTDA) (2) การสอบเทียบความชื้น SAR กับเครือข่ายเซนเซอร์ (05-007 — ระดับภูมิภาค) (3) การใช้ SAR ในการประกันภัยดัชนี/ชดเชย (เชื่อม 11) (4) การรวม SAR+ออปติคอล+AI (06) ราคาต้นทุนต่ำ
- **หน่วยงาน**: GISTDA, กรมชลประทาน/สทนช. (ท่วม/น้ำ), กรมส่งเสริมการเกษตร/สศก. (ข้าว), มหาวิทยาลัย (มก./จุฬา/มข.), สำนักงานพัฒนาพื้นที่สูง (ไม้ผล)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ระบบ "แผนที่ข้าว/ท่วม/ความชื้น SAR รายสัปดาห์" แบบเปิดสำหรับไทย (บริการต่อเนื่อง ไม่ใช่โครงการ) — ยังไม่มี
- **Q2**: การสอบเทียบความชื้นผิวดิน SAR (Sentinel-1/ALOS-2) กับเครือข่ายเซนเซอร์ภาคพื้นไทย (ต่อยอด 05-007) รายภูมิภาค — ยังไม่มี
- **Q3**: การผสาน SAR+ออปติคอล+IoT (05-007/05-001) ประเมินผลผลิต/ระยะข้าวไทยแบบรายแปลง — ยังเป็นงานวิจัย
- **Q4**: เศรษฐศาสตร์ "SAR เชิงพาณิชย์ (X-band) สำหรับไม้ผล/แปลงเล็กไทย" (คุ้มไหม) — ยังไม่มี
- **Q5**: การใช้ SAR ในการชดเชยภัย/ประกันภัยดัชนีไทย (ข้าว/มัน) — มีนำร่อง (เชื่อม 11) ยังไม่ขยาย
- **Q6**: ฐานข้อมูล backscatter/การสอบเทียบสำหรับดินไทย (จำแนกชนิด) — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ---------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | นำร่อง "บริการ SAR รายสัปดาห์" (ข้าว 5 จังหวัด — พื้นที่/ระยะ/ท่วม) ร่วม GISTDA+กรมส่งเสริม; บันทึกความแม่นยำเทียบสำรวจ | "บริการแผนที่ SAR รายสัปดาห์เปิด" (GISTDA — ข้าว/ท่วม/ความชื้น); การสอบเทียบกับสถานีภาคพื้น (05-007)  |
| 2 (2–4 ปี) | ขยายเป็นบริการเชิงพาณิชย์ (ข้าว/อ้อย/มัน — สหกรณ์/โรงงาน); การประเมินผลผลิตด้วย SAR+ออปติคอล (เชื่อม 05-001)            | การใช้ SAR ในระบบชดเชยภัย/ประกันภัยดัชนี (11); ฐานข้อมูล backscatter ดินไทยเปิด                       |
| 3 (4+ ปี)  | "แพลตฟอร์มข้อมูลพื้นดินแห่งชาติ" (SAR+ออปติคอล+IoT+อากาศ — เชื่อม 05-007/05-008) — บริการรายแปลงสำหรับทุกภาคส่วน        | นโยบาย "ข้อมูลการสำรวจระยะไกลเป็นสาธารณูปโภค" (เปิด/ฟรี); การใช้ในการรายงานคาร์บอน/ส่งออก (02-002/12) |

## 9. ความท้าทายและข้อจำกัด

| ความซับซ้อนการประมวลผล  | speckle/การตีความ ต้องผู้เชี่ยวชาญ/ML | ซอฟต์แวร์/แพลตฟอร์มอัตโนมัติ (06), การอบรม       |

| การรวมหลายข้อมูล        | ยังแยกส่วน (SAR/ออปติคอล/IoT)         | แพลตฟอร์มรวม (06), มาตรฐานข้อมูล                 |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **Sentinel-1: ฟรี/10 ม./6–12 วัน** — ตรวจเอกสาร ESA (สถานะดวงปัจจุบัน 1A/1C/1D)
- [ ] **ความแม่นยำแผนที่ข้าว 85–95%** — ตรวจงานอาเซียน/ไทย (ระบุพื้นที่/ปี)
- [ ] **น้ำท่วม 1–3 วัน** — ตรวจระบบ GISTDA-class/งาน
- [ ] **ความชื้นผิวดิน RMSE 0.04–0.06 m³/m³** — ตรวจงาน (ระบุเซนเซอร์/พื้นที่)
- [ ] **ราคา SAR เชิงพาณิชย์ (X-band)** — ตรวจราคา/ผู้ให้บริการล่าสุด
- [ ] **SAR+optical เพิ่มความแม่นยำ +5–15%** — ตรวจงาน (เป็นช่วง)
- [ ] **สถานะระบบ GISTDA (ท่วม/ข้าว/ความชื้น)** — ตรวจเว็บ/ข่าวอัปเดต
- [ ] **ตลาด SAR 1–3 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี

## 11. อภิธานศัพท์

| คำศัพท์                 | ความหมาย                                      |
| ----------------------- | --------------------------------------------- |
| SAR                     | เรดาร์ดาวเทียม (ทะลุเมฆ/กลางคืน)              |
| Backscatter (σ°)        | ความเข้มคลื่นสะท้อน (ตัวแปรหลัก SAR)          |
| VV/VH                   | โพลาไรซ์คลื่น (VH ไวต่อทรงพุ่มข้าว)           |
| Speckle noise           | สัญญาณรบกวนแบบจุดเกลือพริกไทย (ต้องกรอง)      |
| Sentinel-1              | ดาวเทียม SAR C-band ฟรี (ESA/Copernicus)      |
| ALOS-2                  | SAR L-band (JAXA — เจาะทรงพุ่มหนา)            |
| X-band                  | คลื่นสั้น (ความละเอียดสูง — เชิงพาณิชย์)      |
| Multi-temporal          | การวิเคราะห์อนุกรมเวลา (การเปลี่ยนสัญญาณ)     |
| Flood mapping           | การทำแผนที่น้ำท่วม (พื้นผิวเรียบ = สัญญาณต่ำ) |
| Soil moisture retrieval | การประมาณความชื้นผิวดินจาก backscatter        |
