## 1. บทสรุปผู้บริหาร

- **ใจความ**: LCA (Life Cycle Assessment) วัดผลกระทบต่อสิ่งแวดล้อมของผัก CEA ต่อ 1 กก. — คาร์บอน น้ำ พลังงาน ผ่านทุกขั้นตอน (โครงสร้าง/ไฟ/น้ำ/ปุ๋ย/แพ็ค/ขนส่ง) — **ข้อค้นพบหลัก: คาร์บอนของผัก VF ขึ้นกับ "แหล่งไฟฟ้า" เป็นหลัก** — ไฟจากถ่านหิน = คาร์บอนสูงเท่า/เกินผักแปลง; ไฟสะอาด/โซลาร์ = ต่ำกว่ามาก; น้ำของ CEA ต่ำกว่าแปลงเปิดมากเสมอ [1][2][3]
- **ขั้นพัฒนา**: 🏭 วิธีมาตรฐานแล้ว (ISO 14040/44, PEF — ใช้ในงานวิจัย/การตลาด) — แต่ข้อมูล LCA CEA ยังกระจาย/ไม่ตรงกันตามสมมติฐาน
- **ตัวเลขสำคัญที่สุด**: ผักกาดหอม VF ~1–5 kgCO₂e/กก. (ขึ้นกับกริดไฟฟ้า — งานส่วนใหญ่ 2–4); ไฟคิด 60–80% ของคาร์บอนทั้งหมด; น้ำ ~1–2 ลิตร/กก. เทียบแปลงเปิด 100–300 ลิตร [1][2]
- **นัยต่อไทย**: ไทยยังไม่มี LCA CEA — แต่โจทย์มาแน่ (EU เก็บภาษีคาร์บอน CBAM/การตลาดผักปลอดภัย) — ข้อได้เปรียบไทย: โซลาร์ราคาถูก → "ผัก VF คาร์บอนต่ำ" เป็นแบรนด์ส่งออกได้ [5][6]
- **สถานะโดยรวม**: 🏭 มาตรฐานแล้ว (งานวิจัย/การตลาด) / ไทยยังว่าง

## 2. หลักการและขอบเขต

- **หลักการ LCA (ISO 14040/44)**: (1) กำหนดเป้าหมาย/ขอบเขต (cradle-to-gate / cradle-to-grave; หน่วย = 1 กก. ผัก) (2) บัญชีข้อมูล (LCI — พลังงาน/วัสดุ/น้ำ/การขนส่ง) (3) ประเมินผลกระทบ (LCIA — คาร์บอน/น้ำ/ความเป็นพิษ/การใช้ที่ดิน) (4) แปลผล
- **ขอบเขตระบบที่ต้องตัดสินใจ**: รวมโครงสร้าง (อาคาร/ชั้นวาง — amortize กี่ปี), แหล่งไฟฟ้า (กริด/โซลาร์ — marginal vs average), การขนส่ง (ถึงร้าน/ถึงผู้บริโภค), การจัดการของเสีย/น้ำทิ้ง, การรีไซเคิลโคมไฟ
- **ตัวแปรสำคัญ**: (1) **ไฟฟ้า** — 60–80% ของคาร์บอน CEA (LED+HVAC) (2) **CO2 enrichment** (มาจากไหน — โรงงานปุ๋ย = คาร์บอนแฝง) (3) **พลาสติก** (ถาด/แพ็ค — PET/PP) (4) **การขนส่ง** (อากาศ = สูง, เรือ = ต่ำ)
- **ขอบเขตที่ครอบคลุม**: ผล LCA รายงาน 2010–2025, ปัจจัยกำหนด, มาตรฐาน/ตลาด (คาร์บอน/ภาษี), นัยไทย
- **นอกขอบเขต**: MRV คาร์บอนในดินแปลงเปิด (02-002), พลังงาน/โซลาร์ฟาร์ม (08 — ยังไม่มีไฟล์), เศรษฐศาสตร์ (04-001)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                                             | แหล่ง  |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 2000s     | LCA การเกษตรเปิด (ข้าว/ผัก) เริ่มแพร่; CEA ยังไม่มีงาน                                                                                   | [1]    |
| 2010s     | งาน LCA VF กลุ่มแรก (ผักกาดหอม/โหระพา — สหรัฐฯ/ยุโรป): คาร์บอน VF สูงกว่าแปลงเปิดเมื่อไฟกริด (2–8 เท่า บางงาน)                           | [1][2] |
| 2015–2020 | งานเปรียบเทียบหลายมิติ (คาร์บอน/น้ำ/ที่ดิน): **น้ำและที่ดิน VF ต่ำกว่าแปลงเปิดมาก** — คาร์บอนเป็นจุดอ่อน; ไฟสะอาด/โซลาร์ลดคาร์บอน 50–90% | [2][3] |
| 2021–2025 | งาน PEF/EF (European Commission) สำหรับผัก; การตลาด "คาร์บอนฟุตพริ้นท์" บนฉลากเริ่ม; งาน CO2 enrichment/บรรจุภัณฑ์ใน LCA                 | [3][4] |
| 2026–     | แนวโน้ม: มาตรฐาน LCA CEA ร่วม (Global CEA standards), การใช้ "คาร์บอนเครดิต/ฉลากคาร์บอน" ในการขาย, CBAM/มาตรฐาน EU ผลักข้อมูล LCA        | [3][4] |

- **เส้นแบ่ง**: ระเบียบวิธีนิ่งแล้ว — ความแตกต่างของผลลัพธ์อยู่ที่ "สมมติฐาน" (กริดไฟ/ขอบเขต/อายุโครงสร้าง) — การอ่านผลต้องดูสมมติฐานประกอบเสมอ

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                     | ผลลัพธ์                                                  | เงื่อนไข      | แหล่ง  |
| ----------------------------- | -------------------------------------------------------- | ------------- | ------ |
| คาร์บอนผักกาดหอม VF           | ~1–5 kgCO₂e/กก. (งานส่วนใหญ่ 2–4; กริด US/EU)            | งาน 2015–25   | [1][2] |
| คาร์บอนผักกาดหอมแปลงเปิด      | ~0.3–1.0 kgCO₂e/กก. (เขตอบอุ่น)                          | งาน LCA       | [1][2] |
| สัดส่วนไฟฟ้าในคาร์บอน CEA     | 60–80%                                                   | งานส่วนใหญ่   | [1]    |
| คาร์บอนเมื่อใช้โซลาร์/ไฟสะอาด | ลด 50–90% เทียบกริด                                      | งานจำลอง/แปลง | [2][3] |
| การใช้น้ำ VF (ผักกาดหอม)      | ~1–5 ลิตร/กก. vs แปลงเปิด 100–300                        | งาน 2020–25   | [2]    |
| การใช้ที่ดิน VF               | ต่ำกว่าแปลงเปิด 50–100 เท่า (ต่อกก.)                     | งาน           | [2]    |
| การขนส่งทางอากาศ vs เรือ      | อากาศ 2–10 เท่าของเรือ (ต่อกก.-กม.)                      | LCA ทั่วไป    | [3]    |
| CO2 enrichment                | เพิ่มผลผลิต 10–25% แต่คาร์บอนแฝง +5–15% (ถ้ามาจากฟอสซิล) | งาน           | [3]    |
| บรรจุภัณฑ์ (ถาด+ฟิล์ม)        | ~5–15% ของคาร์บอนผัก CEA                                 | งาน           | [3]    |
| ฉลากคาร์บอน (การยอมรับซื้อ)   | ผู้บริโภค EU/เอเชียยอมจ่าย +5–20% (งาน WTP — ช่วง)       | งานตลาด       | [4]    |

- **กฎ**: ผล LCA "ไม่ใช่ตัวเลขเดียว" — ขึ้นกับกริดไฟ/ฤดู/ขอบเขต/วิธีการ — การเปรียบเทียบต้องใช้สมมติฐานเดียวกัน
- **เงื่อนไขสำคัญ**: (1) กริดไฟฟ้า (ไทย ~0.4–0.6 kgCO₂e/kWh — ยังไม่ยืนยัน) (2) CO2 จากแหล่งใด (3) อายุการใช้งานโครงสร้าง (4) การขนส่งสุดท้าย — 3 ข้อแรกเป็น "ตัวคูณ" ของผลลัพธ์

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: การตลาดคาร์บอน/ฉลากคาร์บอนอาหาร ~5–15 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 15–25%/ปี (นโยบาย EU/ผู้บริโภค) [4]
- **มาตรฐาน/กลไก**: ISO 14040/44, EU PEF (Product Environmental Footprint), PAS 2050, ฉลากคาร์บอน (Carbon Trust UK, ญี่ปุ่น), CBAM (EU — เริ่มบังคับบางสินค้า), การรายงาน ESG ของผู้ซื้อ (Walmart/Sainsbury — ขอข้อมูล LCA จากซัพพลายเออร์)
- **ผู้เล่น**: ผู้ให้บริการ LCA/ซอฟต์แวร์ (Simapro, GaBi/Sphera, One Click LCA), ห้องปฏิบัติการ/บริษัทตรวจ (SGS/Bureau Veritas), ที่ปรึกษาคาร์บอน; ไทย: TGO (องค์การบริหารจัดการก๊าซเรือนกระจก — ฉลากคาร์บอน/Carbon Footprint Label มีแล้วสำหรับสินค้าไทย) [5][6]
- **การลงทุน**: ราคาการทำ LCA/ใบรับรอง ~50,000–500,000 บาท/สินค้า (ช่วง — ยังไม่ยืนยัน); คุ้มเมื่อเข้าตลาดส่งออก/แบรนด์พรีเมียม
- **แนวโน้ม**: "คาร์บอนเป็นเงื่อนไขการขาย" (ผู้ซื้อรายใหญ่ขอข้อมูล), การรวม LCA กับมาตรฐาน GAP/ย้อนกลับ, คาร์บอนเครดิต CEA (ยังถกเถียง — วิธีคำนวณ)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: LCA ผัก/อาหารไทยเริ่มมี (ข้าว/มันสำปะหลัง/ผลไม้ — TGO ฉลากคาร์บอน), **CEA/ผักสลัดไทยยังไม่มี LCA เผยแพร่** [5][6]
- **จุดแข็งไทย**: โซลาร์ราคาถูกที่สุดระดับโลก (→ "ผักคาร์บอนต่ำ" ทำได้จริง), แหล่งน้ำอุดม (น้ำของ CEA น้อยมากอยู่แล้ว), โครงสร้างพื้นฐาน TGO ฉลากคาร์บอนพร้อม
- **จุดอ่อน**: กริดไฟฟ้าไทยยังพึ่งก๊าซธรรมชาติ/ถ่านหิน (ค่าไฟ 4–5 บาท/kWh, คาร์บอนต่อหน่วยปานกลาง), ข้อมูล LCI ไทย (ค่าการปล่อยรายกระบวนการ) ยังขาด, ความตระหนัก/การยอมรับราคา
- **นโยบาย**: TGO (ฉลากคาร์บอน/Carbon Footprint), เป้าหมาย Net Zero 2065 ของไทย, แผนพลังงาน (โซลาร์ลอยน้ำ/PPA), นโยบายส่งออก (EUDR — เริ่มจากป่าไม้ก่อน)
- **โอกาส**: (1) "ผัก VF ไทย ฉลากคาร์บอนต่ำ" สำหรับสิงคโปร์/EU (2) การใช้โซลาร์ในฟาร์ม CEA (เชื่อม 08) เป็น "ตัวลดคาร์บอน" (3) ฐานข้อมูล LCI ไทยเป็นสินทรัพย์วิจัย

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: LCA ผัก CEA ไทยตัวแรก (ผักสลัด VF/โรงเรือนมุ้ง — cradle-to-gate) — ยังไม่มี
- **Q2**: ค่าการปล่อยกริดไฟฟ้าไทยรายชั่วโมง (สำหรับ LCA + การตัดสินใจเปิดไฟ/โซลาร์) — มีข้อมูล TGO/กฟผ. ยังไม่พร้อมใช้ใน LCA CEA
- **Q3**: LCI วัสดุไทย (ถาด/ฟิล์ม/ปุ๋ยน้ำไทย) — ฐานข้อมูลขาด
- **Q4**: ผลของ "โซลาร์+แบตเตอรี่" ต่อคาร์บอนผัก CEA ไทย (จำลอง) — ยังไม่มี
- **Q5**: WTP ของผู้ซื้อ (สิงคโปร์/EU) สำหรับผักฉลากคาร์บอนต่ำจากไทย — ยังไม่มี
- **Q6**: ระเบียบวิธี "คาร์บอนเครดิต CEA" (ที่ถกเถียง — ควรใช้เกณฑ์อะไร) — ยังไม่มีข้อสรุปโลก

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                        | ระดับนโยบาย                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ทำ LCA ต้นแบบ 2 ฟาร์ม (VF กทม. + โรงเรือนมุ้งเชียงใหม่ — ผักสลัด) ร่วม TGO/มหาวิทยาลัย; เปิดข้อมูล                          | สนับสนุนทุน LCA CEA ไทย (TGO/สวทช.); ต่อยอดฐานข้อมูล LCI ไทย                       |
| 2 (2–4 ปี) | ฟาร์มส่งออกติด "ฉลากคาร์บอน" + สมัคร TGO CF Label; จับคู่โซลาร์ลดคาร์บอน (เชื่อม 08); รวมข้อมูล LCA ในใบรับรอง GAP/ย้อนกลับ | มาตรฐาน "ผักคาร์บอนต่ำไทย" (ฉลาก/เกณฑ์); เตรียมรับ CBAM/การขอข้อมูล LCA ของผู้ซื้อ |
| 3 (4+ ปี)  | แบรนด์ "Thai Low-Carbon Leaf" ส่งออก (สิงคโปร์/EU — ข้อมูล LCA ทุกล็อต); คาร์บอนเครดิต CEA (ถ้ามาตรฐานชัด)                  | นโยบาย CEA+พลังงานสะอาด (โซลาร์ฟาร์ม/PPA); ฐานข้อมูล LCA แห่งชาติผัก-อาหาร         |

| ข้อมูล LCI ไม่พอ  | ค่าการปล่อยรายกระบวนการไทยขาด      | ฐานข้อมูล TGO/สวทช., ความร่วมมือมหาวิทยาลัย |
| สมมติฐานไม่ตรงกัน | แต่ละงานใช้กรอบต่างกัน — เทียบยาก  | มาตรฐานร่วม (PEF/ISO) + การเปิดข้อมูล       |
| คาร์บอนจากกริดไทย | ไฟปานกลาง-สูง → คาร์บอนผักสูง      | โซลาร์/PPA สะอาด — ลดได้จริง                |
| ต้นทุนทำ LCA      | แสนบาทต่อสินค้า — รายเล็กแบกรับยาก | กลุ่ม/สหกรณ์, มาตรฐานย่อส่วนสำหรับ SME      |
| CO2 enrichment    | เพิ่มผลผลิตแต่คาร์บอนแฝง           | แหล่ง CO2 ชีวภาพ (ไบโอแก๊ส — เชื่อม 08)     |
| การตลาด/การยอมรับ | ผู้ซื้อยังไม่คุ้นฉลากคาร์บอนผัก    | ศึกษา WTP, การตลาดร่วมผู้ซื้อรายใหญ่        |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **คาร์บอน VF 1–5 kgCO₂e/กก. (งานส่วนใหญ่ 2–4)** — ตรวจงาน LCA 2015–25 (ระบุกริด/ขอบเขต)
- [ ] **แปลงเปิด 0.3–1.0 kgCO₂e/กก.** — ตรวจงาน LCA ผักกาดหอม
- [ ] **ไฟฟ้า 60–80% ของคาร์บอน CEA** — ตรวจงานทบทวน
- [ ] **น้ำ VF 1–5 ลิตร/กก. vs แปลง 100–300** — ตรวจงาน 2020–25
- [ ] **กริดไทย ~0.4–0.6 kgCO₂e/kWh** — ตรวจข้อมูล TGO/กฟผ. ณ รอบอัปเดต
- [ ] **ค่า LCA/ใบรับรอง 5 หมื่น–5 แสนบาท** — ตรวจผู้ให้บริการไทย
- [ ] **ตลาดฉลากคาร์บอนอาหาร 5–15 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **TGO ฉลากคาร์บอน (CF Label) สำหรับผัก** — ตรวจเงื่อนไข/สินค้าที่รับรองล่าสุด

## 11. อภิธานศัพท์

| คำศัพท์             | ความหมาย                                                        |
| ------------------- | --------------------------------------------------------------- |
| LCA                 | Life Cycle Assessment — การประเมินวงจรชีวิต (ISO 14040/44)      |
| LCI / LCIA          | บัญชีข้อมูลสิ่งแวดล้อม / การประเมินผลกระทบ                      |
| kgCO₂e              | คาร์บอนไดออกไซด์เทียบเท่า (หน่วยคาร์บอนฟุตพริ้นท์)              |
| Cradle-to-gate      | ขอบเขต: เริ่มจากทรัพยากรถึงประตูโรงงาน/ฟาร์ม (ไม่รวมใช้-ทิ้ง)   |
| PEF / EF            | Product Environmental Footprint (มาตรฐาน EU)                    |
| CBAM                | ภาษีคาร์บอนข้ามพรมแดน EU (Carbon Border Adjustment Mechanism)   |
| CF Label (TGO)      | ฉลากคาร์บอนฟุตพริ้นท์ของไทย (องค์การบริหารจัดการก๊าซเรือนกระจก) |
| Grid intensity      | การปล่อยคาร์บอนต่อหน่วยไฟฟ้าของกริด (kgCO₂e/kWh)                |
| Marginal vs Average | วิธีคิดไฟฟ้า "หน่วยสุดท้ายที่ใช้" vs "ค่าเฉลี่ยกริด"            |
| Carbon credit       | เครดิตการลด/กักเก็บก๊าซเรือนกระจก (ซื้อขายได้)                  |
