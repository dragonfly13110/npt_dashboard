## 1. บทสรุปผู้บริหาร

- **ใจความ**: Circular Food Systems (ระบบอาหารหมุนเวียน) = เปลี่ยน "ของเสียอาหาร" กลับเป็นทรัพยากรในระบบตามลำดับชั้น (waste hierarchy): ลด/บริจาค → อาหารสัตว์ (eco-feed — ญี่ปุ่น/เกาหลี) → โปรตีนแมลง (10-002 — BSF) → ไบโอแก๊ส/ปุ๋ยหมัก/ไบโอชาร์ (08-003/02) → พลังงานชีวมวล (08-004) แทนการฝังกลบ (landfill) — ลดทั้งขยะ มีเทน และต้นทุน — ตัวเลขตั้งต้น: โลกขยะอาหาร 1.05 พันล้านตัน/ปี (2565 — UNEP) = 8–10% ของ GHG โลก (IPCC-class) + ต้นทุน ~1 ล้านล้าน USD/ปี; ไทย 9.7–10.1 ล้านตัน/ปี (2567–2568 — สสส./คพ.) = 36.8% ของขยะทั้งประเทศ; นโยบาย: EU Circular Economy Action Plan + เป้าลดขยะอาหารผูกพัน 10%/30% (2573), ไทย BCG (3.4 ล้านล้านบาท = 21% GDP) [1][3][5][9][10][34]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์บางเส้นทาง (ชีวมวล/ไบโอแก๊ส/อาหารสัตว์ — ญี่ปุ่น เกาหลี ไทย) + 🧪 งานวิจัย/นำร่อง (BSF scale-up, silica แกลบ, AD ขยะอาหารเมือง) [16][27][30][36]
- **ตัวเลขสำคัญที่สุด**: (1) โลกทิ้งขยะอาหาร 1.05 พันล้านตัน (2565 — 60% ครัวเรือน) + สูญเสียก่อนขาย 13% = FLW 8–10% ของ GHG โลก (~5 เท่าของการบิน) [1][3][4]; (2) เปลี่ยนขยะอาหาร 1% ของโลกเป็นอาหารแมลง BSF → โปรตีน ~332,000 ตัน/ปี + ปุ๋ย ~1 ล้านตัน/ปี (Lalander-class) [13]; (3) ไทย: โรงไฟฟ้าชีวมวล 3,759.4 MW (2565 — แกลบ/ชานอ้อย) + CPF ไบโอแก๊สฟาร์มสุกรลด GHG 41,100 tCO₂e/ปี (T-VER — 12 ฟาร์ม) [27][30]
- **นัยต่อไทย**: ไทย (1) ขยะอาหาร 9.7–10.1 ล้านตัน/ปี-class (ตรวจปี) — 40% ยังกินได้ [9][10]; (2) โรงไฟฟ้าชีวมวล 3,759.4 MW (2565) ใช้น้ำตาลอ้อย ~94 ล้านตัน/ปี → กาก 250–300 กก./ตันอ้อย [27][35][41]; (3) นโยบาย BCG + End-of-Waste (NSTDA/DIW/FTI — 2566) [34][37]; (4) งานนำร่อง: silica จากแกลบ (KMUTT — 96–97% บริสุทธิ์), BSF (CMU/เอกชน), ตะกอนเลนบ่อกุ้ง [33][36]; (5) โอกาส: "คัดแยกขยะอาหารต้นทาง + AD/ปุ๋ยหมักเมือง", "eco-feed/BSF ลดนำเข้าอาหารสัตว์", "digestate/ปุ๋ยหมักยกระดับคาร์บอนดิน (02-002)" — จุดสำคัญ: ของเสียคือ "ทรัพยากรที่มีเจ้าของ" — ต้องมีตลาด/มาตรฐาน/กฎหมายรองรับ [10][16][37]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์บางเส้นทาง + 🧪 นำร่อง/วิจัย (เส้นทางใหม่ — BSF/AD เมือง)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (วงจรปิดของระบบอาหาร)

1. **ลำดับชั้นการจัดการ (Waste Hierarchy)**: (1) ลด/ป้องกันต้นทาง (13-001) → (2) บริจาคอาหารส่วนเกิน (EU Food Donation Guidelines) → (3) อาหารสัตว์/eco-feed (ของที่มนุษย์กินไม่ได้หรือกินไม่ทัน — ญี่ปุ่นให้ลำดับแรกสุด, เกาหลีผลิตเชิงพาณิชย์) → (4) แปรรูปชีวภาพ: แมลง (BSF — 10-002), การย่อยแบบไม่ใช้ออกซิเจน (AD — 08-003), ปุ๋ยหมัก/ไบโอชาร์ (02) → (5) พลังงานชีวมวล (08-004) → (6) สุดท้ายคือฝังกลบ/เผา [8][16][17]
2. **หลัก "ของเสีย = ทรัพยากร (End-of-Waste / Industrial Symbiosis)"**: ของเสียโรงหนึ่งเป็นวัตถุดิบอีกโรงหนึ่ง — ไทยลงนาม MOU NSTDA/DIW/FTI (21 ก.ค. 2566) ส่งเสริม end-of-waste + Circular Material Hub (FTI) [37]
3. **การเมืองเชิงนโยบาย**: EU CEAP 2020 (มี.ค. 2563 — หนึ่งในเสาหลัก Green Deal) → แก้ Waste Framework Directive 2568 → เป้าลดขยะอาหารผูกพันตามกฎหมาย (2573: −10% ภาคแปรรูป, −30% ต่อหัว retail+บริโภค เทียบค่าเฉลี่ย 2564–2566) [5][6][8]

### 2.2 ขอบเขต

- **ครอบคลุม**: ขนาดปัญหา (โลก/ไทย), เทคโนโลยีเปลี่ยนของเสีย→ทรัพยากร 3 เส้นทางหลัก (feed/พลังงาน/ปุ๋ย) พร้อมตัวเลข yield + ลด GHG, เศรษฐศาสตร์การแปรรูปของเสีย, นโยบาย EU/BCG ไทย, สถานการณ์ไทย (ชีวมวล/ไบโอแก๊สฟาร์ม/กากอ้อย/แกลบ/ปลอกข้าวโพด/น้ำเสียฟาร์มกุ้ง-สุกร)
- **นอกขอบเขต** (ลิงก์ข้าม): การลด Losses ต้นทางเชิงลึก (13-001), ไบโอแก๊สฟาร์มเชิงลึก (08-003), พลังงานชีวมวลเชิงลึก (08-004), โปรตีนแมลง/ตลาดแมลงเชิงลึก (10-002), คาร์บอนดิน/MRV เชิงลึก (02-002), โคลด์เชน (13-003), ระบบอาหารเมือง (13-004)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: (1) ขยะอาหาร 9.7–10.1 ล้านตัน/ปี (2567–2568 — สสส./คพ. — วิธีวัดต่างกัน ตรวจปี) = 36.8% ของมูลฝอย [9][10]; (2) โรดแม็พขยะอาหาร 2566–2573 (เป้า −25% ใน 2570, −50% ใน 2573 — สอดคล้อง SDG 12.3) [10]; (3) โรงไฟฟ้าชีวมวล 3,759.4 MW (2565) + ไบโอแก๊ส ~412 MW (ข้อมูล 2559 — ตรวจปี) [26][27]; (4) BCG เป็นวาระชาติ (3.4 ล้านล้านบาท = 21% GDP) + End-of-Waste MOU (NSTDA/DIW/FTI — 2566) + Circular Material Hub [34][37]; (5) งานวิจัยนำร่อง: silica แกลบ (KMUTT), BSF (CMU/เอกชน), ตะกอนเลนกุ้ง BCG (งาน มก.-class), น้ำเสียฟาร์มสุกร→ไบโอแก๊ส (CPF T-VER) [12][30][33][36]
- **จุดแข็ง**: เศษเหลือปริมาณมากแน่นอน (แกลบ 8 ล้านตัน/ปี-class, กากอ้อย, ปลอกข้าวโพด 1.7 ล้านตัน, ต้นข้าวโพด 5.2 ล้านตัน — ข้อมูล 2553 ตรวจปี) [36][38]; โครงสร้างโรงงานน้ำตาล/ข้าวมี co-generation อยู่แล้ว; เอกชนใหญ่ (CPF) ทำวงจรปิดครบวง; นโยบาย BCG/T-VER พร้อม [31][34][37]
- **จุดอ่อน**: ขยะอาหารไทย 40% กินได้ยังถูกทิ้ง (คัดแยกต้นทางยังน้อย); กทม. ขยะอาหาร 46% ของมูลฝอย — โครงสร้างการแยก/เก็บยังไม่เป็นระบบ; feed จากขยะอาหารยังไม่มีมาตรฐาน/กฎหมายชัด (ต่างจากญี่ปุ่น/เกาหลี); ตัวเลขขยะอาหารยังไม่เป็นระบบเดียว (9.7 vs 10.1) [9][10][16]
- **โอกาส**: (1) คัดแยกขยะอาหารแหล่งกำเนิด + AD/ปุ๋ยหมักในเมือง (ตาม blueprint 2569–2573 ของ roadmap) [10]; (2) eco-feed/BSF — ลดนำเข้าอาหารสัตว์ (ไทยนำเข้าโปรตีนสูง-class — ดู 10-002) [16]; (3) digestate/ปุ๋ยหมักยกระดับคาร์บอนดิน + เครดิต (02-002) [22][23]; (4) ของเสียอ้อย/ข้าว → พลังงาน + วัสดุมูลค่าสูง (silica — ตลาด 1,000–3,000 บาท/กก.) [36]; (5) น้ำเสียฟาร์มกุ้ง/สุกร → ไบโอแก๊ส + น้ำปุ๋ย (ขยายแบบ CPF สู่ฟาร์มกลาง/เล็กผ่าน T-VER) [30][31]
- **หน่วยงาน**: คพ./ทส. (ข้อมูล/โรดแม็พ), สสส. (โครงการขยะอาหาร), DEDE/EPPO (ชีวมวล/ไบโอแก๊ส), TGO (T-VER), สวทช./NSTDA (end-of-waste), BOI (สิทธิประโยชน์), กรมปศุสัตว์ (อาหารสัตว์จากเศษเหลือ), สถาบัน (มก./CMU/KMUTT/NIA)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลขขยะอาหารไทยไม่ลงตัว (9.7 vs 10.1 ล้านตัน — สสส. 2568 vs คพ. 2567) — ต้องมีวิธีวัดมาตรฐานเดียว (ปรับกับ UNEP Food Waste Index) — ยังไม่มี
- **Q2**: การคัดแยกขยะอาหารแหล่งกำเนิด + เศรษฐศาสตร์การเก็บขนในไทย (ต้นทุน/ตัน เทียบรายได้จาก AD/ปุ๋ยหมัก) — ยังไม่มีงานรวม
- **Q3**: อาหารเหลือ→feed ในไทย: กฎหมาย/มาตรฐานความปลอดภัย (เทียบ EU guideline 2561, เกาหลี 80°C/30 นาที) + อัตราแปลงที่แท้จริงของสตรีมไทย — ยังไม่ชัด
- **Q4**: BSF สเกลเชิงพาณิชย์ไทย: ต้นทุนจริง/กก.โปรตีน เทียบปลาป่น/กากถั่วเหลือง + อัตราแปลงจากขยะอาหารไทย (ผัก/ผลไม้/ข้าว) — ยังไม่มีตัวเลขเปิด
- **Q5**: digestate/ปุ๋ยหมักไทย: สารอาหาร + โลหะหนัก/จุลชีพ (มาตรฐานปุ๋ยอินทรีย์) + ผลต่อ SOC ระยะยาวในดินไทย (เชื่อม 02-002) — ยังเริ่ม
- **Q6**: LCA เทียบ 3 เส้นทาง (feed vs AD vs ปุ๋ยหมัก) ต่อตันของเสีย ณ สภาพไทย (ภูมิอากาศ/โครงข่ายไฟฟ้า) — ยังไม่มีงานเปรียบเทียบรวม
- **Q7**: ตัวเลข GHG ของ FLW กำลังเปลี่ยน (8–10% IPCC 2562 vs 11% Nature Climate Change 2569 — นิยามต่าง) — ต้องติดตามผลกระทบต่อ argument การลงทุน

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                            | ระดับนโยบาย                                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ฟาร์มปศุสัตว์: ไบโอแก๊ส+น้ำปุ๋ย (T-VER — แบบ CPF); โรงสี/โรงน้ำตาล: ขายเศษเหลือให้โรงไฟฟ้า/ไบโอชาร์; งาน Q1 (มาตรฐานวัดขยะอาหาร)                | เดินตามโรดแม็พ 2566–2573 (ลด 25% 2570 — ต้องคัดแยกต้นทาง); มาตรฐาน feed จากขยะอาหาร (Q3); ทุน สสส./TSRI สนับสนุนต้นแบบ |
| 2 (2–4 ปี) | BSF/eco-feed เชิงพาณิชย์ (เชื่อม 10-002); AD ขยะอาหารเมือง/ตลาดสด (46% กทม. — 13-004); ปุ๋ยหมัก/digestate ขายพร้อมคาร์บอนเครดิต (02-002)        | ต่อยอด End-of-Waste เป็นกฎหมาย; กลไกภาษี/อุดหนุนคัดแยก (ตามแผน 2569–2570 ของ roadmap); จัดทำ LCA ระดับชาติ (Q6)        |
| 3 (4+ ปี)  | "ฟาร์ม/โรงงานขยะศูนย์" ครบวงจร (feed+พลังงาน+ปุ๋ย); อุตสาหกรรม symbiosis ระดับคลัสเตอร์ (ของเสียเชื่อมโรงงานกัน); วัสดุมูลค่าสูง (silica-class) | เป้าหมายชาติ Zero Food Waste (2573); นับ FLW ใน NDC/แผน Net Zero 2593; ตลาดคาร์บอน+มาตรฐานปุ๋ยอินทรีย์แห่งชาติ         |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย               | รายละเอียด                                                                                                                      | โอกาสแก้                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| การคัดแยก/การปนเปื้อน    | ขยะปนพลาสติก/สารเคมี ทำลายคุณภาพ feed/ปุ๋ย (งานจีน: คัดแยกดีขึ้น ความบริสุทธิ์ 97.6% — แต่ pre-treatment สูญเสียอินทรีย์ 41.8%) | คัดแยกแหล่งกำเนิด + กฎหมาย (แบบ EU/เกาหลี)          |
| กฎหมาย feed จากขยะ       | EU ห้ามขยะเทศบาลเป็นอาหารสัตว์ (TSE-class); ไทยยังไม่มีกรอบ                                                                     | ใช้แนวทาง EU guideline 2561/เกาหลี (heat treatment) |

| กลิ่น/ชุมชน              | โรง AD/ปุ๋ยหมักใกล้ชุมชนถูกต่อต้าน                                                                                              | เทคโนโลยีปิด + zoning + สื่อสาร                     |
| ของเสีย "มีเจ้าของ"      | เศษเหลือมีราคาแล้ว (แกลบ 40 USD/ตัน) — แย่ง feedstock ระหว่างพลังงาน/ปุ๋ย/feed                                                  | จัดลำดับการใช้ตาม waste hierarchy ระดับชาติ         |
| ข้อมูลไทยไม่ครบ          | ขยะอาหาร 2 ชุดข้อมูลไม่ตรงกัน; การกำจัดปัจจุบันยังฝังกลบ/เผาเปิด-class                                                          | มาตรฐานวัดเดียว (UNEP FWI) + ฐานข้อมูลเปิด          |

## 11. อภิธานศัพท์

| คำศัพท์                     | ความหมาย                                                       |
| --------------------------- | -------------------------------------------------------------- |
| Circular Food System        | ระบบอาหารหมุนเวียน — ของเสียวนกลับเป็นทรัพยากร                 |
| FLW (Food Loss & Waste)     | อาหารสูญหาย + ขยะอาหาร (SDG 12.3)                              |
| Waste Hierarchy             | ลำดับชั้นการจัดการ: ลด→บริจาค→feed→แปรรูปชีวภาพ→พลังงาน→ฝังกลบ |
| Valorization/Upcycling      | การเติมมูลค่าให้ของเสีย (เป็นผลิตภัณฑ์มูลค่าสูงขึ้น)           |
| Eco-feed                    | อาหารสัตว์จากขยะอาหารที่ผ่านกระบวนการ (ญี่ปุ่น)                |
| BSF (Black Soldier Fly)     | แมลงวันลาย — ตัวอ่อนกินขยะอาหาร ผลิตโปรตีน+frass               |
| Frass                       | มูล/เศษจากตัวอ่อนแมลง = ปุ๋ยอินทรีย์                           |
| Anaerobic Digestion (AD)    | การย่อยแบบไม่ใช้ออกซิเจน → ไบโอแก๊ส + digestate                |
| Digestate                   | กากเหลว/แห้งหลัง AD — ปุ๋ย/ปรับปรุงดิน                         |
| Biogas/Biomethane           | ไบโอแก๊ส (CH₄ 50–70%) / ขึ้นคุณภาพเป็น bio-CNG                 |
| Compost                     | ปุ๋ยหมัก (การย่อยแบบใช้ออกซิเจน)                               |
| End-of-Waste                | สถานะ "สิ้นสุดการเป็นของเสีย" → เป็นผลิตภัณฑ์                  |
| Industrial Symbiosis        | ของเสียโรงหนึ่งเป็นวัตถุดิบอีกโรงหนึ่ง                         |
| Circular Material Hub (CMH) | แพลตฟอร์ม FTI เชื่อมของเสีย-วัตถุดิบ                           |
| BCG (Bio-Circular-Green)    | โมเดลเศรษฐกิจชีวภาพ-หมุนเวียน-สีเขียวของไทย                    |
| T-VER                       | โครงการลดก๊าซเรือนกระจกภาคสมัครใจของไทย (TGO)                  |
| Bagasse                     | กากอ้อย (ชานอ้อย)                                              |
| Rice Husk                   | แกลบ (เปลือกข้าว)                                              |
| LCOE                        | ต้นทุนไฟฟ้าต่อหน่วยตลอดอายุโครงการ                             |
| NDC                         | แผนการมีส่วนร่วมลดก๊าซเรือนกระจกระดับชาติ                      |
| Net Zero 2593 (2050)        | เป้าไทยปล่อย GHG สุทธิเป็นศูนย์ (เลื่อนเร็วขึ้น 15 ปี-class)   |
| Methane Slip                | การรั่วไหลของมีเทนที่ไม่ได้ใช้ (ลดประโยชน์ AD)                 |
