## 1. บทสรุปผู้บริหาร

- **แผนที่ดินดิจิทัล (Digital Soil Mapping, DSM)** คือการสร้างแผนที่คุณสมบัติ/ชนิดของดินด้วยคอมพิวเตอร์ โดยใช้ข้อมูลจุดเก็บดินภาคสนาม + ห้องปฏิบัติการ (รวมถึงเทคนิคสเปกโทรสโกปี/คลื่นแสง Vis-NIR) ผนวกกับตัวแปรสิ่งแวดล้อมผ่านความสัมพันธ์เชิงปริมาณ (machine learning: random forest, gradient boosting) เพื่อประมาณค่าดินเป็นภาพพิกเซลรายจุดพร้อมค่าความไม่แน่นอน [1][2]
- **ตัวเลขสำคัญ:** SoilGrids ของ ISRIC ให้แผนที่ดินทั่วโลกความละเอียด 250 เมตร ครอบคลุมคุณสมบัติดิน 14 รายการ (pH, อินทรีย์คาร์บอน, ความหนาแน่นรวม, เนื้อดิน ฯลฯ) ใน 6 ช่วงความลึกมาตรฐาน ใช้ฐานข้อมูลจุดตัวอย่าง WoSIS และตัวแปรแวดล้อมจากชั้นข้อมูลราว 400 ชั้น [2] — ความละเอียดนี้ยังต่ำกว่าเป้าหมาย 90 เมตรของ GlobalSoilMap (ยังไม่ยืนยันตัวเลขละเอียด)
- **สถานะโดยรวม:** 🏭 เชิงพาณิชย์แล้วระดับนานาชาติ (SoilGrids ให้บริการสาธารณะฟรีภายใต้สัญญา CC-BY 4.0) แต่ในประเทศไทยยังเป็นงานวิจัย/นำร่องที่ต้องบ่มเพาะต่อ
- **นัยต่อไทย:** เชื่อมกับระบบ ThaiSoil/กรมพัฒนาที่ดิน (LDD) เพื่อยกระดับจากแผนที่แบบ analog/สเกลหยาบเป็นแผนที่คุณสมบัติเชิงปริมาณความละเอียดสูง ลดต้นทุนการสำรวจดินภาคสนาม และหนุนเกษตรแม่นยำ (precision agriculture)

## 2. หลักการและขอบเขต

- **หลักการ DSM:** อาศัยกรอบ SCORPAN ที่ใช้ตัวแปร 7 กลุ่มอธิบายดิน ได้แก่ s = ตัวดิน/คุณสมบัติเดิม, c = ภูมิอากาศ, o = สิ่งมีชีวิต/พืชพรรณ, r = สภาพภูมิประเทศ (relief/topography), p = วัตถุต้นกำเนิด, a = อายุ (age/time), n = ตำแหน่งเชิงพื้นที่ (spatial position) แล้วใช้เครื่องมือ ML เช่น random forest, gradient boosting สร้างสมการทำนายค่าดิน ณ แต่ละพิกเซล [1]
- **บทบาทของสเปกโทรสโกปี:** ใช้เซนเซอร์ดูดกลืนแสงช่วง visible–near infrared (Vis-NIR) วัดตัวอย่างดินราคาถูกและเร็ว เพื่อทำนายคุณสมบัติเคมี/กายภาพ (อินทรีย์คาร์บอน เนื้อดิน ฯลฯ) แทนวิธีเคมีเปียกที่แพงและช้า; ต้องมีสมการแปลงสัญญาณ (calibration) ที่ฝึกจากชุดดินอ้างอิงของแต่ละพื้นที่ [1][4]
- **ขอบเขตที่ครอบคลุม:** หลักการ DSM, เทคนิคแมชชีนเลิร์นนิง, บทบาทของสเปกโทรสโกปี/สเปกตรัมดิน, ฐานข้อมูลโลก (SoilGrids/GlobalSoilMap), สถานการณ์ไทยที่เชื่อม ThaiSoil/RTN/กรมพัฒนาที่ดิน
- **นอกขอบเขต** (ไม่เขียนซ้ำเพื่อไม่ทับซ้อนไฟล์อื่น): การประเมินความอุดมสมบูรณ์และการให้ปุ๋ยโดยละเอียด (เป็นหัวข้อแยกในโดเมน "ดิน จุลินทรีย์ และธาตุอาหาร"), ระบบนำร่องโดรน/เซนเซอร์เกษตรแม่นยำโดยตรง (โดเมนเครื่องจักรการเกษตรล้ำสมัย)

## 3. สถานะงานวิจัย

| ช่วงเวลา               | ความก้าวหน้า                                                                                                                                  | แหล่ง  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| กลางทศวรรษ 1980s–2000s | กำเนิดแนวคิด DSM/pedometrics และกรอบ SCORPAN; ใช้ GIS + geostatistics ทำนายดินเชิงปริมาณ                                                      | [1]    |
| 2013–2016              | ISRIC เปิดตัว SoilGrids250m (รุ่น 1) ทำแผนที่ดินทั่วโลก 250 ม. โดยใช้ ML                                                                      | [2]    |
| 2020–2021              | SoilGrids 2.0 (Poggio และคณะ, 2021) ใช้ gradient boosting + ตัวแปรแวดล้อมราว 400 ชั้น พร้อมค่าความไม่แน่นอนรายพิกเซล                          | [2][3] |
| 2025–2026              | SoilGrids เวอร์ชันล่าสุดยังใช้ความละเอียด 250 ม. และเป็นผลิตภัณฑ์สาธารณะ CC-BY 4.0; ประเทศไทยยังอยู่ขั้นวิจัย/นำร่องเชื่อมข้อมูล ThaiSoil-LDD | [2]    |

- **เส้นแบ่ง:** ระดับโลก (SoilGrids/ISRIC) เป็นผลิตภัณฑ์เชิงพาณิชย์/สาธารณะพร้อมใช้งานแล้ว; ระดับไทยยังเป็นงานวิจัย/นำร่องที่ต้องบ่มเพาะต่อ ยังไม่มีแผนที่คุณสมบัติเชิงปริมาณ 250 ม. ครอบคลุมทั้งประเทศอย่างเป็นทางการ (ยังไม่ยืนยัน)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                    | ผลลัพธ์                                                                                                        | สถานที่/เงื่อนไข                                                                           | แหล่ง  |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------ |
| ความละเอียดเชิงพื้นที่ (SoilGrids)           | 250 เมตร                                                                                                       | ครอบคลุมทั่วโลก, ค่าเฉลี่ยพิกเซล; 6 ช่วงความลึกมาตรฐาน                                     | [2]    |
| จำนวนคุณสมบัติดินที่ทำแผนที่                 | 14 รายการ (pH, SOC, ความหนาแน่นรวม, coarse fragments, sand/silt/clay, CEC, ไนโตรเจนรวม, ความหนาแน่น/สต็อก SOC) | ทั่วโลก, จากฐานข้อมูล WoSIS                                                                | [2]    |
| จำนวนชั้นข้อมูลตัวแปรแวดล้อม                 | ราว 400 ชั้น (ภูมิอากาศ พืชพรรณ ธรณีสัณฐาน) ใช้คัดเลือกเป็นตัวแปรร่วม                                          | ทั่วโลก, SoilGrids 2.0                                                                     | [2][3] |
| ความหนาแน่นการเก็บตัวอย่างในแปลง (คำแนะนำ)   | 10–20 จุดต่อ 40 เอเคอร์ (~16 ไร่)                                                                              | คำแนะนำห้องปฏิบัติการ มหาวิทยาลัย Iowa State / Colorado State; เงื่อนไข: แปลงเกษตรขนาดใหญ่ | [4]    |
| ความแม่นยำทำนายด้วยสเปกโทรสโกปี (เชิงคุณภาพ) | ดีสำหรับอินทรีย์คาร์บอน/เนื้อดิน แต่ผันแปรตามพื้นที่/ชุดอบรม (ค่า R2/RPD ไม่ระบุเชิงตัวเลขที่ยืนยัน)           | ต้องมี calibration เฉพาะพื้นที่                                                            | [1][4] |

- **กฎ:** ทุกตัวเลขมีแหล่ง + เงื่อนไขตามตาราง; กรณีที่ยังไม่ยืนยันเชิงตัวเลข เช่น ค่า R²/RMSE ของสเปกโทรสโกปีและรายละเอียดความละเอียด 90 ม. ของ GlobalSoilMap เขียนไว้ว่า "ยังไม่ยืนยัน" (ดูข้อ 10)
- ตัวเลขที่มาไม่ครบเงื่อนไข → ระบุว่า "ไม่ระบุ" ตามกฎแม่แบบ

## 5. ตลาดและการลงทุน

- SoilGrids ของ ISRIC เป็นผลิตภัณฑ์หลักของโลก ให้ข้อมูลฟรีภายใต้ CC-BY 4.0 โดยทุนจากงบประมาณหลัก ISRIC และโครงการ EU-H2020 CIRCASA (การเงินเชิงตัวเลขของตลาด DSM ไม่ระบุ) [2]
- ผู้เล่นหลักระดับสถาบัน: ISRIC–World Soil Information, International Union of Soil Sciences (GlobalSoilMap Working Group), หน่วยสำรวจดินระดับชาติ (เช่น ไทยคือกรมพัฒนาที่ดิน) [1][2]
- ผู้เล่นเชิงพาณิชย์/สตาร์ทอัพ: บริษัทที่ขายบริการสเปกโทรสโกปีดิน (เซนเซอร์ Vis-NIR ภาคสนาม) และแพลตฟอร์มเกษตรแม่นยำ; ยังไม่มีตัวเลขเงินทุนรอบล่าสุดที่ยืนยันได้ (ยังไม่ยืนยัน)
- ปัจจัยขับเคลื่อน: ต้นทุนการสำรวจ/วิเคราะห์ดินที่ลดลง, แนวโน้มเกษตรแม่นยำและคาร์บอนในดิน (carbon farming) ต้องการข้อมูลดินเชิงปริมาณ; ปัจจัยฉุดรั้ง: ต้นทุน/การบำรุงรักษาเซนเซอร์และโมเดลที่ต้องสอบเทียบซ้ำตามพื้นที่

## 6. สถานการณ์ประเทศไทย

- **กรมพัฒนาที่ดิน (LDD)** เป็นหน่วยงานหลักดูแลแผนที่ดินและระบบข้อมูลชุดดินไทย (ThaiSoil) แต่หน้าเว็บหลักเป็นหน้าจอเริ่มต้น (JavaScript) ทำให้ข้อมูลรายละเอียด เช่น มาตราส่วนแผนที่และจำนวนชุดดิน ยังไม่สามารถยืนยันได้จากแหล่งที่เข้าถึง (ยังไม่ยืนยัน) [5]
- การนำ DSM/ML มาใช้กับข้อมูลชุดดินไทยเพื่อผลิตแผนที่คุณสมบัติเชิงปริมาณความละเอียดสูงยังเป็นงานวิจัย/นำร่องในมหาวิทยาลัยและหน่วยงานวิจัย (ตัวเลขรายละเอียดยังไม่ยืนยัน)
- โครงสร้าง/นโยบายที่เอื้อ: ความพร้อมของข้อมูลพื้นฐาน LDD และโครงข่าย RTN; อุปสรรค: ข้อมูลตัวอย่างดิน (training points) ยังกระจัดกระจาย, งบประมาณและกำลังคนด้าน pedometrics จำกัด

## 7. ช่องว่างงานวิจัย (Open Questions)

- จะเชื่อมข้อมูลชุดดินไทย (ThaiSoil/LDD) กับตัวแปรแวดล้อมท้องถิ่นให้ได้แผนที่ 250 ม. หรือละเอียดกว่าครอบคลุมทั้งประเทศได้อย่างไร?
- ค่า R²/RMSE ของโมเดลสเปกโทรสโกปีสำหรับดินชนิดหลักของไทย (เช่น ดินเค็ม ดินเปรี้ยว ดินทราย) เป็นเท่าใด และต้องใช้ชุดข้อมูลสอบเทียบกี่จุด?
- จะผสานความไม่แน่นอน (uncertainty) เข้าในคำแนะนำการใช้ปุ๋ย/การจัดการดิน ณ ระดับแปลงได้อย่างไร?
- ต้นทุนต่อพื้นที่ (บาท/ไร่) ระหว่างวิธีสำรวจดั้งเดิม vs DSM+สเปกโทรสโกปีในบริบทไทยเป็นเท่าใด?
- ข้อมูลภาคพื้นดิน (training data) ของไทยควรเพิ่มจากแหล่งใดเพื่อลดอคติของโมเดลรายภูมิภาค?

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                   | ระดับนโยบาย                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ใช้ SoilGrids/ข้อมูล LDD ทดลองทำแผนที่คุณสมบัติเบื้องต้นรายแปลง; ทดลองเซนเซอร์สเปกโทรสโกปีในแปลงนำร่อง | เปิดข้อมูลแผนที่ดิน LDD เป็น API/มาตรฐานเปิด; จัดทำชุดข้อมูลเก็บตัวอย่างดินอ้างอิง (calibration) ระดับชาติ |
| 2 (2–4 ปี) | พัฒนาโมเดล DSM ในพื้นที่นำร่องหลายจังหวัด เชื่อม RTN/ThaiSoil; บริการวิเคราะห์สเปกโทรสโกปีแบบรับจ้าง   | ตั้งมาตรฐานคุณภาพ/สอบเทียบระหว่างห้องแล็บ; สร้างหน่วยงาน/งบวิจัย DSM ไทย                                   |
| 3 (4+ ปี)  | บริการแผนที่ดินความละเอียดสูงรายแปลง เชิงพาณิชย์ สนับสนุนการให้ปุ๋ยแม่นยำ/คาร์บอนเครดิตดิน             | นโยบายข้อมูลดินแห่งชาติและกติกาการให้ปุ๋ยรายแปลง ระยะยาว                                                   |

| ข้อมูลจุดตัวอย่างไม่พอ/กระจายไม่ทั่ว   | โมเดลอคติในภูมิภาค ข้อมูลไทยกระจัดกระจาย  | เก็บตัวอย่างเสริม + ใช้ตัวแปรแวดล้อมท้องถิ่น      |
| ต้นทุนเซนเซอร์/โมเดลที่ต้องสอบเทียบซ้ำ | สเปกโทรสโกปีต้อง calibration เฉพาะพื้นที่ | มาตรฐานสอบเทียบร่วม + โมเดลฐานเปิด                |
| ความละเอียด 250 ม. ยังหยาบต่อแปลงเล็ก  | ใหญ่กว่าเป้าหมาย 90 ม. ของ GlobalSoilMap  | เทคนิค downscaling + ภาพถ่ายดาวเทียมรายละเอียดสูง |
| ความไม่แน่นอน/คุณภาพข้อมูล             | ต้องรายงาน uncertainty รายพิกเซล          | ปฏิบัติตามมาตรฐาน GlobalSoilMap                   |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] ตรวจสอบรายละเอียดแผนที่/ฐานข้อมูล ThaiSoil ของกรมพัฒนาที่ดิน (LDD) — มาตราส่วนแผนที่ จำนวนชุดดิน และสถานะแผนที่คุณสมบัติเชิงปริมาณ 250 ม. ของไทย (ยังไม่ยืนยัน — หน้าเว็บ ldd.go.th เป็นหน้าจอเริ่มต้นเท่านั้น) [5]
- [ ] ตรวจสอบตัวเลขค่าความแม่นยำ R²/RPD และ RMSE ของสเปกโทรสโกปี Vis-NIR สำหรับดินไทย/เขตร้อนจากเอกสาร peer-reviewed โดยตรง (ยังไม่ยืนยัน) [1][4]
- [ ] ตรวจสอบความละเอียดเป้าหมาย 90 เมตรและข้อกำหนดจุดความลึกมาตรฐานของ GlobalSoilMap จากเอกสาร IUSS/GWG อย่างเป็นทางการ (ยังไม่ยืนยันเชิงตัวเลข) [2]
- [ ] ตรวจสอบมูลค่าตลาด/เงินลงทุนของสตาร์ทอัพ DSM และสเปกโทรสโกปีดินล่าสุด (ยังไม่ยืนยัน)
- [ ] ติดตาม SoilGrids เวอร์ชันถัดไปและงานวิจัยการนำ DSM มาใช้กับข้อมูลชุดดินไทยที่เผยแพร่หลังปี 2569

## 11. อภิธานศัพท์

| คำศัพท์                    | ความหมาย                                                                                                          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| DSM (Digital Soil Mapping) | การสร้างแผนที่ดินเชิงปริมาณด้วยคอมพิวเตอร์โดยผูกจุดตัวอย่างเข้ากับตัวแปรสิ่งแวดล้อมผ่านความสัมพันธ์เชิงปริมาณ [1] |
| SCORPAN                    | กรอบตัวแปร 7 กลุ่ม (s,c,o,r,p,a,n) ใช้ทำนายการกระจายของดิน [1]                                                    |
| SoilGrids                  | ระบบแผนที่ดินทั่วโลกของ ISRIC ความละเอียด 250 ม. 14 คุณสมบัติ 6 ช่วงความลึก [2]                                   |
| GlobalSoilMap              | โครงการระหว่างประเทศกำหนดมาตรฐานแผนที่ดินความละเอียดสูง (เป้าหมาย 90 ม.) ของ IUSS [2]                             |
| Vis-NIR spectroscopy       | การวัดสเปกตรัมคลื่นแสงช่วง visible–near infrared เพื่อประเมินคุณสมบัติดิน [1][4]                                  |
| WoSIS                      | ฐานข้อมูลโปรไฟล์ดินรวบรวมระหว่างประเทศของ ISRIC ใช้เป็นข้อมูลฝึกโมเดล SoilGrids [2]                               |
| ThaiSoil / LDD             | ระบบข้อมูลและการสำรวจดินของกรมพัฒนาที่ดินประเทศไทย [5]                                                            |
