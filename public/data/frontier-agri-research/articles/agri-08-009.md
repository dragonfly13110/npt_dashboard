## 1. บทสรุปผู้บริหาร

- **ใจความ**: การอบแห้งพลังงานแสงอาทิตย์ = ใช้แดด (ความร้อน/แสง) อบแห้งผลผลิต — ตั้งแต่ "ตากแดดธรรมดา" จนถึง "ตู้อบแห้งโซลาร์ (Solar dryer) — เรือนกระจก/ตัวเก็บความร้อน+พัดลม/เซนเซอร์ควบคุม" — ประโยชน์: (1) ลด Losses หลังเก็บเกี่ยว (ข้าว/ผัก/ผลไม้/เห็ด/อาหารทะเล — เน่าเสียถ้าไม่แห้งทัน) (2) คุณภาพสม่ำเสมอ (อุณหภูมิ/ความชื้นควบคุม — ดีกว่าตากดิน) (3) เพิ่มมูลค่า (แปรรูป/ส่งออก — อบแห้ง = ราคาสูงขึ้น) (4) ประหยัดค่าไฟ/แก๊ส (เทียบเตาอบ — ใช้แดดฟรี) — ไทย: ตากแดดเป็นภูมิปัญญาอยู่แล้ว — เทคโนโลยีตู้อบโซลาร์ (เรือนกระจก-class) เริ่มแพร่ (วิสาหกิจ/กลุ่มเกษตรกร) [1][2][3]
- **ขั้นพัฒนา**: 🏭 ใช้จริง/ขยาย (ตู้อบโซลาร์ใช้จริงทั่วโลก+ไทย — กลุ่ม/วิสาหกิจ/ส่งออก; เทคโนโลยีเซนเซอร์/ไฮบริดกำลังขยาย) [2][3]
- **ตัวเลขสำคัญที่สุด**: Losses หลังเก็บเกี่ยวไทย (ผัก/ผลไม้) ~15–40% (ช่วง — ขึ้นชนิด/ฤดู — หนึ่งในเหตุ = การถนอมไม่ทัน); ตู้อบโซลาร์ลดเวลา/ประหยัดพลังงาน ~30–70% เทียบตาก/เตา (ช่วง); อุณหภูมิอบเหมาะ ~40–70°C (ช่วง — ขึ้นชนิด — กล้วย/มะม่วง/พริก/สมุนไพร); ตู้อบโซลาร์ (วิสาหกิจ) ราคา ~20,000–200,000 บาท (ช่วง — ขึ้นขนาด/เทคโนโลยี); อบแห้งเพิ่มมูลค่า ~2–5 เท่า (ช่วง — แปรรูป) [1][3][4]
- **นัยต่อไทย**: ไทยแดดจัด (อบแห้งฟรีเกือบทั้งปี) + วิสาหกิจ/แปรรูป (OTOP-class — กลุ่มอบแห้ง) + มาตรฐานส่งออก (GAP/HACCP — การอบต้องควบคุม) — จุดสำคัญ: (1) เริ่มจาก "ตู้อบเรือนกระจกโซลาร์" (กลุ่ม/วิสาหกิจ — ราคาไม่แพง — คุณภาพสม่ำเสมอ) (2) ดู "ชนิดผลผลิต/อุณหภูมิ" (อบผิด = เสียคุณภาพ/สี/สารอาหาร) (3) "ไฮบริด (โซลาร์+ไฟฟ้า/ชีวมวล)" เมื่อแดดไม่พอ (ฝน/ฤดู) — ผูก 08-003 [2][3][4]
- **สถานะโดยรวม**: 🏭 ใช้จริง/ขยาย (ตู้อบโซลาร์ไทย — กลุ่ม/วิสาหกิจ) — เทคโนโลยีเซนเซอร์/AI/ไฮบริดกำลังขยาย

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (3 แบบหลัก)

1. **ตากแดดตรง (Open sun)**: วางบนถาด/ตาข่ายกลางแดด — ถูกสุด/ควบคุมไม่ได้ (ฝุ่น/ฝน/แมลง/คุณภาพไม่สม่ำเสมอ)
2. **ตู้อบเรือนกระจกโซลาร์ (Greenhouse solar dryer)**: โครง/หลังคาพลาสติกหรือแก้ว — รับแดด+พัดลมระบาย (ใช้ไฟฟ้า/โซลาร์) — "ราคาไม่แพง/คุณภาพดี — เหมาะกลุ่ม/วิสาหกิจ"
3. **ตู้อบไฮบริด (Hybrid dryer — โซลาร์+ไฟฟ้า/แก๊ส/ชีวมวล)**: อบต่อเนื่องแม้ไม่มีแดด (ฝน/กลางคืน) — แพงขึ้น — เหมาะผลผลิตเยอะ/มาตรฐาน

### 2.2 อุณหภูมิอบที่เหมาะ (ตาราง — ต้องตรวจ)

| ผลผลิต                  | อุณหภูมิอบ (ช่วง)     | หมายเหตุ            |
| ----------------------- | --------------------- | ------------------- |
| พริก/สมุนไพร/เครื่องเทศ | ~50–60°C              | รักษาสี/สารสำคัญ    |
| ผัก/เห็ด                | ~45–60°C              | รักษาสี/วิตามิน     |
| กล้วย/มะม่วง/ผลไม้      | ~50–70°C              | รักษารส/สี (แปรรูป) |
| ข้าว (ลดความชื้น)       | ~40–50°C (ข้าวเปลือก) | ลดความชื้น ~14%     |
| อาหารทะเล/เนื้อ         | ~50–60°C              | ปลอดภัย/เก็บนาน     |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/อุณหภูมิ/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: ห้องเย็น/แช่เย็น (08-010 — อ้างข้าม), การแปรรูปขั้นสูง (12), มาตรฐาน GAP/HACCP ลึก (13), เครื่องอบอุตสาหกรรม (แก๊ส/ไฟฟ้า — เทียบเท่านั้น)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                            | ผลลัพธ์                                            | สถานที่/เงื่อนไข  | แหล่ง  |
| ------------------------------------ | -------------------------------------------------- | ----------------- | ------ |
| Losses หลังเก็บเกี่ยว (ผัก/ผลไม้ไทย) | ~15–40% (ช่วง — ขึ้นชนิด/ฤดู)                      | FAO/งาน           | [1][3] |
| ตู้อบโซลาร์ประหยัดเวลา/พลังงาน       | ~30–70% เทียบตาก/เตา (ช่วง)                        | งาน               | [2]    |
| อุณหภูมิอบเหมาะ                      | ~40–70°C (ช่วง — ขึ้นชนิด)                         | งาน               | [2][4] |
| ราคาตู้อบโซลาร์ (วิสาหกิจ)           | ~20,000–200,000 บาท (ช่วง — ขึ้นขนาด)              | ตลาด/ผู้ประกอบการ | [3]    |

- **กฎ**: "ตู้อบโซลาร์ = 'คุณภาพสม่ำเสมอ + ใช้แดดฟรี' — คุ้มสำหรับกลุ่ม/วิสาหกิจ (ผลผลิตเยอะพอ)" — "อุณหภูมิ = หัวใจ (อบผิด = เสียสี/สารอาหาร/ราคา) — ต้องอบตามชนิด (ตาราง 2.2)" — "ไฮบริดเมื่อแดดไม่พอ (ฝน/ฤดู — ต้องผลิตต่อเนื่อง)" — ตัวเลขช่วง — ตรวจหัวข้อ 10
- **หมายเหตุ**: ราคา/ตลาดเปลี่ยน — ตรวจอัปเดต

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดผลไม้อบแห้ง/อาหารอบแห้งโลก ~$5–10 พันล้านดอลลาร์/ปี (ช่วง — โต ~5–8%/ปี); ตลาดเครื่องอบแห้ง (ทุกพลังงาน) ~$10–20 พันล้าน/ปี (ช่วง); ไทย: วิสาหกิจ/OTOP/ส่งออก (กล้วยอบ/มะม่วง/พริก — มีตลาด) [3][4]
- **ผู้เล่นหลัก**: กลุ่มวิสาหกิจ/สตรี/สหกรณ์ (ผู้ผลิตอบแห้ง), ผู้ประกอบการตู้อบ (ไทย — ราคา/คุณภาพหลายระดับ), หน่วยงาน (กรมวิชาการ/ส่งเสริม — เทคโนโลยี), บริษัทแปรรูป/ส่งออก (มาตรฐาน 13), นักวิจัย (มก./มข./มจธ. — อุณหภูมิ/เซนเซอร์)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                           | ฉุดรั้ง                            |
| ------------------------------------ | ---------------------------------- |

| เพิ่มมูลค่า (อบแห้ง — ราคา 2–5 เท่า) | ต้นทุนตู้อบ (รายย่อยไม่ไหว)        |
| แดดไทยจัด (ฟรี)                      | คุณภาพไม่สม่ำเสมอ (ตาก — ฝุ่น/ฝน)  |
| มาตรฐานส่งออก (GAP/HACCP — 13)       | ความรู้อุณหภูมิเฉพาะผลผลิต (Q1)    |
| เทคโนโลยีเซนเซอร์/AI ราคาถูกลง       | การยอมรับ (14-003 — เทคโนโลยีใหม่) |

- **แนวโน้ม**: ตู้อบ "อัจฉริยะ" (เซนเซอร์/AI/รีโมต — 05/06-001 — คุณภาพคงที่), ไฮบริด (โซลาร์+ชีวมวล 08-003/ไฟฟ้า), ตู้อบเฉพาะผลผลิตไทย (อุณหภูมิโปรไฟล์ — งาน), การผูกตลาดส่งออก (13 — GAP/HACCP), ระบบกลุ่ม (สหกรณ์/วิสาหกิจ — ตู้อบกลาง)

## 6. สถานการณ์ประเทศไทย

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **Losses หลังเก็บเกี่ยวไทย 15–40%** — ตรวจ FAO/งาน (ระบุชนิด/ปี)
- [ ] **ประหยัดเวลา/พลังงาน 30–70%** — ตรวจงาน (ระบุตู้อบ/ผลผลิต)
- [ ] **อุณหภูมิอบ 40–70°C (ตามชนิด)** — ตรวจงาน (ระบุผลผลิต/โปรไฟล์)
- [ ] **ราคาตู้อบ 20,000–200,000 บาท** — ตรวจผู้ประกอบการไทย (ปี)
- [ ] **อบแห้งเพิ่มมูลค่า 2–5 เท่า** — ตรวจงาน/ตลาด (ระบุ)
- [ ] **เวลาอบลด 30–50%** — ตรวจงาน
- [ ] **ตลาดผลไม้อบแห้ง $5–10 พันล้าน/ปี** — ตรวจ analyst report ระบุปี
- [ ] **พลังงานที่ประหยัด 5–15 กิโลวัตต์ชั่วโมง/รอบ** — ตรวจงาน (ระบุขนาด)
- [ ] **สถานะตู้อบโซลาร์ไทย (กลุ่ม/วิสาหกิจ — ปัจจุบัน)** — ตรวจข่าว/รายงาน
- [ ] **งานอบแห้งไทย (มก./มข. — TCI/ThaiJo)** — ตรวจรายชื่อ (ระบุ)

## 11. อภิธานศัพท์

| คำศัพท์                | ความหมาย                                     |
| ---------------------- | -------------------------------------------- |
| Solar drying           | การอบแห้งด้วยพลังงานแสงอาทิตย์               |
| Open sun drying        | ตากแดดตรง (ถาด/ตาข่าย)                       |
| Greenhouse solar dryer | ตู้อบเรือนกระจกโซลาร์ (รับแดด+พัดลม)         |
| Hybrid dryer           | ตู้อบไฮบริด (โซลาร์+ไฟฟ้า/แก๊ส/ชีวมวล)       |
| Solar collector        | ตัวเก็บความร้อนจากแดด (แผงดูดซับ)            |
| Moisture content       | ความชื้นผลผลิต (%) — เป้าหมายการอบ           |
| Drying rate            | อัตราการอบแห้ง (ความชื้น/เวลา)               |
| Drying profile         | โปรไฟล์การอบ (อุณหภูมิ/เวลา/ชนิดผลผลิต)      |
| Airflow                | การไหลเวียนอากาศ (พัดลม — ลดเวลา)            |
| Post-harvest loss      | การสูญเสียหลังเก็บเกี่ยว (เหตุ = ถนอมไม่ทัน) |
| Value addition         | การเพิ่มมูลค่า (แปรรูป/อบแห้ง)               |
| GAP / HACCP            | มาตรฐานคุณภาพ/ความปลอดภัย (ส่งออก — 13)      |
| Dried fruit            | ผลไม้อบแห้ง (กล้วย/มะม่วง — ตลาด)            |
| Blanching              | การลวกก่อนอบ (รักษาสี/เอนไซม์)               |
| Dehydration            | การไล่ความชื้น (อบแห้ง)                      |
| วิสาหกิจ/OTOP          | กลุ่มผู้ประกอบการท้องถิ่น (ผู้ผลิตอบแห้ง)    |
| Shelf life             | อายุการเก็บ (อบแห้ง = ยาวขึ้น)               |
| กล้วยตาก/กล้วยอบ       | ผลิตภัณฑ์อบแห้งไทย (ตลาด/ส่งออก)             |
