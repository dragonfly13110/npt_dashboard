# สกัดผังการผสมสารป้องกันกำจัดศัตรูพืชบางชนิด

> ถอดจาก 2 หน้าท้ายของเอกสารวิชาการ **คำแนะนำการใช้สารป้องกันกำจัดศัตรูพืชจากงานวิจัย ปี 2568** โดยตารางระบุว่าเป็นเอกสารฉบับปรับปรุงเดือนสิงหาคม 2564

## ขอบเขตของไฟล์นี้

- ถอดรหัสสีของผังให้เป็นเครื่องหมายที่ค้นหาได้ใน Markdown
- ถอดคู่ผสมทั้งหมดที่อ่านสถานะได้จากช่องตาราง จำนวน **508 คู่**
- ระบุคู่ที่แถวต้นฉบับหายไปจากภาพ จำนวน **20 คู่** เป็น `NA` โดยไม่เดาผล
- ถอดหมายเหตุ 1 ถึง 23 และข้อควรระวังจากหน้ารองสุดท้าย
- ชื่อสารที่อยู่ในช่องเดียวกันเป็นกลุ่มตามต้นฉบับ ผลของช่องนั้นจึงเป็นผลระดับกลุ่ม ไม่ควรแยกตีความเกินกว่าที่ผังระบุ

## วิธีอ่านเครื่องหมาย

| เครื่องหมาย | สีในผัง         | ความหมาย                                                                  |
| ----------- | --------------- | ------------------------------------------------------------------------- |
| `+`         | ขาว             | ผสมกันได้                                                                 |
| `+!`        | น้ำเงิน         | ผสมกันได้ แต่ต้องระมัดระวัง                                               |
| `?`         | เขียว           | อย่าผสมจนกว่าจะได้รับคำรับรองจากผู้ผลิต                                   |
| `*n`        | ม่วง            | ดูรายละเอียดหมายเลข `n`                                                   |
| `0`         | เหลือง          | ไม่มีความจำเป็นต้องผสมกัน                                                 |
| `-`         | แดง             | ผสมกันไม่ได้                                                              |
| `NA`        | ไม่มีช่องข้อมูล | คู่ดังกล่าวอยู่ในแถวที่ชื่อและแถวถูกตัดออกจากภาพฉบับปี 2568 จึงไม่กำหนดผล |

> หมายเหตุ: กล่องคำอธิบายในหน้าปี 2568 แสดงสีแดงพร้อมข้อความ 2 สถานะติดกัน แต่ในช่องตารางมีทั้งสีเหลืองและสีแดง จึงแยกเป็น `0` และ `-` ตามผังฉบับเดิมที่ใช้ชุดสีเดียวกัน

## หมายเหตุทั่วไปจากหน้ารองสุดท้าย

### 17. สารฮอร์โมนพืช

สารควบคุมการเจริญเติบโตของพืชที่เป็นสารประกอบแนฟทาลีนแอซิติก แนฟทาลีนแอซิตาไมด์ และกลุ่ม phenoxy เช่น NAA ส่วนใหญ่เข้ากับสารกำจัดแมลงและสารป้องกันโรคพืชได้ ยกเว้นสารที่มีฤทธิ์เป็นด่างมาก หากจำเป็นให้แยกพ่นทีละชนิด หรือปฏิบัติตามคำแนะนำของผู้ผลิต

### 18. สารปฏิชีวนะ

- ให้ผลดีที่สุดเมื่อไม่ผสมกับสารอื่น
- สเตรปโตมัยซิน แอกริ-สเตรป และแอกริมัยซิน สามารถผสมกับไดเมโทเอต แคปแทน และซัลเฟอร์ชนิดผงได้
- ห้ามผสมกับบอร์โดมิกเจอร์ หรือสารที่มีฤทธิ์เป็นด่างมาก

### 19. ไวรัส NPV

NPV สามารถผสมกับสารกำจัดแมลงได้ทุกชนิด โดยเฉพาะสารที่มีประสิทธิภาพทำลายไข่ เช่น คลอร์ไดมีฟอร์มและเมโทมิล ตามข้อความในต้นฉบับ

### 20. แบคทีเรีย BT

BT หรือ _Bacillus thuringiensis_ โดยทั่วไปเข้ากับสารกำจัดแมลงและสารป้องกันโรคพืชได้ แต่ต้องผสมแล้วพ่นทันที ยกเว้นรายการต่อไปนี้

- อะมิทราซ
- อะซินฟอสเมทิล
- แคปทาโฟล
- ไดเมโทเอต
- ไดโนแคป
- ไอโซโพรคาร์บ
- เฟนโทเอต
- โฟซาโลน
- บอร์โดมิกเจอร์

### 21. หลีกเลี่ยงสภาพด่างจัด

อย่าผสมสารป้องกันกำจัดศัตรูพืชในสภาพด่างจัด รวมถึงการผสมกับปุ๋ยบางชนิดที่เมื่อละลายแล้วมีสภาพเป็นด่าง

### 22. ชื่อที่ใช้ในผัง

ชื่อสารในผังเป็นชื่อสามัญทั้งหมด ไม่ใช่ชื่อการค้า

### 23. สถานะของผัง

ผังนี้เป็นเอกสารรวบรวมข้อมูล ไม่ได้เป็นคำแนะนำให้ใช้โดยตรง การผสมบางคู่สามารถก่ออันตรายต่อมนุษย์ สัตว์ หรือพืชได้

## ข้อควรระวังจากต้นฉบับ

การเข้ากันได้ของสารอาจแตกต่างจากผัง เนื่องจากสูตรผลิตภัณฑ์ของแต่ละบริษัทแตกต่างกัน ต้องปฏิบัติตามฉลากและคำแนะนำของผู้ผลิตอย่างเคร่งครัด
