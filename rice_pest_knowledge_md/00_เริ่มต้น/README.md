# Knowledge Base: ศัตรูข้าวและการป้องกันกำจัด

คลังนี้ถอดจากเอกสารวิชาการ **ศัตรูข้าว และการป้องกันกำจัด** ของกองวิจัยและพัฒนาข้าว กรมการข้าว พิมพ์ครั้งที่ 1 พ.ศ. 2562 ซึ่งระบุจำนวนหน้าหนังสือ 220 หน้า และไฟล์ PDF ที่ได้รับมีรวม 221 หน้าเมื่อรวมปก/หน้าเอกสารต้นเรื่อง

## ขอบเขต

- แมลงและไรศัตรูข้าวนาสวน
- แมลงศัตรูข้าวไร่และข้าวสาลี
- การสำรวจ ติดตาม และระดับเศรษฐกิจของแมลงศัตรูข้าว
- โรคข้าว การวินิจฉัย และโรคข้าวที่สำคัญ
- ดัชนีสารป้องกันกำจัดโรคข้าวและบรรณานุกรม

## หลักการถอด

- ไม่สรุปหรือตัดเนื้อหาต้นฉบับ
- ทุกไฟล์ Markdown มี YAML Front Matter และบทความมี marker อ้างอิง PDF page/printed page
- ตารางต้นฉบับถูกจัดเป็น Markdown Table; ค่าตัวเลข หน่วย ชื่อสาร และเครื่องหมาย `*` คงตามต้นฉบับ
- คำบรรยายภาพถูกทำเครื่องหมายเป็น `ภาพประกอบ`
- ประเด็นที่ต้องตรวจสอบแยกไว้ใน `99_ระบบ/REVIEW_FLAGS.md` และท้ายบทความที่เกี่ยวข้อง
