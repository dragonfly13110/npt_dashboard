# REVIEW_FLAGS

## ต้องตรวจสอบกับต้นฉบับ/แหล่งปัจจุบัน

1. PDF metadata ระบุชื่อไฟล์เป็นอักขระ `????` แต่เนื้อหาและหน้าปกอ่านว่า **ศัตรูข้าว และการป้องกันกำจัด** จึงใช้ชื่อจากหน้าปกเป็นชื่อเอกสาร
2. หน้าบรรณานุกรมระบุ 220 หน้า ขณะที่ไฟล์ PDF รวม 221 หน้าเมื่อรวมปก/หน้าเอกสารต้นเรื่อง คงทั้งจำนวนจริงของ PDF และจำนวนที่ต้นฉบับพิมพ์ไว้
3. ตารางที่ 1 หน้าเอกสาร 13 ใช้แถบสีโดยไม่มี legend เป็นข้อความ จัดทำเป็น Markdown Table แบบบรรยายสีและคงคำเตือน ไม่แปลงสีเป็นช่วงตัวเลขใหม่
4. ตารางที่ 2-3 หน้าเอกสาร 34-36 เป็นรายการสาร/ตารางอัตราใช้ที่จัดรูปแบบใหม่เป็น Markdown Table โดยคงรายการ อัตรา หน่วย เครื่องหมาย `*` และหมายเหตุจากต้นฉบับ
5. ตารางสารหน้าเอกสาร 129-133 และดัชนีสารหน้าเอกสาร 211-217 คงอัตรา หน่วย PHI ชื่อสามัญ ชื่อการค้า และ `*` ตามต้นฉบับ ควรตรวจทะเบียน/ฉลากก่อนใช้จริง
6. หน้าเอกสาร 3 มีอักขระสัญลักษณ์ลิขสิทธิ์ที่ extraction อ่านเป็น `R` ในบางตำแหน่ง จึงคงข้อความที่ถอดได้และไม่เดาสัญลักษณ์
7. ฟอนต์ PDF ทำให้วรรณยุกต์บางตัวถูกอ่านเป็นรหัสอักขระพิเศษ ระบบ normalize เฉพาะรูปแบบที่เทียบกับภาพต้นฉบับได้ ส่วนที่ยังไม่แน่ใจไม่ได้แก้เป็นข้อเท็จจริงใหม่
