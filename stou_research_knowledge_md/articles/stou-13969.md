## 📌 1. งานนี้ทำอะไร (Research Overview & Scope)

งานศึกษาค้นคว้าอิสระนี้ศึกษาสถานการณ์ราคาทองคำแท่งของไทยและดัชนีตลาดหลักทรัพย์แห่งประเทศไทย (SET) วิเคราะห์ว่าทั้งสองตัวแปรมีความสัมพันธ์เชิงดุลยภาพระยะยาวหรือไม่ และใช้แบบจำลอง Vector Error Correction Model (VECM) เพื่อพยากรณ์ราคาทองคำแท่งรายเดือนตั้งแต่มกราคม 2568 ถึงธันวาคม 2569

บริบทของงานคือทองคำมักเป็นสินทรัพย์ปลอดภัยในช่วงวิกฤติหรือความไม่แน่นอน ขณะที่ตลาดหุ้นตอบสนองต่อการเติบโตทางเศรษฐกิจ นโยบายการเงิน การเมือง และความเสี่ยงโลก งานจึงเป็นการวิเคราะห์เศรษฐมิติจากข้อมูลอนุกรมเวลา ไม่ใช่งานสำรวจผู้ลงทุน

## 🎯 2. ทำเพื่ออะไร (Objectives & Purpose)

1. ศึกษาสถานการณ์ราคาทองคำแท่งและดัชนีหลักทรัพย์ในประเทศไทย
2. ศึกษาความสัมพันธ์ระหว่างราคาทองคำแท่งกับดัชนีหลักทรัพย์ในประเทศไทย
3. พยากรณ์ราคาทองคำแท่งของประเทศไทย

ผลที่คาดหวังคือช่วยให้นักลงทุน ภาครัฐ และภาคเอกชนใช้ข้อมูลแนวโน้มราคาและความสัมพันธ์ระหว่างตลาดเพื่อประกอบการวางแผน โดยต้องตีความเป็นการพยากรณ์ระยะสั้นถึงปานกลางภายใต้รูปแบบข้อมูลเดิม

## 🔬 3. วิธีดำเนินการวิจัยและการทดลอง

- **ประชากร/กลุ่มตัวอย่าง:** ไม่มีผู้ตอบแบบสอบถาม ใช้ข้อมูลทุติยภูมิอนุกรมเวลารายเดือนของราคาทองคำแท่งในประเทศ (gold) และดัชนีตลาดหลักทรัพย์ (set) ตั้งแต่มกราคม 2554 ถึงธันวาคม 2567 รวม **168 เดือน**
- **เครื่องมือ/แหล่งข้อมูล:** แบบบันทึกข้อมูลทุติยภูมิและโปรแกรมเศรษฐมิติ โดยใช้ข้อมูลราคาทองคำแท่งและดัชนี SET จากแหล่งข้อมูลตลาดการเงิน/หน่วยงานที่เกี่ยวข้อง
- **การทดสอบความหยุดนิ่ง:** Augmented Dickey-Fuller (ADF) unit root; ทั้ง gold และ set หยุดนิ่งเมื่อทำผลต่างอันดับที่ 1 หรือ I(1)
- **การกำหนดแบบจำลอง:** เลือก lag ของ VAR ด้วยเกณฑ์ Akaike Information Criterion (AIC) ได้ lag ที่เหมาะสมเท่ากับ 2 หรือ VAR(2)
- **ความสัมพันธ์ระยะยาว:** Johansen cointegration test ทั้ง Trace test และ Maximum eigenvalue test ที่ระดับความเชื่อมั่น 95%
- **การพยากรณ์:** ใช้ VECM จากระบบตัวแปรที่มี cointegration และพยากรณ์ล่วงหน้า 24 เดือน หรือ 8 ไตรมาส
- **การประเมินความแม่นยำ:** เปรียบเทียบค่าจริงกับค่าพยากรณ์ด้วยค่าสัมประสิทธิ์สหสัมพันธ์และ MAPE

## 📊 4. ผลการวิจัยเป็นอย่างไรแบบละเอียด

### 4.1 สถานการณ์ตลาด

ราคาทองคำแท่งไทยมีแนวโน้มเพิ่มขึ้นในช่วง 10 ปีที่ศึกษา โดยแรงหนุนสำคัญคือวิกฤติการเงิน การระบาดของ COVID-19 สงครามรัสเซีย-ยูเครน เงินเฟ้อ และความไม่แน่นอนของเศรษฐกิจโลก ซึ่งทำให้นักลงทุนย้ายเงินจากสินทรัพย์เสี่ยงมาถือทองคำ ขณะที่ SET มีความผันผวนสูงและเคลื่อนไหวตามการเติบโตทางเศรษฐกิจ สถานการณ์การเมือง ราคาน้ำมัน และดัชนีตลาดโลก

### 4.2 ผลการทดสอบความสัมพันธ์

- ADF พบว่า gold และ set เป็นอนุกรมเวลาที่มีอันดับความหยุดนิ่ง **I(1)**
- AIC เลือกแบบจำลอง VAR ที่มี lag **2**
- Johansen test พบ cointegrating vector **r = 1** ที่ระดับความเชื่อมั่น 95% จึงสรุปได้ว่าราคาทองคำแท่งและ SET มีความสัมพันธ์เชิงดุลยภาพระยะยาวร่วมกัน
- สมการระยะยาวระบุว่า หาก SET เพิ่มขึ้นร้อยละ 1 ราคาทองคำแท่งจะปรับลดลงประมาณ **ร้อยละ 45.929** ตามทิศทางความสัมพันธ์ที่ประมาณได้ในงาน
- ความเร็วในการปรับกลับเข้าสู่ดุลยภาพเมื่อเกิด shock อยู่ที่ประมาณ **ร้อยละ 3.7** และมีนัยสำคัญทางสถิติที่ระดับ 0.01

งานเลือกพยากรณ์เฉพาะ gold เนื่องจากตัวแปร SET ไม่ผ่านเงื่อนไขการ fix ที่ระดับ 0.05 แม้ทั้งสองตัวแปรยังมีความสัมพันธ์เชิงดุลยภาพระยะยาว

### 4.3 ผลการพยากรณ์

ค่าพยากรณ์รายเดือนที่สำคัญคือ ราคาทองคำแท่งเพิ่มจาก **43,011.01 บาท** ในเดือนมกราคม 2568 ไปสูงสุด **44,632.34 บาท** ในเดือนกันยายน 2568 และเพิ่มจาก **44,493.30 บาท** ในเดือนมกราคม 2569 ไปสูงสุด **46,051.70 บาท** ในเดือนกันยายน 2569 ก่อนอ่อนลงเล็กน้อยปลายปี

- ปี 2568 ไตรมาส 3 เป็นช่วงราคาสูงสุด ค่าเฉลี่ยไตรมาสตามบทที่ 4 อยู่ที่ประมาณ **44,438.39 บาท** และราคาสูงสุดรายเดือนอยู่ในกันยายน
- ปี 2569 ไตรมาส 3 เป็นช่วงราคาสูงสุด ค่าเฉลี่ยไตรมาสประมาณ **45,863.83 บาท** และราคาสูงสุดรายเดือนอยู่ในกันยายน
- เมื่อเทียบกับช่วงเดียวกันของปี 2567 ราคาปี 2568 เพิ่มขึ้นในไตรมาส 1-4 เท่ากับ **23.72%, 8.35%, 9.06% และ 3.61%** ตามลำดับ
- ราคาปี 2569 เพิ่มขึ้นในไตรมาส 1-4 เท่ากับ **27.94%, 11.92%, 12.55% และ 6.91%** ตามลำดับ
- การประเมินย้อนหลังให้ค่าสหสัมพันธ์ **r = 99.42%** และ **MAPE = 1.90%** สะท้อนว่าค่าพยากรณ์เคลื่อนไหวไปในทิศทางเดียวกับค่าจริงและมีความคลาดเคลื่อนเฉลี่ยต่ำในชุดข้อมูลทดสอบ

### 4.4 การแยกส่วนความแปรปรวน

ในระยะ 24 เดือน ความแปรปรวนของ gold อธิบายด้วย shock ของ gold เองประมาณ **57.9425-100.0000%** ส่วน shock จาก SET อธิบายได้ไม่เกิน **42.0575%** ขณะที่ความแปรปรวนของ SET อธิบายด้วยตัวมันเองประมาณ **76.86-96.0938%** และ shock จาก gold ไม่เกิน **23.14%** ดังนั้นราคาทองคำในแบบจำลองนี้ถูกขับเคลื่อนโดยความผันผวนของราคาทองคำเองมากกว่า SET

## 💡 5. ข้อเสนอแนะและการประยุกต์ใช้งาน

1. ใช้ผลพยากรณ์เพื่อวางแผนระยะสั้นและติดตามปัจจัยที่ทำให้ราคาทองคำเปลี่ยนเร็ว เช่น ดอกเบี้ย Fed เงินเฟ้อ ค่าเงินบาท ราคาทองคำโลก ราคาน้ำมัน และความขัดแย้งภูมิรัฐศาสตร์
2. ภาครัฐและภาคเอกชนควรสร้างความเชื่อมั่นต่อตลาดทุนและติดตามความเชื่อมโยงระหว่าง SET กับทองคำ เพื่อไม่ให้การเก็งกำไรหรือการตื่นตัวของราคาทองคำเพิ่มความเสี่ยงแก่ผู้ลงทุนโดยไม่ประเมินพื้นฐาน
3. นักลงทุนควรใช้ค่าพยากรณ์เป็นข้อมูลประกอบ ไม่ควรถือเป็นราคาที่รับรอง เพราะเหตุการณ์เศรษฐกิจ โรคระบาด และ shock ใหม่อาจทำให้รูปแบบในอดีตใช้ไม่ได้
4. งานวิจัยต่อไปควรเพิ่มตัวแปรภายนอก เช่น ราคาทองคำตลาดโลก อัตราแลกเปลี่ยน ราคาน้ำมัน อัตราดอกเบี้ย และตัวชี้วัดเศรษฐกิจระหว่างประเทศ รวมทั้งทดสอบช่วงวิกฤติแยกต่างหาก
