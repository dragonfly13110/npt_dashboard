# ชั้นถอดข้อความต้นฉบับตามหน้า PDF

โฟลเดอร์นี้เป็นชั้นความเที่ยงตรงของต้นฉบับ แยกหน้า PDF 1-90 ตามลำดับการอ่านจริง เพื่อให้ Full Text Search, Vector Database และ AI ตรวจกลับไปยังข้อความต้นฉบับได้โดยตรง

การแยกเป็นรายหน้าในโฟลเดอร์นี้ไม่ได้แทนการแบ่งบทความตามหัวข้อธรรมชาติในโฟลเดอร์อื่น แต่เป็นหลักฐานต้นทางสำหรับตรวจทวนตัวเลข หน่วย สูตร รหัส แบบฟอร์ม ตาราง และข้อความที่อาจอ่านจากภาพได้ไม่ครบ

- PDF page และ printed page แยกไว้ใน YAML และ source marker
- ไม่ปรับแก้ตัวเลขหรือคำนวณค่าจากต้นฉบับ
- หน้าที่เป็นภาพ/ตารางควรตรวจเทียบกับ PDF ภาพจริงก่อนนำไปใช้เป็นคำตอบเฉพาะกรณี
