## 1. บทสรุปผู้บริหาร

- **ใจความ**: สารละลายธาตุอาหาร = "ดินของระบบไฮโดรโปนิกส์" — ต้องคุม EC (ความเข้มข้นเกลือ) + pH + สัดส่วนธาตุ (N:P:K:Ca:Mg:S + ธาตุรอง) ให้ตรงช่วงของแต่ละพืช/แต่ละระยะ — ระบบปิดหมุนเวียนน้ำ (recirculating) ลดน้ำ/ปุ๋ย 20–40% แต่ต้องจัดการโรค (Pythium) และธาตุที่ตกค้าง [1][2][4]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (ระบบอัตโนมัติ EC/pH + สูตรสำเร็จมีทั่วโลก) / ⚗️ (เซนเซอร์ธาตุแบบ real-time ไอออน + AI ปรับสูตรอัตโนมัติยังพัฒนา)
- **ตัวเลขสำคัญที่สุด**: ผักกาดหอม EC 1.2–1.8 dS/m (pH 5.5–6.0), มะเขือเทศ 2.0–3.0 (pH 5.5–6.5), สตรอว์เบอร์รี 0.8–1.2 — ค่าเกินช่วง = ใบไหม้/ขาดธาตุ/รากเน่า; Fe ต้องใช้คีเลต (EDTA/DTPA/EDDHA) [1][3]
- **นัยต่อไทย**: ฟาร์มไทยส่วนใหญ่ใช้ปุ๋ยน้ำสำเร็จ/สูตรพื้นฐาน + วัด EC/pH ด้วยเครื่องมือมือถือ — โอกาส: เซนเซอร์ราคาถูก + แอปแนะนำสูตร (เชื่อม 04-005) ลดความผิดพลาด/โรคและเพิ่มคุณภาพผักส่งออก [5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (บางส่วน) / ⚗️ (อัตโนมัติเต็ม)

## 2. หลักการและขอบเขต

- **หลักการ**:
  - **ธาตุหลัก**: N (ไนเตรต/แอมโมเนียม), P, K, Ca, Mg, S — **ธาตุรอง/จุลธาตุ**: Fe, Mn, Zn, Cu, B, Mo (ต้องคีเลต Fe/Zn/Cu/Mn — pH ต่ำเก็บไว้ได้ดี)
  - **EC**: ความเข้มข้นรวมของเกลือ (dS/m หรือ mS/cm) — บอก "แรง" ของอาหาร; **pH**: ควบคุมการละลายธาตุ (pH 5.5–6.5 เหมาะสุด — ธาตุละลายได้ดี ไม่ตกตะกอน)
  - **การปรับตามระยะ**: ต้นกล้า (EC ต่ำ) → ระยะเจริญ (N สูง) → ระยะออกดอก/ผล (K สูง, N ลด); การปรับ EC สูงช่วงท้ายเพิ่มรสชาติ (มะเขือเทศ/สตรอว์เบอร์รี)
- **ระบบปิด (recirculating)**: น้ำที่รากไม่ใช้ → เก็บ/กรอง/ปรับ EC-pH → หมุนกลับ — ลดน้ำ/ปุ๋ย แต่สะสมธาตุส่วนเกิน/โรค (ต้องบำบัดน้ำ: UV, โอโซน, ทรายกรองช้า — slow sand filter มาตรฐานดัตช์) [2][4]
- **ขอบเขตที่ครอบคลุม**: สูตร/ค่า EC-pH รายพืช, อุปกรณ์ (ปั๊ม/หัวฉีด/เซนเซอร์/ตัวควบคุม), ระบบปิด-เปิด, โรค, แนวทางไทย
- **นอกขอบเขต**: โครงสร้างระบบ (04-003), AI รวมระบบ (04-005), ปุ๋ยแปลงเปิด (02-012), คุณภาพน้ำแหล่งใหญ่ (03-005)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                                  | แหล่ง  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 1930s–50s   | Hoagland solution (1938) — ฐานสูตรสารละลายจนทุกวันนี้                                                                                         | [1]    |
| 1960s–80s   | ระบบ NFT (Allen Cooper 1965), สูตร Cooper — การค้าในยุโรป/สหรัฐฯ                                                                              | [1]    |
| 1980s–2000s | ระบบหมุนเวียน + การบำบัดน้ำ (เนเธอร์แลนด์): ทรายกรองช้า/UV/โอโซน ลด Pythium                                                                   | [2][4] |
| 2000s–2010s | เซนเซอร์ EC/pH อัตโนมัติ + เครื่องผสมสารละลาย (dosing) มาตรฐานโรงเรือน; สูตรเฉพาะพืชแพร่                                                      | [1][3] |
| 2015–2025   | เซนเซอร์ไอออน (ISFET NO3/K) เริ่มใช้จริง; AI ปรับสูตรจากข้อมูลการเจริญ (เชื่อม 04-005); นโยบายดัตช์ "ปล่อยน้ำทิ้ง = 0" (2030) ผลักระบบปิดเต็ม | [2][4] |
| 2026–       | แนวโน้ม: เซนเซอร์ราคาถูก (แอปมือถือ), สูตร "เฉพาะพันธุ์+ฤดู" อัตโนมัติ, การวัดธาตุแบบไม่รบกวน (spectral)                                      | [3][4] |

- **เส้นแบ่ง**: การคุม EC/pH อัตโนมัติทำได้แล้ว — สิ่งที่ยังยากคือ "รู้ว่าต้นไม้ขาด/เกินธาตุไหน" (ต้องชำนาญ/เทคนิควิเคราะห์) และ "การบำบัดน้ำหมุนเวียนให้ปลอดโรคอย่างยั่งยืน"

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                      | ค่า/ผลลัพธ์                                                                    | เงื่อนไข                  | แหล่ง  |
| ------------------------------ | ------------------------------------------------------------------------------ | ------------------------- | ------ |
| EC ที่แนะนำ (dS/m)             | ผักกาดหอม 1.2–1.8 / มะเขือเทศ 2.0–3.0 / สตรอว์เบอร์รี 0.8–1.2 / โหระพา 1.5–2.0 | ช่วงโรงเรือน/ไฮโดรโปนิกส์ | [1][3] |
| pH ที่แนะนำ                    | 5.5–6.5 (ส่วนใหญ่) — สูงกว่า 7 → Fe/Mn ตกตะกอน                                 | ทั่วไป                    | [1]    |
| การลดน้ำ/ปุ๋ย (ระบบปิด)        | 20–40% เทียบระบบเปิด (น้ำทิ้ง)                                                 | งานดัตช์/สหภาพยุโรป       | [2][4] |
| N:P:K หลัก (ผักใบ)             | ~1:0.3:1.3 (ช่วง 150–250 ppm N)                                                | สูตรมาตรฐาน               | [1]    |
| การเพิ่มรสชาติ (EC สูงท้ายฤดู) | มะเขือเทศ/สตรอว์เบอร์รีหวานขึ้น (EC 3–4 ช่วงเก็บ)                              | งานสวน                    | [3]    |
| Pythium ในระบบหมุนเวียน        | ทรายกรองช้า/UV ลดการติดเชื้อ ~80–90% (งานแล็บ/แปลง)                            | งานเนเธอร์แลนด์           | [2][4] |
| ความแม่นยำเซนเซอร์ไอออน        | ISFET NO3/K แม่นยำ ±5–15% หลังปรับเทียบ (ยังมีข้อจำกัด)                        | งาน 2020–25               | [3]    |
| ราคาเซนเซอร์ EC/pH (ไทย)       | มือถือ ~500–3,000 บาท; ตัวควบคุมอัตโนมัติหลักหมื่นบาทขึ้น                      | ตลาดไทย                   | [6]    |
| ต้นทุนสารละลาย/ปุ๋ย            | ~2–5 บาท/กก. ผัก (ฟาร์มไทยขนาดกลาง)                                            | วิเคราะห์                 | [6]    |

- **กฎ**: ค่า EC/pH เป็น "ช่วง" ไม่ใช่จุดเดียว — ขึ้นกับพันธุ์/ฤดู/ระบบ/คุณภาพน้ำตั้งต้น (น้ำบาดาลเค็ม → ปรับ EC ยาก — เชื่อม 03-005)
- **เงื่อนไขสำคัญ**: คุณภาพน้ำตั้งต้น (EC ฐาน, เหล็ก, คลอรีน), การคีเลต Fe ที่ pH สูง, การเติมออกซิเจน (DO) — รากต้องการออกซิเจนในสารละลาย (อุณหภูมิสูงไทย → DO ต่ำ)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ปุ๋ย/สารละลายไฮโดรโปนิกส์โลก ~3–6 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 10–15%/ปี ตาม CEA [3]
- **ผู้เล่นหลัก**: ผู้ผลิตปุ๋ยน้ำ/ชุด (General Hydroponics, HydroGarden, Advanced Nutrients, Yara — สายไฮโดรโปนิกส์), ผู้ผลิตเซนเซอร์ (Hanna, Bluelab, Sentek, Sensirion, Priva/Netafim — ระบบ dosing เต็ม) [3][6]
- **การลงทุน**: ระบบ dosing อัตโนมัติ ~1–5 แสนบาท/โรงขนาดกลาง (ไทย — ยังไม่ยืนยัน); เซนเซอร์มือถือหลักพันบาท — เริ่มต้นถูก
- **แนวโน้ม**: การสั่งผสมสูตรจากแอป/ระบบคลาวด์ (เชื่อม 04-005), เซนเซอร์ไอออนราคาลง, "น้ำทิ้ง = 0" (กฎหมาย EU/ดัตช์) บังคับระบบปิดในโรงเรือนส่งออก
- **ความหมายต่อไทย**: ฟาร์มส่งออก (สิงคโปร์/EU) จะถูกบังคับมาตรฐานการปล่อยน้ำ/การใช้ปุ๋ย — ระบบปิด + บันทึกข้อมูลคือข้อได้เปรียบ (และข้อบังคับอนาคต)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ฟาร์มผักสลัดไทยส่วนใหญ่ใช้ปุ๋ยน้ำสำเร็จ (หลายแบรนด์ในประเทศ) + วัด EC/pH มือถือเป็นครั้งคราว; ระบบอัตโนมัติมีในฟาร์มกลาง-ใหญ่/ส่งออก; การหมุนเวียนน้ำยังน้อย (ส่วนใหญ่ระบบเปิด-ปล่อยทิ้ง) [6]
- **ปัญหาที่พบบ่อยไทย**: pH ของน้ำประปา/บ่อสูง (>7.5 — ต้องปรับด้วยกรด), น้ำบาดาล EC สูง/เหล็ก (เชื่อม 03-005), อุณหภูมิน้ำร้อนกลางวัน → ออกซิเจนต่ำ/รากเน่า, การใช้สูตรเดียวตลอดรอบ (ไม่ได้ปรับตามระยะ) [5][6]
- **งานวิจัยไทย**: มีงานสูตรธาตุอาหารผักสลัดไทย (มก./มข./มอ. — EC/pH ที่เหมาะ) — ยังไม่ครอบคลุมทุกพันธุ์/ฤดู [5]
- **โอกาส**: (1) แอป/เซนเซอร์ราคาถูกช่วยฟาร์มเล็ก (2) การทำ "บันทึกข้อมูลสารละลาย" เป็นหลักฐาน GAP/ส่งออก (3) ระบบปิดสำหรับฟาร์มในพื้นที่น้ำจำกัด/ค่าไฟต่ำ
- **อุปสรรค**: ความรู้/ทักษะ (EC/pH ยังเป็นเรื่องไกลตัวเกษตรกร), ต้นทุนระบบอัตโนมัติ, ความเชื่อถือเซนเซอร์ราคาถูก

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ช่วง EC/pH ที่เหมาะกับพันธุ์สลัดที่นิยมไทย ณ อุณหภูมิน้ำ 30–35°C — งานไทยมีแต่ช่วงอุณหภูมิปกติ
- **Q2**: ผลของการเติมออกซิเจน (DO) ในน้ำร้อนไทยต่อราก/ผลผลิต — งานต่างชาติมี (DO ในเขตร้อน) งานไทยยังน้อย
- **Q3**: เศรษฐศาสตร์ "ระบบปิดหมุนเวียน" ในฟาร์มไทย (ประหยัดน้ำ/ปุ๋ย vs ค่าอุปกรณ์/ไฟ) — ยังไม่มี
- **Q4**: การบำบัดน้ำหมุนเวียนราคาไม่แพง (ทรายกรองช้า/UV ราคาถูก) สำหรับฟาร์มไทย — ยังไม่มี
- **Q5**: เซนเซอร์ไอออนราคาถูกในน้ำไทย (ความกระด้าง/เหล็กสูง) — ยังไม่มีงาน
- **Q6**: การเพิ่มรสชาติ/คุณภาพผักสลัดไทยด้วยการปรับ EC ท้ายรอบ (ตลาดพรีเมียม) — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                 | ระดับนโยบาย                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ฟาร์มนำร่อง 10 แห่ง: เซนเซอร์ EC/pH มือถือ/ติดตั้ง + แอปบันทึก + คู่มือสูตรรายพืชไทย; ปรับน้ำตั้งต้น (กรด/กรองเหล็ก) | คู่มือมาตรฐาน "EC/pH รายพืชไทย" (ร่วม มก./AIC); การอบรมกลุ่ม                  |
| 2 (2–4 ปี) | ระบบ dosing อัตโนมัติ + บันทึกข้อมูลในฟาร์มส่งออก (หลักฐาน GAP/ย้อนกลับ); ระบบปิดหมุนเวียนในพื้นที่น้ำจำกัด          | มาตรฐานการปล่อยน้ำ/การใช้ปุ๋ย CEA (เทียบเคียง EU); เงินช่วยเหลือเซนเซอร์      |
| 3 (4+ ปี)  | เซนเซอร์ไอออน + AI ปรับสูตรอัตโนมัติ (เชื่อม 04-005) — "โรงเรือนไทยรู้ธาตุทุกวัน"; การรับรอง "ผักผลิตด้วยข้อมูล"     | นโยบาย "น้ำทิ้ง = 0" ไทย (ระดับส่งออก); ฐานข้อมูลกลางสูตร/คุณภาพน้ำรายภูมิภาค |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย           | รายละเอียด                                    | โอกาสแก้                             |
| -------------------- | --------------------------------------------- | ------------------------------------ |
| ความรู้/ทักษะ        | ฟาร์มเล็กไม่เข้าใจ EC/pH/สูตร                 | แอป/คู่มือ/อบรม/บริการตรวจ           |
| น้ำตั้งต้นไม่ดี      | น้ำบาดาล EC สูง/เหล็ก/กระด้าง (เชื่อม 03-005) | กรอง/RO/ปรับกรด — วิเคราะห์น้ำก่อน   |
| อุณหภูมิน้ำร้อน      | DO ต่ำ/รากเน่าในไทย                           | ถังเย็น/เติมอากาศ/หมุนเวียนกลางคืน   |
| ต้นทุนระบบอัตโนมัติ  | หลักหมื่น–แสนบาท                              | เริ่มมือถือ → ค่อยขยับ, กลุ่มซื้อ    |
| ความเชื่อถือเซนเซอร์ | เซนเซอร์ราคาถูกเพี้ยน                         | เทียบมาตรฐาน/ปรับเทียบ (calibration) |
| โรคในระบบปิด         | Pythium กระจายเร็วผ่านน้ำหมุนเวียน            | กรอง/UV/โอโซน/สุขอนามัย              |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ค่า EC/PpH รายพืช (ตาราง)** — ตรวจเอกสารมาตรฐาน (Yara/General Hydroponics/งานวิชาการ) 2025–26
- [ ] **ระบบปิดลดน้ำ/ปุ๋ย 20–40%** — ตรวจงานดัตช์ (WUR/GreenQ) — ระบุระบบ
- [ ] **ทรายกรองช้า/UV ลด Pythium 80–90%** — ตรวจงาน (Wageningen/งาน EU)
- [ ] **ISFET ±5–15%** — ตรวจงานเซนเซอร์ไอออน 2023–25
- [ ] **ตลาดปุ๋ยไฮโดรโปนิกส์ 3–6 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **ราคาเซนเซอร์/ระบบไทย** — ตรวจผู้จำหน่ายไทย (มือถือ/อัตโนมัติ)
- [ ] **ต้นทุนสารละลาย 2–5 บาท/กก.** — ตรวจ/ปรับจากฟาร์มไทยจริง
- [ ] **กฎหมาย EU/ดัตช์ น้ำทิ้ง 0** — ตรวจสถานะล่าสุด (Green Deal/directive)

## 11. อภิธานศัพท์

| คำศัพท์           | ความหมาย                                         |
| ----------------- | ------------------------------------------------ |
| EC (dS/m)         | ความเข้มข้นเกลือรวมในสารละลาย                    |
| pH                | ความเป็นกรด-ด่าง (ควบคุมการละลายธาตุ)            |
| ไนเตรต/แอมโมเนียม | รูป N ที่พืชใช้ (NO3-/NH4+)                      |
| คีเลต (Chelate)   | การหุ้มธาตุ (Fe-EDTA/DTPA) ให้ละลายได้ที่ pH สูง |
| Dosing            | การฉีด/ผสมสารละลายตามสูตร                        |
| Recirculating     | ระบบน้ำหมุนเวียน (ปิด)                           |
| Pythium           | ราโรคเน่ารากในระบบไฮโดรโปนิกส์                   |
| Slow sand filter  | ทรายกรองช้า — บำบัดน้ำหมุนเวียน (ดัตช์)          |
| ISFET             | เซนเซอร์ไอออน (วัด NO3/K ในน้ำได้)               |
| DO                | ปริมาณออกซิเจนละลายน้ำ                           |
