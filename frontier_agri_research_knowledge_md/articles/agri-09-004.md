## 1. บทสรุปผู้บริหาร

- **ใจความ**: IMTA (Integrated Multi-Trophic Aquaculture) = เลี้ยง "สปีชีส์กินอาหาร (fed)" เช่น ปลา/กุ้ง ร่วมกับ "สปีชีส์เก็บกู้ (extractive)" คือ หอยสองฝากรองกินเศษอาหาร/อุจจาระ (organic extractive) + สาหร่ายดูดซับไนโตรเจน/ฟอสฟอรัสที่ละลายน้ำ (inorganic extractive) + ตัวกินตะกอน (detritivore — ปลานิล/ปลาดุกในน้ำจืด, ปลิงทะเล/เม่นทะเล/หนอนโพลีคีทในทะเล) — ของเสียของตัวหนึ่งกลายเป็นอาหารของอีกตัว → ลดของเสียลงน้ำ เพิ่มผลผลิตต่อพื้นที่และกระจายรายได้ [1][16][19]
- **ขั้นพัฒนา**: 🧪 นำร่องแปลงทดลองเป็นหลัก (งานวิจัย+แปลงสาธิต) — ข้อยกเว้นคือจีน (อ่าวซังโกว เลี้ยงเชิงพาณิชย์เต็มรูปแบบมา 4 ทศวรรษ แต่เน้นระบบหอย+สาหร่าย); แคนาดา/สกอตแลนด์เริ่ม IMTA เชิงพาณิชย์ขนาดเล็กแล้ว; นอร์เวย์/ชิลี/ไอร์แลนด์อยู่ช่วงสาธิต+วิจัย [1][5][11][25]
- **ตัวเลขสำคัญที่สุด**: (1) อ่าวซังโกว จีน — ฟาร์ม IMTA ~100 ตารางกม. ผลิต >240,000 ตัน/ปี จาก >30 ชนิด (เชิงพาณิชย์จริง); (2) อัตราส่วนหอย:สาหร่าย 1:1 / 4:2 ลดฟอสเฟต (PO4-P) ลง 75% ในการทดลอง enclosure 2025; (3) ทฤษฎี 4 สปีชีส์ (ปลา–หอย–สาหร่าย–ตัวกินตะกอน) กัก N/P/C จากอาหารได้ 79–94% แต่ในทางปฏิบัติระบบปิด 45–75% / ระบบเปิด 40–50% — "ลดของเสีย" ต้องตั้งเป้าเป็นช่วงนี้ ไม่ใช่ 100% [1][4][10]
- **นัยต่อไทย**: ไทยมีฐานงานวิจัย IMTA ในบ่อกุ้ง/ปลาอยู่แล้ว (ปลานิล+กุ้ง: กรมประมง 2564 รายงานกำไร 21,733.83 บาท/ไร่ ROI 59.93%; งานกลุ่มเกษตรกร IRR 82.05% คืนทุน ~1 ปี 5 เดือน) — จุดติดขัดคือการขยายเชิงพาณิชย์/มาตรฐานสปีชีส์/ตลาดรองรับผลผลิตเสริม (สาหร่าย/หอย) มากกว่าเทคโนโลยี [15][18][26]
- **สถานะโดยรวม**: 🧪 นำร่องแปลงทดลอง (จีน 📈 เชิงพาณิชย์มานาน — ระบบหอย+สาหร่าย)

## 2. หลักการและขอบเขต

- **หลักการทำงาน (แนวคิด "ของเสีย = ทรัพยากร")**: สปีชีส์หลัก (fed) ได้อาหารเสริมจากมนุษย์ → ปล่อยของเสีย 2 รูปแบบ: (ก) **อนุภาคแขวนลอย** (อาหารเหลือ+อุจจาระ) — ถูกกรองโดยหอยสองฝา (หอยแมลงภู่/หอยนางรม/หอยแครง) หรือกินโดยปลา/ตัวกินตะกอน (ปลานิล/ปลาดุก/ปลิงทะเล) (ข) **ธาตุอาหารละลายน้ำ** (N-P ที่ขับถ่ายทางเหงือก/ปัสสาวะ) — ถูกดูดซับโดยสาหร่ายทะเล/พืชน้ำ การเก็บเกี่ยวสาหร่ายและหอยจึง "ดึงธาตุอาหารออกจากระบบ" เทียบเท่าการบำบัดน้ำเสียแบบมีรายได้ [1][16]
- **ข้อเท็จจริงสำคัญเชิงตัวเลข**: อาหารปลาแซลมอนที่ให้ไปมีสัดส่วน C 62% / N 57% / P 76% ไม่ถูกใช้โดยปลาและปล่อยลงทะเล (คำนวณจากอุตสาหกรรมนอร์เวย์ปี 2023 = ปล่อย C 588,000 ตัน / N 66,000 ตัน / P 22,000 ตัน) — เป็นที่มาของแรงจูงใจ IMTA ในระดับชาติ [9]
- **การออกแบบต้องสมดุล "สัดส่วน"**: อัตราส่วนสปีชีส์ (เช่น หอย:สาหร่าย 1:1, 2:1, 4:2) กำหนดทั้งประสิทธิภาพดูดธาตุอาหารและความเสี่ยง (สาหร่ายมากเกินไป→แย่งธาตุอาหาร; หอยมากเกินไป→ออกซิเจนต่ำ/พีเอชตก) — งานอ่าวซังโกวพบอัตรา 2:1 ถึง 4:3 เป็น "อ่างคาร์บอนสุทธิ" ที่ดีที่สุด [4][24]
- **ขอบเขตที่ครอบคลุม**: IMTA ทุกรูปแบบ (ทะเลเปิด/บ่อดิน/ระบบปิด-BFT), กรณีศึกษาจีน/แคนาดา/นอร์เวย์/ชิลี/ไทย, ตัวเลขประสิทธิภาพ, เศรษฐศาสตร์, นโยบาย
- **นอกขอบเขต**: RAS ระบบหมุนเวียนปิด (ไฟล์แยก — เปรียบเทียบได้), สาหร่าย/บลูคาร์บอนเชิงลึก (ไฟล์แยก), โภชนศาสตร์อาหารสัตว์น้ำ, การประมงทะเลจับตามธรรมชาติ

## 5. ตลาดและการลงทุน

- **ขนาดตลาด (บริบท)**: การเพาะเลี้ยงสัตว์น้ำโลก 130.9 ล้านตัน มูลค่า ~312.8 พันล้าน USD (2022, FAO) [21]; ตลาดสาหร่ายโลก ~36.3 ล้านตัน/17 พันล้าน USD (2021) คาดโตเป็น 85 พันล้าน USD ภายใน 2026 (UNCTAD/GMI — ตัวเลขคาดการณ์ ใช้เทียบเคียงทิศทาง) [22]; ส่งออกผลิตภัณฑ์สาหร่ายปี 2023 = 819,100 ตัน มูลค่า 3.21 พันล้าน USD [23]; ยังไม่มีสำนักใดวัด "มูลค่าตลาด IMTA" โดยตรง — ยังไม่มีข้อมูล
- **ผู้เล่นหลัก**: จีน (การผลิต IMTA รายใหญ่สุดโลก — ระบบอ่าว/รัฐ); แคนาดา — Cooke Aquaculture (IMTA เชิงพาณิชย์ NB), DFO/St. Andrews, ม.นิวบรันสวิก, เครือข่าย CIMTAN; นอร์เวย์ — Cermaq+Folla Alger (ฟาร์ม AURORA 2022–27), Hortimare/Salmon Group, SINTEF; ชิลี — อุตสาหกรรมแซลมอน+หอยแยกกัน "เกิด IMTA โดยปริยาย" ตามภูมิทัศน์; ไทย — ยังไม่มีผู้ประกอบการ IMTA เชิงพาณิชย์ (มีงานวิจัย/แปลงทดลอง) [5][12][25]
- **การลงทุน/เงินทุน**: EU Horizon (SEAFOODTOMORROW — สาธิตเชิงพาณิชย์นอร์เวย์, TRL 6), โครงการ AURORA IMTA (นอร์เวย์), เงินกองทุน Atlantic Innovation Fund (แคนาดา), NSERC-CIMTAN; การลงทุนเอกชนส่วนใหญ่ยังผ่าน "บริษัทปลาใหญ่เดิม" (Cooke/Cermaq) เพราะต้นทุนโครงสร้างซ้ำซ้อนใช้ร่วมได้ [5][11][25]
- **ปัจจัยขับเคลื่อน**: กฎระเบียบสิ่งแวดล้อม/ใบอนุญาตเข้มงวดขึ้น (แคนาดาสู่ระบบปิด/ลดมลภาวะ), ความต้องการ premium/ฉลากยั่งยืน (WTP +10% มีหลักฐานแคนาดา), นโยบาย Blue Economy/BCG, คาร์บอน/เครดิตธาตุอาหาร (nutrient credit — แบบอย่าง Chesapeake Bay), การกระจายความเสี่ยงราคา/โรค (การมีหลายผลผลิต) [6][7][29]
- **ปัจจัยฉุดรั้ง**: ตลาดสาหร่ายมูลค่าต่ำ/ยังไม่มีผู้ซื้อประจำในตะวันตก, กฎหมายออกใบอนุญาตแบบรายสปีชีส์, ความซับซ้อนการจัดการ/แรงงานเฉพาะทาง, ต้นทุนเริ่มต้นสูง, การวัดผลไม่มีมาตรฐาน (LCA ยังไม่ตกลง allocation) [27][29]

## 6. สถานการณ์ประเทศไทย

- **งานวิจัยไทย (มีจริงหลายชิ้น)**: (1) กุ้ง+ปลานิล — กรมประมง 2564: กำไร 21,733.83 บาท/ไร่ ROI 59.93%; งานกลุ่มเกษตรกร (Suwimol 2011): IRR 82.05% คืนทุน ~1 ปี 5 เดือน (ลดต้นทุนอาหารเพราะปลานิลกินอาหารเหลือ/แพลงก์ตอน) [15]; (2) ระบบหมุนเวียนกุ้ง-ปลานิล-สาหร่าย (Attasat): กัก N จากอาหารได้ 88% [18]; (3) ม.สงขลานครินทร์ — สาหร่ายมงกุฎหนาม (Acanthophora spicifera) + หอยแมลงภู่ (Perna viridis) บำบัดน้ำทิ้งกุ้งขาว (วิทยานิพนธ์ 2553) [17][16]; (4) ม.บูรพา — ระบบปิด+สาหร่ายช่อพริกไทย (Caulerpa) บำบัดไนโตรเจนรวม 34–51% และเพิ่มผลผลิตกุ้งกุลาดำ +52% ที่ 120 วัน [16]; (5) ม.เกษตรศาสตร์ — ระบบฟาร์มผสมผสานตามแนวเศรษฐกิจพอเพียง (กุ้งกุลาดำ+ปลากะพง+ปลาทับทิม+หอยแมลงภู่+แพสาหร่าย ใน 2 ไร่: ปลากะพง 270.5 กก. + ปลาทับทิม 535.0 กก. + กุ้ง 57.4 กก.) [27]; (6) แบบจำลองระดับประเทศ (Ferreira et al. 2015 ร่วมมือไทย): จำลอง IMTA กุ้ง-ปลานิล-สาหร่าย Ulva ลด NH4 ออกจากระบบได้จาก 20.5 → 0.32 กก./รอบ [26]
- **สาหร่ายบำบัดน้ำทิ้งไทย**: ฐานข้อมูลดีมาก — Caulerpa sertularioides กำจัด NH4-N 49.9% / NO3-N 103% / PO4-P 41.4%; Gracilaria fisheri ลดแอมโมเนีย 59–89%; Ulva intestinalis ลด TAN 98.9% / ไนเตรต 97.6% (งานไทย 2543–2563) [17]
- **ภาคเอกชน/สตาร์ทอัพไทย**: ยังไม่มีบริการ/ผลิตภัณฑ์ IMTA เชิงพาณิชย์ — มีบริษัทสาหร่าย/อาหารสัตว์น้ำใช้ประโยชน์ได้ (ดู 14-สตาร์ทอัพ AgTech) [15]
- **โครงสร้าง/นโยบาย**: พระราชบัญญัติการประมง พ.ศ. 2558 (ใบอนุญาตเพาะเลี้ยงสัตว์น้ำ — ออกตามชนิด/แปลง ทำให้ "หลายสปีชีส์ในบ่อเดียว" มีช่องว่างกฎหมาย), นโยบาย BCG/Blue Economy เอื้อ แต่ยังไม่มีมาตรฐาน IMTA ไทย, ตลาดผลผลิตเสริม (สาหร่าย/หอยในบ่อ) ยังไม่มีช่องทางรับซื้อชัดเจน — จุดนี้อาจขวางการขยายมากกว่าเทคโนโลยี [15][29]

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: สัดส่วนการปล่อย (stocking ratio) ที่เหมาะสมสำหรับชุดสปีชีส์ไทย (กุ้ง+ปลานิล+หอย+สาหร่าย ต่อบ่อ 1 ไร่) พร้อม ROI จริงหลายรอบปี — ยังไม่มีชุดข้อมูลมาตรฐาน
- **Q2**: การวัด "ประสิทธิภาพลดของเสีย" ของบ่อ IMTA ไทยด้วยวิธีเดียว (nutrient retention/balance) — ยังใช้หลายวิธีเทียบกันไม่ได้
- **Q3**: ตลาดและการยอมรับผลผลิตเสริม (สาหร่าย/หอย/ปลานิลจากบ่อกุ้ง) — มีงานความเต็มใจจ่าย (WTP) ของผู้บริโภคไทยหรือไม่? ยังไม่มีข้อมูล
- **Q4**: บทบาท IMTA ต่อการลดโรค/การบริหารจัดการฟาร์ม (เช่น EMS, การไม่ถ่ายน้ำ) — หลักฐานเชิงปริมาณยังอ่อนในไทย
- **Q5**: เศรษฐศาสตร์ IMTA ทะเลเปิด (กระชังปลาทะเลไทย + หอย/สาหร่าย) ตามแนวชายฝั่งอันดามัน/อ่าวไทย — ยังไม่มีงาน
- **Q6**: มาตรฐาน/กฎหมาย "ใบอนุญาตหลายสปีชีส์" และการรวม IMTA ในแผนการจัดการพื้นที่ชายฝั่ง (และคาร์บอนเครดิตทางทะเล) — ยังไม่มีข้อสรุป

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **งาน "Nature Communications 2017 อ่าวซังโกว" (หอย+สาหร่าย+ปลา)** — ยังไม่พบงานดังกล่าวโดยตรง; งานปี 2017 ที่ตรงที่สุดคือ Xiao et al. 2017 (Scientific Reports — สาหร่ายขนาดใหญ่ดึงธาตุอาหารจากน้ำชายฝั่งจีน) และ Fang et al. 2016 (Aquaculture Environment Interactions) — ตรวจสอบซ้ำว่ามีงาน Nature Communications จริงหรือไม่

- [ ] **IRR 82.05% / คืนทุน 1 ปี 4 เดือน 29 วัน (Suwimol 2011)** — ตรวจงานต้นฉบับ (กลุ่มเกษตรกรที่ไหน/กี่บ่อ/ปีไหน)

- [ ] **สาหร่ายดูดซับ DIN ได้ ~2/3 ของของเสียจากแซลมอน (Wang et al. 2013)** — ตรวจรายละเอียด/ข้อจำกัดการจำลอง
- [ ] **ปลิงทะเล/เม่นทะเลช่วยลดตะกอนใต้กรง (BC แคนาดา)** — ยังเป็นงานแบบจำลองชีวเศรษฐศาสตร์ ยังไม่มีการวัดภาคสนามระยะยาว — ตรวจอัปเดต

## 11. อภิธานศัพท์

| คำศัพท์                       | ความหมาย                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------- |
| IMTA                          | Integrated Multi-Trophic Aquaculture — เลี้ยงหลายระดับอาหารร่วมกันให้ของเสียหมุนเวียนใช้ |
| Fed species                   | สปีชีส์ที่ต้องให้อาหาร (ปลา/กุ้ง) — แหล่งของเสียหลักของระบบ                              |
| Organic extractive            | สปีชีส์กรอง/กินอนุภาคอินทรีย์ (หอยสองฝา, ปลานิล, ปลิงทะเล)                               |
| Inorganic extractive          | สปีชีส์ดูดซับธาตุอาหารละลายน้ำ (สาหร่ายทะเล, พืชน้ำ)                                     |
| Detritivore                   | ตัวกินตะกอน/เศษอินทรีย์ (ปลาดุก, ปลิงทะเล, เม่นทะเล, โพลีคีท)                            |
| DIN/DIP                       | ธาตุไนโตรเจน/ฟอสฟอรัสที่ละลายน้ำ (ของเสียหลักจากปลา/กุ้ง)                                |
| Nutrient retention efficiency | % ธาตุอาหารจากอาหารที่ถูกกักไว้ในผลผลิตของระบบ                                           |
| Nutrient credit               | กลไกให้ค่าตอบแทนการดึงธาตุอาหารออกจากแหล่งน้ำ (แบบอย่าง: Chesapeake Bay)                 |
| BFT / Biofloc                 | ระบบน้ำเขียวจุลินทรีย์ — ฐานที่รวม IMTA กับกุ้ง-ปลานิล-สาหร่ายได้                        |
| TSS                           | ของแข็งแขวนลอยทั้งหมด — ตัวชี้วัดของเสียที่ IMTA ช่วยควบคุม                              |
| FCR                           | อัตราแลกเนื้อ (อาหารที่ใช้ต่อเนื้อที่เพิ่ม) — IMTA ช่วยลด FCR รวม                        |
| WTP / Premium price           | ความเต็มใจจ่าย/ราคาพรีเมียมของสินค้าฉลากยั่งยืน                                          |
| Carrying capacity             | ขีดความสามารถรองรับของแหล่งน้ำ/บ่อต่อการเลี้ยงชนิด/ปริมาณหนึ่ง                           |
| TRL                           | Technology Readiness Level — ระดับความพร้อมเทคโนโลยี (6 = สาธิตเชิงพาณิชย์)              |
