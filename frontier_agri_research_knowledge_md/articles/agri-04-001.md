## 1. บทสรุปผู้บริหาร

- **ใจความ**: Vertical farm/Plant factory (VF/PF) ผลิตผักใบได้ 30–50 เท่าต่อพื้นที่/ปี เทียบแปลงกลางแจ้ง ใช้น้ำ ~95% น้อยกว่า ไม่ใช้ยาฆ่าแมลง [1][6] — แต่ **หน่วยเศรษฐศาสตร์ยังเปราะบาง**: ต้นทุน CAPEX สูง (หลายหมื่นล้านบาทต่อโรงขนาดใหญ่), พลังงาน 25–40% ของ OPEX, กำไรจริงเกิดได้เฉพาะผักใบราคาสูง/ตลาดเฉพาะ (เช่น สิงคโปร์ ญี่ปุ่น เอมิเรตส์) [2][3][4]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้วในกลุ่มผักใบ (leafy greens) — ยังขาดทุน/เพิ่งคุ้มทุนหลายราย; ผลไม้/เบอร์รี่ใน VF ยังเป็น frontier (Plenty×Driscoll สตรอว์เบอร์รี — ยังไม่พิสูจน์กำไร) [3][5]
- **ตัวเลขสำคัญที่สุด**: อัตราการล้มละลาย/หดตัว 2022–2024 สูง (AeroFarms Chapter 11 มิ.ย. 2023, Kalera ล้ม 2022, Infarm ถอนตัวยุโรป, Bowery ลดพนักงาน) [3][4]; ผักใบเป็น "ธุรกิจต้นทุนไฟ + ค่าแรง + ค่าเสื่อม" ที่ต้องขายให้ได้ราคาสูงกว่าตลาดกลางแจ้งหลายเท่า
- **นัยต่อไทย**: ผักไฮโดรโปนิกส์ไทย (กลางแจ้ง/โรงเรือนมุ้ง) คุ้มกว่า VF ระดับเมืองมาก — VF ไทยควรเป็นโมเดล "ผักพรีเมียมใกล้ตลาดกรุงเทพฯ" + การตลาดตรง (ร้านสลัด/โรงแรม) ไม่ใช่แข่งขันราคากับผักตลาด (ดู [04-006](เจาะลึก-04-ผักไฮโดรโปนิกส์และPlantFactoryไทย.md))
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (กลุ่มผักใบ) / ⚗️-🏭 กำลังพิสูจน์ (ผลไม้/เบอร์รี)

## 2. หลักการและขอบเขต

- **หลักการ**: ปลูกในอาคารปิดหลายชั้น (vertical racks) แสง LED เต็มสเปกตรัม น้ำ/สารละลายหมุนเวียน ควบคุมอุณหภูมิ/ความชื้น/CO2 — "สภาพแวดล้อมสมบูรณ์ควบคุมได้" ทำให้ผลผลิต/ตร.ม. สูงมากและคงที่ตลอดปี
- **โครงสร้างต้นทุนหลัก** (ต้องเข้าใจก่อนวิเคราะห์): CAPEX (อาคาร+ชั้นวาง+LED+HVAC ~60–70% ของเงินลงทุน) และ OPEX (ไฟ 25–40%, แรงงาน 15–30%, ค่าเสื่อม 15–25%, น้ำ/สารละลาย 2–5%, ค่าเช่า/อื่นๆ 10–15%) [2][4]
- **โมเดลรายได้**: ขายผักพรีเมียม (ราคา 2–4 เท่าผักธรรมดา), สัญญาระยะยาวกับร้านอาหาร/ซูเปอร์มาร์เก็ต (CPG deals เช่น Plenty×Walmart×Kroger), บริการ "Grow as a Service", ขายคาร์บอน/น้ำที่ประหยัด (Brand value) [3][5]
- **ขอบเขตที่ครอบคลุม**: เศรษฐศาสตร์ VF/PF ทั้งโลก (CAPEX/OPEX/ราคาขาย/จุดคุ้มทุน) + บทเรียนความล้มเหลว + โมเดลที่รอด + นัยต่อไทย
- **นอกขอบเขต**: เทคนิคการผลิต (LED/สารละลาย/หุ่นยนต์ — ดู 04-002/04-004/04-007), ตลาดผักไทย (04-006), โรงเรือนเขตร้อน (04-008)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                 | ค่า                                                                               | เงื่อนไข/แหล่ง                 | สถานะ          |
| ------------------------- | --------------------------------------------------------------------------------- | ------------------------------ | -------------- |
| ผลผลิตผักใบต่อพื้นที่     | 30–50 เท่า/ปี เทียบแปลงกลางแจ้ง (ชั้นวางหลายชั้น + รอบปลูก 4–6 สัปดาห์)           | งานวิชาการ/ผู้ประกอบการ [1][6] | ยืนยันได้กว้าง |
| น้ำที่ประหยัด             | ~90–98% เทียบการเกษตรเปิด                                                         | AeroFarms/งานวิชาการ [1][6]    | ยืนยันได้กว้าง |
| ยาฆ่าแมลง/ยากำจัดศัตรูพืช | 0 (ระบบปิด)                                                                       | [1][6]                         | ยืนยันได้กว้าง |
| CAPEX                     | ~1,000–3,000 ดอลลาร์/ตร.ม. (โรงใหม่มาตรฐาน); โรงใหญ่ระดับ Plenty หลายหมื่นล้านบาท | รายงานอุตสาหกรรม [2][3]        | ยังไม่ยืนยัน   |
| สัดส่วนค่าไฟใน OPEX       | 25–40% (LED + HVAC) — ผักใบ 1 กก. ใช้ไฟ ~10–15 kWh                                | งานวิจัย NREL/วารสาร [2][4]    | ยังไม่ยืนยัน   |
| ต้นทุนผลิตผักกาดหอม VF    | ~3–6 ดอลลาร์/กก. (โรงใหญ่ที่ปรับปรุงแล้ว) vs ผักแปลง ~0.5–1                       | งานวิเคราะห์ [2][4]            | ยังไม่ยืนยัน   |
| ราคาขายผัก VF             | 3–8 ดอลลาร์/กก. (US/สิงคโปร์/ญี่ปุ่น — premium + สัญญา)                           | ตลาด [3][5]                    | ยังไม่ยืนยัน   |
| จุดคุ้มทุน                | หลายรายยังไม่ถึง; รายที่รอด: 5–10 ปีนับจากเริ่ม (ผักใบ premium ตลาดสูง)           | บทวิเคราะห์ [3][4]             | ยังไม่ยืนยัน   |
| อัตราค่าไฟฟ้าต่อผลผลิต    | ไฟแพงขึ้น 0.01 ดอลลาร์/kWh → ต้นทุนผักใบ +~2–5%                                   | การวิเคราะห์ความไว [2]         | ยังไม่ยืนยัน   |
| ผลไม้/เบอร์รีใน VF        | ยังไม่มีผู้ใดประกาศกำไรสุทธิ (Plenty strawberry เริ่ม 2024–25)                    | ข่าว/รายงาน [3][5]             | ยังไม่ยืนยัน   |

- **กฎ**: ตัวเลข CAPEX/OPEX/จุดคุ้มทุนกระจายกว้างมากตามขนาด ประเทศ (ค่าไฟ/ค่าแรง) และตลาด — อย่าใช้ตัวเลขเดียว
- **เงื่อนไขสำคัญ**: (1) ราคาไฟ (2) ราคาขายผัก (3) ค่าแรง (4) อัตราการใช้กำลังผลิต (utilization) — โรงที่เปิด 70–80% กำลังผลิตและขายผัก premium ได้ อยู่รอด; โรงที่แข่งราคา/เปิดกำลังต่ำ ล้ม

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: CEA/VF ทั่วโลก 2025 ~8–12 พันล้านดอลลาร์ (รวม vertical farm ~5–7 พันล้าน — analyst estimate ยังไม่ยืนยัน) [3]; คาดโต 10–20%/ปี แต่ฐานเล็กและหลายรายล้ม [4]
- **เงินทุน VC 2021–2022**: VF ดูดเงิน ~2–4 พันล้านดอลลาร์/ปี (peak) → 2023–2025 ลดลง ~50%+ (AgFunder — อ้างข้าม 14-001) [3]
- **ผู้เล่นที่รอด (ตัวอย่าง)**: Plenty (US), AeroFarms (US ใหม่), Bowery (US), 80 Acres Farms (US), Oishii (US — สตรอว์เบอร์รี premium), Growy/Infarm successor, Mirai/Spread (ญี่ปุ่น), Sustenir/Sky Greens (สิงคโปร์), YesHealth (ไต้หวัน), Sananbio (จีน) [3][4][5]
- **เงินอุดหนุนรัฐ** (ตัวเร่งสำคัญ): สิงคโปร์ (30x30 + co-funding 30%), เอมิเรตส์/ซาอุ (ความมั่นคงอาหาร — เงินทุนตรง+สัญญารัฐ), ญี่ปุ่น (ทุน + ราคาไฟอุดหนุนบางส่วน), จีน (นโยบาย "ไร่ในเมือง") [5]
- **โมเดลที่รอดจริง**: (1) สัญญาขายระยะยาวกับร้านค้า/แบรนด์ (Plenty×Walmart, AeroFarms×Whole Foods) (2) พืชราคาสูงตลอดปี (Oishii strawberry ~50 ดอลลาร์/กล่อง) (3) ตั้งในที่ค่าไฟ/ค่าเช่าถูก (80 Acres มุ่งมิดเวสต์ US) (4) "Vendor financing/leasing" [3][4]
- **ความหมายต่อนักลงทุน**: VF เป็น "ธุรกิจโครงสร้างต้นทุนหนัก" — ต้องมี (ก) สัญญา (ข) ไฟฟ้าราคาถูก (ค) ตลาด premium (ง) ทีมปฏิบัติการ — หายไปข้อเดียว = เสี่ยงล้ม

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยยังไม่มี VF ระดับ "หลายชั้นในอาคาร" ที่ประกาศกำไรยั่งยืน; มีฟาร์มไฮโดรโปนิกส์กลางแจ้ง/โรงเรือนมุ้งหลายร้อยแห่ง (ผักสลัด) + ฟาร์ม "คอนเทนเนอร์" ระยะนำร่อง (เรือนเพาะในตู้ ใกล้กรุงเทพฯ/เชียงใหม่) [6]
- **โครงสร้างต้นทุนไทยที่ต่างจาก US/สิงคโปร์**: ค่าแรงถูก (แรงงาน 15–25% OPEX ไม่แพง), ค่าไฟปานกลาง (~4–5 บาท/kWh ภาคธุรกิจ), ราคาผักสลัดไทย 60–150 บาท/กก. ส่ง — "หน้าต่างกำไร" แคบกว่า แต่ CAPEX ถูกกว่า 2–4 เท่า (ก่อสร้าง/อุปกรณ์ในประเทศ) [6]
- **ตลาด**: ร้านสลัด/แฟรนไชส์ (Salad Concept เป็นต้น), โรงแรม/รีสอร์ท, ส่งออกพรีเมียม (ดู [04-006](เจาะลึก-04-ผักไฮโดรโปนิกส์และPlantFactoryไทย.md)) — ความต้องการผักปลอดภัยโต แต่กำลังซื้อจำกัด
- **นโยบาย**: AIC (ศูนย์เทคโนโลยีเกษตรและนวัตกรรม), โครงการส่งเสริมผักปลอดภัย/เกษตรอินทรีย์, การส่งเสริม Smart Farming — ยังไม่มีเงินอุดหนุน VF เฉพาะ [6]
- **ข้อสรุปเบื้องต้น**: สำหรับไทย "โรงเรือนมุ้ง/หลังคาโปร่ง + เทคนิคไฮโดรโปนิกส์" ให้ ROI ดีกว่า "อาคารปิดเต็มรูปแบบ" — VF ปิดสนิทคุ้มเมื่ออยู่ติดลูกค้าราคาสูง (กรุงเทพฯ) หรือผลิตของหายาก (สมุนไพร/ไมโครกรีนราคาสูง)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลข CAPEX/OPEX/จุดคุ้มทุน VF ระดับ "คอนเทนเนอร์/ห้องแยก" ภายในเงื่อนไขไทย (ค่าไฟ 4–5 บาท, ค่าแรง, ราคาผักสลัด) — ยังไม่มีงานวิเคราะห์เปิดเผย
- **Q2**: อิทธิพลของราคาไฟไทยต่อกำไร VF (scenario analysis 0–30 บาท/kWh) — ยังไม่มี
- **Q3**: ความยืดหยุ่นของราคาผักสลัด premium ไทยเมื่ออุปทาน VF เพิ่ม — ยังไม่มี (ตลาดเล็ก ใครขยายมาก ราคาแตก)
- **Q4**: บทเรียน AeroFarms/Kalera → กรอบ "go/no-go" สำหรับนักลงทุนไทย (สัญญา/ไฟ/ตลาด/ทีม) — ยังไม่มีเอกสารไทย
- **Q5**: มูลค่าที่ผู้บริโภคไทยยอมจ่ายเพิ่ม (WTP) สำหรับผัก VF/ปลอดภัย — มีงาน WTP ผักปลอดภัยบ้าง แต่ไม่เจาะ VF
- **Q6**: ศักยภาพ "VF ส่งออก" (กาตาร์/สิงคโปร์ต้องการนำเข้า — ไทยเป็นผู้ผลิตในภูมิภาค?) — ยังไม่มี
- **Q7**: ตัวเลขคาร์บอน/น้ำของ VF vs ผักนำเข้า (LCA ในบริบทเขตร้อน) — งานต่างประเทศมี (US/EU) แต่บริบทไทยยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                                     | ระดับนโยบาย                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ฟาร์มนำร่อง 2–3 แห่ง (คอนเทนเนอร์/ห้องปิด) ใกล้ กทม./เชียงใหม่ — บันทึกต้นทุนจริง (ไฟ/แรงงาน/เสื่อม/ราคาขาย); ผูกสัญญาลูกค้า 1–2 ปีก่อนสร้าง             | ฐานข้อมูลต้นทุน VF ไทย (เปิดเผยตัวเลข CAPEX/OPEX); ศึกษา WTP ผู้บริโภค; ส่งเสริมไฟราคาถูก/โซลาร์สำหรับ VF (เชื่อม 08) |
| 2 (2–4 ปี) | ขยายเฉพาะโมเดลที่ผ่านเกณฑ์ (กำไรก่อนดอกเบี้ย ≥ 10%); สร้างแบรนด์ "ผักในเมือง" + สัญญาโรงแรม/แฟรนไชส์; บริการ "จัดตั้ง+ปฏิบัติการ VF" (Grow as a Service) | เงินทุนร่วม/สินเชื่อดอกเบี้ยต่ำสำหรับ CEA; มาตรฐาน "ผักปลอดภัยในระบบปิด" (ตรวจสอบย้อนกลับ)                            |
| 3 (4+ ปี)  | ฮับ VF ภูมิภาค (ผลิตผัก premium ส่งออกสิงคโปร์/ตะวันออกกลาง — ใช้ค่าไฟ/ค่าแรงถูกกว่า); จับคู่กับ AI/หุ่นยนต์ (04-004/04-005)                             | นโยบาย "เมืองปลอดภัยทางอาหาร" + แหล่งน้ำ/ไฟเสถียรสำหรับ CEA; สถิติการยอมรับระดับชาติ                                  |

## 11. อภิธานศัพท์

| คำศัพท์            | ความหมาย                                                                        |
| ------------------ | ------------------------------------------------------------------------------- |
| Vertical Farm (VF) | ฟาร์มแนวตั้งหลายชั้นในอาคาร — ควบคุมแสง/น้ำ/อากาศ                               |
| Plant Factory (PF) | คำญี่ปุ่น/เอเชีย — โรงงานผลิตพืชระบบปิด (ส่วนใหญ่หมายถึงระบบเดียวกัน)           |

| Utilization rate   | อัตราการใช้กำลังการผลิต (กำลังผลิตที่ใช้จริง ÷ ทั้งหมด)                         |
| Leafy greens       | ผักใบ (ผักกาดหอม/สลัด/เบบี้ลีฟ) — กลุ่มที่ VF ทำกำไรได้                         |
| Grow as a Service  | โมเดลให้บริการจัดตั้ง/ดำเนินการฟาร์มให้ผู้อื่น                                  |
| DLI                | ปริมาณแสงรวมต่อวัน (mol/m²/วัน) — ดู 04-002                                     |
| LCA                | Life Cycle Assessment — การประเมินผลกระทบตลอดวงจรชีวิต                          |
| WTP                | Willingness to Pay — จำนวนเงินที่ผู้บริโภคยอมจ่ายเพิ่ม                          |
