## 1. บทสรุปผู้บริหาร

- **ใจความ**: โซลาร์ฟลัตติง = แผงโซลาร์ลอยบนผิวน้ำ (แพลอย — สระ/บ่อ/อ่างเก็บน้ำ/บ่อกุ้ง) — "ใช้พื้นที่น้ำที่ไม่แย่งที่ดินทำกิน" + ข้อดีพิเศษ: น้ำเย็นช่วยระบายความร้อนแผง (ผลิตไฟได้ดีขึ้น ~5–15%) + แผงช่วยลดการระเหยน้ำ (ประหยัดน้ำ — แล้งไทย) + ร่มเงาให้บ่อ/ปลา (ลดอุณหภูมิน้ำ — บ่อกุ้ง) — เทคโนโลยีที่เติบโตเร็วที่สุดในโลกโซลาร์ (อ่างเก็บน้ำ/บ่อใหญ่ — จีน/ญี่ปุ่น/เกาหลี/ไทยเริ่ม) [1][2][3]
- **ขั้นพัฒนา**: 🧪 นำร่อง/ขยาย (อ่าง/บ่อใหญ่ — จีน/ญี่ปุ่น/ไทยมีโครงการแล้ว — แต่ "ฟาร์ม/บ่อกุ้งไทยยังน้อย") [2][3]
- **ตัวเลขสำคัญที่สุด**: แผงบนน้ำผลิตไฟได้มากกว่าแผงบนดิน ~5–15% (ช่วง — การระบายความร้อน); ลดการระเหยน้ำ ~20–40% ของพื้นที่ปิดแผง (ช่วง); ต้นทุนโซลาร์ฟลัตติงแพงกว่าโซลาร์ดิน ~10–30% (ช่วง — โครงลอย/ทุ่น); ไทย: โครงการโซลาร์ฟลัตติง (เขื่อน/อ่าง — การไฟฟ้า — เมกะวัตต์-class เริ่มแล้ว); คืนทุน ~5–8 ปี (ช่วง — ขึ้นราคาไฟ/ขนาด) [1][2][4]
- **นัยต่อไทย**: ไทยมีแหล่งน้ำเยอะ (อ่าง/เขื่อน/สระในไร่นา — 03-007/บ่อกุ้ง) — โซลาร์ฟลัตติงเหมาะ (1) อ่าง/เขื่อนใหญ่ (การไฟฟ้า — โรงไฟฟ้าลอยน้ำ) (2) สระในไร่นา/บ่อกุ้ง (ฟาร์ม — ไฟ+ร่มปลา+ประหยัดน้ำ) (3) พื้นที่น้ำเสีย/บ่อบำบัด (ใช้ได้) — จุดสำคัญ: (1) เริ่มที่ "บ่อ/สระของตัวเอง" (ขนาดเล็ก — ไฟใช้เอง/ปั๊ม 08-005/ชาร์จ EV 08-004) (2) ดู "โครงสร้าง/ทุ่น" (พายุ/คลื่น — ไทย) (3) ผลต่อระบบนิเวศน้ำ (ออกซิเจน/แสง/อุณหภูมิ — ต้องประเมิน) [3][4]
- **สถานะโดยรวม**: 🧪 นำร่อง/ขยาย (เขื่อน/อ่างไทย — เริ่ม; ฟาร์ม/บ่อเล็กยังน้อย)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (องค์ประกอบ)

1. **ทุ่นลอย/แพ (Pontoon/floats)**: ทุ่นพลาสติก/HDPE เชื่อมกัน — รองรับแผง (ออกแบบรับลม/คลื่น)
2. **แผงโซลาร์ (PV)**: ติดบนแพ (มุมต่ำ — 5–15° — แดดไทย) — "น้ำเย็น = แผงเย็น = ไฟเพิ่ม 5–15%"
3. **สายเคเบิล/ทอดสมอ (Mooring)**: ยึดฝั่ง/ทุ่นสมอ — ปรับระดับน้ำ (หน้าแล้ง/น้ำท่วม)
4. **ระบบไฟฟ้า**: อินเวอร์เตอร์/หม้อแปลง (บนแพ/ฝั่ง) → ใช้เอง/ขายไฟ (VSPP-class)

### 2.2 รูปแบบ/ขนาด (ตาราง)

| ประเภท                    | ขนาด                | ใช้ทำอะไร                              | เหมาะกับ                             |
| ------------------------- | ------------------- | -------------------------------------- | ------------------------------------ |
| ฟาร์ม/สระเล็ก             | 5–50 กิโลวัตต์      | ไฟใช้เอง (ปั๊ม 08-005/EV 08-004/ฟาร์ม) | สระในไร่นา (03-007), บ่อปลา/กุ้ง     |
| บ่อ/อ่างกลาง              | 100–1,000 กิโลวัตต์ | ไฟฟาร์มใหญ่/ขาย                        | บ่อกุ้งใหญ่/บ่อบำบัดน้ำเสีย          |
| เขื่อน/อ่างใหญ่ (utility) | เมกะวัตต์-class     | ขายไฟ (การไฟฟ้า/IPP)                   | เขื่อน/อ่างเก็บน้ำ (ไทย — เริ่มแล้ว) |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ขนาด/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: โซลาร์บนดิน (08-001 — อ้างข้าม), ปั๊มโซลาร์ (08-005 — อ้างข้าม), การจัดการน้ำ (03), ประมงลึก (09), กฎอ่าง/น้ำ (12)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                         | ผลลัพธ์                                                  | สถานที่/เงื่อนไข | แหล่ง  |
| --------------------------------- | -------------------------------------------------------- | ---------------- | ------ |
| ไฟเพิ่มจากระบายความร้อน (น้ำเย็น) | ~5–15% เทียบโซลาร์ดิน (ช่วง)                             | งาน/โครงการ      | [1][2] |
| ลดการระเหยน้ำ (พื้นที่ปิดแผง)     | ~20–40% (ช่วง)                                           | งาน              | [2]    |
| ต้นทุน (เทียบโซลาร์ดิน)           | +10–30% (ช่วง — ทุ่น/สมอ)                                | ตลาด/งาน         | [2][4] |
| คืนทุน                            | ~5–8 ปี (ช่วง — ขึ้นราคาไฟ/ขนาด)                         | ผู้ประกอบการ     | [4]    |
| เขื่อนสิรินธร (ไทย)               | ~45 เมกะวัตต์ (ติดตั้ง) — ~1 แสนแผง-class                | การไฟฟ้า         | [3]    |
| ตลาดโซลาร์ลอยโลก                  | ~$10–20 พันล้านดอลลาร์ (2030-class — ช่วง; โต 20–30%/ปี) | analyst          | [4]    |
| อุณหภูมิน้ำใต้แพ (บ่อ)            | ลด ~1–3°C (ช่วง — ร่ม)                                   | งาน              | [2][5] |
| ผลออกซิเจนละลายน้ำ (ใต้แพ)        | ลดได้ (ช่วง — ต้องประเมิน/เครื่องเติม)                   | งาน              | [5]    |

- **กฎ**: "โซลาร์ลอย = 'ไม่แย่งที่ดิน + ไฟเพิ่ม + ประหยัดน้ำ + ร่มบ่อ' — เหมาะแหล่งน้ำของตัวเอง (สระ/บ่อ)" — "แต่ 'ทุ่น/ลม/คลื่น/ระบบนิเวศ' = ต้นทุน/ความเสี่ยงที่ต้องออกแบบ (พายุไทย)" — ตัวเลขช่วง — ตรวจหัวข้อ 10
- **หมายเหตุ**: ราคา/โครงการเปลี่ยนเร็ว — ตรวจอัปเดต

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดโซลาร์ลอยโลก ~$10–20 พันล้านดอลลาร์ (2030-class — ช่วง; โต ~20–30%/ปี — เร็วสุดในโซลาร์); ไทย: เขื่อนสิรินธร + โครงการขยาย (การไฟฟ้า/เอกชน) [4]
- **ผู้เล่นหลัก**: การไฟฟ้า (เขื่อน — utility), ผู้พัฒนาโซลาร์ (ทุ่น/EPC — ไทย+ต่างประเทศ), ผู้ผลิตทุ่น (HDPE-class), ผู้ประกอบการฟาร์ม/บ่อกุ้ง (เล็ก-กลาง), กรมชลประทาน/กรมประมง (แหล่งน้ำ/บ่อ)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                            | ฉุดรั้ง                                   |
| ------------------------------------- | ----------------------------------------- |
| ไม่แย่งที่ดินทำกิน (น้ำใช้แล้ว)       | ต้นทุนทุ่น/โครง (แพงกว่าโซลาร์ดิน)        |
| แผงเย็น = ไฟเพิ่ม + ประหยัดน้ำ        | ลม/พายุ/คลื่น (ไทย)                       |
| นโยบายโซลาร์ (ไทย — รับซื้อ/เป้าหมาย) | ระบบนิเวศน้ำ (ออกซิเจน/แสง — ต้องประเมิน) |
| ร่มบ่อกุ้ง/ปลา (คุณภาพ)               | การดูแล/ซ่อม (กลางน้ำ — ยากกว่า)          |
| เขื่อน/อ่างมีอยู่แล้ว (โครงสร้าง)     | กฎ/สิทธิ์การใช้แหล่งน้ำ (12)              |

- **แนวโน้ม**: "โซลาร์ลอยฟาร์ม" (บ่อกุ้ง/สระในไร่ — เล็ก-กลาง — ไฟใช้เอง), ไฮบริด (โซลาร์ลอย+พลังน้ำ), การผูกแบตเตอรี่ (08-008)/EV (08-004), งานระบบนิเวศ (มาตรฐานการติดตั้ง — % ปกคลุม), ทุ่นใหม่ (ทนลม/รีไซเคิล)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยมีโครงการโซลาร์ลอยจริง (1) เขื่อนสิรินธร (การไฟฟ้าฝ่ายผลิต — 45 MW-class — ไฮบริดกับพลังน้ำ — ใหญ่ในอาเซียน) (2) โครงการการไฟฟ้า/เอกชนขยาย (เขื่อน/อ่างอื่น) (3) ฟาร์ม/บ่อกุ้ง (นำร่อง — เอกชน/งานวิจัย — เริ่ม) — งานวิจัยไทย (การระบายความร้อน/ระบบนิเวศ/บ่อกุ้ง) เริ่มมี [3][4]
- **จุดแข็งไทย**: แหล่งน้ำเยอะ (เขื่อน/อ่าง/สระในไร่นา 03-007/บ่อกุ้ง — พื้นที่น้ำมหาศาล), แดดจัด (ผลิตไฟดี), ประสบการณ์เขื่อนสิรินธร (การไฟฟ้า — องค์ความรู้), นโยบายโซลาร์ (เป้าหมาย/รับซื้อ), อุตสาหกรรมบ่อกุ้ง/ปลา (ร่ม = ข้อดี)
- **จุดอ่อน**: ต้นทุนทุ่น/โครง (แพงกว่าโซลาร์ดิน — ฟาร์มเล็กไม่ไหว), พายุ/ลม (ความเสี่ยง — การออกแบบ), ความรู้/ผู้รับเหมาโซลาร์ลอย (ยังน้อย — ไทย), งานระบบนิเวศ (ยังน้อย — กฎ/มาตรฐานยังไม่ชัด), การยอมรับ (14-003 — ฟาร์ม), กฎการใช้แหล่งน้ำ (12)
- **โอกาส**: (1) "โซลาร์ลอยฟาร์มไทย" (สระในไร่นา/บ่อกุ้ง — 5–100 กิโลวัตต์ — ไฟใช้เอง+ร่ม+ประหยัดน้ำ — ผูก 08-005/08-004) (2) "เขื่อน/อ่างขยาย" (การไฟฟ้า — ไฮบริด) (3) "บ่อกุ้ง/ปลา 4.0" (โซลาร์ลอย + เซนเซอร์/เครื่องเติมออกซิเจน — 05/09) (4) "งานมาตรฐาน/ระบบนิเวศ" (สถาบัน — แนวทาง % ปกคลุม/การประเมิน) (5) "ทุ่น/อุปกรณ์ไทย" (อุตสาหกรรม — ส่งออกอาเซียน)
- **หน่วยงาน**: การไฟฟ้าฝ่ายผลิต (เขื่อน), กรมชลประทาน/กรมประมง (แหล่งน้ำ/บ่อ), กกพ. (รับซื้อ), กรมโรงงาน (ความปลอดภัย), มก./มจธ. (งานวิจัย), ผู้ประกอบการโซลาร์/บ่อกุ้ง

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: งาน "ระบบนิเวศโซลาร์ลอยในบ่อไทย" (ออกซิเจน/อุณหภูมิ/ปลา/กุ้ง — % ปกคลุมที่ปลอดภัย) — ยังไม่มีครบ
- **Q2**: เศรษฐศาสตร์ "โซลาร์ลอยฟาร์มไทย" (สระ/บ่อ — ขนาด/คืนทุน/เทียบโซลาร์ดิน) — ยังไม่มีข้อมูลเปิด
- **Q3**: การออกแบบทุ่น/สมอ "ทนพายุไทย" (ลม/คลื่น/ระดับน้ำเปลี่ยน) — ยังไม่มีแนวทางมาตรฐาน
- **Q4**: งาน "โซลาร์ลอย+บ่อกุ้ง" (ร่ม/อุณหภูมิ/ผลผลิต — ไทย) — ยังไม่มีงานครบ
- **Q5**: ผลต่อการระเหย/คุณภาพน้ำ (ไทย — เขตร้อน) — ยังไม่มีงาน
- **Q6**: กฎ/สิทธิ์การใช้แหล่งน้ำ (12 — ใครติดตั้งได้/ที่สาธารณะ) — ยังไม่ชัด
- **Q7**: การยอมรับ (14-003) ของผู้ประกอบการบ่อ/ฟาร์มไทย — ยังไม่มีงาน
