## 1. บทสรุปผู้บริหาร

- **ใจความ**: น้ำบาดาลเป็นแหล่งน้ำสำรองสำคัญของไทย (โดยเฉพาะภาคอีสานที่น้ำผิวดินไม่พอ) — การใช้เกินสมดุล (overdraft) ทำให้ระดับน้ำลด/การทรุดตัว/น้ำเค็มรุก [1] MAR (Managed Aquifer Recharge) คือการเติมน้ำลงชั้นน้ำบาดาลเทียม — ผ่านบ่อซึม (injection well), สระซึม (spreading basin), ฝายใต้ดิน — เพื่อเพิ่มน้ำสำรองใช้หน้าแล้ง [2]
- **ขั้นพัฒนา**: 🧪 นำร่อง ถึง 🏭 เชิงพาณิชย์เริ่มต้น — MAR ใช้จริงมานานในต่างประเทศ (แคลิฟอร์เนีย/ออสเตรเลีย/อิสราเอล) แต่ไทยยังเป็นโครงการนำร่อง (ฝายใต้ดิน/บ่อเติมน้ำ)
- **ตัวเลขสำคัญที่สุด**: น้ำบาดาลคิดเป็นส่วนใหญ่ของน้ำใช้ในอีสาน (สัดส่วนต้องยืนยันจากกรมทรัพยากรน้ำบาดาล) [1]; ไทยมีบ่อน้ำบาดาลใช้งานหลักหมื่นบ่อ (ตัวเลขต้องยืนยัน) [1]
- **นัยต่อไทย**: อีสานพึ่งน้ำบาดาล (รวมน้ำเค็ม — เชื่อม 03-005) — MAR เป็นทางเลือก "เก็บน้ำใต้ดิน" แทนสระผิวดินที่ระเหยง่าย (เชื่อม 03-007) แต่ต้องมีกฎหมาย/การจัดการชั้นน้ำที่ดี
- **สถานะโดยรวม**: 🧪 นำร่อง (ไทย) / 🏭 เชิงพาณิชย์เริ่มต้น (ต่างประเทศ)

## 2. หลักการและขอบเขต

- **หลักการ**: 1) ระบุชั้นน้ำบาดาล (aquifer) ที่มีที่ว่าง/ปลอดภัย 2) เติมน้ำจากแหล่งที่มี (น้ำฝน/น้ำท่า/น้ำเสียบำบัด) ผ่านวิธีต่าง ๆ 3) กักเก็บไว้ใต้ดิน (ไม่ระเหย) 4) สูบใช้เมื่อขาด — "ใช้ชั้นน้ำเป็นอ่างเก็บน้ำธรรมชาติ"
- **วิธีหลัก**: (ก) บ่อเติมน้ำ/หลุมซึม (injection well) — เติมตรงชั้นน้ำ (ข) สระซึม/บ่อซึม (spreading/infiltration basin) — ปล่อยน้ำซึมลง (ค) ฝายใต้ดิน/เขื่อนใต้ดิน (subsurface dam) — กั้นการไหลใต้ดิน (ง) การส่งน้ำเข้าทุ่งแล้วซึมลง (ในพื้นที่เหมาะสม)
- **ข้อควรระวัง**: คุณภาพน้ำที่เติมต้องดีพอ (ไม่นำสารปนเปื้อนลงชั้นน้ำ), ไม่เติมในชั้นน้ำเค็ม/ใกล้แหล่งเค็ม (เชื่อม 02-006/03-005), การตรวจวัดระดับน้ำอย่างต่อเนื่อง
- **ขอบเขตที่ครอบคลุม**: สถานะน้ำบาดาลไทย, วิธี MAR, กฎหมาย, ตัวเลข/ผลลัพธ์, สถานการณ์ไทย
- **นอกขอบเขต**: น้ำบาดาลเค็ม/การทำเกลือ-กุ้ง (ดู 03-005), สระผิวดิน (ดู 03-007), ระบบชลประทานผิวดิน (03-001/03-010)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                | แหล่ง  |
| ----------- | ------------------------------------------------------------------------------------------- | ------ |
| 1977        | พ.ร.บ.น้ำบาดาล — เริ่มกำกับ/ควบคุมการขุดเจาะบ่อบาดาลไทย                                     | [1]    |
| 1980s–2000s | MAR เชิงพาณิชย์ในแคลิฟอร์เนีย/ออสเตรเลีย/อิสราเอล (บ่อซึม/แอ่งซึม)                          | [2]    |
| 2010s       | ไทยเริ่มงานฝายใต้ดิน/บ่อเติมน้ำ (กรมทรัพยากรน้ำบาดาล + มหาวิทยาลัย); พ.ร.บ.น้ำบาดาลปรับปรุง | [1][3] |
| 2020s       | MAR ไทยขยาย (ฝายใต้ดินหลายแห่ง — ตัวเลขต้องยืนยัน); งานวิจัยการเลือกพื้นที่ MAR ด้วย GIS/AI | [3][5] |
| 2025–2026   | การบูรณาการ MAR กับแหล่งน้ำผิวดิน/การพยากรณ์น้ำ (เชื่อม 03-001/11)                          | [4]    |

- **เส้นแบ่ง**: MAR สุกแล้วในต่างประเทศ — ไทยยังเป็นช่วงนำร่อง/ขยายผล รอ "การจัดการชั้นน้ำ+กฎหมาย+การติดตาม" ที่เป็นระบบ

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด               | ผลลัพธ์                                                           | สถานที่/เงื่อนไข                       | แหล่ง |
| ----------------------- | ----------------------------------------------------------------- | -------------------------------------- | ----- |
| น้ำบาดาลในภาคอีสาน      | เป็นแหล่งน้ำหลักของครัวเรือน/เกษตรหลายพื้นที่ (สัดส่วนต้องยืนยัน) | ไทย — กรมทรัพยากรน้ำบาดาล              | [1]   |
| บ่อน้ำบาดาลใช้งานในไทย  | หลักหมื่นบ่อ (ตัวเลขต้องยืนยัน)                                   | ไทย — ยังไม่ยืนยัน                     | [1]   |
| MAR เพิ่มปริมาณน้ำสำรอง | ประสบความสำเร็จในหลายโครงการต่างประเทศ (ตัวเลขต่อโครงการต่างกัน)  | แคลิฟอร์เนีย/ออสเตรเลีย — ยังไม่ยืนยัน | [2]   |
| ฝายใต้ดิน/บ่อเติมน้ำไทย | มีโครงการนำร่อง/ขยายผลหลายแห่ง (จำนวนต้องยืนยัน)                  | ไทย — ยังไม่ยืนยัน                     | [3]   |
| ต้นทุน MAR vs สระผิวดิน | ต่างกันตามวิธี/ขนาด — ไม่มีตัวเลขไทยเปรียบเทียบชัดเจน             | — ยังไม่ยืนยัน                         | [4]   |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: MAR ได้ผลเมื่อ (1) มีชั้นน้ำที่เหมาะสม (2) มีน้ำส่วนเกินหน้าแล้งจริง (3) การเติมไม่ปนเปื้อนชั้นน้ำ — ไม่ใช่ทุกพื้นที่ทำได้

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ไม่มีตลาด "MAR" แยกในไทย — อยู่ในงบภาครัฐ (กรมทรัพยากรน้ำบาดาล/ชลประทาน) + ธุรกิจขุดเจาะบ่อน้ำบาดาล (เอกชน) + อุปกรณ์ (ปั๊ม/ท่อ/ระบบกรอง) [1]
- **ผู้เล่น**: กรมทรัพยากรน้ำบาดาล (กำกับ/งาน MAR/ฝายใต้ดิน), กรมชลประทาน, มหาวิทยาลัย (วิจัย), บริษัทขุดเจาะ/ผู้รับเหมา
- **การลงทุน**: โครงการน้ำบาดาลเพื่อการเกษตรของรัฐ (งบ/จำนวนโครงการต้องยืนยัน); ต่างประเทศมีโมเดล "น้ำบาดาลสำรองใช้ยามแล้ง" (strategic groundwater reserve) [2]
- **ปัจจัยขับเคลื่อน**: ภัยแล้งซ้ำ, น้ำผิวดินไม่พอ, ระดับน้ำบาดาลลดลง
- **ปัจจัยฉุดรั้ง**: งบ/กฎหมาย, ข้อมูลชั้นน้ำไม่ครบ, ความเสี่ยงการปนเปื้อน, การบังคับใช้ พ.ร.บ.น้ำบาดาล

## 6. สถานการณ์ประเทศไทย

- **หน่วยงาน/กฎหมาย**: กรมทรัพยากรน้ำบาดาล (DGR) ภายใต้ กษ./ทรัพยากรธรรมชาติ — พ.ร.บ.น้ำบาดาล พ.ศ.2520 (แก้ไขล่าสุด) + การประกาศเขตวิกฤตน้ำบาดาล; การขึ้นทะเบียนบ่อบาดาล [1]
- **งาน MAR ไทย**: ฝายใต้ดิน/บ่อเติมน้ำในภาคอีสาน (พื้นที่โครงการนำร่อง — รายละเอียดต้องยืนยัน); งานวิจัย มข./มก. เรื่องการเลือกพื้นที่เติมน้ำด้วย GIS [3][5]
- **ปัญหา**: การทรุดตัวของแผ่นดิน (กรุงเทพฯ — อดีต), น้ำเค็มรุกชายฝั่ง/อีสาน (เชื่อม 03-005), การใช้เกินสมดุลในเขตอุตสาหกรรม/ท่องเที่ยว
- **นโยบาย**: แผนแม่บทการบริหารจัดการทรัพยากรน้ำ (สทนช.) มีการจัดการน้ำบาดาลเป็นส่วนหนึ่ง (รายละเอียดต้องยืนยัน)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ปริมาณน้ำบาดาลที่ใช้จริง/ความสมดุลรายลุ่มน้ำของไทย — ข้อมูลยังไม่ครบถ้วน/เปิด
- **Q2**: การเลือกพื้นที่ MAR ที่เหมาะสมที่สุดของไทย (ชั้นน้ำ-แหล่งน้ำเติม-ความเสี่ยง) ด้วย AI — ยังไม่มีเครื่องมือระดับชาติ
- **Q3**: ประสิทธิผลจริงของฝายใต้ดิน/บ่อเติมน้ำไทย (ปริมาณที่เติม/ระยะเวลา) — ยังไม่มีการประเมินเป็นระบบ
- **Q4**: กฎหมาย/สิทธิ์การเติมน้ำลงชั้นน้ำของใคร — ยังคลุมเครือ
- **Q5**: ความเสี่ยงการปนเปื้อน/ปฏิกิริยาเคมีเมื่อเติมน้ำต่างคุณภาพลงชั้นน้ำ — งานน้อย
- **Q6**: เศรษฐศาสตร์ MAR เทียบสระผิวดิน/ฝายชะลอน้ำในเงื่อนไขไทย — ยังไม่มีตัวเลข

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                       | ระดับนโยบาย                                                                                      |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1 (1–2 ปี) | ฐานข้อมูลชั้นน้ำบาดาลเปิด (แผนที่/ความลึก/คุณภาพ — เชื่อม 02-003); โครงการนำร่อง MAR 5 พื้นที่อีสาน พร้อมการติดตามระดับน้ำ | กฎหมาย/ประกาศเขต MAR ที่ชัดเจน + มาตรฐานคุณภาพน้ำที่เติม                                         |
| 2 (2–4 ปี) | ขยาย MAR ผ่านกลไก "น้ำส่วนเกินหน้าแล้ง -> เติมใต้ดิน" ในพื้นที่เหมาะสม; บริการออกแบบระบบเติมน้ำให้ฟาร์ม/สหกรณ์             | งบ MAR ในแผนน้ำชาติ; การเชื่อมข้อมูล MAR กับการพยากรณ์น้ำ (เชื่อม 03-001/11)                     |
| 3 (4+ ปี)  | น้ำบาดาลสำรอง (MAR) เป็น "ธนาคารน้ำ" ใช้ยามแล้งในระดับลุ่มน้ำ — ผูกการจัดสรรน้ำ/ประกันภัย                                  | นโยบาย "Strategic Groundwater Reserve" ระดับชาติ + การบังคับใช้ พ.ร.บ.น้ำบาดาลอย่างมีประสิทธิภาพ |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย          | รายละเอียด                            | โอกาสแก้                                |
| ------------------- | ------------------------------------- | --------------------------------------- |
| ข้อมูลชั้นน้ำไม่ครบ | ขาดแผนที่ธรณีวิทยา/ระดับน้ำรายพื้นที่ | การสำรวจ + ระบบตรวจวัดระดับน้ำอัตโนมัติ |
| ความเสี่ยงปนเปื้อน  | น้ำเติมไม่ดี -> ชั้นน้ำเสียหายถาวร    | มาตรฐานคุณภาพน้ำเติม + การตรวจสอบ       |
| กฎหมาย/สิทธิ์       | ความเป็นเจ้าของชั้นน้ำ/การเติม        | กฎหมายชัดเจน (พ.ร.บ.น้ำบาดาล/น้ำ)       |
| งบ/การติดตาม        | MAR ใช้เวลาหลายปีเห็นผล               | โครงการระยะยาว + KPI ระดับน้ำ           |
| การทรุดตัว/เค็มรุก  | การใช้เกินสมดุลยังไม่หยุด             | การบังคับใช้ + การลดการใช้ (ประหยัด)    |
| ความเข้าใจ          | เกษตรกรมองไม่เห็นน้ำใต้ดิน            | การสื่อสาร/แปลงสาธิต + ข้อมูลเปิด       |

- [ ] **จำนวนฝายใต้ดิน/โครงการ MAR ไทย** — ค้นเว็บ DGR/ข่าว เพื่ออ้างตัวเลขจริง
- [ ] **ผล MAR ต่างประเทศ** — หางานทบทวน (Hydrogeology Journal / Water Resources Research) ระบุกรณีตัวอย่าง
- [ ] **พ.ร.บ.น้ำบาดาล ฉบับแก้ไข** — ตรวจสถานะกฎหมายล่าสุด (ปี/สาระสำคัญ)
- [ ] **งาน MAR/น้ำบาดาลไทย (มข./มก./DGR)** — ค้น TCI/ThaiJo เพื่ออ้าง DOI
- [ ] **ต้นทุนเปรียบเทียบ MAR vs สระ** — ถ้าหาไม่ได้ให้เขียน "ไม่ระบุ" ในหัวข้อ 4

## 11. อภิธานศัพท์

| คำศัพท์         | ความหมาย                                         |
| --------------- | ------------------------------------------------ |
| Aquifer         | ชั้นหิน/ดินที่กักเก็บน้ำใต้ดินได้                |
| MAR             | การเติมน้ำใต้ดินเทียม (Managed Aquifer Recharge) |
| Injection well  | บ่อเติมน้ำตรงลงชั้นน้ำบาดาล                      |
| Spreading basin | สระ/แอ่งปล่อยน้ำซึมลงชั้นน้ำ                     |
| Subsurface dam  | ฝายใต้ดิน/เขื่อนใต้ดินกั้นการไหลใต้ดิน           |
| Overdraft       | การสูบน้ำเกินปริมาณที่ธรรมชาติเติมกลับ           |
| Safe yield      | ปริมาณน้ำที่สูบได้โดยไม่ทำลายชั้นน้ำระยะยาว      |
| น้ำเค็มรุก      | การแทรกตัวของน้ำเค็มเข้าสู่ชั้นน้ำจืด            |
