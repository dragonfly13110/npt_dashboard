## 1. บทสรุปผู้บริหาร

- **ใจความ**: สมาร์ตโฟน (กล้อง RGB/Multispectral, GPS, เซนเซอร์วัดแสง/อุณหภูมิ + AI ในเครื่อง) กลายเป็น "ห้องแล็บพกพา" — ตรวจโรคพืชด้วยภาพ (Plantix/Agrio — ใช้งานจริงในอินเดีย/แอฟริกา หลายล้านครั้ง), ประเมินความเขียว (NDVI ด้วยมือถือ+ฟิลเตอร์), วัดพื้นที่/ผลผลิต/ดิน (แอป + กล้อง) ด้วยต้นทุน ~0 บาทเพิ่ม [1][2]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (แอปตรวจโรค/จัดการฟาร์ม — ใช้จริงกว้างขวาง) / ⚗️-🏭 (การวัดทางวิทยาศาสตร์ — NDVI/ดิน/ผลผลิต ยังผันแปรตามสภาพ)
- **ตัวเลขสำคัญที่สุด**: แอปตรวจโรค (Plantix) ใช้จริง >10 ล้านครั้ง/ปี (หลายประเทศ — ยังไม่ยืนยัน); ความแม่นยำแอปโรค 60–90% (ขึ้นกับชนิด/แสง/ภาพ) — "ตัวช่วยคัดกรอง" ไม่ใช่เครื่องมือวินิจฉัยขั้นสุดท้าย [1][3]
- **นัยต่อไทย**: เกษตรกรไทยใช้สมาร์ตโฟนเกือบ 100% (ผู้ใช้เน็ต) — ช่องทางที่ราคาถูกที่สุดในการนำ AI ถึงฟาร์มรายย่อย (ข้าว/มัน/ผัก/ไม้ผล); โจทย์ไทย: ชุดข้อมูลโรค/พืชไทย + การออกแบบแอปภาษาไทย + การยอมรับ (เชื่อม 14-003) [5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ตรวจโรค/บันทึก) / ⚗️ (วัดทางวิทยาศาสตร์)

## 2. หลักการและขอบเขต

- **หลักการ**: ใช้เซนเซอร์ที่มีอยู่แล้วในสมาร์ตโฟน (กล้อง RGB + แฟลช, GPS, ไจโร, เซนเซอร์แสง) + AI (โมเดล CNN ตรวจจับโรค/ศัตรู/ธาตุอาหารจากภาพ) — งานเสริม (กล้องไฮเปอร์สเปกตรัม/ฟิลเตอร์ NDVI) ขยายขีดความสามารถ
- **กลุ่มงาน**:
  1. **ตรวจโรค/ศัตรู/ธาตุอาหารจากภาพ** — Plantix, Agrio, Plant Doctor (งาน FAO), โมเดล open (TensorFlow/PlantVillage)
  2. **วัดความเขียว/NDVI** — แอป + ฟิลเตอร์ (ความแม่นยำ ±10–20% เทียบเซนเซอร์แพง — งานบางชิ้น)
  3. **วัดพื้นที่/ระยะ/นับ** — GPS + แอป (แผนที่ไร่, วัดขนาดแปลง)
  4. **ตรวจดินเบื้องต้น** — ภาพ+AI (สี/เนื้อดิน), pH strips + แอปอ่านสี — ยังหยาบ
  5. **บันทึกฟาร์ม/ข้อมูลราคา** — แอปจัดการฟาร์ม (บันทึกการผลิต/ค่าใช้จ่าย — เชื่อม 12)
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/แอป/ตัวเลขความแม่นยำ, การใช้งานจริงโลก/ไทย, แนวทางนำไปใช้
- **นอกขอบเขต**: ภาพดาวเทียม (05-001), เซนเซอร์ติดตั้ง (05-003/05-004), Edge AI อุปกรณ์เฉพาะ (05-005)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                     | แหล่ง  |
| --------- | ---------------------------------------------------------------------------------------------------------------- | ------ |
| 2010s     | PlantVillage (Penn State, 2015 — ชุดข้อมูลโรคเปิด) + CNN เริ่มแพร่; แอปแรก ๆ (Plantix 2015, AgroSens?)           | [1]    |
| 2017–2020 | แอปตรวจโรคใช้จริงในอินเดีย/แอฟริกา (Plantix — ความร่วมมือ FAO/บริษัท); งาน NDVI มือถือ                           | [1][3] |
| 2021–2023 | โมเดลเปิด (PlantVillage/TensorFlow) + แอปภาษาไทยเริ่ม (งาน มก./มข.); การวัดธาตุอาหาร/ดินจากภาพเริ่มวิจัย         | [2][5] |
| 2024–2026 | AI มือถือเร็วขึ้น (บนเครื่อง — เชื่อม 05-005), แอปรวมฟีเจอร์ (โรค+พยากรณ์+ตลาด); การยอมรับในไทยผ่านภาครัฐ/ธนาคาร | [3][5] |

- **เส้นแบ่ง**: แอปตรวจโรค "ใช้งานได้จริง" แล้ว — ขีดจำกัดคือความแม่นยำรายชนิด/รายพันธุ์ + การขาดข้อมูลเฉพาะพื้นที่ (ต้องเทรน/ปรับใหม่ทุกภูมิภาค)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                        | ผลลัพธ์                                                     | เงื่อนไข          | แหล่ง  |
| -------------------------------- | ----------------------------------------------------------- | ----------------- | ------ |
| ความแม่นยำแอปตรวจโรค             | 60–90% (ชนิดที่ฝึกมาดี — ภาพปกติ/แสงดี); ต่ำลงมากในสนามจริง | งานประเมินอิสระ   | [1][3] |
| ฐานข้อมูล PlantVillage           | ~50,000+ ภาพ (เริ่ม) — หลายสิบชนิดโรค — ข้อมูลเปิด          | Penn State        | [1]    |
| NDVI มือถือ (ฟิลเตอร์)           | ±10–20% เทียบเครื่องมือแพง (งานที่ควบคุม)                   | งานวิจัย          | [2]    |
| การวัดพื้นที่ด้วย GPS มือถือ     | แม่นยำ ±2–10% (GPS ธรรมดา) — พอใช้วางแผน                    | งาน/ใช้งาน        | [2]    |
| ราคา                             | แอปฟรี–หลักร้อยบาท/เดือน (ฟีเจอร์ pro)                      | ตลาด              | [3]    |
| การใช้จริง (Plantix)             | หลายล้านครั้ง/ปี (อินเดีย/แอฟริกา — ยังไม่ยืนยัน)           | บริษัท/ข่าว       | [3]    |
| อัตราการยอมรับของเกษตรกร (แอป)   | 20–60% ในโครงการที่อบรม (ช่วง — ขึ้นกับพื้นที่/ภาษา)        | งาน 14-003/งานแอป | [5][6] |
| ผลการใช้งานจริง (ลดการฉีดพ่นผิด) | ลดการฉีดยาไม่จำเป็น 20–40% (งานโครงการบางชิ้น)              | งานประเมิน        | [1][3] |

- **กฎ**: ความแม่นยำในห้องแล็บ ≠ สนามจริง (แสง/มุม/พื้นหลัง) — ต้องประเมินในสภาพใช้งานจริงและมี "คำเตือนความไม่แน่นอน" ในแอป
- **เงื่อนไขสำคัญ**: (1) ข้อมูลฝึกเฉพาะพื้นที่/พันธุ์ (2) ออกแบบ UX ให้เกษตรกร (ภาษาไทย/เสียง/ภาพ) (3) เชื่อมกับคำแนะนำจริง (อะไร/เมื่อไร/เท่าไร — เชื่อม 06) — แอปที่บอกแค่ "เป็นโรค" ไม่พอ

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดแอป/ซอฟต์แวร์ฟาร์มโลก ~3–6 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 12–20%/ปี [3]
- **ผู้เล่นหลัก**: Plantix (เยอรมนี — ตรวจโรค/ฝั่ง Global South), Agrio (อิสราเอล), PlantVillage/Nuru (FAO), แอปจัดการฟาร์ม (FarmLogs/AgriWebb), ไทย: แอปไทย (RiceBook?/แอปกรมส่งเสริม — ยังต้องตรวจ), แอปธนาคาร (ธ.ก.ส. — ข้อมูลฟาร์ม) [3][6]
- **การลงทุน**: โมเดลธุรกิจ: ฟรี+โฆษณา/ข้อมูล, ฟรี+ฟีเจอร์จ่าย, B2B (ขายข้อมูล/บริการให้หน่วยงาน/บริษัทเมล็ด-ปุ๋ย) — รายย่อยไม่จ่ายเงินตรง
- **แนวโน้ม**: AI บนเครื่อง (ทำงานไร้เน็ต — เชื่อม 05-005), แอปรวม "โรค+อากาศ+ราคา+ตลาด" (super-app เกษตร), ความร่วมมือกับรัฐ/องค์กรพัฒนา (เข้าถึงรายย่อย)
- **ความเสี่ยง**: การพึ่งผู้ให้บริการต่างชาติ (ข้อมูลเกษตรกร/ความเป็นส่วนตัว), ความแม่นยำเกินจริง (ความเชื่อถือ), การทิ้งผู้ใช้ (คุณภาพไม่พอ)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: แอปตรวจโรคสากลใช้ได้กับไทยบ้าง (Plantix รองรับหลายภาษา); งานวิจัยไทย: โมเดลโรคข้าว/มัน/ทุเรียนจากภาพ (มก./มข./มจพ. — งาน CNN จำนวนมาก), แอป/ต้นแบบหลายชิ้น (ยังไม่เป็น "ซูเปอร์แอป" ระดับชาติ); ภาครัฐ/ธ.ก.ส. มีแอปข้อมูล/ตลาด [5][6]
- **จุดแข็งไทย**: เกษตรกรใช้สมาร์ตโฟน/ไลน์แพร่หลาย (ช่องทางแจกจ่ายเทคโนโลยีดี), งานวิจัย AI ภาพไทยเยอะ, ภาษาไทย/วัฒนธรรมใช้แอปเก่ง
- **จุดอ่อน**: ชุดข้อมูลโรค/พืชไทยเปิดไม่พอ, แอปไทยกระจัดกระจาย (ไม่มีแอปเดียวครบ), การยอมรับ/ความไว้ใจ (เกษตรกรพึ่งเจ้าหน้าที่มากกว่าแอป), การวัดทางวิทยาศาสตร์ (NDVI/ดิน) ยังไม่นิ่ง
- **โอกาส**: (1) แอป "แนะนำศัตรู/โรคข้าว-มัน-ทุเรียน" ภาษาไทย (ร่วม มก./กรมวิชาการ) (2) รวมกับไลน์ (ช่องทางที่ใช้อยู่) (3) เชื่อมข้อมูลราชการ (ราคา/ภัย — เชื่อม 12/11) (4) แพลตฟอร์ม "ฟาร์มเล็กไทย" (บันทึก+ขาย)
- **หน่วยงาน**: กรมวิชาการเกษตร/กรมส่งเสริมการเกษตร, มหาวิทยาลัย, ธ.ก.ส., สตาร์ทอัพไทย (เชื่อม 14-002)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ชุดข้อมูลภาพโรค/ศัตรู "ของไทย" (ข้าว/มัน/ทุเรียน/ยาง — หลายฤดู/หลายสภาพแสง) แบบเปิด — ยังไม่มีครบ
- **Q2**: ความแม่นยำของแอปตรวจโรคในสนามจริงไทย (ประเมินอิสระ — ชนิด/สภาพ) — ยังไม่มี
- **Q3**: UX/ภาษา/รูปแบบที่เกษตรกรไทยยอมรับ (เสียง/ไลน์/เจ้าหน้าที่) — มีงานบางส่วน (14-003) ยังไม่เจาะแอป
- **Q4**: การวัด NDVI/ดิน/ผลผลิตด้วยมือถือในสภาพไทย (ความร้อน/แสง) — ยังไม่นิ่ง
- **Q5**: เศรษฐศาสตร์ "แอปเกษตรไทย" (โมเดลรายได้/การรักษาผู้ใช้) — ยังไม่มี
- **Q6**: ความเป็นส่วนตัว/ความเป็นเจ้าของข้อมูลของเกษตรกรไทย (แนวทาง PDPA เกษตร) — ยังไม่มี
- **Q7**: ผลของการใช้แอปต่อการตัดสินใจ/รายได้จริงของเกษตรกรไทย (RCT) — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                 | ระดับนโยบาย                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | รวบรวมชุดข้อมูลโรค/ศัตรูไทย (ภาพจาก มก./มข./กรมวิชาการ — เปิด); แอปต้นแบบ "ตรวจโรคข้าว/มัน" ภาษาไทย (บนไลน์) ทดลองกับกลุ่มแปลงใหญ่   | ทุนชุดข้อมูลภาพเกษตรเปิด; มาตรฐาน/แนวทาง PDPA สำหรับข้อมูลเกษตร                        |
| 2 (2–4 ปี) | ขยายแอป "ซูเปอร์แอปเกษตรไทย" (โรค+อากาศ+ราคา+ตลาด — เชื่อม 12/11/05-001); บริการ B2B แก่บริษัทเมล็ด/ปุ๋ย/ประกันภัย                   | นโยบาย "AI ถึงฟาร์มเล็ก" (แอป/อบรมเจ้าหน้าที่); การรับรองความแม่นยำแอปโรค (กรมวิชาการ) |
| 3 (4+ ปี)  | ระบบแนะนำ AI แบบเต็ม (ตรวจภาพ+พยากรณ์+สั่งการ — เชื่อม 06) ใช้งานกว้างในแปลงย่อย; การวัดมือถือกลายเป็นข้อมูลราชการ (สำรวจผลผลิต/ภัย) | แพลตฟอร์มข้อมูลเกษตรรายแปลงแห่งชาติ (เชื่อม 05-001/05-003); นโยบาย "ทุกแปลงมีข้อมูล"   |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย             | รายละเอียด                         | โอกาสแก้                                        |
| ---------------------- | ---------------------------------- | ----------------------------------------------- |
| ความแม่นยำสนามจริง     | แสง/มุม/ชนิดพันธุ์ไทย — แอปผิดบ่อย | ชุดข้อมูลไทย, ฝึกใหม่, คำเตือนความไม่แน่นอน     |
| ความเชื่อถือ           | เกษตรกรไม่ไว้ใจแอป (กลัวแนะนำผิด)  | ตรวจยืนยันกับเจ้าหน้าที่, แสดงที่มาคำแนะนำ      |
| ข้อมูลขาด/กระจัดกระจาย | ภาพ/ผลผลิตไทยไม่อยู่ในระบบ         | เก็บแบบมีส่วนร่วม (citizen science), เปิดข้อมูล |
| การวัดทางวิทยาศาสตร์   | NDVI/ดินมือถือผันแปรสูง            | ใช้เป็น "แนวโน้ม" ไม่ใช่ค่าสัมบูรณ์             |
| โมเดลธุรกิจ            | รายย่อยไม่จ่าย — แอปอยู่ไม่ได้     | B2B/รัฐ/ธนาคารสนับสนุน                          |
| ความเป็นส่วนตัว        | ข้อมูลแปลง/รายได้ของเกษตรกร        | PDPA เกษตร + ความยินยอมชัดเจน                   |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ความแม่นยำแอปโรค 60–90%** — ตรวจงานประเมินอิสระ (ไม่ใช่ของบริษัท)
- [ ] **PlantVillage 50,000+ ภาพ** — ตรวจสถานะชุดข้อมูลปัจจุบัน
- [ ] **Plantix ใช้จริงหลายล้านครั้ง/ปี** — ตรวจข่าว/รายงานบริษัท (ข้อมูลปี)
- [ ] **NDVI มือถือ ±10–20%** — ตรวจงานวิจัยเปรียบเทียบ (อุปกรณ์/วิธี)
- [ ] **แอปฟรี–หลักร้อยบาท/เดือน** — ตรวจราคาตลาดจริง
- [ ] **ตลาดแอปฟาร์ม 3–6 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **งานวิจัยไทย CNN โรคข้าว/มัน/ทุเรียน** — ตรวจ TCI/ThaiJo (อัปเดต 2024–26)
- [ ] **อัตราการยอมรับแอปของเกษตรกรไทย 20–60%** — ตรวจงาน 14-003/งานแอปไทย
