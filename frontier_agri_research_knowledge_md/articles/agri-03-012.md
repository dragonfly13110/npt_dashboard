## 1. บทสรุปผู้บริหาร

- **ใจความ**: ระบบน้ำหยด/มินิสปริงเกลอร์จ่ายน้ำตรงบริเวณราก ความถี่สูง-ปริมาณน้อย — ประหยัดน้ำ ~30–50% เทียบสปริงเกลอร์/รดท่วม [3] เพิ่มผลผลิต/คุณภาพ (สวนทุเรียน/มังคุด/ลำไย/ส้ม/องุ่น) และลดต้นทุนแรงงาน — แต่ต้นทุนติดตั้งสูง จุดคุ้มทุนคือตัวชี้ขาดสำหรับไม้ผล/อ้อยไทย [1][2]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว — ใช้จริงทั่วโลกและไทย (สวนผลไม้มูลค่าสูงติดตั้งแพร่หลาย) — แต่ "การทำระบบให้ดี/การดูแล/การคุ้มค่า" ยังเป็นช่องว่าง
- **ตัวเลขสำคัญที่สุด**: ประหยัดน้ำ ~30–50% (EPA — อ้างข้ามจาก 03-001) [3]; ต้นทุนติดตั้งสวนไม้ผลไทย ~30,000–60,000 บาท/ไร่ (ช่วง — ยังต้องยืนยัน) [6]
- **นัยต่อไทย**: สวนทุเรียน/ลำไย/ส้ม (มูลค่าสูง) คุ้มลงทุนชัด; อ้อยแปลงใหญ่ (มูลค่าต่ำกว่า/น้ำจากบ่อ) คุ้มเมื่อน้ำมีจำกัด/ปั๊มแพง — การออกแบบระบบ/การบำรุงรักษา/การรวมกลุ่มซื้อเป็นกุญแจ
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ไทย+โลก)

## 2. หลักการและขอบเขต

- **หลักการ**: ปล่อยน้ำผ่านท่อหลัก→ท่อแขนง→ตัวปล่อยน้ำ (emitter) ตรงโคนต้น/แถวปลูก — เกิด "wetted zone" เฉพาะจุดราก ลดการระเหย/การไหลบ่า/วัชพืช; ตั้งความถี่สูง (รายวัน/วันเว้นวัน) ปริมาณน้อยตาม ET (เชื่อม 03-011)
- **ข้อดีเพิ่ม**: เฟอร์ติเกชัน (ปุ๋ยทางน้ำ — เชื่อม 02-012) แม่นยำ ลดแรงงาน; ควบคุมได้ด้วยตัวจับเวลา/เซนเซอร์ (เชื่อม 03-001)
- **ข้อจำกัด**: (1) ต้นทุนติดตั้ง/เปลี่ยนระบบเดิม (2) การอุดตัน (clogging — น้ำมีตะกอน/เคมี) (3) น้ำเค็มทำรากเค็มเฉพาะจุด (เชื่อม 03-005/02-006) (4) ต้องกรองน้ำ/บำรุงรักษา (5) ผลคุ้มค่าไม่เท่ากันทุกพืช
- **ขอบเขตที่ครอบคลุม**: ต้นทุน/รายได้/จุดคุ้มทุนของน้ำหยดในไม้ผลและอ้อยไทย, การออกแบบ/บำรุงรักษา, สถานการณ์ตลาด
- **นอกขอบเขต**: VRI (ดู 03-003), ชลประทานดิจิทัล/เซนเซอร์ (03-001), ปุ๋ยแม่นยำ (02-012), น้ำเค็ม (03-005)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                    | แหล่ง  |
| ----------- | ------------------------------------------------------------------------------- | ------ |
| 1960s       | น้ำหยดเริ่มในอิสราเอล (Netafim) — แนวคิดจ่ายน้ำตรงราก                           | [1]    |
| 1980s–90s   | เข้าสู่ไทย (สวนผลไม้/ไม้ผลทางภาคใต้/ตะวันออก); การผลิตท่อในประเทศ               | [6]    |
| 2000s–2010s | ราคาอุปกรณ์ถูกลง + เฟอร์ติเกชันแพร่; อ้อยแปลงใหญ่เริ่มใช้                       | [2]    |
| 2020s       | สวนทุเรียน/ไม้ผลมูลค่าสูงติดตั้งน้ำหยด+IoT ควบคุม; งาน ROI รายพืชเริ่มมี        | [4][5] |
| 2025–2026   | น้ำหยด + การตั้งเวลาอัตโนมัติตาม ET (เชื่อม 03-001/03-011) เป็นมาตรฐานสวนคุณภาพ | [4]    |

- **เส้นแบ่ง**: เทคโนโลยีสุกแล้ว — งานวิจัยปัจจุบันอยู่ที่ "การออกแบบเฉพาะแปลง (AI) + เศรษฐศาสตร์รายพืช + การดูแลระบบ" มากกว่าตัวเทคโนโลยี

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                | ผลลัพธ์                                                         | สถานที่/เงื่อนไข                  | แหล่ง |
| ------------------------ | --------------------------------------------------------------- | --------------------------------- | ----- |
| การประหยัดน้ำ            | ~30–50% เทียบสปริงเกลอร์/รดท่วม (ไมโคร-ไอริเกชัน)               | EPA/งานวิชาการ — อ้างข้าม 03-001  | [3]   |
| ต้นทุนติดตั้งสวนไม้ผลไทย | ~30,000–60,000 บาท/ไร่ (ช่วงตามชนิดท่อ/ระบบ)                    | ไทย — ยังไม่ยืนยัน                | [6]   |
| ผลผลิต/คุณภาพ (ไม้ผล)    | +คุณภาพ/ผลผลิตในหลายงาน (ทุเรียน/ลำไย/ส้ม) — ตัวเลขต่องาน       | ไทย/ต่างประเทศ — ยังไม่ยืนยัน     | [4]   |
| อ้อยน้ำหยด               | ประหยัดน้ำ + ผลผลิต/คุณภาพ (CCS) ดีขึ้นบางงาน; ต้นทุนติดตั้งสูง | ต่างประเทศ/ไทย — ยังไม่ยืนยัน     | [2]   |
| จุดคุ้มทุน               | 2–5 ปีสำหรับไม้ผลมูลค่าสูง (ช่วง — ขึ้นกับราคาผลผลิต/น้ำ)       | ไทย — ยังไม่ยืนยัน                | [5]   |
| อายุการใช้งานระบบ        | ท่อ/หัวจ่าย ~5–10 ปี (บำรุงรักษาดี)                             | ผู้ผลิต/งานวิชาการ — ยังไม่ยืนยัน | [1]   |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: ความคุ้มค่าขึ้นกับ (1) ราคาผลผลิต (2) ราคาน้ำ/ค่าปั๊มที่ประหยัด (3) ขนาดแปลง (4) คุณภาพการติดตั้ง/ดูแล — ไม่มีตัวเลขเดียว

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด drip irrigation โลก ~1–2 พันล้านดอลลาร์สหรัฐ (analyst estimate — ยังไม่ยืนยัน) [1]; ตลาดไทยอยู่ในผู้จำหน่าย/ผู้ผลิตท่อน้ำหยด (ในประเทศ + นำเข้า) [6]
- **ผู้เล่นหลัก**: Netafim (อิสราเอล), Rivulis, Jain Irrigation (อินเดีย), Toro (สหรัฐฯ) + ผู้ผลิต/จำหน่ายไทย (ท่อ/หัวจ่ายในประเทศหลายแบรนด์) [1][6]
- **การลงทุน**: เกษตรกรลงทุนเอง/สินเชื่อ ธ.ก.ส. (มีโครงการสนับสนุนอุปกรณ์น้ำ — รายละเอียดต้องยืนยัน); สวนทุเรียน/ผลไม้มูลค่าสูงติดตั้งแพร่หลาย [5]
- **ปัจจัยขับเคลื่อน**: ภัยแล้ง, ราคาทุเรียน/ผลไม้สูง, แรงงานขาด, นโยบายแหล่งน้ำแปลง (เชื่อม 03-007)
- **ปัจจัยฉุดรั้ง**: ต้นทุนติดตั้ง, ความรู้การออกแบบ/ดูแล, น้ำเค็ม/ตะกอน, แปลงเช่า

## 6. สถานการณ์ประเทศไทย

- **ไม้ผล**: ทุเรียน (ตะวันออก/ใต้), ลำไย/ลิ้นจี่ (เหนือ), ส้ม (เหนือ/ภาคกลาง), องุ่น/มังคุด — สวนคุณภาพติดตั้งน้ำหยด/มินิสปริงเกลอร์ + เฟอร์ติเกชันเป็นมาตรฐานในสวนทุเรียนพรีเมียม [4][5]
- **อ้อย**: แปลงใหญ่ภาคกลาง/อีสาน — น้ำหยด/น้ำใต้ผิวดินเริ่มใช้ในไร่อ้อยชลประทาน (ยังไม่แพร่ — ต้นทุน) [2]
- **ตลาด/บริการ**: ผู้จำหน่ายอุปกรณ์/บริการติดตั้งทั่วประเทศ; การออกแบบระบบมืออาชีพยังจำกัด (งานวิศวกร/ผู้แทนแบรนด์) — บริการ "ออกแบบด้วย AI" ยังไม่มี [6]
- **อุปสรรค**: น้ำบาดาลมีตะกอน/เค็ม (ต้องกรอง — เชื่อม 03-005), เกษตรกรไม่ดูแลระบบ (หัวจ่ายตัน), แปลงเล็ก/เช่า

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ROI/จุดคุ้มทุนน้ำหยดรายพืชไทย (ทุเรียน/ลำไย/ส้ม/อ้อย) ณ ราคาปัจจุบัน — ยังไม่มีชุดข้อมูลอัปเดต
- **Q2**: เครื่องมือออกแบบระบบอัตโนมัติ (AI: ขนาดท่อ/หัวจ่าย/รอบการรด ตามแปลงจริง) — ยังไม่มีบริการไทย
- **Q3**: ผลระยะยาวของน้ำหยดต่อโครงสร้างดิน/ราก (wetted zone คงที่) — งานไทยน้อย
- **Q4**: ต้นทุน-ผลของการกรองน้ำบาดาล (ตะกอน/เหล็ก/เค็ม) สำหรับระบบน้ำหยดไทย — ยังไม่มีตัวเลข
- **Q5**: การรวมกลุ่มซื้อ/บริการติดตั้ง-ดูแลผ่านสหกรณ์ (ลดต้นทุนต่อไร่ — เชื่อม 14-004) — ยังไม่มีโมเดล
- **Q6**: การยอมรับของชาวสวนรายย่อย (เชื่อม 14-001) — ยังไม่มีการสำรวจ

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                        | ระดับนโยบาย                                                                       |
| ---------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงสาธิตน้ำหยด+เฟอร์ติเกชันในสวนทุเรียน/ลำไย/อ้อย 5 ภูมิภาค (บันทึกน้ำ/ผลผลิต/ต้นทุน); คู่มือออกแบบฉบับไทย | มาตรฐานการติดตั้ง/คุณภาพอุปกรณ์ (ท่อ-หัวจ่าย-ตัวกรอง); สินเชื่ออุปกรณ์ ธ.ก.ส.     |
| 2 (2–4 ปี) | บริการ "ออกแบบ-ติดตั้ง-ดูแลระบบรายแปลง" (วิศวกร+แอป) ผ่านสหกรณ์/ผู้จำหน่าย; กลุ่มซื้ออุปกรณ์รวมลดต้นทุน     | การสนับสนุนกรองน้ำบาดาล (เชื่อม 03-005); งบวิจัย ROI รายพืช                       |
| 3 (4+ ปี)  | น้ำหยด+อัตโนมัติตาม ET เป็นมาตรฐานสวนคุณภาพส่งออก (GI/การรับรอง); บริการดูแลระยะไกล (เชื่อม 03-001/06)      | นโยบาย "สวนแม่นยำ" + การประเมินผลน้ำที่ประหยัดระดับลุ่มน้ำ (เชื่อม 03-010/03-011) |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย           | รายละเอียด                         | โอกาสแก้                                     |
| -------------------- | ---------------------------------- | -------------------------------------------- |
| ต้นทุนติดตั้งสูง     | หลักหมื่นบาท/ไร่ — แปลงเล็กไม่คุ้ม | กลุ่มซื้อ/บริการจ่ายต่อไร่; พืชมูลค่าสูงก่อน |
| การอุดตัน/บำรุงรักษา | หัวจ่ายตันจากตะกอน/เคมี            | การกรอง + การล้างระบบตามรอบ                  |
| ความรู้การออกแบบ     | ระบบผิด → น้ำไม่ทั่ว/ต้นทุนสูงขึ้น | บริการออกแบบมืออาชีพ + คู่มือไทย             |
| น้ำเค็ม/บาดาล        | รากเค็มเฉพาะจุด (เชื่อม 03-005)    | การผสมน้ำ/ล้างเกลือ (leaching)               |
| แปลงเช่า/รายย่อย     | ไม่ลงทุนระยะยาว                    | สัญญา/ระบบเช่าอุปกรณ์                        |
| ราคาผลผลิตผันผวน     | จุดคุ้มทุนเปลี่ยนตามราคา           | ข้อมูล ROI อัปเดต + การกระจายความเสี่ยง      |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ต้นทุนติดตั้ง 30,000–60,000 บาท/ไร่** — ค้นข้อมูลจริงจากผู้จำหน่าย/สมาคม (ราคาเปลี่ยนตามชนิดท่อ/แบรนด์) หรือเปลี่ยนเป็นช่วงอ้างอิงที่ยืนยันได้
- [ ] **ประหยัดน้ำ 30–50% (EPA)** — อ้างข้าม 03-001 [3] — เปิดลิงก์ยืนยันอีกครั้ง
- [ ] **จุดคุ้มทุน 2–5 ปี** — หางาน ROI ไทย (ThaiJo) หรือเปลี่ยนเป็น "ไม่ระบุ"
- [ ] **ตลาด drip โลก 1–2 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **งานอ้อยน้ำหยดไทย (ตัวเลข)** — ค้น TCI/ThaiJo + งานศูนย์วิจัยพืชไร่
- [ ] **การสนับสนุนสินเชื่อ/อุปกรณ์น้ำ ธ.ก.ส.** — ตรวจเว็บ/ข่าวล่าสุด

## 11. อภิธานศัพท์

| คำศัพท์           | ความหมาย                                            |
| ----------------- | --------------------------------------------------- |
| Drip irrigation   | การให้น้ำแบบหยดตรงราก (ระบบน้ำหยด)                  |
| Emitter / หัวจ่าย | ตัวปล่อยน้ำหยด/มินิสปริงเกลอร์                      |
| Wetted zone       | โซนเปียกบริเวณรากที่ระบบสร้างขึ้น                   |
| Fertigation       | การให้ปุ๋ยละลายไปกับน้ำ (ปุ๋ยทางน้ำ)                |
| Clogging          | การอุดตันของหัวจ่าย (ตะกอน/เคมี/ราก)                |
| Micro-irrigation  | ระบบให้น้ำน้อยปริมาณตรงจุด (น้ำหยด/มินิสปริงเกลอร์) |
| CCS               | ความหวานของอ้อย (Commercial Cane Sugar)             |
| ROI / จุดคุ้มทุน  | ผลตอบแทนการลงทุน / ระยะเวลาคืนทุน                   |
