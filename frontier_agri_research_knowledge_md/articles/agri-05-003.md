## 1. บทสรุปผู้บริหาร

- **ใจความ**: การส่งข้อมูลจากเซนเซอร์ในแปลง (ความชื้นดิน/อากาศ/น้ำ — เชื่อม 03-001) ต้องใช้โครงข่าย — 3 ทางเลือก: **LoRaWAN** (คลื่นวิทยุระยะไกล 2–15 กม., แบตเตอรี่ปี, ราคาถูก — เหมาะแปลงใหญ่ชนบท), **NB-IoT** (ใช้คลื่นมือถือ — ครอบคลุมทันที/ไม่ต้องติดตั้งเกตเวย์), **5G** (เร็ว/หน่วงต่ำ — เหมาะโดรน/วิดีโอ/เครื่องจักรอัตโนมัติ แต่ราคา/ครอบคลุมจำกัดในชนบท) [1][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (LoRaWAN/NB-IoT ใช้จริงทั่วโลกในฟาร์ม; 5G เกษตรนำร่องหลายประเทศ) — การเลือก "เทคโนโลยีที่ใช่" ตามพื้นที่/งานยังเป็นประเด็นหลัก [2][3]
- **ตัวเลขสำคัญที่สุด**: LoRaWAN: เกตเวย์ ~10,000–50,000 บาท (ครอบคลุม 5–15 กม. เปิดพื้นที่), เซนเซอร์ ~500–3,000 บาท, แบตเตอรี่ 2–5 ปี — ค่าใช้จ่ายต่อเซนเซอร์ต่อปีต่ำที่สุด; NB-IoT: ใช้ SIM ปกติ (ค่าแพ็กเกจ ~50–200 บาท/เดือน) [1][3]
- **นัยต่อไทย**: ไทยมีโครงข่ายมือถือครอบคลุมเกือบทั่วถึง (NB-IoT ของ AIS/TRUE/NT) + โครงการ LoRaWAN ท้องถิ่น (งาน มข./มก./บริษัท) — แปลงใหญ่ (อ้อย/ข้าว/สวนผลไม้) สามารถติด IoT ได้จริงแล้ว; จุดติดขัดคือ "การใช้งานต่อเนื่อง/การบำรุงรักษา/การรวมข้อมูล" ไม่ใช่เทคโนโลยี [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**:
  - **LoRaWAN**: โปรโตคอล LPWAN บนคลื่น 433/868/920 MHz — ส่งข้อมูลน้อย/ช้า (0.3–50 kbps) แต่ไกล (เปิดพื้นที่ 5–15 กม.) ใช้พลังงานต่ำมาก (เซนเซอร์อยู่ได้ปี — ใช้แบตเตอรี่ AA/โซลาร์) — ต้องติดตั้งเกตเวย์เอง/ใช้เกตเวย์สาธารณะ (TTN)
  - **NB-IoT**: LPWAN บนคลื่น 4G (เครือข่ายมือถือ) — ครอบคลุมทันที (มีสัญญาณมือถือ), ข้อมูลน้อย/แบตเตอรี่ปี — จ่ายรายเดือนตาม SIM
  - **5G**: แบนด์วิดธ์สูง/หน่วงต่ำ (มิลลิวินาที) — โดรนควบคุมระยะไกล/วิดีโอสด/เครื่องจักรอัตโนมัติ (เชื่อม 07) — แต่ค่าใช้จ่าย/ครอบคลุมชนบทจำกัด
  - **Wi-Fi/เซนเซอร์สาย** (ในโรงเรือน/แปลงเล็ก) — ราคาถูก/สัญญาณในพื้นที่จำกัด
- **การเลือกตามงาน**: วัดดิน/อากาศ (LoRaWAN/NB-IoT — ข้อมูลช้า ถูก), กล้อง/โดรน (5G/Wi-Fi — ข้อมูลมาก), เครื่องจักรควบคุม (5G — หน่วงต่ำ), สัตว์/ยานพาหนะติดตาม (NB-IoT/LoRaWAN GPS)
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/ราคา/ครอบคลุม, การใช้งานจริงไทย/โลก, การเลือกใช้งาน, แนวทางนำไปใช้
- **นอกขอบเขต**: เซนเซอร์ตัววัด (02-005/03-001), การประมวลผล (05-005), โรงเรือน (04-005)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: IoT การเกษตรโลก ~10–20 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 15–25%/ปี [3]
- **ผู้เล่นหลัก**: ชิป/โมดูล (Semtech, ST, Nordic), แพลตฟอร์ม (The Things Network — เปิด, Actility, Helium), ผู้ให้บริการ NB-IoT (AIS/TRUE/NT — ไทย), ระบบฟาร์ม (Netafim GrowSphere, John Deere Ops Center, ผู้ไทยหลายราย) [3][4][6]
- **การลงทุน**: ระบบ IoT แปลงใหญ่ (เซนเซอร์+เกตเวย์+แพลตฟอร์ม) ~5–30 หมื่นบาท/ระบบ (เริ่มต้น — ช่วง); รายเดือน (แพลตฟอร์ม/คลาวด์) หลักร้อย–พันบาท — คุ้มเมื่อแปลงใหญ่/น้ำแพง/ผลผลิตราคาสูง
- **แนวโน้ม**: เซนเซอร์ "ส่งเฉพาะผล" (Edge — เชื่อม 05-005), LoRaWAN สาธารณะฟรี (TTN), การรวมข้อมูลหลายแหล่ง (ดาวเทียม 05-001 + IoT) — "ฟาร์มมีระบบข้อมูลเดียว"
- **ความเสี่ยง**: เทคโนโลยีล้าสมัยเร็ว/มาตรฐานยังแยกส่วน, การพึ่งผู้ให้บริการรายเดียว (lock-in), ความปลอดภัย (แฮกเซนเซอร์/ข้อมูล — EU เริ่มมีกฎ)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: NB-IoT ไทยมีครอบคลุมกว้าง (AIS/TRUE — โปรโมต IoT เกษตร); โครงการ LoRaWAN งานวิจัย/บริษัท (มข./มก. — นาข้าว/สวนทุเรียน/อ้อย); 5G เกษตรนำร่อง (True/ดีแทค + พื้นที่สาธิต); โครงการ Smart Farm ของรัฐ (AIC/กรมส่งเสริม) ติดตั้งเซนเซอร์+แอปในฟาร์มสาธิตทั่วประเทศ [4][5][6]
- **จุดแข็งไทย**: โครงข่ายมือถือครอบคลุมดี, ราคาอุปกรณ์/บริการแข่งขัน (ผู้ประกอบการในประเทศหลายราย), งานวิจัย IoT ฟาร์มเยอะ, ภาครัฐมีโครงการสาธิต
- **จุดอ่อน**: โครงการสาธิตจำนวนมาก "จบที่สาธิต" (ไม่ต่อยอดเชิงพาณิชย์/บำรุงรักษา), ข้อมูลกระจัดกระจาย (แต่ละโครงการคนละแพลตฟอร์ม), เกษตรกรรายย่อยไม่เห็นประโยชน์ทันที (ข้อมูลต้องแปลเป็นคำแนะนำ), สัญญาณชนบทบางพื้นที่ยังขาด
- **โอกาส**: (1) มาตรฐาน "แพลตฟอร์มเดียว" ระดับชาติ (เชื่อมข้อมูลทุกโครงการ) (2) บริการ "IoT เป็นแพ็กเกจ+คำแนะนำ" (เชื่อม 06) (3) การใช้ LoRaWAN ในพื้นที่มือถืออ่อน (ป่า/ชายแดน) (4) ต่อยอดโครงการสาธิตเป็นเชิงพาณิชย์
- **หน่วยงาน**: กสทช., ผู้ให้บริการมือถือ, AIC/กรมส่งเสริมการเกษตร, มหาวิทยาลัย (มข./มก.), สตาร์ทอัพ IoT ไทย

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: แผนที่ความครอบคลุม/คุณภาพ NB-IoT/LoRaWAN ระดับแปลงจริงของไทย (หลายภูมิภาค) — ยังไม่มีเปิด

- **Q3**: อัตราการใช้งานต่อเนื่องหลังโครงการจบ (3–5 ปี) + สาเหตุการหยุดใช้ — ยังไม่มี
- **Q4**: การรวมข้อมูล IoT กับดาวเทียม/โดรน (05-001/05-005) ในระบบเดียวของไทย — ยังไม่มี
- **Q5**: มาตรฐาน/ความปลอดภัย (ข้อมูล/อุปกรณ์) สำหรับ IoT เกษตรไทย — ยังไม่มี
- **Q6**: ผลของข้อมูล IoT ต่อการตัดสินใจ/รายได้จริงของเกษตรกรไทย (RCT — ต่อยอด 03-001) — ยังไม่มี
- **Q7**: LoRaWAN ในพื้นที่ไร้สัญญาณมือถือ (ป่า/ภูเขา — ไม้ผล/กาแฟ) — ยังไม่มีงาน

| 1 (1–2 ปี) | นำร่อง "IoT แปลงใหญ่" 20–30 แปลง (ข้าว/อ้อย/ทุเรียน): เซนเซอร์ดิน/น้ำ + NB-IoT/LoRaWAN + แอปแจ้งเตือน — บันทึกต้นทุน/ผลลัพธ์จริง     | มาตรฐานข้อมูล IoT เกษตรไทย (รูปแบบ/โปรโตคอล); ทดสอบความครอบคลุมรายภูมิภาค             |
| 2 (2–4 ปี) | ขยาย "แพ็กเกจ IoT+คำแนะนำ" (เชื่อม 06 — AI แปลข้อมูลเป็นคำสั่งรดน้ำ/ปุ๋ย) ผ่านสหกรณ์/ผู้ประกอบการ; การบำรุงรักษาแบบบริการ (SaaS)     | แพลตฟอร์มกลางข้อมูลฟาร์ม (ร่วม กสทช./ผู้ให้บริการ); สินเชื่อ/เงินหนุนอุปกรณ์ IoT      |
| 3 (4+ ปี)  | "ฟาร์มทุกแปลงมีข้อมูล" — IoT + ดาวเทียม + โดรน (05-001/05-005) เชื่อมระบบเดียว; การประกันภัย/คาร์บอนใช้ข้อมูล IoT (เชื่อม 11/02-002) | นโยบาย "โครงสร้างพื้นฐานข้อมูลเกษตรแห่งชาติ"; กฎความปลอดภัย/ความเป็นส่วนตัว IoT เกษตร |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ระยะทาง/ราคา/แบตเตอรี่ LoRaWAN** — ตรวจเอกสาร Semtech/TTN + ตลาด (ราคาไทย)
- [ ] **NB-IoT ค่า SIM 50–200 บาท/เดือน + ความครอบคลุม** — ตรวจโปร/ข่าว AIS/TRUE/NT ณ รอบอัปเดต
- [ ] **5G หน่วง 1–10 มิลลิวินาที** — ตรวจเอกสาร/งานทดสอบ
- [ ] **ครอบคลุมมือถือไทย 95–99%** — ตรวจ กสทช./ผู้ให้บริการ
- [ ] **อัตราเสียหายเซนเซอร์ 5–20%/ปี** — ตรวจงานโครงการ (หรือปรับเป็นช่วง)
- [ ] **ROI IoT น้ำ 10–25% (คืนทุน 1–3 ปี)** — อ้างข้าม 03-001 — ตรวจงานอ้างอิง
- [ ] **ตลาด IoT เกษตร 10–20 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **สัดส่วนโครงการ IoT ไทยที่เดินต่อ 3 ปี+** — ตรวจงาน/ข่าว (หรือปรับเป็น "ยังไม่มีการสำรวจ")

## 11. อภิธานศัพท์

| คำศัพท์           | ความหมาย                                          |
| ----------------- | ------------------------------------------------- |
| LPWAN             | เครือข่ายพลังงานต่ำ ระยะไกล (LoRaWAN/NB-IoT)      |
| LoRaWAN           | โปรโตคอลคลื่นวิทยุระยะไกล เปิดมาตรฐาน             |
| NB-IoT            | IoT บนคลื่น 4G (SIM ปกติ)                         |
| Gateway (เกตเวย์) | อุปกรณ์รับ/ส่งข้อมูลจากเซนเซอร์สู่เน็ต            |
| TTN               | The Things Network — เครือข่าย LoRaWAN เปิด (ฟรี) |
| MQTT              | โปรโตคอลส่งข้อมูล IoT น้ำหนักเบา (มาตรฐาน)        |
| Latency           | ความหน่วง (5G: มิลลิวินาที)                       |
| Lock-in           | การผูกติดผู้ให้บริการรายเดียว (เปลี่ยนยาก)        |
| SaaS              | บริการซอฟต์แวร์/แพลตฟอร์มรายเดือน                 |
| RSSI/SNR          | ตัวชี้วัดความแรง/คุณภาพสัญญาณ                     |
