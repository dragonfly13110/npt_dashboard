## 1. บทสรุปผู้บริหาร

- **ใจความ**: ดินเค็มคือดินที่มีเกลือละลายสูง (EC) หรือโซเดียมแลกเปลี่ยนได้สูง (sodic) ทำให้พืชดูดน้ำ/ธาตุอาหารไม่ได้ — ทั่วโลกมีพื้นที่ดินเค็ม ~1 พันล้านเฮกตาร์ [1] และ ~20–33% ของพื้นที่ชลประทานโลกมีปัญหาเกลือบางระดับ (ตัวเลขหลายแหล่งต่างกัน) [2] ไทยมีพื้นที่ดินเค็มกระจุกภาคอีสาน (จำนวนล่าสุดยังต้องยืนยันจากกรมพัฒนาที่ดิน) [3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น — วิธีฟื้นฟูใช้ได้จริงมานาน (ล้างเกลือ ยิปซัม อินทรียวัตถุ) แต่ยังเป็นการบริหารจัดการเชิงพื้นที่ที่ทำได้ไม่ทั่วถึง
- **ตัวเลขสำคัญที่สุด**: ข้าวในแปลงดินเค็มให้ผลผลิตลดลงราว 30–50% เทียบแปลงปกติ (ช่วงอ้างอิงจากหลายงาน — ใช้เทียบเคียงทิศทาง) [6]; การใช้ไบโอชาร์ + การล้างเกลือร่วมกันช่วยลดโซเดียมและเพิ่มผลผลิตข้าวในแปลงทดลองต่างประเทศ ~20–40% (ยังต้องยืนยัน) [4]
- **นัยต่อไทย**: ภาคอีสานเป็นพื้นที่เสี่ยงใหญ่ของประเทศ — งานฟื้นฟูผูกกับการจัดการน้ำ/การระบายน้ำ และพันธุ์ทนเค็ม (ดู 01-007) ต้องทำคู่กัน
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (วิธีฟื้นฟูมีใช้จริง แต่สเกลพื้นที่ยังจำกัด)

## 2. หลักการและขอบเขต

- **กลไก**: ความเค็มทำลายพืช 2 ทาง — (1) ภาวะออสโมติก (น้ำเข้าพืชยากขึ้นจากแรงดันเกลือ) และ (2) พิษของไอออนจำเพาะ (Na⁺/Cl⁻ สะสมในใบ) + ธาตุอาหารไม่สมดุล (K/Ca ถูกรบกวน) ส่วนดินโซดิก (SAR/ESP สูง) เกิด "ดินแน่น-น้ำขัง-รากเน่า" จากโครงสร้างดินแตกตัว
- **การฟื้นฟู 3 กลุ่ม**: (ก) ทางกายภาพ-น้ำ — การล้างเกลือด้วยน้ำ (leaching) + ระบบระบายน้ำ (drainage) (ข) ทางเคมี — ยิปซัม/แคลเซียมเพื่อไล่โซเดียมในดินโซดิก, สารปรับปรุงดิน (ข) ทางชีวภาพ — อินทรียวัตถุ ไบโอชาร์ จุลินทรีย์ทนเค็ม (halotolerant PGPR) พืชทนเค็ม/ไม้ยืนต้นฟื้นฟู (phytoremediation, halophytes)
- **ขอบเขตที่ครอบคลุม**: การวินิจฉัย (EC/SAR/แผนที่), วิธีฟื้นฟูทั้ง 3 กลุ่ม, เศรษฐศาสตร์, สถานการณ์ไทย (ภาคอีสาน)
- **นอกขอบเขต**: พันธุศาสตร์/การตัดต่อยีนทนเค็ม (ดู 01-007), การจัดการน้ำเค็มหมุนเวียนในระบบปิด (03-005 — ยังไม่สร้าง), การชลประทานด้วยน้ำเค็ม (ดู 03-001)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                        | แหล่ง  |
| ----------- | ----------------------------------------------------------------------------------- | ------ |
| 1940s       | USDA Salinity Laboratory (Riverside) วางรากฐานการวินิจฉัย EC/SAR/ESP                | [1]    |
| 1970s–1980s | FAO/UNESCO เริ่มทำแผนที่ดินเค็มโลก; งานฟื้นฟูภาคอีสานไทยเริ่ม (กรมพัฒนาที่ดิน)      | [2][3] |
| 1990s–2000s | งานทุ่งกุลาร้องไห้/นาเค็มอีสาน — ไถปรับพื้นที่ + ระบายน้ำ + พันธุ์ทนเค็ม            | [3]    |
| 2010s       | ใช้ดาวเทียม (Landsat/Sentinel-2) + ML ประเมินความเค็มเชิงพื้นที่                    | [7]    |
| 2020s       | ไบโอชาร์/จุลินทรีย์ทนเค็มในการฟื้นฟู + นโยบายพื้นที่ชลประทานน้ำเค็ม (เอเชียใต้/จีน) | [4][5] |

- **เส้นแบ่ง**: ฟื้นฟูแปลงรายพื้นที่ทำได้จริงและมีผลงานขยายผลมานาน แต่การสเกลทั้งภูมิภาคยังติดข้อจำกัดน้ำ/ต้นทุน/การบริหารพื้นที่ — ยังเป็นงานกึ่งวิจัย-กึ่งบริการภาครัฐ

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                         | ผลลัพธ์                                                   | สถานที่/เงื่อนไข                               | แหล่ง |
| --------------------------------- | --------------------------------------------------------- | ---------------------------------------------- | ----- |
| พื้นที่ดินเค็มโลก                 | ~1,000 ล้านเฮกตาร์ (1 พันล้าน)                            | ทั่วโลก — FAO/UNESCO                           | [1]   |
| พื้นที่ชลประทานโลกที่มีปัญหาเกลือ | ~20–33%                                                   | หลายแหล่งต่างกัน — "ใช้เทียบเคียงทิศทาง"       | [2]   |
| ผลผลิตข้าวในดินเค็ม               | ลด ~30–50% เทียบแปลงปกติ                                  | เงื่อนไขต่างกันตามระดับ EC — ช่วงอ้างอิง       | [6]   |
| ไบโอชาร์ + ล้างเกลือ              | ผลผลิตข้าว +20–40%, โซเดียมลดลง                           | แปลงทดลองต่างประเทศ (เอเชียใต้) — ยังไม่ยืนยัน | [4]   |
| ยิปซัมในดินโซดิก                  | SAR/ESP ลดจริง; อัตรา 2–10 ตัน/เฮกตาร์ ตามระดับความรุนแรง | งานต่างประเทศ — ยังไม่ยืนยัน                   | [5]   |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **ตัวเลขพื้นที่ไทย**: กรมพัฒนาที่ดินเคยรายงานพื้นที่ดินเค็มภาคอีสาน ~17 ล้านไร่ กระจาย ~17 จังหวัด (ตัวเลขรุ่นเก่า ยังต้องยืนยันฉบับล่าสุด) [3]

## 5. ตลาดและการลงทุน

- ตลาดผลิตภัณฑ์ปรับปรุงดิน (soil amendments รวมยิปซัม ปูน อินทรียวัตถุ ไบโอชาร์) โลก ~3–5 พันล้านดอลลาร์สหรัฐ (analyst estimate — ยังไม่ยืนยัน) [7] — ตลาดเฉพาะ "การฟื้นฟูดินเค็ม" ยังไม่มีสำนักวัดแยกชัดเจน
- ผู้เล่น: ผู้ผลิตยิปซัม/ปูนเกษตร (ในประเทศเป็นหลัก), ผู้ผลิตไบโอชาร์ (US Biochar Initiative สมาชิก, Biochar Now ฯลฯ), บริษัทชีวภัณฑ์ทนเค็ม (halotolerant inoculants — ผู้เล่นรายย่อยยังไม่ยืนยัน)
- ปัจจัยขับเคลื่อน: การขยายพื้นที่ชลประทาน + การเปลี่ยนแปลงสภาพอากาศ (แล้ง/น้ำเค็มลอยขึ้น), นโยบายความมั่นคงอาหาร
- ปัจจัยฉุดรั้ง: ต้นทุนฟื้นฟูสูง/ใช้เวลาหลายปี, น้ำสำหรับล้างเกลือมีจำกัด, การยอมรับของเกษตรกร

## 6. สถานการณ์ประเทศไทย

- **หน่วยงาน/งานวิจัย**: กรมพัฒนาที่ดินมีแผนที่ดินเค็ม + ศูนย์วิจัยพัฒนาที่ดินอีสาน (ขอนแก่น/อุบลราชธานี) ทำงานฟื้นฟูและขยายผล; มหาวิทยาลัยขอนแก่น/มหาวิทยาลัยอุบลราชธานี/ศูนย์วิจัยข้าว มีงานข้าวทนเค็มและการจัดการนากลุ่มดินเค็ม [3]
- **พื้นที่หลัก**: ภาคอีสาน (บ่อเกลือโบราณ เกลือสินเธาว์ น้ำใต้ดินเค็มลอยขึ้น) — พื้นที่ดินเค็มเกิดใหม่จากน้ำใต้ดินเค็มที่เพิ่มขึ้นเมื่อตัดป่าหรือชลประทานไม่ดี (ยังไม่ยืนยันรายละเอียด)
- **นโยบาย/โครงสร้าง**: แผนการจัดการทรัพยากรน้ำ/ภัยแล้งระดับจังหวัดครอบคลุมบางพื้นที่; ยังไม่มีนโยบายฟื้นฟูดินเค็มเป็นแผนเฉพาะระดับชาติที่ชัดเจน (ยังไม่ยืนยัน)
- **สตาร์ทอัพไทย**: ยังไม่พบผู้เล่นเฉพาะทางด้านฟื้นฟูดินเค็ม (ยังไม่ยืนยัน — ต้องค้นเพิ่ม)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลขพื้นที่ดินเค็มไทยฉบับล่าสุด (หลังปรับปรุงแผนที่ด้วย remote sensing) เท่าไร — ยังอ้างตัวเลขรุ่นเก่าได้เท่านั้น
- **Q2**: ไบโอชาร์/จุลินทรีย์ทนเค็มในแปลงอีสานจริงให้ผลตอบแทนเท่าไร (ยังไม่มีงานแปลงไทยครบวงจร)
- **Q3**: เศรษฐศาสตร์เปรียบเทียบ "ฟื้นฟูดินเค็ม" vs "เปลี่ยนอาชีพ/พืชทนเค็ม" ต่อไร่ — ยังไม่มี
- **Q4**: แบบจำลองการแพร่ของความเค็ม (น้ำใต้ดิน-ผิวดิน) รายลุ่มน้ำย่อยอีสาน — ยังมีงานจำกัด
- **Q5**: ปฏิสัมพันธ์ แล้ง-เค็ม-คาร์บอนในดิน ภายใต้สภาพอากาศเปลี่ยน — ยังตอบไม่ได้
- **Q6**: มาตรฐานการรับรอง/ติดตามผล "แปลงฟื้นฟูสำเร็จ" ที่เกษตรกร/ภาครัฐใช้ร่วมกัน — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                          | ระดับนโยบาย                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงสาธิต "ล้างเกลือ+ระบายน้ำ+ไบโอชาร์/อินทรียวัตถุ" ใน 2–3 จังหวัดอีสาน วัด EC/ผลผลิตก่อน-หลัง 3 ปี          | ปรับปรุงแผนที่ดินเค็มรายปีด้วยดาวเทียม (เชื่อม 02-003) เปิดเผยต่อสาธารณะ                                 |
| 2 (2–4 ปี) | ขยายเป็นบริการ "รับจัดการแปลงเค็ม" ผ่านสหกรณ์/บริษัทเอกชน (เชื่อม 14-004); สนับสนุนไบโอชาร์จากเศษพืชในพื้นที่ | นโยบายสนับสนุนวัสดุฟื้นฟู (ยิปซัม/ปูน/ไบโอชาร์) ผ่านสินเชื่อ ธ.ก.ส.; กันพื้นที่เสี่ยงในการจัดสรรชลประทาน |
| 3 (4+ ปี)  | การฟื้นฟูเป็นมาตรฐานการผลิต (จีไอ/การรับรอง) สำหรับสินค้าอีสาน; ผูกกับคาร์บอนในดิน (02-002/02-005)            | แผนฟื้นฟูดินเค็มระดับชาติ + กติกาน้ำใต้ดินร่วมระดับลุ่มน้ำ                                               |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย              | รายละเอียด                                      | โอกาสแก้                                                    |
| ----------------------- | ----------------------------------------------- | ----------------------------------------------------------- |
| ความเค็มเกิดซ้ำ         | น้ำใต้ดินเค็มลอยขึ้นเมื่อไม่มีการจัดการระบายน้ำ | ระบบระบายน้ำ/ไถปรับพื้นที่อย่างต่อเนื่อง                    |
| ต้นทุน/ระยะเวลา         | ฟื้นฟูใช้เวลา 3–10 ปี งบสูง                     | ลำดับความสำคัญตามแผนที่เสี่ยง + การสนับสนุนระยะยาว          |
| ตัวเลข/ข้อมูลกระจาย     | แผนที่รุ่นเก่า ข้อมูลรายแปลงไม่เปิด             | remote sensing + ฐานข้อมูลกลาง (เชื่อม 02-003)              |
| น้ำไม่พอสำหรับล้างเกลือ | การล้างเกลือต้องใช้น้ำมาก — ขัดแย้งกับภัยแล้ง   | จัดลำดับการใช้น้ำ; ใช้วิธีชีวภาพเสริม (ไบโอชาร์/จุลินทรีย์) |
| Adoption                | เกษตรกรลังเล ต้องรอผลหลายปี                     | แปลงสาธิต + ผลตอบแทนระยะยาวที่จับต้องได้                    |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **พื้นที่ดินเค็มไทย ~17 ล้านไร่ (ภาคอีสาน ~17 จังหวัด)** — ตรวจเอกสาร/เว็บกรมพัฒนาที่ดินฉบับล่าสุด แล้วแทนที่ตัวเลขในหัวข้อ 4/6
- [ ] **ช่วง "พื้นที่ชลประทานโลกมีปัญหาเกลือ 20–33%"** — ระบุแหล่งต้นฉบับ (FAO อ้าง 20%, 33% จาก Ghassemi et al.) แล้วทำให้เป็นตัวเลขเดียวหรือเก็บช่วงพร้อมแหล่ง
- [ ] **ไบโอชาร์ +20–40% / ยิปซัม 2–10 ตัน/เฮกตาร์** — ค้นงาน primary (Soil Science Society of America Journal, Agricultural Water Management) ยืนยันอัตรา
- [ ] **ข้าวในดินเค็มผลผลิตลด 30–50%** — ยืนยันช่วงจาก Field Crops Research/metadata
- [ ] **ตลาด soil amendments 3–5 พันล้านดอลลาร์** — หาแหล่ง analyst ที่ระบุปีให้ชัด (หรือเปลี่ยนเป็น "ไม่ระบุ")
- [ ] **งานวิจัยไทยฟื้นฟูดินเค็ม (ทุ่งกุลา ฯลฯ)** — ค้น TCI/ThaiJo เพิ่มเติมรายชิ้น + DOI ลงหัวข้อ 12

## 11. อภิธานศัพท์

| คำศัพท์                      | ความหมาย                                                      |
| ---------------------------- | ------------------------------------------------------------- |
| EC (Electrical Conductivity) | ค่าการนำไฟฟ้าของดิน/น้ำ ใช้บอกระดับความเค็ม                   |
| SAR / ESP                    | สัดส่วนโซเดียมแลกเปลี่ยนได้ — บอกความเป็น "ดินโซดิก"          |

| Leaching                     | การล้างเกลือลงล่างด้วยน้ำ                                     |
| Halophyte                    | พืชที่ทน/เจริญในที่เค็มตามธรรมชาติ                            |
| Phytoremediation             | การใช้พืชดูด/ตรึงเกลือเพื่อฟื้นฟูดิน                          |
| Halotolerant PGPR            | จุลินทรีย์ส่งเสริมพืชที่ทนเค็ม (ดู 02-007)                    |
| Osmotic stress               | ความเครียดจากแรงดันออสโมติก — พืชดูดน้ำไม่ได้เพราะเกลือ       |
