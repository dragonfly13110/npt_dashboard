## 1. บทสรุปผู้บริหาร

- **ใจความ**: ไบโอแก๊ส (Biogas) = แก๊สจากการย่อยสลายของเสียอินทรีย์ในบ่อหมักไร้ออกซิเจน (Anaerobic digestion) — ใช้ได้ 3 ทาง: (1) แก๊สหุงต้มในครัวเรือน/ฟาร์ม (2) ผลิตไฟฟ้า+ความร้อน (CHP) (3) ยกระดับเป็น "ไบโอมีเทน" (Biomethane — ~95%+ มีเทน) ใช้แทน CNG/LNG ในรถยนต์/รถบรรทุก หรืออัดใส่ท่อแก๊ส — ไทย: บ่อแก๊สชีวภาพในฟาร์มสุกร/โคนมมีมานาน (โครงการในหลวง/กรมปศุสัตว์/ESCO-class) + การผลิตไฟฟ้าจากขยะ/ของเสีย (IPP/VSPP — รับซื้อ); ไบโอมีเทนสำหรับรถ (NGV-class) เริ่ม [1][2][3]
- **ขั้นพัฒนา**: 🏭 เทคโนโลยี成熟/ใช้งานแล้ว (ไทย: ฟาร์มสุกร/โคนม + โรงไฟฟ้าชีวภาพมีจริง) — ไบโอมีเทนระดับสูง (LNG/ท่อ) ยังกำลังขยาย [2][3]
- **ตัวเลขสำคัญที่สุด**: ผลผลิตแก๊สจากมูลสุกร/โค ~0.3–1.5 ม³/กก. ของแข็งแห้ง (ช่วง — ขึ้นชนิด/ระบบ); ไฟฟ้าจากไบโอแก๊ส ~2–3.5 กิโลวัตต์ชั่วโมง/กก. ของแข็งแห้ง (ช่วง); ฟาร์มสุกร 1,000 ตัว → ไฟฟ้า ~20–60 กิโลวัตต์ (ช่วง); ต้นทุนบ่อ/โรง ~2–8 ล้านบาท/MW-ติดตั้ง (ช่วง); ไทย: โรงไฟฟ้าชีวภาพ (ขยะ/ของเสีย) ~600+ เมกะวัตต์ (ช่วง — สถานะต้องตรวจ) [1][2][4]
- **นัยต่อไทย**: ไทยมี "ของเสีย" เยอะ (สุกร ~10–15 ล้านตัว/โคนม/ขยะ/กากมัน/น้ำเสียโรงงาน) — ไบโอแก๊ส = 2 ประโยชน์: (1) ไฟฟ้า/แก๊ส (ลดค่าไฟฟาร์ม/ขายไฟ — 08-004 ผูก) (2) ลดกลิ่น/สิ่งแวดล้อม + น้ำหมักเป็นปุ๋ย (02-005) + ลดมีเทน (คาร์บอน — 08-002) — จุดสำคัญ: (1) เศรษฐศาสตร์ต้องมี "ของเสียฟรี/อยู่แล้ว" (ไม่ใช่ลงทุนเพื่อของเสีย) (2) เลือกขนาด: ครัวเรือน/ฟาร์มเล็ก (บ่อแก๊ส 4–6 ม³) vs ฟาร์มใหญ่/โรงงาน (ไฟฟ้า — รับซื้อ) (3) ไบโอมีเทน/เชื้อเพลิงรถ (ไทย — นโยบาย NGV/B7-class) เริ่ม [2][3][4]
- **สถานะโดยรวม**: 🏭 ใช้จริง (ไทยมีโรง/บ่อเยอะ) — ไบโอมีเทนระดับสูงกำลังขยาย

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (4 ขั้นตอนย่อยสลาย)

1. **การไฮโดรไลซิส (Hydrolysis)**: จุลินทรีย์ย่อยโมเลกุลใหญ่ (ไขมัน/โปรตีน/คาร์โบไฮเดรต) → โมเลกุลเล็ก
2. **แอซิโดเจเนซิส (Acidogenesis)**: แบคทีเรียสร้างกรด (VFAs)
3. **แอซีโตเจเนซิส (Acetogenesis)**: กรด → อะซิเตต/ไฮโดรเจน/CO2
4. **เมทาโนเจเนซิส (Methanogenesis)**: อาร์เคียสร้างมีเทน (CH4 ~50–70% + CO2) — "หัวใจ = อุณหภูมิ (mesophilic 30–40°C / thermophilic 50–60°C), pH, อัตราส่วน C/N, การกวน"

### 2.2 ระบบ/ขนาด (ตาราง)

| ประเภท                                | ขนาด      | ใช้ทำอะไร                                      | เหมาะกับ                                |
| ------------------------------------- | --------- | ---------------------------------------------- | --------------------------------------- |
| บ่อแก๊สครัวเรือน/ฟาร์มเล็ก            | 4–10 ม³   | แก๊สหุงต้ม (ครัวเรือน 3–5 ชั่วโมง/วัน)         | ฟาร์มหมู/วัวเล็ก, ครัวเรือน (มีของเสีย) |
| ฟาร์มขนาดกลาง                         | 30–200 ม³ | แก๊ส + ไฟใช้เอง (ปั๊มน้ำ/ไฟฟาร์ม)              | ฟาร์มหมู 500–5,000 ตัว                  |
| โรงไฟฟ้าชีวภาพ (ฟาร์มใหญ่/โรงงาน/ขยะ) | MW-class  | ไฟฟ้าขาย (IPP/VSPP — รับซื้อ) + ความร้อน (CHP) | ฟาร์มใหญ่/โรงงานน้ำมันปาล์ม/ขยะเทศบาล   |
| ไบโอมีเทน (อัด/LNG-class)             | โรงงาน    | เชื้อเพลิงรถ (CNG/LNG) / อัดท่อแก๊ส            | ฟาร์มใหญ่/โรงงาน (ของเสียเยอะ)          |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ขนาด/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: โซลาร์/ไฟฟ้าอื่น (08-001/08-004), เอทานอล/ไบโอดีเซล (12 — นโยบาย), ขยะพลาสติก (12), รายละเอียดปุ๋ยน้ำหมัก (02-005)

- **หมายเหตุ**: ตัวเลขไทย/ราคารับซื้อต้องตรวจอัปเดต (นโยบายเปลี่ยน)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดไบโอแก๊สโลก ~$20–40 พันล้านดอลลาร์ (2030 — analyst ช่วง); ตลาดไบโอมีเทนโตเร็ว (EU — เป้าหมาย 35 bcm 2030-class); ไทย: ไฟฟ้าชีวภาพ (ขยะ/ของเสีย) ~600+ MW (ช่วง) + การใช้ในฟาร์ม [3][4]
- **ผู้เล่นหลัก**: ผู้ประกอบการฟาร์ม/โรงงาน (แหล่งของเสีย), ผู้รับเหมา/เทคโนโลยี (บ่อ/โรง — ไทย+ต่างประเทศ), กรมปศุสัตว์/ESCO-class (หนุนฟาร์ม), การไฟฟ้า/กกพ. (รับซื้อ), ปตท./กลุ่มพลังงาน (ไบโอมีเทน/NGV), บริษัทคาร์บอน (08-002)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                                   | ฉุดรั้ง                                  |
| -------------------------------------------- | ---------------------------------------- |
| ของเสียฟรี/ต้องจัดการอยู่แล้ว (ฟาร์ม/โรงงาน) | ต้นทุนลงทุน (บ่อ/โรง)                    |
| ลดกลิ่น/สิ่งแวดล้อม/ค่าไฟ                    | เศรษฐศาสตร์รายเล็ก (บ่อเล็กไม่คุ้มค่าไฟ) |
| ไฟฟ้ารับซื้อ (VSPP/ขยะ)                      | ราคารับซื้อ/นโยบายเปลี่ยน                |
| ไบโอมีเทน/เชื้อเพลิงรถ (นโยบาย NGV-class)    | เอกสาร/การรับรอง (ของเสีย/แก๊ส)          |
| คาร์บอน (08-002 — ลดมีเทน)                   | ความรู้/การบำรุง (บ่อพัง/แก้แก๊ส)        |

- **แนวโน้ม**: ไบโอมีเทน/กรีนแก๊ส (ท่อ/LNG — แทน LPG/NGV), การผูกคาร์บอน/การตลาด ESG (08-002), การควบคุม 4.0 (เซนเซอร์/AI — 06-001 — เพิ่มประสิทธิภาพ), การใช้ร่วมโซลาร์ (08-001 — ไฟฟ้าผสม), กากย่อยสลายเป็นปุ๋ย/สารปรับดิน (02-005)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยใช้ไบโอแก๊สมานาน — (1) บ่อแก๊สฟาร์มสุกร/โคนม (กรมปศุสัตว์/โครงการหนุน — หลายพันบ่อ — ประเมิน) (2) โรงไฟฟ้าชีวภาพ (ขยะเทศบาล/กากปาล์ม/น้ำเสียโรงงาน — รับซื้อ VSPP/IPP) (3) ไบโอมีเทน/แก๊สชีวภาพอัด (เริ่ม — นโยบาย NGV/CNG-class) — งานวิจัยไทย (โคไดเจสชัน/เพิ่มประสิทธิภาพ/ของเสียเฉพาะ — กากมัน/น้ำเสีย) มี [2][4][5]
- **จุดแข็งไทย**: ของเสียเยอะ (สุกร/โค/ปาล์ม/ขยะ/โรงงาน — ฟรี), เทคโนโลยี/ผู้รับเหมามี (ใช้แล้ว), นโยบายรับซื้อไฟ (VSPP), งานวิจัย/หน่วยงาน (มก./กรมปศุสัตว์/สวทช.), โครงการในหลวง/สังคม (บ่อแก๊ส — เข้าถึง)
- **จุดอ่อน**: บ่อเล็กคุ้มน้อย (ค่าไฟไม่พอ/บำรุงยาก), ราคารับซื้อ/นโยบายเปลี่ยน, การบำรุง/แก้แก๊ส (ผู้ดูแลน้อย), ของเสียบางชนิดสับสนกับขยะ (กฎ/การรับรอง), ไบโอมีเทนยังนำร่อง (โครงสร้าง/การตลาด), ข้อมูลแปลง/บ่อ (ยังไม่เป็นระบบ)
- **โอกาส**: (1) "ฟาร์มสุกร/โคนม 4.0" (บ่อเดิม + เซนเซอร์/AI ควบคุม — 06-001 — เพิ่มแก๊ส/ลดกลิ่น) (2) "ไบโอมีเทนไทย" (ฟาร์ม/โรงใหญ่ — นโยบาย NGV/ท่อ — เอาแก๊สขายแทนเผาทิ้ง) (3) "โรงไฟฟ้าขยะ/กากครบวงจร" (ขยะเทศบาล/กากปาล์ม — รับซื้อ + คาร์บอน 08-002) (4) "ปุ๋ยน้ำหมัก/สารปรับดิน" (02-005 — ขายกาก) (5) "คาร์บอนเครดิต" (08-002 — ลดมีเทน — รายได้เสริม)
- **หน่วยงาน**: กรมปศุสัตว์/กรมพัฒนาพลังงานทดแทน (กพพ. — หนุน), กกพ./การไฟฟ้า (รับซื้อ), อบก. (คาร์บอน — 08-002), มก./มจธ./สวทช. (วิจัย), ปตท./ผู้ประกอบการ (ไบโอมีเทน), องค์กรปกครองส่วนท้องถิ่น (ขยะ)

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ผลผลิตแก๊ส 0.3–1.5 ม³/กก. ของแข็งแห้ง** — ตรวจงาน (ระบุชนิด/ระบบ)
- [ ] **ไฟฟ้า 2–3.5 กิโลวัตต์ชั่วโมง/กก. ของแข็งแห้ง** — ตรวจงาน
- [ ] **ฟาร์มสุกร 1,000 ตัว → 20–60 กิโลวัตต์** — ตรวจผู้ประกอบการ/งาน
- [ ] **บ่อ 4–6 ม³ พอหุงต้ม 3–5 ชม./วัน** — ตรวจโครงการ (กรมปศุสัตว์)
- [ ] **ต้นทุน 2–8 ล้านบาท/MW** — ตรวจตลาด/งาน
- [ ] **โรงไฟฟ้าชีวภาพไทย ~600+ เมกะวัตต์ (สถานะ)** — ตรวจ กพพ./ก.พลังงาน (ระบุปี)
- [ ] **ราคารับซื้อไฟชีวภาพไทย 2–5 บาท/กิโลวัตต์ชั่วโมง** — ตรวจกกพ.ล่าสุด
- [ ] **ระยะคืนทุน 3–8 ปี** — ตรวจผู้ประกอบการ/งาน
- [ ] **สถานะไบโอมีเทน/แก๊สอัดไทย (นำร่อง/นโยบาย)** — ตรวจข่าว/ปตท.
- [ ] **ตลาดไบโอแก๊สโลก $20–40 พันล้าน (2030)** — ตรวจ analyst report ระบุปี

## 11. อภิธานศัพท์

| คำศัพท์                     | ความหมาย                                                 |
| --------------------------- | -------------------------------------------------------- |
| Biogas                      | ไบโอแก๊ส (CH4 ~50–70% + CO2 — จากการย่อยสลายไร้ออกซิเจน) |
| Anaerobic digestion (AD)    | การย่อยสลายไร้ออกซิเจน (บ่อหมัก)                         |
| Biomethane                  | ไบโอมีเทน (~95%+ CH4 — ยกระดับ — ใช้แทน CNG/LNG)         |
| CHP                         | ผลิตไฟฟ้า+ความร้อนพร้อมกัน                               |
| Mesophilic / Thermophilic   | อุณหภูมิหมัก 30–40°C / 50–60°C                           |
| Hydrolysis → Methanogenesis | 4 ขั้นตอนย่อยสลาย (หัวใจของบ่อ)                          |
| Feedstock                   | วัตถุดิบ/ของเสีย (มูล/น้ำเสีย/กาก)                       |
| Co-digestion                | การหมักของเสียรวม 2+ ชนิด (เพิ่มแก๊ส)                    |
| Digestate                   | กากย่อยสลาย (ปุ๋ย/สารปรับดิน — 02-005)                   |
| VSPP / IPP                  | ผู้ผลิตไฟฟ้าขนาดเล็ก/เอกชน (สัญญารับซื้อ)                |
| NGV / CNG / LNG             | เชื้อเพลิงแก๊สรถยนต์ (ไบโอมีเทนแทนได้)                   |
| VFA                         | กรดอินทรีย์ (ระหว่างย่อย — ควบคุม pH)                    |
| C/N ratio                   | อัตราส่วนคาร์บอน/ไนโตรเจน (คุณภาพของเสีย)                |
| Floating drum / Fixed dome  | บ่อแก๊ส 2 แบบ (ถังลอย/โดมคงที่)                          |
| Biogas upgrading            | การยกระดับแก๊ส → ไบโอมีเทน                               |
| ปตท.                        | กลุ่มพลังงานไทย (ไบโอมีเทน/NGV)                          |
| กพพ. (DEDE)                 | กรมพัฒนาพลังงานทดแทน (นโยบาย)                            |
| บ่อทิ้งร้าง                 | บ่อที่เลิกใช้ (ปัญหา — การดูแล)                          |
