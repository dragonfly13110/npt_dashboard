## 1. บทสรุปผู้บริหาร

- **ใจความ**: Aquaponics = ระบบบูรณาการเลี้ยงปลา (นิยมปลานิล) กับปลูกผักไร้ดินในวงจรน้ำเดียว — ของเสียปลา (แอมโมเนีย) ถูกจุลินทรีย์เปลี่ยนเป็นไนเตรตที่เป็นธาตุอาหารผัก ผักกรองน้ำกลับให้ปลา — ตอบโจทย์ "อาหารปลอดภัยในเมือง" ด้วยการใช้น้ำน้อย (ประหยัดน้ำ ~30% เทียบไฮโดรโปนิกส์) ไม่ใช้ปุ๋ยเคมี/สารเคมี และผลิตปลา+ผักจากพื้นที่เล็กใกล้ผู้บริโภค [5][6]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น — โลกมีฟาร์มขนาดใหญ่ทำกำไรได้จริงเพียงไม่กี่ราย (Superior Fresh สหรัฐฯ ผลิตแซลมอน ~1.5 ล้านปอนด์ + ผักออร์แกนิก ~3 ล้านปอนด์/ปี) แต่ผลสำรวจพบฟาร์มเชิงพาณิชย์สหรัฐฯ เพียง 31% กำไรใน 12 เดือน และยุโรปถูกประเมินว่าอยู่ใน "หุบเหวแห่งความผิดหวัง" (trough of disillusionment) — ไทยเป็นระดับ 🧪 งานวิจัย + ฟาร์มรายย่อยเริ่มขายพรีเมียม [3][4][7]
- **ตัวเลขสำคัญที่สุด**: ออกแบบระบบด้วย "อัตราส่วนอาหารปลา:พื้นที่ปลูกผัก" 60–100 กรัมอาหาร/ตร.ม./วัน (DWC, งาน UVI 25 ปี — มาตรฐานอ้างอิงโลก) [9]; ผลผลิตปลานิล 21.33 กก./ลบ.ม. FCR 1.36 (เม็กซิโก NFT 2025) [5]; แต่แบบจำลองเชิงพาณิชย์ 73 พารามิเตอร์พบค่า NPV 5 ปีเฉลี่ยติดลบ -US$21,991 และมีเพียง ~25% ของสถานการณ์ที่กำไร — กำไรจริงอยู่ที่ "ผลผลิตผักต่อพื้นที่ + ราคาพรีเมียม + แหล่งรายได้รอง" ไม่ใช่ที่ตัวระบบ [1][2]
- **นัยต่อไทย**: งานวิจัยไทย (มก./ขอนแก่น/แม่โจ้/มทร.อีสาน/มรภ.มหาสารคาม/เชียงใหม่) ยังอยู่ระดับถังทดลอง 28–120 วัน — โจทย์ที่แท้จริงของไทยคือ (1) ออกแบบอัตราส่วนปลา:ผักให้เหมาะกับปลานิล+ผักสลัดเมืองร้อน (2) บวกธาตุ K/Fe/Ca และจัดการโซเดียม (3) หาโมเดลธุรกิจพรีเมียม+ท่องเที่ยว/อบรม เพราะรายได้ผักคิด ~60–87% ของมูลค่าระบบ [18][19][20][30]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (โลก) — ไทย 🧪 นำร่อง/ฟาร์มรายย่อย

## 2. หลักการและขอบเขต

- **กลไกหลัก**: ปลากินอาหาร → ขับถ่ายแอมโมเนีย (NH₃/NH₄⁺) → จุลินทรีย์ไนตริฟาย (Nitrosomonas, Nitrobacter/Nitrospira) เปลี่ยนเป็นไนไตรต์แล้วไนเตรต (NO₃⁻) ซึ่งเป็นปุ๋ยหลักของผัก → รากผักดูดธาตุอาหาร + กรองน้ำ → น้ำสะอาดหมุนกลับบ่อปลา ระบบเดียวหมุนเวียนเกือบปิด ใช้น้ำใหม่เพียง 1.5–5% ต่อวัน (UVI) [9]
- **ระบบย่อยหลัก 3 แบบ**: (1) DWC/Raft (แพลอยน้ำ — ที่นิยมเชิงพาณิชย์ ผลผลิตสูงสุด ต้องการออกซิเจนมาก) (2) NFT (รางน้ำลาดเอียง — ประหยัดน้ำ/พื้นที่ แต่กรองชีวภาพน้อย ต้องมี biofilter แยก) (3) Media-filled bed (ถังกรวด/หินภูเขาไฟ — เหมาะครัวเรือน/สเกลเล็ก ทำทั้งกรองและปลูกในตัว) [9][10]
- **ตัวแปรออกแบบสำคัญ**: "feeding rate ratio" (กรัมอาหารปลา/ตร.ม. พื้นที่ปลูก/วัน) เป็นตัวกำหนดสมดุล — เกินไปน้ำเน่า/ปลาเครียด น้อยไปผักขาดธาตุ; ต้องถ่างรอบเลี้ยงปลา (staggered) ให้อาหารเข้าสม่ำเสมอ [9][10]
- **ขอบเขตที่ครอบคลุม**: หลักการ/ระบบย่อย/ตัวเลขผลผลิต-เศรษฐศาสตร์/ผู้เล่นโลก/งานวิจัยไทย/แนวทางใช้ — เน้นปลานิล+ผักสลัด (คู่ที่ใช้จริงในไทย)
- **นอกขอบเขต**: เศรษฐศาสตร์ RAS ล้วน (ดู RAS), ตลาดผักไฮโดรโปนิกส์ไทย (04-006), เทคนิคสารละลาย/EC/pH เชิงลึก (04-007), ระบบ BFT/ไบโอฟลอค (ดูไฟล์ IMTA/อาหารสัตว์น้ำ)

## 3. สถานะงานวิจัย

- **เส้นแบ่ง**: เทคนิคชีวภาพ (เลี้ยงปลา+ผักให้รอด) สุกแล้วตั้งแต่ยุค UVI — เกมปัจจุบันคือ "เศรษฐศาสตร์สเกลใหญ่ + ตลาดพรีเมียม + ข้อกฎหมาย" ยังพิสูจน์ยาก (ฟาร์มเชิงพาณิชย์กำไรจริงมีน้อย, ยุโรปยังไม่มีนโยบายรองรับ) [1][3][4]

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ต้นทุน/จุดคุ้มทุนอควาโปนิกส์เชิงพาณิชย์ไทย (บาท/กก. ทั้ง CAPEX+OPEX, ต่อไร่/ต่อถัง) — ยังไม่มีข้อมูลเปิด (ฟาร์ม CLV เป็นข้อมูลภายใน) [24]
- **Q2**: อัตราส่วนพื้นที่ผัก:อาหารปลา (feeding rate ratio) ที่เหมาะกับปลานิล+ผักสลัดเมืองร้อน 28–35°C — งานไทยส่วนใหญ่สเกลเล็ก (120–500 ลิตร) ยังไม่มีชุดข้อมูลสเกลกลางแบบ UVI [18][19]
- **Q3**: การสะสมโซเดียม/ธาตุอาหารพืชไม่ครบ (K/Fe/Ca) ในน้ำไทย (น้ำฝน/น้ำประปา/น้ำบาดาล) และสูตรการเสริมที่ปลอดภัยต่อปลา — ยังไม่มีงานไทย (งานต่างประเทศชี้ Na >34.5 มก./ล. เป็นพิษผัก; UVI ต้องใช้น้ำฝนเพราะน้ำบาดาลเค็ม) [9][12]
- **Q4**: ส่วนเพิ่มราคา (WTP) ผัก+ปลาอควาโปนิกส์ไทยเทียบไฮโดรโปนิกส์/ปลาบ่อ — ยังไม่มีงาน WTP ไทย (มาเลเซีย/UK มีแล้ว) [15]
- **Q5**: รายได้รอง (ท่องเที่ยว/อบรม/อุปกรณ์/แฟรนไชส์ชุด DIY) คิดสัดส่วนเท่าไรในฟาร์มไทย และช่วยจุดคุ้มทุนจริงหรือไม่ — ยังไม่มีข้อมูลไทย (ต่างประเทศ 63% ของรายได้ผู้ประกอบการ) [4]
- **Q6**: เส้นทางสเกลอัปจากงานทดลองไทยไประบบ DCAP/เชิงพาณิชย์ (การแยกลูปปลา-ผักเพิ่มผลผลิตผัก 15–72% ในงานกรีซ) — ยังไม่มีการสาธิตระดับกลางในไทย [13]

## 11. อภิธานศัพท์

| คำศัพท์                      | ความหมาย                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Aquaponics / อควาโปนิกส์     | ระบบผลิตปลา+ผักในวงจรน้ำเดียว — ของเสียปลาเป็นธาตุอาหารผัก, ผักกรองน้ำคืนปลา                                      |
| CAP (Coupled)                | ระบบลูปเดียว — น้ำไหลเวียนระหว่างบ่อปลาและแปลงผักโดยตรง                                                           |
| DCAP/DRAPS (Decoupled)       | ระบบหลายลูป — แยกควบคุมบ่อปลา/แปลงผักอิสระ (ผลผลิตผักสูงกว่า, ลงทุนสูงกว่า)                                       |
| Feeding rate ratio           | อัตราส่วนอาหารปลา (กรัม/วัน) ต่อพื้นที่ปลูกผัก (ตร.ม.) — ตัวแปรออกแบบสมดุลระบบ (60–100 กรัม/ตร.ม./วัน สำหรับ DWC) |
| Nitrification / ไนตริฟิเคชัน | กระบวนการจุลินทรีย์เปลี่ยนแอมโมเนีย→ไนไตรต์→ไนเตรต (ธาตุอาหารหลักของผัก)                                          |
| TAN                          | แอมโมเนียรวมในน้ำ — ต้องควบคุมไม่ให้เป็นพิษต่อปลา                                                                 |
| DWC / Raft                   | ระบบน้ำลึก-แพลอยน้ำ (Deep Water Culture)                                                                          |
| NFT                          | ระบบรางน้ำลาดเอียง (Nutrient Film Technique) — กรองชีวภาพน้อย ต้องมี biofilter                                    |
| FCR (Feed Conversion Ratio)  | อัตราแลกเนื้อ — อาหาร (กก.) ต่อน้ำหนักปลาที่เพิ่ม 1 กก.                                                           |
| WTP (Willingness To Pay)     | ราคาสูงสุดที่ผู้บริโภคยอมจ่าย (สำหรับสินค้าพรีเมียม/ปลอดภัย)                                                      |
| GWP                          | ศักยภาพการทำให้โลกร้อน (กก.CO₂-equivalent) — ใช้วัดผลกระทบ LCA                                                    |
| BAP / GAP                    | มาตรฐานการเพาะเลี้ยงสัตว์น้ำที่ดี / มาตรฐานการปฏิบัติทางการเกษตรที่ดี                                             |
| ไข่ผำ (Wolffia)              | พืชน้ำขนาดเล็กโปรตีนสูง — ใช้เป็นผัก/อาหารสัตว์ในระบบ (งาน มรภ.มหาสารคาม)                                         |
| BEP / NPV / IRR              | จุดคุ้มทุน / มูลค่าปัจจุบันสุทธิ / อัตราผลตอบแทนภายใน                                                             |
| 30 by 30 (สิงคโปร์)          | เป้าหมายผลิตอาหารในประเทศ 30% ภายใน 2030 — กรอบนโยบายที่อควาโปนิกส์สิงคโปร์อ้างอิง                                |
