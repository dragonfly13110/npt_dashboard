## 1. บทสรุปผู้บริหาร

- **ใจความ**: Cultivated meat (เนื้อเพาะเลี้ยง/เนื้อห้องแล็บ) = เลี้ยงเซลล์กล้ามเนื้อสัตว์ใน bioreactor (จากเซลล์จริง — ไม่ใช่พืช) — สถานะ 2026: ขายจริงในสิงคโปร์ (ตั้งแต่ 2020 — Eat Just-class) + สหรัฐฯ (FDA/USDA อนุมัติ 2023 — Upside Foods/Good Meat) + อิสราเอล; แต่ "อิตาลีแบน" (2566 — กฎหมายห้ามขาย/ผลิต — แรกในโลก) + ฟลอริดา/แอละแบมา (สหรัฐฯ — 2567) — ยุโรป/ญี่ปุ่น/จีนยังไม่มีอนุมัติขาย; ไทย: ยังไม่มีกฎหมายเฉพาะ/ท่าทีรอดู — แต่ CPF/Thai Union-class ลงทุนแล้ว — "เทคโนโลยีมีจริงแต่ยังแพง/ไม่ยอมรับทุกที่" [1][2][3]
- **ขั้นพัฒนา**: 🧪 นำร่อง/ขายในบางประเทศ (สิงคโปร์/US/อิสราเอล) — ยังไม่แพร่ (ราคา/กำลังผลิต/กฎหมาย) [2][3]
- **ตัวเลขสำคัญที่สุด**: ต้นทุนผลิตลดลงมาก (จาก ~$280,000/เบอร์เกอร์ ปี 2013 — Mosa Meat-class → ~$10–30/กก. ในโรงงานนำร่องบางแห่ง — ช่วง); กำลังผลิต (โรงแรก — ใหญ่สุด ~100,000–200,000 ลิตร-class — ช่วง); ตลาด (analyst — $100 ล้าน–1 พันล้านดอลลาร์ กลางทศวรรษ 2030 — ช่วงกว้าง); ราคาขายปลีก (สิงคโปร์/US — เริ่ม ~$17–30/เนื้อบด 100–150 กรัม-class — ช่วง); การลงทุนรวม (2016–2024 ~$3 พันล้านดอลลาร์+ — ช่วง) [1][3][4]
- **นัยต่อไทย**: ไทย = ผู้ผลิตอาหาร/ส่งออกใหญ่ (CPF/Thai Union/Betagro) + มีอุตสาหกรรมเนื้อ (วัว/หมู/ไก่) — แต่: (1) ยังไม่มีกฎหมายเฉพาะ (ใช้กฎหมายอาหารทั่วไป — อย. — ยังไม่ชัด) (2) ภาคปศุสัตว์ไทย (ห่วงโซ่เนื้อ — ฟาร์ม/โรงฆ่า) อาจได้ผลกระทบ (3) ตลาดไทย (การยอมรับ — ยังไม่รู้) — จุดสำคัญ: (1) ติดตาม "กฎหมาย/อนุมัติ" (อย.ไทย/ตลาดหลัก — EU/สหรัฐฯ/จีน) (2) ดู "นโยบายอาหารไทย" (12 — อาหารแห่งอนาคต — นโยบายมี) (3) การลงทุนไทย (CPF ลงทุน Aleph Farms-class — รอดูการตลาด) [2][3][5]
- **สถานะโดยรวม**: 🧪 นำร่อง/ขายในบางประเทศ (สิงคโปร์/US/อิสราเอล) — กฎหมาย/ตลาดยังไม่นิ่ง

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (กระบวนการ)

1. **เก็บเซลล์ (Biopsy)**: เซลล์กล้ามเนื้อจากสัตว์ (วัว/หมู/ไก่/ปลา — ไม่ต้องฆ่า)
2. **ขยายเซลล์ (Proliferation)**: เลี้ยงใน bioreactor (อาหารเลี้ยงเซลล์ — serum เริ่ม/ไม่มี serum — ใหญ่ขึ้นเรื่อยๆ)
3. **แยกความแตกต่าง (Differentiation)**: เซลล์ → เส้นใยกล้ามเนื้อ (โครงนั่งร้าน/scaffold — เนื้อสัมผัส)
4. **แปรรูป (Harvest/Processing)**: เก็บ/ปั้น/ปรุงรส → เนื้อบด/นักเก็ต/สเต็ก (โครงสร้าง)

### 2.2 เทคโนโลยีหลัก/ผู้เล่น (ตาราง)

| เทคโนโลยี              | รายละเอียด                                    | ผู้เล่น (ตัวอย่าง)                                                       |
| ---------------------- | --------------------------------------------- | ------------------------------------------------------------------------ |
| เซลล์จริง (cultivated) | เลี้ยงเซลล์ใน bioreactor (ราคาแพง/กฎหมายเข้ม) | Eat Just/Good Meat, Upside Foods, Aleph Farms, Mosa Meat, Believer Meats |
| ผสม (hybrid)           | เซลล์+โปรตีนพืช (ราคาถูกกว่า/เริ่มง่าย)       | ผู้เล่นหลายราย (จุดเริ่ม)                                                |
| อาหารเลี้ยงเซลล์       | Serum-free (ลดต้นทุน — วิจัย)                 | งานวิจัย/ผู้ผลิต media                                                   |
| Bioreactor ใหญ่        | 5,000–200,000 ลิตร-class (ลดต้นทุน)           | ผู้ผลิตอุปกรณ์/ผู้เล่นใหญ่                                               |

### 2.3 ขอบเขต

- **ครอบคลุม**: สถานะ/กฎหมาย/ตลาด/ต้นทุน/ไทย — **นอกขอบเขต**: โปรตีนแมลง (10-002), พืช/โปรตีนทางเลือกอื่น (10-005), เซลล์เซ็นเซอร์/เทคนิคชีวภาพลึก (01), กฎหมายอาหารลึกไทย (12)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                         | ผลลัพธ์                                           | สถานที่/เงื่อนไข | แหล่ง  |
| --------------------------------- | ------------------------------------------------- | ---------------- | ------ |
| ต้นทุนเบอร์เกอร์แรก (2013)        | ~$280,000/ชิ้น (Mosa Meat-class)                  | งานสาธิต         | [1]    |
| ต้นทุนล่าสุด (โรงนำร่อง)          | ~$10–30/กก. (ช่วง — อ้างผู้เล่น)                  | ผู้เล่น/งาน      | [3]    |
| ราคาขายปลีก (สิงคโปร์/US — เริ่ม) | ~$17–30/แพ็ก 100–150 กรัม-class (ช่วง)            | ตลาด             | [2][3] |
| กำลังผลิต (โรงใหญ่สุด)            | ~100,000–200,000 ลิตร bioreactor-class (ช่วง)     | ผู้เล่น          | [3]    |
| การลงทุนสะสม (2016–2024)          | ~$3 พันล้านดอลลาร์+ (ช่วง)                        | analyst          | [4]    |
| ตลาด (กลางทศวรรษ 2030)            | ~$100 ล้าน–1 พันล้านดอลลาร์ (ช่วงกว้าง — analyst) | analyst          | [4]    |
| การยอมรับผู้บริโภค (นานาชาติ)     | ~30–60% "ลองกิน" (ช่วง — ขึ้นประเทศ/ข้อมูล)       | งาน              | [5]    |
| ประเทศที่ขาย/แบน (2026)           | ขาย ~3–4 ประเทศ-class / แบน ~3 แห่ง-class         | ข่าว/กฎหมาย      | [2][3] |

- **หมายเหตุ**: ตัวเลข/สถานะเปลี่ยนเร็ว (กฎหมาย/ตลาด/ผู้เล่นล้ม-รวม) — ต้องตรวจอัปเดตทุกปี

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดปัจจุบันเล็กมาก (ขายปลีกเฉพาะจุด — ล้านดอลลาร์-class/ปี); คาดการณ์ (analyst — กลางทศวรรษ 2030 $100 ล้าน–1 พันล้าน — ช่วงกว้าง — ยังไม่แน่นอน); การลงทุน (2016–2024 ~$3 พันล้าน+ — ช่วง; 2023–25 ชะลอ — เงินทุนตึง — ผู้เล่นบางรายล้ม/รวม) [3][4]
- **ผู้เล่นหลัก**: สตาร์ทอัพ (Eat Just/Upside/Aleph/Mosa/Believer-class), ผู้ผลิตอาหารใหญ่ (JBS/Cargill/Tyson-class — ลงทุน/ร่วม), CPF/Thai Union-class (ไทย — ลงทุน), ผู้ผลิต bioreactor/media (อุปทาน), ภาครัฐ (สิงคโปร์/สหรัฐฯ/อิสราเอล — หนุน; อิตาลี/ฟลอริดา — แบน)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                                 | ฉุดรั้ง                             |
| ------------------------------------------ | ----------------------------------- |
| ESG/ผู้บริโภค (เนื้อ-สิ่งแวดล้อม)          | ต้นทุนสูง/กำลังผลิตเล็ก             |
| นโยบายอาหารแห่งอนาคต (ไทย/สิงคโปร์/สหรัฐฯ) | กฎหมายแบน (อิตาลี/ฟลอริดา/แอละแบมา) |
| การลงทุนอาหารใหญ่ (CPF/JBS-class)          | เงินทุนตึง (2023–25 — ชะลอ)         |
| ราคาลด (bioreactor/media)                  | การยอมรับ (14-003 — "เนื้อปลอม")    |
| อาหารฮาลาล/ยิว (รับรอง? — ตลาด)            | กฎหมาย/อนุมัติช้า (EU/จีน/ไทย)      |

- **แนวโน้ม**: "เนื้อผสม (hybrid)" ก่อนเนื้อล้วน (ราคา/รสชาติ), กฎหมายอนุมัติใหม่ (EU/ญี่ปุ่น/จีน — 2569+), การตลาดไฮเอนด์ (โรงแรม/ร้าน — สิงคโปร์/US), ต้นทุนลด (bioreactor ใหญ่), การรวมกิจการ (ผู้เล่นใหญ่ซื้อเล็ก), ไทย (อย./นโยบาย — รอดู)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทย (1) ยังไม่มีกฎหมายเฉพาะ (ใช้กฎหมายอาหารทั่วไป — อย. — ยังไม่มีอนุมัติ/ห้ามชัด — "รอดู") (2) CPF-class ลงทุน (Aleph Farms-class — เนื้อวัว — ต่างประเทศ) (3) นโยบายอาหารแห่งอนาคต (12 — ภาครัฐพูดถึง — ยังไม่มีกรอบชัด) (4) ภาคปศุสัตว์ไทย (วัว/หมู/ไก่ — ฟาร์ม/ส่งออก — ยังไม่กระทบ) (5) งานวิจัย/สตาร์ทอัพ (เริ่ม — น้อย) [3][5]
- **จุดแข็งไทย**: อุตสาหกรรมอาหารใหญ่/ส่งออก (CPF/Thai Union/Betagro), งานวิจัยชีวภาพ (มหาวิทยาลัย/BIOTEC-class), นโยบายอาหารแห่งอนาคต (เริ่ม), ตลาดอาหาร (เอเชีย — สิงคโปร์ใกล้), ต้นทุน/บุคลากร
- **จุดอ่อน**: กฎหมายเฉพาะ (ไม่มี — อนุมัติชัดไม่ได้), การยอมรับ (14-003 — "เนื้อปลอม" — ยังไม่รู้), ตลาดในประเทศ (เล็ก/แพง — ยังไม่พร้อม), การลงทุนไทย (ยังน้อย — ต่างประเทศ), กระทบภาคปศุสัตว์ (ฟาร์ม/โรง — ต้องวางแผน), งานวิจัย (ยังน้อย)
- **โอกาส**: (1) "กฎหมาย/กรอบไทย" (อย./นโยบาย — ชัดก่อนใคร — ดึงลงทุน/ส่งออก) (2) "เนื้อผสม (hybrid)" (อาหารไทย/แปรรูป — ต้นทุน/รสชาติ — CPF-class) (3) "ฮาลาล" (ตลาดมุสลิม — การรับรอง — ใหญ่) (4) "ฐานผลิตอาเซียน" (สิงคโปร์/US-class ขยายมาผลิตในไทย — ต้นทุนต่ำ) (5) "ติดตามกฎหมายตลาดส่งออก" (EU/จีน/ญี่ปุ่น — ถ้าอนุมัติ = ตลาดใหม่)
- **หน่วยงาน**: อย. (กฎหมาย/อนุมัติ), กระทรวงเกษตร/ปศุสัตว์ (ผลกระทบฟาร์ม), สวทช./NIA (ทุน/วิจัย), ภาคอาหาร (CPF/Thai Union-class), มหาวิทยาลัย/BIOTEC (วิจัย), กรมส่งเสริมการค้า (ตลาดส่งออก)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ท่าที/กฎหมายไทยล่าสุด (อย. — กรอบ/อนุมัติ — 2569+) — ยังไม่ชัด (ต้องติดตาม)
- **Q2**: การยอมรับผู้บริโภคไทย (14-003 — "เนื้อเพาะเลี้ยง" — ราคา/ความปลอดภัย/วัฒนธรรม) — ยังไม่มีงาน
- **Q3**: ต้นทุนจริง (ไทย/อาเซียน — bioreactor/media — เทียบเนื้อจริง) — ยังไม่มีข้อมูลเปิด
- **Q4**: งาน "เนื้อผสม (hybrid)" สำหรับอาหารไทย (รสชาติ/ต้นทุน/กฎหมาย) — ยังไม่มี
- **Q5**: ผลกระทบต่อภาคปศุสัตว์ไทย (ฟาร์ม/โรงฆ่า/การจ้างงาน — สถานการณ์) — ยังไม่มีงาน
- **Q6**: ฮาลาล (การรับรองเนื้อเพาะเลี้ยง — ตลาดมุสลิม) — ยังไม่ชัด
- **Q7**: กฎหมายตลาดส่งออก (EU/จีน/ญี่ปุ่น — อนุมัติ/แบน — 2569+) — ยังไม่นิ่ง

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                          | ระดับนโยบาย                                                                             |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ติดตามสถานะ (กฎหมาย/ตลาด/ผู้เล่น — รายไตรมาส); งาน "การยอมรับไทย" (14-003 — มก./สถาบัน); งาน "ฮาลาล" (Q6); การลงทุน/ร่วม (CPF-class — hybrid) | กรอบกฎหมาย/ท่าทีไทย (อย. — ชัด); งานวิจัย (สวทช./NIA); ติดตามกฎหมายส่งออก (EU/จีน)      |
| 2 (2–4 ปี) | "เนื้อผสม (hybrid)" ไทย (แปรรูป — ราคา/รสชาติ — ตลาดในประเทศ/ส่งออก); ฐานผลิตอาเซียน (ผู้เล่นใหญ่ — ไทย); งานต้นทุน/โรง (Q3)                  | กฎหมาย/อนุมัติไทย (ชัด — ถ้าโลกอนุมัติ); มาตรฐาน/ฮาลาล; นโยบายอาหารแห่งอนาคต (12 — ชัด) |
| 3 (4+ ปี)  | "เนื้อเพาะเลี้ยงไทย" (ถ้าต้นทุน/ตลาด/กฎหมายเอื้อ — โรง/แปรรูป/ส่งออก); การปรับภาคปศุสัตว์ (ฟาร์ม/โรง — รับมือ)                                | นโยบาย "โปรตีนไทย" (เนื้อจริง+ทางเลือก — วางแผน); การตลาด/การยอมรับ (14-003)            |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย         | รายละเอียด                              | โอกาสแก้                                                      |
| ------------------ | --------------------------------------- | ------------------------------------------------------------- |
| ต้นทุนสูง          | ยังแพงกว่าเนื้อจริงหลายเท่า             | bioreactor ใหญ่/media ถูก, hybrid (เนื้อผสม)                  |
| กฎหมาย/อนุมัติ     | ช้า/แบน (อิตาลี/ฟลอริดา — EU/ไทยรอดู)   | ติดตาม/กรอบไทยชัด (Q1), การเจรจา (12)                         |
| กำลังผลิตเล็ก      | โรงเล็ก/แพง (ยังไม่ scale)              | โรงใหญ่/ลงทุน (JBS/CPF-class), ระยะเวลา                       |
| การยอมรับ (14-003) | "เนื้อปลอม"/กลัว (ความปลอดภัย/วัฒนธรรม) | ข้อมูล/การตลาด (สาธิต), รับรองความปลอดภัย, hybrid (ใกล้เคียง) |
| เงินทุน            | 2023–25 ตึง (ผู้เล่นล้ม/รวม)            | ผู้เล่นอาหารใหญ่ (เงินทุน/ตลาด), นโยบายหนุน                   |
| กระทบปศุสัตว์      | ฟาร์ม/โรง/แรงงาน (ระยะยาว)              | วางแผนปรับ (12), การตลาด (เนื้อไทยคุณภาพ)                     |
| ฮาลาล/ยิว          | การรับรอง (ยังไม่ชัด)                   | งาน/การรับรอง (Q6 — ตลาดใหญ่)                                 |

## 11. อภิธานศัพท์

| คำศัพท์                         | ความหมาย                                  |
| ------------------------------- | ----------------------------------------- |
| Cultivated meat                 | เนื้อเพาะเลี้ยง (เซลล์สัตว์ — bioreactor) |
| Lab-grown / Clean meat          | ชื่อเรียกอื่น (เนื้อห้องแล็บ/เนื้อสะอาด)  |
| Bioreactor                      | ถังเลี้ยงเซลล์ (ขยายเซลล์ — ใหญ่ขึ้น)     |
| Cell line                       | สายเซลล์ (กล้ามเนื้อ — จาก biopsy)        |
| Scaffold                        | โครงนั่งร้าน (ให้เนื้อมีโครงสร้าง)        |
| Serum-free media                | อาหารเลี้ยงเซลล์ไม่มีซีรั่ม (ลดต้นทุน)    |
| Proliferation / Differentiation | การขยายเซลล์ / การแยกเป็นกล้ามเนื้อ       |
| Hybrid meat                     | เนื้อผสม (เซลล์+โปรตีนพืช)                |
| Novel Food                      | อาหารใหม่ (กรอบกฎหมาย EU-class)           |
| SFA (สิงคโปร์)                  | หน่วยงานอาหารสิงคโปร์ (อนุมัติแรก — 2020) |
| FDA / USDA (US)                 | หน่วยงานสหรัฐฯ (อนุมัติ 2023)             |
| อย. (Thai FDA)                  | หน่วยงานอาหารไทย (ยังไม่มีกรอบเฉพาะ)      |
| Biopsy                          | การเก็บตัวอย่างเซลล์ (จากสัตว์มีชีวิต)    |
| Scale-up                        | การขยายกำลังผลิต (โรงใหญ่)                |
| GFI (Good Food Institute)       | องค์กรข้อมูลโปรตีนทางเลือก                |
| Halal certification             | การรับรองฮาลาล (ตลาดมุสลิม)               |
| Poultry/Beef/Pork               | เนื้อไก่/วัว/หมู (ชนิดที่เพาะเลี้ยง)      |
