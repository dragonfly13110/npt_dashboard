## 1. บทสรุปผู้บริหาร

- **ใจความ**: ระบบส่งน้ำชลประทานไทยเป็นคลองเปิดยาวหลายหมื่นกิโลเมตร บังคับประตูน้ำด้วยมือ วัดน้ำไม่ทั่วถึง — "Canal automation" คือการติดตั้งประตูน้ำอัตโนมัติ/เซนเซอร์/SCADA เพื่อควบคุมระดับน้ำ-อัตราไหลแบบเรียลไทม์ ส่งน้ำ "ตามความต้องการจริง" (on-demand) แทนรอบเวรตายตัว [1][2]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้วในต่างประเทศ (ออสเตรเลีย/สหรัฐ/ฝรั่งเศส — Rubicon/SmartWater ฯลฯ) — ไทยเป็น 🧪 นำร่อง (กรมชลประทานมีโครงการ telemetry/SCADA บางพื้นที่) [3]
- **ตัวเลขสำคัญที่สุด**: ประสิทธิภาพการส่งน้ำ (conveyance efficiency) ของคลองเปิดทั่วไป ~60–80% (น้ำสูญเสียระหว่างทาง — ช่วงอ้างอิง ยังต้องยืนยัน) [1]; การควบคุมอัตโนมัติลดน้ำสูญเสีย/เพิ่มความแม่นยำการส่งน้ำ ~10–30% ในโครงการต่างประเทศ (ยังไม่ยืนยัน) [2][3]
- **นัยต่อไทย**: ลดการสูญเสียน้ำ เพิ่มพื้นที่รับน้ำจากน้ำที่ประหยัดได้ (เทียบเท่าเขื่อนใหม่โดยไม่ต้องสร้าง) — แต่ต้องลงทุนโครงสร้าง+บุคลากร+การเปลี่ยนวิธีการส่งน้ำ
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ต่างประเทศ) / 🧪 นำร่อง (ไทย)

## 2. หลักการและขอบเขต

- **หลักการ**: ระบบคลองควบคุมด้วย (1) ประตูน้ำอัตโนมัติ (check gate — มอเตอร์/ไฮดรอลิก ควบคุมระดับท้ายน้ำหรืออัตราไหล) (2) เซนเซอร์ระดับน้ำ/อัตราไหล (สถานีตรวจวัด — telemetry) (3) SCADA — ระบบรวมศูนย์รับข้อมูล/สั่งการ/แจ้งเตือน (4) แบบจำลองควบคุม (PID/feed-forward) ตัดสินใจเปิด-ปิด [1][2]
- **โหมดการทำงาน**: (ก) upstream control — คลองส่งตามตาราง/เวร (ข) downstream control — คลองตอบสนองความต้องการจริงของท้ายน้ำ (ยืดหยุ่นกว่า — ใช้ในออสเตรเลีย) (ค) on-demand — เกษตรกรขอรับน้ำได้ตามเวลาจริง [1]
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยีประตู/เซนเซอร์/SCADA, ประสิทธิภาพการส่งน้ำ, การลดสูญเสีย, สถานการณ์ไทย
- **นอกขอบเขต**: การส่งน้ำระดับแปลง/ฟาร์ม (ดู 03-001/03-003), การออกแบบคลองใหม่/การบุคลอง (lining) เชิงวิศวกรรมโยธา, การจัดการน้ำท่วม (ดู 03-009)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                    | แหล่ง  |
| ----------- | ----------------------------------------------------------------------------------------------- | ------ |
| 1970s       | ระบบควบคุมคลองอัตโนมัติแรก ๆ (ฝรั่งเศส/สหรัฐฯ)                                                  | [1]    |
| 1990s–2000s | ออสเตรเลีย (Murray-Darling) ติดตั้งประตูอัตโนมัติ+SCADA ขนาดใหญ่ — ลดน้ำสูญเสียได้จริง          | [2]    |
| 2010s       | ไทยเริ่ม telemetry/SCADA นำร่อง (โครงการชลประทานใหญ่ — กรมชลประทาน)                             | [3]    |
| 2020s       | AI/แบบจำลองคู่ (digital twin) วางแผนการส่งน้ำรายวัน; การเชื่อมข้อมูลกับพยากรณ์อากาศ (เชื่อม 11) | [4][5] |
| 2025–2026   | การส่งน้ำ "ตามต้องการ" + การคิดค่าน้ำที่สะท้อนต้นทุน (จูงใจประหยัด) เริ่มถูกพูดถึงในไทย         | [6]    |

- **เส้นแบ่ง**: เทคโนโลยีสุกแล้วและพิสูจน์ผลแล้วในต่างประเทศ — ไทยยังอยู่ช่วงนำร่อง รอ "การขยายทั้งระบบ + บุคลากร + โครงสร้างราคาน้ำ"

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                       | ผลลัพธ์                                              | สถานที่/เงื่อนไข                            | แหล่ง  |
| ------------------------------- | ---------------------------------------------------- | ------------------------------------------- | ------ |
| ประสิทธิภาพการส่งน้ำ (คลองเปิด) | ~60–80% ทั่วไป (สูญเสียจากการรั่ว/ระเหย/การจัดการ)   | ต่างประเทศ/ไทย — ช่วงอ้างอิง — ยังไม่ยืนยัน | [1]    |
| การลดน้ำสูญเสียด้วย automation  | ~10–30% ในโครงการต่างประเทศ (ออสเตรเลีย ฯลฯ)         | ต่างประเทศ — ยังไม่ยืนยัน                   | [2][3] |
| ความแม่นยำการส่งน้ำ             | การส่งถึงท้ายคลองตรงเวลามากขึ้น (เชิงคุณภาพ)         | ต่างประเทศ — ยังไม่ยืนยัน                   | [2]    |
| ระยะเวลาคืนทุน                  | 5–15 ปี ตามขนาดโครงการ (ช่วง)                        | ต่างประเทศ — ยังไม่ยืนยัน                   | [2]    |
| โครงการนำร่องไทย                | telemetry/SCADA บางพื้นที่ (จำนวน/พื้นที่ต้องยืนยัน) | ไทย — ยังไม่ยืนยัน                          | [3]    |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: ผลดีที่สุดเมื่อ (1) น้ำมีจำกัด/มีราคา (2) คลองได้รับการบูรณะแล้ว (3) มีบุคลากรดูแลระบบ — ถ้าน้ำว่าง/ไม่คิดค่าใช้จ่าย แรงจูงใจลดลง

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด SCADA/ระบบควบคุมชลประทานระดับโครงการ ~1 พันล้านดอลลาร์ขึ้นไป (analyst estimate — ยังไม่ยืนยัน) [4]
- **ผู้เล่นหลัก**: Rubicon Water (ออสเตรเลีย — ประตู/ซอฟต์แวร์), Reinke/Valmont (ฝั่งฟาร์ม), Mott MacDonald/ที่ปรึกษา, ผู้ผลิตเซนเซอร์ระดับน้ำ (ระดับแบรนด์ IoT), บริษัทไทย: ผู้รับเหมา/วิศวกร (นำเข้าระบบ) [2][3]
- **การลงทุน**: งบปรับปรุงระบบชลประทานไทย (โครงการขนาดใหญ่ของกรมชลประทาน — ตัวเลขต้องยืนยัน); ต่างประเทศมี PPP/การระดมทุนผ่านค่าน้ำ [6]
- **ปัจจัยขับเคลื่อน**: ภัยแล้ง/การขาดแคลนน้ำ, นโยบายเพิ่มประสิทธิภาพน้ำ (แผนน้ำ 20 ปี), เทคโนโลยี IoT ราคาถูกลง
- **ปัจจัยฉุดรั้ง**: งบลงทุนสูง, บุคลากร/การบำรุงรักษา, ค่าน้ำไม่สะท้อนต้นทุน, คลอง/โครงสร้างเก่า

## 6. สถานการณ์ประเทศไทย

- **กรมชลประทาน**: มีระบบ telemetry/SCADA ในโครงการใหญ่บางแห่ง (เช่น โครงการชลประทานเจ้าพระยาใหญ่/บางส่วน — รายละเอียดต้องยืนยัน) [3]; การส่งน้ำยังเป็นรอบเวร/การแจ้งแผนเป็นหลัก
- **ปัญหาโครงสร้าง**: คลองเปิด (การสูญเสีย), ประตูน้ำเก่า/มือหมุนจำนวนมาก, การวัดน้ำท้ายคลองไม่ครบ, บุคลากรไม่พอ
- **งานวิจัยไทย**: งานแบบจำลองการส่งน้ำ/ระบบควบคุมในมหาวิทยาลัย/ชลประทาน (MIKE/CANALMAN ฯลฯ — รายชิ้นต้องยืนยัน) [5]
- **นโยบาย**: แผนแม่บทการบริหารจัดการทรัพยากรน้ำ (สทนช.) เน้นการเพิ่มประสิทธิภาพการส่งน้ำ; โครงสร้างค่าน้ำชลประทานปัจจุบันยังไม่จูงใจการประหยัด (อภิปรายอยู่ — ยังไม่ยืนยัน) [6]

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ROI ของการติดตั้ง automation บนคลองไทย (พื้นที่/ขนาดต่างกัน) — ยังไม่มีตัวเลขไทย
- **Q2**: การออกแบบ "การส่งน้ำตามความต้องการจริง" ที่สอดคล้องกับสังคมเกษตรไทย (นาข้าว-อ้อยผสม) — ยังไม่มี
- **Q3**: การบูรณาการข้อมูล SCADA กับการพยากรณ์อากาศ/ET (เชื่อม 03-011) และความต้องการน้ำ AI (03-001) — ยังไม่เชื่อมกัน
- **Q4**: โมเดลการเงิน/ค่าน้ำที่ทำให้ automation คุ้มค่าในไทย — ยังไม่มีข้อเสนอเป็นรูปธรรม
- **Q5**: การบำรุงรักษา/บุคลากรระยะยาวของระบบ SCADA ไทย — ยังไม่มีการวางแผนระดับชาติ
- **Q6**: ผลของการควบคุมอัตโนมัติต่อความเท่าเทียมการเข้าถึงน้ำ (หัว-ท้ายคลอง) — ยังไม่มีการศึกษาไทย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                              | ระดับนโยบาย                                                                   |
| ---------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ขยายสถานีวัดน้ำ telemetry ท้ายคลอง + แอปแจ้งแผนการส่งน้ำ/ขอรับน้ำใน 5 โครงการชลประทานใหญ่                         | มาตรฐานอุปกรณ์/ข้อมูลชลประทาน (เปิด API); การวางแผนบุคลากรดูแลระบบ            |
| 2 (2–4 ปี) | ติดตั้งประตูน้ำอัตโนมัติในคลองสายหลัก/สายแยกที่คัดเลือก (พื้นที่น้ำจำกัด); บริการข้อมูลน้ำรายแปลง (เชื่อม 03-001) | โครงสร้างค่าน้ำ/การจัดสรรที่จูงใจประหยัด (นำร่อง 1–2 ลุ่มน้ำ); งบ PPP         |
| 3 (4+ ปี)  | ระบบ SCADA ครอบคลุมโครงการชลประทานหลักทั้งหมด + การส่งน้ำตามต้องการแบบอัตโนมัติ (เชื่อม 06 digital twin)          | นโยบาย "ชลประทานอัจฉริยะแห่งชาติ" + การประเมินน้ำที่ประหยัดได้เทียบเขื่อนใหม่ |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย                  | รายละเอียด                          | โอกาสแก้                                 |
| --------------------------- | ----------------------------------- | ---------------------------------------- |
| งบลงทุนสูง                  | ประตู/เซนเซอร์/SCADA ทั่วระบบแพงมาก | ลำดับความสำคัญพื้นที่น้ำจำกัดก่อน + PPP  |

| คลองเก่า/โครงสร้าง          | ประตู/คันคลองชำรุดก่อน              | การบูรณะควบคู่การติดตั้งระบบ             |
| การเปลี่ยนแปลงวัฒนธรรมทำงาน | ชลประทานคุ้นเคยการหมุนเวนมือ        | การเปลี่ยนกระบวนการ/ความร่วมมือผู้ใช้น้ำ |
| ข้อมูล/ความปลอดภัย          | SCADA ถูกโจมตี/ข้อมูลไม่ครบ         | ความมั่นคงปลอดภัยระบบ + การสำรอง         |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **conveyance efficiency 60–80% / ลดสูญเสีย 10–30%** — หางานทบทวน/กรณีออสเตรเลีย (Rubicon/CSIRO) ยืนยันตัวเลข
- [ ] **โครงการ telemetry/SCADA ไทยปัจจุบัน** — ตรวจเว็บ/รายงานกรมชลประทาน (พื้นที่/ขนาด)
- [ ] **ตลาด SCADA ชลประทาน** — ตรวจ analyst report หรือเปลี่ยนเป็น "ไม่ระบุ"
- [ ] **ระยะเวลาคืนทุน 5–15 ปี** — หาแหล่ง/เปลี่ยนเป็น "ไม่ระบุ"

## 11. อภิธานศัพท์

| คำศัพท์                     | ความหมาย                                                                |
| --------------------------- | ----------------------------------------------------------------------- |
| SCADA                       | ระบบควบคุม/เฝ้าติดตามระยะไกล (Supervisory Control And Data Acquisition) |
| Check gate / ประตูน้ำ       | โครงสร้างควบคุมระดับน้ำ/อัตราไหลในคลอง                                  |
| Telemetry                   | การส่งข้อมูลการวัดระยะไกล (เซนเซอร์→ศูนย์)                              |
| Upstream/Downstream control | วิธีควบคุมคลองจากหัวคลอง/ตอบสนองท้ายคลอง                                |
| On-demand                   | การส่งน้ำตามความต้องการจริงของผู้ใช้                                    |
| Conveyance efficiency       | สัดส่วนน้ำที่ส่งถึงท้ายคลองเทียบที่ปล่อยจากหัวคลอง                      |
| PID controller              | ตัวควบคุมอัตโนมัติ (สัดส่วน-อินทิกรัล-ดิฟเฟอเรนเชียล)                   |
| Digital twin                | แบบจำลองคู่เสมือนของระบบจริง ใช้วางแผน/ทดสอบ                            |
