## 1. บทสรุปผู้บริหาร

- **ใจความ**: Precision agriculture (PA) ให้ผลตอบแทนเชิงบวกโดยเฉลี่ยทั่วโลก — meta-analysis จาก 85 งานศึกษา/1,472 ฟาร์ม-แปลง พบ ROI เพิ่มเฉลี่ย 22.3% กำไรสุทธิ +18.5% ประสิทธิภาพการใช้ไนโตรเจน (NUE) +15.1% ยาฆ่าแมลง -12.8% และ GHG -9.4% [5] — แต่ผลตอบแทน "ขึ้นกับบริบทอย่างมาก": ได้ผลชัดในฟาร์มธัญพืชขนาดใหญ่ (จุดคุ้มทุนส่วนใหญ่ที่ 100–200 เฮกตาร์ = 625–1,250 ไร่) และอ่อนแอ/ไม่เสถียรในฟาร์มเล็กและประเทศกำลังพัฒนา [5][36] — อัตราการยอมรับโลกห่างกันมาก: สหรัฐฯ 27% ของฟาร์ม (2023) [1], EU 18% ของฟาร์มแต่ครอบคลุม 44% ของพื้นที่เกษตร (UAA) [3], อินเดีย 4.7% (สำรวจ 4,800 ครัวเรือน 2023) [13], แอฟริกาใต้สะฮารา UAV <1–3% [15]
- **ตัวเลขสำคัญที่สุด**: ROI +22.3%, กำไรสุทธิ +18.5% (ทั่วโลก) [5]; ผลผลิต +15–25% (ทบทวน 94 งานศึกษา) [6]; ข้าวโพดสหรัฐฯ ลดต้นทุน $25/เอเคอร์ จาก yield mapping (-4.5%) และกำไรปฏิบัติการ +3% (GPS mapping), +2.5% (auto-steer), +1.1% (VRT) [7][8]; VRI ลดน้ำ 27–43% โดยผลผลิตไม่ต่าง [33][40]; ไทย: แปลงข้าวอัจฉริยะต้นทุน -247 บาท/ไร่ ผลผลิต +56 กก./ไร่ (สศก. 2566) [20]
- **นัยต่อไทย**: ไทยยังไม่มีสถิติ adoption ระดับชาติ (gap ตัวเลขใหญ่สุด) [28]; ฟาร์มเฉลี่ยแค่ 16.4 ไร่/ราย [28] vs จุดคุ้มทุน PA 625–1,250 ไร่ [36] → ทางรอดคือ "บริการใช้ร่วม/รับจ้าง" (drone-as-a-service, แปลงใหญ่/สหกรณ์) [21][26] + เทคโนโลยีต้นทุนต่ำ (เซนเซอร์/แอป) [24][25]; มาตรการคูปอง 40 บาท/ไร่ (100,000 ไร่, 2568–2569) เป็นเครื่องมือใหม่ที่ต้องประเมินผล [23]
- **สถานะโดยรวม**: 📈 เชิงพาณิชย์แล้ว (สหรัฐฯ/EU/ออสเตรเลีย/บราซิล, โดรนไทย) — ไทยเป็น 🟡 นำร่อง-ทดลองในภาครัฐ และ 🟢 โดรนเชิงพาณิชย์เฉพาะกลุ่ม

## 2. หลักการและขอบเขต

- **หลักการทำงาน**: PA = การจัดการรายแปลง/รายจุดแทนการจัดการแบบทั้งแปลงเดียว โดย 3 องค์ประกอบหลัก: (1) การเก็บข้อมูลเชิงพื้นที่-เวลา (yield monitor, soil sampling, ภาพถ่ายดาวเทียม/โดรน, เซนเซอร์) (2) การวิเคราะห์/จัดทำคำแนะนำ (map, prescription, DSS) (3) การใช้อินพุตอัตราแปรผัน (VRT — ปุ๋ย/เมล็ด/สารเคมี/น้ำ) และการนำทางอัตโนมัติ (GNSS auto-steer) [2][7] — ผลเชิงเศรษฐศาสตร์เกิดจาก 2 ช่องทาง: ลดต้นทุน (ปุ๋ย/น้ำ/สารเคมี/แรงงาน/น้ำมัน) และเพิ่มผลผลิต/คุณภาพจากการจัดการที่ตรงจุด [5]
- **ตัวแปรตัดสินใจด้านเศรษฐศาสตร์**: ต้นทุนเข้าถึง (entry cost — ฮาร์ดแวร์/ซอฟต์แวร์/บริการ), ขนาดฟาร์ม (economies of scale — ค่าใช้จ่ายคงที่กระจายต่อไร่), ค่าแรง (โอกาสที่ประหยัดได้), ความแปรปรวนภายในแปลง (ยิ่งต่างกันยิ่งคุ้ม), ราคาสินค้า/อินพุต, ทักษะและเวลาเรียนรู้, โครงสร้างพื้นฐาน (อินเทอร์เน็ต/สัญญาณ/ไฟฟ้า) [2][5][13][16]
- **ขอบเขตที่ครอบคลุม**: adoption rate ระดับประเทศ/ภูมิภาค (สหรัฐฯ EU แคนาดา ออสเตรเลีย บราซิล อินเดีย จีน แอฟริกา ไทย), ROI/ต้นทุน-ผลตอบแทนต่อเทคโนโลยี (VRT ปุ๋ย, VRI น้ำ, auto-steer, โดรน, เซนเซอร์/แอป), เศรษฐศาสตร์การตัดสินใจของเกษตรกร (farm size effect, entry cost, การรวมกลุ่ม/บริการรับจ้าง), ตลาดโลก, ตัวเลขไทยและช่องว่างข้อมูล
- **นอกขอบเขต**: เทคโนโลยีแต่ละชนิดโดยละเอียด (ดู 05 เซนเซอร์ / 07 โดรน / 03 VRI), ปัญญาประดิษฐ์/แพลตฟอร์มข้อมูล (ดู 06), การลงทุนสตาร์ทอัพ AgTech (ดู 14), มาตรฐานการค้า/คาร์บอน (ดู 12-EUDR, 08-คาร์บอน), นโยบาย GMO (ไฟล์ 12-นโยบายGMO)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                                                                                                                         | แหล่ง                    |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------ |
| 1990s–2000s | GPS guidance/yield monitor เชิงพาณิชย์ครั้งแรกในสหรัฐฯ; adoption ต่ำ (<22% ของพืชไร่หลัก ก่อนปี 2000); ออสเตรเลียเป็นประเทศแรกที่ GNSS guidance เชิงพาณิชย์ (1997)                                                                   | [7][11]                  |
| 2010–2012   | ARMS: PA ถูกใช้บน 30–50% ของพื้นที่ข้าวโพด/ถั่วเหลืองสหรัฐฯ; auto-steer เริ่มโตเร็วกว่า VRT                                                                                                                                          | [7]                      |
| 2016–2021   | ERR-217 (USDA ERS) ประเมินกำไรจากการใช้ PA อย่างเป็นระบบครั้งแรก (ข้าวโพด: +1.1–3.0% ของกำไร) [7][8]; แคนาดา (สำมะโน 2016→2021): auto-steer 21%→27%, GIS 8%→13% [11]; ออสเตรเลีย: 86% ของฟาร์มธัญพืช GRDC ใช้ auto-steer (2016) [11] | [7][8][11]               |
| 2019–2022   | EU ออก Integrated Farm Statistics (Regulation (EU) 2018/1091) → ข้อมูล PA ระดับ EU ชุดแรก; South America: บราซิล 84% ของผู้ปลูกใช้เครื่องมือดิจิทัลอย่างน้อย 1 ชนิด (2020)                                                           | [3][16]                  |
| 2023–2024   | สหรัฐฯ: 27% ของฟาร์มใช้ PA (USDA 2023) [1]; EU: 18% ของฟาร์ม/44% ของ UAA (2023) [3]; อินเดีย: IIM-A สำรวจ 4,800 ครัวเรือนพบ adoption 4.7% [13]; meta-analyses ระดับโลกตีพิมพ์ผลตอบแทนรวม (ROI +22.3%) [5]                            | [1][3][5][13]            |
| 2025–2026   | ตลาด PA โลก ~10–13 พันล้านดอลลาร์ (2025) [17][18][19]; ไทย: โดรนเกษตรสะสม ~20,000 เครื่อง [21], คูปอง "โดรนคนละครึ่งพลัส" 100,000 ไร่ [23], สศก. พยากรณ์ผลผลิตด้วยโดรน+ดาวเทียม Sentinel (แม่นยำ ~70% เป้า >80%) [35]                | [17][18][19][21][23][35] |

- **เส้นแบ่ง**: เทคโนโลยี "ข้อมูล" (auto-steer, yield monitor) เชิงพาณิชย์เต็มรูปแบบในฟาร์มใหญ่สหรัฐฯ/ออสเตรเลีย/บราซิล [2][11][16]; VRT ปุ๋ย ยังเป็นกลุ่มน้อยในหลายประเทศ (แคนาดา 16%, ฟาร์มธัญพืชออสเตรเลีย 11% [11]); โดรนพ่นสารโตเร็วในจีน/บราซิลแต่ถูกกติกาคุมใน EU/UK [11]; หุ่นยนต์/ระบบเต็มรูปแบบยังต้นทุนสูง [11]; ไทยยังไม่มีระบบสำมะโน adoption PA ระดับชาติ (อยู่ระหว่างใช้ข้อมูลโดรน/ดาวเทียมของ สศก.) [28][35]

## 6. สถานการณ์ประเทศไทย

- **งานวิจัย/หน่วยงานรัฐ** (พร้อมสถานะขั้นพัฒนา):
  - 🟢 **โดรนพ่นสาร/หว่านเชิงพาณิชย์**: ไทยมีโดรนเกษตรสะสม ~20,000 เครื่อง (2567), ยอดขาย ~8,000 เครื่อง/ปี (+50%), ใช้ทั้งพ่นปุ๋ย/สาร หว่านข้าว — สมาคมโดรนเพื่อการเกษตร (ประเทศไทย) ประเมิน [21]; งานวิเคราะห์ความคุ้มทุนโดรน (มรภ.อุบลราชธานี, วารสาร TCI) สรุปว่า "เจ้าของโดรนที่ใช้เอง+รับจ้างในแปลงใหญ่" คุ้มทุน ขณะที่ข้อกังวลหลักคือราคาลงทุน/กฎหมาย [26]
  - 🟡 **แปลงข้าวอัจฉริยะ (สศก./กระทรวงเกษตร)**: โครงการ 1 อำเภอ 1 แปลงเกษตรอัจฉริยะ ภายใต้แผนแม่บทย่อยเกษตรอัจฉริยะ — ปีงบ 2566 ทำครบ 150 ไร่ 14 จังหวัด 600 ราย: ต้นทุน -247 บาท/ไร่ ผลผลิต +56 กก./ไร่ [20]
  - 🟡 **HandySense (เนคเทค-สวทช.)**: ระบบเซนเซอร์+IoT ฟาร์มอัจฉริยะแบบ Open Innovation (เปิดพิมพ์เขียวฟรี) — อุปกรณ์ลงทะเบียน 1,767 เครื่อง/1,118 บัญชี (2567) [24] → 2,700+ อุปกรณ์/ข้อมูล >1.8 ล้านจุด (2569) [25]; ฝึกอบรม 4,000 คน; แปลงสาธิต 200 แห่ง [24]; งานยอมรับของเกษตรกร (มะม่วงน้ำดอกไม้ บางพลี, 223 ราย, อายุเฉลี่ย 57.1 ปี, พื้นที่เฉลี่ย 2.2 ไร่) พบการยอมรับระดับมาก แต่อุปสรรคคือ "ต้องลงทุนสูงเหมาะกับช่วงแรก" [27]
  - 🟡 **คูปอง "โดรนคนละครึ่งพลัส สู่สมาร์ทฟาร์มมิ่ง" (อว./NIA)**: สนับสนุน 40 บาท/ไร่ รวม 100,000 ไร่ (ไม่เกิน 30 ไร่/ราย) นำร่อง อยุธยา/อ่างทอง/ปทุมธานี ธ.ค. 2568–มิ.ย. 2569 — เป็น "สนามทดลองนโยบาย" แรกของไทยด้าน PA [23]

  - 🔬🧪 **งานวิจัยมหาวิทยาลัย (TCI)**: การยอมรับโดรนของเกษตรกร (TAM — ปทุมธานี/นครนายก/เชียงใหม่/สุพรรณบุรี/สุรินทร์/อุดรธานี ฯลฯ) [26]; งานทดลอง VRT/เซนเซอร์ในแปลงทดลองมีน้อยเมื่อเทียบต่างประเทศ — ยังเป็นแปลงทดลอง/ห้องแล็บ ไม่ได้ขยายเชิงพาณิชย์ [27]

- **โครงสร้าง/นโยบาย**: ฟาร์มไทยเฉลี่ย 16.4 ไร่/ราย (ผู้ถือครอง 8.7 ล้านราย) [28]; รายได้เงินสดสุทธิทางการเกษตรเพียง 83,130–84,779 บาท/ครัวเรือน/ปี [30][31] → ฐานะการเงินจำกัดการลงทุน PA รายบุคคล; 71.3% ของผู้ถือครองใช้เครื่องจักรกลแล้ว (ฐานรองรับ auto-steer/VRT บางส่วน) [28]; มาตรการ "ไร่ละ 1,000" (ช่วยต้นทุน 463 บาท/ไร่) สะท้อนต้นทุนข้าวไทย ~3,800–4,600 บาท/ไร่ ที่ PA ต้องแข่งกับนโยบายช่วยเหลือโดยตรง [20][37]
- **จุดแข็ง/จุดอ่อน**: จุดแข็ง = ราคาโดรน/เซนเซอร์ไทยถูกลง, โครงสร้างแปลงใหญ่/สหกรณ์พร้อมรองรับ "บริการใช้ร่วม", ภาครัฐมีระบบติดตาม (สศก.) และ Open Innovation (HandySense) [21][24][25]; จุดอ่อน = ไม่มีสถิติ adoption PA ระดับชาติ (สสช./สศก. ยังไม่เก็บในสำมะโน/การสำรวจหลัก) [28], ฟาร์มเล็ก-แปลงเล็ก (median ต่ำกว่าเฉลี่ยมาก), ทักษะดิจิทัล/อายุเฉลี่ยเกษตรกรสูง, งานเศรษฐศาสตร์ระดับแปลงไทยในวารสาร TCI น้อยมาก [26][27]

- **Q1**: อัตราการยอมรับ PA ระดับชาติของไทย (%) จำแนกเทคโนโลยี (auto-steer/VRT/โดรน/เซนเซอร์/แอป) — ยังไม่มีหน่วยงานใดเก็บอย่างเป็นระบบ; ควรบรรจุในสำมะโนการเกษตร 2571 (แบบแคนาดา/สหรัฐฯ) [11][28]
- **Q2**: ROI/ต้นทุน-ผลตอบแทนแยกเทคโนโลยีในบริบทฟาร์มไทย (บาท/ไร่, โดยเฉพาะ VRT ปุ๋ย-น้ำ ในนาข้าว/อ้อย/มันสำปะหลัง) — มีแต่ตัวเลขต่างประเทศ [5][8][9] และตัวเลขรวมของโครงการ 1 อำเภอ 1 แปลง [20]
- **Q3**: ผลของ "รูปแบบบริการใช้ร่วม" (cooperative/shared service, DaaS) ต่อ entry cost และรายได้ฟาร์มเล็กไทย — ต่างประเทศมีหลักฐาน (SSA: $5–8/เฮกตาร์/ฤดู, อินเดีย drone subsidy) [13][15] แต่ยังไม่มีงานประเมินคูปอง 40 บาท/ไร่ ของไทยหลังสิ้นสุด (มิ.ย. 2569) [23]
- **Q4**: เศรษฐศาสตร์ VRI/การจัดการน้ำแม่นยำในนาข้าวไทย (พื้นที่นา 46.2% ของที่ถือครอง [28]) — งาน VRI ส่วนใหญ่เป็นข้าวโพดสหรัฐฯ [32][33]; ไทยมีงาน AWD แต่ยังไม่เชื่อมกับตัวเลข VRI ต่อน้ำ 1 ลบ.ม.
- **Q5**: การออกแบบนโยบาย — "คูปอง vs สินเชื่อ vs บริการภาครัฐ" แบบใดให้ผลตอบแทนต่องบประมาณสูงสุดในโครงสร้างฟาร์ม 16.4 ไร่ [28]; ต่างประเทศชี้ว่า "คำแนะนำเฉพาะแปลง+การเงิน" ต้องไปด้วยกัน (Ethiopia/Tanzania) [38]
- **Q6**: ผลกระทบระยะยาวของ PA ต่อการกระจายรายได้ (equity) — meta-analysis ระบุว่า benefits ไม่เสถียรในฟาร์มเล็ก-ประเทศกำลังพัฒนา [5] — ยังไม่มีงานไทย

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                                                                           | ระดับนโยบาย                                                                                                                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | ใช้บริการโดรน/เครื่องจักรรับจ้างแทนซื้อ (แปลงใหญ่/สหกรณ์/ศูนย์บริการเกษตร) — ลด entry cost [21][26]; ติดตั้งเซนเซอร์ราคาถูก (HandySense/open innovation [24][25]); ใช้แอป/SSNM ลดปุ๋ย 10% [10] | ต่อยอดคูปอง 40 บาท/ไร่ → มาตรการถาวร + ประเมินผลอย่างเข้มงวด (RCT) [23]; สั่งให้ สสช./สศก. เก็บสถิติ adoption PA ในสำมะโน/การสำรวจรายปี (แบบ ARMS แคนาดา) [2][11][28]                                 |
| 2 (2–4 ปี) | แปลงใหญ่ระดับจังหวัดทดลอง VRT ปุ๋ย-น้ำ (นา/อ้อย/มัน) + บันทึกต้นทุนจริงบาท/ไร่ (ต่อยอด 1 อำเภอ 1 แปลง [20]); ตั้งศูนย์บริการ agronomy ที่ปรึกษา (เลียนแบบบราซิล/อาร์เจนตินา [16])              | สินเชื่อดอกเบี้ยต่ำ/คูปองเฉพาะเทคโนโลยี ROI สูง (เซนเซอร์-โดรน) [36]; มาตรฐานข้อมูลเกษตร + แพลตฟอร์มกลาง (เชื่อม 06-ธรรมาภิบาลข้อมูล); อบรมผู้ให้บริการโดรน/VRT ผ่านสถาบันอาชีวะ-มหาวิทยาลัย [22][26] |
| 3 (4+ ปี)  | ฟาร์มธุรกิจ/แปลงใหญ่ 625+ ไร่ ใช้ PA แบบบูรณาการ (auto-steer+VRT+โดรน) จุดคุ้มทุนเทียบงานต่างประเทศ 100–200 เฮกตาร์ [36]; บริการ "PA-as-a-Service" ระดับชาติ                                   | นโยบายจูงใจรายได้-ภาษีสำหรับฟาร์ม PA + ผูกกับมาตรฐานการค้า/คาร์บอน (EUDR, ตลาดคาร์บอน — ดู 12-EUDR, 08-คาร์บอน); ระบบสถิติ PA ไทยเปิดสาธารณะเพื่อวิจัยต่อ                                             |

### Blueprint สำหรับไทย (ข้อเสนอเฉพาะ 1–6)

1. **เก็บข้อมูล baseline ระดับชาติก่อนนโยบาย** — บรรจุคำถาม adoption PA (auto-steer/VRT/โดรน/เซนเซอร์/แอป) ในสำมะโนการเกษตร 2571 และ Socio ของ สศก. รายปี ตามแบบอย่างสหรัฐฯ (ARMS [2]) แคนาดา (Census [11]) และ EU (Integrated Farm Statistics [3]) — ตัวเลขนี้เองคือ "gap" ใหญ่ที่สุดของไทย
2. **จัดลำดับเทคโนโลยีตาม ROI ไทย** — เริ่มจากโดรน/บริการรับจ้างและ SSNM/แอป (ผลตอบแทน 1–2 ปี [6], ปุ๋ย -10% [10]) ก่อน VRT เครื่องจักรใหญ่ (คุ้มเมื่อ >100–200 เฮกตาร์ [36]) — ใช้แปลงสาธิตในแต่ละภาคกำหนดค่า ROI บาท/ไร่
3. **หนุนรูปแบบ "ใช้ร่วม ไม่ใช่ซื้อ"** — ขยายกลไกแปลงใหญ่/สหกรณ์/ศูนย์บริการให้ถือครองเครื่องจักร PA (หลักฐาน SSA/อินเดีย [13][15] และความคุ้มทุนโดรนแปลงใหญ่ไทย [26]) + platform จับคู่บริการ (GetzTrac [23])
4. **เครื่องมือการเงินหลายชั้น** — คูปองค่าใช้บริการ (ต่อยอด 40 บาท/ไร่ [23]) สำหรับรายย่อย, สินเชื่อ/ลีสซิ่งดอกเบี้ยต่ำผ่าน ธ.ก.ส. สำหรับผู้ประกอบการบริการ, เงินอุดหนุนจัดซื้อสำหรับสหกรณ์/แปลงใหญ่ (เลียนแบบ Pradhan Mantri Kisan Drone Yojana อินเดีย [13])
5. **สร้าง "ข้อมูลสาธารณะ" เป็นปัจจัยการผลิต** — ต่อยอด HandySense Open Innovation [24][25] และข้อมูลดาวเทียม/โดรนของ สศก. [35] สู่คำแนะนำเฉพาะแปลงฟรี (แบบ SSNM — ผล +12% ผลผลิต/+15% กำไร/-10% N [10]) เปิด API ให้สตาร์ทอัพต่อยอด
6. **วิจัย+ประเมินผลเชิงสถาบัน** — ตั้งหน่วยติดตามผลนโยบาย PA (ต้นทุนต่อไร่/ผลผลิต/ปุ๋ย/น้ำ ก่อน-หลัง) ใน TCI-วารสารไทย และเชื่อม PA กับมาตรฐานการค้า/คาร์บอนเพื่อสร้างรายได้ที่สอง (EUDR/ตลาดคาร์บอน — ดูไฟล์ 12-EUDR, 08-คาร์บอน)

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย                       | รายละเอียด                                                                                                                                            | โอกาสแก้                                                                                                          |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Entry cost สูง                   | เซนเซอร์/ซอฟต์แวร์หลายหมื่นบาทถึง VRT หลายหมื่นยูโร [39]; ฟาร์มไทยรายได้เงินสดสุทธิเกษตร <85,000 บาท/ปี [31]                                          | บริการรับจ้าง/ใช้ร่วม [15][26], คูปอง/สินเชื่อ [13][23], ฮาร์ดแวร์เปิดราคาถูก (HandySense) [24]                   |
| Economies of scale               | จุดคุ้มทุน 100–200 เฮกตาร์ [36] vs ฟาร์มไทยเฉลี่ย 16.4 ไร่ [28]; adoption สหรัฐฯ เพิ่มตามขนาดฟาร์มชัดเจน (9%→70% auto-steer) [2]                      | รวมกลุ่มแปลงใหญ่ [26], ผู้ให้บริการมืออาชีพ [16], เก็บค่าบริการต่อไร่ [15]                                        |
| ผลตอบแทนไม่แน่นอนรายปี           | VRN/VRI กำไรขึ้นกับสภาพอากาศ-ราคา (บางปี/บางแปลงขาดทุน) [9][32]; ประโยชน์อ่อนแอ-ไม่เสถียรในฟาร์มเล็ก/ประเทศกำลังพัฒนา [5]                             | ยอมรับความเสี่ยงระยะยาว (3–5 ปี), ประกันภัย/สัญญารับซื้อ (ดู 11-ประกันภัย), เลือกเทคโนโลยี ROI สูงสุดก่อน [36]    |
| ข้อมูล/ดิจิทัลไม่พร้อม           | EU ฟาร์มมีอินเทอร์เน็ตแค่ 43% [3]; บราซิล 45% ของผู้ปลูกระบุไม่มีอินเทอร์เน็ตแปลงเป็นข้อจำกัด [16]; ไทย 71.3% ใช้เครื่องจักรแต่โครงข่ายชนบทจำกัด [28] | มาตรฐาน IoT/ข้อมูล (dSURE), แพลตฟอร์มข้อมูลเปิด [24][35], ใช้ GSM/LoRaWAN (ดู 05)                                 |
| ทักษะ/อายุเกษตรกร                | อายุเฉลี่ยหัวหน้าครัวเรือนไทย ~59.9 ปี [30]; งานยอมรับ HandySense ระบุ "ลงทุนสูง+ซับซ้อน" [27]                                                        | อบรมผ่านกรมส่งเสริมการเกษตร [22], ผู้ประกอบการบริการรุ่นใหม่, UX ง่าย (B-Farm block code [25])                    |
| ตัวเลข/หลักฐานไทยขาดแคลน         | ไม่มีสถิติ adoption ระดับชาติ; งานเศรษฐศาสตร์ PA ใน TCI น้อย [26][27]; ตัวเลขต่างประเทศใช้เทียบเคียงทิศทางได้เท่านั้น                                 | ระบบสำมะโน PA (Blueprint ข้อ 1), งานประเมินผลนโยบาย (คูปอง/ไร่ละ 1,000 [23][37]), RCT มหาวิทยาลัย                 |
| ความเสี่ยงของ "ผลกระทบกระจุกตัว" | ฟาร์มใหญ่ได้ประโยชน์มากกว่า → ช่องว่างรายได้กว้างขึ้น (equity risk) [5][14]                                                                           | นโยบายมุ่งฟาร์มเล็ก/บริการใช้ร่วม, คูปองเฉพาะรายย่อย [23], จับคู่คำแนะนำ+การเงิน (บทเรียน Tanzania/Ethiopia [38]) |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ตัวเลข "adoption อินเดีย 12%→35% (2020→2025)"** — มาจากการวิเคราะห์ข้อมูลทุติยภูมิ (AlliesFeed) คุณภาพแหล่งไม่แน่นอน; ใช้ 4.7% (IIM-A 2023) เป็นค่าหลักที่เชื่อถือได้ [13] — ตรวจงานสำรวจล่าสุด 2025–2026
- [ ] **ตัวเลขตลาดโลก (17–24 พันล้านดอลลาร์ 2030)** — แต่ละสำนักวิจัยนิยามขอบเขตต่างกัน (CAGR 9.5–13.6%); ตรวจรายงานใหม่ 2026 ประกอบการอ้างอิงครั้งหน้า [17][18][19]
- [ ] **"HandySense >2,700 อุปกรณ์/1.8 ล้านจุดข้อมูล" (NAC2026)** — ตัวเลขประกาศงานแสดงสินค้า; ตรวจกับข้อมูลลงทะเบียน NetPIE ล่าสุด (1,767 เครื่อง ACE2024) ว่าเป็นตัวเลขใช้งานจริงหรือเป้าหมาย [24][25]
- [ ] **ผลของ "ไร่ละ 1,000" ต่อต้นทุน -463 บาท/ไร่ (-12.22%)** — สศก. ระบุเองว่าได้รับอิทธิพลจากสภาพอากาศ/ราคาข้าว/การจัดการอื่นร่วมด้วย — ไม่ใช่ผลของ PA โดยตรง [37]
- [ ] **"ฟาร์มไทย 71.3% ใช้เครื่องจักรกล" เป็นฐานรองรับ auto-steer/VRT** — สำมะโนนับรวมเครื่องจักรทุกรูปแบบ (รวมเครื่องสูบน้ำ) ไม่ได้ระบุสัดส่วนรถแทรกเตอร์ที่รองรับระบบนำทาง [28] — ตรวจรายละเอียดตารางสำมะโนก่อนสรุป

## 11. อภิธานศัพท์

| คำศัพท์                           | ความหมาย                                                                                     |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| PA (Precision Agriculture)        | เกษตรแม่นยำ — จัดการอินพุตตามความแตกต่างภายในแปลง (จุด/ต้น/ไร่) ด้วยข้อมูล+GPS+เซนเซอร์      |
| VRT / VRN                         | Variable Rate Technology / Variable Rate Nitrogen — ใส่ปุ๋ย-อินพุตอัตราแปรผันตามแผนที่คำสั่ง |
| VRI (Variable Rate Irrigation)    | ชลประทานอัตราแปรผัน — ให้น้ำต่างอัตราตามโซนในแปลง                                            |
| Auto-steer / GNSS guidance        | ระบบนำทางรถแทรกเตอร์/เครื่องจักรอัตโนมัติด้วยดาวเทียม — ลดเหลื่อมซ้อน/เมื่อยล้า              |
| Yield monitor / yield map         | อุปกรณ์วัดผลผลิตระหว่างเกี่ยวนวด + แผนที่ผลผลิตรายจุด                                        |
| FMIS                              | Farm Management Information System — ซอฟต์แวร์บริหารจัดการข้อมูลฟาร์ม                        |
| SSNM                              | Site-Specific Nutrient Management — จัดการธาตุอาหารเฉพาะแปลง (ข้าว/ข้าวโพด/ข้าวสาลี)         |
| NUE / WUE                         | ประสิทธิภาพการใช้ไนโตรเจน / น้ำ                                                              |
| Entry cost                        | ต้นทุนแรกเข้า (ค่าอุปกรณ์/ซอฟต์แวร์/อบรม) ก่อนได้ผลตอบแทน                                    |
| Economies of scale                | การประหยัดต่อขนาด — ต้นทุนคงที่ต่อไร่ลดลงเมื่อฟาร์มใหญ่ขึ้น                                  |
| DaaS (Drone-as-a-Service)         | บริการรับจ้างโดรน/เครื่องจักร — ไม่ต้องซื้อเอง                                               |
| UAA (Utilised Agricultural Area)  | พื้นที่เกษตรที่ใช้ประโยชน์ — ตัวส่วนของสถิติ EU                                              |
| ARMS                              | สำรวจระดับฟาร์มของ USDA (สหรัฐฯ) — แหล่งสถิติ adoption PA หลัก                               |
| TAM (Technology Acceptance Model) | แบบจำลองการยอมรับเทคโนโลยี (ใช้ในงานไทยหลายชิ้น)                                             |
| IRR / ROI / BEP                   | อัตราผลตอบแทนภายใน / ผลตอบแทนต่อการลงทุน / จุดคุ้มทุน                                        |
