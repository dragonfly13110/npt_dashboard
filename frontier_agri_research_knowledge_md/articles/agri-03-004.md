## 1. บทสรุปผู้บริหาร

- **ใจความ**: "การเก็บน้ำในดิน" คือการเพิ่มความชื้นดินที่พืชใช้ได้โดยไม่ต้องลงทุนชลประทานใหญ่ — ผ่านการไถพรวนน้อย/ไม่ไถ (conservation tillage/no-till), พืชคลุมดิน (cover crop), ฟาง/เศษซากคลุม (mulch), และการจัดการโครงสร้างดิน [1] ลดน้ำท่า (runoff) เพิ่มการซึมน้ำ เพิ่มอินทรียวัตถุในระยะยาว
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้วในสหรัฐฯ/บราซิล/ออสเตรเลีย (no-till ครอบคลุมพื้นที่มหาศาล) — ไทยเป็น 🧪 นำร่อง (อ้อย/ข้าว)
- **ตัวเลขสำคัญที่สุด**: no-till/ไถน้อยลดการพังทลายของดินได้ ~60–90% และเพิ่มน้ำที่ซึมลงดิน (ช่วงอ้างอิง — ยังต้องยืนยัน) [2]; พืชคลุมดินช่วยเพิ่มความชื้นดิน/อินทรียวัตถุ แต่ในเขตแล้งอาจแย่งน้ำกับพืชหลัก (ผลไม่เป็นบวกเสมอ) [3]
- **นัยต่อไทย**: เหมาะกับอ้อย (แปลงใหญ่ เผา/ไถพรวนเยอะ), ข้าวนาหว่าน, ยาง/ปาล์ม — ช่วยลดการเผา ลดต้นทุนไถ ลดผลกระทบแล้ง และเก็บคะแนนคาร์บอน (เชื่อม 02-002)
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ต่างประเทศ) / 🧪 นำร่อง (ไทย)

## 2. หลักการและขอบเขต

- **กลไกหลัก**: (1) เศษซากคลุมผิวดิน (residue/mulch) → กันฝนกระทบ ลดการไหลบ่า ลดการระเหย (2) ราก/ช่องว่างจากไถน้อย → เพิ่มอัตราการซึมน้ำ (infiltration) (3) อินทรียวัตถุเพิ่ม → ดินร่วนซุย เก็บน้ำได้มากขึ้น (WHC) (4) พืชคลุมดิน (ถั่ว/ธัญพืชฤดูพัก) → ครอบคลุมดินระหว่างฤดู ดึงธาตุ/ลดการชะล้าง
- **ข้อควรระวัง**: ในเขตแล้ง/น้ำน้อย พืชคลุมดินอาจดูดน้ำที่ข้าว/อ้อยต้องการ (water trade-off) — ต้องเลือกชนิด/เวลา/วิธีจัดการให้เหมาะสม (เช่น ใช้พืชตระกูลถั่วอายุสั้น/ตายเองก่อนฤดูหลัก)
- **ขอบเขตที่ครอบคลุม**: เทคนิคไถอนุรักษ์/ไม่ไถ, พืชคลุมดิน, ฟางคลุม, การจัดการโครงสร้างดิน; ผลต่อความชื้น/ผลผลิต; สถานการณ์ไทย
- **นอกขอบเขต**: ชลประทาน/ระบบน้ำ (03-001/03-003), การปรับปรุงดินทรายเชิงเคมี (02-009), คาร์บอน/MRV เจาะลึก (02-002), ดินเค็ม/กรด (02-006/02-010)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                | แหล่ง  |
| ----------- | ------------------------------------------------------------------------------------------- | ------ |
| 1930s       | ยุค Dust Bowl (สหรัฐฯ) — เริ่มแนวคิดการไถพรวนเพื่ออนุรักษ์ (conservation tillage)           | [1]    |
| 1970s–80s   | No-till เชิงพาณิชย์เริ่มแพร่ (สหรัฐฯ/บราซิล) ด้วยเครื่องจักรและสารเคมีกำจัดวัชพืชที่เหมาะสม | [1]    |
| 2000s–2010s | Cover crop กลับมาได้รับความนิยม (USDA CSP จ่ายเงินจูงใจ); งานระยะยาว 20+ ปี เริ่มมีผล       | [3]    |
| 2010s–2020s | ไทย: งานอ้อย "การไถน้อย/ไม่เผา" + พืชคลุมในสวนยาง/ปาล์ม; โครงการไร่อ้อยยั่งยืน (Bonsucro)   | [5][6] |
| 2025–2026   | ผูก no-till/cover crop กับคาร์บอนเครดิต (เชื่อม 02-002) และนโยบายลด PM2.5 (ลดการเผา)        | [4]    |

- **เส้นแบ่ง**: เทคนิคพิสูจน์แล้วในเขตอบอุ่น/เขตร้อนบางพื้นที่ — ไทยยังขาด "ชุดข้อมูลแปลงจริงระยะยาว" ที่จะยืนยันผลในระบบปลูกของเรา

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                  | ผลลัพธ์                                                                 | สถานที่/เงื่อนไข                          | แหล่ง  |
| -------------------------- | ----------------------------------------------------------------------- | ----------------------------------------- | ------ |
| การลดการพังทลาย (no-till)  | ลด ~60–90% เทียบไถแบบเดิม                                               | สหรัฐฯ/บราซิล — งานระยะยาว — ยังไม่ยืนยัน | [2]    |
| ความชื้นดิน/น้ำที่ซึมลงดิน | เพิ่ม ~10–30% ในหลายงาน (ขึ้นกับดิน/ฝน)                                 | งานต่างประเทศ — ยังไม่ยืนยัน              | [2][3] |
| อินทรียวัตถุ (10–20 ปี)    | เพิ่มช้า ~0.1–0.4% ต่อทศวรรษ ขึ้นกับสภาพอากาศ                           | งานระยะยาว — ยังไม่ยืนยัน                 | [4]    |
| พืชคลุมดินในเขตแล้ง        | ผลต่อผลผลิตหลักได้ทั้ง +/– (แย่งน้ำ) — ต้องเลือกชนิด/เวลาให้ดี          | สหรัฐฯ/เมดิเตอร์เรเนียน — ยังไม่ยืนยัน    | [3]    |
| อ้อยไทยไม่เผา+ไถน้อย       | งานนำร่องรายงานผลผลิตเทียบเท่า/ดีกว่าเล็กน้อย + ต้นทุนลด (ยังไม่ยืนยัน) | ภาคกลาง/ตะวันออกเฉียงเหนือ — ยังไม่ยืนยัน | [5]    |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)
- **เงื่อนไขสำคัญ**: ผลดีที่สุดเมื่อทำต่อเนื่องหลายปี + มีเศษซากเพียงพอ — การเผาตอซังทำลายข้อดีทั้งหมด

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด no-till/เครื่องจักรไถอนุรักษ์ + เมล็ด cover crop — ฝังอยู่ในตลาดเครื่องจักรเกษตรและเมล็ดพันธุ์ (ไม่มีการแยกสำนักชัด — ยังไม่ยืนยัน) [6]
- **ผู้เล่น**: ผู้ผลิตเครื่องหยอดเมล็ด no-till (John Deere, Case IH, Bourgault, แบรนด์ไทย/จีน), ผู้จำหน่ายเมล็ด cover crop (สหรัฐฯ: La Crosse/Legacy; ไทย: เมล็ดถั่ว/ปอเทือง ฯลฯ), บริษัทบริการจัดการ (Agri-Neo/Services)
- **นโยบาย/การเงิน**: USDA CSP (Environmental Quality Incentives) จ่ายจูงใจรายปี; สหภาพยุโรป CAP green measures; ไทย: โครงการไร่อ้อยยั่งยืน/ลดเผา (มาตรการภาครัฐ/โรงงานน้ำตาล) [5]
- **ปัจจัยขับเคลื่อน**: นโยบายลดเผา (PM2.5), คาร์บอนเครดิต, ต้นทุนไถ/แรงงาน, ราคาน้ำมัน
- **ปัจจัยฉุดรั้ง**: นิสัยการไถ/เผาแบบเดิม, เครื่องจักรเฉพาะ, ความเสี่ยงวัชพืช/โรคช่วงเปลี่ยนผ่าน

## 6. สถานการณ์ประเทศไทย

- **อ้อย**: โรงงานน้ำตาลผลักดัน "ไร่อ้อยยั่งยืน/ไม่เผา" (Bonsucro/GMP) — การไถน้อย+คลุมฟางเริ่มขยายในไร่ใหญ่; งานวิจัยที่ศูนย์วิจัยพืชไร่/มก. [5]
- **ข้าว**: นาหว่านน้ำตม/การไม่เผาฟาง; งานไถน้อยในนาน้ำฝนอีสานมีบางส่วน (ยังไม่ยืนยัน) [7]
- **ยาง/ปาล์ม/ผลไม้**: พืชคลุมดิน (ถั่ว) ในสวนยางเป็นแนวปฏิบัติเก่าแก่ของไทยอยู่แล้ว — ฐานดีต่อการขยาย
- **หน่วยงาน**: กรมวิชาการเกษตร/กรมพัฒนาที่ดิน/ศูนย์วิจัยข้าว; นโยบายลด PM2.5 และ "เกษตรยั่งยืน" เป็นตัวหนุน
- **อุปสรรค**: เศษซากถูกเผา (นิสัย+โรค/แมลง), เกษตรกรเช่าที่ไม่สนใจระยะยาว, เครื่องจักร/ความรู้จำกัดในรายเล็ก

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ตัวเลข "น้ำที่เก็บได้/ความชื้นเพิ่ม" ของ no-till+คลุมในระบบอ้อย/ข้าวไทย (แปลงจริงหลายฤดู) — ยังไม่มี
- **Q2**: ปฏิสัมพันธ์ "cover crop vs น้ำที่มีจำกัด" ในแล้งอีสาน — ยังตอบไม่ได้สำหรับถั่ว/ปอเทือง
- **Q3**: ผลระยะยาว (10+ ปี) ต่อผลผลิต/ศัตรูพืช/วัชพืชในไทย — ยังไม่มีแปลงทดลองต่อเนื่อง
- **Q4**: เศรษฐศาสตร์การเปลี่ยนผ่าน (ค่าเครื่อง/ค่าเมล็ด/ปีแรกผลอาจลด) — ยังไม่มีตัวเลขไทย
- **Q5**: การเชื่อมกับคาร์บอนเครดิต (MRV — 02-002) ที่ยอมรับได้ในระบบไทย — ยังไม่มี
- **Q6**: แรงจูงใจ/การยอมรับเกษตรกรรายเล็ก (เชื่อม 14-001/14-003) — ยังไม่มีการสำรวจ

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                       | ระดับนโยบาย                                                                     |
| ---------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงสาธิต "ไม่เผา+ไถน้อย+คลุมฟาง/ถั่ว" ในอ้อย/ข้าว/ยาง วัดความชื้นดิน-ผลผลิต-ต้นทุน 3 ปี   | ต่อยอดมาตรการลดเผา → แพ็กเกจสนับสนุน (เมล็ดถั่ว/ค่าจ้างเครื่องหยอด no-till)     |
| 2 (2–4 ปี) | บริการ "แปลงอัตโนมัติ" (รับจ้างหยอด no-till/คลุม) ผ่านสหกรณ์; รวมกลุ่มซื้อเมล็ด cover crop | มาตรฐาน "ไร่อ้อยยั่งยืน" ขยายเป็นข้อบังคับการรับซื้อ; เงินจูงใจรายไร่           |
| 3 (4+ ปี)  | การไม่ไถ+คลุมเป็นข้อกำหนดการรับรอง/ส่งออก (น้ำตาล/ยาง) + นับคาร์บอนได้จริง (เชื่อม 02-002) | นโยบาย "ดินเก็บน้ำ" ระดับชาติ: เป้าหมายพื้นที่ไม่เผา/ไถน้อย + งบติดตามผลระยะยาว |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย        | รายละเอียด                            | โอกาสแก้                                   |
| ----------------- | ------------------------------------- | ------------------------------------------ |
| นิสัยเผา/ไถเดิม   | เปลี่ยนยาก กลัววัชพืช/โรค/แมลง        | สาธิตผล + แพ็กเกจช่วงเปลี่ยนผ่าน           |
| ต้นทุนเปลี่ยนผ่าน | เครื่อง no-till/เมล็ดแพง ปีแรกผลอาจลด | สินเชื่อ/จูงใจ (ธ.ก.ส.) + บริการรับจ้าง    |
| วัชพืช/ศัตรู      | ควบคุมยากกว่าเมื่อไม่ไถ               | สารเคมีที่เหมาะ/การจัดการผสมผสาน           |
| พืชคลุมแย่งน้ำ    | ในแล้งอาจเสียผลผลิต                   | เลือกชนิด/เวลาปลูก-ตัดให้เหมาะ (ข้อมูล Q2) |
| เกษตรกรเช่าที่    | ไม่ลงทุนระยะยาวในที่ของคนอื่น         | สัญญาระยะยาว/กองทุนปรับปรุงดินร่วม         |
| PM2.5/การบังคับ   | นโยบายลดเผาไร้กลไกจริงจัง             | เก็บภาษี/ค่าปรับคู่กับสิ่งจูงใจเชิงบวก     |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ลดการพังทลาย 60–90% / ความชื้นเพิ่ม 10–30%** — ยืนยันจากงาน primary (Soil & Tillage Research; Agronomy Journal) พร้อมเงื่อนไขดิน/ฝน
- [ ] **OM เพิ่ม 0.1–0.4% ต่อทศวรรษ** — หางาน meta-analysis (Global Change Biology) ที่อ้างได้
- [ ] **ผล +/- ของ cover crop ในเขตแล้ง** — หางานทบทวนเฉพาะประเด็น water trade-off
- [ ] **งานอ้อยไทยไม่เผา/ไถน้อย (ศูนย์วิจัย/มก./โรงงาน)** — ค้น TCI/ThaiJo + ข่าวโรงงานน้ำตาล ยืนยันตัวเลข
- [ ] **USDA CSP/มาตรการลดเผาไทย** — ตรวจข้อมูลนโยบายล่าสุด (ปี/งบ/เงื่อนไขอาจเปลี่ยน)
- [ ] **ข้อมูล no-till ไทยในข้าว/ยาง** — ค้น ThaiJo เพิ่มรายชิ้น + DOI

## 11. อภิธานศัพท์

| คำศัพท์              | ความหมาย                                                  |
| -------------------- | --------------------------------------------------------- |
| Conservation tillage | การไถพรวนเพื่ออนุรักษ์ (ไถน้อย/ไถแนวขวาง) — ลดการรบกวนดิน |
| No-till              | การไม่ไถพรวน — หยอดเมล็ดลงดินที่ไม่ได้ไถ                  |
| Cover crop           | พืชคลุมดินที่ปลูกระหว่างฤดู/ร่วมกับพืชหลัก                |
| Mulch / residue      | เศษซาก/ฟางคลุมผิวดิน                                      |
| Infiltration         | อัตราการซึมน้ำเข้าดิน                                     |
| Runoff               | น้ำท่า/น้ำไหลบ่าบนผิวดิน (เสียออกจากแปลง)                 |
| WHC                  | ความจุเก็บน้ำของดิน                                       |
| Water trade-off      | สถานการณ์ที่พืชคลุมแย่งน้ำจากพืชหลัก                      |
