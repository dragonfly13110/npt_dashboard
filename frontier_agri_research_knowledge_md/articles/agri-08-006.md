## 1. บทสรุปผู้บริหาร

- **ใจความ**: พลังงานชีวมวล = เผา/ย่อยสลาย "ชีวมวลเหลือทิ้ง" (ฟางข้าว/แกลบ/ชานอ้อย/กากมัน/กากปาล์ม/ไม้โตเร็ว) เพื่อผลิตไฟฟ้า/ความร้อน/ไอน้ำ — ไทยมีศักยภาพสูงมาก (ข้าว/อ้อย/ปาล์ม/มัน — "ประเทศเกษตร = แหล่งชีวมวล") แต่ปัจจุบันใช้จริงน้อย (หลายส่วนยังเผาทิ้ง/ทิ้งให้เน่า — สร้าง PM2.5/เสียโอกาส) — หัวใจ: "การขนส่ง/เก็บชีวมวล = ต้นทุนใหญ่ (กระจัดกระจาย) — ต้องมีระบบรวบรวม" [1][2][3]
- **ขั้นพัฒนา**: 🏭 ใช้จริง/ขยาย (ไทยมีโรงไฟฟ้าชีวมวล ~4,000–6,000 เมกะวัตต์รวมทุกเชื้อเพลิง — ช่วง; สหภาพยุโรป/อเมริกาใช้มานาน) — แต่ "ศักยภาพเหลือทิ้งยังใช้ไม่เต็ม" [2][3][4]
- **ตัวเลขสำคัญที่สุด**: ศักยภาพชีวมวลเหลือทิ้งไทย ~40–60 ล้านตัน/ปี (ช่วง — ฟาง/แกลบ/ชานอ้อย/กากปาล์ม/มัน — สถานะต้องตรวจ); ไฟฟ้าชีวมวลไทย ~4,000–6,000 เมกะวัตต์ (ช่วง — รวม VSPP/IPP); ต้นทุนเชื้อเพลิงชีวมวลต่ำ (ฟาง/แกลบ ~500–1,500 บาท/ตัน — ช่วง); ค่าความร้อนฟาง/แกลบ ~10–16 MJ/กก. (ช่วง); โรงไฟฟ้าชีวมวล (~10–20 เมกะวัตต์) ใช้ชีวมวล ~5–15 หมื่นตัน/ปี (ช่วง) [1][3][4]
- **นัยต่อไทย**: ไทยเผาฟาง/ชานอ้อย (PM2.5 — ภาคเหนือ/กลาง) — เปลี่ยน "เผาทิ้ง" เป็น "ขายเป็นเชื้อเพลิง" = 2 ประโยชน์ (1) รายได้เสริมเกษตรกร/โรงงาน (2) ลดหมอกควัน/PM2.5 — จุดสำคัญ: (1) ต้องมี "ระบบรวบรวม/ขนส่ง" (ฟางกระจาย — รวมกลุ่ม/สหกรณ์/โรงงานใหญ่) (2) เลือก "ตลาด" (ขายฟาง/แกลบให้โรงงาน vs โรงไฟฟ้าเล็ก/ไอน้ำโรงงาน) (3) อย่าแย่ง "วัสดุปรับปรุงดิน" (ฟาง/แกลบ — กลับดินดีกว่าไหม — 02-004 ไบโอชาร์) [2][3][4]
- **สถานะโดยรวม**: 🏭 ใช้จริง/ขยาย (ไทย — โรงไฟฟ้าชีวมวล/ไอน้ำโรงงาน) — ศักยภาพเหลืออีกมาก

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (เทคโนโลยีหลัก)

1. **การเผาไหม้ตรง (Direct combustion)**: เผาชีวมวล → หม้อไอน้ำ → ไอน้ำ → ไฟฟ้า/ความร้อน (โรงงานน้ำตาล — CHP ใช้ชานอ้อยมานาน) — "หลัก/ใหญ่สุด"
2. **แก๊สซิฟิเคชัน (Gasification)**: เปลี่ยนชีวมวล → แก๊สเชื้อเพลิง (Syngas) — ใช้เครื่องยนต์/กังหัน (ขนาดเล็ก-กลาง)
3. **การอัดเม็ด (Pellet/briquette)**: อัดฟาง/แกลบ/กาก → เม็ดเชื้อเพลิง (ขาย/ขนส่งง่าย — ตลาดส่งออก)
4. **ไบโอชาร์/ถ่าน (Pyrolysis → biochar)**: เผาแบบไร้ออกซิเจน → ถ่าน (02-004 — ใช้ดิน/คาร์บอน)

### 2.2 การเปรียบเทียบชีวมวลหลักไทย (ตาราง)

| เชื้อเพลิง | แหล่ง        | ค่าความร้อน (MJ/กก. — ช่วง) | ราคา (บาท/ตัน — ช่วง) | หมายเหตุ                      |
| ---------- | ------------ | --------------------------- | --------------------- | ----------------------------- |
| แกลบ       | โรงสีข้าว    | ~12–16                      | ~500–1,500            | เก็บง่าย (โรงสี) — ใช้แล้ว    |
| ฟางข้าว    | นาข้าว       | ~10–14                      | ~500–1,000            | กระจาย/ขนส่งแพง — เผาทิ้งบ่อย |
| ชานอ้อย    | โรงน้ำตาล    | ~7–10 (ชื้น)                | ใช้เองในโรง           | โรงน้ำตาลใช้เอง (CHP)         |
| กากปาล์ม   | สวน/โรงปาล์ม | ~8–14                       | ~500–1,000            | ใช้/ขาย                       |
| ไม้โตเร็ว  | สวนไม้       | ~15–18                      | ~1,500–2,500          | ราคาสูงกว่า (เพาะเอง)         |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: ไบโอแก๊ส (08-003), ไบโอชาร์/การใช้ดิน (02-004 — อ้างข้าม), เอทานอล/ไบโอดีเซล (12 — เชื้อเพลิงเหลว), ขยะชุมชน (12), ราคาไฟลึก (กกพ.)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                           | แหล่ง     |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| 1980s–2000s | โรงไฟฟ้าชีวมวลเริ่ม (แกลบ/ชานอ้อย — โรงงานใช้เอง); เทคโนโลยี combustion ครบ                                                            | [1][2]    |
| 2010s       | โรงไฟฟ้าชีวมวลไทยขยาย (VSPP รับซื้อ — แกลบ/ฟาง/กากปาล์ม); งานวิจัยแก๊สซิฟิเคชัน/เพลเล็ต; ปัญหา PM2.5 (เผาฟาง) ชัด                      | [2][3]    |
| 2021–2024   | เพลเล็ตส่งออก (ยุโรป — ข้าวโพด/ไม้); งานวิจัย "การรวบรวมฟาง/โลจิสติกส์" (ต้นทุนขนส่ง); นโยบายลดเผา (ไทย — บังคับ/คุม)                  | [3][4]    |
| 2025–2026   | โรงไฟฟ้าชีวมวลไทย (สถานะ/กำลัง — ต้องตรวจ); การผูกคาร์บอน (08-002 — เชื้อเพลิงทดแทน); งาน "ฟาง → เพลเล็ต/ไบโอชาร์" (ไทย — มก.)         | [3][4]    |
| 2026–       | แนวโน้ม: "ฟางไม่เผา" (ไทย — เป้าหมาย/กฎ), เพลเล็ตตลาดส่งออก, ไบโอชาร์ (02-004 — ใช้ดิน+คาร์บอน), โรงไฟฟ้า "ชีวมวล+โซลาร์" ผสม (08-001) | [3][4][5] |

- **เส้นแบ่ง**: "โรงไฟฟ้า/ไอน้ำชีวมวล = ใช้จริง (ไทย — แกลบ/ชานอ้อย/กากปาล์ม)" — "ขั้นนำร่อง = ฟาง/ของเหลือใหม่ (รวบรวม/เพลเล็ต/ไบโอชาร์ — ยังไม่เต็มที่)"

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                       | ผลลัพธ์                                          | สถานที่/เงื่อนไข | แหล่ง  |
| ------------------------------- | ------------------------------------------------ | ---------------- | ------ |
| ศักยภาพชีวมวลเหลือทิ้งไทย       | ~40–60 ล้านตัน/ปี (ช่วง — สถานะต้องตรวจ)         | ก.พลังงาน/งาน    | [3][4] |
| กำลังผลิตไฟฟ้าชีวมวลไทย         | ~4,000–6,000 เมกะวัตต์ (ช่วง — รวมทุกเชื้อเพลิง) | ก.พลังงาน/กกพ.   | [4]    |
| ราคาฟาง/แกลบ (ไทย)              | ~500–1,500 บาท/ตัน (ช่วง)                        | ตลาด             | [3]    |
| ค่าความร้อนฟาง/แกลบ             | ~10–16 MJ/กก. (ช่วง)                             | งาน              | [1]    |
| โรงไฟฟ้า 10–20 เมกะวัตต์        | ใช้ชีวมวล ~5–15 หมื่นตัน/ปี (ช่วง)               | ผู้ประกอบการ     | [3]    |
| ต้นทุนขนส่งฟาง (ระยะไกล)        | เพิ่ม ~200–500 บาท/ตัน/50 กม. (ช่วง)             | งาน              | [3]    |
| PM2.5 จากการเผา (ไทย — ต้นเหตุ) | ~20–40% ของ PM2.5 ภาคเหนือ (ช่วง)                | งาน/กรม          | [5]    |
| ประสิทธิภาพโรงไฟฟ้าชีวมวล       | ~20–30% (ไฟฟ้าเท่านั้น — ช่วง)                   | งาน              | [1]    |

- **กฎ**: "ชีวมวลคุ้มเมื่อ 'ของเหลืออยู่แล้ว + รวมกลุ่มเก็บ' (ฟาง/แกลบ — ขายได้เงินแทนเผาทิ้ง)" — "ค่าโลจิสติกส์ = หัวใจ (ฟางกระจาย — ระยะทางสั้น/ใหญ่เก็บคุ้ม)" — "ต้องชั่งน้ำหนัก 'กลับดิน vs เผาเป็นไฟ' (ดินเสื่อมถ้าดึงออกหมด — 02-004 ไบโอชาร์)" — ตัวเลขช่วงกว้าง — ตรวจหัวข้อ 10
- **หมายเหตุ**: กำลังผลิต/สถานะโรงไฟฟ้าไทยเปลี่ยนตลอด — ตรวจอัปเดต

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดพลังงานชีวมวลโลก ~$50–90 พันล้านดอลลาร์/ปี (ช่วง — analyst 2030-class); ตลาดเพลเล็ตส่งออกโตเร็ว (เอเชีย/ยุโรป); ไทย: โรงไฟฟ้าชีวมวล + เพลเล็ตส่งออก (เริ่ม) [3][4]
- **ผู้เล่นหลัก**: โรงงาน (น้ำตาล/ปาล์ม/โรงสี — ใช้เอง/ขายไฟ), ผู้รวบรวม/ค้าเชื้อเพลิง, โรงไฟฟ้า (IPP/VSPP), ผู้ผลิตเพลเล็ต, กรม/องค์กรปกครองส่วนท้องถิ่น (ฟาง/ขยะ), เกษตรกร/สหกรณ์ (ผู้ขายฟาง/แกลบ)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                         | ฉุดรั้ง                                 |
| ---------------------------------- | --------------------------------------- |
| ของเหลือเยอะ/ราคาถูก (ฟาง/แกลบ)    | ค่าโลจิสติกส์ (ขนส่งฟางไกล)             |
| นโยบายลดเผา/PM2.5 (ไทย)            | การรวบรวมฟาง (กระจัดกระจาย/ฤดูเดียว)    |
| ไฟฟ้ารับซื้อ (VSPP) / ราคาไฟขึ้น   | ราคาชีวมวลผันผวน (ฟาง/แกลบ)             |
| เพลเล็ตส่งออก (ตลาดโต)             | แย่ง "วัสดุปรับปรุงดิน" (กลับดินดีกว่า) |
| คาร์บอน (08-002 — เชื้อเพลิงทดแทน) | ความรู้/การบำรุง/การยอมรับ (14-003)     |

- **แนวโน้ม**: "ฟางไม่เผา" (ไทย — เป้าหมาย/กฎ — รวบรวม/เพลเล็ต), โรงไฟฟ้าผสม (ชีวมวล+โซลาร์ — 08-001), ไบโอชาร์ (02-004 — ใช้ดิน+คาร์บอน — ทางเลือกที่ยั่งยืนกว่า), การผูกคาร์บอน (08-002), ระบบรวบรวม 4.0 (แอป/ข้อมูล — 06-006)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ไทยใช้พลังงานชีวมวลจริง (1) โรงน้ำตาล/ปาล์ม (ชานอ้อย/กาก — CHP — ใช้เอง+ขายไฟ) (2) โรงไฟฟ้าชีวมวล (แกลบ/ฟาง/กากปาล์ม/ไม้ — VSPP/IPP — หลายโรง) (3) โรงอบ/ไอน้ำอุตสาหกรรม (ข้าว/แปรรูป) (4) เพลเล็ตส่งออก (เริ่ม) — แต่ "ฟางจำนวนมากยังเผาทิ้ง" (PM2.5 — ภาคเหนือ/กลาง — นโยบายลดเผา กำลังบังคับ) [4][5]
- **จุดแข็งไทย**: ชีวมวลเหลือทิ้งเยอะ (ข้าว/อ้อย/ปาล์ม/มัน — ~40–60 ล้านตัน/ปี — ช่วง), โรงงาน/โครงสร้าง (น้ำตาล/โรงสี — ครบวงจร), นโยบายรับซื้อ (VSPP), งานวิจัย (แก๊สซิฟิเคชัน/เพลเล็ต — มก./มข.), นโยบายลดเผา (PM2.5 — แรงกดดัน = โอกาส)
- **จุดอ่อน**: การรวบรวมฟาง (กระจาย/ฤดูเดียว/ขนส่งแพง), ราคาชีวมวลผันผวน, โรงเล็ก/เงินทุน (รายย่อย), การแย่ง "วัสดุปรับปรุงดิน" (ฟาง/แกลบ — ดินไทยเสื่อมอยู่แล้ว), การยอมรับ/ความรู้ (14-003), ข้อมูลศักยภาพ (รายพื้นที่ — ยังไม่เป็นระบบ)
- **โอกาส**: (1) "ฟาง → เชื้อเพลิง/เพลเล็ต" (รวมกลุ่ม/สหกรณ์/อปท. — รวบรวมฟางหน้าแล้ง — ลดเผา+รายได้) (2) "โรงไฟฟ้า/ไอน้ำเล็กครบวงจร" (โรงสี/แปรรูป — แกลบ/ฟาง — ใช้เอง+ขายไฟ) (3) "ฟาง → ไบโอชาร์" (02-004 — ใช้ดิน+คาร์บอน — ทางเลือกคู่) (4) "เพลเล็ตส่งออก" (ตลาดเอเชีย/ยุโรป) (5) "คาร์บอน" (08-002 — เชื้อเพลิงทดแทน — เครดิต)
- **หน่วยงาน**: ก.พลังงาน/กพพ. (นโยบาย/รับซื้อ), กกพ. (ราคาไฟ), กรมโรงงาน/อปท. (ฟาง/ขยะ/PM2.5), กรมวิชาการ/มก. (งานวิจัย), โรงงาน/สหกรณ์ (รวบรวม), อบก. (คาร์บอน — 08-002)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ข้อมูล "ศักยภาพฟาง/ของเหลือรายพื้นที่" (ภาค/จังหวัด — ปริมาณ/ที่อยู่/หน้าฤดู) — ยังไม่เป็นระบบ
- **Q2**: เศรษฐศาสตร์ "การรวบรวมฟาง" (ขนาด/ระยะทาง/ราคา/เครื่องเก็บอัด — จุดคุ้ม) — ยังไม่มีงานไทยครบ
- **Q3**: "ฟาง → เพลเล็ต/ไบโอชาร์" เปรียบเทียบ "กลับดิน" (ผลต่อดิน/ผลผลิต/คาร์บอน — ระยะยาว) — ยังไม่มีงานไทย
- **Q4**: ราคา/ความเสี่ยงโรงไฟฟ้าชีวมวลไทย (สถานะ/นโยบาย/การแข่งขัน) — ยังไม่ชัด
- **Q5**: การยอมรับ (14-003) ของเกษตรกรต่อ "ขายฟาง/แกลบ" (ราคา/สัญญา/ฤดู) — ยังไม่มีงาน
- **Q6**: มาตรฐานเพลเล็ต/การรับรอง (ส่งออก/ตลาด) — ยังไม่ชัด
- **Q7**: การผูก "คาร์บอน+พลังงานชีวมวล" ไทย (08-002 — มูลค่า) — ยังไม่มีงาน

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                            | ระดับนโยบาย                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1 (1–2 ปี) | งาน "ศักยภาพฟางรายพื้นที่" (ก.พลังงาน/มก.); นำร่อง "รวบรวมฟาง" (สหกรณ์/อปท. — หน้าฤดู — เครื่องอัดฟาง); งาน "ฟาง vs กลับดิน" (Q3)               | นโยบาย "ฟางไม่เผา" (ชัด — เป้าหมาย/หนุน); แนวทางรวบรวม (กรม)                   |
| 2 (2–4 ปี) | "ศูนย์รวบรวม/เพลเล็ต" (สหกรณ์/ผู้ประกอบการ — ลดเผา+ขาย); โรงไฟฟ้า/ไอน้ำเล็กครบวงจร (โรงสี/แปรรูป); "ฟาง → ไบโอชาร์" (02-004 — เชิงพาณิชย์)      | ราคารับซื้อ/สัญญา (กกพ.); มาตรฐานเพลเล็ต; การผูกคาร์บอน (08-002)               |
| 3 (4+ ปี)  | "พลังงานจากของเหลือครบวงจร" (รวบรวม→เพลเล็ต/ไบโอชาร์/โรงเล็ก — ทุกภาค); การตลาดคาร์บอน (08-002); "ฟางไม่เผา" ระดับชาติ (ข้อมูล/ติดตาม — 06-006) | นโยบาย "ชีวมวลไทย" (เป้าหมาย/การบังคับลดเผา); ข้อมูล/การติดตาม (ดาวเทียม — 05) |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ศักยภาพชีวมวลเหลือทิ้งไทย 40–60 ล้านตัน/ปี** — ตรวจ ก.พลังงาน/งาน (ระบุปี)
- [ ] **กำลังผลิตไฟฟ้าชีวมวลไทย 4,000–6,000 เมกะวัตต์** — ตรวจ กพพ./กกพ. (สถานะล่าสุด)
- [ ] **ราคาฟาง/แกลบ 500–1,500 บาท/ตัน** — ตรวจตลาด (ปี)
- [ ] **ค่าความร้อน 10–16 MJ/กก.** — ตรวจงาน (ระบุชีวมวล)
- [ ] **โรง 10–20 MW ใช้ชีวมวล 5–15 หมื่นตัน/ปี** — ตรวจผู้ประกอบการ/งาน
- [ ] **ต้นทุนขนส่ง +200–500 บาท/ตัน/50 กม.** — ตรวจงาน
- [ ] **PM2.5 จากการเผา 20–40% (ภาคเหนือ)** — ตรวจงาน/กรมควบคุมมลพิษ
- [ ] **ประสิทธิภาพโรงไฟฟ้า 20–30%** — ตรวจงาน
- [ ] **สถานะโรงไฟฟ้าชีวมวลไทย (รายการ/กำลัง — ปัจจุบัน)** — ตรวจข่าว/รายงาน
- [ ] **ตลาดพลังงานชีวมวลโลก $50–90 พันล้าน/ปี** — ตรวจ analyst report ระบุปี

| HHV/LHV                | ค่าความร้อนสูง/ต่ำ (MJ/กก.)                |
| VSPP / IPP             | ผู้ผลิตไฟฟ้าขนาดเล็ก/เอกชน (รับซื้อ)       |
| ฟางข้าว                | ก้าน/ใบข้าวหลังเก็บเกี่ยว (เหลือทิ้ง)      |
| แกลบ                   | เปลือกข้าว (โรงสี — เชื้อเพลิงหลัก)        |

| กากปาล์ม               | กากทะลาย/เปลือกปาล์ม (สวน/โรงปาล์ม)        |
| ไม้โตเร็ว              | ไม้ยูคา/กระถิน (เพาะเพื่อเชื้อเพลิง)       |
| PM2.5                  | ฝุ่นละอองขนาดเล็ก (การเผา = ต้นเหตุ)       |
