## 1. บทสรุปผู้บริหาร

- **ใจความ**: เซนเซอร์ความชื้นดินแบบติดตั้งในแปลง (FDR/capacitance, TDR, tensiometer) + ค่า EC/อุณหภูมิ วัดต่อเนื่องรายลึก (10–60 ซม.) → ส่งข้อมูลผ่าน LoRaWAN/NB-IoT (05-003) → AI ตัดสินใจเปิด-ปิดน้ำอัตโนมัติ (เชื่อม 03-001) — เปลี่ยนจากการรดตามตารางเป็นการรดตาม "ความต้องการจริงของดิน/พืช" [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (CropX/Sentek/AquaSpy/Teros — ใช้จริงทั่วโลก; ไทยมีโครงการนำร่อง) — ปัญหาหลักคือการสอบเทียบ/การบำรุงรักษา/การเปลี่ยนข้อมูลเป็นคำแนะนำ [2][3]
- **ตัวเลขสำคัญที่สุด**: FDR สอบเทียบดีแล้วแม่นยำ ±2–3% (ความชื้นปริมาตร vwc); เซนเซอร์ ~5,000–20,000 บาท/จุด (ช่วง — ไทย); ประหยัดน้ำ 15–30% (บริการ CropX-class — งานผู้ให้บริการ); ใช้เซนเซอร์ 1 จุดต่อ 5–20 ไร่ (ขึ้นชนิดดิน/ระบบน้ำ) [1][2][3]
- **นัยต่อไทย**: งานนำร่องมีอยู่จริง (ข้าว/อ้อย/ไม้ผล — มหาวิทยาลัย/บริษัท) — แต่การขยายผลติดที่ "การสอบเทียบดินไทย (ทรายอีสาน/ดินเหนียวกลาง)" + "การบำรุงรักษา" + "ต้นทุนต่อไร่" [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: เซนเซอร์ฝังในดินวัดสมบัติไดอิเล็กทริก (FDR/capacitance — ความถี่เปลี่ยนตามปริมาณน้ำ) หรือวัดแรงดูดน้ำ (tensiometer) → แปลงเป็นความชื้นปริมาตร (vwc %) / ความตึงน้ำ (kPa) → เทียบกับ "จุดวิกฤต" (field capacity/plant available water) → สั่งรดน้ำเมื่อถึงเกณฑ์ [1]
- **ชนิดเซนเซอร์**:
  - **FDR/capacitance** (Teros 12, Sentek Drill&Drop, Decagon EC-5): แม่นยำพอใช้ได้จริง/ราคากลาง/แบตเตอรี่นาน — นิยมที่สุดในฟาร์ม
  - **TDR** (Campbell): แม่นยำสูงสุด/แพง — งานวิจัย/แปลงสำคัญ
  - **Tensiometer** (Watermark/Irrometer): วัดแรงดูดโดยตรง/ใช้งานง่าย — ไม้ผล/สวน
  - **EC + อุณหภูมิ** (รวมในเซนเซอร์): บอกธาตุอาหาร/การเค็ม (เชื่อม 02-006)
  - **Neutron probe**: แม่นยำแต่ต้องมีใบอนุญาต (รังสี) — งานวิจัย
- **การสอบเทียบ**: ค่า FDR ขึ้นกับชนิดดิน (ทราย/เหนียว/อินทรียวัตถุ) — ต้องปรับเส้นโค้งต่อพื้นที่ (หรือใช้สมการเฉพาะดิน); ดินเค็ม/EC สูงบิดเบือนค่า
- **การติดตั้ง**: ความลึกตามระบบราก (10–30/30–60 ซม.), จำนวนจุดตามความแปรปรวนแปลง, ใกล้ระบบราก/ไม่ใกล้หัวจ่ายน้ำเกินไป
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/การสอบเทียบ, ราคา/บริการ, งานไทย, แนวทางใช้
- **นอกขอบเขต**: เซนเซอร์เคลื่อนที่ on-the-go (02-005), การวัดจากดาวเทียม (05-001/05-010), เครือข่ายส่งข้อมูล (05-003)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                     | แหล่ง  |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 1980s–2000s | TDR/FDR จากงานวิจัยสู่เครื่องมือเชิงพาณิชย์ (Campbell/Decagon); งานบริหารน้ำตามความชื้นดิน (deficit irrigation)                  | [1]    |
| 2010s       | เซนเซอร์ราคาลง + LoRaWAN/NB-IoT → "เครือข่ายไร้สายในแปลง"; บริการครบวงจร (CropX — 2015, Sentek)                                  | [2][3] |
| 2020–2025   | AI คุมรดน้ำอัตโนมัติ (เชื่อม 03-001) + การผูกกับน้ำหยด/ปืนใหญ่; การสอบเทียบอัตโนมัติ (ML ต่อพื้นที่); งานประหยัดน้ำระดับแปลงใหญ่ | [2][3] |
| 2026–       | แนวโน้ม: เซนเซอร์ "self-calibrating" (ปรับเองตามสภาพ), การรวมความชื้นดิน+ET ดาวเทียม (03-011) + สภาพอากาศ (05-008) ในระบบเดียว   | [3]    |

- **เส้นแบ่ง**: เทคโนโลยีสุกแล้ว — ปัญหาจริง: การสอบเทียบรายพื้นที่, ความทนทาน (กลางแปลง/น้ำท่วม/หนู), การดูแลระยะยาว, และ "ข้อมูล→การตัดสินใจ" (เกษตรกรยังไม่ไว้ใจ/ไม่เข้าใจ)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                            | ผลลัพธ์                                | เงื่อนไข             | แหล่ง  |
| ------------------------------------ | -------------------------------------- | -------------------- | ------ |
| ความแม่นยำ FDR (สอบเทียบแล้ว)        | ±2–3% vwc (เทียบ TDR/oven-dry)         | ดินปกติ (ไม่เค็มจัด) | [1]    |
| คลาดเคลื่อนเมื่อไม่ได้สอบเทียบ       | 5–15% (ต่างชนิดดินชัดเจน)              | สภาพจริง             | [1][2] |
| ราคาเซนเซอร์ (จุด)                   | ~5,000–20,000 บาท (Teros/Sentek-class) | ตลาด                 | [3]    |
| ชุดระบบ (เซนเซอร์+เกตเวย์+แพลตฟอร์ม) | ~5 หมื่น–3 แสนบาท/แปลง                 | ตลาด/งาน             | [3]    |
| การประหยัดน้ำ (คุมตามความชื้น)       | 15–30% (งาน/บริการ)                    | ระบบน้ำหยด/แปลงใหญ่  | [2][3] |
| ผลต่อผลผลิต (สวน/พืชราคาสูง)         | +0–10% (งานไม่เสมอไป — ขึ้นการจัดการ)  | งานหลากหลาย          | [2]    |
| ระยะเวลาใช้เซนเซอร์ 1 จุด            | ครอบคลุม 5–20 ไร่ (ขึ้นดิน/ระบบ)       | แนวทาง               | [3]    |
| อายุแบตเตอรี่ (LoRaWAN)              | 2–5 ปี (ส่งราย 15 นาที–ชม.)            | เอกสาร               | [3]    |
| ความลึกติดตั้ง                       | 10–60 ซม. (ตามราก)                     | แนวทาง               | [1]    |
| คืนทุน (สวนผลไม้/น้ำแพง)             | 1–3 ปี                                 | งาน/บริการ           | [2][3] |

- **กฎ**: "สอบเทียบ" สำคัญกว่า "ซื้อแพง" — เซนเซอร์ถูกแต่ไม่สอบเทียบให้ผลผิดพลาดใหญ่; การประหยัดน้ำชัดเจนเมื่อมีระบบน้ำควบคุม (น้ำหยด/ปืนใหญ่) + ราคาน้ำ/พลังงานสูง
- **เงื่อนไขสำคัญ**: (1) ชนิดดิน/การสอบเทียบ (2) การติดตั้งถูกตำแหน่ง (3) จำนวนจุดพอ (แปลงแปรปรวนมากต้องหลายจุด) (4) การบำรุงรักษา (ล้าง/เปลี่ยน) (5) การรวมกับข้อมูลอื่น (อากาศ 05-008/ET 03-011)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: เซนเซอร์ความชื้นดิน/การจัดการน้ำเกษตร ~0.5–2 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 10–20%/ปี [3]
- **ผู้เล่นหลัก**: CropX (บริการครบวงจร — นิวซีแลนด์/สหรัฐฯ), Sentek (ออสเตรเลีย — หลายความลึก), Meter/Teros (สหรัฐฯ), AquaSpy, Campbell (TDR งานวิจัย); ผู้ไทย (ตัวแทนจำหน่าย/ระบบน้ำ+เซนเซอร์ — ผู้ประกอบการระบบน้ำหยด) [2][3][4][5]
- **การลงทุน**: เริ่มจาก "บริการ + เซนเซอร์ไม่กี่จุด" (หลักหมื่นบาท/แปลง) ไม่ต้องซื้อระบบเต็ม; โมเดลรายเดือน (ข้อมูล+คำแนะนำ) กำลังมา
- **แนวโน้ม**: การสอบเทียบอัตโนมัติ (AI), การรวมกับน้ำหยด/ปืนใหญ่ (ระบบปิดอัตโนมัติ — เชื่อม 03-001), เซนเซอร์ราคาลง (ตลาดแข่ง), การใช้ข้อมูลเพื่อประกันภัย/คาร์บอน (เชื่อม 11/02-002)
- **ความเสี่ยง**: การตลาดเกินจริง (ตัวเลขประหยัดจากผู้ขาย), การพึ่งบริการรายเดือน, เซนเซอร์เสียกลางแปลง (การเข้าถึงซ่อม), ข้อมูลไม่นำไปสู่การกระทำ

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: โครงการนำร่อง IoT ความชื้นดินมีในหลายพื้นที่ (ข้าว/อ้อย/ทุเรียน/กาแฟ — มก./มข./มจธ. + บริษัทน้ำหยด + โครงการ Smart Farm ภาครัฐ); การใช้เชิงพาณิชย์กว้างยังน้อย — กระจุกสวนผลไม้ใหญ่ (ทุเรียน — คู่กับน้ำหยด 03-012) [4][5][6]
- **จุดแข็งไทย**: งานวิจัย/นำร่องเยอะ, ผู้ประกอบการระบบน้ำ+เซนเซอร์มี, โครงสร้าง NB-IoT/LoRaWAN พร้อม (05-003), พืชมูลค่าสูง (ทุเรียน) จ่ายไหว
- **จุดอ่อน**: การสอบเทียบดินไทยยังไม่เป็นระบบ (เส้นโค้งรายพื้นที่/รายชุดดิน), การบำรุงรักษาระยะยาว, เกษตรกรรายย่อย (แปลงเล็ก/ไม่มีระบบน้ำควบคุม), การต่อยอดจากนำร่องสู่เชิงพาณิชย์น้อย, ข้อมูลกระจัดกระจาย
- **โอกาส**: (1) "ชุดสอบเทียบเซนเซอร์สำหรับชุดดินหลักไทย" (พด.+มหาวิทยาลัย — บริการสาธารณะ) (2) แพ็กเกจ "น้ำหยด+เซนเซอร์+AI รดน้ำ" สำหรับทุเรียน/ไม้ผล (เชื่อม 03-012/03-001) (3) การใช้ในอ้อย/มัน (ลดน้ำ/พลังงาน) (4) การรวมกับข้อมูลดาวเทียม (03-011/05-010) ลดจำนวนเซนเซอร์
- **หน่วยงาน**: กรมพัฒนาที่ดิน (ชุดดิน/เส้นโค้ง), มหาวิทยาลัย (มก./มข./มจธ.), กรมชลประทาน/ชลประทานเกษตร, ผู้ประกอบการระบบน้ำ, สวนทุเรียน/สหกรณ์

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย            | รายละเอียด                                   | โอกาสแก้                                                      |

| ต้นทุน/รายย่อย        | เซนเซอร์+ระบบแพงต่อไร่เล็ก                   | บริการรายเดือน, สหกรณ์ซื้อร่วม, เซนเซอร์น้อยจุด+ดาวเทียมเสริม |
| การบำรุงรักษา         | เซนเซอร์เสีย/ถูกน้ำท่วม/หนูกัดสาย            | อุปกรณ์ทนทาน, สัญญาบริการ, การออกแบบติดตั้ง                   |
| ข้อมูลไม่เป็นคำสั่ง   | มีค่าความชื้นแต่ไม่รู้ว่า "รดเมื่อไร"        | AI+เกณฑ์ต่อพืช (เชื่อม 03-001/06), แอปง่าย                    |
| ดินเค็ม/EC สูง        | บิดเบือนค่า FDR                              | ใช้เซนเซอร์ EC ประกอบ, เซนเซอร์รุ่นทนเค็ม (เชื่อม 02-006)     |
| ไฟฟ้า/แบตเตอรี่       | จุดไกล/ไม่มีไฟ                               | โซลาร์/แบต, LoRaWAN ประหยัดไฟ (05-003)                        |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **FDR ±2–3% vwc (สอบเทียบแล้ว)** — ตรวจสเปก/งาน (Teros/Sentek-class)
- [ ] **ราคาเซนเซอร์ 5,000–20,000 บาท/จุด + ระบบ 5 หมื่น–3 แสนบาท** — ตรวจตลาดไทย/ต่างประเทศ
- [ ] **ประหยัดน้ำ 15–30% (คุมตามความชื้น)** — ตรวจงานอิสระ/เอกสารบริการ (ระบุพืช/ระบบ)
- [ ] **1 จุดต่อ 5–20 ไร่** — ตรวจแนวทาง/งาน (เป็นช่วงอ้างอิง)
- [ ] **คืนทุน 1–3 ปี (สวนผลไม้)** — ตรวจงาน 03-012/เอกสาร (ต่อยอด)
- [ ] **เส้นโค้งสอบเทียบชุดดินไทยยังไม่มีฐานเปิด** — ตรวจ พด./งานไทย (ปรับถ้ามีแล้ว)
- [ ] **สถานะเชิงพาณิชย์ไทย (กระจุกทุเรียน)** — ตรวจข่าว/งานอัปเดต
- [ ] **ตลาดเซนเซอร์น้ำเกษตร 0.5–2 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี

## 11. อภิธานศัพท์

| คำศัพท์                 | ความหมาย                                           |
| ----------------------- | -------------------------------------------------- |
| FDR/Capacitance         | เซนเซอร์วัดความชื้นด้วยความจุไฟฟ้า (ย่านฟรีเควนซี) |
| TDR                     | เซนเซอร์แม่นยำสูง (เวลาเดินทางของคลื่น) — แพง      |
| Tensiometer             | วัดแรงดูดน้ำของดิน (kPa) — ใช้นิยมในสวน            |
| vwc                     | ความชื้นปริมาตร (%) — มาตรฐานเปรียบเทียบ           |
| Field capacity          | ความชื้นที่ดินอุ้มน้ำไว้หลังน้ำส่วนเกินไหลออก      |
| Permanent wilting point | ความชื้นที่พืชเหี่ยวถาวร (ขีดห้ามรดช้าเกิน)        |
| Calibration curve       | เส้นโค้งแปลงสัญญาณเป็น vwc (รายชนิดดิน)            |
| Plant available water   | ช่วงน้ำที่พืชใช้ได้ (ระหว่าง FC–PWP)               |
| Irrigation scheduling   | การกำหนดจังหวะ/ปริมาณรดน้ำ                         |
| Deficit irrigation      | การรดน้ำน้อยกว่าปกติ (ประหยัดน้ำ ตามช่วงพืช)       |
