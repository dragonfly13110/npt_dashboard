## 1. บทสรุปผู้บริหาร

- **ใจความ**: ระบบปิด (โรงเรือน/VF) เป็น "บ่อเพาะ" ทั้งแมลงและโรค — ความหนาแน่นสูง + ความชื้น + อากาศหมุนเวียน = ระบาดเร็ว แต่ข้อดีคือควบคุมได้ด้วย IPM: (1) กันแมลงเข้าจากภายนอก (มุ้ง/ห้องสะอาด) (2) เฝ้าระวัง (กับดักเหนียว/สแกน AI — เชื่อม 04-004) (3) ใช้ชีววิธี (แมลงตัวห้ำ/แตนเบียน/จุลินทรีย์) ก่อนสารเคมี [1][2][4]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้วในยุโรป (เนเธอร์แลนด์/สเปนใช้ชีววิธีในโรงเรือนอย่างกว้างขวาง — Koppert/Biobest) — ไทยใช้ชีววิธีในโรงเรือนเพิ่มขึ้นแต่ยังไม่กว้าง [4][6]
- **ตัวเลขสำคัญที่สุด**: การใช้โปรแกรมชีววิธีในโรงเรือนลดการใช้สารเคมี 50–90% (งานยุโรป); แตนเบียน Encarsia formosa กำจัดหวี่ขาวได้เองตามธรรมชาติในโรงเรือนที่จัดการดี [1][2]
- **นัยต่อไทย**: โรงเรือนมุ้งไทย (ผักสลัด/เมล่อน/สตรอว์เบอร์รี/กล้วยไม้) ลดแมลงได้มากอยู่แล้ว (มุ้ง 50–80 mesh) — จุดต่อไปคือ "ชีววิธี + สแกน AI" เพื่อตอบโจทย์ผักปลอดภัย/ส่งออก (ข้อกำหนดสารเคมีตกค้าง) [5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (ยุโรป) / เริ่มแพร่ในไทย

## 2. หลักการและขอบเขต

- **หลักการ IPM 5 ชั้น**:
  1. **ป้องกัน** — มุ้งกันแมลง (mesh 50–80), ประตูห้องสะอาด, วัสดุ/สารตั้งต้นปลอดเชื้อ, น้ำสะอาด
  2. **เฝ้าระวัง** — กับดักเหนียว (สีเหลือง/น้ำเงิน), การสำรวจรายสัปดาห์, สแกนภาพ AI (เชื่อม 04-004/04-005)
  3. **ชีววิธี** — ปล่อยแมลงตัวห้ำ/ตัวเบียน, ใช้จุลินทรีย์ (Bt, Beauveria, Trichoderma, Bacillus)
  4. **วิธีกล/ฟิสิกส์** — UV-C, ไอน้ำ/ความร้อน, กับดักแสง, การไล่ลม
  5. **สารเคมี (ทางเลือกสุดท้าย)** — เลือกสารเฉพาะกลุ่ม (selective), สลับกลุ่มป้องกันดื้อยา
- **ศัตรูหลักในระบบปิด**: หวี่ขาว (whitefly — Bemisia/Trialeurodes), เพลี้ยไฟ (thrips — Frankliniella), ไรแดง (Tetranychus urticae), เพลี้ยอ่อน (aphids), หนอนชอนใบ (Liriomyza); โรค: ราสีเทา (Botrytis cinerea), ราแป้ง (powdery mildew), รากเน่า (Pythium), โรคใบจุดแบคทีเรีย
- **ชีววิธีหลัก (โรงเรือน)**:
  - แตนเบียน _Encarsia formosa_ → หวี่ขาว; แตนเบียน Aphidius → เพลี้ยอ่อน
  - ตัวห้ำ: แมลงหางหนีบ _Orius_ → เพลี้ยไฟ/ไร; ไรตัวห้ำ _Amblyseius (Neoseiulus) californicus / Phytoseiulus persimilis_ → ไรแดง
  - จุลินทรีย์: _Bacillus thuringiensis_ (Bt) → หนอน; _Beauveria bassiana / Metarhizium_ → แมลงหลายชนิด; _Trichoderma / Bacillus subtilis_ → โรคในดิน/สารตั้งต้น
- **ขอบเขตที่ครอบคลุม**: ศัตรูหลัก, ชีววิธี/ผลิตภัณฑ์, เทคโนโลยี (มุ้ง/UV/สแกน), ตัวเลขการลดสารเคมี, ตลาด, สถานะไทย
- **นอกขอบเขต**: เทคโนโลยีพันธุกรรมกำจัดศัตรู (01-004), การสแกนหุ่นยนต์ลึก (04-004), การทำนายโรค AI (04-005)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                                                                   | แหล่ง  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ | ------ |
| 1920s–70s   | เริ่มใช้ชีววิธีโรงเรือนในยุโรป (Encarsia ควบคุมหวี่ขาว — เรือนกระจกอังกฤษ/เนเธอร์แลนด์)                                        | [1]    |
| 1980s–90s   | บริษัทชีวภัณฑ์ (Koppert 1967, Biobest 1987) ขยาย; เนเธอร์แลนด์ใช้ชีววิธีเป็นระบบในโรงเรือนมะเขือเทศ/พริก                       | [1][4] |
| 2000s–2010s | IPM โรงเรือนกลายเป็นมาตรฐาน EU; การปล่อยตัวห้ำผสม (mix releases); การใช้ Bt/จุลินทรีย์แพร่                                     | [2][4] |
| 2015–2025   | UV-C/แสงกำจัดโรคโรงเรือน (งานวิจัย); AI สแกนแมลง/โรค (เชื่อม 04-004); ระบบ "ปล่อยอัตโนมัติ" (โดรน/หุ่นยนต์ปล่อยตัวห้ำ — เริ่ม) | [2][3] |
| 2026–       | แนวโน้ม: การผสม "มุ้ง+ชีววิธี+AI" เป็นแพ็กเกจโรงเรือนใหม่; การลดสารเคมีตามข้อกำหนดส่งออก (EU MRL) บังคับชีววิธี                | [3][4] |

- **เส้นแบ่ง**: ชีววิธีพิสูจน์แล้วในเขตอบอุ่น — ความท้าทายเขตร้อนไทย: อุณหภูมิ/ความชื้นสูง (ตัวห้ำ/เชื้อราต้องทนร้อน), หน้าฝน (ความชื้น → โรค) — ต้องคัดสายพันธุ์/ระบบที่ทนร้อน

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                         | ผลลัพธ์                                                                      | เงื่อนไข          | แหล่ง  |
| --------------------------------- | ---------------------------------------------------------------------------- | ----------------- | ------ |
| ลดการใช้สารเคมี                   | 50–90% (โรงเรือนที่ใช้ IPM เต็มระบบ)                                         | ยุโรป/งานทบทวน    | [1][2] |
| Encarsia vs หวี่ขาว               | ควบคุมได้เองตามธรรมชาติ (อัตรา 1 แตนเบียน : 5–10 ตัวอ่อน)                    | โรงเรือนมะเขือเทศ | [1]    |
| ไรตัวห้ำ (P. persimilis) vs ไรแดง | กำจัดได้ 80–95% เมื่อปล่อยทัน (ก่อนระบาด)                                    | งานทดลอง/แปลง     | [1][2] |
| มุ้ง 50–80 mesh                   | กันแมลงใหญ่ได้เกือบหมด (หวี่ขาว/เพลี้ยไฟบางส่วน) — แลกกับการระบายอากาศน้อยลง | วิศวกรรมโรงเรือน  | [5]    |
| UV-C (โรงเรือน)                   | ลดโรคผิวดิน/รา 30–70% (งานทดลอง — ต้องระวังพืช)                              | งาน 2015–25       | [3]    |
| Bt กำจัดหนอน                      | ได้ผล 70–90% (หนอนวัยอ่อน — ต้องพ่นให้ถูกช่วง)                               | งานทั่วโลก        | [2]    |
| ต้นทุนชีววิธี/ไร่/เดือน (ไทย)     | หลักร้อย–หลักพันบาท (ช่วง — ยังไม่ยืนยัน)                                    | ตลาดไทย           | [6]    |
| การลดแรงงานเฝ้าระวัง (AI สแกน)    | 30–60% (เวลาสำรวจลด — เชื่อม 04-004)                                         | งานผู้ให้บริการ   | [3]    |
| ราคาผักปลอดภัย/อินทรีย์           | ขายได้สูงกว่า 20–80% (ตามตลาด)                                               | ตลาดไทย/สากล      | [6]    |

- **กฎ**: ชีววิธี "ต้องเริ่มก่อนระบาด" — ถ้าศัตรูระบาดแล้ว ตัวห้ำตามไม่ทัน ต้องใช้สารเคมี/เก็บทำลายคู่กัน
- **เงื่อนไขสำคัญ**: (1) การคุมสภาพอากาศ (ความชื้น/อุณหภูมิ — เชื่อม 04-008/04-005) (2) ความสะอาดโรงเรือน (3) การปล่อยซ้ำตามรอบ (4) อย่าใช้สารเคมีที่ฆ่าตัวห้ำ (broad-spectrum) พร้อมกัน

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ชีวภัณฑ์/การควบคุมทางชีวภาพโลก ~5–7 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 12–18%/ปี (นโยบาย EU ลดสารเคมี 50% ภายใน 2030) [3][4]
- **ผู้เล่นหลัก**: Koppert, Biobest, Bioline Agrosciences, Syngenta Biologicals, Corteva/BASF (สายชีวภัณฑ์), ไทย: ผู้ผลิต/จำหน่ายชีวภัณฑ์ในประเทศ (กรมวิชาการเกษตร — เชื้อราไตรโคเดอร์มา/บาซิลลัส, บริษัทไทยหลายราย) [4][6]
- **การลงทุน**: ระบบ IPM เต็มรูปแบบ ~5–15% ของต้นทุนการผลิตผัก (ยุโรป — ยังไม่ยืนยัน); คุ้มเมื่อ (1) ราคาผลผลิตสูง (2) ตลาดปลอดภัย/ส่งออก (3) สารเคมีถูกจำกัด
- **ตัวขับเคลื่อน**: EU Farm to Fork (ลดสารเคมี 50% 2030), MRL เข้มงวดขึ้น (EU — ผลต่อส่งออกไทย), ผู้บริโภคผักปลอดภัย, ต้นทุนสารเคมีขึ้น
- **ความเสี่ยง**: ชีววิธีแพงกว่า/ต้องความรู้, ประสิทธิภาพแปรผันตามสภาพอากาศ, การดื้อยาของศัตรูต่อชีววิธี (พบได้แต่ช้า)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: โรงเรือนมุ้งไทยกันแมลงได้ดี (ผักสลัด/เมล่อน/สตรอว์เบอร์รี) — การใช้ชีววิธีมีแนวโน้มเพิ่ม (ไตรโคเดอร์มา/บาซิลลัสใช้ในโรงเรือนผัก), แต่ส่วนใหญ่ยังพึ่งสารเคมีเมื่อระบาด [5][6]
- **หน่วยงาน/ผลิตภัณฑ์**: กรมวิชาการเกษตร (พด. — ผลิต/แจกจ่ายไตรโคเดอร์มา, บาซิลลัส), ศูนย์บริหารศัตรูพืช, บริษัทชีวภัณฑ์ในประเทศหลายราย, งานวิจัย มก./มข. (ตัวห้ำ/ตัวเบียนพื้นบ้าน) [5][6]
- **ปัญหาหลักไทย**: หน้าร้อน/ฝน (แมลง/โรคหนัก), ความรู้การปล่อยตัวห้ำ (จังหวะ/อัตรา), ราคาชีวภัณฑ์/การเข้าถึงท้องถิ่น, ความเชื่อถือ
- **โอกาส**: ตลาดส่งออกผักสด (EU/ญี่ปุ่น/สิงคโปร์ — MRL เข้มงวด) → ชีววิธีเป็น "ใบเบิกทาง" การรับรอง; โครงการผักปลอดภัย/อินทรีย์ของรัฐ
- **พืชที่ใช้ชีววิธีไทยแล้ว**: มะเขือเทศ/พริก (โรงเรือน), เมล่อน, สตรอว์เบอร์รี (เหนือ), ผักสลัด (ฟาร์มส่งออก) — ยังน้อยเมื่อเทียบยุโรป

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ประสิทธิภาพตัวห้ำ/ตัวเบียน (Orius, Amblyseius, Encarsia) ณ อุณหภูมิ 30–38°C ของไทย — งานต่างชาติทำที่ 20–28°C
- **Q2**: สายพันธุ์/สูตรชีวภัณฑ์ไทยที่ทนร้อน-ชื้น (ไตรโคเดอร์มา/บาซิลลัส/Beauveria สายพันธุ์ไทย) — มีงานเริ่ม ยังไม่ครอบคลุม
- **Q3**: ต้นทุน-ผลตอบแทน IPM เต็มระบบในโรงเรือนไทย (ต่อไร่/ต่อกก.) — ยังไม่มี
- **Q4**: ผลของ "มุ้งละเอียด vs การระบายอากาศ" ต่อโรค/แมลงในโรงเรือนไทย (trade-off) — ยังไม่มี
- **Q5**: AI สแกนแมลง/โรคในโรงเรือนไทย (ชุดข้อมูลไทย/พันธุ์ไทย) — เชื่อม 04-004/04-005 — ยังไม่มี
- **Q6**: การยอมรับของเกษตรกรไทยต่อชีววิธี (ต่อยอด 14-003) — มีงานบางส่วน (ผัก/ข้าว) ยังไม่เจาะโรงเรือน

| 1 (1–2 ปี) | โรงเรือนนำร่อง 10–15 แห่ง: มุ้ง + กับดักเหนียว + สแกนสัปดาห์ละครั้ง + ปล่อยตัวห้ำตามคำแนะนำ; บันทึกผล/ต้นทุน                 | คู่มือ IPM โรงเรือนไทย (ร่วม กรมวิชาการเกษตร/AIC); ทะเบียนชีวภัณฑ์ไทย (คุณภาพ/ราคา)          |
| 2 (2–4 ปี) | ขยาย "แพ็กเกจ IPM" (บริการปล่อยตัวห้ำ/สแกน AI — เชื่อม 04-004) ผ่านผู้จำหน่าย/สหกรณ์; ใบรับรอง "ผักปลอดสาร/IPM" สำหรับส่งออก | เงินหนุนชีวภัณฑ์/ศูนย์กระจายชีวภัณฑ์ภูมิภาค; นโยบายลดสารเคมีตาม EU (MRL) — เตรียมพร้อมส่งออก |
| 3 (4+ ปี)  | โรงเรือนไทย "IPM อัตโนมัติ" (สแกน AI → ปล่อยตัวห้ำ/พ่นจุดอัตโนมัติ — เชื่อม 04-004/04-005) เป็นมาตรฐานผักส่งออก              | มาตรฐานแห่งชาติ "การรับรองการใช้ชีววิธี"; ฐานข้อมูลศัตรูพืช-ชีววิธีไทย (เปิด)                |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย            | รายละเอียด                              | โอกาสแก้                                        |
| --------------------- | --------------------------------------- | ----------------------------------------------- |
| ประสิทธิภาพในร้อนชื้น | ตัวห้ำ/เชื้อราทนร้อนไม่ดี หน้าฝนโรคหนัก | คัดสายพันธุ์ไทย, คุมอากาศ (04-008/04-005)       |
| จังหวะ/อัตราการปล่อย  | ปล่อยช้า/ผิดอัตรา = ไม่ทันระบาด         | คู่มือ/แอป, บริการผู้เชี่ยวชาญ, AI ช่วยตัดสินใจ |
| ต้นทุน/ราคา           | ชีวภัณฑ์แพงกว่าสารเคมีบางตัว            | ผลิตในประเทศ/สหกรณ์, ใช้กับพืชราคาสูงก่อน       |
| ความรู้/ความเชื่อถือ  | เกษตรกรไม่ไว้ใจ "ปล่อยแมลงดี"           | สาธิตผลจริง, อบรม, ตัวอย่างแปลงสำเร็จ           |
| มุ้ง vs อากาศ         | มุ้งละเอียดกันแมลงแต่ขวางลม (ร้อน/โรค)  | ออกแบบช่องระบาย/พัดลม (04-008)                  |
| สารเคมีกับตัวห้ำ      | พ่นสารเคมีกว้าง = ฆ่าตัวห้ำตายไปด้วย    | เลือกสารเฉพาะกลุ่ม/คุมจังหวะ                    |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ลดสารเคมี 50–90% (IPM เต็มระบบ)** — ตรวจงานทบทวนยุโรป (ระบุระบบ/ระยะเวลา)
- [ ] **อัตราปล่อย Encarsia (1:5–10)** — ตรวจคู่มือ Koppert/Biobest
- [ ] **ไรตัวห้ำกำจัดไรแดง 80–95%** — ตรวจงานทดลอง/แปลง
- [ ] **มุ้ง 50–80 mesh กันแมลงได้เกือบหมด** — ตรวจเอกสารวิศวกรรม/ผู้จำหน่ายมุ้ง
- [ ] **UV-C ลดโรค 30–70%** — ตรวจงาน 2015–25 (ชนิดโรค/พืช/ความเสี่ยง)
- [ ] **ตลาดชีวภัณฑ์โลก 5–7 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **ต้นทุนชีววิธีไทย หลักร้อย–พันบาท/ไร่/เดือน** — ตรวจราคาตลาด/ผู้จำหน่ายไทย
- [ ] **EU ลดสารเคมี 50% ภายใน 2030 (Farm to Fork)** — ตรวจสถานะกฎหมายล่าสุด (2025–26)

## 11. อภิธานศัพท์

| คำศัพท์                         | ความหมาย                                                 |
| ------------------------------- | -------------------------------------------------------- |
| IPM                             | Integrated Pest Management — การจัดการศัตรูพืชแบบผสมผสาน |
| ตัวห้ำ (Predator)               | แมลง/ไรที่กินศัตรูพืช (Orius, Amblyseius)                |
| ตัวเบียน (Parasitoid)           | แมลงที่วางไข่ใน/บนตัวศัตรู (แตนเบียน)                    |
| Encarsia formosa                | แตนเบียนควบคุมหวี่ขาว                                    |
| Whitefly / Thrips / Spider mite | หวี่ขาว / เพลี้ยไฟ / ไรแดง — ศัตรูหลักโรงเรือน           |
| Botrytis / Powdery mildew       | ราสีเทา / ราแป้ง — โรคหลักความชื้นสูง                    |
| MRL                             | ปริมาณสารเคมีตกค้างสูงสุดที่ยอมรับได้ (EU/ไทย)           |
| Mesh (มุ้ง)                     | ความละเอียดตาข่าย (50/80 mesh — กันแมลง)                 |
| Bt                              | Bacillus thuringiensis — จุลินทรีย์กำจัดหนอน             |
| Sticky trap                     | กับดักเหนียว (สีเหลือง/น้ำเงิน — เฝ้าระวัง)              |
