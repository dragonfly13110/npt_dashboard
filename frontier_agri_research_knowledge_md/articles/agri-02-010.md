## 1. บทสรุปผู้บริหาร

- **ใจความ**: ดินกรด (pH < 5.5–6.5) ครอบคลุมพื้นที่เพาะปลูกไทยจำนวนมาก — โดยเฉพาะ "ดินเปรี้ยว" (acid sulfate) แถบที่ราบลุ่มภาคกลาง (รังสิต-นครนายก-ฉะเชิงเทรา) ที่เกิดจากไพไรต์ในดินถูกออกซิไดซ์กลายเป็นกรดกำมะถัน [1][2] ความเป็นกรดทำให้ Al/Mn เป็นพิษต่อราก และฟอสฟอรัสถูกตรึงใช้ไม่ได้ (P fixation)
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น — วิธีจัดการ (ปูนขาว/โดโลไมต์, การจัดการน้ำ) ใช้จริงมานานในไทย แต่ยังมีพื้นที่ไม่ได้จัดการ/ต้องทำซ้ำ
- **ตัวเลขสำคัญที่สุด**: ดินเปรี้ยวจัดในไทย ~หลายล้านไร่ (ตัวเลขแน่นอนต้องยืนยันจากกรมพัฒนาที่ดิน) [1]; การใส่ปูนโดโลไมต์ 1–2 ตัน/เฮกตาร์ เพิ่ม pH ~0.5–1 หน่วย และเพิ่มผลผลิตข้าวในแปลงทดลองภาคกลาง ~20–40% (ยังต้องยืนยัน) [4]
- **นัยต่อไทย**: เป็นปัญหากลางของที่ราบลุ่มเจ้าพระยา (ข้าวหลักของประเทศ) — การจัดการปูน+น้ำ+พันธุ์ทนกรดทำพร้อมกันได้ผลดี
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (วิธีมีใช้จริง ขยายผลเป็นโครงการรัฐมานาน)

## 2. หลักการและขอบเขต

- **แหล่งความเป็นกรด**: (1) ดินเปรี้ยว (acid sulfate) — ไพไรต์ (FeS₂) ในดินเลนสะสม ถูกระบายน้ำออกแล้วออกซิไดซ์เป็นกรดซัลฟิวริก → pH ต่ำกว่า 4, บางครั้งมีสาร "จาวปลวก" (jarosite) สีเหลือง (2) ดินกรดทั่วไปจากฝนชะล้าง/การใส่ปุ๋ยไนโตรเจนแอมโมเนียมในระยะยาว (3) วัตถุต้นกำเนิดดิน (หินแกรนิต/ดินร่วนปนทรายอีสาน)
- **ผลเสีย**: อะลูมิเนียมละลาย (Al³⁺) เป็นพิษต่อราก (ยับยั้งการเจริญ), Mn เกินพิษ, P ถูกตรึง (เกิด Al/Fe-phosphate), Ca/Mg/Mo ขาด, จุลินทรีย์ดินทำงานลดลง
- **การจัดการ**: (1) ปูนขาว/ปูนมาร์ล/โดโลไมต์ (lime requirement — คำนวณตาม buffer pH/วิธีของ LDD) (2) การจัดการน้ำ (แช่น้ำในนาลดการออกซิไดซ์ไพไรต์ — อย่าให้ดินแห้งกรอบ) (3) พันธุ์ข้าวทนกรด (4) ปุ๋ยฟอสเฟตที่เหมาะ (เช่น ปุ๋ยร็อกฟอสเฟตในดินกรด) + ธาตุรอง (Si)
- **ขอบเขตที่ครอบคลุม**: การวินิจฉัย/แผนที่, การจัดการปูน+น้ำ+ธาตุ, สถานการณ์ไทย
- **นอกขอบเขต**: ดินเค็ม (02-006), ดินทราย (02-009), พันธุกรรมทนกรดแบบ GEd (ดู 01-007/01-001 สำหรับงานยีน)

## 3. สถานะงานวิจัย

| ช่วงเวลา    | ความก้าวหน้า                                                                  | แหล่ง  |
| ----------- | ----------------------------------------------------------------------------- | ------ |
| 1950s–60s   | งานปูนขาว/ปูนมาร์ลเพื่อแก้ดินเปรี้ยวในที่ลุ่มภาคกลาง                          | [2]    |
| 1970s–80s   | ระบุกลไก acid sulfate (ไพไรต์-จาวปลวก) + งานปรับปรุงทุ่งรังสิต                | [1][2] |
| 1990s–2000s | โครงการปรับปรุงดินเปรี้ยวของกรมพัฒนาที่ดิน (ปูน+น้ำ+พันธุ์) ขยายผล            | [1]    |
| 2010s       | site-specific liming + ปุ๋ย Si/ซิลิเกตในนาข้าวเปรี้ยว                         | [4][5] |
| 2020s       | การจัดการ "น้ำท่วมควบคุม" ในนาลดการเกิดกรด + ดัชนีชี้วัดระยะไกลประเมินพื้นที่ | [3][7] |

- **เส้นแบ่ง**: วิธีแก้มีมานานและพิสูจน์แล้ว แต่ "ทำซ้ำทุก 2–3 ปี" + "ต้นทุนปูน/การขนส่ง" ทำให้บางแปลงปล่อยทิ้ง — งานวิจัยปัจจุบันมุ่งทำแม่นยำ/ประหยัด

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                   | ผลลัพธ์                                               | สถานที่/เงื่อนไข                                | แหล่ง |
| --------------------------- | ----------------------------------------------------- | ----------------------------------------------- | ----- |
| pH ดินเปรี้ยวจัด            | < 4.0 (รุนแรง) — พืชปกติโตไม่ได้                      | ที่ราบลุ่มเจ้าพระยา (รังสิต/นครนายก/ฉะเชิงเทรา) | [1]   |
| ปูนโดโลไมต์ 1–2 ตัน/เฮกตาร์ | pH เพิ่ม ~0.5–1 หน่วย; ผลผลิตข้าว +20–40% ในแปลงทดลอง | ภาคกลาง — ยังไม่ยืนยัน                          | [4]   |
| พื้นที่ดินกรด/เปรี้ยวไทย    | ครอบคลุมหลายล้านไร่ (ตัวเลขแน่นอนต้องยืนยัน LDD)      | กรมพัฒนาที่ดิน                                  | [1]   |
| P fixation                  | ปุ๋ย P ที่ใช้ได้ผลลดลงมากในดินกรด (ต้องปรับวิธีใส่)   | งานทดลองหลายพื้นที่ — ยังไม่ยืนยัน              | [3]   |
| ปุ๋ยร็อกฟอสเฟต              | ใช้ได้ดีในดินกรด (ละลายได้ดีกว่าในดินด่าง)            | งานต่างประเทศ/ไทย — ยังไม่ยืนยัน                | [5]   |

- **กฎ**: ทุกตัวเลขมีแหล่ง + เงื่อนไข — จุดที่ยังไม่ยืนยันกำกับไว้แล้ว (ดูหัวข้อ 10)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดปูนเกษตร/ปูนมาร์ล/โดโลไมต์ของไทย — ภาครัฐเป็นผู้สนับสนุนหลัก (โครงการปรับปรุงดิน); มูลค่าตลาดโดยรวมไม่แยกสำนักชัด (ยังไม่ยืนยัน) [6]
- **ผู้เล่น**: โรงโม่ปูน/เหมืองปูน (ภาคกลาง/สระบุรี), กรมพัฒนาที่ดิน (ผู้วางแผน/อุดหนุน), ผู้ผลิตปุ๋ยซิลิเกต/Si (รายย่อย)
- **ปัจจัยขับเคลื่อน**: ราคาข้าว/ผลผลิตต่อไร่, โครงการรัฐ, การส่งเสริมดินยั่งยืน
- **ปัจจัยฉุดรั้ง**: ต้นทุนขนส่งปูนถึงแปลง, ต้องใส่ซ้ำ, เกษตรกรไม่เห็นผลทันที

## 6. สถานการณ์ประเทศไทย

- **หน่วยงาน**: กรมพัฒนาที่ดินมีศูนย์บริการดินเปรี้ยว + วัสดุปูนปรับปรุงดินแจกจ่าย; มก./ศูนย์วิจัยข้าวมีงานพันธุ์ข้าวทนกรดและปุ๋ยในนาดินเปรี้ยว [1][6]
- **พื้นที่หลัก**: ที่ราบลุ่มแม่น้ำเจ้าพระยา (ทุ่งรังสิต นครนายก ฉะเชิงเทรา ปราจีนบุรี) + ดินกรดด่างภาคอีสาน (เนื้อดินทราย pH ต่ำ)
- **นโยบาย**: โครงการปรับปรุงดินเปรี้ยวอยู่ในแผนงานปรับปรุงบำรุงดินของ LDD; การส่งเสริม "ดินดี" ระดับกระทรวง
- **เอกชน**: โรงปูนขาว/โดโลไมต์ป้อนภาคเกษตร; บริการตรวจดิน pH/ธาตุ

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: แผนที่พื้นที่ดินกรด/เปรี้ยวไทยฉบับล่าสุด (เชื่อม 02-003) — ยังอ้างรุ่นเก่า
- **Q2**: การใส่ปูนแบบแม่นยำ (site-specific liming ตามค่า pH รายแปลง — เชื่อม 02-012) ในบริบทแปลงเล็กไทย — ยังไม่มีบริการ
- **Q3**: ปุ๋ยซิลิเกต/Si ในนาข้าวเปรี้ยวไทย — งาน/ตัวเลขยังน้อย
- **Q4**: ปฏิสัมพันธ์ การจัดการน้ำ (ท่วม-ระบาย) + ปูน + พันธุ์ทนกรด ระยะยาว — ยังขาดการทดลองครบวงจร
- **Q5**: ผลของปูนต่อคาร์บอนในดิน/การปล่อยก๊าซเรือนกระจกในนาน้ำขัง — ยังถกเถียง
- **Q6**: เศรษฐศาสตร์ "ใส่ปูนซ้ำทุก 3 ปี" ต่อไร่ในนาค่าเช่า (ไม่ได้เจ้าของที่ดิน) — ยังไม่มีตัวเลข

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                   | ระดับนโยบาย                                                             |
| ---------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 1 (1–2 ปี) | แปลงสาธิต "ปูนตามค่าตรวจ pH + จัดการน้ำ" ในนาดินเปรี้ยว 4–5 จังหวัด; ตรวจ pH ก่อน-หลัง | ระบบตรวจ pH ฟรี/ราคาถูกถึงอำเภอ (เชื่อม 02-005/02-008)                  |
| 2 (2–4 ปี) | บริการ "คำนวณปูนเฉพาะแปลง" (แอป/Line) + โรงปูนตำบล; สหกรณ์รวมสั่งปูนลดต้นทุน           | แผนที่ pH รายแปลงระดับประเทศ (เชื่อม 02-003); เงินอุดหนุนปูนกลุ่มเสี่ยง |
| 3 (4+ ปี)  | การใส่ปูน/จัดการกรดเป็นมาตรฐานการผลิตข้าวคุณภาพ (GI/ส่งออก)                            | นโยบาย "นาไร้ดินเปรี้ยว" + ผูกข้อมูล 5 ปี ประเมินผลตอบแทน               |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย      | รายละเอียด                                     | โอกาสแก้                            |
| --------------- | ---------------------------------------------- | ----------------------------------- |
| กรดเกิดใหม่     | ไพไรต์ออกซิไดซ์ต่อเมื่อดินแห้ง — ต้องควบคุมน้ำ | รักษาระดับน้ำ/หลีกเลี่ยงการระบายลึก |
| ต้นทุน/ขนส่งปูน | ปูนหนัก ขนส่งไกลแพง                            | โรงปูนระดับตำบล + อุดหนุนค่าขนส่ง   |
| ต้องทำซ้ำ       | ปูนละลาย/ถูกชะ ทุก 2–3 ปี                      | ตารางการใส่ตามข้อมูล pH + สหกรณ์    |
| พื้นที่เช่า     | คนเช่าไม่อยากลงทุนระยะยาว                      | สัญญา/กองทุนปรับปรุงดินร่วม         |
| การตีความ       | เกษตรกรสับสน pH vs ปุ๋ย                        | คำแนะนำง่าย + เจ้าหน้าที่/แอป       |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **พื้นที่ดินเปรี้ยว/กรดไทย (ล้านไร่)** — ตรวจเอกสารกรมพัฒนาที่ดินฉบับล่าสุด (รายงาน "ดินเปรี้ยวจัด" เคยรายงาน ~1.4–5 ล้านไร่ตามนิยามต่างกัน — ต้องระบุให้ชัด)
- [ ] **ปูนโดโลไมต์ 1–2 ตัน/เฮกตาร์ + pH 0.5–1 + ผลผลิต +20–40%** — ค้นงาน primary ไทย (วารสารดินและปุ๋ย/ThaiJo) ยืนยันอัตรา
- [ ] **P fixation และปุ๋ยร็อกฟอสเฟต** — หางานอ้างอิงที่เจาะจงดินไทย
- [ ] **Si fertilizer ในนาไทย** — ค้นงานล่าสุด/แหล่งการตลาด
- [ ] **โครงการปรับปรุงดินเปรี้ยว LDD** — ตรวจรายงานประจำปี/ข่าวล่าสุด
- [ ] **ตลาดปูนเกษตรไทย** — ถ้าหาข้อมูลไม่ได้ให้เปลี่ยนเป็น "ไม่ระบุ"

## 11. อภิธานศัพท์

| คำศัพท์            | ความหมาย                                               |
| ------------------ | ------------------------------------------------------ |
| Acid sulfate soil  | ดินเปรี้ยว — มีไพไรต์ เมื่อออกซิไดซ์ปล่อยกรดกำมะถัน    |
| Pyrite (FeS₂)      | แร่เหล็กกำมะถันในดินเลน — ต้นกำเนิดความเป็นกรด         |
| Jarosite (จาวปลวก) | แร่เหลืองของเสียจากการออกซิไดซ์ไพไรต์                  |
| Lime requirement   | ปริมาณปูนที่ต้องใส่เพื่อยกระดับ pH (คำนวณจากวิธีทดสอบ) |
| Dolomite           | ปูนโดโลไมต์ — ให้ทั้งแคลเซียมและแมกนีเซียม             |
| Al toxicity        | พิษของอะลูมิเนียมละลายต่อรากในดินกรด                   |
| P fixation         | การตรึงฟอสฟอรัสไว้ในดิน (พืชใช้ไม่ได้)                 |
| Buffer pH          | ค่าที่ใช้คำนวณ lime requirement ในการทดสอบดิน          |
