## 1. บทสรุปผู้บริหาร

- **ใจความ**: "ข้าว-ข้าวโพดตรึงไนโตรเจนเอง" ยังเป็นความฝัน แต่อุตสาหกรรมขาย "จุลินทรีย์ดัดแปลงพันธุกรรมตรึง N" ไปแล้ว — ตัวแทนหลักคือ **Pivot Bio (PROVEN 40)** ที่มีงาน peer-reviewed (เทคนิค ¹⁵N) ยืนยันว่าจ่ายไนโตรเจนได้จริง ~21 กก.N/เฮกตาร์ [2][3] แต่ผลในแปลงเกษตรผันแปรสูง: เครือข่ายมหาวิทยาลัยสหรัฐฯ 10 รัฐ พบผลบวกมีนัยสำคัญเพียง **2 จาก 61 แปลง** [9] ขณะที่บริษัทอ้าง win rate >90% [1] — **เป็นสมรภูมิ "งานวิจัย vs โฆษณา" ที่ร้อนแรงที่สุดเรื่องหนึ่งของวงการตอนนี้** (บทความ Giller et al. 2025 ชี้ว่าผลส่วนใหญ่อาจมาจากฮอร์โมนไม่ใช่การตรึง N) [9]
- **ตัวเลขสำคัญที่สุด**: (ก) PROVEN 40 ให้ N จริง 21.2 กก.N/เฮกตาร์ (95% CI: −0.16 ถึง 42.6, งานอิสระ U. Illinois) [3] (ข) การถ่ายยีน nitrogenase ตรง ๆ เข้าข้าวยังอยู่แค่ห้องแล็บ (TRL 5) [7]
- **นัยต่อไทย**: งานไทยยังเป็นแบคทีเรียดั้งเดิม (พด.12 ของกรมพัฒนาที่ดิน: อ้างเพิ่ม N 3 กก./ไร่/ปี) [10] — ยังไม่มีผลิตภัณฑ์ "gene-edited microbe" ระดับเดียวกับ Pivot Bio และยังไม่พบหลักฐานว่ามีการจดทะเบียนจำหน่ายในไทย
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว (จุลินทรีย์เสริม — ฝั่งตะวันตก) + 🔬 งานวิจัย (การถ่ายยีน nif เข้าพืชตรง ๆ)

## 2. หลักการและขอบเขต

- **ทำไมธัญพืชตรึง N เองไม่ได้**: เอนไซม์ nitrogenase ไวต่อออกซิเจนมาก (ถูกทำลายทันทีที่โดน O₂) พืชตระกูลถั่วแก้โดยสร้างปมราก (nodule) เป็นสภาพกึ่งไร้ออกซิเจน ข้าว/ข้าวโพด/ข้าวสาลีไม่มีระบบนี้ จึงต้องพึ่งปุ๋ยเคมี
- **4 เส้นทาง**: (1) จุลินทรีย์เสริมตรึง N รอบราก (แบบดั้งเดิม — เก่า) (2) **จุลินทรีย์ดัดแปลงพันธุกรรม** (Pivot Bio ใช้เทคนิค derepression ของระบบ nif + ตัดยีน GlnD ทำให้ปล่อยแอมโมเนียมมากขึ้น ~15 เท่า) (3) **ถ่ายยีน nif 13 ยีน (~40 kb) เข้าพืชโดยตรง** (4) วิศวกรรมซิมไบโอซิส/ไซยาโนแบคทีเรีย
- **ขอบเขตที่ครอบคลุม**: BNF ในธัญพืช (ข้าว/ข้าวโพด/ข้าวสาลี) ทุกเส้นทาง + ปุ๋ยชีวภาพ
- **สิ่งที่ไม่อยู่ในขอบเขต**: ปุ๋ยเคมี/การจัดการไนโตรเจนทั่วไป, ไรโซเบียมถั่วเหลือง (ระบบปมรากเดิม), จุลินทรีย์ควบคุมโรค (ชีวภัณฑ์)

## 5. ตลาดและการลงทุน

- **Pivot Bio**: ระดมทุนรวม **$697 ล้าน** (PitchBook); Series D $430M (2564, DCVC/Temasek); เป้ารายได้ $1 พันล้านภายใน 2030; **ข่าว Series F $215M @ มูลค่า $1.8B + รายได้ $148M (2025) + พื้นที่ 6.1 ล้านเอเคอร์ — มาจากแหล่งทุติยภูมิแหล่งเดียว ยังไม่ยืนยันโดยบริษัท** [5]
- **โปรแกรม N-OVATOR**: 1.5 ล้านเอเคอร์ (2022–23) ทดแทนปุ๋ย 28,500 ตัน, เลี่ยง CO₂e 251,000 ตัน; จ่ายเงินชดเชยสะสม >$13 ล้าน [5]
- **Azotic Technologies**: ยังดำเนินกิจการ (ไม่ล้มละลาย) แต่เปลี่ยนเจ้าของ 3 ครั้งใน 2 ปี (Koppert→Ontario Inc→Virya→**Exa Ventures LLC** ธ.ค. 2568 — ตัวตนนักลงทุนยังไม่เปิดเผย); ยุบบริษัทลูกยุโรป ก.พ. 2568; CEO ใหม่ เม.ย. 2568; ขยายตลาดฟิลิปปินส์ (ข้าว, พ.ค. 2567) และญี่ปุ่น [4]
- **การลงทุนทั้งอุตสาหกรรม**: VC ในกลุ่ม "crop-agnostic N-fixing" ≥ **$1.5 พันล้าน** (ประมาณการ Giller — ยังไม่ยืนยันจากแหล่งอื่น); ตลาด biofertilizers โลก $1.3B (2566) → $2.14B (2571) (analyst) [9]

## 6. สถานการณ์ประเทศไทย

- **ผลิตภัณฑ์ภาครัฐ**: พด.12 (Azotobacter + B. unamae + B. subtilis + A. chroococcum — ใช้ 300 กก.ปุ๋ยหมักขยายเชื้อ/ไร่) และ พด.11 (ไรโซเบียมโสนอัฟริกัน/ปอเทือง) ของกรมพัฒนาที่ดิน [10]
- **งานมหาวิทยาลัย**: ม.ธรรมศาสตร์ TU-Orga1 (ข้าว: ดิน N +37.1%, ผลผลิต +21.8% — งานเก่า 2554 พื้นที่เดียว); ม.เกษตรศาสตร์คัดแยก PGPR 28 ไอโซเลตจากนาข้าว (2566) กำลังพัฒนา; ม.แม่โจ้ (B. altitudinis); ม.นเรศวร (ร่วมยูเรีย) [10]
- **จุดอ่อน**: งานไทยเป็นแบคทีเรีย wild-type ทั้งหมด ยังไม่มีงาน "gene-edited microbe" (แบบ Pivot) หรือเอนโดไฟต์ (แบบ Azotic) ในธัญพืช; BIOTEC ไม่พบโปรแกรม BNF ธัญพืชเปิดเผย; ยังไม่พบหลักฐานการจดทะเบียน PROVEN 40/Envita ในไทย
- **บริบท**: ไทยใช้ปุ๋ยเคมีปีละหลายล้านตัน — ราคาปุ๋ยผันผวนตามวิกฤตโลก (ต้นทุนขึ้นกระทบชาวนาโดยตรง); นโยบายลดการใช้สารเคมี/เกษตรยั่งยืนเป็นกระแสหลัก

## 7. ช่องว่างงานวิจัย (Open Questions)

1. การทดลองอิสระแบบสุ่ม หลายปี หลายพื้นที่ **ในระบบเขตร้อน/เอเชีย** (งานที่มีกระจุกอเมริกา-ยุโรป) — ไทยแทบไม่มีข้อมูลเลย
2. "ตรึงจริงหรือฮอร์โมน?" — ยังไม่มีวิธีแยกผล IAA ออกจาก N ในแปลง; Giller เสนอ 6 เกณฑ์บังคับก่อนอ้างว่า "ตรึง N" (ครบยีน, แก้ oxygen paradox, ประชากรพอ, วัดการหายใจเพิ่ม, เจริญไร้ N ได้, ยืนยัน 2 วิธี) — ไทยควรใช้เกณฑ์นี้ในการรับรองปุ๋ยชีวภาพ [9]
3. การผันแปรระหว่างชนิดแมลง/พื้นที่ — อะไรทำให้ได้ผลบางแปลงบางปีเท่านั้น
4. nif gene transfer: ต้นทุนพลังงานต่อผลผลิต + การแก้ NifH instability ยังไม่มีคำตอบ
5. ผลระยะยาวของการใช้จุลินทรีย์ GEd ต่อจุลินทรีย์ดินดั้งเดิม (ยังไม่มีข้อมูล)
6. ข้าวไทย: ไม่มีงานระบบ BNF "gene-edited microbe" ในนาข้าวแม้แต่แปลงทดลอง

## 8. นัยต่อการนำไปใช้ (Blueprint)

**ระยะเร่งด่วน (0–1 ปี)**: ใช้พด.12/พด.11 ต่อในพื้นที่ที่มีหลักฐานผลดี (อ้างอิงข้อมูลกรมพัฒนาที่ดิน) + ตั้งเกณฑ์รับรอง "คำอ้างตรึง N" ของผู้ขายตาม 6 เกณฑ์ Giller — ปกป้องชาวนาจากผลิตภัณฑ์โฆษณาเกินจริง
**ระยะกลาง (1–3 ปี)**: โครงการทดลองอิสระระดับประเทศ (กรมวิชาการเกษตร/BIOTEC + มหาวิทยาลัย) เปรียบเทียบ PROVEN-40 class / Azotic class ในข้าวนาปี-นาปรัง หลายจังหวัด 2–3 ปี — สร้างข้อมูล "made in Thailand" ก่อนตัดสินใจรับเทคโนโลยีต่างชาติ
**ระยะยาว (3–5 ปี)**: พัฒนาจุลินทรีย์ GEd สายพันธุ์ไทย (แบคทีเรียจากนาข้าวไทย 28 ไอโซเลตเป็นฐานตั้งต้น — ทุน BIOTEC/NSTDA + กฎหมาย GEd 2567 ครอบคลุมจุลินทรีย์) + ติดตาม nif gene transfer ระหว่างที่ยังอยู่ในแล็บ

## 9. ความท้าทายและข้อจำกัด

- **ความน่าเชื่อถือ**: ตัวเลขบริษัท vs งานอิสระต่างกันมาก (win rate >90% vs 2/61 แปลง) — การตัดสินใจซื้อต้องพึ่งข้อมูลอิสระ
- **การตรวจจับ**: เทคนิค ¹⁵N ตรวจจับได้ ~20% Ndfa (~10 กก.N/เฮกตาร์) — N ที่ได้น้อยกว่านี้ "มีจริงแต่ตรวจไม่พบ" → เปิดช่องโต้แย้งได้เสมอ [9]
- **โครงสร้างบริษัทผันผวน**: Azotic เปลี่ยนเจ้าของ 3 ครั้ง/2 ปี, ยุบ entity ยุโรป — ความเสี่ยงเรื่องการรับประกันผลิตภัณฑ์ระยะยาว
- **ราคา**: 26 เหรียญ/เอเคอร์ (~350 บาท/ไร่) เทียบปุ๋ยยูเรีย — ต้องคุ้มจริงในบริบทไทยที่แรงงาน/ราคาปุ๋ยต่างจากตะวันตก
- **กฎหมาย**: จุลินทรีย์ GEd ยังไม่มีเส้นทางรับรองชัดเจนในไทย (ประกาศ 2567 เน้นพืช)

## 11. อภิธานศัพท์

| คำ           | คำอธิบาย                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------ |
| BNF          | Biological Nitrogen Fixation — การตรึงไนโตรเจนโดยสิ่งมีชีวิต                                     |
| Nitrogenase  | เอนไซม์ตรึง N₂ → NH₃ (ไวต่อออกซิเจน, ใช้พลังงาน 16 ATP/โมเลกุล)                                  |
| nif genes    | กลุ่มยีน ~20 ยีนที่ประกอบเป็น nitrogenase (การถ่ายยีนเข้าพืช = ความฝัน "ข้าวตรึง N เอง")         |
| Ndfa         | สัดส่วน N ที่มาจากอากาศ (% ของ N ทั้งหมดที่พืชดูด)                                               |
| Derepression | เทคนิคปลดล็อก/เปิดการทำงานของยีน nif ในแบคทีเรียให้ตรึง N ต่อเนื่อง (Pivot Bio)                  |
| ¹⁵N dilution | เทคนิคไอโซโทปวัด N ที่มาจากอากาศในแปลง (ขีดจำกัด ~20% Ndfa)                                      |
| PGPR         | Plant Growth-Promoting Rhizobacteria — แบคทีเรียส่งเสริมการเจริญของพืช                           |
| Endophyte    | แบคทีเรียที่อาศัยอยู่ภายในเนื้อเยื่อพืช (Azotic: Gluconacetobacter diazotrophicus จากอ้อยบราซิล) |
| TRL          | Technology Readiness Level — ระดับความพร้อมเทคโนโลยี (TRL 5 = ต้นแบบยืนยันในแล็บ)                |
