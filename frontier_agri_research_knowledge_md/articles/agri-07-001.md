## 1. บทสรุปผู้บริหาร

- **ใจความ**: การเก็บผลไม้ = "ปัญหาที่ยากที่สุด" ในหุ่นยนต์เกษตร (frontier): ต้องมองเห็นผลไม้ในเรือนยอดบัง/แสงเปลี่ยน (computer vision), เข้าถึงกิ่งซับซ้อน (manipulation), หยิบโดยไม่ช้ำ (gentle grasping), ตัด/ดึงด้วยแรงพอดี (end-effector) — แล้วทำซ้ำ 2–5 วินาทีต่อลูก ตลอดวัน; ยังไม่มีหุ่นยนต์เก็บผลไม้เชิงพาณิชย์เต็มรูปแบบ (2026) — สถานะ = ทดลอง/นำร่อง (pilot) กับผลไม้บางชนิด (สตรอเบอร์รี/แอปเปิล/เบอร์รี/หน่อไม้ฝรั่ง) [1][2][3]
- **ขั้นพัฒนา**: 🧪 นำร่องแปลงทดลอง/การใช้งานจำกัด (ต้นแบบเชิงพาณิชย์เริ่มในสตรอเบอร์รี/หน่อไม้ฝรั่ง — ยังไม่ "เก็บแทนคน" เต็มระบบ) [3]
- **ตัวเลขสำคัญที่สุด**: ความเร็วเก็บ ~2–5 วินาที/ลูก (สตรอเบอร์รี/แอปเปิล — สภาพแปลง/งานทดลอง; เทียบคนเก็บสตรอเบอร์รี ~3–5 วินาที/ลูก); อัตราความสำเร็จ (pick success) ~60–90% (ขึ้นผลไม้/สภาพต้น — งานทดลอง); ต้นทุนเครื่อง ~1–5 แสนดอลลาร์/เครื่อง (รุ่นพาณิชย์เริ่ม) — ยังสูงกว่าคนในหลายกรณี แต่ทิศทางลดลง [2][3][4]
- **นัยต่อไทย**: ไทยมีผลไม้เก็บด้วยแรงงานเข้มข้นสูง (ทุเรียน/มังคุด/ลำไย/ลองกอง/เงาะ — ต้นสูง กิ่งเปราะ) — เป็น "โจทย์หลังสุด" ที่ยังห่างจากการนำมาใช้ 3–5+ ปี; แต่สตรอเบอร์รี/เบอร์รี (ภาคเหนือ) และหน่อไม้ฝรั่งเป็นจุดเริ่มที่เหมาะ (ต้นเตี้ย/เก็บซ้ำ) — ไทยควรติดตาม + ลงทุนงาน vision/end-effector กับผลไม้ไทยเฉพาะ (ทุเรียน — หนาม/หนัก/ค่าความเสียหายสูงมาก) [5][6]
- **สถานะโดยรวม**: 🧪 นำร่องแปลงทดลอง/ใช้งานจำกัด

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (5 ชั้นของระบบ)

1. **การรับรู้ (Perception)**: กล้อง RGB/สเตอรีโอ/ToF/ไฮเปอร์สเปกตรัม + AI ตรวจจับผลไม้/ตำแหน่ง 3D/การบัง (fruit detection & localization) — ผ่านแสงแดดจ้า/เงา/ใบบัง/ผลไม้เป็นพวง (ทนได้ดีพอในแปลงจริง แต่ยังล้มเหลวในสภาพยาก)
2. **การวางแผน (Planning)**: แขนหุ่นยนต์ (arm) + วิถีการเคลื่อนที่ (motion planning) — หลบกิ่ง/ไม่ชนผลไม้ข้างเคียง; ระบบรับรู้ "กิ่งไหนดึงได้" (compliance)
3. **การจับ/ตัด (Manipulation)**: end-effector หลายแบบ — (ก) ดูดสุญญากาศ (vacuum — Abundant ใช้กับแอปเปิล) (ข) กรงเล็บอ่อน/หัตถ์หนีบ (soft gripper — สตรอเบอร์รี) (ค) จานหมุนตัดขั้ว (แอปเปิล) (ง) คีมตัด+ท่อลำเลียง (หน่อไม้ฝรั่ง/สตรอเบอร์รี) — หัวใจ = "หยิบไม่ช้ำ" (แรง/การควบคุม)
4. **การลำเลียง/บรรจุ**: ใส่ถาด/ตะกร้าโดยไม่ช้ำ + แยกเกรดเบื้องต้น (ความสุก/ขนาด — AI ต่อยอด)
5. **การนำทาง (Navigation)**: เคลื่อนตามแถว (row) — ระบบนำทาง/แผนที่แปลง (ต่อยอด 07-005)

### 2.2 เทคโนโลยีแยกย่อยตามผลไม้

| ผลไม้/งาน                         | วิธีเก็บ                                 | ผู้เล่น/งาน                                                                                           | สถานะ                                    |
| --------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| สตรอเบอร์รี (raised bed)          | แขน+กรงเล็บอ่อน/มีดตัด+สายพาน            | Dogtooth (UK), Agrobot (สเปน), Harvest CROO (US), Octinion (เบลเยียม), Tortuga (US — ปรับไปงานวัชพืช) | ใกล้พาณิชย์สุด — เก็บ/บรรจุครบในบางฟาร์ม |
| แอปเปิล (ต้นมาตรฐาน/สูง)          | จานตัดขั้ว / ดูด+บิด / โดรนมีแขน (Tevel) | FFRobotics (อิสราเอล), Tevel (อิสราเอล — โดรนบินเก็บ), Abundant (US — ดูด; เลิกกิจการ 2019–2020)      | นำร่อง/ทดลอง                             |

| หน่อไม้ฝรั่ง (ตัดหน่อ)            | กล้อง+มีดตัด+ท่อลำเลียง                  | Inaho (ญี่ปุ่น — เก็บแบบ "รับจ้างเก็บ")                                                               | ใช้งานเชิงพาณิชย์จำกัด (ญี่ปุ่น)         |
| แตงกวา/มะเขือเทศ (โรงเรือน)       | แขน+กรงเล็บตัด                           | งาน EU (CROPS/GRIFFIN-class), 04-004                                                                  | งานวิจัย/นำร่อง                          |

- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/สถานะ/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: หุ่นยนต์กำจัดวัชพืช (07-002), รถแทรกเตอร์ (07-005), หุ่นยนต์โรงเรือนทั่วไป (04-004), โดรนสำรวจ/พ่น (05-005/05-006)

| 1990s–2010s | วิชันดีขึ้น (RGB-D); งานเก็บสตรอเบอร์รี/แตงกวา/ส้มมาก (ญี่ปุ่น/สเปน/เนเธอร์แลนด์/สหรัฐ) — ยังช้า/เปราะ                                                                                                          | [1][2]    |

| 2022–2025   | AI (deep learning) ยกระดับการตรวจจับ/ความเร็ว; Dogtooth/Agrobot/Harvest CROO ใช้งานเชิงพาณิชย์จำกัด (สตรอเบอร์รี — เก็บ+บรรจุ); Inaho รับจ้างเก็บหน่อไม้ฝรั่ง (ญี่ปุ่น); Tevel โดรนเก็บแอปเปิล (อิสราเอล/สหรัฐ) | [3][4][5] |

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                          | ผลลัพธ์                                                                                         | สถานที่/เงื่อนไข                         | แหล่ง  |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------- | ------ |
| เวลาเก็บ/ลูก (สตรอเบอร์รี — หุ่นยนต์)              | ~2–5 วินาที/ลูก (งานทดลอง/ระบบล่าสุด; เทียบคน ~3–5 วินาที/ลูก)                                  | ฟาร์ม/แปลงทดลอง — ขึ้นจำนวนแขน/การบัง    | [2][3] |
| เวลาเก็บ/ลูก (แอปเปิล — หุ่นยนต์)                  | ~5–10+ วินาที/ลูก (ช้ากว่าคนหลายเท่า)                                                           | ต้นแอปเปิลมาตรฐาน — งานทดลอง             | [2]    |
| อัตราความสำเร็จเก็บ (pick success)                 | ~60–90% (ขึ้นผลไม้/สภาพ — ยังไม่ 95%+ ที่จำเป็น)                                                | งานทดลอง/แปลง                            | [2][3] |
| การช้ำ/ความเสียหายของผล                            | ต่ำกว่าเกณฑ์ตลาดได้ (สตรอเบอร์รี — กรงเล็บอ่อน) แต่ยังมีกรณีช้ำ (แอปเปิลดูด — บทเรียน Abundant) | งานทดลอง                                 | [3][4] |
| ต้นทุนเครื่อง                                      | ~1–5 แสนดอลลาร์/เครื่อง (รุ่นพาณิชย์เริ่ม — สตรอเบอร์รี)                                        | ตลาด                                     | [4]    |
| ความคุ้มค่าเทียบแรงงาน                             | ยังแพงกว่าคนในหลายพื้นที่ (แต่ใกล้จุดคุ้มที่ค่าแรงสูง + เก็บหลายฤดู/หลายกะ)                     | เศรษฐศาสตร์ฟาร์ม — ขึ้นค่าแรง/ราคาผลผลิต | [3][4] |
| แรงงานขาดแคลน (ผลไม้เก็บมือ — ญี่ปุ่น/สหรัฐ/ยุโรป) | วิกฤตต่อเนื่อง (แรงงานตามฤดูกาลลด — ตัวขับเคลื่อนหลัก)                                          | รายงานอุตสาหกรรม/ข่าว                    | [5]    |

- **กฎ**: "คุ้มเมื่อ = ค่าแรงสูง + ราคาผลไม้สูง + เก็บได้หลายชั่วโมง/กลางคืน/หลายรอบ" — ตัวเลขทุกตัวเป็นช่วง/งานทดลอง (ยังไม่มีมาตรฐานวัดแบบเดียวกัน) — ใช้เทียบเคียงทิศทาง
- **ตัวเลขต่างกันหลายแหล่ง**: ความเร็ว/ความสำเร็จต่างกันมาก (ระบบ+ผลไม้+ฟาร์ม) — อย่ายึดค่าเดียว; ดูแนวโน้ม (เร็วขึ้นทุกปี + AI)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดหุ่นยนต์เก็บเกี่ยวผลไม้ ~3–8 พันล้านดอลลาร์ (2030 — analyst estimate หลายสำนัก ช่วงกว้าง ยังไม่ยืนยัน); ตลาด "agricultural robotics" ทั้งหมด ~5–15 พันล้านดอลลาร์ (2030) [4]
- **ผู้เล่นหลัก**: (ดูตาราง 3.1) + งานวิจัย (WUR, UC Davis, มก. ญี่ปุ่น — Kyoto/Okayama, ETH Zurich); ผู้ลงทุน: VC AgTech (ในสหรัฐ/ยุโรป/อิสราเอล); ไทย: ยังไม่มีผู้เล่นเก็บผลไม้

### 5.1 ตารางผู้เล่นโดยรวม

| กลุ่ม                  | ตัวอย่าง                                                  | บทบาท                       |
| ---------------------- | --------------------------------------------------------- | --------------------------- |
| สตาร์ทอัพเก็บผลไม้     | Dogtooth, Harvest CROO, Agrobot, Tevel, FFRobotics, Inaho | พัฒนา/ขาย-บริการ            |
| ผู้ผลิตเครื่องจักรใหญ่ | John Deere, Kubota, Yanmar (ดู/ร่วม/ลงทุน)                | เข้าตลาดผ่านซื้อ/ร่วมทุน    |
| มหาวิทยาลัย/งานวิจัย   | WUR, UC Davis, Georgia Tech, มหาวิทยาลัยญี่ปุ่น           | งานพื้นฐาน (gripper/vision) |
| ฟาร์ม/ผู้รับจ้าง       | ฟาร์มเบอร์รีอังกฤษ, ฟาร์มแอปเปิล US/EU                    | ผู้ใช้แรก (early adopters)  |

- **ปัจจัยขับเคลื่อน**: แรงงานขาดแคลน/แพงขึ้น (ผลไม้เก็บมือ — ตัวหลัก), ราคาผลไม้สูง, AI ตรวจจับดีขึ้น, การเก็บกลางคืน (คุณภาพ/หลบร้อน), ระบบบริการ/รับจ้าง (ลดภาระซื้อเครื่อง)
- **ปัจจัยฉุดรั้ง**: ต้นทุนเครื่องสูง, ยังเก็บไม่ครบ 100% (ต้องคนซ่อม), ผลไม้หลายชนิดยังทำไม่ได้ (ผลไม้เขตร้อนต้นสูง), การบัง/แสง (แปลงจริง), การลงทุน VC หดตัว (2023–2025 — AgTech ทั่วโลก)
- **แนวโน้ม**: บริการ/รับจ้างเก็บ (เก็บต่อกิโล — Inaho-class), การเก็บ+บรรจุ+เกรดในเครื่องเดียว, หุ่นยนต์เล็กหลายตัวทำงานร่วม (07-003), ผูก data/AI วางแผนการเก็บ (06-001)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ยังไม่มีหุ่นยนต์เก็บผลไม้เชิงพาณิชย์/งานนำร่องระดับฟาร์ม (มีงานวิจัยแขน/วิชันในมหาวิทยาลัย — ยังเป็นงานห้องแล็บ); แรงงานเก็บผลไม้ไทยยังพอมี (แต่ค่าจ้างขึ้น/แรงงานลด — โดยเฉพาะทุเรียน/ลำไยช่วงเร่งด่วน) [5][6]
- **ผลไม้ที่ควรเริ่มก่อน (ตามเกณฑ์สากล)**: (1) สตรอเบอร์รีภาคเหนือ (ราชบุรี/เชียงใหม่ — เก็บซ้ำ/ต้นเตี้ย — เหมือนโจทย์ที่สำเร็จในยุโรป) (2) หน่อไม้ฝรั่ง (กำแพงเพชร/ราชบุรี — เก็บซ้ำทุกวัน) (3) พริก/มะเขือเทศโรงเรือน (04) — ส่วนทุเรียน/มังคุด/ลำไย (ต้นสูง/กิ่งเปราะ/ค่าความเสียหายสูง) = ระยะ 5+ ปี (งานวิจัย)
- **จุดแข็งไทย**: งาน AI/วิชันมหาวิทยาลัยพร้อม (ต่อยอด), ข้อมูลภาพผลไม้ไทยมีในงานวิจัย (ขยายชุด), แรงงานยังมี (ช่วงปรับตัว), ตลาดส่งออกผลไม้สดใหญ่ (มีเงินจ่าย)
- **จุดอ่อน**: ไม่มีสตาร์ทอัพหุ่นยนต์เก็บผลไม้, งบ/เครื่องมือ R&D จำกัด, ผลไม้หลักของไทย "ยากสุด" (ทุเรียน — หนาม/หนัก/สูง/ตัดขั้ว), ฟาร์มเล็ก (รายได้ไม่พอซื้อเครื่อง), ค่าแรงยังต่ำกว่าจุดคุ้ม (เทียบยุโรป/ญี่ปุ่น)
- **โอกาส**: (1) งานวิจัย "end-effector+AI สำหรับทุเรียน/มังคุด" (ร่วม มก./มจธ./มข. — เผยแพร่นานาชาติ; เก็บ+ตัดขั้วแบบลดช้ำ) (2) นำร่อง "หุ่นยนต์เก็บสตรอเบอร์รี/หน่อไม้ฝรั่ง" (นำเข้า/ร่วมทุน — รับจ้างเก็บ) (3) สร้างชุดภาพผลไม้ไทยเปิด (AI) (4) จับคู่แรงงานขาดแคลน (ช่วงทุเรียน) กับบริการรับจ้างเก็บ (รุ่น 2–3 ปี)
- **หน่วยงาน**: มก./มจธ./มข./มช. (งานวิจัย), กรมวิชาการ/ส่งเสริม (แปลง/ข้อมูล), NIA/สวทช. (ทุน), ผู้ส่งออก/สหกรณ์ทุเรียน (ต้นทุนความเสียหาย — จ่ายได้)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ระบบเก็บ "ทุเรียน" (ผลใหญ่/หนาม/หนัก 2–5 กก./ต้นสูง 10+ ม./ตัดขั้ว) — ยังไม่มีงานที่จริงจัง (นานาชาติก็ไม่มี — เป็นโจทย์ไทยแท้)
- **Q2**: ชุดข้อมูลภาพผลไม้ไทยเปิด (ทุเรียน/มังคุด/ลำไย — ตำแหน่ง 3D/การบัง/ความสุก) — ยังไม่มี
- **Q3**: end-effector "ไม่ช้ำ" สำหรับผลไม้ไทย (มังคุด/ลองกอง — เปลือกบาง/ช้ำง่าย) — ยังไม่มี
- **Q4**: เศรษฐศาสตร์ "รับจ้างเก็บ" ในไทย (ราคา/กก. ที่ยอมจ่าย — เทียบแรงงาน) — ยังไม่มีงาน
- **Q5**: การเก็บกลางคืน/สภาพแสงไทย (ร้อนจัด) — การออกแบบระบบ — ยังไม่มี
- **Q6**: การผูกหุ่นยนต์เก็บกับ digital twin/การวางแผนการเก็บ (06-001) — ยังไม่มี
- **Q7**: มาตรฐานวัด "ความสำเร็จ/ความช้ำ" ของหุ่นยนต์เก็บ (ทดสอบแบบเดียวกัน) — ยังไม่มี (นานาชาติ)

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย           | รายละเอียด                                                | โอกาสแก้                                                                       |
| -------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------ |
| การมองเห็นในแปลงจริง | แสงจ้า/เงา/ใบบัง/ผลไม้เป็นพวง — ตรวจจับ/ตำแหน่ง 3D พลาด   | AI หลายกล้อง/ไฮเปอร์สเปกตรัม, การเก็บกลางคืน (แสงคุม)                          |
| การหยิบไม่ช้ำ        | ผลไม้บอบบาง (สตรอเบอร์รี/มังคุด) — แรงเกิน = ช้ำ/เสียเกรด | กรงเล็บอ่อน/แรงคุม (soft robotics), การทดสอบแรง                                |
| ความเร็ว             | ยังช้ากว่าคน (โดยเฉพาะแอปเปิล/ผลไม้ต้นสูง)                | หลายแขน/หลายโดรน (Tevel-class), ระบบดีขึ้นด้วย AI                              |
| ต้นทุน               | เครื่อง 1–5 แสนดอลลาร์ — ฟาร์มเล็กจ่ายไม่ไหว              | บริการ/รับจ้าง (เก็บต่อกก.), เช่า/ร่วมทุน                                      |
| ผลไม้เขตร้อนต้นสูง   | ทุเรียน/ลำไย/เงาะ — เข้าถึง/ตัดขั้ว/ผลใหญ่หนัก            | งานวิจัยระยะยาว (Q1) — เริ่มจาก "ยานพาหะ+แขนยาว"                               |
| เศรษฐศาสตร์          | ค่าแรงไทยยังถูก — จุดคุ้มยังไกล (เทียบญี่ปุ่น/ยุโรป)      | เลือกผลไม้/พื้นที่ที่ค่าแรงแพง/เก็บเร่งด่วน; มองตลาดส่งออก (ค่าความเสียหายสูง) |
| การยอมรับ            | เกษตรกร/คนงานกลัว "เครื่องแย่งงาน" /ไม่ไว้ใจ (14-003)     | สาธิตผล (ช้ำน้อยกว่า/เก็บกลางคืน), รับจ้างแบบเสริมคน                           |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **2–5 วินาที/ลูก (สตรอเบอร์รี) / 5–10+ วินาที/ลูก (แอปเปิล)** — ตรวจงานทดลองล่าสุด (ระบุระบบ/ปี)
- [ ] **pick success 60–90%** — ตรวจงาน (ระบุผลไม้/สภาพ)
- [ ] **คนเก็บสตรอเบอร์รี ~3–5 วินาที/ลูก** — ตรวจแหล่งแรงงาน/งานศึกษา
- [ ] **ต้นทุนเครื่อง 1–5 แสนดอลลาร์** — ตรวจราคา/ข่าวผู้เล่น
- [ ] **Abundant เลิกกิจการ 2020 (สาเหตุ)** — ตรวจข่าวย้อนหลัง
- [ ] **สถานะ Dogtooth/Agrobot/Harvest CROO (ใช้งานเชิงพาณิชย์ 2025–26?)** — ตรวจเว็บ/ข่าว
- [ ] **Inaho รับจ้างเก็บหน่อไม้ฝรั่ง (ญี่ปุ่น — สถานะ)** — ตรวจข่าวล่าสุด
- [ ] **Tevel โดรนเก็บแอปเปิล (สถานะ 2025–26)** — ตรวจข่าวล่าสุด
- [ ] **ตลาดเก็บเกี่ยวหุ่นยนต์ 3–8 พันล้านดอลลาร์ (2030)** — ตรวจ analyst report ระบุปี
- [ ] **งานหุ่นยนต์เก็บผลไม้ไทย (มหาวิทยาลัย)** — ตรวจ TCI/ข่าว (ระบุชิ้น)
- [ ] **แรงงานเก็บผลไม้ไทยขาดแคลน/ค่าแรงขึ้น (2025–26)** — ตรวจข่าว/รายงาน
