## 1. บทสรุปผู้บริหาร

- **ใจความ**: หุ่นยนต์กำจัดวัชพืชแม่นยำ = AI จำแนก "พืช vs วัชพืช" แบบเรียลไทม์ (ภาพ/กล้อง) แล้วกำจัดเฉพาะวัชพืชด้วย 3 วิธี: (1) **เลเซอร์** (Carbon Robotics LaserWeeder — ยิงเลเซอร์ความร้อนฆ่ายอดวัชพืช) (2) **กลไก** (จอบ/มีดหมุนเฉพาะจุด — FarmWise/Steketee/Naïo/Odd.Bot — ฝังดิน/ถอน/ตัด) (3) **ไฟฟ้า** (กระแสไฟฟ้าเผาเนื้อเยื่อ — RootWave/Zasso — ไม่ต้องสัมผัส) — เป้าหมาย: ลด/เลิกสารเคมีกำจัดวัชพืช (glyphosate-class) + ลดแรงงานถอนวัชพืช (แพงที่สุดในผัก/ออร์แกนิก) [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น (เลเซอร์/กลไก/ไฟฟ้า มีขาย/บริการแล้วในอเมริกา/ยุโรป — ผัก/แปลงใหญ่; ไทยยังไม่มี) [3][4]
- **ตัวเลขสำคัญที่สุด**: LaserWeeder กำจัดวัชพืชได้ ~5,000 ต้น/นาที (ความสามารถระบบ — อ้างผู้ผลิต); การถอนวัชพืชด้วยมือในผัก/ออร์แกนิกแพงมาก ~$150–700/เอเคอร์/รอบ (งาน/รายงาน — ตัวขับเคลื่อน); กำจัดได้ ~90–99% (งานทดลอง — เลเซอร์/กลไก ขึ้นชนิดวัชพืช/ขนาด); ต้นทุนบริการ/เครื่อง ~$1–2 แสนดอลลาร์ (เครื่อง) หรือรับจ้างต่อไร่ — ยังแพงแต่ "จ่ายเพื่อเลิกสารเคมี/แรงงาน" [2][3][4]
- **นัยต่อไทย**: ไทยใช้แรงงานถอนวัชพืชในผัก/ข้าว/อ้อยอยู่มาก (อ้อย-วัชพืชมีสารเคมี) — หุ่นยนต์เหล่านี้ "มาได้ก่อนหุ่นยนต์เก็บผลไม้" (เครื่องจักรบนพื้นเรียบ/แปลงผัก — เริ่มได้จริง); แต่ไทยยังไม่มีผู้เล่น/บริการ — จุดเริ่ม = ฟาร์มผักออร์แกนิก/โรงเรือน (04-004) + งานวิจัย AI จำแนกวัชพืชภาษาไทย (มีงานวิจัยข้าวแล้ว) [5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (ต่างประเทศ) — ไทยยังว่าง

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (3 เทคโนโลยี)

1. **เลเซอร์ (Laser weeding)**: กล้อง+AI ตรวจจับ/จำแนกวัชพืช → กระจก/เลเซอร์ยิงความร้อนที่ "จุดเจริญ" (meristem) ยอดวัชพืช → เซลล์ตาย (ไม่ต้องถอนราก) — ยิงได้รวดเร็ว (~มิลลิวินาที/จุด) ไม่สัมผัสดิน/ไม่รบกวนดิน; ต้อง "แม่นยำมาก" (ไม่โดนพืช) + พลังงานเลเซอร์ต้องพอ (วัชพืชใหญ่/รากลึกอาจงอกใหม่)
2. **กลไก (Mechanical weeding)**: วิชันจำแนก → (ก) จอบหมุน/มีดเฉพาะจุด (ระหว่างต้น — Steketee IC, FarmWise Titan) (ข) แขนถอน/ตัดรอบต้น (Odd.Bot) (ค) พรวนตื้นระหว่างแถว + ปรับความลึกอัตโนมัติ — กำจัด "ราก+ยอด" (อยู่ทนกว่า) แต่รบกวนดิน/ต้องดูความลึก (รากพืช)
3. **ไฟฟ้า (Electrical weeding)**: ขั้วไฟฟ้าแตะ/พ่นน้ำเกลือนำไฟฟ้าบนวัชพืช → กระแสความถี่สูงผ่านเนื้อเยื่อ → เซลล์แตก/ตาย (RootWave/Zasso — ปัจจุบันใช้กับวัชพืชสูง/แปลงใหญ่) — ไม่ใช้สารเคมี ไม่รบกวนดิน แต่ช้ากว่า/ไฟต้องปลอดภัย

### 2.2 การจำแนกด้วย AI (หัวใจของทุกวิธี)

| ปัจจัย         | รายละเอียด                                                                          |
| -------------- | ----------------------------------------------------------------------------------- |
| ข้อมูลฝึก      | ภาพพืช-วัชพืชรายแปลง (ต้องเก็บเอง/โหลดจากผู้ผลิต — ไทยยังไม่มีชุดเปิด)              |
| แบบจำลอง       | CNN/detector (deep learning) บน edge (ต่อยอด 05-005) — ตัดสินใจ <0.1–0.5 วินาที/ภาพ |
| ความแม่นยำ     | จำแนกได้สูง (งานทดลอง ~90–99%) แต่ "พืชคล้ายวัชพืช" (ต้นเล็ก/ระยะกล้า) พลาดได้      |
| การปรับตามแปลง | ต้อง calibrate ต่อแปลง/ชนิดพืช (เรียบง่ายในผักเป็นแถว — ยากในข้าวนา/แปลงผสม)        |

### 2.3 ขอบเขต

- **ครอบคลุม**: 3 เทคโนโลยี + AI + ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: การฉีดพ่นสารแม่นยำ (spot spraying — 05/02), ยากำจัดวัชพืช/ไกลโฟเซต (02-012), หุ่นยนต์เก็บผลไม้ (07-001), รถแทรกเตอร์ (07-005)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                       | ผลลัพธ์                                                    | สถานที่/เงื่อนไข           | แหล่ง  |
| ----------------------------------------------- | ---------------------------------------------------------- | -------------------------- | ------ |
| ความเร็วกำจัด (LaserWeeder)                     | ~5,000 ต้น/นาที (อ้างผู้ผลิต)                              | ฟาร์มผัก/แถว — สภาพอุดมคติ | [3]    |
| ประสิทธิภาพกำจัด (เลเซอร์/กลไก — งานทดลอง)      | ~90–99% (วัชพืชต้นเล็ก; วัชพืชใหญ่/งอกใหม่ลดลง)            | งาน/ฟาร์ม — ขึ้นชนิด/ขนาด  | [2][3] |
| ต้นทุนถอนวัชพืชด้วยมือ (ผัก/ออร์แกนิก)          | ~$150–700/เอเคอร์/รอบ (ตัวขับเคลื่อนตลาด)                  | รายงานฟาร์มสหรัฐ/ยุโรป     | [2]    |
| ต้นทุนเครื่อง/บริการ                            | เครื่อง ~$1–2 แสนดอลลาร์; รับจ้าง ~$300–600/เอเคอร์ (ช่วง) | ตลาด (สหรัฐ/ยุโรป)         | [3][4] |
| การประหยัดสารเคมี                               | ลดการใช้ยากำจัดวัชพืชได้ ~80–100% (กรณีใช้แทน)             | ฟาร์ม — เป้าหมาย           | [2][3] |
| ผลผลิตเทียบการถอนมือ/สารเคมี (งานเปรียบเทียบ)   | ไม่ด้อยกว่า (งานหลายชิ้น — ผัก) ขึ้นการจัดการ              | งานทดลอง                   | [2]    |
| การงอกใหม่ของวัชพืช (เลเซอร์ — ยอดตายแต่รากยัง) | มีบางส่วน (วัชพืชยืนต้น/ใหญ่) — ต้องทำซ้ำ                  | งานทดลอง                   | [2]    |
| ความเร็วทำงาน (ไร่/ชม.)                         | ~1–3 เอเคอร์/ชม. (ขึ้นเครื่อง/ความหนาแน่นวัชพืช)           | ฟาร์ม                      | [3]    |

- **กฎ**: "เลเซอร์/ไฟฟ้า = ไม่รบกวนดิน ไม่มีสารเคมี แต่ต้องยิงแม่น+ทำซ้ำ; กลไก = ถอนรากได้แต่รบกวนดิน" — เลือกตามชนิดวัชพืช/พืช/ราคา; ตัวเลขช่วงกว้าง (ต่างระบบ/ต่างแปลง) — ใช้เทียบเคียงทิศทาง
- **หมายเหตุ**: ตัวเลขจากผู้ผลิต (ความเร็ว/ต้นทุน) ต้องตรวจสอบอิสระ (หัวข้อ 10)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาด "agricultural weeding robots" ~$1–4 พันล้านดอลลาร์ (2030 — analyst estimate ช่วงกว้าง); ตลาดหุ่นยนต์กำจัดวัชพืชทั้งหมด (รวม smart spray) โต ~15–25%/ปี (ช่วง — ยังไม่ยืนยัน) [4]
- **ผู้เล่นหลัก**: ตาราง 3.1 + ผู้ผลิตรถแทรกเตอร์ (CNH ซื้อ Steketee, AGCO, John Deere — See & Spray class ทำ spot spray ไม่ใช่หุ่นยนต์กำจัด) + มหาวิทยาลัย (งาน AI จำแนกวัชพืช — มหาวิทยาลัยสหรัฐ/ยุโรป/ญี่ปุ่น)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                                      | ฉุดรั้ง                                             |
| ----------------------------------------------- | --------------------------------------------------- |
| แรงงานถอนวัชพืชแพง/ขาดแคลน                      | ต้นทุนเครื่อง/บริการสูง                             |
| แนวโน้มเลิกสารเคมี (กฎ/ตลาดออร์แกนิก/ผู้บริโภค) | จำกัดในแปลงผัก/แถว (ข้าว/ไร่ใหญ่ยังยาก)             |
| วัชพืชดื้อยา (glyphosate-resistant) เพิ่ม       | ต้อง calibrate ต่อแปลง/พันธุ์                       |
| AI/edge ราคาถูกลง                               | วัชพืชหลายชนิด/สภาพดินต่าง (การงอกใหม่)             |
| RaaS (รับจ้างต่อไร่) ลดภาระซื้อ                 | การยอมรับของเกษตรกร (14-003) — "เครื่องใหม่ราคาแพง" |

- **แนวโน้ม**: เลเซอร์ราคาลง/เร็วขึ้น, รวมหลายฟังก์ชัน (กำจัดวัชพืช+ให้ปุ๋ย+เก็บข้อมูล — ผูก 06-001), ขยายสู่ตลาดใหม่ (อาเซียน — ไทย/เวียดนาม ผักส่งออก), บริการรับจ้างแทนขายเครื่อง

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ยังไม่มีหุ่นยนต์กำจัดวัชพืชเชิงพาณิชย์/บริการในไทย; งานวิจัย AI จำแนกวัชพืช-ข้าว (มหาวิทยาลัยไทย — มีงาน/ต้นแบบ) ยังไม่ต่อยอดเป็นเครื่อง; ไทยใช้แรงงานถอนวัชพืช (ผัก/ข้าว) + สารเคมี (อ้อย/ข้าว/ปาล์ม) มาก [5][6]
- **จุดแข็งไทย**: งาน AI/ภาพมหาวิทยาลัยพร้อม (ต่อยอด), ผักส่งออก/ออร์แกนิก (เชียงใหม่/ราชบุรี/กาญจนบุรี) จ่ายค่าแรงถอนวัชพืชสูง — เหมาะนำร่อง, โรงเรือน (04-004) เริ่มมี, แรงงาน/ความรู้เครื่องจักรมี
- **จุดอ่อน**: ไม่มีผู้เล่น/บริการในประเทศ, ฟาร์มเล็ก/รายได้ต่ำ (ซื้อเครื่องไม่ไหว), ข้อมูลภาพวัชพืชไทยเปิดยังน้อย, การ calibrate ต่อแปลง (ข้าวนา/อ้อย — ยังยาก), ค่าแรงไทยถูกกว่า (จุดคุ้มไกลกว่า)
- **โอกาส**: (1) นำร่อง "รับจ้างกำจัดวัชพืช" ในฟาร์มผักออร์แกนิก/โรงเรือน (เช่า/ร่วมทุนกับผู้ผลิตต่างชาติ — หัวหอม/แครอท/ผักสลัด) (2) งานวิจัย "AI จำแนกวัชพืชไทย" (ข้าว/อ้อย/มันสำปะหลัง — ชุดภาพเปิด + ทดลองเลเซอร์/กลไก) (3) ผูกกับ "ผักปลอดสาร" (ตลาดส่งออก/โรงแรม — ราคาดีกว่า) (4) การใช้ในอ้อย (ลดสารเคมี — นโยบายโรงงาน)
- **หน่วยงาน**: มก./มข./มจธ./มช. (AI/แปลง), กรมวิชาการ (วัชพืช/สารเคมี), โรงงานน้ำตาล (อ้อย), NIA/สวทช. (ทุน), ผู้ส่งออกผัก/โรงแรม (ออร์แกนิก)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ชุดภาพ "พืช-วัชพืชไทย" เปิด (ข้าว/อ้อย/มัน/ผัก — หลายฤดู/หลายพื้นที่) — ยังไม่มี
- **Q2**: ประสิทธิภาพเลเซอร์/ไฟฟ้ากับวัชพืชเขตร้อน (กกช้าง/หญ้าขจรจบ/ผักโขม — งอกใหม่เร็ว) — ยังไม่มีงานไทย
- **Q3**: การใช้หุ่นยนต์กำจัดวัชพืชใน "นา/ไร่" (ไม่ใช่ผักแถว) — งานไทย/ต่างประเทศยังน้อย
- **Q4**: เศรษฐศาสตร์เทียบแรงงานไทย (ค่าแรงถอนวัชพืช/ไร่ จริง) — ยังไม่มีข้อมูลเปิด
- **Q5**: ผลต่อดิน/ความชื้น/ผลผลิต (กลไกในดินไทย — ดินเหนียว/ทราย) — ยังไม่มี
- **Q6**: ระบบ "วัชพืช+ปุ๋ย+ข้อมูล" รวมเครื่องเดียว (ต่อยอด 06-001) สำหรับแปลงไทย — ยังไม่มี
- **Q7**: มาตรฐานความปลอดภัยเลเซอร์/ไฟฟ้าในฟาร์ม (คน/สัตว์) — ยังไม่ชัด (ต่างประเทศกำลังวาง)

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                          | ระดับนโยบาย                                                                           |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | งาน "AI จำแนกวัชพืชไทย" (ข้าว/ผัก — ชุดภาพเปิด มก./มข.); นำร่องรับจ้างกำจัดวัชพืชฟาร์มผักออร์แกนิก/โรงเรือน (ร่วมทุนต่างชาติ) | ทุนวิจัย AI วัชพืชไทย (สวทช./NIA); ข้อมูลต้นทุนการถอนวัชพืช/สารเคมีรายพืช (สศก.)      |

## 11. อภิธานศัพท์

| คำศัพท์                  | ความหมาย                                               |
| ------------------------ | ------------------------------------------------------ |
| Precision weeding        | การกำจัดวัชพืชเฉพาะจุด (แม่นยำต่อต้น)                  |
| Laser weeding            | ยิงเลเซอร์ความร้อนฆ่ายอดวัชพืช (Carbon Robotics-class) |
| Mechanical weeding       | การกำจัดด้วยกลไก (จอบ/มีด/ถอน — Steketee/FarmWise)     |
| Electrical weeding       | กระแสไฟฟ้าความถี่สูงทำลายเนื้อเยื่อ (RootWave/Zasso)   |
| Meristem (จุดเจริญ)      | จุดเจริญของยอด/โคนต้น — เป้าหมายการยิงเลเซอร์          |
| Crop-weed discrimination | การจำแนก "พืช-วัชพืช" ด้วย AI (หัวใจของระบบ)           |
| Spot treatment           | การจัดการเฉพาะจุด (ต่างจากการพ่นทั้งแปลง)              |
| Glyphosate resistance    | การดื้อยาของวัชพืช (ตัวขับเคลื่อนตลาด)                 |
| Row crop                 | พืชปลูกเป็นแถว (เหมาะกับหุ่นยนต์กำจัดวัชพืช)           |
| RaaS                     | บริการรับจ้างหุ่นยนต์ต่อไร่/ต่อเอเคอร์                 |
| Organic farming          | เกษตรอินทรีย์ (ห้ามสารเคมี — ใช้หุ่นยนต์แทน)           |
| Edge AI                  | AI ประมวลผลบนตัวเครื่อง (ไม่ต้องส่ง cloud)             |
| Calibration              | การปรับระบบต่อแปลง/พันธุ์ (สำคัญมาก)                   |
| Re-growth                | การงอกใหม่ของวัชพืช (จุดอ่อนของเลเซอร์/ไฟ)             |
| IC-cultivator            | จอบอัจฉริยะ (ควบคุมตำแหน่งด้วยวิชัน)                   |
| Electrode contact        | ขั้วไฟฟ้าสัมผัสวัชพืช (วิธีไฟฟ้า)                      |
| Solar-powered robot      | หุ่นยนต์พลังงานแสงอาทิตย์ (FarmDroid)                  |
| Chemical-free weeding    | การกำจัดวัชพืชไร้สารเคมี                               |
