## 1. บทสรุปผู้บริหาร

- **ใจความ**: “ชลประทานดิจิทัล” คือการนำเซนเซอร์ความชื้นดิน + ข้อมูลสภาพอากาศ + การพยากรณ์น้ำด้วย AI/machine learning มาใช้คำนวณและสั่งรดน้ำอัตโนมัติแบบปิดวงรอบ (closed-loop) ให้จ่ายน้ำเฉพาะจุดที่รากพืชต้องการ ลดการรดเกินจริง (over-irrigation) และลดการระเหย/ไหลทิ้ง เทคโนโลยีผสม “ฮาร์ดแวร์” (ระบบน้ำหยด/สปริงเกลอร์อัตโนมัติ) กับ “ซอฟต์แวร์” (แบบจำลอง ET / AI กำหนดการรดน้ำ) โดยระดับการประหยัดน้ำแปรผันตามเส้นฐาน (baseline) เดิมของแต่ละแปลง
- **ตัวเลขสำคัญ (ยืนยันแล้ว)**: เกษตรใช้สัดส่วน ~72% ของการดึงน้ำจืดทั้งโลก โดยมีชลประทานเป็นตัวขับเคลื่อนหลัก [1]; ประชากร ~1.2 พันล้านคนอาศัยในพื้นที่เกษตรที่ขาดแคลนน้ำรุนแรง [1]; ระบบไมโคร/น้ำหยดช่วยลดการใช้น้ำได้ 20–50% เทียบกับสปริงเกลอร์แบบเดิม (EPA สหรัฐฯ) [3]; แต่เกษตรกรทั่วโลกใช้น้ำหยดเพียง ~3% (2023) [2]
- **หัวคำถาม “ประหยัดน้ำกี่ %”**: ไม่มีตัวเลขเดียว — หากเปลี่ยนจาก “รดแบบท่วมพื้น” (flood/surface) มาเป็น closed-loop น้ำหยด+AI จะประหยัดได้มาก (เทียบชั้น 20–50% ตาม [3] และน่าจะสูงกว่านั้นเมื่อเทียบกับระบบท่วม) แต่หากเพิ่ม AI scheduling ให้ระบบน้ำหยดที่จัดการดีอยู่แล้ว อัตราประหยัดเพิ่มเติมจะต่ำกว่า (ช่วง ~15–30% ยังไม่ยืนยันจากแหล่งต้นฉบับ → ดู Section 10)
- **นัยต่อไทย**: ไทยพึ่งชลประทานแบบเปิด (คลอง/ทุ่ง) เป็นหลัก — โอกาสประหยัดน้ำสูงสุดอยู่ที่การเปลี่ยนชลประทานแบบพื้นผิวให้เป็นระบบปิด/แม่นยำ + ใช้ AI วางแผนส่งน้ำตามความต้องการจริงของพืช
- **สถานะโดยรวม**: 🧪 นำร่องแปลงทดลอง + 📈 เชิงพาณิชย์เริ่มต้น (มีสินค้าขายแล้วต่างประเทศ แต่ในไทยยังกระจายจำกัด)

## 2. หลักการและขอบเขต

- **หลักการทำงาน (closed-loop)**: ทำงานเป็นวงรอบ — (1) วัด: เซนเซอร์ความชื้นดิน / ข้อมูลสภาพอากาศ (ET อ้างอิง), (2) คำนวณ: AI/แบบจำลองพยากรณ์ความต้องการน้ำของพืช (crop water requirement) + พยากรณ์ฝน/อากาศล่วงหน้า, (3) สั่งการ: วาล์ว/ปั๊มอัตโนมัติเปิดรดน้ำตามความต้องการจริง แล้ววนกลับเริ่มวงรอบใหม่ [1][2]
- **พยากรณ์น้ำด้วย AI**: ใช้อัลกอริทึม ML เช่น Random Forest / LSTM / Neural Network เรียนรู้จากข้อมูลย้อนหลัง (ฝน อุณหภูมิ ความชื้นดิน ระยะการเจริญเติบโต) เพื่อคาดการณ์ทั้ง “ปริมาณ” และ “เวลารด” แทนการรดตามตารางแบบตายตัว (timer) ที่มักรดเกินจริง [5]
- **ขอบเขตในไฟล์นี้**: กลไกปิดวงรอบชลประทานดิจิทัล, การพยากรณ์น้ำด้วย AI, ตัวเลขการประหยัดน้ำ, สถานะงานวิจัย/ตลาด, สถานการณ์ไทย — เน้นคำถามกลาง “ประหยัดน้ำกี่ %”
- **สิ่งที่ไม่อยู่ในขอบเขต**: ดัชนีความเครียดน้ำ CWSI (03-002), ชลประทานอัตราแปรผัน VRI (03-003), การเก็บน้ำในดิน/ไถอนุรักษ์ (03-004), การจัดการน้ำเค็ม (03-005) — ดูไฟล์โดเมนเดียวกัน

## 5. ตลาดและการลงทุน

- **มูลค่า/ทิศทาง**: ตลาด smart irrigation (ตัวควบคุมอัตโนมัติ + เซนเซอร์) โลกประมาณ ~1.6 พันล้านดอลลาร์สหรัฐ (2566) คาดโตเป็น ~3–4 พันล้านดอลลาร์สหรัฐภายในทศวรรษหน้า (CAGR ~13–15% — ตัวเลขจากนักวิเคราะห์ตลาด ยังต้องยืนยันข้ามสำนัก) [4] ขณะที่ตลาด precision irrigation รวม (น้ำหยด/หัวฉีด/ปั๊ม) มีขนาดใหญ่กว่าหลายเท่า แต่ adoption ยังต่ำ — โลกใช้น้ำหยด/ไมโคร-ไอริเกชันเพียง ~3% ของพื้นที่เพาะปลูก (2023) [2]
- **ผู้เล่นหลัก**: (ก) ระบบน้ำหยด/หัวฉีดรายใหญ่: Netafim, Rivulis, Jain Irrigation [8] (ข) ตัวควบคุมอัจฉริยะ + ซอฟต์แวร์กำหนดการรด: Rachio, RainMachine (ตลาดบ้าน/สวน), CropX, Phytech, Semios (ตลาดฟาร์ม — เซนเซอร์ความชื้นดิน + AI scheduling) [8] (ค) ผู้ให้บริการ agronomy-as-a-service ที่ผูกข้อมูลสภาพอากาศ/ดาวเทียม (เชื่อมโดเมน 05)
- **ปัจจัยขับเคลื่อน**: การขาดแคลนน้ำ (~1.2 พันล้านคนในพื้นที่เกษตรขาดน้ำรุนแรง [1]), ภัยแล้งซ้ำ (เอลนีโญ — เชื่อมเจาะลึก-01-001), ราคาน้ำ/ค่าไฟฟ้าสูงขึ้น, นโยบาย ESG/คาร์บอน
- **ปัจจัยฉุดรั้ง**: ต้นทุนติดตั้ง/ค่าบริการ, ความซับซ้อน (ต้องตั้งค่า/สอบเทียบ), adoption ทั่วโลกยังต่ำ [2], โครงสร้างชลประทานแบบเปิดที่เปลี่ยนยากในหลายประเทศรวมไทย [6]

## 6. สถานการณ์ประเทศไทย

- **บริบท**: ภาคเกษตรไทยเป็นผู้ใช้น้ำรายใหญ่สุดของประเทศ (สัดส่วน ~70% ของการใช้น้ำจืดทั้งหมด — ตัวเลขต้องยืนยันจากกรมทรัพยากรน้ำ/กรมชลประทาน) [6] พื้นที่เกษตรส่วนใหญ่นอกเขตชลประทานหรืออยู่ในระบบคลองส่งน้ำแบบเปิด ซึ่งการควบคุม/วัดการจ่ายน้ำท้ายคลองทำได้จำกัด (ตัวเลขพื้นที่ชลประทานต้องยืนยัน) [6]
- **งานวิจัยไทย**: มีงาน IoT/เซนเซอร์ความชื้นดิน และการประยุกต์ ML พยากรณ์น้ำกระจายในมหาวิทยาลัย/กรมชลประทานบ้าง (ต้องค้น TCI/ThaiJo ยืนยันรายชิ้น) [9]; GISTDA มีภารกิจข้อมูลน้ำ/ดาวเทียมที่ใช้เป็นแพลตฟอร์มต่อยอดได้ [7]
- **เอกชน/สตาร์ทอัพ**: บริการ smart farming/โดรนเริ่มเสนอระบบรดน้ำอัตโนมัติและวางแผนการให้น้ำในแปลงใหญ่ (อ้อย มันสำปะหลัง ไม้ผล) แต่ยังกระจายจำกัด (ยังไม่ยืนยันรายชื่อ/ขนาด) [9]
- **โครงสร้าง/นโยบายที่เอื้อหรือขวาง**: เอื้อ — แผนแม่บทการจัดการทรัพยากรน้ำแห่งชาติ, นโยบาย smart farming, โครงการเพิ่มพื้นที่ชลประทาน; ขวาง — ระบบคลองเปิด, ความรับผิดชอบหลายหน่วยงาน (กรมชลประทาน/กรมทรัพยากรน้ำ/ท้องถิ่น), งบลงทุนอุปกรณ์, เกษตรแปลงเล็กทำให้ต้นทุนต่อไร่สูง

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: “การเพิ่ม AI scheduling ลงบนระบบน้ำหยดเดิมประหยัดน้ำจริงกี่ %” — ตัวเลข ~15–30% ในหัวข้อ 4 ยังไม่ยืนยันจากแหล่งต้นฉบับโดยตรง — ต้อง meta-analysis/field trial หลายพื้นที่
- **Q2**: ตัวเลขประหยัดน้ำของไทยเมื่อเปลี่ยนจาก “รดท่วม/สปริงเกลอร์” เป็น closed-loop น้ำหยด+AI ต่อไร่ — ยังไม่มีข้อมูลแปลงจริงไทย
- **Q3**: ความแม่นยำของแบบจำลอง LSTM/ML พยากรณ์ความต้องการน้ำในลุ่มน้ำเจ้าพระยา/นาข้าวไทย (เทียบ ET ในเขตอบอุ่น) — งานยังน้อย
- **Q4**: จุดคุ้มทุน (ต้นทุนต่อไร่ vs ค่าน้ำ/ค่าไฟที่ประหยัด) ของระบบปิดในแปลงเล็กไทย — ยังไม่มีตัวเลข
- **Q5**: การยอมรับของเกษตรกรไทยต่อระบบอัตโนมัติ (ผูกกับกรอบ TAM/UTAUT — ดูเจาะลึก-14-003) — ยังขาดงานเชื่อมโยง
- **Q6**: มาตรฐานข้อมูล/API ระหว่างเซนเซอร์-แพลตฟอร์ม-กรมชลประทาน เพื่อสเกลระดับลุ่มน้ำ — ยังไม่มี

## 8. นัยต่อการนำไปใช้ (Blueprint)

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                 | ระดับนโยบาย                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | เริ่มแปลงสาธิต “น้ำหยด+เซนเซอร์+AI” ในแปลงใหญ่ (อ้อย/มันสำปะหลัง/ไม้ผล) วัดผลเทียบ baseline การรดเดิม; ใช้ตัวควบคุมอัตโนมัติราคากลาง | ตั้งมาตรฐานข้อมูลเซนเซอร์/API ระดับชาติ; สนับสนุนการติดตั้งผ่านสินเชื่อดอกเบี้ยต่ำ/เงินอุดหนุนบางส่วน (ธ.ก.ส.) |
| 2 (2–4 ปี) | ขยายเป็นบริการรับจ้างระบบน้ำอัตโนมัติ (machinery-as-a-service — เชื่อมเจาะลึก-14-004) + ผูกกับโดรนตรวจแปลง                           | อัปเดตแผนน้ำชาติให้รองรับชลประทานแม่นยำ; บูรณาการข้อมูลน้ำกับ GISTDA/กรมชลประทาน                               |
| 3 (4+ ปี)  | สเกลเต็มเป็นบริการระดับลุ่มน้ำ/จังหวัด รวมการพยากรณ์น้ำระยะยาว (LSTM class)                                                          | โครงสร้างราคาน้ำที่สะท้อนต้นทุนจริง + มาตรฐานการรับรองระบบชลประทานอัจฉริยะ                                     |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย                             | รายละเอียด                            | โอกาสแก้                                     |
| -------------------------------------- | ------------------------------------- | -------------------------------------------- |
| Adoption ต่ำทั่วโลก (~3%) [2]          | ต้นทุน/ความซับซ้อน/ความคุ้นเคย        | ตัวเลือกแบบบริการ/เช่า; การสาธิตผลตอบแทนจริง |
| ตัวเลข “% ประหยัด” ต่างกันตาม baseline | เทียบไม่เหมือนกัน → สื่อสารตลาดผิดได้ | ระบุ baseline ทุกครั้ง (กฎหัวข้อ 4)          |
| โครงสร้างชลประทานเปิดของไทย [6]        | เปลี่ยนทั้งระบบยาก/ใช้เวลานาน         | เริ่มจากแปลงใหญ่/สวนเฉพาะจุดก่อน             |
| ข้อมูล/มาตรฐานกระจัดกระจาย [7][9]      | เซนเซอร์หลายยี่ห้อ หลายหน่วยงาน       | มาตรฐาน API + แพลตฟอร์มกลาง                  |
| เกษตรแปลงเล็ก ต้นทุนต่อไร่สูง          | ไม่คุ้มติดตั้งรายแปลง                 | บริการรวม/ร่วมทุนผ่านสหกรณ์ (เจาะลึก-14-004) |
| สภาพอากาศร้อนชื้น/พายุ                 | ความแม่นยำการพยากรณ์ลดลง              | แบบจำลองเฉพาะพื้นที่ + ข้อมูลท้องถิ่น        |

## 11. อภิธานศัพท์

| คำศัพท์                     | ความหมาย                                                                   |
| --------------------------- | -------------------------------------------------------------------------- |
| Closed-loop irrigation      | ระบบรดน้ำปิดวงรอบ: วัด → คำนวณ → สั่งรด → วัดซ้ำ                           |
| ET (Evapotranspiration)     | การคายระเหยน้ำของพืช+ดิน ใช้คำนวณความต้องการน้ำ                            |
| Smart irrigation controller | ตัวควบคุมการรดอัตโนมัติที่ใช้ข้อมูลสภาพอากาศ/ความชื้นดินแทนตารางเวลาตายตัว |
| Soil moisture sensor        | เซนเซอร์วัดความชื้นดิน (capacitive/TDR)                                    |
| Baseline                    | เส้นฐานการใช้น้ำเดิมของแปลง ใช้เทียบผลประหยัด (ต่างกัน → ตัวเลข % ต่างกัน) |
| LSTM                        | โครงข่ายประสาทชนิดหนึ่ง ใช้พยากรณ์อนุกรมเวลา (เช่น ความต้องการน้ำ/ฝน)      |
| WUE                         | ประสิทธิภาพการใช้น้ำ (ผลผลิตต่อหน่วยน้ำ)                                   |
| Micro-irrigation            | ระบบให้น้ำปริมาณน้อยตรงราก (น้ำหยด/มินิสปริงเกลอร์)                        |
