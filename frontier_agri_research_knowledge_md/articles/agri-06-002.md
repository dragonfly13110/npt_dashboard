## 1. บทสรุปผู้บริหาร

- **ใจความ**: แชตบอต/ผู้ช่วย AI (LLM — GPT-class/โมเดลภาษาไทย) ให้เกษตรกร "ถาม-ตอบ/รับคำแนะนำ" ด้วยภาษาไทยง่าย ๆ (พิมพ์/เสียง) — เรื่องโรค/ปุ๋ย/ราคา/วิธีทำ (ต่อยอดความรู้จากแอปวินิจฉัย 05-002) — ผูกกับข้อมูลส่วนตัว (แปลง/เซนเซอร์/ราคา — เชื่อม 06-001) ยิ่งมีค่าขึ้น; ตลาดกำลังระเบิด (2024–2026) [1][2][3]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์แล้ว (ผู้ช่วย AI เกษตรหลายรายทั่วโลก/เริ่มในไทย) — แต่คุณภาพ/ความแม่นยำ/การยอมรับในกลุ่มเกษตรกรจริงยังเป็นประเด็น [1][2][3]
- **ตัวเลขสำคัญที่สุด**: ความแม่นยำคำแนะนำ (เทียบผู้เชี่ยวชาญ) ยังแปรผัน 60–90% (ขึ้นหัวข้อ/ภาษา); งานประเมินผู้ช่วย AI เกษตร (ต่างประเทศ) ผู้ใช้พอใจแต่ "ปฏิบัติตามคำแนะนำจริง" ยังน้อย; ต้นทุน LLM ต่อคำถามหลักสตางค์–บาท (ถูกลงมาก — เปิดโมเดล 2023+) [1][2][3]
- **นัยต่อไทย**: ไทยมี "โครงสร้างพร้อม" (การเข้าถึงมือถือ/ไลน์สูง — ต่อยอด 14-003) + งานวิจัยผู้ช่วย AI ไทยเริ่มมี (มก./มจธ./เอกชน) — จุดติดขัด: ข้อมูล/ความรู้ไทย (ภาษา/ศัพท์ท้องถิ่น/พันธุ์ไทย) และ "การไว้วางใจ" (ความผิดพลาดต้องไม่ทำร้ายเกษตรกร) [4][5][6]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์แล้ว

## 2. หลักการและขอบเขต

- **หลักการ**: LLM (โมเดลภาษาขนาดใหญ่) + การปรับแต่ง (fine-tune ข้อมูลเกษตร) หรือ RAG (ค้นความรู้/เอกสาร/ข้อมูลราคาแล้วประกอบคำตอบ) → แชต/เสียง (LINE/Facebook/แอป) → ตอบคำถาม/แนะนำ/เตือน (ผูกข้อมูลแปลง/เซนเซอร์/อากาศ — 05-007/05-008) [1][2]
- **รูปแบบ**: (1) ถาม-ตอบความรู้ทั่วไป (โรค/แมลง/ปุ๋ย) (2) ผู้ช่วยส่วนตัว (รู้แปลงของฉัน — data-aware) (3) ผู้ช่วยตัดสินใจ (วิเคราะห์ข้อมูล/แนะนำการกระทำ) (4) ผู้ช่วยเจ้าหน้าที่ (ขยายงานส่งเสริม — ต่อยอด 14-004)
- **ข้อจำกัดสำคัญ**: ภาพหลอน (hallucination — ตอบผิดแต่มั่นใจ), ความรู้ไทย/ภาษาถิ่นไม่ครบ, การอัปเดต (ความรู้ใหม่), ความรับผิดชอบ/จริยธรรม (คำแนะนำผิด = เสียหาย — ต้องมีคำเตือน/การตรวจสอบ — เชื่อม 06-005), ราคาโมเดลดีๆ ยังแพงสำหรับบริการฟรี
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/สถานะ, การยอมรับ, ไทย, แนวทางใช้
- **นอกขอบเขต**: ระบบแนะนำเฉพาะทาง (ปุ๋ย 02-012/น้ำ 03-001), การวินิจฉัยด้วยภาพ (05-002), twin (06-001)

## 3. สถานะงานวิจัย

| ช่วงเวลา  | ความก้าวหน้า                                                                                                        | แหล่ง     |
| --------- | ------------------------------------------------------------------------------------------------------------------- | --------- |
| 2019–2022 | GPT-3/LLM แรก; งาน Agri-NLP (คำถาม-ตอบเกษตร — ต่างประเทศ)                                                           | [1]       |
| 2023      | GPT-4/ChatGPT เปิด; ผู้ช่วยเกษตรรายแรก (ต่างประเทศ — งาน/สตาร์ทอัพ); งานภาษาไทยเริ่ม (AI ไทย)                       | [1][2]    |
| 2024–2025 | RAG + ผู้ช่วยผูกข้อมูลฟาร์ม; การประเมินความแม่นยำ/ความปลอดภัย; ผู้ช่วยไทยหลายราย (ไลน์/แอป); งานเสียง/ภาษาถิ่น      | [2][3][4] |
| 2026–     | แนวโน้ม: โมเดลเกษตรเฉพาะ (agricultural LLM), การผูกเซนเซอร์/ราคาแบบเรียลไทม์ (06-001), การรับรอง/มาตรฐานความปลอดภัย | [3]       |

- **เส้นแบ่ง**: เทคโนโลยีพร้อม/ราคาลง — ปัญหาจริง: ความแม่นยำ+ความรับผิดชอบ (คำแนะนำผิด), ข้อมูลไทย (ภาษา/พันธุ์/วิธีท้องถิ่น), การยอมรับ/การใช้จริงของเกษตรกร (หลายงานจบที่ "ทดลองพอใจ" ไม่ใช่ "ใช้ประจำ")

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                           | ผลลัพธ์                                       | เงื่อนไข        | แหล่ง  |
| ----------------------------------- | --------------------------------------------- | --------------- | ------ |
| ความแม่นยำคำตอบ (เทียบผู้เชี่ยวชาญ) | 60–90% (ขึ้นหัวข้อ/ภาษา/ชุดทดสอบ)             | งานประเมิน      | [1][2] |
| ผู้ใช้พอใจ (งานทดลอง)               | 70–90% พอใจ/เป็นประโยชน์                      | งาน (กลุ่มเล็ก) | [2]    |
| การปฏิบัติตามคำแนะนำจริง            | ยังต่ำ (งานต่างประเทศ — ใช้ลองมากกว่าใช้จริง) | งาน             | [2][3] |
| ต้นทุนต่อคำถาม (LLM เปิด/API)       | สตางค์–บาท (ขึ้นโมเดล/ขนาด)                   | ตลาด            | [3]    |
| การเข้าถึงมือถือ/ไลน์ของเกษตรกรไทย  | ~85–95% (มือถือ; LINE ~50–70%+)               | สถิติ           | [4][5] |
| งานผู้ช่วย AI ภาษาไทย (เริ่ม)       | มีงาน/ต้นแบบ (มก./มจธ./เอกชน — จำนวนยังน้อย)  | งาน/ข่าว        | [4][5] |
| ราคาโมเดล LLM ระดับ enterprise      | แสน–ล้านบาท/ปี (บริการ)                       | ตลาด            | [3]    |

- **กฎ**: "แม่นยำ" ยังไม่พอ — "ใช้จริง/ปฏิบัติตาม" คือตัวชี้วัดจริง (ต้องเชื่อมกับข้อมูลส่วนตัว/การเตือน/เจ้าหน้าที่); ความผิดพลาด 1 ครั้งทำลายความเชื่อถือ (ต้องออกแบบ "บอกความไม่แน่นอน/ปรึกษาเจ้าหน้าที่")
- **เงื่อนไขสำคัญ**: (1) ข้อมูลไทย (ภาษา/พันธุ์/วิธี) (2) ระบบตรวจสอบคำตอบ (RAG+การกลั่นกรอง — 06-005) (3) ช่องทางที่เกษตรกรใช้จริง (ไลน์/เสียง) (4) การผูกข้อมูลส่วนตัว (แปลง/เซนเซอร์ — ยินยอมข้อมูล) (5) ความรับผิดชอบ/จริยธรรม

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: Agri-AI/ผู้ช่วยเกษตร ~1–4 พันล้านดอลลาร์ (2025 — analyst estimate ยังไม่ยืนยัน); โต 20–40%/ปี (ฐานเล็ก แต่มาแรง) [3]
- **ผู้เล่นหลัก**: ต่างประเทศ (ผู้ช่วย AI เกษตรหลายราย — คุณภาพ/การตลาดต่างกัน; แพลตฟอร์มใหญ่ผูก LLM — John Deere/Corteva-class), โมเดลภาษาไทย (Typhoon/OpenThaiGPT/งาน มจธ./มก.), ไทย: สตาร์ทอัพ/หน่วยงานเริ่มทำผู้ช่วย (ไลน์/แอป — จำนวนน้อย) [2][3][4][5][6]
- **การลงทุน**: โมเดลเปิด + RAG ข้อมูลไทย = ต้นทุนเริ่มต้นต่ำ (หลักหมื่น–แสนบาท); โมเดลระดับ enterprise แพง (บริการ); การเป็น "บริการต่อเนื่อง" (ผูกข้อมูลฟาร์ม/ราคา — รายเดือน) มีค่า
- **แนวโน้ม**: ผู้ช่วย "รู้แปลงของฉัน" (data-aware — 06-001), เสียง/ภาษาถิ่น, การผูกการซื้อขาย/ราคา (12), การรับรองความปลอดภัย (เริ่มมีในต่างประเทศ)
- **ความเสี่ยง**: คำแนะนำผิด (ความรับผิดชอบ/ชื่อเสียง), การตลาดเกินจริง (demo เก่ง — ใช้งานจริงเพี้ยน), เกษตรกรไม่ใช้ต่อ (ทิ้งหลังลอง), คู่แข่ง LLM ใหญ่ (รายเล็กถูกกลืน)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: งานวิจัย/ต้นแบบผู้ช่วย AI ภาษาไทยเริ่มมี (มก./มจธ./OpenThaiGPT — เกษตรบางหมวด; สตาร์ทอัพเริ่ม — ไลน์/แอป); การใช้จริงกว้างยังน้อย — ส่วนใหญ่เป็น "ทดลอง"; เกษตรกรใช้ไลน์/ติ๊กต็อก/ยูทูปเป็นช่องทางข้อมูลหลักอยู่แล้ว (ช่องทางพร้อม) [4][5][6]
- **จุดแข็งไทย**: การเข้าถึงมือถือ/ไลน์สูง, ภาษาไทย/ข้อมูลงานวิจัยไทยมี (แต่กระจัดกระจาย), โมเดลภาษาไทยเปิดเริ่มมี, งานวิจัย AI มหาวิทยาลัยหลายกลุ่ม, ภาครัฐสนใจ (ส่งเสริมดิจิทัล)
- **จุดอ่อน**: ข้อมูลความรู้ไทยยังไม่จัดระบบ (ศัพท์/วิธีท้องถิ่น/พันธุ์), ผู้ช่วยที่ "รู้แปลงของฉัน" ยังไม่มี, การยอมรับ/ความเชื่อถือ (กลัวตอบผิด), เจ้าหน้าที่/ระบบหนุนหลังไม่เชื่อม, งบ/ความต่อเนื่อง
- **โอกาส**: (1) "ฐานความรู้เกษตรไทย" (ภาษาไทย/ภาพ/วิธี — จัดระบบเปิด) (2) ผู้ช่วยไทย "ภาษาไทย+เสียง+ไลน์+ผูกแปลง" (14-003) (3) ผู้ช่วยเจ้าหน้าที่ส่งเสริม (ขยายงาน — 14-004) (4) การผูกกับราคา/ตลาด (12)
- **หน่วยงาน**: มหาวิทยาลัย (มก./มจธ./มข.), กรมส่งเสริมการเกษตร/กรมวิชาการ (ความรู้), สตาร์ทอัพ AgTech, ETDA/NIA (นโยบาย AI)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: ฐานความรู้/ชุดทดสอบเกษตรไทย (ภาษาไทย/ภาพ/มาตรฐานคำตอบ) สำหรับประเมินผู้ช่วย — ยังไม่มีเปิด
- **Q2**: การประเมินผู้ช่วย AI ไทยกับเกษตรกรจริง (ความแม่นยำ/การยอมรับ/การปฏิบัติตาม — ต่อยอด 14-003) — ยังไม่มี
- **Q3**: ผู้ช่วย "รู้แปลงของฉัน" (ผูกเซนเซอร์/ราคา — 06-001/05-007) ภาษาไทย — ยังไม่มีเชิงพาณิชย์
- **Q4**: การออกแบบ "คำตอบปลอดภัย" (ความไม่แน่นอน/การส่งต่อเจ้าหน้าที่) สำหรับคำแนะนำที่เสี่ยง — ยังไม่มีมาตรฐาน
- **Q5**: เสียง/ภาษาถิ่นไทย (อีสาน/เหนือ) ในผู้ช่วย — ยังไม่มีงาน
- **Q6**: เศรษฐศาสตร์บริการผู้ช่วย (ฟรี/รายเดือน/ผูกสินค้า) ไทย — ยังไม่มี

| 1 (1–2 ปี) | ผู้ช่วยนำร่อง "ภาษาไทย+ไลน์+ถาม-ตอบความรู้" (มก./มจธ.+สตาร์ทอัพ — ข้าว/ทุเรียน/ผัก); ทดสอบกับเกษตรกร 1,000–5,000 คน (เก็บการใช้จริง) | "ฐานความรู้เกษตรไทยเปิด" (กรมวิชาการ/ส่งเสริม+มหาวิทยาลัย — จัดระบบ/มาตรฐาน); แนวทางความปลอดภัย AI คำแนะนำเกษตร |
| 2 (2–4 ปี) | ผู้ช่วย "รู้แปลงของฉัน" (ผูกเซนเซอร์/ราคา/อากาศ — 06-001/05-007/05-008) — บริการต่อเนื่อง; ผู้ช่วยเจ้าหน้าที่ส่งเสริม (14-004)       | การรับรอง/มาตรฐานผู้ช่วย AI (ความแม่นยำ/ความรับผิดชอบ); การเชื่อมข้อมูลภาครัฐ (API)                             |
| 3 (4+ ปี)  | "ผู้ช่วยเกษตรไทยประจำตัว" (ภาษา/เสียง/ทุกพืช — ใช้ระดับชาติ) — ผูกการขาย/ประกัน/คาร์บอน (11/02-002/12)                               | นโยบาย "AI เป็นบริการสาธารณะการเกษตร" (ฟรี/เปิด); กฎความรับผิดชอบ/จริยธรรม AI เกษตร                             |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย             | รายละเอียด                      | โอกาสแก้                                        |
| ---------------------- | ------------------------------- | ----------------------------------------------- |
| คำแนะนำผิด (ภาพหลอน)   | ตอบผิดแต่มั่นใจ — เสี่ยงเสียหาย | RAG+ฐานความรู้, การกลั่นกรอง (06-005), คำเตือน  |
| ข้อมูลไทยไม่ครบ        | ภาษา/พันธุ์/วิธีท้องถิ่น/ราคา   | ฐานความรู้ไทยเปิด, งานภาษาไทย, การอัปเดต        |
| การยอมรับ/ความเชื่อถือ | กลัวผิด/ไม่เคยใช้               | สาธิต/อบรม, หนุนเจ้าหน้าที่, เริ่มเรื่องปลอดภัย |
| การใช้ต่อเนื่อง        | ทดลองแล้วทิ้ง                   | ผูกข้อมูลส่วนตัว/การเตือนที่มีค่า, คุณภาพคำตอบ  |
| ต้นทุนโมเดลดี          | โมเดลแพงสำหรับบริการฟรี         | โมเดลเปิด/ภาษาไทย, รายได้อื่น (สินค้า/บริการ)   |
| ความรับผิดชอบ/จริยธรรม | ใครรับผิดเมื่อแนะนำผิด?         | มาตรฐาน/คำเตือน/การส่งต่อผู้เชี่ยวชาญ, กฎชัด    |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ความแม่นยำ 60–90% (เทียบผู้เชี่ยวชาญ)** — ตรวจงานประเมิน (ระบุภาษา/หมวด/ชุดทดสอบ)
- [ ] **ความพอใจ 70–90% / การปฏิบัติตามต่ำ** — ตรวจงาน (ระบุกลุ่ม/พื้นที่)
- [ ] **ต้นทุนต่อคำถามสตางค์–บาท** — ตรวจราคา API/โมเดลล่าสุด
- [ ] **มือถือเกษตรกรไทย ~85–95% / LINE สูง** — ตรวจสถิติ (สำนักงานสถิติ/ETDA)
- [ ] **งานผู้ช่วย AI ไทย (มก./มจธ./OpenThaiGPT/สตาร์ทอัพ)** — ตรวจ TCI/ข่าวอัปเดต
- [ ] **ตลาด Agri-AI 1–4 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **สถานะโมเดลภาษาไทย (Typhoon/OpenThaiGPT)** — ตรวจเว็บ/ข่าวล่าสุด
- [ ] **การใช้ไลน์/ยูทูปของเกษตรกรไทย** — ตรวจสถิติ/งาน (ปรับตัวเลข)

## 11. อภิธานศัพท์

| คำศัพท์                 | ความหมาย                                 |
| ----------------------- | ---------------------------------------- |
| LLM                     | โมเดลภาษาขนาดใหญ่ (GPT-class)            |
| GenAI                   | AI สร้างเนื้อหา/คำตอบ (แชต/เสียง/ภาพ)    |
| RAG                     | การค้นความรู้แล้วประกอบคำตอบ (ลดภาพหลอน) |
| Fine-tuning             | การปรับโมเดลด้วยข้อมูลเฉพาะ (เกษตร/ไทย)  |
| Hallucination           | การตอบผิดแต่มั่นใจ (อันตรายในคำแนะนำ)    |
| Agri-Advisor            | ผู้ช่วย AI ให้คำแนะนำเกษตร               |
| Data-aware assistant    | ผู้ช่วยที่รู้ข้อมูลแปลง/เซนเซอร์ส่วนตัว  |
| LINE/Facebook Messenger | ช่องทางแชตที่เกษตรกรไทยใช้จริง           |
| OpenThaiGPT/Typhoon     | โมเดลภาษาไทยเปิด (งานวิจัยไทย)           |
| Human-in-the-loop       | การส่งต่อ/ตรวจโดยคน (กรณีเสี่ยง)         |
