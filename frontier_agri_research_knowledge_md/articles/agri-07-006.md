## 1. บทสรุปผู้บริหาร

- **ใจความ**: งานเก็บเกี่ยว = "จุดคอขวด" ของฤดูกาล (เวลา 1–3 สัปดาห์/แปลง — เก็บช้า = ข้าวร่วง/อ้อยไฟไหม้/ราคาตก) — ความก้าวหน้า: (1) **รถเกี่ยวนวดข้าว/เครื่องเก็บอ้อยทันสมัยมากอยู่แล้ว** (คนขับ + เซนเซอร์ — ไม่ใช่อัตโนมัติ) (2) **อัตโนมัติ/ไร้คนเริ่มแล้ว**: รถเกี่ยวนวดอัตโนมัติ (John Deere X9 autonomy-class — สหรัฐ/ข้าวสาลี), รถเกี่ยวนวดข้าวไร้คน (ญี่ปุ่น — รับรองกับนา/ข้าว), เครื่องเก็บอ้อยไร้คน (งานวิจัย/นำร่อง — ไทยเป็นสนามจริงเพราะอ้อยล้ม/ไฟไหม้) (3) **AI ในเครื่องเก็บ**: ลดการสูญเสีย (ข้าวหลุด/อ้อยเหลือ), วัดผลผลิตเรียลไทม์ (yield mapping — ผูก 06-001/06-004) [1][2][3]
- **ขั้นพัฒนา**: 📈 เชิงพาณิชย์ (เครื่องเก็บทันสมัย + อัตโนมัติเริ่ม) — รถเกี่ยวนวดข้าวไร้คน = เชิงพาณิชย์เริ่ม (ญี่ปุ่น/สหรัฐ); เครื่องอ้อยไร้คน = นำร่อง [2][3]
- **ตัวเลขสำคัญที่สุด**: การสูญเสียการเก็บเกี่ยว (ข้าว — ร่วง/หัก/หลุด) ~3–10% (ช่วง — งาน; ขึ้นเครื่อง/สภาพ/เวลาเก็บ); อ้อย: ค่าเก็บเกี่ยว+ขน ~15–25% ของต้นทุนรวม (รายงาน — ช่วง); รถเกี่ยวนวดอัตโนมัติทำงาน ~20–24 ชม./วัน (อ้างผู้ผลิต — สลับกะ); ไทย: มีรถเกี่ยวนวดข้าว ~4–6 หมื่นคัน (ช่วง — บริการรับจ้างเก็บ) [3][4][5][6]
- **นัยต่อไทย**: ไทย = "สนามทดสอบจริง" ของการเก็บเกี่ยว: ข้าว (เกี่ยวนวดรับจ้าง — ใช้แรงงาน/ราคาแข่งกัน) อ้อย (เก็บด้วยคนตัด/เครื่องจักร — ไฟไหม้/ฝุ่น/ค่าแรง) มันสำปะหลัง (เครื่องขุด) — จุดที่ "อัตโนมัติ" ช่วยได้จริง: (1) ลดการสูญเสีย (AI ควบคุมความเร็ว/หัวตัด) (2) ทำงาน 24 ชม. (ช่วงเร่งด่วน) (3) บริการรับจ้างเก็บ (ผู้ให้บริการ — คุ้มกว่าเจ้าของแปลง) (4) ข้อมูลผลผลิตรายแปลง (yield map — ผูก 06-001) [5][6]
- **สถานะโดยรวม**: 📈 เชิงพาณิชย์แล้ว (เครื่องทันสมัย) / อัตโนมัติไร้คนเริ่ม (นำร่อง-พาณิชย์เริ่ม)

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (3 กลุ่ม)

1. **เครื่องเก็บเกี่ยวทันสมัย (มีคนขับ)**: รถเกี่ยวนวดข้าว (combine — ตัด+นวด+แยก+เก็บในตัว), เครื่องเก็บอ้อย (sugarcane harvester — ตัดยอด+ตัดลำ+ตัดโคน+หั่น+ทิ้งใบ), เครื่องขุดมัน/ขุดถั่ว (root crop harvester) — ทุกเครื่องมีเซนเซอร์ (ความชื้น/การอุดตัน/การสูญเสีย) แล้ว; ขั้นถัดไป = AI ปรับอัตโนมัติ (ความเร็ว/ความสูงหัวตัดตามสภาพ)
2. **อัตโนมัติ/ไร้คน (autonomy)**: ต่อยอด 07-005 (RTK/กล้อง/AI หลบ) กับงานเก็บ: (ก) นำทางอัตโนมัติตามแถว (ข) ระบบ "ตามกัน" (master-slave — 2 คันทำงานคู่) (ค) การทำงานอัตโนมัติเต็มขั้นตอน (เข้าปล่อง/เทข้าว — งานยาก) — รับรองแล้วในญี่ปุ่น (นา/ข้าว), สหรัฐ (ข้าวสาลี/ข้าวโพด)
3. **AI ภายในเครื่อง (smart harvesting)**: (ก) ลดการสูญเสีย (ตรวจจับรวง/ความชื้น/ปรับรอบ) (ข) **yield mapping** (วัดปริมาณ/ความชื้นทุกจุด — GPS) — ข้อมูล = แผนที่ผลผลิต (ผูก 06-001/02-012) (ค) ตรวจจับสิ่งแปลกปลอม (หิน/เหล็ก — ปกป้องเครื่อง)

### 2.3 ขอบเขต

- **ครอบคลุม**: เครื่องเก็บทันสมัย + อัตโนมัติ + AI ในเครื่อง (ข้าว/อ้อย/มัน/ธัญพืช) — **นอกขอบเขต**: หุ่นยนต์เก็บผลไม้/ผักแบบเลือกเก็บ (07-001), รถแทรกเตอร์/ไถ (07-005), การแปรรูปหลังเก็บ (โรงสี/โรงงาน), การสำรวจ/พยากรณ์ (05-006/06-004)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                   | ผลลัพธ์                                    | สถานที่/เงื่อนไข     | แหล่ง  |
| ------------------------------------------- | ------------------------------------------ | -------------------- | ------ |
| การสูญเสียการเก็บเกี่ยวข้าว (ร่วง/หลุด/หัก) | ~3–10% (ช่วง — งาน; ขึ้นเครื่อง/สภาพ/เวลา) | นา — งาน/มหาวิทยาลัย | [2][3] |
| การลดการสูญเสียด้วยการปรับอัตโนมัติ (AI)    | ~1–5% ลดลง (งาน/ผู้ผลิต — ช่วง)            | งาน/รุ่นใหม่         | [2][3] |
| สัดส่วนค่าเก็บเกี่ยว+ขนอ้อย                 | ~15–25% ของต้นทุนรวม (ช่วง)                | รายงาน/งาน           | [4][6] |
| ชั่วโมงทำงาน (ไร้คน — 2 กะ/3 กะ)            | ~20–24 ชม./วัน (อ้างผู้ผลิต)               | สหรัฐ/ญี่ปุ่น        | [3]    |
| รถเกี่ยวนวดข้าวไทย (จำนวน — ช่วง)           | ~4–6 หมื่นคัน (บริการรับจ้าง)              | กรมวิชาการ/ข่าว      | [5]    |
| ผลผลิตที่เก็บได้/วัน (เกี่ยวนวด — ช่วง)     | ~30–80 ไร่/วัน/คัน (ขึ้นเครื่อง/สภาพ)      | ไทย                  | [5]    |
| งานไร้คนเก็บเกี่ยวไทย (นำร่อง)              | มีงานศึกษา/ทดลอง (ยังไม่มีพาณิชย์)         | มข./มก./บริษัท       | [5][6] |

- **กฎ**: "การสูญเสีย 3–10% = ตัวเลขที่ AI/อัตโนมัติจะลดได้จริง (คุ้มที่ราคาข้าว/อ้อยสูง)" — "ไร้คนคุ้มเมื่อบริการรับจ้าง/แปลงใหญ่" — ตัวเลขช่วงกว้าง ใช้เทียบเคียงทิศทาง
- **หมายเหตุ**: ตัวเลขจากผู้ผลิต (ชั่วโมง/การลดสูญเสีย) ต้องตรวจอิสระ (หัวข้อ 10)

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดรถเกี่ยวนวด/เครื่องเก็บเกี่ยว ~$15–30 พันล้านดอลลาร์ (ทั่วโลก — ใหญ่); ตลาด "autonomous harvesting" (ส่วนใหม่) ~$1–3 พันล้านดอลลาร์ (2030 — analyst ช่วงกว้าง) [3][4]
- **ผู้เล่นหลัก**: ตาราง 3.1 + ผู้ผลิตเครื่องขุดมัน (ไทย/จีน/บราซิล), ผู้ให้บริการรับจ้างเก็บ (ไทย — เครือข่าย Siam Kubota-class + รายย่อย), โรงงานน้ำตาล (ควบคุม/จัดเก็บอ้อย)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                                     | ฉุดรั้ง                                  |
| ---------------------------------------------- | ---------------------------------------- |
| ค่าแรงเก็บเกี่ยวแพง/ขาดแคลน (ช่วงฤดู)          | ราคาเครื่องไร้คนสูงมาก                   |
| ระยะเวลาเก็บจำกัด (ข้าวร่วง/อ้อยไฟไหม้/ฝน)     | การบำรุง/ช่าง (เครื่องซับซ้อน)           |
| บริการรับจ้าง (ใช้หลายฤดู — คุ้มกว่าซื้อ)      | แปลงเล็ก/ไม่ต่อเนื่อง (อัตโนมัติไม่คุ้ม) |
| yield map/ข้อมูล (06-001/02-012) — เพิ่มมูลค่า | การยอมรับ/ทักษะ (14-003)                 |
| AI ลดการสูญเสีย (กำไรตรง)                      | กฎ/การรับรอง (ไร้คน — ถนน/ความปลอดภัย)   |

- **แนวโน้ม**: ไร้คนใน "บริการรับจ้าง" (เอเชีย — ไทย/เวียดนาม/อินโดนีเซีย), AI ลดสูญเสียมาตรฐาน (วัดจริง), yield map ผูกข้อมูลฟาร์ม (06-001) ครบวงจร, เครื่องอ้อยไร้คน (ออสเตรเลีย→ไทย)

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: ข้าว — รถเกี่ยวนวดข้าวแพร่หลายมาก (บริการรับจ้าง — เครือข่ายผู้ประกอบการ); อัตโนมัติ/ไร้คน = ยังไม่มีเชิงพาณิชย์ (มีงานทดลอง — มข./มก. + บริษัทนำร่อง); อ้อย — เก็บด้วยคนตัด (~60–70% — ช่วง) + เครื่องจักร (เครื่องรับจ้าง); การเผาอ้อย = ปัญหา (นโยบายลด); มันสำปะหลัง — ยังใช้แรงงานขุดมาก; งาน AI ลดการสูญเสีย/yield map = งานวิจัยเริ่ม [5][6]
- **จุดแข็งไทย**: เครือข่ายบริการรับจ้างเก็บข้าวเข้มแข็ง (ตัวกลางพร้อมรับเทคโนโลยีใหม่), งานวิศวกรรม/AgTech มหาวิทยาลัย (มข./มก./มจธ.) มี, ผู้ประกอบการเครื่องจักรในประเทศ (Siam Kubota-class), แรงกดดัน "เลิกเผาอ้อย" (นโยบาย) เร่งเครื่องจักร/เทคโนโลยี
- **จุดอ่อน**: ฟาร์มเล็ก (แปลงกระจาย — อัตโนมัติยาก), การลงทุนเครื่องไร้คนแพง (ผู้ให้บริการรายย่อยไม่ไหว), งานวิจัยไร้คนยังน้อย/เงินทุนจำกัด, การวัดการสูญเสียจริงยังไม่มีมาตรฐานไทย, ช่าง/ซ่อมระบบไฮเทคจำกัดในพื้นที่
- **โอกาส**: (1) "บริการรับจ้างเก็บอัตโนมัติ" (ผู้ให้บริการใหญ่ + เครื่องไร้คนนำเข้า — ทำงาน 24 ชม. ช่วงเร่ง) (2) งาน "AI ลดการสูญเสียข้าว" (วัด/ปรับ — ร่วม มข./มก. + ผู้ประกอบการ) (3) "yield map ข้าว/อ้อย" (ข้อมูลรายแปลง → 06-001/02-012 — งานกับโรงสี/โรงงาน) (4) เครื่องอ้อยไร้คน/ลดการเผา (นโยบาย — โรงงานสนับสนุน) (5) งานขุดมันอัตโนมัติ (ลดแรงงาน)
- **หน่วยงาน**: มข./มก./มจธ./มทส. (วิจัย), กรมวิชาการ/กรมส่งเสริม (ทดสอบเครื่อง), โรงงานน้ำตาล/โรงสี (ผู้ใช้/ข้อมูล), Siam Kubota-class/ผู้ประกอบการ (นำเข้า/บริการ), ธ.ก.ส. (สินเชื่อ)
