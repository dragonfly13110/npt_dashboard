## 1. บทสรุปผู้บริหาร

- **ใจความ**: การเพาะเลี้ยงในทะเลเปิด/นอกชายฝั่ง = ย้ายกระชังจากชายฝั่งแออัดออกไปน้ำลึก/คลื่นแรง เพื่อหลบปัญหาโรค-เห็บทะเล-พื้นที่จำกัด แต่แลกด้วยทุน/วิศวกรรม/โลจิสติกส์ที่สูงขึ้นมาก [1][2][4] — ผู้นำโลกคือ **จีน** (รัฐหนุนเต็มที่: ผลผลิต 500,000 ตัน/65.2 ล้าน ลบ.ม. ปี 2024) ตามด้วย **นอร์เวย์** (SalMar Ocean, Havfarm — ยังขาดทุน) ส่วน **สหรัฐฯ/ไทย** ยังเป็นนำร่อง [7][10][17][18]
- **ขั้นพัฒนา**: 🏭 เชิงพาณิชย์เริ่มต้น (จีน = 📈 เฉพาะกลุ่มด้วยงบรัฐ, นอร์เวย์/ปานามาเชิงพาณิชย์แต่ยังพิสูจน์กำไรไม่ได้); สหรัฐฯ/ไทย = 🧪 นำร่อง — ไทยยังไม่มีฟาร์มกระชังนอกชายฝั่งเชิงพาณิชย์แม้แต่แห่งเดียว [12][16][31]
- **ตัวเลขสำคัญที่สุด**: จีน 2024 — กระชังนอกชายฝั่ง 65.2 ล้าน ลบ.ม. ผลผลิต 50 หมื่นตัน (เพิ่ม 6.3/4.3 เท่าเทียบต้นแผน 13) คิดเป็น ~1/4 ของปลาทะเลเลี้ยงทั้งประเทศ [7]; แต่ SalMar Ocean (นอร์เวย์) FY2025 เก็บเกี่ยว 7,200 ตัน EBIT **-23.7 โครน/กก.** และ Open Blue (ปานามา ฟาร์ม cobia นอกฝั่งใหญ่สุดโลก ระดมทุน 156.9 ล้านดอลลาร์) **ยุติการเลี้ยงเชิงพาณิชย์ มี.ค. 2026** — บทเรียนว่าทรัพยากรธรรมชาติไม่คุ้มทุนถ้าไม่มีราคาพรีเมียม/งบรัฐ [10][16]; CAPEX กระชังนอกฝั่ง ~$16–24/กก. (เล็ก) ถึง $8–12/กก. (ใหญ่) [24]
- **นัยต่อไทย**: ไทยมีปลากะพงขาวผลผลิต 53,421 ตัน (2566) แต่เลี้ยงในบ่อ/กระชังชายฝั่ง ~90:10 [28] — การก้าวไปทะเลเปิดต้องเริ่มจากงานสำรวจพื้นที่/แบบจำลองกำลังผลิต + กระชัง HDPE ปรับเกรดก่อน (เหมือนจีน) ไม่ใช่ข้ามไปแพลอยน้ำเหล็กทันที [8][33]
- **สถานะโดยรวม**: 🏭 เชิงพาณิชย์เริ่มต้น (จีน/นอร์เวย์) — ไทย 🔬/🧪 ยังไม่มีเชิงพาณิชย์

## 2. หลักการและขอบเขต

- **นิยาม (ICES WGOOA 2024–2025)**: "offshore" = ระยะห่างจากฝั่ง ≥3 ไมล์ทะเล (เกินขอบฟ้า) ส่วน "exposed" = ระดับพลังงานคลื่น-กระแสน้ำ-ความลึกของพื้นที่ ซึ่งวัดด้วยดัชนี SEE/EV — พื้นที่ใกล้ฝั่งก็ exposed ได้และไกลฝั่งก็ sheltered ได้ ต้องระบุทั้ง 2 มิติ [1][2] — สหประชาชาติ/UNCLOS ยังไม่มีนิยาม "offshore aquaculture" และไม่มีกฎหมายเฉพาะ (ประเด็นกฎหมายทะเลยังค้าง) [1]
- **หลักการทางชีวภาพ**: น้ำลึก/กระแสแรง = การเจือจางของเสียดีกว่า ลดแรงกดดันเห็บทะเล-โรคจากฝูงฟาร์มชายฝั่ง อุณหภูมิคงตัวกว่า (หลบหน้าร้อนด้วยกระชังจมน้ำลึก) แต่ปลาต้องทนความเครียดคลื่น-กระแส และชนิดที่มีถุงลม (physostome) ต้องมีช่องอากาศให้เติมลมเมื่อจมน้ำ [4][6][11]
- **หลักการทางวิศวกรรม**: 3 ตระกูลหลัก — (1) กระชัง HDPE แบบถ่วง (ถูกสุด ~5 แสนหยวน/ชุด 6,000 ลบ.ม. ต้านลม 12) (2) กระชังโครงเหล็ก/แพลอยกึ่งจม (Deep Blue 1/2, Ocean Farm 1, Havfarm — ทนกว่าแต่แพง ~10 เท่า) (3) เรือเพาะเลี้ยงเคลื่อนที่ (Guoxin 1 — หลบพายุ/ตามน้ำเย็นได้ แต่ค่าน้ำมันสูง) — ระบบย่อย: การทอดสมอ (grid/turret), การให้อาหารอัตโนมัติจากเรือ/แพอาหาร, กล้อง-เซนเซอร์-ไบโอแมสออนไลน์, การจม-ลอยด้วยการถ่วงน้ำ [5][8][9]
- **ขอบเขตที่ครอบคลุม**: เทคโนโลยี/โครงการจริงปี 2010–2026, ตัวเลขผลิต-ต้นทุน, สิ่งแวดล้อม-โรค, งานไทย, Blueprint
- **นอกขอบเขต**: RAS/ระบบปิด (ไฟล์ 09-001), ชีววิทยาโรคโดยละเอียด (ไฟล์ AI กล้องใต้น้ำ), หุ่นยนต์/เซนเซอร์ในฟาร์ม (07/05), การตลาดกุ้ง

## 5. ตลาดและการลงทุน

- **ตลาด**: จีน深远海 = ผลผลิต 500,000 ตัน (2024) จากปลาทะเลเลี้ยง ~2.1 ล้านตัน; มูลค่าเศรษฐกิจภาพรวม (47 หมื่นตัน ปี 2023 ตามห่วงโซ่) >1 แสนล้านหยวน สร้างงาน 3 แสนตำแหน่ง [7]; Rabobank คาดแซลมอนนอกชายฝั่ง ≤10% ของอุปทานโลกภายในปลายทศวรรษนี้ — ถ้า CAPEX ลดเหลือ $10/กก. ต้องใช้ทุน $10,000 ล้านต่อกำลังผลิต 1 ล้านตัน [25]
- **ผู้เล่นหลัก**: จีน (Wanzefeng/Shandong Ocean Group, Guoxin, จิงไห่หยานไถ, ฯลฯ), SalMar Ocean (นอร์เวย์), Nordlaks, Open Blue (ปานามา — เปลี่ยนเป็น R&D), Ocean Era/GulfStream (สหรัฐฯ), ผู้จัดหาเทคโนโลยี: Innovasea (SeaStation/ระบบให้อาหาร), Akva (ระบบป้อนอาหารอัตโนมัติ) [9][10][13][16][24]
- **การลงทุนล่าสุด**: นอร์เวย์ — AOF จ่ายค่าพิสูจน์ใบอนุญาต 130.3 ล้านโครน (มี.ค. 2026) + กรอบ "พื้นที่นอกชายฝั่ง" (ออกแบบเลียนแบบปิโตรเลียม: områdetilsagn + พื้นที่พัฒนา) [12][14]; สหรัฐฯ — Velella Epsilon >1.5 ล้านดอลลาร์ (งบ Sea Grant/เอกชน) [18]; จีน — รื่อเจา ลงทุนรัฐ 1,000 ล้านหยวน (ศูนย์ R&D/โรงงาน/ท่า) สนับสนุน Deep Blue [9]; เอกวาดอร์/บราซิลยังเป็นงานวิชาการ
- **ปัจจัยขับเคลื่อน**: หมดพื้นที่ชายฝั่ง, โรค/เห็บทะเล (นอร์เวย์ >10% ของต้นทุนแซลมอนชายฝั่งใช้รักษาเห็บ [5]), ราคาพรีเมียม "กึ่งธรรมชาติ" (ปลาเหลืองใหญ่เรือ Guoxin ขาย ~2 เท่าชายฝั่ง [6]), นโยบายรัฐ (จีน/นอร์เวย์)
- **ปัจจัยฉุดรั้ง**: CAPEX+ค่าดำเนินการสูง (EBIT ติดลบ [10]), ความเสี่ยงพายุ/ประกัน, กฎหมาย/ใบอนุญาตลากยาว (สหรัฐฯ 8 ปี [18]), ฤดูเลี้ยงจำกัดในน้ำอุ่น (จีน/ตุรกี), ราคาแซลมอนโลกผันผวน

## 6. สถานการณ์ประเทศไทย

- **งานวิจัย**: คณะประมง มก. "ซูเปอร์กระชัง" (2564) — กระชัง 2 ชั้น (วงนอก 10 ม./วงใน 5–6 ม.) นอกฝั่งศรีราชา 2 กม. ระบบ IMTA + auto-feeding/กล้องใต้น้ำ/เซนเซอร์ออกซิเจนออนไลน์ นำแบบจากจีน+นอร์เวย์ — ยังเป็นนำร่อง ไม่ขยายเชิงพาณิชย์ [31]; กรมประมง + JICA ปรับปรุงพันธุ์ปลากะพงต้าน ISKNV (อัตราพันธุกรรม 0.285, รอด +25.4%/รุ่น, ศักยภาพลดขาดทุน 155 ล้านบาท/ปี) [30]; มก. ศึกษาปลาช่อนทะเล (cobia) กระชังชุมชนที่กระบี่ (2567) [32]
- **ภาคเอกชน**: ยังไม่มีฟาร์มกระชังทะเลเปิดเชิงพาณิชย์ในไทย — การเลี้ยงทะเลไทยกระจุกชายฝั่ง (ปลากะพงขาว 53,421 ตัน 2566 — ฉะเชิงเทรา 27.8%, สมุทรสาคร 21.1%, สมุทรสงคราม 20.9%) [28]
- **โครงสร้าง/นโยบาย**: การเพาะเลี้ยงในทะเลไทยต้องขออนุญาตตาม พ.ร.ก.การประมง 2558 และมาตรฐาน มกษ. 7016-2558 (ปลากะพง) [28] — ยังไม่มีโซน/กรอบ "พื้นที่นอกชายฝั่ง" ไม่มีมาตรฐานกระชังเหล็ก/ระบบสมอสำหรับทะเลเปิด ไม่มีงานศึกษา GIS ระดับชาติว่าทะเลไทยจุดใดเหมาะ (Q1); ข้อได้เปรียบ = ชนิดปลาเขตร้อนโตเร็ว (ปลากะพง/ปลาหมึก/ปลาช่อนทะเล) แต่อุปสรรค = มรสุม 2 ฤดู/น้ำอุ่น (จำกัดฤดูเหมือนจีน-ตุรกี) [32]

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: แผนที่ศักยภาพพื้นที่นอกฝั่งไทย (ระยะ 3–12 ไมล์) ด้วยดัชนี exposure แบบ Lojek [2] + กำลังผลิต/พายุ 50 ปี — ยังไม่มีงานไทยตีพิมพ์
- **Q2**: ต้นทุนจริง (บาท/กก.) ของกระชัง HDPE เกรดทะเลเปิด + แพให้อาหารในทะเลไทย เทียบกระชังชายฝั่ง — ยังไม่มีข้อมูลเปิด (ไม่มีฟาร์มจริงให้เก็บ)
- **Q3**: ชนิดปลาไทยที่เลี้ยงในกระชังจมน้ำได้ (ปลากะพง = physostome ต้องมีช่องอากาศ?), ความเครียดคลื่น/กระแสระยะยาว — อิงงานแซลมอนเท่านั้น [4][11]
- **Q4**: การกู้-ซ่อมตาข่าย/ดำน้ำ-ROV ในมรสุม และความปลอดภัยแรงงาน (บทเรียน AOF เข้าพื้นที่ไม่สะดวกช่วงพายุ) [12]
- **Q5**: ผลกระทบตะกอน/ธาตุอาหารในน่านน้ำไทยน้ำตื้น กระแสน้ำอ่อน (อ่าวไทยตอนใน) — งาน PEZ แบบแคนาดา/นอร์เวย์ยังไม่มีในไทย
- **Q6**: กรอบกฎหมาย/สิทธิการใช้พื้นที่นอกฝั่ง 3–12 ไมล์ของไทย (ปัจจุบันไม่มีข้อกำหนดเฉพาะ) + เกณฑ์ประกัน/การรับรอง

| Offshore aquaculture           | การเพาะเลี้ยงนอกฝั่ง (ICES แนะนำ ≥3 ไมล์ทะเลจากฝั่ง — เกินขอบฟ้า)  |
| Exposed aquaculture            | การเพาะเลี้ยงในพื้นที่พลังงานคลื่น/กระแสสูง (วัดด้วยดัชนี SEE/EV)  |
| HDPE gravity cage              | กระชังถ่วงน้ำพลาสติก HDPE — ถูกสุด/นิยมสุดในจีน                    |
| Steel truss cage               | กระชังโครงเหล็ก/แพลอยน้ำ (Deep Blue, Ocean Farm 1, Havfarm)        |
| Submersible / Semi-submersible | กระชังจมน้ำเต็ม/กึ่งจม — หลบคลื่น-อุณหภูมิผิวน้ำ                   |
| Aquaculture vessel (工船)      | เรือเพาะเลี้ยงเคลื่อนที่ (Guoxin 1) — หลบพายุ/ตามน้ำเย็น           |
| Mooring (สมอ)                  | ระบบยึดจอด: grid (ตาราง), turret (หมุนตามคลื่น), single point      |
| Hs (Significant Wave Height)   | ความสูงคลื่นนัยสำคัญ — ตัวตั้งออกแบบโครงสร้าง (AOF = 6.7 ม.)       |
| MTB (Maximum Allowed Biomass)  | ชีวมวลสูงสุดที่ใบอนุญาตอนุญาต (นอร์เวย์)                           |
| Physostome                     | ปลามีท่อเชื่อมถุงลม-หลอดอาหาร ต้องเติมอากาศผิวน้ำ (แซลมอน/ปลากะพง) |
| Sea lice (เห็บทะเล)            | ปรสิตหลักของแซลมอน — ตัวขับเคลื่อนการย้ายออกนอกฝั่ง                |
| HAB (ขี้ปลา/แพลงก์ตอนพิษ)      | การบานของแพลงก์ตอนพิษ — หลบได้ด้วยน้ำลึก/กระแสแรง                  |
| IMTA                           | ระบบเลี้ยงผสมหลายชั้นอาหาร (ปลา+หอย+สาหร่าย) ลดของเสีย             |
| FAD                            | ตัวรวมฝูงปลา — กระชังนอกฝั่งดึงดูดปลาเศรษฐกิจ (บทเรียน Velella)    |
| PEZ (Potential Exposure Zone)  | ขอบเขตพื้นที่เสี่ยงรับตะกอนอาหาร/อุจจาระจากกระชัง (แบบจำลองแคนาดา) |
