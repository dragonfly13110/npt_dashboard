## 1. บทสรุปผู้บริหาร

- **ใจความ**: โดรนพ่นสาร (spraying drone/UAV) = โดรนแบกถังสาร (10–40 ลิตร) + หัวฉีด (sprayer) บินพ่นเหนือแปลงตามแผนที่ — ได้เปรียบเหนือเครื่องพ่นภาคพื้น: (1) ใช้ในแปลงที่เครื่องเข้ายาก (ข้าวนาปัก/แปลงเล็ก/ลาดชัน/ผลไม้สูง) (2) เร็ว (ไร่/ชม. มากกว่า) (3) คนไม่สัมผัสสาร (ปลอดภัย) (4) ผูกภาพถ่าย (พ่นตามจุด/แม่นยำ — spot spray) — เอเชีย = "หัวหอก" (จีน — DJI Agras-class/XAG ใช้เป็นหลักสิบล้านไร่; ไทย/เวียดนาม/อินโดนีเซีย/อินเดีย โตเร็ว) [1][2][3]
- **ขั้นพัฒนา**: 📈 เชิงพาณิชย์แล้ว/แพร่ (เอเชีย) — งานวิจัยต่อยอด = พ่นตามจุด (AI), ฝูงโดรน, การรับรอง/กฎ [2][3]
- **ตัวเลขสำคัญที่สุด**: โดรนพ่น ~15–30+ ไร่/ชม. (อ้างผู้ผลิต — เทียบคนพ่นสะพาย 2–5 ไร่/ชม.); ลดน้ำ/สารได้ ~30–90% (งาน/ผู้ผลิต — ช่วง; ขึ้นการพ่นตามจุด/ปริมาณสาร); ตลาดโดรนเกษตร ~$2–5 พันล้านดอลลาร์ (ทั่วโลก — ช่วง) และเอเชียเป็น ~50%+ (ช่วง); จีน: โดรนพ่นครอบคลุมพื้นที่เกษตรหลายสิบล้านไร่/ปี (ข่าว — ช่วง) [1][2][3][4]
- **นัยต่อไทย**: ไทยใช้โดรนพ่นแล้วแพร่ (ข้าว/ยาง/ปาล์ม/ผลไม้ — ผู้ให้บริการรับจ้างหลายพันราย; ~2–3 หมื่น+ เครื่อง — ช่วง) — "นวัตกรรมที่คนไทยรับไปเองเร็วสุด" — ประเด็นที่ต้องตาม: (1) กฎการบิน/การรับรอง (CAAT) (2) ความปลอดภัย (สารกระจาย/ลม) (3) การพ่นตามจุด (AI — ลดสาร — ต่อยอด 05-006) (4) ฝูงโดรน (การประสาน — งานใหญ่) (5) ผลต่อสุขภาพ/สิ่งแวดล้อม (การวัดจริง) [5][6]
- **สถานะโดยรวม**: 📈 เชิงพาณิชย์แล้ว/แพร่ (ไทย/เอเชีย) — ต่อยอด = AI/ฝูง/กฎ

## 2. หลักการและขอบเขต

### 2.1 หลักการทำงาน (5 ชั้น)

1. **ตัวเครื่อง (airframe)**: โดรนมัลติโรเตอร์ (DJI Agras-class/XAG — ใหญ่/แบกถัง), แบตเตอรี่ (บิน 10–25 นาที/ถัง), ถังสาร 10–40 ลิตร, หัวฉีด (atomizer/หัวพ่นละออง — ขนาดหยดควบคุม)
2. **การพ่น (application)**: หัวฉีด + การคุมความสูง (เซนเซอร์/RTK — 2–4 ม. เหนือทรงพุ่ม), ความกว้างรางพ่น (swath), ขนาดหยด (droplet size — ลม/เป้า) — ต่อยอดความรู้การพ่น (เทียบเครื่องพ่น)
3. **การนำทาง/แผนที่ (navigation)**: RTK-GPS + แผนที่แปลง (polygon — บินตามเส้นทางอัตโนมัติ), การหลบ (ต้นไม้/สายไฟ/คน — กล้อง/เรดาร์), ทำงานตอนลมน้อย (เช้า/เย็น)
4. **AI/ข้อมูล (ต่อยอด 05-005/05-006)**: (ก) ภาพสำรวจ (NDVI-class) → แผนที่พ่น (จุด/ปริมาณต่างกัน — spot/spatial spray) (ข) การตรวจจับโรค/วัชพืช → พ่นเฉพาะจุด (ค) การบันทึกการพ่น (ข้อมูล — ผูก 06-001)
5. **การควบคุม/ฝูง (fleet/control)**: 1 คนคุมหลายโดรน (ฝูง — งานใหญ่; เริ่มในจีน/ไทย), การบินอัตโนมัติ/ตรวจสอบระยะไกล (05-003)

### 2.2 เทคโนโลยีแยกย่อย

| เทคโนโลยี                    | รายละเอียด                  | ผู้เล่น                                            | สถานะ                      |
| ---------------------------- | --------------------------- | -------------------------------------------------- | -------------------------- |
| โดรนพ่น (หลัก)               | มัลติโรเตอร์ 10–40 ลิตร     | DJI (Agras T-series), XAG, ผู้ผลิตจีน/ไทย (ประกอบ) | เชิงพาณิชย์/แพร่ (เอเชีย)  |
| พ่นตามจุด (spot/smart spray) | ผูกภาพ AI → เฉพาะจุด/ปริมาณ | งานวิจัย/รุ่นใหม่ (DJI-class เริ่ม)                | นำร่อง/เริ่มพาณิชย์        |
| ฝูงโดรน                      | หลายเครื่องประสานงาน        | จีน (ใหญ่) / ไทยเริ่ม                              | นำร่อง/เริ่ม               |

| โดรนเพาะเมล็ด/หว่านปุ๋ย      | บรรทุกเมล็ด/ปุ๋ย (ต่อยอด)   | DJI-class (จีน — ข้าว)                             | เชิงพาณิชย์ (จีน/เริ่มไทย) |

### 2.3 ขอบเขต

- **ครอบคลุม**: เทคโนโลยี/สถานะ/ตัวเลข/ตลาด/ไทย/แนวทางใช้ — **นอกขอบเขต**: โดรนสำรวจ/ภาพถ่าย (05-006), AI บนเครื่อง (05-005 — อ้างข้าม), การพ่นภาคพื้น/เครื่องจักรใหญ่ (07-005/07-006), การใช้สารเคมี/ทางเลือก (07-002/02)

## 4. ผลลัพธ์เชิงประจักษ์ (ตัวเลข)

| ตัวชี้วัด                                   | ผลลัพธ์                                                  | สถานที่/เงื่อนไข         | แหล่ง  |
| ------------------------------------------- | -------------------------------------------------------- | ------------------------ | ------ |
| ความเร็วพ่น (โดรน)                          | ~15–30+ ไร่/ชม. (อ้างผู้ผลิต; เทียบคนสะพาย ~2–5 ไร่/ชม.) | ฟาร์ม — ขึ้นเครื่อง/แปลง | [1][3] |
| การลดน้ำ/สาร (พ่นทั่วไป vs พ่นตามจุด)       | ~30–90% (ช่วง — งาน/ผู้ผลิต; ขึ้นระบบ)                   | งาน/แปลง                 | [2][3] |
| ความสม่ำเสมอการพ่น (โดรน vs เครื่องภาคพื้น) | เทียบได้/ดีบางกรณี (งาน — ขึ้นลม/ความสูง)                | งานทดลอง                 | [2]    |
| ราคาโดรนพ่น                                 | ~1.5–5 แสนบาท/เครื่อง (รุ่นพาณิชย์ — ช่วง)               | ตลาดไทย                  | [5]    |
| ค่าบริการพ่น (รับจ้าง — ไทย)                | ~50–150 บาท/ไร่ (ช่วง — ขึ้นพื้นที่/สาร)                 | ตลาดไทย                  | [5]    |
| จีน — พื้นที่พ่นด้วยโดรน                    | หลายสิบล้านไร่/ปี (ข่าว — ช่วง)                          | ข่าว/ผู้ผลิต             | [1][4] |
| ตลาดโดรนเกษตร                               | ~$2–5 พันล้านดอลลาร์ (ทั่วโลก — ช่วง); เอเชีย ~50%+      | analyst                  | [4]    |
| จำนวนโดรนพ่นไทย (ประมาณ)                    | ~2–3 หมื่น+ เครื่อง (ช่วง)                               | กรมวิชาการ/ข่าว          | [5][6] |

- **กฎ**: "โดรนพ่น = เร็ว + ปลอดภัยคน + ใช้แปลงยากได้" แต่ "ผลการพ่นขึ้นลม/ความสูง/หัวฉีดมาก — ต้องวัดจริง (หยดกระจาย)" — ตัวเลขช่วงกว้าง/จากผู้ผลิต — ใช้เทียบเคียงทิศทาง (ตรวจหัวข้อ 10)
- **หมายเหตุ**: "การประหยัดสาร 30–90%" ส่วนใหญ่มาจาก "พ่นตามจุด" (ไม่ใช่พ่นทั่ว) — ต้องแยกแยะ

## 5. ตลาดและการลงทุน

- **ขนาดตลาด**: ตลาดโดรนเกษตร ~$2–5 พันล้านดอลลาร์ (ทั่วโลก — analyst ช่วงกว้าง); โต ~15–25%/ปี (ช่วง); เอเชีย = ใหญ่สุด (จีน + อาเซียน) [4]
- **ผู้เล่นหลัก**: DJI Agriculture (ผู้นำ), XAG, Yamaha (ญี่ปุ่น), ผู้ให้บริการรับจ้างไทย (หลายพันราย), ตัวแทนจำหน่าย/ประกอบไทย (นำเข้า — ราคา), งานวิจัย (มหาวิทยาลัย — พ่นตามจุด/ฝูง/การวัด)

### 5.1 ตัวขับเคลื่อน/ฉุดรั้ง

| ขับเคลื่อน                       | ฉุดรั้ง                                        |
| -------------------------------- | ---------------------------------------------- |
| แรงงานพ่นยาก/ขาด (ข้าว/ผลไม้สูง) | กฎการบิน/การรับรอง (CAAT — บินต้องขึ้นทะเบียน) |
| ประหยัดน้ำ/สาร (ราคาสารแพง)      | ลม/สภาพอากาศ (พ่นได้เฉพาะเวลาที่ลมน้อย)        |
| เร็ว (ไร่/ชม.) + แปลงยาก         | ความปลอดภัย (สารกระจาย/ผู้คนใกล้เคียง)         |
| ราคาโดรนลง/ผู้ให้บริการหลาย      | การพ่นไม่ได้ผลบางกรณี (ทรงพุ่มหนา/ลมแรง)       |
| AI/พ่นตามจุด (ลดสารอีก)          | การวัดผลจริง/มาตรฐานยังไม่ชัด (ไทย)            |

- **แนวโน้ม**: พ่นตามจุด (ภาพ→พ่น) แพร่ (ผูก 05-006), ฝูงโดรน (จีน→อาเซียน), รุ่นใหญ่ (50–60 ลิตร), โดรนพ่นในผลไม้/ยาง (ลาดชัน), การวัดสุขภาพ/สิ่งแวดล้อม (ผลจริง) เป็นวาระ

## 6. สถานการณ์ประเทศไทย

- **สถานะ**: โดรนพ่นแพร่แล้วในไทย (ข้าว — ภาคกลาง/อีสาน, ยาง/ปาล์ม/ผลไม้ — ใต้/ตะวันออก; ผู้ให้บริการรับจ้างหลายพันราย; ~2–3 หมื่น+ เครื่อง — ช่วง); กฎ: การบินต้องขึ้นทะเบียน/ได้รับอนุญาต (CAAT) + ผู้บังคับต้องมีใบอนุญาต (ช่วง); การพ่นตามจุด/ฝูง = ยังน้อย (นำร่อง); งานวิจัยโดรนไทย (มก./มข./มจธ. — การพ่น/การวัด) มี [5][6]
- **จุดแข็งไทย**: ผู้ให้บริการรับจ้างพร้อม (โครงสร้าง — ขยายบริการได้), ราคาสารแพง (แรงจูงใจประหยัด), แปลงข้าว/ผลไม้เหมาะ (พ่นยากด้วยเครื่อง), งานวิจัย/มหาวิทยาลัยมี, หน่วยงานเริ่มวางกฎ (CAAT/กรมวิชาการ)
- **จุดอ่อน**: กฎ/การบังคับยังไม่สมบูรณ์ (บางพื้นที่บินไม่ตามกฎ — ความปลอดภัย), การวัดผลการพ่นจริง (หยด/การกระจาย) ยังไม่มีมาตรฐานไทย, การพ่นตามจุดยังน้อย, ผู้ใช้บางกลุ่มขาดทักษะ (การผสมสาร/ความสูง/ลม), ผลกระทบสุขภาพ/สิ่งแวดล้อมยังไม่ได้ประเมิน
- **โอกาส**: (1) "บริการพ่นตามจุด" (ผูกภาพ 05-006 — ลดสาร 30–90% — ผู้ให้บริการใหญ่) (2) งาน "มาตรฐานการพ่นโดรนไทย" (การวัดหยด/การกระจาย — กรมวิชาการ+มหาวิทยาลัย) (3) ฝูงโดรนสำหรับแปลงใหญ่ (ข้าว — ผู้ให้บริการ) (4) การใช้ในผลไม้สูง (ทุเรียน/ยาง — ราคาสาร/แรงงานสูง) (5) การบันทึกข้อมูลพ่น (ผูก 06-001 — ติดตามสาร/ใบรับรอง)
- **หน่วยงาน**: CAAT (กฎการบิน), กรมวิชาการ (สาร/การพ่น/มาตรฐาน), กรมส่งเสริม (ผู้ให้บริการ/อบรม), มก./มข./มจธ. (งานวิจัย), สมาคม/ชมรมผู้ให้บริการโดรนไทย, ผู้ผลิต/ตัวแทน (DJI-class)

## 7. ช่องว่างงานวิจัย (Open Questions)

- **Q1**: มาตรฐาน "การวัดผลการพ่นโดรนไทย" (หยด/การกระจาย/การซึม — ข้าว/ยาง/ทุเรียน) — ยังไม่มี
- **Q2**: พ่นตามจุดสำหรับพืชไทย (ข้าว/อ้อย/ทุเรียน — ภาพ+ปริมาณสาร) — ยังไม่มีงานพาณิชย์
- **Q3**: ผลต่อสุขภาพ/สิ่งแวดล้อมของโดรนพ่น (การกระจายสาร/คนในพื้นที่) — ยังไม่มีงานไทย
- **Q4**: ฝูงโดรนในแปลงไทย (การประสาน/การหลบ/กฎ) — ยังไม่มี
- **Q5**: เศรษฐศาสตร์ "พ่นตามจุด vs พ่นทั่ว" ไทย (บาท/ไร่ — ราคาสาร) — ยังไม่มีข้อมูลเปิด
- **Q6**: การพ่นผลไม้สูง/ลาดชัน (ทุเรียน/ยาง — เทคนิค/การวัด) — ยังไม่มีงาน
- **Q7**: การยอมรับ/ทักษะผู้ให้บริการไทย (การอบรม/มาตรฐานวิชาชีพ) — ยังไม่มี

| ขั้น       | ระดับฟาร์ม/ธุรกิจไทย                                                                                                                           | ระดับนโยบาย                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 1 (1–2 ปี) | "บริการพ่นตามจุด" (ผู้ให้บริการใหญ่ + ภาพ 05-006 — ข้าว/อ้อย); งานมาตรฐานการพ่น (กรมวิชาการ+มหาวิทยาลัย); อบรมผู้ให้บริการ (ทักษะ/ความปลอดภัย) | มาตรฐาน/กฎโดรนพ่นไทย (CAAT+กรมวิชาการ — บังคับ/ตรวจสอบ); ข้อมูลการใช้สาร/พื้นที่ (ติดตาม) |

| 3 (4+ ปี)  | "การพ่นแม่นยำระดับชาติ" (พ่นตามจุด+ฝูง+ข้อมูล — ทุกพืชหลัก); ผูกการติดตามสาร/ใบรับรอง (ส่งออก — 12)                                            | นโยบาย "ลดสารเคมีด้วยโดรนแม่นยำ" (เป้าหมาย %); กฎ/การบังคับครบวงจร (ความปลอดภัย)          |

## 9. ความท้าทายและข้อจำกัด

| ความท้าทาย          | รายละเอียด                                | โอกาสแก้                                           |
| ------------------- | ----------------------------------------- | -------------------------------------------------- |
| ลม/สภาพอากาศ        | พ่นไม่ได้/หยดปลิว (ผลการพ่นลด)            | ทำงานช่วงลมน้อย, หัวฉีดคุมหยด, การพยากรณ์ (05-008) |
| กฎ/การบังคับ        | บินไม่ขึ้นทะเบียน/ไม่ปลอดภัย (บางพื้นที่) | บังคับ/ตรวจสอบ (CAAT), อบรมผู้ให้บริการ            |

| การยอมรับ/ทักษะ     | ผู้ใช้บางกลุ่มไม่รู้วิธีที่ถูกต้อง        | อบรม/ใบรับรอง (วิชาชีพ), สาธิตผล                   |
| ฝูงโดรน             | การประสาน/หลบ/การชาร์จ                    | งานวิจัย (Q4), ผู้ให้บริการใหญ่ก่อน                |

## 10. สมมติฐานที่ต้องตรวจสอบ (สำหรับ AI รอบหน้า)

- [ ] **ความเร็วพ่น 15–30+ ไร่/ชม. (เทียบคน 2–5 ไร่/ชม.)** — ตรวจผู้ผลิต/งาน (ระบุเครื่อง)
- [ ] **ลดน้ำ/สาร 30–90% (พ่นตามจุด)** — ตรวจงาน/ผู้ผลิต (ระบุระบบ/ปี)
- [ ] **DJI Agras-class ผู้นำตลาด / รุ่น 30–50+ ลิตร** — ตรวจเว็บ/ข่าวล่าสุด
- [ ] **จีนพ่นด้วยโดรนหลายสิบล้านไร่/ปี** — ตรวจข่าว/เอกสาร
- [ ] **ราคาโดรนพ่นไทย 1.5–5 แสนบาท / บริการ 50–150 บาท/ไร่** — ตรวจตลาด/ข่าว (ระบุปี)
- [ ] **โดรนพ่นไทย ~2–3 หมื่น+ เครื่อง** — ตรวจกรมวิชาการ/ข่าว (ระบุปี)
- [ ] **กฎ CAAT (ขึ้นทะเบียน/ใบอนุญาต — สถานะ)** — ตรวจเอกสาร/ข่าวล่าสุด
- [ ] **ตลาดโดรนเกษตร $2–5 พันล้านดอลลาร์** — ตรวจ analyst report ระบุปี
- [ ] **งานวิจัยโดรนพ่นไทย (มก./มข./มจธ.)** — ตรวจ TCI/ThaiJo (ระบุชิ้น)
- [ ] **ผลการพ่นเทียบเครื่องภาคพื้น (งาน)** — ตรวจงานทดลอง (ระบุปี/พื้นที่)
