## 1. บทสรุปผู้บริหาร

การขยายพื้นที่ปลูกกัญชงอุตสาหกรรมเพื่อเก็บเส้นใยและเมล็ดพันธุ์ในแปลงขนาดใหญ่ เขตอำเภอกำแพงแสนและบางเลน จังหวัดนครปฐม จำเป็นต้องประยุกต์ใช้เทคโนโลยีเกษตรแม่นยำ (Precision Agriculture) และโดรนสำรวจสเปกตรัมสูง (Multispectral UAV) ร่วมกับแบบจำลองปัญญาประดิษฐ์ (AI/ML) เพื่อประเมินความสมบูรณ์ทรงพุ่ม และทำนายความเสี่ยงการพุ่งสูงของระดับสาร $\Delta^9$-THC เกินขีดจำกัดทางกฎหมาย ($> 0.2\%\text{ w/w}$) ที่เกิดจากความเครียดด้านอุณหภูมิและภัยแล้ง ขณะเดียวกันสำหรับระบบ Indoor PFAL การใช้ระบบคุมแวดล้อมอัตโนมัติ (IoT Control & SCADA) ช่วยบริหารจัดการสเปกตรัมแสง PPFD, ความเข้มข้น $CO_2$, EC/pH และ VPD แบบเรียลไทม์ ส่งผลให้ได้มวลชีวภาพเส้นใยและช่อดอกแห้งคุณภาพสูงสม่ำเสมอทั้งแปลง

- **สถานะการวิจัย/การประยุกต์**: 🔬 งานวิจัยโดรนสแกน multispectral มก.กำแพงแสน 🧪 แปลงทดสอบกัญชงเส้นใยบางเลน 🏭 ระบบอุตสาหกรรมแปรรูปเส้นใยและสกัดสาร

## 2. หลักการและขอบเขตวิจัย

- **การประมวลผลดรรชนีพืชพรรณด้วยโดรน Multispectral (UAV Sensing)**:
  - ใช้กล้องถ่ายภาพ multispectral ติดตั้งบนโดรน จับสัญญาณสะท้อนแสง 5 ย่านคลื่น: Blue ($475\,\text{nm}$), Green ($560\,\text{nm}$), Red ($668\,\text{nm}$), Red Edge ($717\,\text{nm}$), และ Near-Infrared ($842\,\text{nm}$)
  - คำนวณดรรชนีพืชพรรณสำคัญ:
    $$\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}}$$
    $$\text{NDRE} = \frac{\text{NIR} - \text{Red Edge}}{\text{NIR} + \text{Red Edge}}$$
    $$\text{CCCI} = \frac{\text{NDRE}}{\text{NDVI}}$$
  - ค่า NDRE และ CCCI สะท้อนความเข้มข้นคลอโรฟิลล์และระดับไนโตรเจนในเนื้อเยื่อกัญชงได้อย่างแม่นยำโดยไม่เกิดปัญหาสภาพอิ่มตัว (Saturation) เหมือน NDVI ในแปลงกัญชงทรงพุ่มหนาแน่น
- **แบบจำลองพาดิพของความเครียดต่อค่า THC (THC Spike Prediction Model)**:
  - เมื่อกัญชงเจ็บป่วยจากความเค็ม ความร้อน หรือการขาดน้ำ ปริมาณเอนไซม์ _THCA Synthase_ จะถูกกระตุ้นเป็นพิเศษ ส่งผลให้ระดับ $\Delta^9$-THC ในช่อดอกพุ่งเกิน $0.2-0.3\%\text{ w/w}$ ส่งผลให้แปลงถูกสั่งทำลาย
  - ใช้ Machine Learning (Random Forest & XGBoost Algorithm) ประมวลผลค่า NDRE ร่วมกับอุณหภูมิสะสม (Growing Degree Days: GDD) เพื่อเตือนภัยความเสี่ยง THC พุ่งสูงล่วงหน้า 14 วันก่อนการเก็บเกี่ยว
- **ระบบควบคุมแวดล้อม Indoor อัตโนมัติ (IoT & SCADA Integration)**:
  - เครือข่ายเซ็นเซอร์ไร้สาย (Wireless Sensor Nodes) วัดอุณหภูมิ, RH, VPD, PPFD, $CO_2$, EC/pH ของวัสดุปลูก ส่งข้อมูลเข้า SCADA Controller
  - อัลกอริทึม PID & Fuzzy Logic ควบคุมการปรับหรี่ไฟ LED, การฉีดจ่ายปุ๋ยอัตโนมัติ (Automated Fertigation Dosage) และการเติมก๊าซ $CO_2$
- **ขอบเขตพื้นที่**: แปลงปลูกกัญชงเส้นใย อ.บางเลน, อ.กำแพงแสน และห้องปฏิบัติการเกษตรอัจฉริยะ มก.กำแพงแสน

## 3. สรีรวิทยาและสภาพแวดล้อมเฉพาะนครปฐม

- **ลักษณะการเติบโตของกัญชงเส้นใยในพื้นที่นครปฐม**:
  - กัญชงพันธุ์เส้นใย (เช่น KU-Hemp 04) มีอัตราการยืดตัวของลำต้นสูงมาก ($3-5\,\text{cm/day}$) ต้องใช้น้ำและไนโตรเจนสูงในระยะทำใบ การสำรวจด้วยสายตาไม่สามารถครอบคลุมแปลงขนาดใหญ่ $> 50$ ไร่ ได้ทันท่วงที
  - การใช้โดรนบินที่ความสูง $50\,\text{meters}$ ให้ความละเอียดภาพ (Ground Sampling Distance: GSD) $2.5\,\text{cm/pixel}$ สามารถระบุพื้นที่ขาดปุ๋ย N และจุดระบาดของแมลงได้อย่างแม่นยำ

## 5. เทคนิคการจัดการปลูก ดิน ปุ๋ย และน้ำ

- **ผังโครงสร้างระบบ Precision Smart Farming สำหรับกัญชง**:

```
[โดรน Multispectral UAV บินสแกนแปลง] ──► [ประมวลผลดรรชนี NDRE / CCCI / Canopy Height]
                                                         │
                                                         ▼
[AI Model วิเคราะห์ความเสี่ยง THC / N Stress] ◄── [ cloud Server & GIS Mapping]
                 │
                 ▼
[แผนที่การจ่ายปุ๋ยแปรผัน (VRA Map)] ──► [โดรนพ่นปุ๋ยทางใบ / ระบบน้ำหยดอัตโนมัติ]
```

- **การจ่ายปุ๋ยตามอัตราแปรผัน (Variable Rate Application: VRA)**:
  - โซนที่ค่า NDRE $< 0.45$: จ่ายปุ๋ย N เพิ่มเติม $25\,\text{kg N/ไร่}$ ผ่านระบบน้ำหยด
  - โซนที่ค่า NDRE $> 0.65$: ลดอัตราการจ่ายปุ๋ย N เพื่อป้องกันลำต้นเปราะหักและลดการสะสมกรดแคนนาบินอยด์เกินกำหนด

## 6. การจัดการโรคและศัตรูพืชสำคัญ

- **การตรวจจับจุดระบาดของหนอนเจาะสมอฝ้าย (_Helicoverpa armigera_) ด้วยโดรน thermal**:
  - หนอนเจาะยอดทำให้เกิดความร้อนสะสมบริเวณทรงพุ่มที่เสียหาย โดรนติดกล้องความร้อน (Thermal IR Camera) สามารถตรวจจับอุณหภูมิใบที่สูงขึ้น $1.5-2.0^\circ\text{C}$ จากการหยุดคายน้ำ นำไปสู่การปล่อยแตนเบียน _Trichogramma_ spp. เฉพาะจุด (Spot-release)

## 7. นวัตกรรมและเทคโนโลยีหลังการเก็บเกี่ยว

- **การคาดการณ์วันเก็บเกี่ยวด้วย Thermal & Spectral Integration**:
  - ประเมินดรรชนีการสุกแก่ของเส้นใยและช่อดอกเพื่อวางแผนการใช้เครื่องจักรเก็บเกี่ยว (Hemp Harvester) ในแปลงขนาดใหญ่ ช่วยลดการสูญเสียเส้นใยจากการเก็บเกี่ยวล่าช้าได้ $15-20\%$

## 9. ข้อจำกัดและความท้าทายในพื้นที่

- **ต้นทุนอุปกรณ์เซ็นเซอร์และกล้อง Multispectral**: มีราคานำเข้าสูง ต้องอาศัยบริการแบบถ่ายทอดเทคโนโลยี (Service Model) จากมหาวิทยาลัยเกษตรศาสตร์
- **ข้อจำกัดสัญญาณไร้สายในพื้นที่ห่างไกล**: แปลงกัญชงในเขตบางเลนบางส่วนมีปัญหาการเชื่อมต่อสัญญาณ 5G/IoT ต้องใช้ระบบ Local Edge Computing
